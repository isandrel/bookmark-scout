Building agents with MCP

Give an agent tools through a small, typed server instead of custom glue code.

Rae Ilunga · Updated Oct 9, 2026 · 6 min

The Model Context Protocol is an open protocol for connecting AI applications to tools and data. A server describes what it offers (tools, resources, and prompts), and the client inside the AI application calls them with JSON-RPC messages.

Each tool has a name, a description the model reads, and a JSON Schema for its input, so the agent knows exactly what to send.

{
  "name": "search_notes",
  "description": "Find notes that mention a topic",
  "inputSchema": {
    "type": "object",
    "properties": { "query": { "type": "string" } },
    "required": ["query"]
  }
}
