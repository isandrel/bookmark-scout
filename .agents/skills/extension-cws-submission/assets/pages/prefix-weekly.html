Prompt caching, explained

Put what stays the same first. A repeated prefix can come from cache: faster, and often cheaper.

Noor Hale · Oct 16, 2026 · 5 min read

Every request makes a model process its whole prompt before it writes a single token. When many requests start with the same long prefix, such as a system prompt, a style guide, or a shared document, several providers can reuse the work already done for that prefix instead of computing it again.

The rule of thumb: stable content first, variable content last. A cache hit needs an identical prefix, and cached entries expire after a few minutes without use.

messages = [
    {"role": "system", "content": STYLE_GUIDE},  # stable
    {"role": "user", "content": REFERENCE_DOC},  # stable
    {"role": "user", "content": question},       # changes
]
