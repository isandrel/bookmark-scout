<h1 align="center">Bookmark Scout</h1>

<h3 align="center">Jede Seite in Sekunden im richtigen Lesezeichenordner speichern.</h3>

<p align="center">
  Geben Sie ein paar Buchstaben eines Ordnernamens ein oder drücken Sie ein Tastenkürzel, und die Seite landet dort, wo sie hingehört.<br>

## ✨ Was Sie damit tun können

- 📁 **Im richtigen Ordner speichern, indem Sie seinen Namen eingeben.** Geben Sie ein paar Buchstaben ein, auch von einem Ordner tief in anderen Ordnern, und drücken Sie Enter. Kleine Tippfehler werden trotzdem erkannt.
- ⚡ **Mit einem Tastenkürzel speichern.** Drücken Sie auf einer beliebigen Seite ⌥⇧S auf dem Mac (Alt+Shift+S unter Windows und Linux). Eine kleine Meldung zeigt, wo die Seite gespeichert wurde, mit **Rückgängig** und weiteren Ordnern, in die Sie sie verschieben können.
- 🔎 **Alles Gespeicherte wiederfinden.** Durchsuchen Sie alle Lesezeichen schon beim Tippen, über die Symbolleiste, die Seitenleiste oder einen Lesezeichen-Manager in voller Seitengröße.
- 🧹 **Lesezeichen aus vielen Jahren aufräumen.** Entfernen Sie doppelte Lesezeichen, finden Sie Links, die nicht mehr funktionieren, und entfernen Sie Tracking-Codes aus Webadressen. Sie sehen jede Änderung, bevor sie ausgeführt wird, und können sie rückgängig machen.
- ✨ **Optionale KI-Vorschläge.** Lassen Sie KI den Ordner für Sie auswählen, mit Ihrem eigenen KI-Konto oder einem kostenlosen KI-Modell auf Ihrem Computer, etwa dem in Chrome integrierten. KI bleibt aus, bis Sie sie aktivieren.
- 🔒 **Von Grund auf privat.** Kein Konto, keine Werbung, kein Tracking, und nichts geht an den Entwickler. Speichern und Suchen funktionieren sogar offline.

## 📦 Installieren

- **Chrome**: [Chrome Web Store](https://chromewebstore.google.com/detail/bookmark-scout/pmjiopaebkmoenkoodpoldfbnfncnedk)
- **Firefox**: demnächst bei Firefox Add-ons. Bis dahin können Sie die Erweiterung [manuell installieren](https://docs.bookmark-scout.com/de/installation#firefox) (für Fortgeschrittene).
- **Edge**: demnächst bei Microsoft Edge Add-ons. Bis dahin können Sie die Erweiterung [manuell installieren](https://docs.bookmark-scout.com/de/installation#edge) (für Fortgeschrittene).

Speichern Sie dann Ihre erste Seite:

1. **Anheften.** Klicken Sie in der Symbolleiste Ihres Browsers auf das Puzzleteil-Symbol und dann auf die Stecknadel neben Bookmark Scout.
2. **Öffnen Sie eine Seite, die Sie behalten möchten**, und klicken Sie auf das Symbol von Bookmark Scout.
3. **Geben Sie ein paar Buchstaben eines Ordnernamens ein** und drücken Sie Enter: Die Seite wird im ersten aufgelisteten Ordner gespeichert. Um einen anderen auszuwählen, drücken Sie vorher ↓. Das ist alles.

Beim nächsten Mal drücken Sie auf der Seite einfach ⌥⇧S auf dem Mac (Alt+Shift+S unter Windows und Linux). Mehr dazu in der [Anleitung zum Speichern und Ordnen](https://docs.bookmark-scout.com/de/guides/save-and-organize).

## 🔒 Ihr Datenschutz

Bookmark Scout hat kein Konto und keinen Server. Der Entwickler erhält also nie Ihre Lesezeichen, Einstellungen oder sonstige Daten. Ihre Lesezeichen werden in Ihrem Browser gelesen und geändert. Daten verlassen den Browser nur, wenn Sie eine Funktion verwenden, die das erfordert, zum Beispiel KI (die Daten gehen an das KI-Unternehmen Ihrer Wahl) oder die Prüfung auf defekte Links (dabei werden die gespeicherten Websites aufgerufen). Details finden Sie in der [Datenschutzerklärung](https://bookmark-scout.com/de/privacy/).

## 🔐 Berechtigungen

Was Ihr Browser abfragt:

- **Bei der Installation:** *„Deine Lesezeichen lesen und ändern“.* Mehr braucht Bookmark Scout für den Anfang nicht.
- **Nur wenn Sie eine Funktion verwenden, die mehr braucht**, nach einer kurzen Erklärung von Bookmark Scout. Die Prüfung auf defekte Links fragt zum Beispiel, ob sie diese Websites aufrufen darf, und das Speichern über die Seitenleiste, ob sie sehen darf, welcher Tab geöffnet ist. Wenn Sie ablehnen, bleibt nur diese eine Funktion aus.

Hier sehen Sie [jede Berechtigung und wofür sie gebraucht wird](https://docs.bookmark-scout.com/de/permissions).

## ❓ Fragen

**Ist es wirklich kostenlos?**<br>
Ja. Keine Werbung, kein kostenpflichtiges Abo, und jeder kann den Quellcode lesen. Wenn Sie KI mit dem Konto eines KI-Unternehmens aktivieren, kann dieses Unternehmen Ihnen die Nutzung berechnen.

**Brauche ich KI?**<br>
Nein. Speichern, Suchen und Aufräumen funktionieren auch ohne.

**Funktioniert es in Firefox, Edge oder Safari?**<br>
Firefox und Edge: ja (siehe [Installieren](#-installieren)). Safari: nein, weil Safari Erweiterungen keinen Zugriff auf Lesezeichen erlaubt.

Weitere Antworten finden Sie in den [häufigen Fragen](https://docs.bookmark-scout.com/de/faq).
