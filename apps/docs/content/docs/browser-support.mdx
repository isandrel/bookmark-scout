Bookmark Scout works best in Chrome, where it is available from the Chrome Web Store. Edge has the same features, except where noted below. Firefox has a slightly smaller set, because it lets extensions do less with bookmarks. All three run on a computer; phones and tablets are not supported.

## Where to get it

<StoreAvailability />

Where a store does not list Bookmark Scout yet, you can [install it by hand](/installation#install-from-a-github-release). Listing material is prepared in the repository's <RepoLink tree="store">`store/` folder</RepoLink>, and each store reviews an extension before listing it.

## What works where [#feature-matrix]

This table comes from the manifests of the built extension for each browser and the browser checks in its code.

| Feature | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| Toolbar popup with search and saving | Yes | Yes | Yes |
| Quick save shortcuts with a notification in the page | Yes. Change the keys on `chrome://extensions/shortcuts`, where you can also give quick save <Shortcut id="browser.bookmark_page" /> | Yes. Change the keys on `edge://extensions/shortcuts`, including <Shortcut id="browser.bookmark_page" /> | Yes. Change the keys in Bookmark Scout's Settings or Firefox's **Manage Extension Shortcuts**. Firefox keeps <Shortcut id="browser.bookmark_page" /> and <Shortcut id="browser.bookmark_all_tabs" /> for itself |
| Side panel | Yes | Yes | Yes, in the Firefox sidebar: choose Bookmark Scout in the sidebar |
| Bookmarks manager and Tools sidebar | Replaces the browser's bookmarks page, and opens from **Open bookmark manager** in the popup and side panel | Opens from **Open bookmark manager**. Whether Edge also applies the override to its Favorites page has not been checked. | Opens from **Open bookmark manager** in the popup. Firefox cannot replace its bookmarks page. |
| Saved searches, maintenance tools, import and export, statistics, manager AI tools | Yes | Yes | Yes, in the manager. Automated tests cover import and export, the reports, Check Dead Links, Metadata Fetcher, Index Page Text, Fetch Covers, Smart Rules, and AI Folder Reorganization; the other tools are checked by hand. |
| Settings page | Yes | Yes | Yes |
| Ask AI and the other AI tools | Yes | Yes | Yes, after you agree to share data with your AI provider |
| Built-in AI, free on your computer, for folder suggestions | Yes, Chrome 138 or later on a computer that can run Chrome's model | Only if Edge offers the same built-in AI; not checked | No: Firefox has no built-in AI |
| Local AI agents through `bookmark-scout-mcp` (for developers) | Yes | Yes | Yes; `bookmark-scout-mcp install` registers it with Firefox too. Not covered by automated tests |
| Open in incognito window from the manager | Yes | Yes, as an InPrivate window | Yes, as a private window, when the extension is allowed in private windows |
| Right-click menu to save links | Yes, after you turn on **Right-Click Menu** (asks for permission) | Same | Yes, after you turn on **Right-Click Menu** |
| Site icons next to bookmarks | Icons saved with **Refresh Site Icons**, and from the browser's icon cache once you turn on **Use the browser's icon cache** | Same | Only icons saved with **Refresh Site Icons**, which runs in the manager. Firefox has no favicon API for extensions, so other bookmarks show a generic icon. |
| Optional website access for dead-link checks, title fetching, site icon refreshes, page text indexing, and cover fetching | Requested when you run the tool | Same | Same |
| Covers taken while you browse (**Capture Covers While Browsing**) | Yes, after you allow access to all pages | Same | Same |

How much of each browser is covered by automated tests is in [Project status](/status#what-is-tested-in-each-browser).

## Safari

Safari is not supported. Safari Web Extensions do not implement the `bookmarks` API, which every part of Bookmark Scout depends on.
