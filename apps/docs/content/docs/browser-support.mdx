Chrome is the primary target. Edge is Chromium-based and has the same features, except where noted below. Firefox uses a Manifest V2 build with a smaller feature set.

## Feature matrix

This table comes from the manifests of the built extension for each browser.

| Feature | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| Toolbar popup with search and saving | Yes | Yes | Yes |
| Side panel | Yes | Yes | Not supported. The page is declared as a Firefox sidebar, but nothing tests it there. |
| Bookmarks manager and Tools sidebar | Replaces the browser's bookmarks page, and opens from **Open bookmark manager** in the popup and side panel | Opens from **Open bookmark manager**. Whether Edge also applies the override to its Favorites page has not been checked. | Opens from **Open bookmark manager** in the popup. Firefox cannot replace its bookmarks page. |
| Saved searches, maintenance tools, import and export, statistics, manager AI tools | Yes | Yes | Yes, in the manager. Automated tests cover import and export and the reports; the other tools are checked by hand. |
| Settings page | Yes | Yes | Yes |
| Right-click menu to save links | Yes, after you turn on **Context Menu** (asks for permission) | Same | Yes, after you turn on **Context Menu** |
| Site icons next to bookmarks | Icons saved with **Refresh Site Icons**, and from the browser's icon cache once you turn on **Use the browser's icon cache** | Same | Only icons saved with **Refresh Site Icons**, which runs in the manager. Firefox has no favicon API for extensions, so other bookmarks show a generic icon. |
| Optional website access for dead-link checks, title fetching, and site icon refreshes | Requested when you run the tool | Same | Same |

## What is tested

- **Chrome (Chromium)**: unit tests and end-to-end tests for the popup, side panel, manager, settings, maintenance tools, reports, import and export, keyboard shortcuts, saved searches, context-menu saves, drag and drop, network tools, and AI tools against mocked providers.
- **Edge**: the same end-to-end suite runs against the Edge build.
- **Firefox**: a smoke suite covers popup search and folder creation, the side panel page loaded in a tab, opening the manager from the popup and side panel, the manager page, a settings save, a JSON export and import round trip, and the statistics and privacy reports, and saved site icons in the popup. Context menus, drag and drop, keyboard shortcuts, and network and AI tools (including **Refresh Site Icons** itself) are not covered.

The Edge suite and the Firefox smoke suite are required CI checks, like the Chromium suite. Real AI providers and live websites are checked by hand, not by automated tests.

## Safari

Safari is not supported. Safari Web Extensions do not implement the `bookmarks` API, which every part of Bookmark Scout depends on.
