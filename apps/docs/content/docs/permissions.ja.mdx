以下は、ブラウザごとにビルドした拡張機能に含まれる権限です。Bookmark Scout にはコンテンツスクリプトがないため、アクセスしたページを読み取ることはありません。インストール時に求めるのは動作に欠かせない権限だけで、それ以外の権限は、必要な機能をオンにしたときや実行したときに求めます。

## インストール時に許可される権限 [#granted-at-install]

| 権限 | ブラウザ | 理由 |
| --- | --- | --- |
| `bookmarks` | すべて | ブックマークを表示、検索し、ポップアップ、サイドパネル、マネージャー、右クリックメニューで操作したときに、ブックマークを作成、編集、移動、削除するため |
| `storage` | すべて | 設定を保存するため。また、AI プロバイダーの設定、タグ、要約、保存した検索、最近のフォルダ、最近の検索、**サイトアイコンを更新** で保存したサイトアイコンを、このデバイスにのみ保存するため |
| `activeTab` | すべて | ツールバーのボタンや右クリックメニューをクリックしたときに、そのタブのタイトルと URL を読み取り、表示中のページを保存できるようにするため。他のタブや履歴にはアクセスしません |
| `sidePanel` | Chrome、Edge | サイドパネルの画面を提供するため。Firefox では、同じページをサイドバーとして宣言します |
| `contextMenus` | Firefox | Firefox では、拡張機能が後からこの権限を求めることができないため。メニューが表示されるのは、**コンテキストメニュー** をオンにした後だけです |

Chrome と Edge では、拡張機能がブラウザのブックマークページを Bookmark Scout のマネージャーに置き換えます。これはページの置き換え（オーバーライド）であり、権限ではありません。Firefox ではこれが許可されていないため、マネージャーはポップアップの **ブックマークマネージャーを開く** から開きます。[ブラウザ対応](/browser-support)をご覧ください。

## 必要なときに求める権限 [#asked-for-when-you-need-it]

| 権限 | ブラウザ | 求めるタイミング |
| --- | --- | --- |
| `tabs` | すべて | サイドパネルから現在のページを保存するとき、またはフォルダの提案を求めるとき。先に短い説明が表示されます。ツールバーのポップアップでは必要ありません |
| `contextMenus` | Chrome、Edge | [設定](/settings#data)で **コンテキストメニュー** をオンにしたとき。初期設定ではオフで、Chrome は確認なしでこの権限を付与します |
| `favicon` | Chrome、Edge | [設定](/settings#appearance)で **ブラウザのアイコンキャッシュを使う** をオンにしたとき。ブラウザがすでに保存しているアイコンを表示するために使います |
| データ共有への同意 | Firefox | **AI機能** または **ページの内容を読む** をオンにしたとき、または **サービスを確認** をクリックしたとき。拡張機能が AI プロバイダーに何かを送信する前に、Firefox が確認します |

許可しなかった場合、その機能はオフのままで、何も送信されません。後からブラウザの拡張機能の設定で権限を取り消すと、その機能はオフになり、再びオンにすると改めて許可を求めます。

## 任意のウェブサイトへのアクセス [#optional-website-access]

拡張機能は `http://*/*` と `https://*/*` へのアクセスも宣言していますが、インストール時には一切許可されません。ブラウザは、必要になった時点で確認します。

- **リンク切れチェック**、**メタデータ取得**、**サイトアイコンを更新** は、ブックマークはどのサイトも指しうるため、初めて実行したときにウェブサイトへのアクセスを求めます。リクエストは Cookie なしで送信され、タイトルとアイコンのリンクを得るためにページの head 部分だけを読み取ります。許可しなかった場合、スキャンは行われません。[リンク切れの検出と修復](/guides/dead-links)と[サイトアイコンを更新する](/guides/clean-up#refresh-site-icons)をご覧ください。
- AI 設定の **ページの内容を読む** は、オンにしたときにウェブサイトへのアクセスを求めます。これにより、AI ツールがページを Cookie なしでダウンロードし、その本文を AI プロバイダーに送信できるようになります。ローカルネットワーク上のページは読み取られません。[ページの内容を読む](/guides/ai-tools#read-page-content)をご覧ください。
- AI 設定の **サービスを確認** と **モデルを更新** は、そのプロバイダーのアドレス 1 つへのアクセスだけを求めます。[AI ツールの設定](/guides/ai-tools)をご覧ください。

アクセスを取り消すには、ブラウザの拡張機能のページを開き（たとえば `chrome://extensions/` を開いて Bookmark Scout の **詳細** を選ぶか、Firefox の `about:addons` で **権限** を開きます）、サイトへのアクセスや権限を変更します。

## 求めない権限 [#what-is-not-requested]

- ページの内容へのアクセスやコンテンツスクリプトはありません
- 履歴、ダウンロード、Cookie の権限はありません
- インストール時のホストへのアクセスはありません

権限を使うときにデータがどこへ送られるかは、[プライバシー](/privacy)で説明しています。ストアに提出した各権限の理由は、リポジトリの <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink> にあります。
