title: 権限
description: Bookmark Scout が求めるブラウザの各権限とその理由、そしてツールを実行したときにだけ求める任意のウェブサイトへのアクセスについて説明します。
---

以下は、ブラウザごとにビルドした拡張機能に含まれる権限です。Bookmark Scout はコンテンツスクリプトを宣言しておらず、アクセスしたページを読み取るのは、あなたが求めたときだけです（ポップアップの **このページの本文を索引に追加** がそのタブに表示されている本文を読み取ります）。クイック保存ショートカットの後は、そのタブに自身の通知を表示するだけです。インストール時に求めるのは動作に欠かせない権限だけで、それ以外の権限は、必要な機能をオンにしたときや実行したときに求めます。

## ブラウザが確認する内容とその理由 [#what-your-browser-will-ask-and-why]

Bookmark Scout をインストールするとき、ブラウザが表示するのは 1 行だけです。それ以外はすべて、必要な機能を使うときにだけ、Bookmark Scout での短い説明の後に求めます。許可しなかった場合は、その機能だけがオフのままになります。この表では、Chrome の確認の文言を日本語版の表記どおりに引用し、Firefox の確認の内容は説明として記載しています。

| ブラウザの表示（Chrome と Edge / Firefox） | タイミング | 理由 |
| --- | --- | --- |
| 「ブックマークの読み取りと変更」 / ブックマークの読み取りと変更の許可 | インストール時 | ブックマークを保存、検索、整理するため |
| 「アクセスしたウェブサイトのアイコンの読み取り」（Chrome と Edge のみ） | **サイトアイコンを更新** で **ブラウザのアイコンを表示** をクリックしたとき、または **ブラウザのアイコンキャッシュを使う** をオンにしたとき | ブラウザがすでに保存しているアイコンをブックマークの横に表示するため。何もダウンロードしません |
| 「閲覧履歴の読み取り」 / ブラウザのタブへのアクセスの許可 | サイドパネルから現在のページを保存するとき、またはフォルダの提案を求めるとき | 表示中のページを知るため。ツールバーのボタンとクイック保存ショートカットには権限が不要なので、説明ではまずそれらを勧めます |
| 「example.com の全サイト 上にある自分のデータの読み取りと変更」、または「多数のウェブサイト上にある自分のデータの読み取りと変更」 / example.com ドメインのサイトにあるデータへのアクセスの許可 | **リンク切れチェック**、**メタデータ取得**、**サイトアイコンを更新** を実行したとき | その実行の対象となるブックマークのページを、そのサイトにだけリクエストするため |
| 「すべてのウェブサイト上にある自分の全データの読み取りと変更」 / すべてのウェブサイトのデータへのアクセスの許可 | ツールの実行が 20 を超えるサイトにわたるとき、または **ページの内容を読む** をオンにしたとき | どのサイトのページでもリクエストするため |
| 「api.example.com 上にある自分のデータの読み取りと変更」 / api.example.com のデータへのアクセスの許可 | **サービスを確認** または **モデルを更新** をクリックしたとき | AI プロバイダーのアドレスに接続するため |
| 「連携するネイティブ アプリケーションと通信」 / Firefox 以外のプログラムとメッセージをやり取りすることの許可 | **ローカル AI エージェントを許可** をオンにしたとき | コンピューター上の bookmark-scout-mcp プログラムと通信するため |
| Firefox のみ：拡張機能が認証情報、ブックマーク、閲覧行動を収集しようとしていると開発者が述べている、という確認 | **AI機能** をオンにしたとき | API キー、ブックマークとフォルダ名、現在のページのタイトルと URL が AI プロバイダーに送られます。この確認でいう開発者とは選択した AI プロバイダーのことで、Bookmark Scout は何も受け取りません |
| Firefox のみ：同じ確認で、対象がウェブサイトのコンテンツのもの | **ページの内容を読む** をオンにしたとき | ページの本文が AI プロバイダーに送られます |
| Firefox のみ：同じ確認で、対象が認証情報のもの | **サービスを確認** または **モデルを更新** をクリックしたとき | API キーが AI プロバイダーに送られます |
| Firefox のみ：同じ確認で、対象がブックマークと閲覧行動のもの | **ローカル AI エージェントを許可** をオンにしたとき | コンピューター上の AI エージェントが調べられる内容です |

右クリックメニュー（**右クリックメニュー**）も Chrome と Edge では任意の権限ですが、警告がないため、ブラウザは確認せずに追加します。

## インストール時に許可される権限 [#granted-at-install]

| 権限 | ブラウザ | 理由 |
| --- | --- | --- |
| `bookmarks` | すべて | ブックマークを表示、検索し、ポップアップ、サイドパネル、マネージャー、右クリックメニューで操作したときに、ブックマークを作成、編集、移動、削除するため |
| `storage` | すべて | 設定を保存するため。また、AI プロバイダーの設定、タグ、要約、保存した検索、最近のフォルダ、最近の検索、**サイトアイコンを更新** で保存したサイトアイコンを、このデバイスにのみ保存するため |
| `activeTab` | すべて | ツールバーのボタンや右クリックメニューをクリックしたとき、またはクイック保存ショートカットを押したときに、そのタブのタイトルと URL を読み取り、表示中のページを保存できるようにするため。他のタブや履歴にはアクセスしません カバー画像の取得がオンのときは、ポップアップの **この画面をカバー画像にする** ボタンでそのタブの画面を1枚撮影します。保存する前に確認できます。 ページ本文の索引がオンのときは、ポップアップの **このページの本文を索引に追加** ボタンでそのタブに表示されている本文を読み取ります。保存する前に確認できます。 |
| `scripting` | すべて | クイック保存ショートカットの後、そのタブにだけ通知を表示するため。ページからは何も読み取りません。ページ本文の索引がオンのときは、ポップアップの **このページの本文を索引に追加** ボタンをクリックした後、そのタブで関数を1つ実行し、入力欄に入力した内容を除いて表示どおりのページを受け取り、その本文をこの端末で読み取ります |
| `sidePanel` | Chrome、Edge | サイドパネルの画面を提供するため。Firefox では、同じページをサイドバーとして宣言します |
| `offscreen` | Chrome、Edge | AI クイック保存のリクエスト、ローカルの AI エージェントによるページの読み取り、**メタデータ取得** によるページタイトルの読み取り、**ページ本文の索引** によるページ本文の読み取り、**AIフォルダ整理** のリクエストを、非表示の拡張機能のページで実行するため。このページは処理が終わるとブラウザが閉じます。Firefox ではバックグラウンドページ自体がこれを行います |
| `alarms` | すべて | タイマーでバックグラウンドを起こし、ブラウザーがバックグラウンドを止めた後も **リンク切れチェック** などのバックグラウンドのタスクを再開します。確認の表示はありません |
| `contextMenus` | Firefox | Firefox では、拡張機能が後からこの権限を求めることができないため。メニューが表示されるのは、**右クリックメニュー** をオンにした後だけです |

Chrome と Edge では、拡張機能がブラウザのブックマークページを Bookmark Scout のマネージャーに置き換えます。これはページの置き換え（オーバーライド）であり、権限ではありません。Firefox ではこれが許可されていないため、マネージャーはポップアップの **ブックマークマネージャーを開く** から開きます。[ブラウザ対応](/browser-support)をご覧ください。

## 必要なときに求める権限 [#asked-for-when-you-need-it]

| 権限 | ブラウザ | 求めるタイミング |
| --- | --- | --- |
| `tabs` | すべて | サイドパネルから現在のページを保存するとき、またはフォルダの提案を求めるとき。先に短い説明が表示され、この権限を必要としないツールバーのポップアップとクイック保存ショートカットを案内します |
| `contextMenus` | Chrome、Edge | [設定](/settings#data)で **右クリックメニュー** をオンにしたとき。初期設定ではオフで、Chrome は確認なしでこの権限を付与します |
| `favicon` | Chrome、Edge | **サイトアイコンを更新** で **ブラウザのアイコンを表示** をクリックしたとき、または[設定](/settings#appearance)で **ブラウザのアイコンキャッシュを使う** をオンにしたとき。ブラウザがすでに保存しているアイコンを表示するために使います。先に短い説明が表示されます |
| データ共有への同意 | Firefox | 各機能は、送信するものについてだけ同意を求めます。**AI機能** は API キー、ブックマーク、現在のページのタイトルと URL、**ページの内容を読む** はページの本文、**サービスを確認** は API キーについてです。先に短い説明が表示され、データは Bookmark Scout ではなく AI プロバイダーに送られることを伝えます |
| `nativeMessaging` | すべて | [設定](/settings#agent-bridge)で**ローカル AI エージェントを許可**をオンにしたとき。拡張機能がコンピューター上の bookmark-scout-mcp プログラムと通信できるようにします。最初に短い説明が表示されます。Firefox では、同じ確認でブックマークのデータをそのプログラムと共有することへの同意も求めます |

許可しなかった場合、その機能はオフのままで、何も送信されません。後からブラウザの拡張機能の設定で権限を取り消すと、その機能はオフになり、再びオンにすると改めて許可を求めます。

## 任意のウェブサイトへのアクセス [#optional-website-access]

拡張機能は `http://*/*` と `https://*/*` へのアクセスも宣言していますが、インストール時には一切許可されません。ブラウザは、必要になった時点で確認します。

- **リンク切れチェック**、**メタデータ取得**、**サイトアイコンを更新** は、実行したときに、その実行の対象となるブックマークのサイトだけ（それぞれのサブドメインを含む）へのアクセスを求めます。20 を超えるサイトにわたる実行では、代わりにすべてのウェブサイトへのアクセスを求めます。以前に許可したサイトについては、再び確認されません。リクエストは Cookie なしで送信され、タイトルとアイコンのリンクを得るためにページの head 部分だけを読み取ります。許可しなかった場合、スキャンは行われません。実行の対象外のサイトにリダイレクトするリンクはたどれないため、**リンク切れチェック** はそのリンクをリンク切れではなく **手動で確認** として表示します。[リンク切れの検出と修復](/guides/dead-links)と[サイトアイコンを更新する](/guides/clean-up#refresh-site-icons)をご覧ください。
- **ページ本文の索引** も、読み取るブックマークのサイトについて同じように確認します。
- **カバー画像の取得** も、読み取るブックマークのサイトについて同じように確認します。別のサイトにある画像は、そのサイトも許可した場合にだけダウンロードされます。
- AI 設定の **ページの内容を読む** は、オンにしたときにすべてのウェブサイトへのアクセスを求めます。これにより、AI ツールがページを Cookie なしでダウンロードし、その本文を AI プロバイダーに送信できるようになります。ローカルネットワーク上のページは読み取られません。[ページの内容を読む](/guides/ai-tools#read-page-content)をご覧ください。
- AI 設定の **サービスを確認** と **モデルを更新** は、そのプロバイダーのアドレス 1 つへのアクセスだけを求めます。[AI ツールの設定](/guides/ai-tools)をご覧ください。

アクセスを取り消すには、ブラウザの拡張機能のページを開き（たとえば `chrome://extensions/` を開いて Bookmark Scout の **詳細** を選ぶか、Firefox の `about:addons` で **権限** を開きます）、サイトへのアクセスや権限を変更します。

## 求めない権限 [#what-is-not-requested]

- ページの内容へのアクセスやコンテンツスクリプトはありません
- 履歴、ダウンロード、Cookie の権限はありません
- インストール時のホストへのアクセスはありません

権限を使うときにデータがどこへ送られるかは、[プライバシー](/privacy)で説明しています。ストアに提出した各権限の理由は、リポジトリの <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink> にあります。
