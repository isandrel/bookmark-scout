## 你可以用它做什么 [#what-you-can-do-with-it]

- **查找**：在工具栏弹出窗口或侧边栏中按标题或网址搜索所有书签，并在书签管理器中保存命名的搜索。请参阅[搜索和已保存的搜索](/guides/search)。
- **整理**：将当前网页或某个链接保存到任意文件夹，通过拖动调整文件夹结构，删除后可以撤消。请参阅[保存和整理](/guides/save-and-organize)。
- **清理**：移除重复书签，去掉跟踪参数，查找并修复失效链接。请参阅[清理重复书签和跟踪网址](/guides/clean-up)以及[查找并修复失效链接](/guides/dead-links)。
- **迁移书签库**：导出为 HTML、JSON、Markdown 或 CSV，并在预览后导入 HTML 或 JSON。请参阅[导入和导出](/guides/import-export)。
- **按需使用 AI**：AI 工具默认处于关闭状态。开启后，由你选择服务商并使用你自己的密钥。请参阅[设置 AI 工具](/guides/ai-tools)。

## 你的数据去向 [#where-your-data-goes]

Bookmark Scout 没有账号，也没有自己的服务器。你的书签始终保存在浏览器中。只有当你使用需要联网的功能（例如检查失效链接，或使用你已开启的 AI 工具）时，数据才会离开浏览器，并且会直接发送到你选择的网站或服务商。请阅读[隐私摘要](/privacy)。

## 浏览器 [#browsers]

Chrome 是主要目标浏览器。Edge 同样基于 Chromium，并运行同一套端到端测试。Firefox 无法替换其书签页面，因此书签管理器需要通过弹出窗口中的按钮打开，另有少数浏览器功能有所不同。详情请参阅[浏览器支持](/browser-support)。
