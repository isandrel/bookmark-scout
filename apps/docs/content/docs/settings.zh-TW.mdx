從擴充功能的「**選項**」項目開啟設定頁面，例如在 Chrome 中對工具列圖示按一下滑鼠右鍵，然後選擇「**選項**」。變更會在你修改時自動儲存。

## 使用設定頁面 [#using-the-settings-page]

- 頂端的「**搜尋設定...**」可以在任何分頁中找到設定，並顯示相符的數量。
- 變更過的設定會標示為「**已修改**」，並提供可重設為預設值的按鈕。「**全部重設**」會重設所有設定。
- 「**匯出**」會將設定儲存為 JSON 檔案，「**匯入**」則會從 JSON 檔案還原設定。兩者都不會影響書籤。
- 設定會儲存在瀏覽器的同步儲存空間中，因此在開啟瀏覽器同步功能時，會跟著你同步到其他裝置。AI 供應商的 API 金鑰、「**基礎網址**」和「**額外標頭 JSON**」是例外：這些資料只會留在這部裝置上。請參閱「[隱私權](/privacy)」。

## 外觀 [#appearance]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **語言** | 瀏覽器設定 | 英文、簡體中文、繁體中文、日文、韓文、西班牙文、德文、法文或巴西葡萄牙文，或依照瀏覽器設定 |
| **主題** | 系統 | 系統、淺色或深色，套用到所有開啟的 Bookmark Scout 頁面 |
| **顯示網站圖示** | 開啟 | 在彈出式視窗和側邊面板中的書籤旁顯示網站圖示 |
| **使用瀏覽器的圖示快取** | 關閉 | Chrome 和 Edge：對於沒有使用「**重新整理網站圖示**」儲存圖示的網站，也顯示瀏覽器已快取的圖示。開啟時會要求讀取網站圖示的權限。Firefox 沒有提供擴充功能使用的圖示快取，因此不會顯示這項設定 |
| **網站圖示大小** | 16px (小) | 16、24 或 32 像素 |

## 搜尋 [#search]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **搜尋延遲** | 300 ms | 停止輸入後，彈出式視窗要等待多久才開始搜尋 |
| **搜尋結果上限** | 20 個結果 | 顯示的相符結果數量上限；還有更多結果時會顯示提示 |
| **搜尋時展開資料夾** | 開啟 | 展開含有相符結果的資料夾 |
| **搜尋記錄** | 開啟 | 在這部裝置上記住最近的搜尋 |
| **相符的資料夾** | 開啟 | 搜尋時，在結果上方列出名稱相符的資料夾，方便將目前網頁儲存到那裡 |
| **相符資料夾數量上限** | 5 | 最多列出幾個相符的資料夾 |
| **允許拼字錯誤** | 開啟 | 4 個字母以上的搜尋字詞，與資料夾名稱相差一個字母也能相符 |

請參閱「[搜尋和已儲存的搜尋](/guides/search)」。

## 行為 [#behavior]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **排序方式** | 新增日期 | 「**新增日期**」、「**依字母順序**」或「**資料夾優先**」。只會變更 Bookmark Scout 顯示書籤的方式，絕不會變更瀏覽器儲存的順序 |
| **依資料夾分組** | 開啟 | 在彈出式視窗和側邊面板中，於每一層將子資料夾列在書籤之前 |
| **連結開啟位置** | 新分頁 | **新分頁**、**背景新分頁**或**目前分頁**：在 Bookmark Scout 中點選連結時要在哪裡開啟。按滑鼠中鍵和 Ctrl/Cmd+點選仍依瀏覽器的方式開啟 |
| **刪除前確認** | 開啟 | 刪除前先詢問。無論是否開啟，每次刪除都可以在 10 秒內復原 |
| **預設資料夾名稱** | 新資料夾 | 新資料夾的初始名稱 |
| **最近使用的資料夾** | 開啟 | 在彈出式視窗和右鍵選單中顯示最近使用的資料夾 |
| **最近使用的資料夾上限** | 5 | 要顯示幾個最近使用的資料夾 |

請參閱「[儲存和整理](/guides/save-and-organize)」。

## 進階 [#advanced]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **彈出式視窗寬度** | 400 px | 瀏覽器允許的上限為 800 px |
| **彈出式視窗高度** | 500 px | 瀏覽器允許的上限為 600 px |
| **截斷長度** | 50 個字元 | 縮短彈出式視窗 AI 建議標頭中的網頁標題 |
| **通知顯示時間** | 4000 ms | 訊息保持顯示的時間。「復原」訊息有自己的 10 秒時限 |

## AI [#ai]

AI 預設為關閉。只有在開啟「**AI 功能**」後，這些設定才會生效。

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **AI 功能** | 關閉 | 開啟 AI 工具和彈出式視窗的資料夾推薦。在 Firefox 中，開啟時會詢問你是否同意分享 AI 供應商所需的資料 |
| **開啟時自動推薦** | 關閉 | 每次開啟彈出式視窗時都要求資料夾推薦 |
| **讀取網頁內容** | 關閉 | 將各網頁的主要文字 (而不只是標題和網址) 傳送給資料夾推薦、自動加上標籤和內容摘要工具。開啟時會要求網站存取權 |
| **AI 供應商**和 **AI 模型** | OpenAI、GPT-4o Mini | 所有 AI 工具使用的供應商和模型 |
| **推薦數量上限** | 5 | 要求的資料夾推薦數量上限 |
| **分類數量上限** | 不限 | 重組計畫最多可建立的頂層資料夾數量 |
| **每個資料夾的項目下限**和**每個資料夾的項目上限** | 1 和不限 | 重組計畫的資料夾大小目標 |

在這些設定下方，供應商面板中有「**API 金鑰**」、「**基礎網址**」、「**自訂模型**」和「**額外標頭 JSON**」，以及「**驗證服務**」和「**重新整理模型**」。資料夾限制會以指示的形式傳送給供應商，系統不會檢查其輸出是否符合這些限制。請參閱「[設定 AI 工具](/guides/ai-tools)」。

## AI 工具 [#ai-tools]

每項工具都有「**啟用**」開關 (預設為開啟)。關閉後，該工具就不會顯示在書籤管理員的「**工具**」側欄中。

| 工具 | 設定和預設值 |
| --- | --- |
| **AI 脈絡打包工具** | 「**輸出格式**」Markdown；「**包含資料夾路徑**」、「**包含日期**」、「**包含已儲存的標籤**」和「**包含已儲存的摘要**」開啟；「**項目數量上限**」200；「**深度上限**」8；「**摘錄長度**」240 |
| **自動加上標籤** | 「**標籤數量下限**」2；「**標籤數量上限**」5；「**標籤樣式**」kebab-case；「**合併模式**」附加；「**移除重複的標籤**」開啟 |
| **內容摘要工具** | 「**摘要長度**」160；「**包含網域提示**」開啟；「**合併模式**」取代 |
| **AI 資料夾重組** | 「**一律先預覽**」開啟；「**最低信賴度**」0.55 (低於此值的移動會被捨棄)；「**批次大小**」每次要求 100 個書籤 |

無論「**預設範圍**」如何設定，自動加上標籤和內容摘要工具一律處理目前資料夾。

## 維護 [#maintenance]

| 工具 | 設定和預設值 |
| --- | --- |
| **重複書籤清理工具** | 「**比對方式**」正規化網址；「**統一 www**」、「**忽略通訊協定**」和「**忽略結尾斜線**」開啟；「**保留規則**」最舊的；「**群組數量上限**」500。一律掃描所有書籤 |
| **網址清理工具** | 「**移除片段**」關閉；「**排序查詢參數**」和「**移除重複的查詢參數**」開啟；「**保留參數**」和「**移除參數**」清單 |
| **檢查失效連結** | 「**要求逾時**」8000 ms；「**同時要求數**」4；「**重試次數**」1；「**追蹤重新導向**」開啟；「**成功狀態碼**」200, 201, 202, 204, 301, 302, 307, 308 |

「**移除參數**」等清單要輸入以逗號分隔的值。預設清單列於「[清理重複書籤和追蹤網址](/guides/clean-up#strip-tracking-parameters)」。另請參閱「[找出並修復失效連結](/guides/dead-links)」。

## 中繼資料與內容 [#metadata--content]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **啟用中繼資料擷取工具** | 開啟 | 在工具側欄中顯示「**中繼資料擷取工具**」 |
| **覆寫標題** | 關閉 | 為已有標題的書籤提供新標題 |
| **擷取說明** | 開啟 | 在確認畫面中顯示網頁說明。說明絕不會儲存 |
| **要求逾時** | 8000 ms | 每個網頁的逾時時間。「**重新整理網站圖示**」也會使用這項設定 |
| **同時要求數** | 4 | 同時要求的網頁數量。「**重新整理網站圖示**」也會使用這項設定 |
| **啟用「重新整理網站圖示」** | 開啟 | 在工具側欄中顯示「**重新整理網站圖示**」 |
| **預設範圍** | 目前資料夾 | 重新整理網站圖示時的初始範圍 |
| **偏好的圖示大小** | 32px | 網頁列出多個圖示時，下載最接近這個大小的圖示 |
| **圖示檔案大小上限** | 64 KB | 不會下載或儲存超過這個大小的圖示檔案 |
| **圖示儲存空間上限** | 4096 KB | 這部裝置上已儲存圖示的總大小；超過時會先移除最舊的圖示 |

## 安全性 [#security]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **啟用隱私掃描工具** | 開啟 | 在工具側欄中顯示「**隱私掃描工具**」。這項工具一律掃描所有書籤 |
| **掃描標題** | 關閉 | 除了網址外也檢查標題 |
| **掃描查詢參數**和**掃描片段** | 開啟 | 檢查每個網址中的這些部分 |
| **敏感參數** | `token`、`access_token`、`refresh_token`、`auth`、`authorization`、`api_key`、`apikey`、`key`、`secret`、`password`、`pwd`、`code`、`session` | 要標示的參數名稱 |
| **偵測電子郵件地址**和**偵測 UUID** | 開啟 | 標示電子郵件地址和類似 UUID 的值 |
