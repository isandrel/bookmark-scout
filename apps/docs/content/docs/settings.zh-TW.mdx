從擴充功能的「**選項**」項目開啟設定頁面，例如在 Chrome 中對工具列圖示按一下滑鼠右鍵，然後選擇「**選項**」。變更會在你修改時自動儲存。

## 使用設定頁面 [#using-the-settings-page]

- 設定頁面開啟時會顯示「**常用設定**」，也就是大多數人會變更的幾項設定。其他分頁都列在「**進階設定**」下，「**常用設定**」中的每項設定也都在各自的分頁中：無論在哪裡變更，改的都是同一項設定。
- 頂端的「**搜尋設定...**」可以在任何分頁中找到設定，並顯示相符的數量。輸入的每個字詞都必須相符，順序不拘，不分大小寫和重音符號。相符的字詞會在所在位置醒目標示，含有相符項目的分頁會醒目標示數量；如果設定是在未顯示的文字中相符（例如說明或設定 ID），其下方會有一則簡短的提示，說明在哪裡相符。有些設定也能用其他常見說法找到，例如用「夜間模式」找到**主題**。搜尋範圍、字詞比對方式和顯示內容可在[設定搜尋](#settings-search)中變更。
- 每個分頁都分成有標題的小節。工具的開關在小節標題旁邊，關閉時該工具的其他設定會收合。逾時、檔案名稱長度等技術性設定放在**進階設定**裡，預設收合，展開它或搜尋到其中的設定時才會打開。
- 變更過的設定會標示為「**已修改**」，並提供可重設為預設值的按鈕。「**重設所有快速鍵**」會重設所有設定。
- 「**備份設定**」會將你選取的內容儲存為備份檔案：設定、這台電腦的設定、已儲存的搜尋和表格檢視、提示詞和「關於我」、智慧規則、AI 服務（包括「**基礎網址**」和供應商專屬欄位）、封面，以及只有在你選取並確認後才包含的 AI 服務金鑰（預設以密碼保護）。「**還原設定**」會顯示備份中每項內容會帶來哪些變更，讓你選取內容並「**合併**」或「**取代**」，並為「**復原匯入**」保留一份安全副本；它也會將只含設定值的檔案合併到目前的設定中。兩者都不會影響書籤。旁邊的「**匯出書籤**」會開啟書籤管理員並進入其匯出工具。請見[備份和還原設定](/guides/import-export#back-up-and-restore-settings)。
- 你變更的設定會儲存在瀏覽器的同步儲存空間中，因此在開啟瀏覽器同步功能時，會跟著你同步到其他裝置。適合某個螢幕的設定，或指向每部電腦上各不相同內容的設定，只會留在你變更它們的裝置上：彈出式視窗和書籤管理器的版面配置、管理員和彈出式視窗快速鍵、智慧規則、儲存上限、瀏覽時或快速儲存時擷取封面、快速儲存選定的資料夾、AI 活動記錄、詢問 AI 時的網路搜尋，以及本機 AI 代理。下文中每一項都註明了這一點（「**僅儲存在此裝置上**」等）。AI 服務及其 API 金鑰、「**基礎網址**」和「**額外標頭 JSON**」也只會留在這部裝置上。請參閱「[隱私權](/privacy)」。
- 在可勾選和重新排序的清單中（彈出式視窗的組成部分、按鈕和懸停卡片的內容，卡片和預覽的內容，側邊欄工具，選單，以及右鍵選單的項目），後續版本新增的項目會一直顯示，直到你將其隱藏；你隱藏的項目會保持隱藏。

## 儲存與搜尋 [#search]

### 相符的資料夾 [#folder-matches]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **相符的資料夾** | 開啟 | 搜尋時，在結果上方列出名稱相符的資料夾，方便將目前網頁儲存到那裡 |
| **相符資料夾數量上限** | <SettingDefault path="search.folder_matches.max" /> | 最多列出幾個相符的資料夾 |
| **資料夾名稱權重** | <SettingDefault path="search.folder_matches.name_weight" /> | 資料夾本身名稱中的詞占多大分量 |
| **上層資料夾權重** | <SettingDefault path="search.folder_matches.parent_weight" /> | 所在上層資料夾名稱中的詞占多大分量，這樣「react hooks」能找到 React 裡的 Hooks |
| **內部書籤權重** | <SettingDefault path="search.folder_matches.bookmark_weight" /> | 資料夾內書籤的標題和網站中的詞占多大分量。設為 0 只搜尋資料夾名稱 |

### 搜尋比對 [#search-matching]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **模糊比對** | 開啟 | 拼字略有不同的詞也能比對，例如「rect」能找到 React。結果依相關性（BM25）排序，拼字越接近排得越前面 |
| **允許 1 處編輯的最短長度** | <SettingDefault path="search.search_matching.one_edit" /> | 可相差 1 處編輯的最短詞長（字母數）：增、刪、改一個字母，或交換相鄰兩個字母 |
| **允許 2 處編輯的最短長度** | <SettingDefault path="search.search_matching.two_edits" /> | 可相差 2 處編輯的最短詞長（字母數） |
| **比對詞的開頭** | 開啟 | 輸入的詞也能比對以它開頭的較長詞，輸入「rea」就能找到 React。完整的詞仍排得更前面 |
| **詞頻飽和度（BM25 k1）** | <SettingDefault path="search.search_matching.bm25_k1" /> | 同一個詞重複出現時還能為結果加多少分。越低，出現一次與多次的差別越小 |
| **長度正規化（BM25 b）** | <SettingDefault path="search.search_matching.bm25_b" /> | 詞相同時偏向較短結果的程度：0 不偏向，1 完全偏向 |

### 搜尋 [#searching]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **搜尋延遲** | <SettingDefault path="search.search.debounce_ms" /> ms | 停止輸入後，彈出式視窗要等待多久才開始搜尋 |
| **搜尋結果上限** | 20 個結果 | 顯示的相符結果數量上限；還有更多結果時會顯示提示 |
| **搜尋時展開資料夾** | 開啟 | 展開含有相符結果的資料夾 |
| **搜尋記錄** | 開啟 | 在這部裝置上記住最近的搜尋 |
| **保留的最近搜尋** | <SettingDefault path="search.search.history_max" /> | 記住的最近搜尋數量 |

請參閱「[搜尋和已儲存的搜尋](/guides/search)」。

### 快速儲存快捷鍵 [#quick-save]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **快速儲存資料夾** | 最佳相符 | <Shortcut id="commands.quick-save" /> 將目前網頁儲存到哪裡：最相符的資料夾、上次使用的資料夾或指定資料夾。AI 快捷鍵一律使用 AI 的建議 |
| **儲存到的資料夾** | 未選擇 | 「**指定資料夾**」所使用的資料夾。如果該資料夾被刪除，快速儲存會使用上次使用的資料夾。僅儲存在此裝置上 |
| **提供的其他資料夾** | <SettingDefault path="search.quick_save.alternatives" /> | 快速儲存通知提供多少個其他資料夾用於移動網頁 |
| **通知顯示時間** | <SettingDefault path="search.quick_save.notification_ms" seconds /> 秒 | 快速儲存通知自動關閉前顯示多久；指標停留時保持開啟 |
| 「**快速儲存時儲存封面**」 | 關閉 | 快速儲存後，同時為書籤儲存封面：網頁本身的圖片（只從該網站或你允許的網站下載），或在你按下快捷鍵時擷取的分頁截圖，不經檢視。僅在「**啟用取得封面**」開啟時有效；私密視窗中以及「**永不擷取這些網站**」或「**永不讀取這些網站**」中的網站都不會儲存。通知會提供「**移除封面**」，「**復原**」會連同書籤一起移除封面。只保存在這部裝置上。開啟時會顯示下面兩項設定 |
| 「**快速儲存封面來源**」 | 與封面來源相同 | 快速儲存保留哪種封面：依照[封面來源](#fetch-covers)的順序，或僅用於快速儲存的其中一個選項 |
| 「**書籤已有封面時**」 | 保留 | 「**保留**」會留下書籤已有的封面；「**取代**」會用新封面取代它。用「**將目前畫面設為封面**」儲存的封面永遠不會被取代 |

這些設定下方的「**鍵盤快捷鍵**」會顯示各快捷鍵在瀏覽器中指派的按鍵，並提供「**變更快捷鍵**」。在 Firefox 中，你也可以直接在這裡輸入新按鍵，或將其重設為預設值。在 Chrome 和 Edge 中，這裡也會說明如何將 <Shortcut id="browser.bookmark_page" /> 指派給快速儲存。請參閱「[用鍵盤快捷鍵儲存](/guides/save-and-organize#quick-save)」和「[用書籤鍵快速儲存](/guides/save-and-organize#ctrl-d)」。

### 右鍵選單 [#context-menu]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **右鍵選單** | 關閉 | 在瀏覽器的右鍵選單中顯示「**將書籤儲存至...**」。在 Chrome 和 Edge 中，開啟時會新增選用的右鍵選單權限，不會顯示提示 |
| **選單顯示位置** | 連結 | 按右鍵時在哪裡顯示選單：「**連結**」（儲存連結）、「**頁面**」（儲存目前的頁面）和「**選取的文字**」（儲存頁面，使用「**連結文字**」命名時以選取的文字命名）。都不需要其他權限 |
| **書籤名稱來源** | 連結文字 | 透過右鍵選單儲存時，以連結文字、網頁標題或連結網址作為書籤名稱 |
| **選單中最近使用的資料夾數** | <SettingDefault path="search.context_menu.recent_max" /> | 選單列出的最近使用資料夾數量，與彈出式視窗的「**最近使用的資料夾上限**」分開設定 |

「**選單項目**」選擇選單提供的項目及其順序：「**最近使用的資料夾**」（子選單）和「**書籤列**」。勾選項目即可顯示，拖曳其控點（或使用控點選單）可移動位置；「**還原預設值**」會依最初的順序重新顯示兩者。

### 設定搜尋 [#settings-search]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **搜尋範圍** | 名稱、說明、關鍵字、設定 ID | 本頁頂端的搜尋要在每個設定的哪些文字中尋找 |
| **字詞比對** | 所有字詞，順序不限 | 輸入的每個字詞可依任意順序出現在任何位置，還是整個搜尋內容必須依輸入原樣相符 |
| **醒目標示相符項目** | 開啟 | 標示你搜尋的字詞，以及有相符項目的分頁 |
| **說明隱藏的相符項目** | 開啟 | 相符的文字未顯示（例如說明或設定 ID）時，在設定下方說明在哪裡找到 |
| **在分頁上顯示相符數** | 開啟 | 在每個分頁旁顯示其中有多少設定相符 |

| 設定 | 預設值 | 作用 |
| --- | --- | --- |

| **時間格式** | 與我的語言一致 | 「**12 小時制**」、「**24 小時制**」，或依你的語言習慣 |

### 彈出式視窗 [#popup]

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **彈出式視窗寬度** | <SettingDefault path="appearance.popup.width" /> px | 瀏覽器允許的上限為 800 px |
| **彈出式視窗高度** | <SettingDefault path="appearance.popup.height" /> px | 瀏覽器允許的上限為 600 px |
| **截斷長度** | <SettingDefault path="appearance.popup.truncate_length" /> 個字元 | 縮短彈出式視窗 AI 建議標頭中的網頁標題 |
| **樹狀清單密度** | 寬鬆 | 彈出視窗和側邊面板中樹狀清單的列為 **寬鬆** 或 **緊湊**。僅儲存在此裝置上 |
| **游標停留時顯示詳細資訊** | 開啟 | 在彈出式視窗或側邊面板中，將指標停在書籤上或用方向鍵移到書籤，卡片會顯示其完整標題和網址、資料夾、標籤、摘要、已儲存的封面和新增日期。按 `Esc` 關閉卡片。關閉後，列的標題和網址會以一般提示顯示 |

表格下方的三個清單用於安排彈出視窗和側邊面板。勾選項目即可顯示，拖曳其控點即可移動；控點也是一個按鈕，其選單可將項目移到最前、上移、下移或移到最後。**還原預設值** 會還原每個清單的一般順序。這些清單僅儲存在此裝置上。

- **彈出視窗的組成部分**：搜尋框下方由上到下顯示的內容：目前頁面、背景工作、上次快速儲存、最近使用的資料夾、AI 資料夾建議、相符的資料夾、書籤、提示和按鍵提示。書籤一律顯示；其他部分可移到書籤的上方或下方。
- **工具列按鈕**：搜尋框旁邊的按鈕：**全部展開**（搜尋時）、書籤管理器、主題，以及 AI 按鈕（設定好 AI 後）。
- **詳細資訊卡片內容**：詳細資訊卡片依序顯示的內容：標題、網址、封面、標籤、摘要、資料夾和新增日期。標題、網址和封面排在最前面時，它們共用卡片最上面一列。

## 行為 [#behavior]

### 樹狀清單與排序 [#tree-and-sorting]

### 書籤管理器選單 [#manager-menus]

在各自的分頁中安排管理器的每個選單：**項目選單**（在列或樹狀清單中的資料夾上按右鍵，或點選列的 ⋯ 按鈕）、**整理選單**（標題列中的 ⋮）、**空白處選單**（在列下方按右鍵）和 **預覽按鈕**（書籤預覽下方，第一個是主要按鈕）。取消勾選命令即可隱藏；它會移到 **已隱藏**，再次勾選會把它加回末尾。拖曳命令的控點可重新排序，拖曳 **區段分隔線** 可把命令移到另一個區段；控點也是一個按鈕，其選單可把項目移到頂端、上移、下移或移到底端，因此也能用鍵盤操作。**新增區段分隔線** 會在末尾加入一條供你上移，點選它的 ✕ 可移除並合併兩個區段。**還原預設值** 只還原目前的選單。每個選單至少保留一個命令，項目選單會保留 **查看詳細資料** 或 **複製書籤 ID**，因此對任何書籤或資料夾都有可用的命令；如果保留的命令都不適用，選單會顯示 **沒有可用的動作**。所有選單都會與其他設定一起同步。

### 彈出視窗中的書籤和資料夾操作 [#popup-menus]

選擇彈出視窗和側邊面板中書籤和資料夾提供哪些指令，並像管理器選單一樣拖曳指令的控點，在群組內調整順序。一列的前幾個指令是按鈕，在指標指向該列或用鍵盤移到該列時顯示：書籤上是 **刪除**，資料夾上是 **展開所有子資料夾**、**新增目前網頁**、**新增資料夾** 和 **刪除**。其餘指令，如 **在新分頁中開啟** 和 **在新視窗中開啟**，在該列的 ⋯ 選單中；在該列上按右鍵（或按選單鍵）會列出全部指令。隱藏一個按鈕後，下一個指令會成為按鈕。**還原預設值** 會還原完整選單。書籤一律保留 **在新分頁中開啟** 或 **刪除**，資料夾一律保留 **新增資料夾** 或 **全部開啟**。與書籤管理器選單一樣，會與其他設定一起同步。

### 管理員和彈出式視窗快速鍵 [#page-shortcuts]

變更在書籤管理員、彈出式視窗和側邊面板中使用的按鍵；初始按鍵列在[鍵盤快速鍵](/guides/keyboard-shortcuts)中。按一下快速鍵旁的「**變更**」，然後按下新的按鍵，按 `Esc` 取消。同一頁面上另一個快速鍵已經使用的按鍵會被拒絕，並說明是哪個快速鍵；瀏覽器自己保留的按鍵和在清單中移動的按鍵（方向鍵、`Home`、`End` 和空白鍵，無論單獨按下還是與 `Shift`、`Ctrl` 或 `Cmd` 組合，以及 `Enter`）也會被拒絕，除非它們本來就是這個快速鍵的按鍵。彈出式視窗和側邊面板的快速鍵一律不使用 `Ctrl` 或 `Cmd`。已變更的快速鍵旁的重設按鈕會恢復它的預設按鍵，「**全部重設**」會恢復所有快速鍵。複製、剪下和貼上保留瀏覽器的按鍵，[快速儲存快捷鍵](#quick-save)由瀏覽器管理。只儲存在這部裝置上。

## AI [#ai]

AI 預設為關閉。只有在開啟「**AI 功能**」後，這些設定才會生效；在那之前，這裡和「**AI 工具**」分頁中的 AI 設定會以灰色顯示，並附上說明這一點的提示。你仍然可以變更這些設定。在設定好預設服務之前，頂端會顯示「**AI 是選用功能**」方塊，說明 AI 能做什麼、需要什麼、可能產生哪些費用，以及會傳送哪些內容，並附上前往[設定 AI 工具](/guides/ai-tools)的連結。

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **AI 功能** | 關閉 | 開啟 AI 工具和彈出式視窗的資料夾推薦。在 Firefox 中，開啟時會詢問你是否同意與 AI 供應商分享你的 API 金鑰、書籤，以及目前網頁的標題和網址 |
| **AI 服務** | 無 | 你新增的供應商，各有自己的模型和金鑰；AI 工具會使用預設服務；**內建 AI** 只負責建議資料夾，所以它是預設服務時，其他工具會使用第一個已開啟的其他服務 |

在這些設定下方，供應商面板中有「**API 金鑰**」、「**基礎網址**」、「**自訂模型**」和「**額外標頭 JSON**」，以及「**驗證服務**」和「**重新整理模型**」。資料夾限制會以指示的形式傳送給供應商，系統不會檢查其輸出是否符合這些限制。請參閱「[設定 AI 工具](/guides/ai-tools)」。

**API 金鑰** 下方的 **需要 API 金鑰** 一開始與供應商的要求一致。關閉後即可不帶金鑰使用服務，例如位於會自行加入金鑰的代理或閘道之後的服務。

| **背景工作** | **超過此數量時在背景套用** <SettingDefault path="maintenance.background_tasks.apply_in_background_above" />：涉及更多書籤的已檢視變更會在背景分批套用，關閉頁面後仍會繼續；每一批都是[歷史記錄](/guides/save-and-organize)中的一項變更，可在那裡復原。智慧規則的執行會依它變更的書籤計數，其標籤在「**由規則變更**」中復原 |

工具會從「**所有書籤**」開始，這樣即使從管理員開啟時所在的資料夾開始掃描，也不會漏掉其他資料夾。如果想讓工具從目前開啟的資料夾開始，請變更它的「**預設範圍**」。「**AI 資料夾重組**」會從目前開啟的資料夾開始，因為針對所有書籤的計畫會把它們全部傳送給你的 AI 供應商。在管理員的最上層 (沒有開啟任何資料夾) 時，所有工具都會從「**所有書籤**」開始。

「**移除參數**」等清單可以輸入名稱後按 Enter 新增，也可以從建議中選取。「**成功狀態碼**」是常用狀態碼的核取清單，也可以新增其他狀態碼。為了讓設定能放進瀏覽器同步，每個清單最多 20 項，參數名稱最多 32 個字元（英文字母、數字和網址符號）。預設清單列於「[清理並完善書籤](/guides/clean-up#strip-tracking-parameters)」。另請參閱「[找出並修復失效連結](/guides/dead-links)」。

## 開發人員選項 [#developers]

### 本機 AI 代理 [#agent-bridge]

**允許本機 AI 代理**（預設關閉，僅限此裝置）讓你電腦上的 AI 代理（例如 Claude Code、Codex 或 Cursor）透過 bookmark-scout-mcp 程式查詢你的書籤。該程式需要你安裝，並用 `bookmark-scout-mcp install` 註冊。這項設定不需要開啟「**AI 功能**」。開啟這項設定時，瀏覽器會請你允許擴充功能與該程式通訊。**允許變更**（預設關閉）還讓它們可以儲存網頁，並提議移動、重新命名、刪除和新增資料夾；每次變更都會開啟 Bookmark Scout 視窗，由你核准或拒絕，你也可以在書籤管理器中復原。開關下方的面板會顯示該程式是否正在執行。

**隱藏隱私值**（預設開啟）會依照隱私掃描工具的清單，替換代理收到的標題和網址中的敏感網址參數、權杖和電子郵件地址。**本機代理可以執行的動作**列出了每一類查詢，預設全部開啟；關閉的查詢將完全不會提供給代理。
