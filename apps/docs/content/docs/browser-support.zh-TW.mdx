---
title: 瀏覽器支援
description: Chrome、Microsoft Edge 和 Firefox 各支援哪些功能、各自從哪裡取得，以及不支援 Safari 的原因。
---

Bookmark Scout 在 Chrome 中效果最好，可以從 Chrome 線上應用程式商店取得。Edge 的功能與 Chrome 相同，下方註明的部分除外。Firefox 的功能稍微少一些，因為它允許擴充功能對書籤做的事比較少。這三種瀏覽器都在電腦上執行；不支援手機和平板電腦。

## 從哪裡取得 [#where-to-get-it]

<StoreAvailability />

如果某個商店尚未上架 Bookmark Scout，你可以[手動安裝](/installation#install-from-a-github-release)。商店資訊頁面的資料準備在存放區的 <RepoLink tree="store">`store/` 資料夾</RepoLink>中，每個商店都會先審查擴充功能，再將它上架。

## 各瀏覽器支援的功能 [#feature-matrix]

這個表格依據各瀏覽器建置完成的擴充功能資訊清單 (manifest)，以及程式碼中的瀏覽器檢查整理而成。

| 功能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 可搜尋和儲存的工具列彈出式視窗 | 支援 | 支援 | 支援 |
| 快速儲存快捷鍵，並在網頁中顯示通知 | 支援。可在 `chrome://extensions/shortcuts` 變更按鍵，也可以在那裡將 <Shortcut id="browser.bookmark_page" /> 指派給快速儲存 | 支援。可在 `edge://extensions/shortcuts` 變更按鍵，包括 <Shortcut id="browser.bookmark_page" /> | 支援。可在 Bookmark Scout 的設定或 Firefox 的「**管理擴充套件快速鍵**」中變更按鍵。Firefox 會保留 <Shortcut id="browser.bookmark_page" /> 和 <Shortcut id="browser.bookmark_all_tabs" /> 供自己使用 |
| 側邊面板 | 支援 | 支援 | 支援，位於 Firefox 側邊欄：在側邊欄中選擇 Bookmark Scout |
| 書籤管理員和工具側欄 | 取代瀏覽器的書籤頁面，也可以從彈出式視窗和側邊面板中的「**開啟書籤管理員**」開啟 | 從「**開啟書籤管理員**」開啟。尚未確認 Edge 是否也會將這項覆寫套用到其「我的最愛」頁面。 | 從彈出式視窗中的「**開啟書籤管理員**」開啟。Firefox 無法取代其書籤頁面。 |
| 已儲存的搜尋、維護工具、匯入和匯出、統計資料、書籤管理員中的 AI 工具 | 支援 | 支援 | 支援，在書籤管理員中使用。自動化測試涵蓋匯入、匯出、報告、檢查失效連結、中繼資料擷取工具、索引網頁內文、取得封面、智慧規則和 AI 資料夾重組；其他工具則以人工檢查。 |
| 設定頁面 | 支援 | 支援 | 支援 |
| 「詢問 AI」和其他 AI 工具 | 支援 | 支援 | 支援，需先同意與你的 AI 供應商分享資料 |
| 內建 AI：在你的電腦上免費推薦資料夾 | 支援，需要 Chrome 138 以上版本，且電腦能執行 Chrome 的模型 | 僅限 Edge 提供相同的內建 AI 時；尚未確認 | 不支援：Firefox 沒有內建 AI |
| 透過 `bookmark-scout-mcp` 使用本機 AI 代理 (適用於開發人員) | 支援 | 支援 | 支援；`bookmark-scout-mcp install` 也會在 Firefox 中註冊它。自動化測試未涵蓋 |
| 從書籤管理員以無痕式視窗開啟 | 支援 | 支援，以 InPrivate 視窗開啟 | 支援，以隱私視窗開啟，前提是擴充功能已獲准在隱私視窗中執行 |
| 用來儲存連結、網頁或選取文字的右鍵選單 | 支援，需開啟「**右鍵選單**」(不會顯示提示) | 同 Chrome | 支援，需開啟「**右鍵選單**」 |
| 書籤旁的網站圖示 | 使用「**重新整理網站圖示**」儲存的圖示，以及開啟「**使用瀏覽器的圖示快取**」後取自瀏覽器圖示快取的圖示 | 同 Chrome | 僅限使用「**重新整理網站圖示**」儲存的圖示，這項工具要在書籤管理員中執行。Firefox 沒有提供擴充功能使用的網站圖示 API，因此其他書籤會顯示通用圖示。 |
| 用於檢查失效連結、擷取標題、重新整理網站圖示、索引網頁內文和取得封面的選用網站存取權 | 執行工具時要求 | 同 Chrome | 同 Chrome |
| 瀏覽時擷取的封面 (「**瀏覽時擷取封面**」) | 支援，需先允許存取所有網頁 | 同 Chrome | 同 Chrome |

各瀏覽器有多少部分由自動化測試涵蓋，請參閱「[專案狀態](/status#what-is-tested-in-each-browser)」。

## Safari [#safari]

不支援 Safari。Safari 網頁擴充功能並未實作 `bookmarks` API，而 Bookmark Scout 的所有部分都依賴這個 API。
