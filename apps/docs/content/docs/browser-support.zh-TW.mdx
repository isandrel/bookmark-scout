Chrome 是主要支援的瀏覽器。Edge 以 Chromium 為基礎，功能與 Chrome 相同，下方註明的部分除外。Firefox 使用 Manifest V2 建置版本，功能較少。

## 功能對照表 [#feature-matrix]

這個表格依據各瀏覽器建置完成的擴充功能資訊清單 (manifest) 整理而成。

| 功能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 可搜尋和儲存的工具列彈出式視窗 | 支援 | 支援 | 支援 |
| 側邊面板 | 支援 | 支援 | 支援，位於 Firefox 側邊欄：在側邊欄中選擇 Bookmark Scout |
| 書籤管理員和工具側欄 | 取代瀏覽器的書籤頁面，也可以從彈出式視窗和側邊面板中的「**開啟書籤管理員**」開啟 | 從「**開啟書籤管理員**」開啟。尚未確認 Edge 是否也會將這項覆寫套用到其「我的最愛」頁面。 | 從彈出式視窗中的「**開啟書籤管理員**」開啟。Firefox 無法取代其書籤頁面。 |
| 已儲存的搜尋、維護工具、匯入和匯出、統計資料、書籤管理員中的 AI 工具 | 支援 | 支援 | 支援，在書籤管理員中使用。自動化測試涵蓋匯入、匯出和報告；其他工具則以人工檢查。 |
| 設定頁面 | 支援 | 支援 | 支援 |
| 用來儲存連結的右鍵選單 | 支援，需開啟「**右鍵選單**」(會要求權限) | 同 Chrome | 支援，需開啟「**右鍵選單**」 |
| 書籤旁的網站圖示 | 使用「**重新整理網站圖示**」儲存的圖示，以及開啟「**使用瀏覽器的圖示快取**」後取自瀏覽器圖示快取的圖示 | 同 Chrome | 僅限使用「**重新整理網站圖示**」儲存的圖示，這項工具要在書籤管理員中執行。Firefox 沒有提供擴充功能使用的網站圖示 API，因此其他書籤會顯示通用圖示。 |
| 用於檢查失效連結、擷取標題和重新整理網站圖示的選用網站存取權 | 執行工具時要求 | 同 Chrome | 同 Chrome |

## 測試範圍 [#what-is-tested]

- **Chrome (Chromium)**：單元測試和端對端測試，涵蓋彈出式視窗、側邊面板、書籤管理員、設定、維護工具、報告、匯入和匯出、鍵盤快速鍵、已儲存的搜尋、從右鍵選單儲存、拖放、網路工具，以及以模擬供應商測試的 AI 工具。
- **Edge**：對 Edge 建置版本執行相同的端對端測試套件。
- **Firefox**：冒煙測試套件涵蓋彈出式視窗的搜尋和建立資料夾、在分頁中載入的側邊面板頁面、從彈出式視窗和側邊面板開啟書籤管理員、書籤管理員頁面、儲存設定、JSON 匯出再匯入的完整流程、統計資料和隱私報告，以及彈出式視窗中已儲存的網站圖示。右鍵選單、拖放、鍵盤快速鍵，以及網路和 AI 工具 (包括「**重新整理網站圖示**」本身) 都不在測試範圍內。

Edge 測試套件和 Firefox 冒煙測試套件與 Chromium 測試套件一樣，都是 CI 的必要檢查項目。實際的 AI 供應商和線上網站則以人工檢查，而非自動化測試。

## Safari [#safari]

不支援 Safari。Safari 網頁擴充功能並未實作 `bookmarks` API，而 Bookmark Scout 的所有部分都依賴這個 API。
