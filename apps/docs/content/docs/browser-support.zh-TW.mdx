Chrome 是主要支援的瀏覽器。Edge 以 Chromium 為基礎，功能與 Chrome 相同，下方註明的部分除外。Firefox 使用 Manifest V2 建置版本，功能較少。

## 功能對照表 [#feature-matrix]

這個表格依據各瀏覽器建置完成的擴充功能資訊清單 (manifest)，以及程式碼中的瀏覽器檢查整理而成。

| 功能 | Chrome | Edge | Firefox |

| 可搜尋和儲存的工具列彈出式視窗 | 支援 | 支援 | 支援 |
| 快速儲存快捷鍵，並在網頁中顯示通知 | 支援。可在 `chrome://extensions/shortcuts` 變更按鍵，也可以在那裡將 `Ctrl+D` 指派給快速儲存 | 支援。可在 `edge://extensions/shortcuts` 變更按鍵，包括 `Ctrl+D` | 支援。可在 Bookmark Scout 的設定或 Firefox 的「**管理擴充套件快速鍵**」中變更按鍵。Firefox 會保留 `Ctrl+D` 和 `Ctrl+Shift+D` 供自己使用 |

## 測試範圍 [#what-is-tested]

- **Chrome (Chromium)**：單元測試和端對端測試，涵蓋彈出式視窗、側邊面板、書籤管理員、設定、維護工具、報告、匯入和匯出、鍵盤快速鍵、快速儲存、已儲存的搜尋、從右鍵選單儲存、拖放、網路工具、以模擬供應商測試的 AI 工具，以及橫跨其中多項功能的使用者流程。橋接測試會在 Linux 和 macOS 上的 Chromium 中，搭配擴充功能執行 `bookmark-scout-mcp` 程式。
- **Edge**：對 Edge 建置版本執行相同的端對端測試套件。
- **Firefox**：冒煙測試套件涵蓋彈出式視窗的搜尋和建立資料夾、在分頁中載入的側邊面板頁面、從彈出式視窗和側邊面板開啟書籤管理員、書籤管理員頁面及其網址、`Delete` 和復原、資料夾樹狀結構按鍵、右鍵選單和拖放 (使用模擬的拖曳事件)、快速儲存快捷鍵提示和按鍵錄製器、AI 資料分享同意、儲存設定、JSON 匯出再匯入的完整流程、統計資料和隱私報告，以及彈出式視窗中已儲存的網站圖示。從網頁上的右鍵選單儲存、其他鍵盤快速鍵、彈出式視窗中的拖放、快速儲存通知本身、本機 AI 代理，以及網路和 AI 工具 (包括「**重新整理網站圖示**」本身) 都不在測試範圍內。

Edge 測試套件和 Firefox 冒煙測試套件與 Chromium 測試套件一樣，都是 CI 的必要檢查項目。實際的 AI 供應商和線上網站則以人工檢查，而非自動化測試。

## Safari [#safari]

不支援 Safari。Safari 網頁擴充功能並未實作 `bookmarks` API，而 Bookmark Scout 的所有部分都依賴這個 API。
