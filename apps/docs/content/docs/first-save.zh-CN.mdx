---
title: 第一次保存
description: 将 Bookmark Scout 添加到 Chrome 并固定图标，然后输入文件夹名称的一部分，把第一个网页保存到合适的文件夹。之后只需按一个快捷键即可保存。
---

整个过程大约需要一分钟。你需要电脑上的 Chrome，以及至少一个书签文件夹。

<Steps>
<Step>
### 将 Bookmark Scout 添加到 Chrome [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

在商店页面上点击**添加至 Chrome**，然后点击**添加扩展程序**。Chrome 只会请求一项权限：读取和更改你的书签。随后会在新标签页中打开一个标题为 **Bookmark Scout 已就绪**的页面，简要列出下面的步骤；它会显示你的快速保存快捷键实际分配到的按键。使用的是 Firefox 或 Edge？请参阅[安装](/installation#firefox-and-edge)。
</Step>
<Step>
### 固定图标 [#pin-the-icon]

点击 Chrome 工具栏右侧拼图形状的**扩展程序**按钮，然后点击 Bookmark Scout 旁边的图钉。这样它的图标就会一直显示在工具栏中，点击一下即可打开。
</Step>
<Step>
### 保存当前所在的网页 [#save-the-page-you-are-on]

打开任意一个你想保存的网页，然后点击 Bookmark Scout 图标。搜索框下方的**要保存的页面**这一行会显示该网页的标题。

输入文件夹名称的一部分，例如为名为 Pasta 的文件夹输入 `pas`。匹配的文件夹会显示在**保存到文件夹**下，最匹配的排在最前面。按 `↓` 选中第一个，再按 `Enter`，或者点击该文件夹。出现**已添加书签**即表示保存成功。
</Step>
<Step>
### 下次只需按一个快捷键 [#next-time-press-one-key]

在任意网页上按 `Alt+Shift+S`（在 Mac 上按 `⌥⇧S`）。Bookmark Scout 会把网页保存到最合适的文件夹，无需打开任何界面。页面角落会出现一条小消息，说明保存到了哪里。点击其中的**撤消**可以取消这次保存，也可以在**移动到**下选择其他文件夹。
</Step>
</Steps>

## 如果情况有所不同 [#if-something-is-different]

- **列表中没有你想要的文件夹。** 输入名称的其他部分，或者加上它所在文件夹名称的几个字母，例如 `recipes pas`。有一处小的拼写错误也没关系。
- **按快捷键没有反应。** 可能是其他扩展程序已经占用了这个快捷键。点击 Bookmark Scout 图标打开它：**未设置快速保存快捷键**这一行中有**去设置**。请参阅[用键盘快捷键保存](/guides/save-and-organize#quick-save)。
- **这个网页已经保存过。** Bookmark Scout 不会重复保存；消息会说明它在哪里。
