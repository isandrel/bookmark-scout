## 질문 [#questions]

### Bookmark Scout는 무료인가요? [#is-bookmark-scout-free]

네. <License /> 라이선스의 무료 오픈 소스이며, 광고도 계정도 유료 요금제도 없습니다. 비용이 들 수 있는 것은 선택 사항인 AI 기능뿐입니다. AI 기능은 AI 회사에 있는 내 계정을 사용하며, 그 회사가 사용할 때마다 요금을 청구할 수 있습니다. 내 컴퓨터에서 폴더를 추천하는 Chrome의 내장 AI는 무료입니다.

### AI를 꼭 사용해야 하나요? [#do-i-need-to-use-ai]

아니요. AI는 선택 사항입니다. 저장, 검색, 정리, 정돈, 가져오기와 내보내기는 모두 AI 없이 동작하며, AI는 [설정](/settings#ai)에서 켜기 전까지 꺼져 있습니다. AI를 사용하려면 OpenAI, Anthropic, Google 같은 AI 회사의 계정과, Bookmark Scout가 그 계정을 사용할 수 있게 해 주는 계정의 키(API 키)가 필요합니다. 이런 회사는 대부분 사용할 때마다 보통 적은 금액을 청구합니다. Ollama처럼 내 컴퓨터에서 실행하는 AI 프로그램은 무료지만 꽤 성능이 좋은 컴퓨터가 필요합니다. Chrome에서는 내장 AI를 실행할 수 있는 컴퓨터라면 계정이나 키 없이 무료로 폴더를 추천받을 수 있습니다. AI 도구가 다루는 북마크 제목과 주소는 내가 고른 회사로 전송됩니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

### 내 북마크를 어딘가로 보내나요? [#does-it-send-my-bookmarks-anywhere]

개발자에게는 보내지 않습니다. Bookmark Scout 서버는 존재하지 않습니다. 데이터는 직접 켠 AI 도구를 사용할 때(내가 고른 제공업체로 전송)나 깨진 링크 확인 또는 제목 가져오기를 실행할 때(북마크한 웹사이트에 요청), 로컬 AI 에이전트가 북마크를 조회하도록 허용했을 때(에이전트가 요청한 내용을 이 컴퓨터의 프로그램을 통해 받음)만 브라우저 밖으로 나갑니다. [개인정보 보호](/privacy)를 참고하세요.

### 묻지 않고 북마크를 바꾸지는 않나요? [#will-it-change-my-bookmarks-without-asking]

바꾸지 않습니다. 중복 정리, URL 정리, 깨진 링크 복구, 가져온 제목, AI 재구성, 가져오기는 모두 무엇이든 쓰기 전에 검토 화면을 보여 줍니다. **AI에게 묻기**와 로컬 AI 에이전트는 변경 사항을 계획으로 보여 주고 승인을 기다립니다. 삭제는 기본적으로 확인을 요청하며, 삭제, 정돈, 가져오기는 메시지에서 실행 취소할 수 있고, 북마크 관리자에서 한 변경은 <Shortcut id="manager.undo" />로 실행 취소할 수 있습니다.

### 어느 브라우저 스토어에서 받을 수 있나요? [#which-browser-stores-list-it]

<StoreAvailability />

각 스토어는 확장 프로그램을 등록하기 전에 심사합니다. 사용하는 브라우저의 스토어에 아직 등록되지 않았다면 [직접 설치](/installation#install-from-a-github-release)할 수 있습니다(고급).

### Firefox에서도 동작하나요? [#does-it-work-in-firefox]

아직 Firefox 부가 기능에서는 받을 수 없으며, Firefox 버전은 곧 나올 예정입니다. 그전까지는 임시 부가 기능으로 [직접 설치](/installation#firefox)할 수 있지만, Firefox를 다시 시작하면 제거됩니다. 설치하고 나면 몇 가지 차이를 빼고 똑같이 동작합니다. Firefox는 확장 프로그램이 북마크 페이지를 대체하도록 허용하지 않으므로, 정리 도구, 가져오기와 내보내기, 저장된 검색이 있는 Bookmark Scout 관리자는 팝업의 **북마크 관리자 열기**로 열어야 하고, 브라우저의 아이콘 캐시는 사용할 수 없습니다. [브라우저 지원](/browser-support)을 참고하세요.

### Microsoft Edge에서도 동작하나요? [#does-it-work-in-microsoft-edge]

아직 Microsoft Edge 추가 기능에서는 받을 수 없으며, Edge 버전은 곧 나올 예정입니다. 그전까지는 [직접 설치](/installation#edge)할 수 있고, 설치하면 Chrome과 거의 같게 동작합니다. [브라우저 지원](/browser-support)을 참고하세요.

### 휴대전화에서도 동작하나요? [#does-it-work-on-my-phone]

아니요. Bookmark Scout는 컴퓨터의 브라우저용 확장 프로그램입니다. 휴대전화와 태블릿의 브라우저에서는 실행되지 않습니다.

### Safari는 왜 지원하지 않나요? [#why-not-safari]

Safari Web Extensions는 Bookmark Scout의 기반인 `bookmarks` API를 구현하지 않습니다.

## 문제 해결 [#troubleshooting]

### 북마크 관리자는 어디에 있나요? [#where-is-the-bookmarks-manager]

Chrome에서는 브라우저 자체의 북마크 페이지를 엽니다(예: <Shortcut id="browser.open_bookmarks_manager" />). Bookmark Scout가 이 페이지를 관리자로 대체합니다. **도구** 사이드바가 숨겨져 있으면 관리자 머리글의 **도구 표시**를 클릭하세요.

### Firefox에서 Bookmark Scout가 사라졌습니다 [#bookmark-scout-disappeared-from-firefox]

Firefox는 다시 시작할 때 임시 부가 기능을 제거합니다. [설치](/installation)에 나온 대로 `about:debugging#/runtime/this-firefox`에서 다시 로드하세요.

### 사이트 아이콘이 표시되지 않습니다 [#site-icons-are-missing]

[설정](/settings#appearance)에서 **파비콘 표시**가 켜져 있는지 확인하세요. Chrome과 Edge는 사이트마다 캐시해 둔 아이콘을 표시하므로, 최근에 방문하지 않은 사이트에는 기본 지구본 아이콘이 표시됩니다. Firefox에는 확장 프로그램용 아이콘 API가 없습니다. 어느 브라우저에서든 [사이트 아이콘 새로 고침](/guides/clean-up#refresh-site-icons)을 사용하면 각 사이트의 아이콘을 내려받아 이 기기에 보관합니다.

### API 키가 저장되지 않았습니다 [#my-api-key-was-not-saved]

선택한 AI 회사(서비스의 제공업체)의 키 형식과 맞지 않는 키는 거부되어 저장되지 않으며, 이를 알리는 메시지가 표시됩니다. 서비스의 제공업체가 키를 발급한 회사와 같은지 확인하세요. [AI 도구 설정](/guides/ai-tools#turn-on-ai)을 참고하세요.

### AI가 태그나 요약을 다른 언어로 씁니다 [#ai-writes-tags-or-summaries-in-the-wrong-language]

AI는 태그, 요약, 새 폴더 이름을 [설정](/settings#ai-output-language)의 **AI 출력 언어**에서 정한 언어로 씁니다. 기본값은 Bookmark Scout 자체의 표시 언어입니다. 그곳에서 다른 언어를 고르거나, **각 페이지와 같음**을 골라 각 페이지의 언어를 따르게 하세요. AI에게 묻기는 내가 쓴 언어로 답합니다.

### 정상 동작하는 사이트인데 깨진 링크 확인에서 직접 확인이 필요하다고 나옵니다 [#the-dead-link-check-says-a-working-site-needs-a-manual-check]

로그인을 요구하거나, 요청 빈도를 제한하거나, 자동 검사를 차단하거나, 서버 오류가 발생한 사이트는 브라우저에서는 여전히 동작하는 경우가 많으므로 **직접 확인 필요**로 분류됩니다. 링크를 열어 확인하세요. 페이지를 찾을 수 없음, 연결 거부, 알 수 없는 호스트, 리디렉션 반복만 **깨진 링크 확인됨**으로 분류됩니다. [깨진 링크 찾기와 복구](/guides/dead-links#read-the-results)를 참고하세요.

### 검사 중에 콘솔에 "Failed to load resource"가 표시됩니다 [#the-console-shows-failed-to-load-resource-during-a-scan]

Chrome은 실패한 요청마다 페이지의 개발자 콘솔에 한 줄씩 기록합니다. 확장 프로그램은 이 기록을 숨길 수 없으며, 검사에 문제가 생겼다는 뜻도 아닙니다.

### 관리자에서 바꾼 순서가 팝업에 반영되지 않습니다 [#reordering-in-the-manager-does-not-show-in-the-popup]

팝업은 **브라우저 순서**(기본값)와 **폴더 우선** 정렬일 때 브라우저에 저장된 순서를 표시합니다. **추가일 순**과 **알파벳 순** 정렬은 목록을 계속 다시 정렬합니다. [설정](/settings#behavior)에서 **정렬 순서**를 변경하세요.

### 검색 결과가 표시된 것보다 더 있다고 나옵니다 [#search-says-there-are-more-matches-than-it-shows]

결과는 **최대 검색 결과**(기본값 20개)까지만 표시됩니다. 검색어를 구체적으로 바꾸거나 [설정](/settings#search)에서 한도를 늘리세요.

### 다른 컴퓨터에서 태그, 요약, 저장된 검색이 보이지 않습니다 [#my-tags-summaries-or-saved-searches-are-missing-on-another-computer]

이 데이터는 만든 기기에만 저장되며 동기화되지 않습니다. 옮기려면 북마크를 JSON으로 내보내고(태그와 요약은 가져오기로 만들어지는 북마크에 함께 옮겨집니다), [설정](/settings) 맨 아래의 **설정 백업**으로 백업을 저장하세요(저장된 검색이 포함됩니다). 설정은 브라우저 동기화가 켜져 있으면 브라우저 계정을 통해 동기화됩니다.

### 실수로 삭제했습니다 [#i-deleted-something-by-mistake]

10초 안에 메시지의 **실행 취소**를 클릭하세요. 항목과 그 안의 모든 항목, 저장된 태그와 요약이 복원되며, 복원된 항목의 추가한 날짜는 새로 지정됩니다. 북마크 관리자에서는 그곳에서 한 삭제나 AI에게 묻기 또는 로컬 AI 에이전트가 한 삭제도 브라우저를 닫기 전까지 <Shortcut id="manager.undo" />로 실행 취소할 수 있습니다. [관리자에서 선택, 실행 취소, 다시 실행](/guides/save-and-organize#select-undo-and-redo-in-the-manager)을 참고하세요.

### 빠른 저장 단축키가 동작하지 않습니다 [#the-quick-save-shortcut-does-nothing]

다른 확장 프로그램이 이미 <Shortcut id="commands.quick-save" />나 <Shortcut id="commands.ai-quick-save" />를 사용하고 있으면 브라우저가 Bookmark Scout의 단축키에 키를 지정하지 않으며, 팝업에 **빠른 저장 단축키가 설정되지 않음**이 표시됩니다. **설정하기**를 클릭하거나 [설정](/settings#quick-save)의 **저장 및 검색**에서 **키보드 단축키**를 열고 다른 키를 고르세요. 브라우저 자체 페이지처럼 확장 프로그램이 아무것도 표시할 수 없는 페이지에서는 알림 대신 툴바 아이콘에 결과가 표시됩니다. [키보드 단축키로 저장](/guides/save-and-organize#quick-save)을 참고하세요.

### 업데이트 후 설정이 사라졌습니다 [#my-settings-are-gone-after-an-update]

업데이트해도 보통은 설정이 그대로 유지됩니다. 버전 0.3.3으로의 업데이트 한 번은 Bookmark Scout의 저장 데이터를 새 형식으로 옮기면서 기존 데이터를 변환하지 않고 삭제했습니다. 그 이후에는 설정이 기본값으로 돌아가고, AI 서비스와 API 키를 다시 추가해야 하며, 사용자 지정 프롬프트, 저장된 검색, 최근 검색과 폴더, 태그와 요약, 저장된 사이트 아이콘이 사라집니다. 북마크 자체는 영향을 받지 않습니다. 업데이트 전에 [설정](/settings) 맨 아래의 **설정 백업**(당시 이름은 **내보내기**)으로 설정을 저장해 두었다면 **설정 복원**으로 그 파일을 여세요.
