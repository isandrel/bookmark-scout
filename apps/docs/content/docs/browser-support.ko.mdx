---
title: 브라우저 지원
description: Chrome, Microsoft Edge, Firefox에서 동작하는 기능과 브라우저별로 설치할 수 있는 곳, 그리고 Safari를 지원하지 않는 이유를 설명합니다.
---

Bookmark Scout는 Chrome에서 가장 잘 동작하며, Chrome 웹 스토어에서 설치할 수 있습니다. Edge는 아래에 따로 적은 경우를 제외하면 기능이 같습니다. Firefox는 확장 프로그램이 북마크로 할 수 있는 일을 더 제한하기 때문에 기능이 조금 적습니다. 세 브라우저 모두 컴퓨터에서 동작하며, 휴대전화와 태블릿은 지원하지 않습니다.

## 설치할 수 있는 곳 [#where-to-get-it]

<StoreAvailability />

스토어에 아직 Bookmark Scout가 등록되지 않았다면 [직접 설치](/installation#install-from-a-github-release)할 수 있습니다. 스토어 등록 자료는 저장소의 <RepoLink tree="store">`store/` 폴더</RepoLink>에서 준비하며, 각 스토어는 확장 프로그램을 등록하기 전에 심사합니다.

## 브라우저별 기능 [#feature-matrix]

이 표는 브라우저별로 빌드한 확장 프로그램의 매니페스트와 코드에 있는 브라우저 확인을 바탕으로 작성되었습니다.

| 기능 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 검색과 저장 기능이 있는 툴바 팝업 | 지원 | 지원 | 지원 |
| 페이지 안에 알림을 표시하는 빠른 저장 단축키 | 지원. `chrome://extensions/shortcuts`에서 키를 바꿀 수 있으며, 빠른 저장에 <Shortcut id="browser.bookmark_page" />를 지정할 수도 있음 | 지원. `edge://extensions/shortcuts`에서 <Shortcut id="browser.bookmark_page" />를 포함해 키를 바꿀 수 있음 | 지원. Bookmark Scout 설정이나 Firefox의 **확장 기능 단축키 관리**에서 키를 바꿀 수 있음. Firefox는 <Shortcut id="browser.bookmark_page" />와 <Shortcut id="browser.bookmark_all_tabs" />를 직접 사용함 |
| 사이드 패널 | 지원 | 지원 | 지원(Firefox 사이드바): 사이드바에서 Bookmark Scout를 선택합니다 |
| 북마크 관리자와 **도구** 사이드바 | 브라우저의 북마크 페이지를 대체하며, 팝업과 사이드 패널의 **북마크 관리자 열기**로도 열 수 있음 | **북마크 관리자 열기**로 엶. Edge가 즐겨찾기 페이지에도 대체를 적용하는지는 확인하지 않았습니다. | 팝업의 **북마크 관리자 열기**로 엶. Firefox는 북마크 페이지를 대체할 수 없습니다. |
| 저장된 검색, 유지 관리 도구, 가져오기와 내보내기, 통계, 관리자의 AI 도구 | 지원 | 지원 | 관리자에서 지원. 가져오기와 내보내기, 보고서, 깨진 링크 확인, 메타데이터 가져오기, 페이지 본문 색인, 표지 가져오기, 스마트 규칙, AI 폴더 재구성은 자동 테스트로 확인하며, 다른 도구는 직접 확인합니다. |
| 설정 페이지 | 지원 | 지원 | 지원 |
| AI에게 묻기와 기타 AI 도구 | 지원 | 지원 | AI 제공업체와 데이터를 공유하는 데 동의한 뒤 지원 |
| 컴퓨터에서 무료로 실행되는 내장 AI의 폴더 추천 | 지원. Chrome 138 이상, Chrome의 모델을 실행할 수 있는 컴퓨터에서 | Edge가 같은 내장 AI를 제공하는 경우에만. 확인하지 않음 | 미지원. Firefox에는 내장 AI가 없음 |
| `bookmark-scout-mcp`를 통한 로컬 AI 에이전트(개발자용) | 지원 | 지원 | 지원. `bookmark-scout-mcp install`이 Firefox에도 등록함. 자동 테스트로는 다루지 않음 |
| 관리자에서 시크릿 창으로 열기 | 지원 | InPrivate 창으로 지원 | 확장 프로그램이 사생활 보호 창에서 허용된 경우 사생활 보호 창으로 지원 |
| 링크를 저장하는 마우스 오른쪽 버튼 메뉴 | 지원. **마우스 오른쪽 버튼 메뉴**를 켠 뒤 사용 가능(권한 요청) | 동일 | 지원. **마우스 오른쪽 버튼 메뉴**를 켠 뒤 사용 가능 |
| 북마크 옆의 사이트 아이콘 | **사이트 아이콘 새로 고침**으로 저장한 아이콘, 그리고 **브라우저 아이콘 캐시 사용**을 켜면 브라우저의 아이콘 캐시에 있는 아이콘 | 동일 | 관리자에서 실행하는 **사이트 아이콘 새로 고침**으로 저장한 아이콘만 표시. Firefox에는 확장 프로그램용 파비콘 API가 없어 다른 북마크에는 기본 아이콘이 표시됩니다. |
| 깨진 링크 확인, 제목 가져오기, 사이트 아이콘 새로 고침, 페이지 본문 색인, 표지 가져오기를 위한 선택적 웹사이트 접근 | 도구를 실행할 때 요청 | 동일 | 동일 |
| 탐색 중에 찍는 표지(**탐색 중 표지 캡처**) | 지원. 모든 페이지에 대한 접근을 허용한 뒤 | 동일 | 동일 |

브라우저별로 자동 테스트가 얼마나 다루는지는 [프로젝트 현황](/status#what-is-tested-in-each-browser)에 있습니다.

## Safari [#safari]

Safari는 지원하지 않습니다. Safari Web Extensions는 Bookmark Scout의 모든 부분이 의존하는 `bookmarks` API를 구현하지 않습니다.
