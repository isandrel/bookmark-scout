Chrome이 주요 대상입니다. Edge는 Chromium 기반이며, 아래에 따로 적은 경우를 제외하면 기능이 같습니다. Firefox는 기능 범위가 더 작은 Manifest V2 빌드를 사용합니다.

## 기능 비교표 [#feature-matrix]

이 표는 브라우저별로 빌드한 확장 프로그램의 매니페스트를 바탕으로 작성되었습니다.

| 기능 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 검색과 저장 기능이 있는 툴바 팝업 | 지원 | 지원 | 지원 |
| 사이드 패널 | 지원 | 지원 | 지원(Firefox 사이드바): 사이드바에서 Bookmark Scout를 선택합니다 |
| 북마크 관리자와 **도구** 사이드바 | 브라우저의 북마크 페이지를 대체하며, 팝업과 사이드 패널의 **북마크 관리자 열기**로도 열 수 있음 | **북마크 관리자 열기**로 엶. Edge가 즐겨찾기 페이지에도 대체를 적용하는지는 확인하지 않았습니다. | 팝업의 **북마크 관리자 열기**로 엶. Firefox는 북마크 페이지를 대체할 수 없습니다. |
| 저장된 검색, 유지 관리 도구, 가져오기와 내보내기, 통계, 관리자의 AI 도구 | 지원 | 지원 | 관리자에서 지원. 가져오기와 내보내기, 보고서는 자동 테스트로 확인하며, 다른 도구는 직접 확인합니다. |
| 설정 페이지 | 지원 | 지원 | 지원 |
| 링크를 저장하는 마우스 오른쪽 버튼 메뉴 | 지원. **컨텍스트 메뉴**를 켠 뒤 사용 가능(권한 요청) | 동일 | 지원. **컨텍스트 메뉴**를 켠 뒤 사용 가능 |
| 북마크 옆의 사이트 아이콘 | **사이트 아이콘 새로 고침**으로 저장한 아이콘, 그리고 **브라우저 아이콘 캐시 사용**을 켜면 브라우저의 아이콘 캐시에 있는 아이콘 | 동일 | 관리자에서 실행하는 **사이트 아이콘 새로 고침**으로 저장한 아이콘만 표시. Firefox에는 확장 프로그램용 파비콘 API가 없어 다른 북마크에는 기본 아이콘이 표시됩니다. |
| 깨진 링크 확인, 제목 가져오기, 사이트 아이콘 새로 고침을 위한 선택적 웹사이트 접근 | 도구를 실행할 때 요청 | 동일 | 동일 |

## 테스트 범위 [#what-is-tested]

- **Chrome (Chromium)**: 팝업, 사이드 패널, 관리자, 설정, 유지 관리 도구, 보고서, 가져오기와 내보내기, 키보드 단축키, 저장된 검색, 컨텍스트 메뉴 저장, 드래그 앤 드롭, 네트워크 도구, 모의 제공업체를 사용한 AI 도구에 대한 단위 테스트와 엔드 투 엔드 테스트가 있습니다.
- **Edge**: 같은 엔드 투 엔드 테스트 모음을 Edge 빌드에서 실행합니다.
- **Firefox**: 스모크 테스트 모음이 팝업 검색과 폴더 만들기, 탭에서 로드한 사이드 패널 페이지, 팝업과 사이드 패널에서 관리자 열기, 관리자 페이지, 설정 저장, JSON 내보내기 후 다시 가져오기, 통계 및 개인정보 보고서, 팝업에 표시되는 저장된 사이트 아이콘을 다룹니다. 컨텍스트 메뉴, 드래그 앤 드롭, 키보드 단축키, 네트워크 도구와 AI 도구(**사이트 아이콘 새로 고침** 자체 포함)는 다루지 않습니다.

Edge 테스트 모음과 Firefox 스모크 테스트 모음은 Chromium 테스트 모음과 마찬가지로 필수 CI 검사입니다. 실제 AI 제공업체와 실제 웹사이트는 자동 테스트가 아니라 직접 확인합니다.

## Safari [#safari]

Safari는 지원하지 않습니다. Safari Web Extensions는 Bookmark Scout의 모든 부분이 의존하는 `bookmarks` API를 구현하지 않습니다.
