Voici les autorisations de l'extension compilée pour chaque navigateur. Bookmark Scout ne déclare aucun script de contenu et ne lit une page que vous consultez que si vous le demandez : **Indexer le texte de cette page** dans la fenêtre pop-up lit le texte que cet onglet affiche, et avec **Capturer les couvertures en naviguant** activé, il capture une page en favori que vous ouvrez, et cette capture reste sur cet appareil ; après un raccourci d'enregistrement rapide, il se contente d'afficher sa propre notification dans cet onglet. À l'installation, il ne demande que ce dont il ne peut pas se passer ; tout le reste est demandé lorsque vous activez ou lancez la fonctionnalité qui en a besoin. Avec Récupérer les couvertures et **Enregistrer une couverture avec l'enregistrement rapide** activés, un raccourci d'enregistrement rapide lit aussi les balises d'image d'aperçu de cet onglet et peut en prendre une capture comme couverture du nouveau favori, gardée sur cet appareil.

## Ce que votre navigateur va demander, et pourquoi [#what-your-browser-will-ask-and-why]

Lorsque vous installez Bookmark Scout, le navigateur affiche une seule ligne. Tout le reste n'est demandé que lorsque vous utilisez la fonctionnalité qui en a besoin, après une courte explication dans Bookmark Scout. Si vous refusez, seule cette fonctionnalité reste désactivée. Le tableau cite le libellé de Chrome en français et décrit celui de Firefox.

| Le navigateur indique (Chrome et Edge / Firefox) | Quand | Raison |
| --- | --- | --- |
| « Accéder à vos favoris et les modifier » / lire et modifier les favoris | À l'installation | Enregistrer vos favoris, y faire des recherches et les ranger |
| « Accéder aux icônes des sites Web que vous consultez » (Chrome et Edge uniquement) | Vous cliquez sur **Afficher les icônes du navigateur** dans **Actualiser les icônes de site**, ou activez **Utiliser le cache d'icônes du navigateur** | Afficher à côté de vos favoris les icônes que votre navigateur a déjà enregistrées. Rien n'est téléchargé |
| « Consulter votre historique de navigation » / accéder aux onglets du navigateur | Vous enregistrez la page actuelle, ou demandez des suggestions de dossiers, depuis le panneau latéral | Savoir sur quelle page vous êtes. Le bouton de la barre d'outils et le raccourci d'enregistrement rapide ne nécessitent aucune autorisation : l'explication les propose donc en premier |
| « Lire et modifier vos données sur tous les sites example.com », ou « sur certains sites Web » / accéder à vos données pour les sites du domaine example.com | Vous lancez **Vérifier les liens morts**, **Récupération des métadonnées** ou **Actualiser les icônes de site** | Demander les pages enregistrées en favoris concernées par cette exécution, sur leurs seuls sites |
| « Lire et modifier toutes vos données sur tous les sites Web » / accéder à vos données pour tous les sites Web | Un outil est lancé sur plus de 20 sites, ou vous activez **Lire le contenu des pages** | Demander des pages sur n'importe quel site |
| « Lire et modifier toutes vos données sur tous les sites Web » / accéder à vos données pour tous les sites Web | Vous activez **Capturer les couvertures en naviguant** | Capturer une page en favori dans l'onglet que vous consultez quand elle se charge, sans clic, ce que les navigateurs n'autorisent qu'avec l'accès à toutes les pages. La capture reste sur cet appareil, et le même accès permet aux outils de sites Web de s'exécuter sans demander |
| « Lire et modifier vos données sur api.example.com » / accéder à vos données pour api.example.com | Vous cliquez sur **Vérifier le service** ou **Actualiser les modèles** | Joindre l'adresse de votre fournisseur d'IA |
| « Communiquer avec les applications natives associées » / échanger des messages avec des programmes autres que Firefox | Vous activez **Autoriser les agents d'IA locaux** | Communiquer avec le programme bookmark-scout-mcp de votre ordinateur |
| Firefox uniquement : le développeur indique que l'extension souhaite collecter des informations d'authentification, des favoris et l'activité de navigation | Vous activez les **Fonctionnalités d'IA** | Votre clé API, vos favoris et noms de dossiers, ainsi que le titre et l'URL de la page actuelle, sont envoyés à votre fournisseur d'IA. Le développeur mentionné dans cette demande est le fournisseur d'IA que vous avez choisi ; Bookmark Scout ne reçoit rien |
| Firefox uniquement : la même demande, pour le contenu des sites Web | Vous activez **Lire le contenu des pages** | Le texte des pages est envoyé à votre fournisseur d'IA |
| Firefox uniquement : la même demande, pour les informations d'authentification | Vous cliquez sur **Vérifier le service** ou **Actualiser les modèles** | Votre clé API est envoyée à votre fournisseur d'IA |
| Firefox uniquement : la même demande, pour les favoris et l'activité de navigation | Vous activez **Autoriser les agents d'IA locaux** | Ce que les agents d'IA de votre ordinateur peuvent consulter |

Le menu du clic droit (**Menu du clic droit**) est lui aussi facultatif dans Chrome et Edge, mais il ne déclenche aucun avertissement : le navigateur l'ajoute donc sans rien demander.

## Accordées à l'installation [#granted-at-install]

| Autorisation | Navigateurs | Raison |
| --- | --- | --- |
| `bookmarks` | Tous | Afficher vos favoris et y effectuer des recherches, ainsi que les créer, les modifier, les déplacer et les supprimer lorsque vous agissez dans la fenêtre pop-up, le panneau latéral, le gestionnaire ou le menu contextuel |
| `storage` | Tous | Enregistrer vos paramètres et, uniquement sur cet appareil, les paramètres de votre fournisseur d'IA, vos étiquettes, résumés, recherches enregistrées, dossiers récents, recherches récentes et les icônes de site enregistrées avec **Actualiser les icônes de site** |
| `activeTab` | Tous | Lorsque vous cliquez sur le bouton de la barre d'outils ou sur le menu contextuel, ou appuyez sur un raccourci d'enregistrement rapide, lire le titre et l'URL de cet onglet, pour que vous puissiez enregistrer la page que vous consultez. Aucun autre onglet, aucun historique. Avec Récupérer les couvertures activé, le bouton **Utiliser cette vue comme couverture** de la fenêtre pop-up capture aussi une image de cet onglet, que vous voyez avant qu'elle soit conservée. Avec Indexer le texte des pages activé, le bouton **Indexer le texte de cette page** de la fenêtre pop-up lit le texte que cet onglet affiche, que vous voyez avant qu'il soit conservé. Avec Récupérer les couvertures et **Enregistrer une couverture avec l'enregistrement rapide** activés, un raccourci d'enregistrement rapide lit aussi les balises d'image d'aperçu de cet onglet et peut en prendre une capture comme couverture du nouveau favori, sans vérification ; jamais dans une fenêtre privée. |
| `scripting` | Tous | Après un raccourci d'enregistrement rapide, afficher la notification dans cet onglet uniquement. Il ne lit rien de la page. Avec Indexer le texte des pages activé, le bouton **Indexer le texte de cette page** de la fenêtre pop-up exécute, après votre clic, une fonction dans cet onglet qui renvoie la page telle qu'elle s'affiche, sans ce que vous avez saisi dans ses champs, pour en lire le texte sur cet appareil |
| `sidePanel` | Chrome, Edge | Fournir la vue du panneau latéral. Firefox déclare cette même page comme barre latérale |
| `offscreen` | Chrome, Edge | Exécuter la requête de l'enregistrement rapide avec l'IA, la lecture d'une page pour un agent d'IA local, la lecture des titres de pages de la **Récupération des métadonnées**, la lecture du texte des pages d'**Indexer le texte des pages** et les requêtes de la **Réorganisation des dossiers par IA** dans une page d'extension masquée, que le navigateur ferme lorsque le travail se termine. La page d'arrière-plan de Firefox s'en charge elle-même |
| `alarms` | Tous | Réveiller l'arrière-plan à intervalles, pour qu'une tâche en arrière-plan comme **Vérifier les liens morts** reprenne après que le navigateur a arrêté l'arrière-plan. Aucune invite |
| `contextMenus` | Firefox | Firefox ne permet pas aux extensions de la demander ultérieurement. Le menu n'apparaît toutefois qu'après l'activation du **Menu du clic droit** |

Dans Chrome et Edge, l'extension remplace également la page Favoris du navigateur par le gestionnaire Bookmark Scout. Il s'agit d'un remplacement de page, et non d'une autorisation. Firefox ne le permet pas : le gestionnaire s'y ouvre donc depuis **Ouvrir le gestionnaire de favoris** dans la fenêtre pop-up ; consultez [Compatibilité des navigateurs](/browser-support).

## Demandées lorsque vous en avez besoin [#asked-for-when-you-need-it]

| Autorisation | Navigateurs | Demandée lorsque |
| --- | --- | --- |
| `tabs` | Tous | Vous enregistrez la page actuelle, ou demandez des suggestions de dossiers, depuis le panneau latéral. Une courte explication s'affiche d'abord et propose la fenêtre pop-up de la barre d'outils et le raccourci d'enregistrement rapide, qui n'en ont jamais besoin |
| `contextMenus` | Chrome, Edge | Vous activez le **Menu du clic droit** dans les [Paramètres](/settings#data). Il est désactivé par défaut, et Chrome accorde cette autorisation sans demande de confirmation |
| `favicon` | Chrome, Edge | Vous cliquez sur **Afficher les icônes du navigateur** dans **Actualiser les icônes de site**, ou activez **Utiliser le cache d'icônes du navigateur** dans les [Paramètres](/settings#appearance), pour afficher les icônes que le navigateur a déjà enregistrées. Une courte explication s'affiche d'abord |
| Consentement au partage de données | Firefox | Chaque fonctionnalité ne demande que ce qu'elle envoie : les **Fonctionnalités d'IA** pour votre clé API, vos favoris, ainsi que le titre et l'URL de la page actuelle ; **Lire le contenu des pages** pour le texte des pages ; **Vérifier le service** pour votre clé API. Une courte explication indique d'abord que les données vont à votre fournisseur d'IA, et non à Bookmark Scout |
| `nativeMessaging` | Tous | Vous activez **Autoriser les agents d'IA locaux** dans les [Paramètres](/settings#agent-bridge), pour que l'extension puisse communiquer avec le programme bookmark-scout-mcp de votre ordinateur. Une courte explication s'affiche d'abord ; dans Firefox, la même demande porte aussi sur le partage des données de favoris avec lui |

Si vous refusez, la fonctionnalité reste désactivée et rien n'est envoyé. Si vous retirez ultérieurement une autorisation dans les paramètres des extensions du navigateur, la fonctionnalité est désactivée ; la réactiver entraîne une nouvelle demande.

## Accès facultatif aux sites Web [#optional-website-access]

L'extension déclare aussi un accès à `http://*/*`, à `https://*/*` et à `<all_urls>`, mais aucune partie de cet accès n'est accordée à l'installation. Le navigateur vous le demande au moment où vous en avez besoin :

- **Vérifier les liens morts**, **Récupération des métadonnées** et **Actualiser les icônes de site** demandent, lorsque vous les lancez, l'accès aux seuls sites des favoris concernés par cette exécution, chacun avec ses sous-domaines. Une exécution portant sur plus de 20 sites demande à la place l'accès à tous les sites Web. Les sites que vous avez déjà autorisés ne sont pas demandés à nouveau. Les requêtes sont envoyées sans cookies, et seul l'en-tête de la page est lu pour obtenir les titres et les liens des icônes. Si vous refusez, rien n'est analysé. Un lien qui redirige vers un site extérieur à l'exécution ne peut pas être suivi : **Vérifier les liens morts** le marque donc **À vérifier manuellement** au lieu de mort. Consultez [Trouver et réparer les liens morts](/guides/dead-links) et [Actualiser les icônes de site](/guides/clean-up#refresh-site-icons).
- **Indexer le texte des pages** le demande de la même façon, pour les sites des favoris qu'il lit.
- **Récupérer les couvertures** le demande de la même façon, pour les sites des favoris qu'il lit ; une image sur un autre site n'est téléchargée que si vous avez aussi autorisé ce site.
- **Capturer les couvertures en naviguant** demande l'accès à toutes les pages (`<all_urls>`) lorsque vous l'activez : les navigateurs ne laissent une extension capturer un onglet sans clic qu'avec cet accès. Les captures ne sont prises que de pages en favori dans l'onglet que vous consultez, jamais des sites de **Ne jamais capturer ces sites**, pas dans les fenêtres privées sauf si vous activez **Capturer aussi dans les fenêtres privées** et autorisez l'extension à y fonctionner, et restent sur cet appareil. Tant qu'il est accordé, les outils ci-dessus ne demandent plus l'accès à leurs sites. Consultez [Afficher les couvertures sur les cartes](/guides/clean-up#capture-covers-while-you-browse).
- **Lire le contenu des pages**, dans les paramètres d'IA, demande l'accès à tous les sites Web lors de son activation, pour que les outils d'IA puissent télécharger les pages, sans cookies, et envoyer leur texte principal à votre fournisseur d'IA. Les pages de votre réseau local ne sont jamais lues. Consultez [Lire le contenu des pages](/guides/ai-tools#read-page-content).
- **Vérifier le service** et **Actualiser les modèles**, dans les paramètres d'IA, demandent l'accès à l'adresse de ce seul fournisseur. Consultez [Configurer les outils d'IA](/guides/ai-tools).

Pour retirer cet accès, ouvrez la page de l'extension dans le navigateur (par exemple `chrome://extensions/`, puis **Détails** sous Bookmark Scout, ou **Permissions** dans `about:addons` de Firefox) et modifiez l'accès aux sites ou les autorisations.

## Ce qui n'est pas demandé [#what-is-not-requested]

- Aucun script de contenu déclaré, et aucun accès au contenu des pages au-delà des fonctionnalités ci-dessus que vous activez
- Aucune autorisation d'accès à l'historique, aux téléchargements ou aux cookies
- Aucun accès aux hôtes à l'installation

L'endroit où vont vos données lorsqu'une autorisation est utilisée est décrit dans [Confidentialité](/privacy). La justification de chaque autorisation, telle que soumise aux boutiques, figure dans le fichier <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink> du dépôt.
