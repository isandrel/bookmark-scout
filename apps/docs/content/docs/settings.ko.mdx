설정 페이지는 확장 프로그램의 **옵션** 항목에서 엽니다. 예를 들어 Chrome에서는 툴바 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **옵션**을 선택합니다. 변경 사항은 바꾸는 즉시 저장됩니다.

## 설정 페이지 사용하기 [#using-the-settings-page]

- 맨 위의 <strong>설정 검색...</strong>은 모든 탭에서 설정을 찾고, 일치하는 설정이 몇 개인지 알려 줍니다.
- 바꾼 설정에는 **변경됨** 표시와 함께 기본값으로 되돌리는 버튼이 나타납니다. **전체 초기화**는 모든 설정을 초기화합니다.
- **내보내기**는 설정을 JSON 파일로 저장하고, **가져오기**는 그 파일에서 설정을 복원합니다. 둘 다 북마크는 건드리지 않습니다.
- 설정은 브라우저의 동기화 저장소에 저장되므로, 브라우저 동기화가 켜져 있으면 다른 기기에도 적용됩니다. 단, AI 제공업체의 API 키, **기본 URL**, <strong>추가 헤더(JSON)</strong>는 예외로 이 기기에만 저장됩니다. [개인정보 보호](/privacy)를 참고하세요.

| **파비콘 크기** | 16px (작게) | 16, 24, 32픽셀 |

## AI [#ai]

AI는 기본적으로 꺼져 있습니다. 이 설정은 **AI 기능**을 켠 뒤에만 의미가 있습니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **AI 기능** | 꺼짐 | AI 도구와 팝업의 폴더 추천을 켭니다. Firefox에서는 켤 때 AI 제공업체에 필요한 데이터를 공유하는 데 동의할지 묻습니다 |
| **열 때 자동 추천** | 꺼짐 | 팝업을 열 때마다 폴더 추천을 요청합니다 |
| **페이지 내용 읽기** | 꺼짐 | 폴더 추천, 자동 태그 지정, 콘텐츠 요약에 각 페이지의 제목과 URL뿐 아니라 본문도 보냅니다. 켜면 웹사이트 접근 권한을 요청합니다 |
| **AI 제공자**와 **AI 모델** | OpenAI, GPT-4o Mini | 모든 AI 도구가 사용하는 제공업체와 모델 |
| **최대 추천 수** | 5 | 요청할 최대 폴더 추천 수 |
| **최대 카테고리 수** | 제한 없음 | 재구성 계획이 만들 수 있는 최상위 폴더의 최대 수 |
| **폴더당 최소 항목 수**와 **폴더당 최대 항목 수** | 1과 제한 없음 | 재구성 계획의 폴더 크기 목표 |

그 아래 제공업체 패널에는 **API 키**, **기본 URL**, **사용자 지정 모델**, <strong>추가 헤더(JSON)</strong>와 함께 **서비스 확인**, **모델 새로 고침**이 있습니다. 폴더 제한은 제공업체에 지시 사항으로 전달되며, 결과가 이 제한을 지키는지는 확인하지 않습니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

## AI 도구 [#ai-tools]

각 도구에는 **사용** 스위치가 있습니다(기본값은 켜짐). 끄면 관리자의 **도구** 사이드바에서 숨겨집니다.

| 도구 | 설정과 기본값 |
| --- | --- |
| **AI 컨텍스트 패커** | **출력 형식** Markdown, **폴더 경로 포함**, **날짜 포함**, **저장된 태그 포함**, **저장된 요약 포함** 켜짐, **최대 항목 수** 200, **최대 깊이** 8, **발췌 길이** 240 |
| **자동 태그 지정** | **최소 태그 수** 2, **최대 태그 수** 5, **태그 스타일** kebab-case, **병합 모드** 추가, **중복 태그 제거** 켜짐 |
| **콘텐츠 요약** | **요약 길이** 160, **도메인 힌트 포함** 켜짐, **병합 모드** 교체 |
| **AI 폴더 재구성** | **항상 먼저 미리 보기** 켜짐, **최소 신뢰도** 0.55(이보다 낮은 이동은 제외), **배치 크기** 요청당 북마크 100개 |

자동 태그 지정과 콘텐츠 요약은 **기본 범위** 설정과 관계없이 항상 현재 폴더에서 동작합니다.

## 유지보수 [#maintenance]

| 도구 | 설정과 기본값 |
| --- | --- |
| **중복 정리** | **비교 방식** 정규화된 URL, **www 정규화**, **프로토콜 무시**, **끝 슬래시 무시** 켜짐, **유지 규칙** 가장 오래된 항목, **최대 그룹 수** 500. 항상 모든 북마크를 검사합니다 |
| **URL 정리** | **프래그먼트 제거** 꺼짐, **쿼리 매개변수 정렬**과 **쿼리 매개변수 중복 제거** 켜짐, **유지할 매개변수**와 **제거할 매개변수** 목록 |
| **깨진 링크 확인** | **요청 제한 시간** 8000 ms, **동시 요청 수** 4, **재시도 횟수** 1, **리디렉션 따라가기** 켜짐, **성공 상태 코드** 200, 201, 202, 204, 301, 302, 307, 308 |

**제거할 매개변수** 같은 목록에는 쉼표로 구분한 값을 입력합니다. 기본 목록은 [중복과 추적 URL 정리](/guides/clean-up#strip-tracking-parameters)에 있습니다. [깨진 링크 찾기와 복구](/guides/dead-links)도 참고하세요.
