설정 페이지는 확장 프로그램의 **옵션** 항목에서 엽니다. 예를 들어 Chrome에서는 툴바 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **옵션**을 선택합니다. 변경 사항은 바꾸는 즉시 저장됩니다.

## 설정 페이지 사용하기 [#using-the-settings-page]

- 맨 위의 <strong>설정 검색...</strong>은 모든 탭에서 설정을 찾고, 일치하는 설정이 몇 개인지 알려 줍니다.
- 각 탭은 제목이 있는 섹션으로 나뉩니다. 도구의 켜기/끄기 스위치는 제목 옆에 있으며, 꺼져 있는 동안 나머지 설정은 접혀 있습니다. 시간 제한이나 파일 이름 길이 같은 기술적인 설정은 **고급 설정**에 있으며, 직접 열거나 검색으로 찾을 때까지 닫혀 있습니다.
- 바꾼 설정에는 **변경됨** 표시와 함께 기본값으로 되돌리는 버튼이 나타납니다. **전체 초기화**는 모든 설정을 초기화합니다.
- **설정 백업**은 변경한 설정, 사용자 지정 프롬프트, AI 서비스(이름, 제공업체, 모델, **기본 URL**, 제공업체별 항목을 저장하며 API 키와 <strong>추가 헤더(JSON)</strong>는 저장하지 않음), 저장된 검색, 관리자 표의 열과 정렬을 백업 파일로 저장합니다. **설정 복원**은 백업을 복원해 파일에 있는 항목을 각각 대체하며, 설정 값만 담긴 파일이면 현재 설정에 병합합니다. 백업을 복원한 뒤 **설정 필요**로 표시된 서비스는 [AI](#ai)에서 API 키와 추가 헤더를 다시 입력하세요. 둘 다 북마크는 건드리지 않습니다. 그 옆의 **북마크 내보내기**를 누르면 북마크 관리자의 내보내기 도구가 열립니다. [가져오기와 내보내기](/guides/import-export)를 참고하세요.
- 바꾼 설정은 브라우저의 동기화 저장소에 저장되므로, 브라우저 동기화가 켜져 있으면 다른 기기에도 적용됩니다. 단, 빠른 저장에 고른 폴더, **아이콘 저장 용량 제한**, AI 활동 기록, AI에게 묻기의 웹 검색처럼 한 기기에 속하는 몇몇 설정은 그 기기에만 저장됩니다. AI 서비스와 그 API 키, **기본 URL**, <strong>추가 헤더(JSON)</strong>도 이 기기에만 저장됩니다. [개인정보 보호](/privacy)를 참고하세요.

## AI [#ai]

AI는 기본적으로 꺼져 있습니다. 이 설정은 **AI 기능**을 켠 뒤에만 의미가 있습니다. 그전까지는 여기와 **AI 도구** 탭의 AI 설정이 그 사실을 알리는 안내 아래에 흐리게 표시됩니다. 그래도 설정을 바꿀 수는 있습니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **AI 기능** | 꺼짐 | AI 도구와 팝업의 폴더 추천을 켭니다. Firefox에서는 켤 때 API 키, 북마크, 현재 페이지의 제목과 URL을 AI 제공업체와 공유하는 데 동의할지 묻습니다 |
| **AI 서비스** | 없음 | 추가한 제공업체로, 각각 고유한 모델과 키가 있으며 모든 AI 도구는 기본 서비스를 사용합니다 |

그 아래 제공업체 패널에는 **API 키**, **기본 URL**, **사용자 지정 모델**, <strong>추가 헤더(JSON)</strong>와 함께 **서비스 확인**, **모델 새로 고침**이 있습니다. 폴더 제한은 제공업체에 지시 사항으로 전달되며, 결과가 이 제한을 지키는지는 확인하지 않습니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

| **최대 추천 수** | 5 | 요청할 최대 폴더 추천 수 |

### AI에게 묻기가 할 수 있는 일 [#ask-ai-actions]

AI에게 묻기가 조회하고 변경할 수 있는 모든 작업이 여기에 나열되며, 기본적으로 모두 켜져 있습니다. 끈 작업은 AI에 아예 제공되지 않습니다. 여기서 무엇을 고르든 변경 계획을 적용할 때는 항상 먼저 확인합니다.

### 로컬 AI 에이전트 [#agent-bridge]

**로컬 AI 에이전트 허용**(기본값: 꺼짐, 이 기기에만 적용)을 켜면 컴퓨터의 AI 에이전트(Claude Code, Codex, Cursor 등)가 bookmark-scout-mcp 프로그램을 통해 북마크를 조회할 수 있습니다. 이 프로그램은 설치한 뒤 `bookmark-scout-mcp install`로 등록합니다. 켜면 브라우저가 확장 프로그램이 그 프로그램과 통신하도록 허용할지 묻습니다. **변경 허용**(기본값: 꺼짐)을 켜면 페이지를 저장하고 이동, 이름 변경, 삭제, 새 폴더를 제안할 수도 있습니다. 각 변경마다 Bookmark Scout 창이 열려 승인하거나 거절할 수 있으며, 북마크 관리자에서 실행 취소할 수 있습니다. 스위치 아래 패널에 프로그램이 실행 중인지 표시됩니다.

**개인 값 숨기기**(기본값: 켜짐)는 에이전트가 받는 제목과 URL에 포함된 민감한 URL 매개변수, 토큰, 이메일 주소를 개인정보 스캐너의 목록에 따라 바꿉니다. **로컬 에이전트가 할 수 있는 일**에는 모든 조회가 나열되며 기본적으로 모두 켜져 있습니다. 끈 조회는 에이전트에 아예 제공되지 않습니다.

## AI 도구 [#ai-tools]

각 도구에는 **사용** 스위치가 있습니다(기본값은 켜짐). 끄면 관리자의 **도구** 사이드바에서 숨겨집니다.

| 도구 | 설정과 기본값 |
| --- | --- |
| **AI 컨텍스트 패커** | **출력 형식** Markdown, **폴더 경로 포함**, **날짜 포함**, **저장된 태그 포함**, **저장된 요약 포함** 켜짐, **최대 항목 수** 200, **최대 깊이** 8, **발췌 길이** 240 |
| **자동 태그 지정** | **최소 태그 수** 2, **최대 태그 수** 5, **태그 스타일** kebab-case, **병합 모드** 추가, **중복 태그 제거** 켜짐 |
| **콘텐츠 요약** | **요약 길이** 160, **도메인 힌트 포함** 켜짐, **병합 모드** 교체 |
| **AI 폴더 재구성** | **최소 신뢰도** 55%(이보다 낮은 이동은 제외), **배치 크기** 요청당 북마크 100개 |
