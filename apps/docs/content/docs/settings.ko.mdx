---

설정 페이지는 확장 프로그램의 **옵션** 항목에서 엽니다. 예를 들어 Chrome에서는 툴바 아이콘을 마우스 오른쪽 버튼으로 클릭하고 **옵션**을 선택합니다. 변경 사항은 바꾸는 즉시 저장됩니다.

## 설정 페이지 사용하기 [#using-the-settings-page]

- 설정 페이지는 대부분의 사람이 바꾸는 몇 가지 설정을 모은 **기본 설정** 탭에서 열립니다. 다른 탭은 모두 **고급 설정** 아래에 있으며, **기본 설정**의 각 설정은 해당 탭에도 있습니다. 어느 쪽에서 바꾸든 같은 설정이 바뀝니다.
- 맨 위의 <strong>설정 검색...</strong>은 모든 탭에서 설정을 찾고, 일치하는 설정이 몇 개인지 알려 줍니다. 입력한 단어는 모두 일치해야 하며, 순서와 대소문자, 악센트는 구분하지 않습니다. 일치한 단어는 그 자리에서 강조 표시되고, 일치하는 설정이 있는 탭은 개수가 강조 표시됩니다. 설명이나 설정 ID처럼 화면에 보이지 않는 텍스트에서 일치한 설정에는 그 아래에 어디에서 일치했는지 짧은 메모가 표시됩니다.
- 각 탭은 제목이 있는 섹션으로 나뉩니다. 도구의 켜기/끄기 스위치는 제목 옆에 있으며, 꺼져 있는 동안 나머지 설정은 접혀 있습니다. 시간 제한이나 파일 이름 길이 같은 기술적인 설정은 **고급 설정**에 있으며, 직접 열거나 검색으로 찾을 때까지 닫혀 있습니다.
- 바꾼 설정에는 **변경됨** 표시와 함께 기본값으로 되돌리는 버튼이 나타납니다. **전체 초기화**는 모든 설정을 초기화합니다.
- **설정 백업**은 선택한 항목을 백업 파일로 저장합니다. 설정, 이 컴퓨터의 설정, 저장된 검색과 표 보기, 프롬프트와 내 소개, 스마트 규칙, AI 서비스(**기본 URL**과 제공업체별 항목 포함), 표지, 그리고 직접 선택하고 확인했을 때만 AI 서비스 키가 들어가며, 키는 기본적으로 비밀번호로 보호됩니다. **설정 복원**은 백업의 각 항목이 무엇을 바꾸는지 보여 주고, 항목을 골라 **병합** 또는 **교체**할 수 있게 하며, **가져오기 실행 취소**를 위한 안전 사본을 보관합니다. 설정 값만 담긴 파일이면 현재 설정에 병합합니다. 둘 다 북마크는 건드리지 않습니다. 그 옆의 **북마크 내보내기**를 누르면 북마크 관리자의 내보내기 도구가 열립니다. [설정 백업과 복원](/guides/import-export#back-up-and-restore-settings)을 참고하세요.
- 바꾼 설정은 브라우저의 동기화 저장소에 저장되므로, 브라우저 동기화가 켜져 있으면 다른 기기에도 적용됩니다. 단, 화면에 맞추는 설정이나 컴퓨터마다 다른 것을 가리키는 설정은 바꾼 기기에만 저장됩니다. 팝업과 북마크 관리자의 레이아웃, 관리자 및 팝업 단축키, 스마트 규칙, 저장 용량 제한, 탐색 중이나 빠른 저장 시 표지 캡처, 빠른 저장에 고른 폴더, AI 활동 기록, AI에게 묻기의 웹 검색, 로컬 AI 에이전트가 여기에 해당하며, 아래 설명에 각각 그렇게 적혀 있습니다(**이 기기에만 저장됩니다** 등). AI 서비스와 그 API 키, **기본 URL**, <strong>추가 헤더(JSON)</strong>도 이 기기에만 저장됩니다. [개인정보 보호](/privacy)를 참고하세요.
- 체크하고 순서를 바꾸는 목록(팝업의 구성 요소, 버튼, 호버 카드 항목, 카드와 미리보기 항목, 사이드바 도구, 메뉴, 오른쪽 클릭 메뉴 항목)에서는 이후 버전에서 추가된 항목이 숨길 때까지 표시되고, 숨긴 항목은 계속 숨겨집니다.

### 빠른 저장 단축키 [#quick-save]

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **빠른 저장 폴더** | 최적 일치 | <Shortcut id="commands.quick-save" />로 현재 페이지를 저장할 위치: 페이지에 가장 잘 맞는 폴더, 마지막으로 사용한 폴더, 또는 지정한 폴더. AI 단축키는 항상 AI 추천을 사용합니다 |
| **저장할 폴더** | 선택 안 함 | **지정한 폴더**에서 사용할 폴더. 이 폴더가 삭제되면 빠른 저장은 마지막으로 사용한 폴더를 사용합니다. 이 기기에만 저장됩니다 |
| **제안할 다른 폴더** | <SettingDefault path="search.quick_save.alternatives" /> | 빠른 저장 알림이 옮길 곳으로 제안하는 다른 폴더 수 |
| **알림 표시 시간** | <SettingDefault path="search.quick_save.notification_ms" seconds />초 | 빠른 저장 알림이 닫히기 전까지 표시되는 시간. 포인터를 올려 두면 계속 열려 있습니다 |
| **빠른 저장 시 표지 저장** | 끔 | 빠른 저장 후 북마크의 표지도 저장합니다. 페이지 자체 이미지(그 사이트나 허용한 사이트에서만 내려받음) 또는 단축키를 누를 때 찍은 탭 스크린샷을 검토 없이 사용합니다. **표지 가져오기 사용**이 켜져 있을 때만 작동하며, 시크릿 창이나 **캡처하지 않을 사이트**, **읽지 않을 사이트**의 사이트에서는 저장하지 않습니다. 알림에 **표지 제거**가 표시되며, **실행 취소**는 북마크와 함께 표지를 제거합니다. 이 기기에만 저장됩니다. 켜져 있는 동안 다음 두 설정이 표시됩니다 |
| **빠른 저장 표지 출처** | 표지 출처와 같음 | 빠른 저장이 유지할 표지: [표지 출처](#fetch-covers)의 순서 또는 빠른 저장 전용으로 고른 선택지 |
| **북마크에 이미 표지가 있을 때** | 유지 | **유지**는 북마크에 이미 있는 표지를 그대로 두고, **대체**는 새 표지로 바꿉니다. **이 화면을 표지로 사용**으로 저장한 표지는 대체하지 않습니다 |

그 아래 **키보드 단축키**에는 브라우저에서 각 단축키에 지정된 키와 **단축키 변경**이 표시됩니다. Firefox에서는 그 자리에서 새 키를 입력하고 기본값으로 되돌릴 수도 있습니다. Chrome과 Edge에서는 빠른 저장에 <Shortcut id="browser.bookmark_page" />를 지정하는 방법도 안내합니다. [키보드 단축키로 저장](/guides/save-and-organize#quick-save)과 [빠른 저장에 북마크 키 사용](/guides/save-and-organize#ctrl-d)을 참고하세요.

### 마우스 오른쪽 버튼 메뉴 [#context-menu]

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **마우스 오른쪽 버튼 메뉴** | 꺼짐 | 브라우저의 마우스 오른쪽 버튼 메뉴에 <strong>북마크 저장 위치...</strong>를 표시합니다. Chrome과 Edge에서는 켜면 선택적 마우스 오른쪽 버튼 메뉴 권한이 확인 창 없이 추가됩니다 |
| **메뉴를 표시할 곳** | 링크 | 마우스 오른쪽 버튼을 눌렀을 때 메뉴가 나타나는 곳: **링크**(링크 저장), **페이지**(보고 있는 페이지 저장), **선택한 텍스트**(페이지를 저장하며, **링크 텍스트** 이름 지정에서는 선택한 텍스트를 이름으로 씀). 어느 것도 다른 권한이 필요하지 않습니다 |
| **북마크 이름 출처** | 링크 텍스트 | 마우스 오른쪽 버튼으로 저장한 북마크의 이름을 링크 텍스트, 페이지 제목, 링크 URL 중 하나로 정합니다 |
| **메뉴의 최근 폴더 수** | <SettingDefault path="search.context_menu.recent_max" /> | 메뉴에 표시할 최근 폴더 수입니다. 팝업의 **최근 폴더 최대 수**와는 따로 정합니다 |

**메뉴 항목**에서는 메뉴에 표시할 항목과 순서를 고릅니다: **최근 폴더**(하위 메뉴)와 **북마크바**. 항목을 체크하면 표시되고, 손잡이를 끌거나 손잡이 메뉴를 사용해 옮길 수 있습니다. **기본값 복원**을 누르면 두 항목이 처음 순서대로 다시 표시됩니다.

## 외관 [#appearance]

### 언어, 테마, 아이콘 [#language-theme-and-icons]

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **언어** | 브라우저 설정 | <Languages of="extension" join="or" /> 중에서 고르거나 브라우저 설정을 따릅니다 |
| **테마** | 시스템 | 시스템, 라이트, 다크 중 하나이며, 열려 있는 모든 Bookmark Scout 페이지에 적용됩니다 |
| **파비콘 표시** | 켜짐 | 팝업과 사이드 패널에서 북마크 옆에 사이트 아이콘을 표시합니다 |
| **브라우저 아이콘 캐시 사용** | 꺼짐 | Chrome과 Edge: **사이트 아이콘 새로 고침**으로 저장한 아이콘이 없는 사이트에 브라우저가 이미 캐시한 아이콘도 표시합니다. 여기서 켜거나 **사이트 아이콘 새로 고침** 카드의 **브라우저 아이콘 표시**로 켜면 사이트 아이콘을 읽을 권한을 요청합니다. 확장 프로그램용 아이콘 캐시가 없는 Firefox에서는 표시되지 않습니다 |
| **파비콘 크기** | 16px (작게) | 16, 24, 32픽셀 |

### 날짜와 시간 [#dates]

| --- | --- | --- |
| **날짜 형식** | 내 언어에 맞춤 | 관리자의 날짜 열, 기록, 세부 정보 등 모든 곳의 날짜 표시 방식. **짧게**, **길게**, **연-월-일**(2026-03-14) 중에서 고르며, 각 항목에 예시가 표시됩니다 |

| **글자 수 제한** | <SettingDefault path="appearance.popup.truncate_length" />자 | 팝업의 AI 추천 머리글에 표시되는 페이지 제목을 줄입니다 |
| **트리 밀도** | 보통 | 팝업과 사이드 패널 트리의 행을 **보통** 또는 **촘촘하게** 표시합니다. 이 기기에만 저장됩니다 |
| **포인터를 올리면 세부 정보 표시** | 켜짐 | 팝업이나 사이드 패널에서 북마크에 포인터를 올려 두거나 화살표 키로 이동하면 전체 제목과 주소, 폴더, 태그, 요약, 저장된 커버, 추가한 날짜를 카드로 보여 줍니다. `Esc`로 카드를 닫습니다. 끄면 행의 제목과 주소가 일반 도움말로 표시됩니다 |

표 아래의 세 목록으로 팝업과 사이드 패널을 구성합니다. 항목을 체크하면 표시되고, 핸들을 끌면 옮겨집니다. 핸들은 버튼이기도 해서 메뉴로 항목을 맨 위, 위, 아래, 맨 아래로 옮길 수 있습니다. **기본값 복원**은 각 목록을 원래 순서로 되돌립니다. 이 목록들은 이 기기에만 저장됩니다.

- **팝업 구성**: 검색창 아래에 위에서부터 표시할 항목입니다. 현재 페이지, 백그라운드 작업, 마지막 빠른 저장, 최근 폴더, AI 폴더 제안, 일치하는 폴더, 북마크, 알림, 키 안내. 북마크는 항상 표시되며, 다른 항목을 그 위나 아래로 옮길 수 있습니다.
- **도구 모음 버튼**: 검색창 옆의 버튼입니다. **모두 펼치기**(검색하는 동안), 북마크 관리자, 테마, AI 버튼(AI를 설정한 뒤).
- **세부 정보 카드 내용**: 카드에 순서대로 표시할 내용입니다. 제목, 주소, 표지, 태그, 요약, 폴더, 추가한 날짜. 제목, 주소, 표지가 맨 앞에 있으면 카드 맨 위 줄에 함께 표시됩니다.

### 북마크 관리자 메뉴 [#manager-menus]

관리자의 각 메뉴를 각각의 탭에서 정리합니다. **항목 메뉴**(행이나 트리의 폴더를 오른쪽 클릭, 또는 행의 ⋯ 버튼), **정리 메뉴**(헤더의 ⋮), **빈 공간 메뉴**(행 아래를 오른쪽 클릭), **미리 보기 버튼**(북마크 미리 보기 아래, 첫 번째가 기본 버튼)입니다. 명령의 체크를 해제하면 숨겨져 **숨김** 으로 옮겨지고, 다시 체크하면 끝에 추가됩니다. 명령을 핸들로 끌면 순서가 바뀌고, **구역 구분선** 을 끌면 명령을 다른 구역으로 옮길 수 있습니다. 핸들은 버튼이기도 해서 그 메뉴로 맨 위, 위, 아래, 맨 아래로 옮길 수 있으므로 키보드로도 조작할 수 있습니다. **구역 구분선 추가** 는 끝에 구분선을 추가하므로 위로 옮겨 사용하고, 구분선의 ✕ 로 삭제하면 두 구역이 합쳐집니다. **기본값 복원** 은 그 메뉴만 되돌립니다. 모든 메뉴에는 명령이 적어도 하나 남고, 항목 메뉴에는 **세부정보 보기** 또는 **북마크 ID 복사** 가 남으므로 어떤 북마크나 폴더에도 쓸 수 있는 명령이 있습니다. 남긴 명령이 하나도 해당되지 않으면 메뉴에 **사용할 수 있는 작업이 없습니다** 가 표시됩니다. 모든 메뉴는 다른 설정과 함께 동기화됩니다.

### 팝업의 북마크 작업과 폴더 작업 [#popup-menus]

팝업과 사이드 패널에서 북마크와 폴더가 제공할 명령을 고르고, 관리자 메뉴처럼 핸들을 끌어 그룹 안에서 순서를 바꿉니다. 행의 첫 명령들은 행을 가리키거나 키보드로 이동했을 때 나타나는 버튼입니다. 북마크에는 **삭제**, 폴더에는 **모든 하위 폴더 펼치기**, **현재 페이지 추가**, **폴더 추가**, **삭제**가 있습니다. **새 탭에서 열기**, **새 창에서 열기** 같은 나머지는 행의 ⋯ 메뉴에 있고, 행을 오른쪽 클릭하면(또는 메뉴 키) 모두 표시됩니다. 버튼을 숨기면 다음 명령이 버튼이 됩니다. **기본값 복원**은 전체 메뉴를 되돌립니다. 북마크에는 **새 탭에서 열기** 또는 **삭제**가, 폴더에는 **폴더 추가** 또는 **모두 열기**가 항상 남습니다. 북마크 관리자 메뉴처럼 다른 설정과 함께 동기화됩니다.

### 관리자 및 팝업 단축키 [#page-shortcuts]

북마크 관리자, 팝업, 사이드 패널 안에서 쓰는 키를 바꿉니다. 처음 키는 [키보드 단축키](/guides/keyboard-shortcuts)에 나와 있습니다. 단축키 옆의 **변경**을 클릭하고 새 키를 누르세요. `Esc`를 누르면 취소됩니다. 같은 페이지의 다른 단축키가 이미 쓰는 키는 그 단축키의 이름과 함께 거부되며, 브라우저가 직접 쓰는 키와 목록 안에서 이동하는 키(화살표, `Home`, `End`, 스페이스 단독 또는 `Shift`, `Ctrl`, `Cmd` 조합, 그리고 `Enter`)도 그 단축키 자신의 키가 아니면 거부됩니다. 팝업과 사이드 패널의 단축키는 `Ctrl`이나 `Cmd`를 쓰지 않습니다. 바꾼 단축키 옆의 재설정 버튼을 누르면 기본 키로 돌아가고, **모든 단축키 재설정**은 모든 단축키를 되돌립니다. 복사, 잘라내기, 붙여넣기는 브라우저의 키를 그대로 쓰며, [빠른 저장 단축키](#quick-save)는 브라우저가 관리합니다. 이 기기에만 저장됩니다.

## AI [#ai]

AI는 기본적으로 꺼져 있습니다. 이 설정은 **AI 기능**을 켠 뒤에만 의미가 있습니다. 그전까지는 여기와 **AI 도구** 탭의 AI 설정이 그 사실을 알리는 안내 아래에 흐리게 표시됩니다. 그래도 설정을 바꿀 수는 있습니다. 기본 서비스를 설정하기 전까지는 맨 위의 **AI는 선택 사항입니다** 상자에서 AI로 할 수 있는 일, 필요한 것, 들 수 있는 비용, 전송되는 내용을 알려 주며, [AI 도구 설정](/guides/ai-tools) 링크도 있습니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **AI 기능** | 꺼짐 | AI 도구와 팝업의 폴더 추천을 켭니다. Firefox에서는 켤 때 API 키, 북마크, 현재 페이지의 제목과 URL을 AI 제공업체와 공유하는 데 동의할지 묻습니다 |
| **AI 서비스** | 없음 | 추가한 제공업체로, 각각 고유한 모델과 키가 있으며 AI 도구는 기본 서비스를 사용합니다. **내장 AI**는 폴더 추천만 하므로, 내장 AI가 기본인 동안 다른 도구는 켜져 있는 다른 서비스 중 첫 번째를 사용합니다 |

그 아래 제공업체 패널에는 **API 키**, **기본 URL**, **사용자 지정 모델**, <strong>추가 헤더(JSON)</strong>와 함께 **서비스 확인**, **모델 새로 고침**이 있습니다. 폴더 제한은 제공업체에 지시 사항으로 전달되며, 결과가 이 제한을 지키는지는 확인하지 않습니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

**API 키** 아래의 **API 키 필요**는 처음에 제공업체에 맞춰 설정됩니다. 끄면 키를 직접 붙여 주는 프록시나 게이트웨이 뒤에 있는 서비스처럼 키 없이 서비스를 사용할 수 있습니다.

[스마트 규칙으로 태그 추가와 이동](/guides/clean-up#tag-and-move-with-smart-rules)을 참고하세요. **새 북마크에 태그 추가** 끔: 켜면 사용 중인 규칙이 **적용할 새 북마크**에서 허용한 각 새 북마크에 태그를 붙입니다. 옮기지는 않습니다. **새 북마크 이동** 끔: 켜면 **새 북마크 자동으로 이동**을 선택한 규칙이 Bookmark Scout 밖에서 추가된 새 북마크를 그 폴더로 옮깁니다. **적용할 새 북마크** Bookmark Scout로 저장한 북마크: 둘 다 적용되는 새 북마크입니다. **모든 곳**은 브라우저의 별표, 동기화, 다른 확장 프로그램에서 온 북마크도 포함합니다. 세 가지 모두 이 기기에만 적용됩니다. 각 규칙에는 마지막으로 검토한 실행(언제 실행했는지와 태그를 추가한, 옮긴, 제외한 북마크 수)이 표시되고, 편집기의 **주소나 제목으로 테스트**는 예시가 검색과 일치하는지 알려 줍니다. 규칙 아래의 **마지막 실행의 충돌**에는 두 규칙이 서로 다른 폴더로 옮기려 한 북마크가 각각 **검토**와 함께 표시되고, **규칙으로 변경됨**에는 새 북마크에 태그 추가, 새 북마크 이동, 검토한 실행이 최근에 바꾼 내용이 각각 실행 취소와 함께 표시됩니다. |
| **깨진 링크 확인** | **요청 제한 시간** <SettingDefault path="maintenance.dead_links.request_timeout_ms" seconds />초, **동시 요청 수** <SettingDefault path="maintenance.dead_links.concurrency" />, **재시도 횟수** <SettingDefault path="maintenance.dead_links.retry_count" />, **리디렉션 따라가기** 켜짐, **성공 상태 코드** <SettingDefault path="maintenance.dead_links.success_statuses" />; **깨진 링크 확인됨 기본값**, **직접 확인할 링크 기본값**, **리디렉션된 링크 기본값** 그대로 유지 |
| **백그라운드 작업** | **백그라운드 적용 기준** <SettingDefault path="maintenance.background_tasks.apply_in_background_above" />: 이보다 많은 북마크에 대한 검토한 변경은 백그라운드에서 나누어 적용되며, 페이지를 닫아도 계속됩니다. 각 부분은 [기록](/guides/save-and-organize)의 변경 하나이며, 거기서 실행 취소합니다. 스마트 규칙 실행은 바꾸는 북마크 수로 판단하며, 그 태그는 **규칙으로 변경됨**에서 실행 취소합니다 |

도구는 **모든 북마크**에서 시작합니다. 관리자가 열릴 때의 폴더에서 검사하더라도 다른 폴더를 빠뜨리지 않기 위해서입니다. 열린 폴더에서 시작하려면 도구의 **기본 범위**를 바꾸세요. **AI 폴더 재구성**은 열린 폴더에서 시작합니다. 모든 북마크에 대한 계획을 만들면 북마크 전체가 AI 제공업체로 전송되기 때문입니다. 열린 폴더가 없는 관리자의 최상위에서는 모든 도구가 **모든 북마크**에서 시작합니다.

**제거할 매개변수** 같은 목록은 이름을 입력하고 Enter를 누르거나 추천 항목을 골라 편집합니다. **성공 상태 코드**는 자주 쓰는 코드의 체크리스트이며, 다른 코드도 추가할 수 있습니다. 설정이 브라우저 동기화 용량에 맞도록 각 목록은 20개까지, 매개변수 이름은 32자(영문자, 숫자, URL 기호)까지입니다. 기본 목록은 [북마크 정돈과 보강](/guides/clean-up#strip-tracking-parameters)에 있습니다. [깨진 링크 찾기와 복구](/guides/dead-links)도 참고하세요.

### 페이지 본문 색인 [#index-page-text]

그 아래 **페이지 본문 색인**에는 색인된 페이지 수, 오래된 수와 지난 실행에서 실패한 수, 마지막으로 본문을 색인한 시각이 표시됩니다. **실패한 항목 다시 시도**와 **오래된 항목 새로 고침**은 그 페이지만 다시 읽고, **페이지 본문 삭제**는 북마크, 태그, 기록은 건드리지 않고 모두 지웁니다.

### 표지 가져오기 [#fetch-covers]

| 설정 | 기본값 | 하는 일 |
| --- | --- | --- |
| **표지 가져오기 사용** | 끔 | 도구 사이드바에 **표지 가져오기**를 표시합니다 |
| **기본 범위** | 현재 폴더 | 도구가 처음 읽는 북마크 |
| **표지 출처** | 페이지 이미지 우선, 없으면 스크린샷 | 페이지 자체 이미지와 탭 스크린샷이 모두 가능할 때 북마크가 어떤 표지를 유지할지 정합니다. **페이지 이미지 우선, 없으면 스크린샷**: 표지 가져오기가 스크린샷을 대체하고, 탐색 중에 찍는 스크린샷은 페이지 이미지가 없는 북마크에만 쓰입니다. **스크린샷 우선**: 탐색 중에 찍은 스크린샷이 페이지 이미지를 대체합니다. **페이지 이미지만**: 탐색 중에 스크린샷을 찍지 않습니다. **이 화면을 표지로 사용**은 저장한 이미지를 항상 유지합니다. '이 화면을 표지로 사용'으로 저장한 표지는 표지 가져오기나 탐색 중 스크린샷으로 자동 대체되지 않으며, 직접 다른 이미지를 저장할 때만 바뀝니다. **스크린샷만**: 스크린샷만 사용합니다. 표지 가져오기는 페이지를 읽지 않으며 검토 화면에서 이를 알립니다. |
| **탐색 중 표지 캡처** | 끔 | 표지가 없거나 오래된 스크린샷이 표지인 북마크한 페이지가 보고 있는 탭에서 로드를 마치면, 페이지가 안정된 뒤 탭의 스크린샷을 표지로 찍습니다. 시크릿 창에서는 그 설정도 켜지 않는 한 찍지 않으며, 확장 프로그램이나 브라우저 자체 페이지, 로컬 파일은 찍지 않습니다. 켜면 모든 페이지에 대한 접근 권한을 요청합니다. 이 기기에만 보관. 켜져 있는 동안 다음 네 가지 설정이 표시됩니다 |
| **비공개 창에서도 캡처** | 끔 | 시크릿 창에서도 스크린샷을 찍습니다. 단, 브라우저가 Bookmark Scout의 실행을 그곳에서 허용한 경우에만 찍습니다. 브라우저의 확장 프로그램 설정에 있는 확장 프로그램 페이지에서 Chrome과 Edge는 시크릿 모드 실행을, Firefox는 비공개 창 실행을 허용하세요. 브라우저가 허용하지 않는 동안에는 설정에 그렇게 표시됩니다. 이 기기에만 보관 |
| **캡처 전 대기 시간** | <SettingDefault path="metadata_content.covers.browse_settle_ms" seconds />초 | 북마크한 페이지가 로드된 뒤 스크린샷을 찍기 전까지 앞에 표시된 채로 있어야 하는 시간 |
| **캡처 간격** | <SettingDefault path="metadata_content.covers.browse_min_interval_ms" seconds />초 | 두 스크린샷 사이의 최소 시간. 브라우저가 허용하는 값보다 짧게 할 수 없습니다(Chrome은 1초에 최대 두 장까지 찍습니다) |
| **다음보다 오래된 스크린샷 다시 찍기** | <SettingDefault path="metadata_content.covers.browse_max_age_days" />일 | 탐색 중에 찍은 스크린샷이 이보다 오래되면 다음 방문 때 다시 찍습니다. 0이면 다시 찍지 않습니다. **이 화면을 표지로 사용**으로 고른 표지는 다시 찍지 않습니다 |
| **캡처하지 않을 사이트** | 없음 | 탐색 중에 찍지 않는 사이트(각각 하위 도메인 포함). `example.com` 같은 사이트를 입력하거나 주소를 붙여 넣습니다. '읽지 않을 사이트'에 있는 사이트도 캡처하지 않습니다. |
| **표지 너비** | <SettingDefault path="metadata_content.covers.width_px" /> px | 각 표지로 보관하는 복사본의 너비이며, 더 큰 이미지는 이 너비로 줄어듭니다 |
| **표지 이미지 품질** | <SettingDefault path="metadata_content.covers.quality" percent /> | 어떤 방법으로 저장하든 각 표지로 보관하는 사본의 품질입니다. 낮을수록 파일이 작아집니다. 바꾼 뒤 저장하는 표지에 적용됩니다 |
| **최대 이미지 크기** | <SettingDefault path="metadata_content.covers.max_image_kb" /> KB | 이보다 큰 이미지 파일은 내려받지 않습니다 |
| **표지 저장 공간** | <SettingDefault path="metadata_content.covers.max_cache_mb" /> MB | 표지가 이 기기에서 차지할 수 있는 공간이며, 오래된 것부터 지웁니다. 이 기기에만 저장. **이 화면을 표지로 사용**으로 고른 표지는 마지막에 지움 |

그 아래 **북마크 표지**에는 보관된 표지 수와 크기가 표시되며, **표지 삭제**는 북마크, 태그, 기록은 건드리지 않고 모두 지웁니다.

| **새 백업을 비밀번호로 보호** | 꺼짐 | **이 백업을 비밀번호로 보호**가 처음부터 선택되어 있는지 여부 |
| **API 키를 비밀번호로 보호** | 켜짐 | AI 서비스 키가 든 백업에서 키가 처음부터 비밀번호로 보호되는지 여부. 대화 상자에서 끄면 확인을 요청합니다 |

## 개발자용 [#developers]

### 로컬 AI 에이전트 [#agent-bridge]

**로컬 AI 에이전트 허용**(기본값: 꺼짐, 이 기기에만 적용)을 켜면 컴퓨터의 AI 에이전트(Claude Code, Codex, Cursor 등)가 bookmark-scout-mcp 프로그램을 통해 북마크를 조회할 수 있습니다. 이 프로그램은 설치한 뒤 `bookmark-scout-mcp install`로 등록합니다. **AI 기능**을 켜지 않아도 됩니다. 이 스위치를 켜면 브라우저가 확장 프로그램이 그 프로그램과 통신하도록 허용할지 묻습니다. **변경 허용**(기본값: 꺼짐)을 켜면 페이지를 저장하고 이동, 이름 변경, 삭제, 새 폴더를 제안할 수도 있습니다. 각 변경마다 Bookmark Scout 창이 열려 승인하거나 거절할 수 있으며, 북마크 관리자에서 실행 취소할 수 있습니다. 스위치 아래 패널에 프로그램이 실행 중인지 표시됩니다.

**개인 값 숨기기**(기본값: 켜짐)는 에이전트가 받는 제목과 URL에 포함된 민감한 URL 매개변수, 토큰, 이메일 주소를 개인정보 스캐너의 목록에 따라 바꿉니다. **로컬 에이전트가 할 수 있는 일**에는 모든 조회가 나열되며 기본적으로 모두 켜져 있습니다. 끈 조회는 에이전트에 아예 제공되지 않습니다.
