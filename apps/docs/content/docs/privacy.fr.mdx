## En bref [#in-short]

- **Ni compte, ni serveur.** Bookmark Scout fonctionne au sein de votre navigateur. Le développeur ne reçoit rien de l'extension.
- **Aucune télémétrie.** L'extension ne comporte ni mesure d'audience, ni rapports de plantage, ni publicité.
- **L'IA reste désactivée tant que vous ne l'activez pas**, et les requêtes vont alors directement de votre navigateur au fournisseur que vous avez choisi. Dans Firefox, l'activation demande aussi votre consentement au partage de ces données. Avec l'IA intégrée de Chrome, les suggestions de dossiers restent sur votre ordinateur.
- **Agents d'IA locaux seulement si vous les autorisez.** Avec **Autoriser les agents d'IA locaux** activé (désactivé par défaut), les agents d'IA de votre ordinateur, comme Claude Code, peuvent consulter vos favoris via le programme bookmark-scout-mcp ; ils ne les modifient qu'avec **Autoriser les modifications** activé, chaque modification après votre accord.
- **Des autorisations uniquement lorsque vous en avez besoin.** À l'installation, l'extension ne demande que ce dont elle ne peut pas se passer ; l'accès aux onglets, le menu contextuel, le cache d'icônes du navigateur et l'accès aux sites Web sont demandés la première fois que vous utilisez la fonctionnalité concernée. Consultez [Autorisations](/permissions).

## Ce que lit l'extension [#what-the-extension-reads]

- Vos favoris, pour les afficher, les rechercher, les modifier, les déplacer, les supprimer, les importer et les exporter.
- Le titre et l'URL de l'onglet actif, lorsque vous enregistrez la page que vous consultez (depuis la fenêtre pop-up, le panneau latéral ou un raccourci d'enregistrement rapide) ou demandez une suggestion de dossier.
- Les icônes de site du cache d'icônes du navigateur, dans Chrome et Edge, une fois l'option **Utiliser le cache d'icônes du navigateur** activée.
- Les icônes de site que vous téléchargez avec **Actualiser les icônes de site**, depuis chaque site enregistré en favori.
- Le texte des pages en favori, quand vous lancez **Indexer le texte des pages**, pour chaque page de l'exécution.
- L'en-tête des pages en favori et l'image d'aperçu que chacune indique, quand vous lancez **Récupérer les couvertures**, pour chaque page de l'exécution. Ou une capture de l'onglet que vous regardez, quand vous cliquez sur **Utiliser cette vue comme couverture** dans la fenêtre pop-up.

Elle ne lit pas le contenu des pages que vous consultez. Après un raccourci d'enregistrement rapide, elle affiche sa propre notification dans cet onglet, qui ne lit rien de la page.

Il ne contient jamais de clé API ni d'en-têtes supplémentaires, et il n'est pas chiffré. Consultez [Paramètres](/settings).

## Quand les données quittent votre navigateur [#when-data-leaves-your-browser]

Uniquement lorsque vous utilisez l'une de ces fonctionnalités, et uniquement vers la destination indiquée :

| Fonctionnalité | Destination | Données envoyées |
| --- | --- | --- |
| Recommandations de dossiers par IA, y compris le raccourci d'enregistrement rapide avec l'IA | Le fournisseur d'IA que vous avez configuré | Le titre et l'URL de la page actuelle, ainsi que les noms de vos dossiers. Si **Lire le contenu des pages** est activé, également le texte principal de la page |
| Étiquetage automatique, Générateur de résumés, Réorganisation des dossiers par IA | Le fournisseur d'IA que vous avez configuré | Les titres, les URL et les chemins de dossier des favoris compris dans la portée. Si **Lire le contenu des pages** est activé, l'étiquetage automatique et le générateur de résumés envoient aussi le texte principal de chaque page ; la réorganisation des dossiers par IA ne le fait jamais. L'étiquetage automatique envoie aussi les noms de vos étiquettes les plus utilisées, sauf si **Envoyer les étiquettes existantes** est désactivé |
| Demander à l'IA | Le fournisseur d'IA que vous avez configuré | Vos messages et la conversation jusqu'à présent, ainsi que ce que l'IA consulte pour répondre : les favoris correspondants (avec leur dossier, leur date d'ajout, leurs étiquettes et leur résumé), les noms des dossiers, le titre et l'URL de la page actuelle, si les liens enregistrés qu'elle vérifie fonctionnent encore et, si **Lire le contenu des pages** est activé, le texte des pages qu'elle lit. Si sa recherche sur le Web est activée, le fournisseur effectue aussi des recherches sur le Web. La conversation n'est pas enregistrée |
| Vérifier les liens morts, Récupération des métadonnées, vérification des liens par Demander à l'IA | Chaque site enregistré en favori | Une requête pour la page, sans cookies, après que vous avez autorisé l'accès aux sites Web |
| Actualiser les icônes de site | Chaque site enregistré en favori | Une requête pour une page enregistrée en favori par site et pour un fichier d'icône sur le domaine de ce site, sans cookies, après que vous avez autorisé l'accès aux sites Web. Aucun service d'icônes tiers n'est utilisé |
| Indexer le texte des pages | Chaque page en favori de l'exécution | Une requête pour la page, sans cookies, après que vous avez autorisé l'accès au site. Son texte lisible reste sur cet appareil |
| Récupérer les couvertures | Chaque page en favori de l'exécution et l'image qu'elle indique | Une requête pour l'en-tête de la page et pour son image, sans cookies ni l'adresse de la page, uniquement sur les sites que vous avez autorisés. Une petite copie reste sur cet appareil |
| Agents d'IA locaux, seulement avec **Autoriser les agents d'IA locaux** activé (désactivé par défaut) | Le programme bookmark-scout-mcp de votre ordinateur et les agents d'IA que vous y exécutez | Ce qu'un agent demande : les favoris correspondants (avec leurs dossiers, dates d'ajout, étiquettes et résumés), les noms de dossiers, le titre et l'URL de la page actuelle, si les liens enregistrés fonctionnent encore (après que vous avez autorisé l'accès aux sites Web) et, avec **Lire le contenu des pages** activé, le texte d'une page. Les valeurs privées des titres et URL sont masquées sauf si vous désactivez cette option. Les agents peuvent envoyer ce qu'ils lisent à leur propre fournisseur d'IA. Chaque consultation figure dans l'activité IA tant que **Enregistrer les requêtes** est activé |

Chaque fonction d'IA qui utilise un fournisseur envoie aussi votre texte **À propos de moi** (paramètres d'IA) tant qu'il n'est pas vide ; il est vide par défaut.

Un fournisseur qui s'exécute sur votre propre ordinateur, comme Ollama, garde les requêtes d'IA sur votre machine. L'IA intégrée de Chrome aussi : elle calcule les suggestions de dossiers avec le propre modèle de Chrome sur votre ordinateur, sans clé API, et Chrome télécharge ce modèle depuis Google une seule fois, quand vous le demandez, sans aucune de vos données. Les exportations de favoris, les fichiers du **Préparateur de contexte IA** et la sauvegarde des paramètres sont enregistrés sous forme de fichiers sur votre ordinateur et ne sont mis en ligne nulle part. Une exportation de favoris au format JSON contient aussi les étiquettes et le résumé de chaque favori ; pour les exportations de favoris et de contexte IA, une vérification de confidentialité peut d'abord masquer les valeurs sensibles. Les données exactes envoyées par chaque outil d'IA sont détaillées dans [Configurer les outils d'IA](/guides/ai-tools#what-each-tool-sends), et chaque autorisation est expliquée dans [Autorisations](/permissions).
