## 執行位置 [#where-it-runs]

| 介面 | 說明 |
| --- | --- |
| 彈出式視窗 | 工具列按鈕：搜尋、資料夾樹狀結構、儲存書籤和 AI 資料夾推薦 |
| 側邊面板 | Chrome 或 Edge 側邊面板中的相同檢視畫面，瀏覽網頁時會保持開啟 |
| 書籤管理員 | 在 Chrome 和 Edge 中取代瀏覽器的書籤頁面：資料夾樹狀結構、路徑導覽、書籤表格和「**工具**」側欄 |
| 設定 | 擴充功能的選項頁面，共有十一個分頁。請參閱「[設定](/settings)」 |
| 右鍵選單 | 開啟「**右鍵選單**」後，可在任何連結上使用「**將書籤儲存至...**」 |

## 尋找 [#find]

- 邊輸入邊搜尋標題和網址，提供大小寫須相符、全字拼寫須相符和規則運算式選項，並醒目顯示相符內容。相符的資料夾會自動展開。
- 這部裝置上的最近搜尋記錄，可以清除或關閉。
- 書籤管理員中的表格篩選器，可依標題、網址、類型、資料夾、網域和新增日期篩選，並可依任一欄排序。
- 已儲存的搜尋：已命名的篩選條件組合，每次開啟時都會依目前的書籤重新評估。最多 50 個，保存在這部裝置上。

指南：「[搜尋和已儲存的搜尋](/guides/search)」。

## 儲存和整理 [#save-and-organize]

- 將目前網頁儲存至任何資料夾，同一個資料夾中不會重複儲存，並提供列出用過資料夾的「**最近使用**」面板。
- 從右鍵選單將連結儲存至最近使用的資料夾或書籤列。
- 在書籤管理員中建立資料夾、拖放書籤和資料夾，以及一次移動多個項目。
- 依新增日期、自然字母順序或資料夾優先排序，不會變更瀏覽器儲存的順序。
- 在「**書籤詳細資料**」中編輯名稱和網址，以及加上標籤和摘要。
- 刪除時可選擇是否要確認，並可在 10 秒內復原，資料夾中的所有內容都會一併還原。
- 在書籤管理員中，以拖曳或方向鍵調整表格欄寬；「**重設檢視**」可還原版面配置。

指南：「[儲存和整理](/guides/save-and-organize)」。

## 清理 [#clean-up]

- **重複書籤清理工具**：以可設定的比對方式找出重複書籤，經確認後移除多餘的副本，並可復原。
- **網址清理工具**：預覽後清除 `utm_source` 等追蹤參數。
- **檢查失效連結**：將確定失效的連結與需要手動檢查的連結分開，並可透過刪除、追蹤重新導向、使用 Wayback Machine 連結或編輯網址來修復，且可復原。
- **中繼資料擷取工具**：只讀取網頁的 head 部分，依據線上網頁建議標題，並套用你選取的標題。說明只會顯示供確認，絕不會儲存。
- **重新整理網站圖示**：經確認後下載各網站本身的圖示，即使瀏覽器沒有快取圖示，或是在 Firefox 中，書籤也能顯示圖示。圖示會保存在這部裝置上，並可清除。
- **隱私掃描工具**：標示網址 (也可選擇包含標題) 中含有權杖、敏感參數、電子郵件地址或 UUID 的項目。
- **書籤統計**：針對單一資料夾或所有書籤，列出最常見的網域和資料夾、通訊協定、重複項目，以及資料夾的層級深度。

指南：「[清理重複書籤和追蹤網址](/guides/clean-up)」和「[找出並修復失效連結](/guides/dead-links)」。

## 匯入和匯出 [#import-and-export]

- 匯出為 HTML、JSON、Markdown 或 CSV，並可在隱私確認時從檔案中遮蔽敏感值。
- 預覽目標資料夾、數量和重複項目後匯入 HTML 或 JSON，並可復原。
- 以 JSON 檔案匯出和匯入擴充功能的設定。

指南：「[匯入和匯出](/guides/import-export)」。

## AI 工具 (選用) [#ai-tools-optional]

預設為關閉。可以使用自己的 OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter 金鑰，或 models.dev 目錄中其他約 200 個供應商的金鑰，也可以使用 Ollama、CLIProxyAPI 或任何與 OpenAI 相容的端點。

- 彈出式視窗中的資料夾推薦，包括經確認的新資料夾路徑。
- 針對目前資料夾使用的「**自動加上標籤**」和「**內容摘要工具**」，結果要經你確認後才會儲存。
- 「**AI 資料夾重組**」，在移動任何項目前先預覽。
- 「**AI 脈絡打包工具**」，可將書籤匯出為 Markdown 或 XML 供 AI 對話使用，即使關閉 AI 也能使用。

標籤和摘要會保存在這部裝置上，不會同步、無法搜尋，也不會包含在書籤匯出檔案中。指南：「[設定 AI 工具](/guides/ai-tools)」。

## 鍵盤和語言 [#keyboard-and-language]

- 彈出式視窗、側邊面板和書籤管理員中的快速鍵一律不使用 `Ctrl` 或 `Cmd`，書籤管理員中還有按 `?` 開啟的說明對話方塊。請參閱「[鍵盤快速鍵](/guides/keyboard-shortcuts)」。
- 系統、淺色或深色主題。
- 英文、簡體中文、繁體中文、日文、韓文、西班牙文、德文、法文和巴西葡萄牙文。
