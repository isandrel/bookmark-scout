## 執行位置 [#where-it-runs]

| 介面 | 說明 |
| --- | --- |
| 彈出式視窗 | 工具列按鈕：搜尋、資料夾樹狀結構、儲存書籤和 AI 資料夾推薦 |
| 側邊面板 | 瀏覽器側邊面板 (Firefox 中為側邊欄) 中的相同檢視畫面，瀏覽網頁時會保持開啟 |
| 書籤管理員 | 在 Chrome 和 Edge 中取代瀏覽器的書籤頁面：資料夾樹狀結構、路徑導覽、書籤表格和「**工具**」側欄。在較窄的視窗中，資料夾樹狀結構和「**工具**」會疊在表格上方開啟；較深的資料夾路徑會將中間的資料夾收合到「**…**」選單中 |
| 設定 | 擴充功能的設定頁面：最先顯示「**常用設定**」，另外十一個分頁位於「**進階設定**」下。請參閱「[設定](/settings)」 |
| 任何網頁 | <Shortcut id="commands.quick-save" /> 和 <Shortcut id="commands.ai-quick-save" /> 可快速儲存目前所在的網頁，並在網頁中顯示通知 |
| 右鍵選單 | 開啟「**右鍵選單**」後，可在任何連結上使用「**將書籤儲存至...**」 |

## 尋找 [#find]

- 邊輸入邊搜尋標題和網址，在「**更多搜尋選項**」下提供大小寫須相符、全字拼寫須相符和模式搜尋 (規則運算式) 選項，並醒目顯示相符內容。相符的資料夾會自動展開。
- 這部裝置上的最近搜尋記錄，可以清除或關閉。
- 書籤管理員中的表格篩選器，可依標題、網址、類型、資料夾、網域和新增日期篩選，並可依任一欄排序。
- 已儲存的搜尋：已命名的篩選條件組合，每次開啟時都會依目前的書籤重新評估。最多 50 個，保存在這部裝置上。

指南：「[搜尋和已儲存的搜尋](/guides/search)」。

## 儲存和整理 [#save-and-organize]

- 將目前網頁儲存至任何資料夾，同一個資料夾中不會重複儲存，並提供列出用過資料夾的「**最近使用**」面板。
- 輸入資料夾名稱的一部分，或 `work/react` 之類的路徑，然後儲存到結果上方列出的其中一個相符資料夾。
- 在任何網頁上按 <Shortcut id="commands.quick-save" /> 快速儲存，儲存到與網頁最相符的資料夾 (在你的裝置上排序)、上次使用的資料夾，或你選擇的資料夾；<Shortcut id="commands.ai-quick-save" /> 則會儲存到 AI 的第一個建議。網頁中的通知會提供「**復原**」，以及「**移動到**」下的其他資料夾。在 Chrome 和 Edge 中，你可以將 <Shortcut id="browser.bookmark_page" /> 指派給快速儲存。
- 從右鍵選單將連結儲存至最近使用的資料夾或書籤列。
- 在書籤管理員中建立資料夾、拖放書籤和資料夾，以及一次移動多個項目。
- 依瀏覽器本身的順序 (預設)、新增日期、自然字母順序或資料夾優先顯示書籤，不會變更瀏覽器儲存的順序。
- 在「**書籤詳細資料**」中編輯名稱和網址，以及加上標籤和摘要。
- 刪除時可選擇是否要確認，並可在 10 秒內復原，資料夾中的所有內容都會一併還原。
- 在書籤管理員中，以拖曳或方向鍵調整表格欄寬；「**重設檢視**」可還原版面配置。
- 書籤管理員的網址會指出目前的資料夾或搜尋 (`?id=`、`?q=`)，因此「**上一頁**」、「**下一頁**」和加入書籤的連結都能正常運作，Chrome 本身的資料夾連結也能開啟，「**複製此資料夾的連結**」則可複製這類連結。
- 當 Chrome 同時將書籤保存在你的 Google 帳戶中和僅限這部裝置上時，書籤管理員的資料夾樹狀結構會像 Chrome 一樣，將書籤分成兩個區段顯示。
- 「**連結開啟位置**」可選擇點選的連結要在新分頁、背景分頁或目前分頁中開啟。

指南：「[儲存和整理](/guides/save-and-organize)」。

## 清理 [#clean-up]

- **重複書籤清理工具**：以可設定的比對方式找出重複書籤，經確認後移除多餘的副本，並可復原。
- **網址清理工具**：預覽後清除 `utm_source` 等追蹤參數。
- 「**智慧規則**」：以搜尋形式撰寫的規則 (例如 `domain:github.com`)，在確認後加上標籤並把書籤移到資料夾，可以復原。請參閱[用智慧規則加上標籤和移動](/guides/clean-up#tag-and-move-with-smart-rules)。
- **檢查失效連結**：將確定失效的連結與需要手動檢查的連結分開，並可透過刪除、追蹤重新導向、使用 Wayback Machine 連結或編輯網址來修復，且可復原。它在背景執行，關閉管理員後仍會繼續，可在**背景工作**中暫停、繼續或取消。
- **中繼資料擷取工具**：只讀取網頁的 head 部分，依據線上網頁建議標題，並套用你選取的標題。說明只會顯示供確認，絕不會儲存。它與**檢查失效連結**一樣在背景執行。
- **重新整理網站圖示**：經確認後下載各網站本身的圖示，即使瀏覽器沒有快取圖示，或是在 Firefox 中，書籤也能顯示圖示。圖示會保存在這部裝置上，並可清除。它與**檢查失效連結**一樣在背景執行。
- **隱私掃描工具**：標示網址 (也可選擇包含標題) 中含有權杖、敏感參數、電子郵件地址或 UUID 的項目。
- **書籤統計**：針對單一資料夾或所有書籤，列出最常見的網域和資料夾、通訊協定、重複項目，以及資料夾的層級深度。

指南：「[清理重複書籤和追蹤網址](/guides/clean-up)」和「[找出並修復失效連結](/guides/dead-links)」。

## 匯入和匯出 [#import-and-export]

- 匯出為 HTML、JSON、Markdown 或 CSV，並可在隱私確認時從檔案中遮蔽敏感值。
- 預覽目標資料夾、數量和重複項目後匯入 HTML 或 JSON，並可復原。
- JSON 匯出檔案會保留每個書籤的標籤和摘要，匯入這類檔案時會一併還原。
- 將擴充功能的設定、自訂提示詞、AI 服務（不含 API 金鑰）、已儲存的搜尋，以及書籤管理員表格的欄位備份為 JSON 檔案，並可還原。

指南：「[匯入和匯出](/guides/import-export)」。

## AI 工具 (選用) [#ai-tools-optional]

預設為關閉。可以使用自己的 OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter 金鑰，或 models.dev 目錄中其他約 200 個供應商的金鑰，也可以使用 Ollama、CLIProxyAPI 或任何與 OpenAI 相容的端點。在 Chrome 中，「**內建 AI**」會使用 Chrome 本身的模型免費推薦資料夾，在你的電腦上執行，不需要金鑰。

- 彈出式視窗中的資料夾推薦，包括經確認的新資料夾路徑，以及 <Shortcut id="commands.ai-quick-save" /> 快速儲存快捷鍵。
- 彈出式視窗和側邊面板中的「**詢問 AI**」：搜尋你的書籤、資料夾、標籤和摘要、找出重複書籤並檢查連結，藉此回答問題；儲存網頁，並以計畫的形式提議移動、重新命名、刪除和新增資料夾，在你核准之前不會做任何變更，而且每項變更都可以復原；回答結尾還會提供下一步動作的按鈕。設定中的「**詢問 AI 可以執行的動作**」可以關閉任何查詢或變更。
- 針對目前資料夾使用的「**自動加上標籤**」和「**內容摘要工具**」，結果要經你確認後才會儲存，並可復原。
- 「**AI 資料夾重組**」，在移動任何項目前先預覽，並可復原。
- 「**AI 脈絡打包工具**」，可將書籤匯出為 Markdown 或 XML 供 AI 對話使用，即使關閉 AI 也能使用。
- 「**AI 輸出語言**」可選擇標籤、摘要和新資料夾名稱的語言；「**關於我**」讓每項 AI 功能對你稍有認識；提示詞庫則可以改寫每項工具的提示詞，並提供 `{{today}}` 和 `{{existingTags}}` 等預留位置的清單。

標籤和摘要會保存在這部裝置上。它們不會同步，也無法在彈出式視窗中搜尋，但「詢問 AI」可以查詢這些資料，JSON 書籤匯出檔案也會包含這些資料。指南：「[設定 AI 工具](/guides/ai-tools)」。

## 本機 AI 代理 (選用) [#local-ai-agents-optional]

預設為關閉，且每部裝置分別設定。開啟「**允許本機 AI 代理**」後，電腦上的 AI 代理 (例如 Claude Code、Codex 或 Cursor) 可以透過 `bookmark-scout-mcp` 程式使用 Bookmark Scout 的查詢功能。這個程式是一個 MCP 伺服器，透過瀏覽器的原生訊息傳遞功能與擴充功能通訊。如果同時開啟「**允許變更**」，代理還可以儲存網頁並提議變更，每項變更都會在 Bookmark Scout 視窗中等待你核准，而且可以在書籤管理員中復原。標題和網址中的私密值預設會對代理隱藏。

指南：「[搭配本機 AI 代理使用](/guides/local-agents)」。

## 鍵盤和語言 [#keyboard-and-language]

- 任何網頁上都能使用的快速儲存快捷鍵，可以在瀏覽器的快捷鍵設定中變更；在 Firefox 中，則可直接在 Bookmark Scout 的設定中變更。
- 彈出式視窗和側邊面板中的快速鍵一律不使用 `Ctrl` 或 `Cmd`；書籤管理員則使用 Chrome 書籤管理員的按鍵 (全選、復原、重做、在分頁中開啟)，並提供按 <Shortcut id="manager.show_help" /> 開啟的說明對話方塊。請參閱「[鍵盤快速鍵](/guides/keyboard-shortcuts)」。
- 書籤管理員中的選取方式與 Chrome 相同：點選、`Cmd`+點選 (在 Windows 和 Linux 上為 `Ctrl`+點選)、`Shift`+點選和 <Shortcut id="manager.select_all" />；方向鍵可在表格和資料夾樹狀結構中移動，螢幕閱讀器會將資料夾樹狀結構讀作樹狀檢視。
- 用 <Shortcut id="manager.undo" /> 和 <Shortcut id="manager.redo" /> 復原和重做書籤管理員中的編輯、移動和刪除，在整個瀏覽器工作階段中都有效。
- 書籤管理員中各列和資料夾的右鍵選單：剪下、複製和貼上，在分頁、新視窗或無痕式視窗中全部開啟，重新命名和刪除；另有「**依名稱排序**」，以及「**新增書籤**」或「**新增資料夾**」。設定中的「**書籤管理器選單**」可選擇要顯示哪些指令，以及顯示順序。
- 書籤管理員中的拖放方式與 Chrome 相同：拖放到表格或樹狀結構中的資料夾上、依瀏覽器順序拖放到列與列之間，也可以從其他網頁拖入連結；<Shortcut id="manager.copy" />、<Shortcut id="manager.cut" /> 和 <Shortcut id="manager.paste" /> 可複製、移動和貼上。
