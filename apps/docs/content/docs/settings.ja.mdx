設定ページは、拡張機能の **オプション** 項目から開きます。たとえば Chrome では、ツールバーのアイコンを右クリックして **オプション** を選びます。変更は操作したときに保存されます。

## 設定ページの使い方 [#using-the-settings-page]

- 設定ページは、多くの人が変更するいくつかの設定をまとめた **基本設定** タブで開きます。ほかのタブはすべて **詳細設定** の下に並んでいます。**基本設定** の各設定はそれぞれのタブにもあり、どちらで変更しても同じ設定が変わります。
- 上部の **設定を検索...** で、すべてのタブから設定を探せます。一致した件数も表示されます。
- 各タブは見出し付きのセクションに分かれています。ツールのオン・オフのスイッチは見出しの横にあり、オフの間はそのツールの他の設定が折りたたまれます。タイムアウトやファイル名の長さなどの技術的な設定は **詳細設定** にまとめられ、開くか検索で見つかるまで閉じたままです。
- 変更した設定には **変更済み** の印が付き、初期値に戻すボタンが表示されます。**すべてリセット** ですべての設定を初期値に戻せます。
- **設定をバックアップ** で、変更した設定、カスタムプロンプト、AI サービス（名前、プロバイダー、モデル、**ベースURL**、プロバイダー固有の項目。API キーと **追加ヘッダー（JSON）** は含みません）、保存した検索、マネージャーの表の列と並べ替えをバックアップファイルに保存します。**設定を復元** でバックアップを復元すると、ファイルに含まれる項目がそれぞれ置き換わります。設定値だけのファイルは現在の設定にマージされます。バックアップの復元後は、**要設定** と表示されたサービスについて、[AI](#ai) で API キーと追加ヘッダーを入力し直してください。どちらもブックマークには影響しません。その隣の **ブックマークを書き出す** は、ブックマークマネージャーをエクスポートツールの画面で開きます。[インポートとエクスポート](/guides/import-export)をご覧ください。
- 設定はブラウザの同期ストレージに保存されるため、ブラウザの同期がオンなら他のデバイスにも引き継がれます。ただし、1 つのデバイスに属するいくつかの設定（クイック保存に選んだフォルダ、**アイコンの保存容量上限**、AI アクティビティの記録、AI に質問のウェブ検索）はそのデバイスにとどまります。AI サービスとその API キー、**ベースURL**、**追加ヘッダー（JSON）** もこのデバイスにとどまります。[プライバシー](/privacy)をご覧ください。

## AI [#ai]

AI は初期設定でオフです。これらの設定は、**AI機能** をオンにした後にだけ意味を持ちます。それまでは、ここと **AIツール** タブの AI の設定は、その旨を示す注意書きの下でグレー表示になります。それでも変更はできます。既定のサービスを設定するまでは、上部の **AI は任意です** という枠に、AI でできること、必要なもの、かかる可能性のある費用、送信される内容が表示され、[AI ツールの設定](/guides/ai-tools) へのリンクもあります。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **AI機能** | オフ | AI ツールとポップアップのフォルダの提案をオンにします。Firefox では、オンにすると、API キー、ブックマーク、現在のページのタイトルと URL を AI プロバイダーと共有することへの同意を求めます |
| **AI サービス** | なし | 追加したプロバイダー。それぞれにモデルとキーがあり、AI ツールは既定のサービスを使います。**内蔵 AI** はフォルダの提案だけを行うため、内蔵 AI が既定のあいだ、ほかのツールはオンになっているほかのサービスの最初のものを使います |

その下のプロバイダーのパネルには、**APIキー**、**ベースURL**、**カスタムモデル**、**追加ヘッダー（JSON）** と、**サービスを確認**、**モデルを更新** があります。フォルダの上限は指示としてプロバイダーに送られ、プロバイダーの出力がそれに従っているかどうかは確認されません。[AI ツールの設定](/guides/ai-tools)をご覧ください。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |

### AI に質問でできること [#ask-ai-actions]

AI に質問が調べたり変更したりできる操作がここに一覧表示され、既定ではすべてオンです。オフにした操作は AI に一切提示されません。ここで何を選んでも、変更プランの適用は必ず事前に確認されます。

## AIツール [#ai-tools]

各ツールには **有効化** スイッチがあります（初期設定でオン）。オフにすると、マネージャーの **ツール** サイドバーに表示されなくなります。

| ツール | 設定と初期値 |
| --- | --- |
| **AIコンテキストパッカー** | **出力形式** Markdown、**フォルダパスを含める**、**日付を含める**、**保存済みタグを含める**、**保存済み要約を含める** はオン、**最大件数** 200、**最大階層** 8、**抜粋の長さ** 240 |
| **自動タグ付け** | **最小タグ数** 2、**最大タグ数** 5、**タグのスタイル** kebab-case、**統合モード** 追加、**重複タグを削除** オン |
| **コンテンツ要約** | **要約の長さ** 160、**ドメインのヒントを含める** オン、**統合モード** 置換 |
| **AIフォルダ整理** | **最小信頼度** 55%（これを下回る移動は除外されます）、**バッチサイズ** 1 リクエストあたり 100 件のブックマーク |

自動タグ付けとコンテンツ要約は、常に現在のフォルダを対象にします。

### AIフォルダ整理 [#ai-folder-reorganization]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **最大カテゴリ数** | 制限なし | 再整理プランで作成できるトップレベルフォルダの最大数 |
| **フォルダあたりの最小件数** と **フォルダあたりの最大件数** | 1 と制限なし | 再整理プランで目指すフォルダの大きさ |

## メンテナンス [#maintenance]

| ツール | 設定と初期値 |
| --- | --- |
| **重複クリーナー** | **照合方法** 正規化したURL、**wwwを正規化**、**プロトコルを無視**、**末尾のスラッシュを無視** はオン、**保持ルール** 最も古いもの、**最大グループ数** 500。常にすべてのブックマークをスキャンします |
| **URLクリーナー** | **フラグメントを削除** オフ、**クエリパラメータを並べ替え** と **クエリパラメータの重複を削除** はオン、**保持するパラメータ** と **削除するパラメータ** のリスト |
| **リンク切れチェック** | **リクエストのタイムアウト** 8 秒、**同時実行数** 4、**再試行回数** 1、**リダイレクトをたどる** オン、**成功とみなすステータスコード** 200, 201, 202, 204, 301, 302, 307, 308 |

ツールは **すべてのブックマーク** から始まります。マネージャーを開いたときのフォルダからスキャンしても、ほかのフォルダが漏れないようにするためです。開いているフォルダから始めたい場合は、ツールの **既定の範囲** を変更してください。**AIフォルダ整理** は開いているフォルダから始まります。すべてのブックマークを対象にしたプランでは、そのすべてが AI プロバイダーに送信されるためです。フォルダを開いていないマネージャーの最上位では、どのツールも **すべてのブックマーク** から始まります。

**削除するパラメータ** などのリストは、名前を入力して Enter を押すか、候補から選んで編集します。**成功とみなすステータスコード** は一般的なコードのチェックリストで、ほかのコードも追加できます。設定がブラウザの同期に収まるよう、各リストは 20 件まで、パラメータ名は 32 文字（英数字と URL の記号）までです。初期設定のリストは[重複とトラッキング URL のクリーンアップ](/guides/clean-up#strip-tracking-parameters)に記載しています。[リンク切れの検出と修復](/guides/dead-links)もご覧ください。

| **ファイル名の接頭辞** | `bookmarks_` | すべてのエクスポートファイル名の先頭 |
| **ファイル名の最大長** | 50 | 生成されるファイル名の最大の長さ |
| **JSONのインデント幅**、**HTMLのインデント幅**、**Markdownのインデント幅** | 2、4、2 | 各形式での 1 階層あたりのスペースの数 |
| **日付を含める** と **URLを含める** | オン | エクスポートに含めます |

[インポートとエクスポート](/guides/import-export)をご覧ください。

## 開発者向け [#developers]

### ローカル AI エージェント [#agent-bridge]

**ローカル AI エージェントを許可**（初期設定はオフ、このデバイスのみ）をオンにすると、コンピューター上の AI エージェント（Claude Code、Codex、Cursor など）が bookmark-scout-mcp プログラムを通じてブックマークを調べられます。プログラムはインストールして `bookmark-scout-mcp install` で登録します。**AI機能** をオンにする必要はありません。このスイッチをオンにすると、拡張機能がそのプログラムと通信することを許可するよう、ブラウザーから求められます。**変更を許可**（初期設定はオフ）をオンにすると、ページの保存や、移動・名前の変更・削除・新しいフォルダの提案もできるようになります。変更ごとに Bookmark Scout のウィンドウが開いて承認または拒否でき、ブックマークマネージャーで元に戻すこともできます。スイッチの下のパネルに、プログラムが実行中かどうかが表示されます。

**非公開の値を隠す**（初期設定はオン）は、エージェントが受け取るタイトルと URL に含まれる機密性の高い URL パラメーター、トークン、メールアドレスを、プライバシースキャナーのリストに従って置き換えます。**ローカルエージェントにできること**には検索の種類が一覧表示され、既定ではすべてオンです。オフにしたものはエージェントに一切提示されません。
