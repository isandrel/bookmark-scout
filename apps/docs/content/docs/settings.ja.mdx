設定ページは、拡張機能の **オプション** 項目から開きます。たとえば Chrome では、ツールバーのアイコンを右クリックして **オプション** を選びます。変更は操作したときに保存されます。

## 設定ページの使い方 [#using-the-settings-page]

- 設定ページは、多くの人が変更するいくつかの設定をまとめた **基本設定** タブで開きます。ほかのタブはすべて **詳細設定** の下に並んでいます。**基本設定** の各設定はそれぞれのタブにもあり、どちらで変更しても同じ設定が変わります。
- 上部の **設定を検索...** で、すべてのタブから設定を探せます。一致した件数も表示されます。
- 各タブは見出し付きのセクションに分かれています。ツールのオン・オフのスイッチは見出しの横にあり、オフの間はそのツールの他の設定が折りたたまれます。タイムアウトやファイル名の長さなどの技術的な設定は **詳細設定** にまとめられ、開くか検索で見つかるまで閉じたままです。
- 変更した設定には **変更済み** の印が付き、初期値に戻すボタンが表示されます。**すべてのショートカットをリセット** ですべての設定を初期値に戻せます。
- **設定をバックアップ** で、変更した設定、カスタムプロンプト、AI サービス（名前、プロバイダー、モデル、**ベースURL**、プロバイダー固有の項目。API キーと **追加ヘッダー（JSON）** は含みません）、保存した検索、スマートルール、マネージャーの表の列と並べ替えをバックアップファイルに保存します。**設定を復元** でバックアップを復元すると、ファイルに含まれる項目がそれぞれ置き換わります。設定値だけのファイルは現在の設定にマージされます。バックアップの復元後は、**要設定** と表示されたサービスについて、[AI](#ai) で API キーと追加ヘッダーを入力し直してください。どちらもブックマークには影響しません。その隣の **ブックマークを書き出す** は、ブックマークマネージャーをエクスポートツールの画面で開きます。[インポートとエクスポート](/guides/import-export)をご覧ください。カバー画像が保存されている間は、**設定をバックアップ** でカバー画像を含めるかどうかを確認し、カバー画像を含むバックアップを復元するときは先に確認画面を表示します。[バックアップのカバー画像](/guides/import-export#covers-in-a-backup) を参照してください。
- 設定はブラウザの同期ストレージに保存されるため、ブラウザの同期がオンなら他のデバイスにも引き継がれます。ただし、1 つのデバイスに属するいくつかの設定（クイック保存に選んだフォルダ、**アイコンの保存容量上限**、AI アクティビティの記録、AI に質問のウェブ検索）はそのデバイスにとどまります。AI サービスとその API キー、**ベースURL**、**追加ヘッダー（JSON）** もこのデバイスにとどまります。[プライバシー](/privacy)をご覧ください。

### クイック保存ショートカット [#quick-save]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **クイック保存のフォルダ** | 最適な一致 | <Shortcut id="commands.quick-save" /> で現在のページを保存する場所: 最もよく一致するフォルダ、最後に使ったフォルダ、指定したフォルダのいずれか。AI のショートカットは常に AI の提案を使います |
| **保存先フォルダ** | 未選択 | **指定のフォルダ** で使うフォルダ。削除された場合、クイック保存は最後に使ったフォルダを使います |
| **提案するほかのフォルダ** | <SettingDefault path="search.quick_save.alternatives" /> | クイック保存の通知が移動先として提案するほかのフォルダの数 |
| **通知の表示時間** | <SettingDefault path="search.quick_save.notification_ms" seconds /> 秒 | クイック保存の通知が閉じるまでの時間。ポインタを合わせている間は開いたままです |
| **クイック保存でカバー画像も保存** | オフ | クイック保存のあと、ブックマークのカバー画像も保存します。ページ自身の画像（そのサイトか許可したサイトからだけダウンロード）か、ショートカットを押したときに撮ったタブのスクリーンショットを、確認なしで使います。**カバー画像の取得を有効にする** がオンのときだけ動作し、プライベートウィンドウや **撮影しないサイト**、**読み込まないサイト** のサイトでは保存しません。通知に **カバー画像を削除** が表示され、**元に戻す** でブックマークとともに削除されます。この端末にのみ保存されます。オンの間は次の 2 つの設定が表示されます |
| **クイック保存のカバー画像のソース** | 「カバー画像のソース」と同じ | クイック保存で残すカバー画像。[カバー画像のソース](#fetch-covers) の順に従うか、その選択肢の 1 つをクイック保存専用に選びます |
| **ブックマークにカバー画像があるとき** | 残す | **残す** はブックマークにすでにあるカバー画像をそのままにし、**置き換える** は新しい画像に置き換えます。**この画面をカバー画像にする** で保存したカバー画像は置き換えません |

その下の **キーボードショートカット** には、各ショートカットにブラウザで割り当てられているキーが **ショートカットを変更** とともに表示されます。Firefox では、その場で新しいキーを入力したり初期設定に戻したりもできます。Chrome と Edge では、クイック保存に <Shortcut id="browser.bookmark_page" /> を割り当てる方法も説明されます。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)と[ブックマークのキーでクイック保存する](/guides/save-and-organize#ctrl-d)をご覧ください。

### 右クリックメニュー [#context-menu]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **右クリックメニュー** | オフ | ブラウザーの右クリックメニューに **ブックマークの保存先...** を表示します。Chrome と Edge では、オンにすると任意の右クリックメニューの権限が確認なしで追加されます |
| **メニューを表示する場所** | リンク | 右クリックでメニューを表示する場所です。**リンク**（リンクを保存）、**ページ**（開いているページを保存）、**選択したテキスト**（ページを保存し、**リンクテキスト** の命名では選択したテキストを名前にします）。どれもほかの権限は必要ありません |
| **ブックマーク名の取得元** | リンクテキスト | 右クリックで保存するブックマークの名前を、リンクテキスト、ページタイトル、リンク URL のどれにするか |
| **メニューの最近のフォルダ数** | <SettingDefault path="search.context_menu.recent_max" /> | メニューに表示する最近のフォルダの数。ポップアップの **最近のフォルダ最大数** とは別です |

**メニューの項目** では、メニューに表示する項目とその順序を選びます: **最近のフォルダ**（サブメニュー）と **ブックマークバー**。項目をチェックすると表示され、ハンドルをドラッグする（またはハンドルのメニューを使う）と移動できます。**既定に戻す** で両方が最初の順序で表示されます。

### ポップアップ [#popup]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **ポップアップ幅** | <SettingDefault path="appearance.popup.width" /> px | ブラウザの上限は 800 px です |
| **ポップアップ高さ** | <SettingDefault path="appearance.popup.height" /> px | ブラウザの上限は 600 px です |
| **文字数制限** | <SettingDefault path="appearance.popup.truncate_length" /> 文字 | ポップアップの AI の提案のヘッダーに表示するページタイトルを短くします |
| **ツリーの表示密度** | 標準 | ポップアップとサイドパネルのツリーの行を **標準** または **コンパクト** にします。このデバイスにのみ保存されます |
| **ポインタを合わせて詳細を表示** | オン | ポップアップやサイドパネルでブックマークにポインタを置くか矢印キーで移動すると、タイトルとアドレスの全体、フォルダ、タグ、要約、保存済みのカバー画像、追加日をカードで表示します。`Esc` でカードを閉じます。オフにすると、行のタイトルとアドレスは通常のツールチップで表示されます |

表の下にある 3 つのリストで、ポップアップとサイドパネルを並べ替えます。項目にチェックを入れると表示され、ハンドルをドラッグすると移動します。ハンドルはボタンでもあり、そのメニューで項目を先頭、上、下、末尾へ移動できます。**既定に戻す** で各リストを通常の順序に戻せます。これらのリストはこのデバイスにのみ保存されます。

- **ポップアップの構成**: 検索ボックスの下に上から順に表示するもの。現在のページ、バックグラウンドタスク、直前のクイック保存、最近のフォルダ、AI のフォルダ候補、フォルダの候補、ブックマーク、お知らせ、キーのヒント。ブックマークは常に表示され、ほかの部分をその上か下に移動できます。
- **ツールバーのボタン**: 検索ボックスの横のボタン。**すべて展開** (検索中)、ブックマークマネージャー、テーマ、AI のボタン (AI の設定後)。
- **詳細カードの内容**: 詳細カードに順に表示するもの。タイトル、アドレス、カバー、タグ、要約、フォルダ、追加日。タイトル、アドレス、カバーが先頭にある間は、カードの一番上の行に並びます。

## 動作 [#behavior]

### ツリーと並び順 [#tree-and-sorting]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **並び順** | ブラウザの順序 | **ブラウザの順序**（ブックマークバーと同じ順序）、**追加日順**（新しい順）、**アルファベット順**、**フォルダ優先**。列で並べ替えるまでは、マネージャーの表もこの順序になります。変わるのは Bookmark Scout でのブックマークの表示だけで、ブラウザに保存されている順序は変わりません |
| **フォルダでグループ化** | オン | ポップアップとサイドパネルの各階層で、サブフォルダをブックマークより先に表示します |
| **ツリーのドラッグ＆ドロップ** | オン | ポップアップとサイドパネルで、ブックマークやフォルダをドラッグして移動し、ウェブページのリンクをサイドパネルのフォルダにドロップして保存します。誤って行を動かさないようにするにはオフにします。マネージャーでは引き続き移動できます |
| **開いたときに展開** | なし | ポップアップやサイドパネルを開いたときに展開しておくフォルダ。**なし**、**ブックマークバー**、または **前回のまま** (前回閉じたときに開いていたフォルダ。このデバイスに記憶します) |

### リンク [#links]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **リンクを開く場所** | 新しいタブ | **新しいタブ**、**バックグラウンドの新しいタブ**、**現在のタブ** から、Bookmark Scout でリンクをクリックしたときに開く場所を選びます。中クリックや <Shortcut id="mouse.open_in_background" />はブラウザーの動作に従います |
| **リンクを開く場所を表示** | オン | 各リンクの後ろと、ポップアップやサイドパネルでポインタを合わせたブックマークの行に小さなアイコンを表示し、クリックでどこに開くかを示します。新しいタブは枠から出る矢印、バックグラウンドのタブは重なったレイヤー、このタブは矢印です。アイコンにポインタを合わせると説明が出ます。オフにするとアイコンを隠します |
| **確認する件数** | <SettingDefault path="behavior.links.confirm_open_above" /> | この数より多いブックマークを一度に開くとき（Enter、**すべて開く**）は、Chrome のマネージャーと同じように先に確認します。フォルダは直下のブックマークを数えます |

### ツールサイドバー [#tools-sidebar]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **マネージャーの表示** | リスト | **リスト** は表を表示し、**カード** は同じ行をカードのグリッドで表示します。選択、キー操作、メニューは同じです。**表示** の横にある 2 つのボタンでも切り替えられます。この端末にのみ保存されます |
| **ツールサイドバーのレイアウト** | タブ | **タブ** は 1 セクションずつ表示し、**すべて** で全ツールを表示します。**一覧** はすべてのセクションを続けて表示します。このデバイスにのみ保存されます |
| **最初に開くタブ** | メンテナンス | ツールサイドバーが **タブ** 表示のときに開くタブ: **すべて**、1 つのセクション、または **データ**。表示するツールがないタブの場合は、ツールがある最初のタブを開きます。この端末にのみ保存されます |

**サイドバーのツール** では、ツールサイドバーに表示するツールと、各セクション内での順序を選びます。チェックを外すとそのツールのカードが非表示になり、ハンドルをドラッグする（またはハンドルのメニューを使う）と移動できます。非表示にしたツールはオンのままなので、**スマートルール**、**ページ本文の索引**、**カバー画像の取得** の自動の処理は続きます。ツールをオフにするには、それぞれのスイッチを使います。**既定に戻す** ですべてのツールが最初の順序で表示されます。この端末にのみ保存されます。

### ブックマークマネージャー [#manager-view]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **マネージャーの並び順** | 並び順と同じ | 表を列で並べ替えるまで、マネージャーがフォルダを表示する順序です。**並び順と同じ** は上の **並び順** に従います。マネージャーだけの順序を選ぶこともできます。ポップアップとサイドパネルは **並び順** のままです |

### ブックマークマネージャーのメニュー [#manager-menus]

マネージャーの各メニューをそれぞれのタブで整えます。**項目メニュー**（行やツリーのフォルダを右クリック、または行の ⋯ ボタン）、**整理メニュー**（ヘッダーの ⋮）、**空白部分のメニュー**（行の下を右クリック）、**プレビューのボタン**（ブックマークのプレビューの下。最初のボタンがメイン）です。コマンドのチェックを外すと非表示になり、**非表示** に移ります。もう一度チェックすると末尾に戻ります。コマンドをハンドルでドラッグすると並べ替えられ、**セクションの区切り** をドラッグするとコマンドを別のセクションに移せます。ハンドルはボタンでもあり、そのメニューで一番上・上・下・一番下へ移動できるので、キーボードでも操作できます。**セクションの区切りを追加** は末尾に区切りを追加するので、上へ移動して使います。区切りの ✕ で削除すると 2 つのセクションがつながります。**既定に戻す** はそのメニューだけを元に戻します。どのメニューにも少なくとも 1 つのコマンドが残り、項目メニューには **詳細を表示** または **ブックマークIDをコピー** が残るため、どのブックマークやフォルダにも使えるコマンドがあります。残したコマンドがどれも当てはまらない場合、メニューには **使用できる操作はありません** と表示されます。すべてのメニューは他の設定と一緒に同期されます。

### ポップアップのブックマーク操作とフォルダ操作 [#popup-menus]

ポップアップとサイドパネルでブックマークとフォルダに表示するコマンドを選び、マネージャーのメニューと同じように、ハンドルをドラッグしてグループ内の順序を変えます。行の最初のコマンドは、行にポインタを合わせるかキーボードで移動したときに表示されるボタンです。ブックマークでは **削除**、フォルダでは **すべてのサブフォルダを展開**、**現在のページを追加**、**フォルダを追加**、**削除** です。**新しいタブで開く** や **新しいウィンドウで開く** などの残りは行の ⋯ メニューにあり、行を右クリック (またはメニューキー) するとすべて表示されます。ボタンを非表示にすると、次のコマンドがボタンになります。**既定に戻す** ですべてのメニューを元に戻せます。ブックマークでは **新しいタブで開く** か **削除**、フォルダでは **フォルダを追加** か **すべて開く** が常に残ります。ブックマークマネージャーのメニューと同じく、他の設定と一緒に同期されます。

### マネージャーとポップアップのショートカット [#page-shortcuts]

ブックマークマネージャー、ポップアップ、サイドパネルの中で使えるキーを変更します。初期のキーは[キーボードショートカット](/guides/keyboard-shortcuts)に載っています。ショートカットの横の **変更** をクリックして新しいキーを押してください。`Esc` でキャンセルします。同じページの別のショートカットがすでに使っているキーは、そのショートカットの名前を示して受け付けません。ブラウザーが自分で使うキーや、リスト内を移動するキー（矢印、`Home`、`End`、`Enter`、スペース）も、そのショートカット自身のキーでない限り受け付けません。ポップアップとサイドパネルのショートカットは `Ctrl` や `Cmd` を使いません。変更したショートカットの横のリセットボタンで初期のキーに戻り、**すべてリセット** ですべてのショートカットが戻ります。コピー、切り取り、貼り付けはブラウザーのキーのままで、[クイック保存ショートカット](#quick-save)はブラウザーが管理します。この端末にだけ保存されます。

## AI [#ai]

AI は初期設定でオフです。これらの設定は、**AI機能** をオンにした後にだけ意味を持ちます。それまでは、ここと **AIツール** タブの AI の設定は、その旨を示す注意書きの下でグレー表示になります。それでも変更はできます。既定のサービスを設定するまでは、上部の **AI は任意です** という枠に、AI でできること、必要なもの、かかる可能性のある費用、送信される内容が表示され、[AI ツールの設定](/guides/ai-tools) へのリンクもあります。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **AI機能** | オフ | AI ツールとポップアップのフォルダの提案をオンにします。Firefox では、オンにすると、API キー、ブックマーク、現在のページのタイトルと URL を AI プロバイダーと共有することへの同意を求めます |
| **AI サービス** | なし | 追加したプロバイダー。それぞれにモデルとキーがあり、AI ツールは既定のサービスを使います。**内蔵 AI** はフォルダの提案だけを行うため、内蔵 AI が既定のあいだ、ほかのツールはオンになっているほかのサービスの最初のものを使います |

その下のプロバイダーのパネルには、**APIキー**、**ベースURL**、**カスタムモデル**、**追加ヘッダー（JSON）** と、**サービスを確認**、**モデルを更新** があります。フォルダの上限は指示としてプロバイダーに送られ、プロバイダーの出力がそれに従っているかどうかは確認されません。[AI ツールの設定](/guides/ai-tools)をご覧ください。

**APIキー** の下の **API キーが必要** は、最初はプロバイダーに合わせた状態です。オフにすると、キーを自分で付け加えるプロキシやゲートウェイの奥にあるサービスなどを、キーなしで使えます。

## メンテナンス [#maintenance]

| ツール | 設定と初期値 |
| --- | --- |
| **重複クリーナー** | **照合方法** 正規化したURL、**wwwを正規化**、**プロトコルを無視**、**末尾のスラッシュを無視** はオン、**保持ルール** 最も古いもの、**最大グループ数** <SettingDefault path="maintenance.duplicates.max_groups" />。常にすべてのブックマークをスキャンします |
| **URLクリーナー** | **フラグメントを削除** オフ、**クエリパラメータを並べ替え** と **クエリパラメータの重複を削除** はオン、**保持するパラメータ** と **削除するパラメータ** のリスト |
| **スマートルール** | 実行順に並んだルール: **ルールを追加** または **テンプレートから始める** を使い、各ルールの名前、検索、タグ、フォルダとオン・オフを設定します。ルールをドラッグすると、どの移動が優先されるかを変えられます。テンプレートは最初オフで、移動するテンプレートは先にフォルダを選ぶよう求めます。[スマートルールでタグ付けと移動](/guides/clean-up#tag-and-move-with-smart-rules) を参照してください。**新しいブックマークにタグを付ける** オフ: オンにすると、有効なルールが **対象とする新しいブックマーク** で許可された新しいブックマークにタグを付けます。移動はしません。**新しいブックマークを移動する** オフ: オンにすると、**新しいブックマークを自動で移動** をオンにしたルールが、Bookmark Scout 以外から追加された新しいブックマークをそのフォルダに移動します。**対象とする新しいブックマーク** Bookmark Scout で保存したもの: 両方が対象とする新しいブックマークです。**すべて** にすると、ブラウザのスター、同期、ほかの拡張機能からのものも含めます。3 つともこの端末だけの設定です。各ルールには前回の確認済みの実行（日時と、タグを付けた、移動した、対象外にしたブックマークの数）が表示され、エディターの **アドレスやタイトルで試す** で、例が検索に一致するかを確認できます。ルールの下の **前回の実行での競合** には、2 つのルールが別々のフォルダに移動しようとしたブックマークが、それぞれ **確認** ボタン付きで表示されます。**ルールによる変更** には、新しいブックマークへのタグ付け、新しいブックマークの移動、確認して実行したルールが最近変更した内容が、それぞれ元に戻すボタン付きで表示されます。 |
| **リンク切れチェック** | **リクエストのタイムアウト** <SettingDefault path="maintenance.dead_links.request_timeout_ms" seconds /> 秒、**同時実行数** <SettingDefault path="maintenance.dead_links.concurrency" />、**再試行回数** <SettingDefault path="maintenance.dead_links.retry_count" />、**リダイレクトをたどる** オン、**成功とみなすステータスコード** <SettingDefault path="maintenance.dead_links.success_statuses" />、**リンク切れ確定の既定**・**手動で確認するリンクの既定**・**リダイレクトされたリンクの既定** そのまま残す |
| **バックグラウンドのタスク** | **バックグラウンドで適用する件数** <SettingDefault path="maintenance.background_tasks.apply_in_background_above" />: これより多いブックマークへの確認済みの変更は、バックグラウンドで分割して適用され、ページを閉じても続きます。各部分は[履歴](/guides/save-and-organize)の 1 件の変更として表示され、そこで元に戻せます。スマートルールの実行では、変更するブックマークの数で判断します。そのタグは **ルールによる変更** で元に戻します |

ツールは **すべてのブックマーク** から始まります。マネージャーを開いたときのフォルダからスキャンしても、ほかのフォルダが漏れないようにするためです。開いているフォルダから始めたい場合は、ツールの **既定の範囲** を変更してください。**AIフォルダ整理** は開いているフォルダから始まります。すべてのブックマークを対象にしたプランでは、そのすべてが AI プロバイダーに送信されるためです。フォルダを開いていないマネージャーの最上位では、どのツールも **すべてのブックマーク** から始まります。

**削除するパラメータ** などのリストは、名前を入力して Enter を押すか、候補から選んで編集します。**成功とみなすステータスコード** は一般的なコードのチェックリストで、ほかのコードも追加できます。設定がブラウザの同期に収まるよう、各リストは 20 件まで、パラメータ名は 32 文字（英数字と URL の記号）までです。初期設定のリストは[ブックマークのクリーンアップと充実](/guides/clean-up#strip-tracking-parameters)に記載しています。[リンク切れの検出と修復](/guides/dead-links)もご覧ください。

### カバー画像の取得 [#fetch-covers]

| 設定 | 既定 | 内容 |
| --- | --- | --- |
| **カバー画像の取得を有効にする** | オフ | ツールサイドバーに **カバー画像の取得** を表示します |
| **既定の範囲** | 現在のフォルダ | ツールが最初に読むブックマーク |
| **カバー画像のソース** | ページの画像を優先し、なければスクリーンショット | ページ自身の画像とタブのスクリーンショットの両方が使えるとき、ブックマークにどちらのカバー画像を残すか。**ページの画像を優先し、なければスクリーンショット**: カバー画像の取得がスクリーンショットを置き換え、閲覧中に撮影するスクリーンショットはページの画像がないブックマークにだけ使います。**スクリーンショットを優先**: 閲覧中に撮影したスクリーンショットがページの画像を置き換えます。**ページの画像のみ**: 閲覧中にスクリーンショットを撮りません。**この画面をカバー画像にする** では、保存した画像が常に残ります。「この画面をカバー画像にする」で保存したカバー画像は、カバー画像の取得でも閲覧中のスクリーンショットでも自動で置き換えられません。置き換わるのは、あなたが別の画像を保存したときだけです。**スクリーンショットのみ**：スクリーンショットだけを使います。カバー画像の取得はページを読み込まず、確認画面でそのことを伝えます。 |
| **閲覧中にカバー画像を撮影** | オフ | カバー画像のないブックマーク済みのページ、または古いスクリーンショットのページが表示中のタブで読み込みを終えたら、ページが落ち着いてからタブのスクリーンショットをカバー画像として撮影します。プライベートウィンドウでは、その撮影もオンにしない限り撮影しません。拡張機能やブラウザ自身のページ、ローカルファイルは撮影しません。オンにすると、すべてのページへのアクセスを求めます。この端末だけに保存。オンの間は、次の 4 つの設定が表示されます |
| **プライベートウィンドウでも撮影** | オフ | プライベートウィンドウでもスクリーンショットを撮影します。ただし、ブラウザが Bookmark Scout にそこでの実行を許可している場合だけです。許可するには、ブラウザの拡張機能の設定にある拡張機能のページで、Chrome と Edge ではシークレットモードでの実行を、Firefox ではプライベートウィンドウでの実行を許可します。ブラウザが許可していない間は、設定にそのことが表示されます。この端末だけに保存 |
| **撮影までの待ち時間** | <SettingDefault path="metadata_content.covers.browse_settle_ms" seconds /> 秒 | ブックマーク済みのページが読み込まれた後、スクリーンショットを撮影するまでに、そのページが前面に表示され続けている必要がある時間 |
| **撮影の間隔** | <SettingDefault path="metadata_content.covers.browse_min_interval_ms" seconds /> 秒 | 2 枚のスクリーンショットの間に空ける最短の時間。ブラウザが許す範囲より短くはできません（Chrome が撮影できるのは 1 秒に 2 枚まで） |
| **次より古いスクリーンショットを撮り直す** | <SettingDefault path="metadata_content.covers.browse_max_age_days" /> 日 | 閲覧中に撮影したスクリーンショットがこれより古い場合、次にアクセスしたときに撮り直します。0 にすると撮り直しません。**この画面をカバー画像にする** で選んだカバー画像は撮り直しません |
| **撮影しないサイト** | なし | 閲覧中に撮影しないサイト（それぞれのサブドメインを含む）。`example.com` のようにサイトを入力するか、アドレスを貼り付けます。「読み込まないサイト」にあるサイトも撮影しません。 |
| **カバー画像の幅** | <SettingDefault path="metadata_content.covers.width_px" /> px | 各カバー画像として保存するコピーの幅。これより大きい画像は縮小されます |
| **カバー画像の画質** | <SettingDefault path="metadata_content.covers.quality" percent /> | 各カバー画像として保存するコピーの画質で、どの方法で保存したカバー画像にも使われます。低いほどファイルが小さくなります。変更後に保存したカバー画像に適用されます |
| **画像の最大サイズ** | <SettingDefault path="metadata_content.covers.max_image_kb" /> KB | これより大きい画像ファイルはダウンロードしません |
| **カバー画像の保存容量** | <SettingDefault path="metadata_content.covers.max_cache_mb" /> MB | カバー画像がこの端末で使える容量。古いものから削除されます。この端末だけに保存 |

その下の **ブックマークのカバー画像** には保存されているカバー画像の数とサイズが表示され、**カバー画像を削除** でブックマーク、タグ、履歴に触れずにすべて削除できます。

## 開発者向け [#developers]

### ローカル AI エージェント [#agent-bridge]

**ローカル AI エージェントを許可**（初期設定はオフ、このデバイスのみ）をオンにすると、コンピューター上の AI エージェント（Claude Code、Codex、Cursor など）が bookmark-scout-mcp プログラムを通じてブックマークを調べられます。プログラムはインストールして `bookmark-scout-mcp install` で登録します。**AI機能** をオンにする必要はありません。このスイッチをオンにすると、拡張機能がそのプログラムと通信することを許可するよう、ブラウザーから求められます。**変更を許可**（初期設定はオフ）をオンにすると、ページの保存や、移動・名前の変更・削除・新しいフォルダの提案もできるようになります。変更ごとに Bookmark Scout のウィンドウが開いて承認または拒否でき、ブックマークマネージャーで元に戻すこともできます。スイッチの下のパネルに、プログラムが実行中かどうかが表示されます。

**非公開の値を隠す**（初期設定はオン）は、エージェントが受け取るタイトルと URL に含まれる機密性の高い URL パラメーター、トークン、メールアドレスを、プライバシースキャナーのリストに従って置き換えます。**ローカルエージェントにできること**には検索の種類が一覧表示され、既定ではすべてオンです。オフにしたものはエージェントに一切提示されません。
