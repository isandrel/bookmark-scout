title: 設定
description: Bookmark Scout の設定ページにあるすべての設定を、タブごとに初期値と変わる内容とともに説明します。
---

設定ページは、拡張機能の **オプション** 項目から開きます。たとえば Chrome では、ツールバーのアイコンを右クリックして **オプション** を選びます。変更は操作したときに保存されます。

## 設定ページの使い方 [#using-the-settings-page]

- 上部の **設定を検索...** で、すべてのタブから設定を探せます。一致した件数も表示されます。
- 変更した設定には **変更済み** の印が付き、初期値に戻すボタンが表示されます。**すべてリセット** ですべての設定を初期値に戻せます。
- **エクスポート** で設定を JSON ファイルとして保存し、**インポート** でそのファイルから復元します。どちらもブックマークには影響しません。
- 設定はブラウザの同期ストレージに保存されるため、ブラウザの同期がオンなら他のデバイスにも引き継がれます。ただし、AI プロバイダーの API キー、**ベースURL**、**追加ヘッダー（JSON）** は例外で、このデバイスにとどまります。[プライバシー](/privacy)をご覧ください。

## 外観 [#appearance]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **言語** | ブラウザの設定 | 英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、ドイツ語、フランス語、ブラジルポルトガル語のいずれか、またはブラウザに合わせる |
| **テーマ** | システム | システム、ライト、ダーク。開いているすべての Bookmark Scout のページに適用されます |
| **ファビコンを表示** | オン | ポップアップとサイドパネルで、ブックマークの横にサイトアイコンを表示します |
| **ブラウザのアイコンキャッシュを使う** | オフ | Chrome と Edge: **サイトアイコンを更新** で保存したアイコンがないサイトについて、ブラウザがすでにキャッシュしているアイコンも表示します。オンにするとサイトアイコンを読み取る権限を求めます。拡張機能向けのアイコンキャッシュがない Firefox では表示されません |
| **ファビコンサイズ** | 16px (小) | 16、24、32 ピクセル |

## 検索 [#search]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **検索遅延** | 300 ms | 入力を止めてからポップアップが検索を始めるまでの待ち時間 |
| **最大検索結果数** | 20 件 | 表示する一致の最大数。それより多い場合はその旨が表示されます |
| **検索時にフォルダを展開** | オン | 一致する項目を含むフォルダを開きます |
| **検索履歴** | オン | 最近の検索をこのデバイスに記憶します |
| **フォルダの候補** | オン | 検索中、名前が一致するフォルダを結果の上に表示し、現在のページをそこに保存できるようにします |
| **フォルダ候補の最大数** | 5 | 表示する一致フォルダの数 |
| **入力ミスを許容** | オン | 4 文字以上の検索語は、1 文字違いのフォルダ名にも一致します |

[検索と保存した検索](/guides/search)をご覧ください。

## 動作 [#behavior]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **並び順** | 追加日順 | **追加日順**、**アルファベット順**、**フォルダ優先**。変わるのは Bookmark Scout でのブックマークの表示だけで、ブラウザに保存されている順序は変わりません |
| **フォルダでグループ化** | オン | ポップアップとサイドパネルの各階層で、サブフォルダをブックマークより先に表示します |
| **リンクを開く場所** | 新しいタブ | **新しいタブ**、**バックグラウンドの新しいタブ**、**現在のタブ** から、Bookmark Scout でリンクをクリックしたときに開く場所を選びます。中クリックや Ctrl/Cmd+クリックはブラウザーの動作に従います |
| **削除前に確認** | オン | 削除する前に確認します。どちらの場合も、削除は 10 秒間元に戻せます |
| **デフォルトフォルダ名** | New Folder | 新しいフォルダに最初に入る名前 |
| **最近のフォルダ** | オン | ポップアップと右クリックメニューに、最近使ったフォルダを表示します |
| **最近のフォルダ最大数** | 5 | 表示する最近のフォルダの数 |

[保存と整理](/guides/save-and-organize)をご覧ください。

## 詳細設定 [#advanced]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **ポップアップ幅** | 400 px | ブラウザの上限は 800 px です |
| **ポップアップ高さ** | 500 px | ブラウザの上限は 600 px です |
| **文字数制限** | 50 文字 | ポップアップの AI の提案のヘッダーに表示するページタイトルを短くします |

## AI [#ai]

AI は初期設定でオフです。これらの設定は、**AI機能** をオンにした後にだけ意味を持ちます。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **AI機能** | オフ | AI ツールとポップアップのフォルダの提案をオンにします。Firefox では、オンにすると、AI プロバイダーが必要とするデータの共有について同意を求めます |
| **起動時に自動提案** | オフ | ポップアップを開くたびにフォルダの提案をリクエストします |
| **ページの内容を読む** | オフ | フォルダの提案、自動タグ付け、コンテンツ要約に、タイトルと URL だけでなく各ページの本文も送信します。オンにするとウェブサイトへのアクセス許可を求めます |
| **AIプロバイダー** と **AIモデル** | OpenAI、GPT-4o Mini | すべての AI ツールが使うプロバイダーとモデル |
| **最大候補数** | 5 | リクエストするフォルダの提案の最大数 |
| **最大カテゴリ数** | 制限なし | 再整理プランで作成できるトップレベルフォルダの最大数 |
| **フォルダあたりの最小件数** と **フォルダあたりの最大件数** | 1 と制限なし | 再整理プランで目指すフォルダの大きさ |

その下のプロバイダーのパネルには、**APIキー**、**ベースURL**、**カスタムモデル**、**追加ヘッダー（JSON）** と、**サービスを確認**、**モデルを更新** があります。フォルダの上限は指示としてプロバイダーに送られ、プロバイダーの出力がそれに従っているかどうかは確認されません。[AI ツールの設定](/guides/ai-tools)をご覧ください。

## AIツール [#ai-tools]

各ツールには **有効化** スイッチがあります（初期設定でオン）。オフにすると、マネージャーの **ツール** サイドバーに表示されなくなります。

| ツール | 設定と初期値 |
| --- | --- |
| **AIコンテキストパッカー** | **出力形式** Markdown、**フォルダパスを含める**、**日付を含める**、**保存済みタグを含める**、**保存済み要約を含める** はオン、**最大件数** 200、**最大階層** 8、**抜粋の長さ** 240 |
| **自動タグ付け** | **最小タグ数** 2、**最大タグ数** 5、**タグのスタイル** kebab-case、**統合モード** 追加、**重複タグを削除** オン |
| **コンテンツ要約** | **要約の長さ** 160、**ドメインのヒントを含める** オン、**統合モード** 置換 |
| **AIフォルダ整理** | **常に先にプレビュー** オン、**最小信頼度** 0.55（これを下回る移動は除外されます）、**バッチサイズ** 1 リクエストあたり 100 件のブックマーク |

自動タグ付けとコンテンツ要約は、**既定の範囲** の設定にかかわらず、常に現在のフォルダを対象にします。

## メンテナンス [#maintenance]

| ツール | 設定と初期値 |
| --- | --- |
| **重複クリーナー** | **照合方法** 正規化したURL、**wwwを正規化**、**プロトコルを無視**、**末尾のスラッシュを無視** はオン、**保持ルール** 最も古いもの、**最大グループ数** 500。常にすべてのブックマークをスキャンします |
| **URLクリーナー** | **フラグメントを削除** オフ、**クエリパラメータを並べ替え** と **クエリパラメータの重複を削除** はオン、**保持するパラメータ** と **削除するパラメータ** のリスト |
| **リンク切れチェック** | **リクエストのタイムアウト** 8000 ms、**同時実行数** 4、**再試行回数** 1、**リダイレクトをたどる** オン、**成功とみなすステータスコード** 200, 201, 202, 204, 301, 302, 307, 308 |

**削除するパラメータ** などのリストには、カンマ区切りで値を入力します。初期設定のリストは[重複とトラッキング URL のクリーンアップ](/guides/clean-up#strip-tracking-parameters)に記載しています。[リンク切れの検出と修復](/guides/dead-links)もご覧ください。

## メタデータと内容 [#metadata--content]

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **メタデータ取得を有効化** | オン | ツール サイドバーに **メタデータ取得** を表示します |
| **タイトルを上書き** | オフ | すでにタイトルがあるブックマークにも新しいタイトルを提案します |
| **説明を取得** | オン | 確認画面にページの説明を表示します。説明が保存されることはありません |
| **リクエストのタイムアウト** | 8000 ms | 1 ページあたり。**サイトアイコンを更新** でも使われます |
| **同時実行数** | 4 | 同時にリクエストするページの数。**サイトアイコンを更新** でも使われます |
| **サイトアイコンの更新を有効化** | オン | ツール サイドバーに **サイトアイコンを更新** を表示します |
| **既定の範囲** | 現在のフォルダ | サイトアイコンの更新で最初に選ばれている範囲 |
| **優先するアイコンサイズ** | 32px | ページに複数のアイコンがある場合、このサイズに最も近いものをダウンロードします |
| **アイコンファイルの最大サイズ** | 64 KB | これより大きいアイコンファイルはダウンロードも保存もしません |
| **アイコンの保存容量上限** | 4096 KB | このデバイスに保存するアイコンの合計サイズ。古いものから削除されます |
