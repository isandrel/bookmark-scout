이 페이지는 요약본입니다. 실제로 적용되는 것은 웹사이트에 있는 전체 <SiteLink to="privacy">개인정보 처리방침</SiteLink>이며, <PrivacyEffectiveDate />부터 시행되었습니다.

## 요약 [#in-short]

- **계정도 서버도 없습니다.** Bookmark Scout는 브라우저 안에서 실행됩니다. 개발자는 확장 프로그램으로부터 아무것도 받지 않습니다.
- **원격 측정이 없습니다.** 확장 프로그램에는 분석, 오류 보고, 광고가 없습니다.
- **AI는 직접 켜기 전까지 꺼져 있으며**, 켠 뒤의 요청은 브라우저에서 내가 고른 제공업체로 바로 전송됩니다. Firefox에서는 켤 때 해당 데이터를 공유하는 데 동의할지도 묻습니다.
- **권한은 필요할 때만 요청합니다.** 설치할 때는 확장 프로그램이 동작하는 데 꼭 필요한 권한만 요청하며, 탭 접근, 마우스 오른쪽 버튼 메뉴, 브라우저의 아이콘 캐시, 웹사이트 접근 권한은 해당 기능을 처음 사용할 때 요청합니다. [권한](/permissions)을 참고하세요.

## 확장 프로그램이 읽는 정보 [#what-the-extension-reads]

- 북마크: 표시, 검색, 편집, 이동, 삭제, 가져오기, 내보내기를 위해 읽습니다.
- 활성 탭의 제목과 URL: 보고 있는 페이지를 저장하거나 폴더 추천을 요청할 때 읽습니다.
- 브라우저 자체 아이콘 캐시의 사이트 아이콘: Chrome과 Edge에서 **브라우저 아이콘 캐시 사용**을 켠 경우에 읽습니다.
- **사이트 아이콘 새로 고침**으로 북마크한 각 웹사이트에서 내려받은 사이트 아이콘.

방문하는 페이지의 내용은 읽지 않습니다.

## 저장하는 정보 [#what-it-stores]

| 데이터 | 저장 위치 | 동기화 |
| --- | --- | --- |
| 설정(AI 사용 여부, 선택한 제공업체와 모델 포함) | 브라우저 동기화 저장소 | 예. 브라우저 동기화가 켜져 있으면 브라우저 계정을 통해 동기화 |
| 관리자의 북마크 표 레이아웃 | 브라우저 동기화 저장소 | 설정과 같음 |
| AI 제공업체 설정: API 키, 기본 URL, 추가 헤더 | 이 기기의 로컬 저장소 | 아니요 |
| 태그, 요약, 저장된 검색, 최근 폴더, 최근 검색 | 이 기기의 로컬 저장소 | 아니요 |
| **사이트 아이콘 새로 고침**으로 저장한 사이트 아이콘(기본값 최대 4096 KB) | 이 기기의 로컬 저장소 | 아니요 |

**도구** 사이드바의 검사 결과는 해당 대화 상자가 열려 있는 동안에만 보관됩니다. 확장 프로그램을 제거하면 저장된 데이터도 삭제되며, 북마크는 브라우저에 그대로 남습니다.

## 데이터가 브라우저 밖으로 나가는 경우 [#when-data-leaves-your-browser]

다음 기능 중 하나를 사용할 때만, 그리고 명시된 곳으로만 전송됩니다.

| 기능 | 전송 대상 | 전송되는 내용 |
| --- | --- | --- |
| AI 폴더 추천 | 설정한 AI 제공업체 | 현재 페이지의 제목과 URL, 폴더 이름. **페이지 내용 읽기**가 켜져 있으면 페이지 본문도 전송 |
| 자동 태그 지정, 콘텐츠 요약, AI 폴더 재구성 | 설정한 AI 제공업체 | 대상 범위에 있는 북마크의 제목, URL, 폴더 경로. **페이지 내용 읽기**가 켜져 있으면 자동 태그 지정과 콘텐츠 요약은 각 페이지의 본문도 전송하며, AI 폴더 재구성은 전송하지 않음 |
| AI에게 묻기 | 설정한 AI 제공업체 | 내 메시지와 지금까지의 대화, 그리고 AI가 답하기 위해 조회하는 내용: 일치하는 북마크, 폴더 이름, 현재 페이지의 제목과 URL, **페이지 내용 읽기**가 켜져 있으면 AI가 읽는 페이지의 텍스트. 웹 검색을 켜면 제공업체가 웹도 검색함. 대화는 저장되지 않음 |
| 깨진 링크 확인, 메타데이터 가져오기 | 북마크한 각 웹사이트 | 웹사이트 접근을 허용한 뒤, 쿠키 없이 보내는 페이지 요청 |
| 사이트 아이콘 새로 고침 | 북마크한 각 웹사이트 | 웹사이트 접근을 허용한 뒤, 쿠키 없이 사이트당 북마크한 페이지 하나와 그 사이트 도메인의 아이콘 파일을 요청. 타사 아이콘 서비스는 사용하지 않음 |

Ollama처럼 내 컴퓨터에서 실행되는 제공업체를 사용하면 AI 요청이 내 컴퓨터 밖으로 나가지 않습니다. **AI 컨텍스트 패커**를 포함한 내보내기는 내 컴퓨터에 파일로 저장되며 어디에도 업로드되지 않습니다. 개인정보 검토 단계에서 민감한 값을 먼저 가릴 수 있습니다. 각 AI 도구가 보내는 데이터는 [AI 도구 설정](/guides/ai-tools#what-each-tool-sends)에, 각 권한에 대한 설명은 [권한](/permissions)에 있습니다.

## 이 문서 사이트 [#this-docs-site]

이 문서는 정적 사이트이며, 자체 분석, 계정, 쿠키가 없습니다. 글꼴은 Google Fonts가 아니라 이 사이트에서 제공됩니다. 호스팅 업체는 개인정보 처리방침에 명시되어 있습니다.
