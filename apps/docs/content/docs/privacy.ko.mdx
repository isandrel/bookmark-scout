## 요약 [#in-short]

- **계정도 서버도 없습니다.** Bookmark Scout는 브라우저 안에서 실행됩니다. 개발자는 확장 프로그램으로부터 아무것도 받지 않습니다.
- **원격 측정이 없습니다.** 확장 프로그램에는 분석, 오류 보고, 광고가 없습니다.
- **AI는 직접 켜기 전까지 꺼져 있으며**, 켠 뒤의 요청은 브라우저에서 내가 고른 제공업체로 바로 전송됩니다. Firefox에서는 켤 때 해당 데이터를 공유하는 데 동의할지도 묻습니다. Chrome의 내장 AI를 사용하면 폴더 추천이 내 컴퓨터 밖으로 나가지 않습니다.
- **로컬 AI 에이전트는 허용한 경우에만.** **로컬 AI 에이전트 허용**을 켜면(기본값: 꺼짐) 컴퓨터의 AI 에이전트(Claude Code 등)가 bookmark-scout-mcp 프로그램을 통해 북마크를 조회할 수 있으며, **변경 허용**을 켠 경우에만 변경할 수 있고, 각 변경은 승인한 뒤에 이루어집니다.
- **권한은 필요할 때만 요청합니다.** 설치할 때는 확장 프로그램이 동작하는 데 꼭 필요한 권한만 요청하며, 탭 접근, 마우스 오른쪽 버튼 메뉴, 브라우저의 아이콘 캐시, 웹사이트 접근 권한은 해당 기능을 처음 사용할 때 요청합니다. [권한](/permissions)을 참고하세요.

## 확장 프로그램이 읽는 정보 [#what-the-extension-reads]

- 북마크: 표시, 검색, 편집, 이동, 삭제, 가져오기, 내보내기를 위해 읽습니다.
- 활성 탭의 제목과 URL: 보고 있는 페이지를 (팝업, 사이드 패널, 빠른 저장 단축키로) 저장하거나 폴더 추천을 요청할 때 읽습니다.
- 브라우저 자체 아이콘 캐시의 사이트 아이콘: Chrome과 Edge에서 **브라우저 아이콘 캐시 사용**을 켠 경우에 읽습니다.
- **사이트 아이콘 새로 고침**으로 북마크한 각 웹사이트에서 내려받은 사이트 아이콘.
- 북마크한 페이지의 본문(**페이지 본문 색인**을 실행할 때, 실행 범위의 각 페이지에서).
- 북마크한 페이지의 머리 부분과 각 페이지가 지정한 미리 보기 이미지(**표지 가져오기**를 실행할 때, 실행 범위의 각 페이지에서).

방문하는 페이지의 내용은 읽지 않습니다. 빠른 저장 단축키를 누른 뒤에는 그 탭에 자체 알림을 표시하며, 이 알림은 페이지에서 아무것도 읽지 않습니다.

**도구** 사이드바의 검사 결과는 해당 대화상자가 열려 있는 동안에만 보관됩니다. 확장 프로그램을 제거하면 저장된 데이터도 삭제되며, 북마크는 브라우저에 그대로 남습니다.

설정 페이지 아래쪽의 **설정 백업**은 변경한 설정, 사용자 지정 프롬프트, 내 소개, AI 서비스(이름, 제공업체, 모델, 기본 URL, 제공업체별 항목), 저장된 검색, 스마트 규칙, 표의 열과 정렬을 백업 파일로 저장합니다. API 키와 추가 헤더는 절대 들어가지 않으며, 파일은 암호화되지 않습니다. [설정](/settings)을 참고하세요.

## 데이터가 브라우저 밖으로 나가는 경우 [#when-data-leaves-your-browser]

다음 기능 중 하나를 사용할 때만, 그리고 명시된 곳으로만 전송됩니다.

| 기능 | 전송 대상 | 전송되는 내용 |
| --- | --- | --- |
| AI 폴더 추천(AI 빠른 저장 단축키 포함) | 설정한 AI 제공업체 | 현재 페이지의 제목과 URL, 폴더 이름. **페이지 내용 읽기**가 켜져 있으면 페이지 본문도 전송 |
| 자동 태그 지정, 콘텐츠 요약, AI 폴더 재구성 | 설정한 AI 제공업체 | 대상 범위에 있는 북마크의 제목, URL, 폴더 경로. **페이지 내용 읽기**가 켜져 있으면 자동 태그 지정과 콘텐츠 요약은 각 페이지의 본문도 전송하며, AI 폴더 재구성은 전송하지 않음. 자동 태그 지정은 **기존 태그 보내기**를 끄지 않으면 자주 쓰는 태그 이름도 보냄 |
| AI에게 묻기 | 설정한 AI 제공업체 | 내 메시지와 지금까지의 대화, 그리고 AI가 답하기 위해 조회하는 내용: 일치하는 북마크(폴더, 추가한 날짜, 태그, 요약 포함), 폴더 이름, 현재 페이지의 제목과 URL, AI가 확인한 북마크 링크가 아직 작동하는지 여부, **페이지 내용 읽기**가 켜져 있으면 AI가 읽는 페이지의 텍스트. 웹 검색을 켜면 제공업체가 웹도 검색함. 대화는 저장되지 않음 |
| 깨진 링크 확인, 메타데이터 가져오기, AI에게 묻기의 링크 확인 | 북마크한 각 웹사이트 | 웹사이트 접근을 허용한 뒤, 쿠키 없이 보내는 페이지 요청 |
| 사이트 아이콘 새로 고침 | 북마크한 각 웹사이트 | 웹사이트 접근을 허용한 뒤, 쿠키 없이 사이트당 북마크한 페이지 하나와 그 사이트 도메인의 아이콘 파일을 요청. 타사 아이콘 서비스는 사용하지 않음 |
| 페이지 본문 색인 | 실행 범위의 각 북마크 페이지 | 웹사이트 접근을 허용한 뒤 쿠키 없이 페이지를 요청합니다. 읽을 수 있는 본문은 이 기기에 남습니다 |
| 표지 가져오기 | 실행 범위의 각 북마크 페이지와 그 페이지가 지정한 이미지 | 허용한 사이트에서만 쿠키와 페이지 주소 없이 페이지의 머리 부분과 이미지를 요청합니다. 작은 복사본은 이 기기에 남습니다 |
| 로컬 AI 에이전트(**로컬 AI 에이전트 허용**을 켠 경우에만, 기본값: 꺼짐) | 컴퓨터의 bookmark-scout-mcp 프로그램과 그곳에서 실행하는 AI 에이전트 | 에이전트가 요청한 것: 일치하는 북마크(폴더, 추가한 날짜, 태그, 요약 포함), 폴더 이름, 현재 페이지의 제목과 URL, 북마크한 링크가 아직 작동하는지 여부(웹사이트 접근을 허용한 뒤), 그리고 **페이지 내용 읽기**를 켠 경우 페이지 텍스트. 제목과 URL의 개인 값은 끄지 않는 한 숨겨집니다. 에이전트는 읽은 내용을 자체 AI 제공자에게 보낼 수 있습니다. **요청 기록**이 켜져 있는 동안 각 조회는 AI 활동에 남습니다 |

제공업체를 쓰는 모든 AI 기능은 **내 소개**(AI 설정)에 내용이 있으면 그것도 보냅니다. 기본값은 비어 있습니다.

Ollama처럼 내 컴퓨터에서 실행되는 제공업체를 사용하면 AI 요청이 내 컴퓨터 밖으로 나가지 않습니다. Chrome의 내장 AI도 마찬가지입니다. 폴더 추천을 내 컴퓨터의 Chrome 자체 모델로 실행하며 API 키를 쓰지 않습니다. 이 모델은 사용자가 요청할 때 Chrome이 Google에서 한 번만 다운로드하며, 사용자의 데이터는 포함되지 않습니다. 북마크 내보내기, **AI 컨텍스트 패커** 파일, 설정 백업은 내 컴퓨터에 파일로 저장되며 어디에도 업로드되지 않습니다. JSON 형식의 북마크 내보내기에는 각 북마크의 태그와 요약도 들어갑니다. 북마크와 AI 컨텍스트 내보내기는 개인정보 검토 단계에서 민감한 값을 먼저 가릴 수 있습니다. 각 AI 도구가 보내는 데이터는 [AI 도구 설정](/guides/ai-tools#what-each-tool-sends)에, 각 권한에 대한 설명은 [권한](/permissions)에 있습니다.

## 이 문서 사이트 [#this-docs-site]

이 문서는 정적 사이트이며, 자체 분석, 계정, 쿠키가 없습니다. 글꼴은 Google Fonts가 아니라 이 사이트에서 제공됩니다. 호스팅 업체는 개인정보 처리방침에 명시되어 있습니다.
