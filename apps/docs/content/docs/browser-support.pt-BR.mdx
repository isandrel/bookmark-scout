title: Compatibilidade com navegadores
description: O que funciona no Chrome, no Microsoft Edge e no Firefox, o que é testado em cada um e por que o Safari não é compatível.
---

O Chrome é o navegador principal. O Edge é baseado no Chromium e tem os mesmos recursos, exceto nos casos indicados abaixo. O Firefox usa uma versão Manifest V2 com um conjunto menor de recursos.

## Tabela de recursos [#feature-matrix]

Esta tabela vem dos manifestos da extensão compilada para cada navegador.

## O que é testado [#what-is-tested]

- **Chrome (Chromium)**: testes de unidade e testes de ponta a ponta para o pop-up, o painel lateral, o gerenciador, as configurações, as ferramentas de manutenção, os relatórios, a importação e a exportação, os atalhos de teclado, as pesquisas salvas, o salvamento pelo menu de contexto, o arrastar e soltar, as ferramentas de rede e as ferramentas de IA com provedores simulados.
- **Edge**: o mesmo conjunto de testes de ponta a ponta é executado na versão para o Edge.
- **Firefox**: um conjunto de testes básicos (smoke tests) cobre a pesquisa e a criação de pastas no pop-up, a página do painel lateral carregada em uma guia, a abertura do gerenciador pelo pop-up e pelo painel lateral, a página do gerenciador, o salvamento de uma configuração, uma exportação e importação de JSON de ida e volta, os relatórios de estatísticas e de privacidade e os ícones dos sites salvos no pop-up. Menus de contexto, arrastar e soltar, atalhos de teclado e as ferramentas de rede e de IA (incluindo o próprio **Atualizar ícones dos sites**) não são cobertos.

O conjunto do Edge e o conjunto de testes básicos do Firefox são verificações obrigatórias da CI, assim como o conjunto do Chromium. Os provedores de IA reais e os sites ativos são verificados manualmente, não por testes automatizados.

## Safari [#safari]

O Safari não é compatível. As Safari Web Extensions não implementam a API `bookmarks`, da qual todas as partes do Bookmark Scout dependem.
