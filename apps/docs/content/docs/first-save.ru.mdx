---

Это займёт около минуты. Вам понадобятся Chrome на компьютере и хотя бы одна папка закладок.

<Steps>
<Step>
### Добавьте Bookmark Scout в Chrome [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

На странице расширения нажмите **Установить**, затем **Установить расширение**. Chrome запросит только одно разрешение: просмотр и изменение закладок. После этого в новой вкладке откроется страница **Bookmark Scout готов к работе** с кратким изложением шагов ниже; на ней показаны клавиши, которые на самом деле получило быстрое сохранение. Пользуетесь Firefox или Edge? См. [Установка](/installation#firefox-and-edge).
</Step>
<Step>
### Закрепите значок [#pin-the-icon]

Нажмите кнопку **Расширения** со значком пазла в правой части панели инструментов Chrome, затем значок булавки рядом с Bookmark Scout. Теперь его значок всегда на панели инструментов, в одном нажатии.
</Step>
<Step>
### Сохраните открытую страницу [#save-the-page-you-are-on]

Откройте любую страницу, которую хотите сохранить, и нажмите на значок Bookmark Scout. Строка под полем поиска, **Сохраняемая страница**, показывает название страницы.

Введите часть названия папки, например `fin` для папки Fine-tuning. Подходящие папки появятся в разделе **Сохранить в папку**, начиная с лучшего совпадения. Первая выделена: нажмите `Enter`, чтобы сохранить туда, или нажмите на любую папку. Сообщение **Закладка добавлена** подтверждает сохранение.
</Step>
<Step>
### В следующий раз нажмите одну клавишу [#next-time-press-one-key]

На любой странице нажмите <Shortcut id="commands.quick-save" />. Bookmark Scout сохранит страницу в самую подходящую папку, ничего не открывая. Небольшое сообщение в углу страницы покажет, куда она попала. Нажмите в нём **Отменить**, чтобы отменить сохранение, или выберите другую папку в разделе **Переместить в**.
</Step>
</Steps>

## Если что-то не так [#if-something-is-different]

- **Нужной папки нет в списке.** Введите другую часть её названия или несколько букв из названия папки, в которой она лежит, например `llms fin`. Небольшая опечатка не помешает.
- **Клавиша ничего не делает.** Возможно, её уже использует другое расширение. Нажмите на значок Bookmark Scout: в строке **Сочетание клавиш для быстрого сохранения не задано** есть кнопка **Настроить**. См. [Сохранение с помощью сочетания клавиш](/guides/save-and-organize#quick-save).
- **Страница уже была сохранена.** Bookmark Scout не сохраняет её дважды; сообщение покажет, где она находится.
