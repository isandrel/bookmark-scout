Bookmark Scout 是免費的，不需要帳戶，也沒有廣告。它在電腦上的瀏覽器中執行，不適用於手機或平板電腦。

## 加到 Chrome [#add-it-to-chrome]

<Steps>
<Step>
<StoreListing browser="chrome" />

在商店資訊頁面上按一下「**加到 Chrome**」，然後按一下「**新增擴充功能**」。Chrome 只會要求一項權限：讀取和變更你的書籤。其他功能只有在你第一次使用時才會要求更多權限，並說明原因；請參閱「[權限](/permissions)」。
</Step>
<Step>
固定圖示：按一下工具列右側拼圖形狀的「**擴充功能**」按鈕，然後按一下 Bookmark Scout 旁的圖釘。
</Step>
<Step>
儲存第一個網頁：請參閱「[第一次儲存](/first-save)」。
</Step>
</Steps>

加入後，新分頁中會立即開啟一個標題為「**Bookmark Scout 已準備就緒**」的頁面，列出相同的入門步驟：固定圖示、儲存網頁，以及快速儲存快捷鍵的按鍵 (如果其他擴充功能已經使用這些按鍵，則會顯示「**前往設定**」)。這個頁面只會在你第一次安裝 Bookmark Scout 時開啟一次，更新後絕不會再開啟。頁面上的「**閱讀指南**」會開啟「[儲存和整理](/guides/save-and-organize)」，「**開啟設定**」則會開啟「[設定](/settings)」。

從商店安裝的版本會自動更新。

在商店上架之前，你可以從 GitHub 手動安裝 Bookmark Scout，方法請見[下方說明](#install-from-a-github-release)。這需要多幾個步驟，而且在 Firefox 中每次重新啟動後都要再做一次。

## 安裝完成後 [#after-installing]

- 在任何網頁上按一下 Bookmark Scout 圖示，即可儲存網頁或搜尋書籤。建議從「[第一次儲存](/first-save)」開始。
- 在任何網頁上按 <Shortcut id="commands.quick-save" />，不必開啟任何視窗就能儲存網頁。請參閱「[用鍵盤快捷鍵儲存](/guides/save-and-organize#quick-save)」。
- 在 Chrome 中，Bookmark Scout 會以自己的書籤管理員取代瀏覽器的書籤頁面。你可以像以前一樣開啟它，例如按 <Shortcut id="browser.open_bookmarks_manager" />，或使用彈出式視窗中的「**開啟書籤管理員**」。它的「**工具**」側欄中有各種清理工具。
- 設定會在分頁中開啟：對工具列圖示按一下滑鼠右鍵，然後選擇「**選項**」。請參閱「[設定](/settings)」。

## 更新 [#updating]

從商店安裝的版本會自動更新，而且更新會保留你的設定。過去只有一次更新 (更新至 0.3.3 版) 是例外：它曾重設一次 Bookmark Scout 自己儲存的資料，但從未動到你的書籤；請參閱「[常見問題](/faq#my-settings-are-gone-after-an-update)」。

如要隨時保留一份設定、自訂提示詞、AI 服務和已儲存搜尋的副本，請使用「[設定](/settings)」底部的「**備份設定**」。

## 進階：從 GitHub 手動安裝 [#install-from-a-github-release]

只有在你所用瀏覽器的商店尚未上架 Bookmark Scout，或想測試某個版本時，才需要使用這個方法。以這種方式安裝的版本不會自動更新：如要更新，請下載較新的版本，然後重複這些步驟。

每個 <RepoLink path="/releases">GitHub 版本發布</RepoLink>都為各瀏覽器提供一個下載檔案：

| 瀏覽器 | 檔案 |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` 或 `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

請從<ReleaseLink />下載，然後依照所用瀏覽器的步驟操作。

<Tabs items={["Chrome", "Edge", "Firefox"]}>
<Tab value="Chrome" id="chrome">

<Steps>
<Step>
下載 `bookmark-scout-<version>-chrome.crx` 或 `bookmark-scout-<version>-chrome.zip`。如果使用 ZIP 檔，請解壓縮到會長期保留的資料夾，因為 Chrome 會從該資料夾載入擴充功能。
</Step>
<Step>
開啟 `chrome://extensions/`，然後開啟右上角的「**開發人員模式**」。
</Step>
<Step>
將 CRX 檔案拖曳到頁面上，或按一下「**載入未封裝項目**」並選取解壓縮後的資料夾。
</Step>
<Step>
從拼圖形狀的「擴充功能」選單將 Bookmark Scout 固定到工具列。
</Step>
</Steps>

</Tab>
<Tab value="Edge" id="edge">

<Steps>
<Step>
下載 `bookmark-scout-<version>-edge.zip`，並解壓縮到會長期保留的資料夾。
</Step>
<Step>
開啟 `edge://extensions/`，然後開啟「**開發人員模式**」。
</Step>
<Step>
按一下「**載入解壓縮**」，然後選取解壓縮後的資料夾。
</Step>
<Step>
從拼圖形狀的「擴充功能」選單，讓 Bookmark Scout 顯示在工具列上 (按一下它旁邊的眼睛圖示)。
</Step>
</Steps>

</Tab>
<Tab value="Firefox" id="firefox">

<Steps>
<Step>
下載 `bookmark-scout-<version>-firefox.zip` 並解壓縮。
</Step>
<Step>
開啟 `about:debugging#/runtime/this-firefox`。
</Step>
<Step>
按一下「**載入暫用附加元件**」，然後選取解壓縮後的 `manifest.json` 檔案。
</Step>
</Steps>

<Callout type="warn" title="Firefox 的限制">
Firefox 重新啟動時會移除暫用附加元件，因此每次重新啟動後都要再載入一次。暫用附加元件不會開啟「**Bookmark Scout 已準備就緒**」頁面。Firefox 也無法取代其書籤頁面，因此請從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員 (包含工具、已儲存的搜尋以及匯入和匯出功能)。請參閱「[瀏覽器支援](/browser-support)」。
</Callout>

</Tab>
</Tabs>
