# Project Status

This page summarizes the current repository status so roadmap docs do not drift from the implementation.

## Implemented

- Browser extension built with WXT, React, TypeScript, Zustand, Radix/shadcn UI primitives, and browser bookmark APIs
- Chrome primary target with Firefox and Edge build targets
- Popup bookmark search, folder filtering, drag-and-drop organization, quick add, folder creation, and expand/collapse controls
- Deletion from the popup, side panel, and manager with a confirmation dialog (on by default, optional in Settings) and a 10-second Undo that restores the subtree and its saved tags and summaries
- Chrome side panel entrypoint
- Custom bookmarks page override with folder tree, breadcrumbs, bookmark table, and tools sidebar
- Configurable date-added, natural alphabetical, and folders-first ordering without mutating stored bookmark order
- Options page with settings for appearance, language, search, behavior, advanced UI sizing, AI, AI tools, maintenance, metadata, security, analytics, data, and context menus
- Settings persisted through `chrome.storage.sync`
- AI providers from config: OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, OpenRouter, Ollama, CLIProxyAPI, and custom OpenAI-compatible endpoints
- AI folder recommendations, including reviewed creation of a suggested new folder path that saves the current page there
- AI context packing with saved tags and summaries, tag suggestions, summaries, and folder reorganization (previewed before applying by default)
- Bookmark maintenance tools for duplicate cleanup, URL cleanup, dead-link scanning, metadata fetching (reviewed titles are applied; descriptions are preview-only), privacy scanning, and statistics
- Privacy review with optional redaction before bookmark exports and AI context exports
- Bookmark import from HTML or JSON, with a preview of the target folder, counts, and duplicates, a duplicate-handling choice, and undo
- Bookmark export to HTML, JSON, Markdown, or CSV
- Right-click context menu save flow for links
- English, Japanese, and Korean extension locales
- Localized marketing site in English, Japanese, and Korean
- Fumadocs documentation site
- Unit tests and unattended Chromium E2E tests for popup, manager, settings, maintenance, reports, import/export, route-mocked and local-server network tools, and mocked-provider AI tools
- A settings-to-behavior matrix (`apps/extension/tests/settings-matrix.ts`) that maps every setting to the code that reads it and a test that changes it

## Partial

- Bookmark tags and summaries: editable in Bookmark Details and saved from reviewed AI suggestions, but stored only in local extension storage. They are not synced, searchable, or included in bookmark exports.
- AI tool limits (tag count and style, summary length, reorganization folder limits) are sent to the provider as instructions; the output is not checked against them. Live provider compatibility is verified manually.
- Firefox and Edge receive build validation only; browser E2E tests run in Chromium. Firefox has no side panel.
- Four tool scope settings are fixed: Auto-Tagging and Content Summarizer always use the current folder; Duplicate Cleaner and Privacy Scanner always scan all bookmarks.

## Planned

- Keyboard shortcuts for faster navigation and actions
- Saved searches and smart bookmark views
- Reviewed repair for dead links
- Firefox and Edge browser tests, and automated context-menu and drag-and-drop flows
- Store listing polish for Chrome Web Store, Firefox Add-ons, and Edge Add-ons

## Known Documentation Rules

- Update docs when feature status, installation paths, browser support, privacy expectations, or configuration changes.
- AI features are opt-in and may send bookmark data to the selected provider.
- CI runs extension unit and Chromium browser tests without manual setup. Firefox and Edge currently receive build validation.
