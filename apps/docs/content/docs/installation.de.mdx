Bookmark Scout ist kostenlos und Open Source.

## Aus dem Store Ihres Browsers installieren [#install-from-your-browsers-store]

<StoreAvailability />

Öffnen Sie den Eintrag und fügen Sie Bookmark Scout von dort zu Ihrem Browser hinzu. Eine aus einem Store installierte Kopie aktualisiert sich selbst.

## Aus einem GitHub-Release installieren [#install-from-a-github-release]

Wenn der Store Ihres Browsers Bookmark Scout noch nicht führt, installieren Sie die Erweiterung aus einem <RepoLink path="/releases">GitHub-Release</RepoLink>, das einen Download pro Browser enthält:

| Browser | Datei |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` oder `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

Laden Sie die Datei aus <ReleaseLink /> herunter und folgen Sie dann den Schritten für Ihren Browser.

<Callout type="warn" title="Einschränkungen in Firefox">
Firefox entfernt temporäre Add-ons beim Neustart, daher müssen Sie die Erweiterung nach jedem Neustart erneut laden. Außerdem kann Firefox seine Lesezeichenseite nicht ersetzen. Öffnen Sie den Lesezeichen-Manager (mit Tools, gespeicherten Suchen sowie Import und Export) daher über **Lesezeichen-Manager öffnen** im Pop-up. Siehe [Browserunterstützung](/browser-support).
</Callout>

## Nach der Installation [#after-installing]

- Klicken Sie auf das Bookmark-Scout-Symbol, um das Pop-up zu öffnen und Ihre Lesezeichen zu durchsuchen. Beginnen Sie mit [Suche und gespeicherte Suchen](/guides/search).
- Öffnen Sie in Chrome die Lesezeichenseite des Browsers (zum Beispiel mit `Ctrl+Shift+O` oder unter macOS mit `Cmd+Option+B`), um zum Bookmark-Scout-Manager und seiner Tools-Leiste zu gelangen.
- Die Einstellungen öffnen sich in einem Tab über den Eintrag **Optionen** der Erweiterung, in Chrome zum Beispiel per Rechtsklick auf das Symbol in der Symbolleiste. Siehe [Einstellungen](/settings).

## Aktualisieren [#updating]

Eine aus einem Store installierte Kopie aktualisiert sich selbst. Andernfalls laden Sie die neuere Version aus <ReleaseLink /> herunter und wiederholen die Schritte für Ihren Browser.

Vor einem Update können Sie Ihre Einstellungen, eigenen Prompts, KI-Dienste und gespeicherten Suchen mit **Exportieren** unten in den [Einstellungen](/settings) sichern; ein bestimmtes Update setzt sie zurück, siehe [die FAQ](/faq#my-settings-are-gone-after-an-update).

## Aus dem Quellcode erstellen [#building-from-source]

Um an Bookmark Scout mitzuarbeiten, erstellen Sie die Erweiterung selbst: Folgen Sie [Mitwirken und Entwicklung](/contributing#build-from-source).
