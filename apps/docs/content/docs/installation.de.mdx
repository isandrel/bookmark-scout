Bookmark Scout ist kostenlos, ohne Konto und ohne Werbung. Es läuft in einem Browser auf einem Computer, nicht auf Smartphones oder Tablets.

## Zu Chrome hinzufügen [#add-it-to-chrome]

<Steps>
<Step>
<StoreListing browser="chrome" />

Klicken Sie im Store-Eintrag auf **Zu Chrome hinzufügen** und dann auf **Erweiterung hinzufügen**. Chrome fragt nur nach einer Sache: Ihre Lesezeichen lesen und ändern zu dürfen. Andere Funktionen fragen erst bei der ersten Verwendung nach mehr und erklären, warum; siehe [Berechtigungen](/permissions).
</Step>
<Step>
Heften Sie das Symbol an: Klicken Sie rechts in der Symbolleiste auf die Schaltfläche **Erweiterungen** mit dem Puzzleteil und dann auf die Stecknadel neben Bookmark Scout.
</Step>
<Step>
Speichern Sie Ihre erste Seite: siehe [Ihr erstes Lesezeichen](/first-save).
</Step>
</Steps>

Direkt nach dem Hinzufügen öffnet sich in einem neuen Tab eine Seite mit dem Titel **Bookmark Scout ist bereit**, mit denselben ersten Schritten: das Symbol anheften, eine Seite speichern, und die Tasten Ihres Tastenkürzels zum Schnellspeichern (oder **Einrichten**, wenn eine andere Erweiterung sie bereits verwendet). Sie öffnet sich nur einmal, wenn Sie Bookmark Scout zum ersten Mal installieren, nie nach einem Update. **Anleitung lesen** darauf öffnet [Speichern und ordnen](/guides/save-and-organize), und **Einstellungen öffnen** öffnet die [Einstellungen](/settings).

Eine Kopie aus dem Store aktualisiert sich selbst.

## Nach der Installation [#after-installing]

- Klicken Sie auf einer beliebigen Seite auf das Bookmark-Scout-Symbol, um sie zu speichern oder Ihre Lesezeichen zu durchsuchen. Beginnen Sie mit [Ihr erstes Lesezeichen](/first-save).
- Drücken Sie auf einer beliebigen Seite <Shortcut id="commands.quick-save" />, um sie zu speichern, ohne etwas zu öffnen. Siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save).
- In Chrome ersetzt Bookmark Scout die Lesezeichenseite des Browsers durch seinen eigenen Lesezeichen-Manager. Öffnen Sie ihn wie bisher, zum Beispiel mit <Shortcut id="browser.open_bookmarks_manager" />, oder mit **Lesezeichen-Manager öffnen** im Pop-up. Seine Seitenleiste **Tools** enthält die Werkzeuge zum Bereinigen.
- Die Einstellungen öffnen sich in einem Tab: Klicken Sie mit der rechten Maustaste auf das Symbol in der Symbolleiste und wählen Sie **Optionen**. Siehe [Einstellungen](/settings).

## Aktualisieren [#updating]

Eine aus einem Store installierte Kopie aktualisiert sich selbst, und Updates behalten Ihre Einstellungen. Ein früheres Update, auf Version 0.3.3, war eine Ausnahme: Es hat die eigenen gespeicherten Daten von Bookmark Scout einmal zurückgesetzt, Ihre Lesezeichen aber nie; siehe [die FAQ](/faq#my-settings-are-gone-after-an-update).

Um jederzeit eine Kopie Ihrer Einstellungen, eigenen Prompts, KI-Dienste und gespeicherten Suchen zu behalten, verwenden Sie **Einstellungen sichern** unten in den [Einstellungen](/settings).

## Fortgeschritten: von Hand aus GitHub installieren [#install-from-a-github-release]

Verwenden Sie diesen Weg nur, wenn der Store Ihres Browsers Bookmark Scout noch nicht führt, oder um ein Release zu testen. Eine so installierte Kopie aktualisiert sich nicht selbst: Laden Sie für ein Update das neuere Release herunter und wiederholen Sie die Schritte.

Jedes <RepoLink path="/releases">GitHub-Release</RepoLink> enthält einen Download pro Browser:

| Browser | Datei |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` oder `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

Laden Sie die Datei aus <ReleaseLink /> herunter und folgen Sie dann den Schritten für Ihren Browser.

<Tabs items={["Chrome", "Edge", "Firefox"]}>
<Tab value="Chrome" id="chrome">

<Steps>
<Step>
Laden Sie `bookmark-scout-<version>-chrome.crx` oder `bookmark-scout-<version>-chrome.zip` herunter. Wenn Sie die ZIP-Datei verwenden, entpacken Sie sie in einen Ordner, den Sie behalten, denn Chrome lädt die Erweiterung aus diesem Ordner.
</Step>
<Step>
Öffnen Sie `chrome://extensions/` und aktivieren Sie den **Entwicklermodus** (oben rechts).
</Step>
<Step>
Ziehen Sie die CRX-Datei auf die Seite, oder klicken Sie auf **Entpackte Erweiterung laden** und wählen Sie den entpackten Ordner aus.
</Step>
<Step>
Heften Sie Bookmark Scout über das Puzzleteil-Menü **Erweiterungen** an die Symbolleiste an.
</Step>
</Steps>

</Tab>
<Tab value="Edge" id="edge">

<Steps>
<Step>
Laden Sie `bookmark-scout-<version>-edge.zip` herunter und entpacken Sie die Datei in einen Ordner, den Sie behalten.
</Step>
<Step>
Öffnen Sie `edge://extensions/` und aktivieren Sie den **Entwicklermodus**.
</Step>
<Step>
Klicken Sie auf **Entpackte Erweiterung laden** und wählen Sie den entpackten Ordner aus.
</Step>
<Step>
Zeigen Sie Bookmark Scout über das Puzzleteil-Menü **Erweiterungen** in der Symbolleiste an (das Augensymbol daneben).
</Step>
</Steps>

</Tab>
<Tab value="Firefox" id="firefox">

<Steps>
<Step>
Laden Sie `bookmark-scout-<version>-firefox.zip` herunter und entpacken Sie die Datei.
</Step>
<Step>
Öffnen Sie `about:debugging#/runtime/this-firefox`.
</Step>
<Step>
Klicken Sie auf **Temporäres Add-on laden…** und wählen Sie die entpackte Datei `manifest.json` aus.
</Step>
</Steps>

<Callout type="warn" title="Einschränkungen in Firefox">
Firefox entfernt temporäre Add-ons beim Neustart, daher laden Sie die Erweiterung nach jedem Neustart erneut. Die Seite **Bookmark Scout ist bereit** öffnet sich bei einem temporären Add-on nicht. Außerdem kann Firefox seine Lesezeichenseite nicht ersetzen. Öffnen Sie den Lesezeichen-Manager (mit Tools, gespeicherten Suchen sowie Import und Export) daher über **Lesezeichen-Manager öffnen** im Pop-up. Siehe [Browserunterstützung](/browser-support).
</Callout>

</Tab>
</Tabs>
