# Getting Started

Welcome to **Bookmark Scout** — a modern browser extension for managing your bookmarks, powered by AI folder recommendations.

## Installation

### From GitHub Releases

Download the latest release from [GitHub Releases](https://github.com/isandrel/bookmark-scout/releases).

### Load in Chrome

1. Download `bookmark-scout-*-chrome.crx` or `bookmark-scout-*-chrome.zip`
2. Open `chrome://extensions/`
3. Enable **Developer mode** (top right)
4. Drag the CRX into the page, or extract the ZIP and click **Load unpacked**
5. Select the extracted folder when using the ZIP

## Key Features

- 🤖 **AI Folder Recommendations** — Smart suggestions from OpenAI, Anthropic, or Google AI
- 🔍 **Instant Search** — Find bookmarks quickly
- 📂 **Drag & Drop** — Organize with ease
- ⚡ **Quick Add** — Save tabs with one click
- 📱 **Side Panel** — Access from Chrome's side panel
