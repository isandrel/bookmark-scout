# Getting Started

Welcome to **Bookmark Scout** — a browser extension for searching, organizing, cleaning up, importing/exporting, and saving bookmarks. It includes opt-in AI tools for recommendations, tagging, summaries, context packing, and folder reorganization.

## Installation

### From GitHub Releases

Download the latest release from [GitHub Releases](https://github.com/isandrel/bookmark-scout/releases). Release assets are published separately for Chrome, Firefox, and Edge.

### Load in Chrome

1. Download `bookmark-scout-*-chrome.crx` or `bookmark-scout-*-chrome.zip`
2. Open `chrome://extensions/`
3. Enable **Developer mode** (top right)
4. Drag the CRX into the page, or extract the ZIP and click **Load unpacked**
5. Select the extracted folder when using the ZIP

## Key Features

- 🔍 **Instant Search** — Find bookmarks quickly with folder filtering and debounced search
- 📂 **Drag & Drop** — Move bookmarks and folders directly in the extension
- ⚡ **Quick Add** — Save the current tab to a selected folder
- 🗂️ **Bookmarks Manager** — Replace the default Chrome bookmarks page with a custom table-based manager
- 🧰 **Maintenance Tools** — Clean duplicate bookmarks, tracking URLs, dead links, metadata, privacy issues, and statistics
- 📤 **Import/Export** — Export HTML, JSON, Markdown, or CSV and import HTML or JSON
- 🤖 **Opt-in AI Tools** — Use configured providers for recommendations, tagging, summaries, context packing, and reorganization plans
