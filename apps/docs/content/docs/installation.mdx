---
title: Install
description: Install Bookmark Scout in Chrome, Microsoft Edge, or Firefox from a GitHub release.
---

Bookmark Scout is free and open source. Each <RepoLink path="/releases">GitHub release</RepoLink> has one download per browser:

| Browser | File |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` or `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

Download it from <ReleaseLink />, then follow the steps for your browser.

<Tabs items={["Chrome", "Edge", "Firefox"]}>
<Tab value="Chrome" id="chrome">

<StoreListing browser="chrome" />

<Steps>
<Step>
Download `bookmark-scout-<version>-chrome.crx` or `bookmark-scout-<version>-chrome.zip`. If you use the ZIP, extract it to a folder you will keep, because Chrome loads the extension from that folder.
</Step>
<Step>
Open `chrome://extensions/` and turn on **Developer mode** (top right).
</Step>
<Step>
Drag the CRX file onto the page, or click **Load unpacked** and select the extracted folder.
</Step>
<Step>
Pin Bookmark Scout to the toolbar from the puzzle-piece Extensions menu so the popup is one click away.
</Step>
</Steps>

</Tab>
<Tab value="Edge" id="edge">

<StoreListing browser="edge" />

<Steps>
<Step>
Download `bookmark-scout-<version>-edge.zip` and extract it to a folder you will keep.
</Step>
<Step>
Open `edge://extensions/` and turn on **Developer mode**.
</Step>
<Step>
Click **Load unpacked** and select the extracted folder.
</Step>
</Steps>

</Tab>
<Tab value="Firefox" id="firefox">

<StoreListing browser="firefox" />

<Steps>
<Step>
Download `bookmark-scout-<version>-firefox.zip` and extract it.
</Step>
<Step>
Open `about:debugging#/runtime/this-firefox`.
</Step>
<Step>
Click **Load Temporary Add-on** and select the extracted `manifest.json` file.
</Step>
</Steps>

<Callout type="warn" title="Firefox limits">
Firefox removes temporary add-ons when it restarts, so you load it again after each restart. Firefox also cannot replace its bookmarks page, so open the bookmarks manager (with Tools, saved searches, and import and export) from **Open bookmark manager** in the popup. See [Browser support](/browser-support).
</Callout>

</Tab>
</Tabs>

## After installing

- Click the Bookmark Scout icon to open the popup and search your bookmarks. Start with [Search and saved searches](/guides/search).
- In Chrome, open the browser's bookmarks page (for example with `Ctrl+Shift+O`, or `Cmd+Option+B` on macOS) to reach the Bookmark Scout manager and its Tools sidebar.
- Settings open in a tab from the extension's **Options** entry, for example by right-clicking the toolbar icon in Chrome. See [Settings](/settings).

## Updating

Download the newer release from <ReleaseLink /> and repeat the steps for your browser.
