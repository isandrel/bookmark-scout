Bookmark Scout is free, with no account and no ads. It runs in a browser on a computer, not on phones or tablets.

## Add it to Chrome

<Steps>
<Step>
<StoreListing browser="chrome" />

On the listing, click **Add to Chrome**, then **Add extension**. Chrome asks for one thing only: to read and change your bookmarks. Other features ask for more only when you first use them, and say why; see [Permissions](/permissions).
</Step>
<Step>
Pin the icon: click the puzzle-piece **Extensions** button at the right of the toolbar, then the pin next to Bookmark Scout.
</Step>
<Step>
Save your first page: see [Your first save](/first-save).
</Step>
</Steps>

Right after you add it, a page titled **Bookmark Scout is ready** opens in a new tab with the same first steps: pin the icon, save a page, and the keys of your quick save shortcut (or **Set it up** when another extension already uses them). In Chrome and Edge, it also offers to give quick save <Shortcut id="browser.bookmark_page" /> instead. It opens only once, when you first install Bookmark Scout, never after an update. **Read the guide** on it opens [Save and organize](/guides/save-and-organize), and **Open settings** opens [Settings](/settings).

A copy from the store updates on its own.

## Firefox and Edge

<StoreListing browser="edge" />

Until a store lists it, you can install Bookmark Scout by hand from GitHub, as described [below](#install-from-a-github-release). That takes a few more steps, and in Firefox you repeat them after every restart.

## After installing

- Click the Bookmark Scout icon on any page to save it or to search your bookmarks. Start with [Your first save](/first-save).
- Press <Shortcut id="commands.quick-save" /> on any page to save it without opening anything. See [Save with a keyboard shortcut](/guides/save-and-organize#quick-save).
- In Chrome, Bookmark Scout replaces the browser's bookmarks page with its own bookmarks manager. Open it as before, for example with <Shortcut id="browser.open_bookmarks_manager" />, or with **Open bookmark manager** in the popup. Its **Tools** sidebar holds the cleanup tools.
- Settings open in a tab: right-click the toolbar icon and choose **Options**. See [Settings](/settings).

## Updating

A copy installed from a store updates on its own, and updates keep your settings. One past update, to version 0.3.3, was an exception: it reset Bookmark Scout's own saved data once, though never your bookmarks; see [the FAQ](/faq#my-settings-are-gone-after-an-update).

To keep a copy of your settings, custom prompts, AI services, and saved searches at any time, use **Back up settings** at the bottom of [Settings](/settings).

## Advanced: install by hand from GitHub [#install-from-a-github-release]

Use this only if your browser's store does not list Bookmark Scout yet, or to test a release. A copy installed this way does not update on its own: to update, download the newer release and repeat the steps.

Each <RepoLink path="/releases">GitHub release</RepoLink> has one download per browser:

| Browser | File |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` or `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

Download it from <ReleaseLink />, then follow the steps for your browser.

<Tabs items={["Chrome", "Edge", "Firefox"]}>
<Tab value="Chrome" id="chrome">

<Steps>
<Step>
Download `bookmark-scout-<version>-chrome.crx` or `bookmark-scout-<version>-chrome.zip`. If you use the ZIP, extract it to a folder you will keep, because Chrome loads the extension from that folder.
</Step>
<Step>
Open `chrome://extensions/` and turn on **Developer mode** (top right).
</Step>
<Step>
Drag the CRX file onto the page, or click **Load unpacked** and select the extracted folder.
</Step>
<Step>
Pin Bookmark Scout to the toolbar from the puzzle-piece Extensions menu.
</Step>
</Steps>

</Tab>
<Tab value="Edge" id="edge">

<Steps>
<Step>
Download `bookmark-scout-<version>-edge.zip` and extract it to a folder you will keep.
</Step>
<Step>
Open `edge://extensions/` and turn on **Developer mode**.
</Step>
<Step>
Click **Load unpacked** and select the extracted folder.
</Step>
<Step>
Show Bookmark Scout in the toolbar from the puzzle-piece Extensions menu (the eye icon next to it).
</Step>
</Steps>

</Tab>
<Tab value="Firefox" id="firefox">

<Steps>
<Step>
Download `bookmark-scout-<version>-firefox.zip` and extract it.
</Step>
<Step>
Open `about:debugging#/runtime/this-firefox`.
</Step>
<Step>
Click **Load Temporary Add-on** and select the extracted `manifest.json` file.
</Step>
</Steps>

<Callout type="warn" title="Firefox limits">
Firefox removes temporary add-ons when it restarts, so you load it again after each restart. The **Bookmark Scout is ready** page does not open for a temporary add-on. Firefox also cannot replace its bookmarks page, so open the bookmarks manager (with Tools, saved searches, and import and export) from **Open bookmark manager** in the popup. See [Browser support](/browser-support).
</Callout>

</Tab>
</Tabs>
