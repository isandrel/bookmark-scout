以下是为各浏览器构建的扩展程序中包含的权限。Bookmark Scout 没有声明任何内容脚本，也永远不会读取你访问的网页；按下快速保存快捷键后，它只会在该标签页中显示自己的通知。安装时，它只请求缺少后就无法运行的权限；其他权限都会在你开启或运行需要它的功能时才请求。

## 浏览器会询问什么，以及原因 [#what-your-browser-will-ask-and-why]

安装 Bookmark Scout 时，浏览器只会显示一行内容。其他所有权限都只会在你使用需要它的功能时才请求，并且 Bookmark Scout 会先给出简短说明。如果你拒绝，只有该功能会保持关闭。表格引用 Chrome 的简体中文措辞，并描述 Firefox 的提示内容。

| 浏览器的提示（Chrome 和 Edge / Firefox） | 时机 | 原因 |
| --- | --- | --- |
| “读取和更改您的书签” / 请求读取和修改书签 | 安装时 | 保存、搜索和整理你的书签 |
| “读取您访问过的网站对应的图标”（仅限 Chrome 和 Edge） | 你点击**刷新网站图标**卡片上的**显示浏览器图标**，或开启**使用浏览器的图标缓存**时 | 在书签旁显示浏览器已保存的图标。不会下载任何内容 |
| “读取您的浏览记录” / 请求访问浏览器标签页 | 你在侧边栏中保存当前网页或请求文件夹建议时 | 了解你当前所在的网页。工具栏按钮和快速保存快捷键不需要任何权限，因此说明会先推荐它们 |
| “读取和更改您在 所有example.com网站 上的数据”或“读取和更改您在一些网站上的数据” / 请求访问 example.com 网域中网站上的数据 | 你运行**检查失效链接**、**元数据获取**或**刷新网站图标**时 | 请求该次运行中已加入书签的网页，并且只限于这些网页所在的网站 |
| “读取和更改您在所有网站上的所有数据” / 请求访问所有网站上的数据 | 某次工具运行涉及超过 20 个网站，或你开启**读取网页内容**时 | 请求任意网站上的网页 |
| “读取和更改您在 api.example.com 上的数据” / 请求访问 api.example.com 上的数据 | 你点击**验证服务**或**刷新模型**时 | 访问你的 AI 服务商的地址 |
| “与协作的本机应用通信” / 请求与 Firefox 以外的程序交换消息 | 你开启**允许本地 AI 智能体**时 | 与你电脑上的 bookmark-scout-mcp 程序通信 |
| 仅限 Firefox：提示开发者表示该扩展希望收集身份验证信息、书签和浏览活动 | 你开启 **AI 功能**时 | 你的 API 密钥、书签和文件夹名称，以及当前网页的标题和网址会发送给你的 AI 服务商。此提示中所说的开发者是你选择的 AI 服务商；Bookmark Scout 不会收到任何内容 |
| 仅限 Firefox：同一提示，所列数据为网站内容 | 你开启**读取网页内容**时 | 网页文本会发送给你的 AI 服务商 |
| 仅限 Firefox：同一提示，所列数据为身份验证信息 | 你点击**验证服务**或**刷新模型**时 | 你的 API 密钥会发送给你的 AI 服务商 |
| 仅限 Firefox：同一提示，所列数据为书签和浏览活动 | 你开启**允许本地 AI 智能体**时 | 你电脑上的 AI 智能体可以查询的内容 |

在 Chrome 和 Edge 中，右键菜单（设置中的**右键菜单**）同样是可选的，但它没有警告提示，因此浏览器会直接添加它，不会询问。

## 安装时授予 [#granted-at-install]

| 权限 | 浏览器 | 原因 |
| --- | --- | --- |
| `bookmarks` | 全部 | 显示和搜索你的书签，并在你于弹出窗口、侧边栏、书签管理器或右键菜单中执行操作时创建、修改、移动和删除书签 |
| `storage` | 全部 | 保存你的设置，以及仅保存在本设备上的 AI 服务商设置、标签、摘要、已保存的搜索、最近文件夹、最近搜索和通过**刷新网站图标**保存的网站图标 |
| `activeTab` | 全部 | 当你点击工具栏按钮或右键菜单，或按下快速保存快捷键时，读取该标签页的标题和网址，以便你保存当前所在的网页。不涉及其他标签页，也不涉及历史记录开启获取封面后，弹出窗口中的“**用当前画面作为封面**”按钮还会截取该标签页的一张画面，保存前你会先看到它。 |
| `scripting` | 全部 | 按下快速保存快捷键后，仅在该标签页中显示通知。它不会从网页读取任何内容 |
| `sidePanel` | Chrome、Edge | 提供侧边栏视图。Firefox 则将同一页面声明为侧栏 |
| `offscreen` | Chrome、Edge | 在隐藏的扩展程序页面中运行 AI 快速保存的请求、本地 AI 代理对页面的读取、**元数据获取** 对页面标题的读取，以及 **AI 文件夹重组** 的请求，工作结束后浏览器会关闭该页面。Firefox 的后台页面会自行完成这项工作 |
| `alarms` | 全部 | 按定时唤醒后台，使 **检查失效链接** 等后台任务在浏览器停止后台后继续进行。不会显示提示 |
| `contextMenus` | Firefox | Firefox 不允许扩展程序稍后再请求此权限。菜单仍然只会在你开启**右键菜单**后才出现 |

在 Chrome 和 Edge 中，扩展程序还会用 Bookmark Scout 书签管理器替换浏览器的书签页面。这是页面替换，而不是权限。Firefox 不允许这样做，因此在 Firefox 中需通过弹出窗口中的**打开书签管理器**来打开书签管理器；请参阅[浏览器支持](/browser-support)。

## 需要时才请求 [#asked-for-when-you-need-it]

| 权限 | 浏览器 | 请求时机 |
| --- | --- | --- |
| `tabs` | 全部 | 你在侧边栏中保存当前网页或请求文件夹建议时。请求前会先显示简短说明，并推荐永远不需要此权限的工具栏弹出窗口和快速保存快捷键 |
| `contextMenus` | Chrome、Edge | 你在[设置](/settings#data)中开启**右键菜单**时。此项默认关闭，Chrome 授予此权限时不会弹出提示 |
| `favicon` | Chrome、Edge | 你点击**刷新网站图标**卡片上的**显示浏览器图标**，或在[设置](/settings#appearance)中开启**使用浏览器的图标缓存**以显示浏览器已保存的图标时。请求前会先显示简短说明 |
| 数据共享同意 | Firefox | 每项功能只请求它所发送的数据：**AI 功能**请求你的 API 密钥、书签以及当前网页的标题和网址；**读取网页内容**请求网页文本；**验证服务**请求你的 API 密钥。请求前会先显示简短说明，告知数据会发送给你的 AI 服务商，而不是 Bookmark Scout |
| `nativeMessaging` | 全部 | 你在[设置](/settings#agent-bridge)中开启**允许本地 AI 智能体**时，让扩展可以与你电脑上的 bookmark-scout-mcp 程序通信。会先显示简短说明；在 Firefox 中，同一提示还会请你同意与该程序共享书签数据 |

如果你拒绝，该功能会保持关闭，也不会发送任何内容。如果你之后在浏览器的扩展程序设置中撤回某项权限，相应功能会关闭；再次开启时会重新请求权限。

## 可选的网站访问权限 [#optional-website-access]

扩展程序还声明了对 `http://*/*` 和 `https://*/*` 的访问权限，但安装时不会授予其中任何一项。浏览器会在你需要时才向你请求：

- **检查失效链接**、**元数据获取**和**刷新网站图标**会在你运行时，只请求访问该次运行中书签所在的网站，每个网站都包括其子域名。涉及超过 20 个网站的运行会改为请求访问所有网站。之前已允许的网站不会再次请求。请求不会携带 Cookie，并且只会读取网页的 head 部分来获取标题和图标链接。如果你拒绝，则不会扫描任何内容。重定向到此次运行范围以外网站的链接无法被跟随，因此**检查失效链接**会将其标记为**需手动检查**，而不是失效。请参阅[查找并修复失效链接](/guides/dead-links)和[刷新网站图标](/guides/clean-up#refresh-site-icons)。
- **索引网页正文**也以同样的方式，为它读取的书签所在的网站请求访问权限。
- **获取封面**也以同样的方式，为它读取的书签所在的网站请求访问权限；其他网站上的图片，只有在你也允许了该网站时才会下载。
- AI 设置中的**读取网页内容**会在你开启时请求访问所有网站的权限，以便 AI 工具在不携带 Cookie 的情况下下载网页，并将网页正文发送给你的 AI 服务商。永远不会读取你本地网络中的网页。请参阅[读取网页内容](/guides/ai-tools#read-page-content)。
- AI 设置中的**验证服务**和**刷新模型**只会请求访问该服务商的地址。请参阅[设置 AI 工具](/guides/ai-tools)。

如需撤回访问权限，请打开浏览器中该扩展程序的页面（例如打开 `chrome://extensions/`，然后点击 Bookmark Scout 上的**详情**，或在 Firefox 的 `about:addons` 中打开**权限**），然后更改其网站访问权限或其他权限。

## 不会请求的权限 [#what-is-not-requested]

- 无网页内容访问权限，也没有声明的内容脚本
- 无历史记录、下载内容或 Cookie 权限
- 安装时无主机访问权限

使用权限时你的数据会去往何处，请参阅[隐私](/privacy)。提交给各商店的每项权限的使用理由，请参阅代码仓库中的 <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink>。
