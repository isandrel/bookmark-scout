Chrome 是主要目标浏览器。Edge 基于 Chromium，功能与 Chrome 相同，下文注明的情况除外。Firefox 使用 Manifest V2 版本，功能较少。

## 功能对照表 [#feature-matrix]

此表依据为各浏览器构建的扩展程序清单文件（manifest）整理。

| 功能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 带搜索和保存功能的工具栏弹出窗口 | 是 | 是 | 是 |
| 侧边栏 | 是 | 是 | 不支持。该页面已声明为 Firefox 侧栏，但未在 Firefox 中进行任何测试。 |
| 书签管理器和工具侧栏 | 替换浏览器的书签页面，也可从弹出窗口和侧边栏中的**打开书签管理器**打开 | 从**打开书签管理器**打开。尚未确认 Edge 是否也会将此替换应用到其收藏夹页面。 | 从弹出窗口中的**打开书签管理器**打开。Firefox 无法替换其书签页面。 |
| 已保存的搜索、维护工具、导入和导出、统计、书签管理器中的 AI 工具 | 是 | 是 | 是，在书签管理器中。自动化测试覆盖了导入和导出以及各项报告；其他工具为人工检查。 |
| 设置页面 | 是 | 是 | 是 |
| 用于保存链接的右键菜单 | 是，需开启**右键菜单**（会请求权限） | 同 Chrome | 是，需开启**右键菜单** |
| 书签旁的网站图标 | 通过**刷新网站图标**保存的图标；开启**使用浏览器的图标缓存**后，还会使用浏览器图标缓存中的图标 | 同 Chrome | 仅显示通过**刷新网站图标**保存的图标，该工具在书签管理器中运行。Firefox 没有面向扩展程序的网站图标 API，因此其他书签会显示通用图标。 |
| 用于失效链接检查、标题获取和网站图标刷新的可选网站访问权限 | 在你运行相应工具时请求 | 同 Chrome | 同 Chrome |

## 测试范围 [#what-is-tested]

- **Chrome (Chromium)**：单元测试，以及针对以下内容的端到端测试：弹出窗口、侧边栏、书签管理器、设置、维护工具、报告、导入和导出、键盘快捷键、已保存的搜索、通过右键菜单保存、拖放、联网工具，以及使用模拟服务商的 AI 工具。
- **Edge**：针对 Edge 版本运行同一套端到端测试。
- **Firefox**：一套冒烟测试，覆盖弹出窗口中的搜索和文件夹创建、在标签页中加载的侧边栏页面、从弹出窗口和侧边栏打开书签管理器、书签管理器页面、保存设置、JSON 导出再导入的往返流程、统计和隐私报告，以及弹出窗口中已保存的网站图标。右键菜单、拖放、键盘快捷键，以及联网工具和 AI 工具（包括**刷新网站图标**本身）均未覆盖。

与 Chromium 测试套件一样，Edge 测试套件和 Firefox 冒烟测试套件也是 CI 中的必需检查。真实的 AI 服务商和在线网站通过人工检查，而非自动化测试。

## Safari [#safari]

不支持 Safari。Safari Web Extensions 未实现 `bookmarks` API，而 Bookmark Scout 的每个部分都依赖于该 API。
