---
title: 浏览器支持
description: Chrome、Microsoft Edge 和 Firefox 中分别支持哪些功能、各自从哪里获取，以及不支持 Safari 的原因。
---

Bookmark Scout 在 Chrome 中效果最好，可以从 Chrome 应用商店获取。Edge 的功能与 Chrome 相同，下文注明的情况除外。Firefox 的功能稍少一些，因为它允许扩展程序对书签做的操作更少。这三种浏览器都在电脑上运行；不支持手机和平板电脑。

## 从哪里获取 [#where-to-get-it]

<StoreAvailability />

如果某个商店尚未上架 Bookmark Scout，你可以[手动安装](/installation#install-from-a-github-release)。上架材料准备在代码仓库的 <RepoLink tree="store">`store/` 文件夹</RepoLink>中，每个商店都会先审核扩展程序，然后才会上架。

## 各浏览器支持的功能 [#feature-matrix]

此表依据为各浏览器构建的扩展程序清单文件（manifest）以及代码中的浏览器检查整理。

| 功能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 带搜索和保存功能的工具栏弹出窗口 | 是 | 是 | 是 |
| 在页面中显示通知的快速保存快捷键 | 是。可在 `chrome://extensions/shortcuts` 更改按键，也可以在那里将 <Shortcut id="browser.bookmark_page" /> 设为快速保存快捷键 | 是。可在 `edge://extensions/shortcuts` 更改按键，包括 <Shortcut id="browser.bookmark_page" /> | 是。可在 Bookmark Scout 的设置或 Firefox 的**管理扩展快捷键**中更改按键。Firefox 自己保留 <Shortcut id="browser.bookmark_page" /> 和 <Shortcut id="browser.bookmark_all_tabs" /> |
| 侧边栏 | 是 | 是 | 是，位于 Firefox 侧栏中：在侧栏中选择 Bookmark Scout |
| 书签管理器和工具侧栏 | 替换浏览器的书签页面，也可从弹出窗口和侧边栏中的**打开书签管理器**打开 | 从**打开书签管理器**打开。尚未确认 Edge 是否也会将此替换应用到其收藏夹页面。 | 从弹出窗口中的**打开书签管理器**打开。Firefox 无法替换其书签页面。 |
| 已保存的搜索、维护工具、导入和导出、统计、书签管理器中的 AI 工具 | 是 | 是 | 是，在书签管理器中。自动化测试覆盖了导入和导出、各项报告、检查失效链接、元数据获取、索引网页正文、获取封面、智能规则和 AI 文件夹重组；其他工具为人工检查。 |
| 设置页面 | 是 | 是 | 是 |
| “询问 AI”和其他 AI 工具 | 是 | 是 | 是，需在你同意与 AI 服务商共享数据之后 |
| 内置 AI：在你的电脑上免费推荐文件夹 | 是，需要 Chrome 138 或更高版本，且电脑能够运行 Chrome 的模型 | 仅当 Edge 提供同样的内置 AI 时可用；尚未确认 | 否：Firefox 没有内置 AI |
| 通过 `bookmark-scout-mcp` 连接本地 AI 智能体（面向开发者） | 是 | 是 | 是；`bookmark-scout-mcp install` 也会在 Firefox 中注册它。未被自动化测试覆盖 |
| 从书签管理器在无痕式窗口中打开 | 是 | 是，以 InPrivate 窗口打开 | 是，以隐私窗口打开，前提是允许扩展在隐私窗口中运行 |
| 用于保存链接、网页或选中文字的右键菜单 | 是，需开启**右键菜单**（不会弹出提示） | 同 Chrome | 是，需开启**右键菜单** |
| 书签旁的网站图标 | 通过**刷新网站图标**保存的图标；开启**使用浏览器的图标缓存**后，还会使用浏览器图标缓存中的图标 | 同 Chrome | 仅显示通过**刷新网站图标**保存的图标，该工具在书签管理器中运行。Firefox 没有面向扩展程序的网站图标 API，因此其他书签会显示通用图标。 |
| 用于失效链接检查、标题获取、网站图标刷新、网页正文索引和封面获取的可选网站访问权限 | 在你运行相应工具时请求 | 同 Chrome | 同 Chrome |
| 浏览时截取的封面（**浏览时捕获封面**） | 是，需在你允许访问所有网页之后 | 同 Chrome | 同 Chrome |

各浏览器有多少内容被自动化测试覆盖，请参阅[项目状态](/status#what-is-tested-in-each-browser)。

## Safari [#safari]

不支持 Safari。Safari Web Extensions 未实现 `bookmarks` API，而 Bookmark Scout 的每个部分都依赖于该 API。
