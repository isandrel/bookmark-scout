---
title: 權限
description: Bookmark Scout 要求的各項瀏覽器權限、需要這些權限的原因，以及只在你執行工具時才要求的選用網站存取權。
---

以下是各瀏覽器建置完成的擴充功能所包含的權限。Bookmark Scout 沒有宣告任何內容指令碼，只會在你要求時讀取你造訪的網頁：彈出式視窗中的「**索引此網頁的內文**」會讀取該分頁顯示的內文；開啟「**瀏覽時擷取封面**」後，它會擷取你開啟的已加入書籤網頁的畫面，該畫面只保存在這部裝置上；使用快速儲存快捷鍵後，只會在該分頁中顯示自己的通知。安裝時只會要求缺少就無法運作的權限；其他權限都會在你開啟或執行需要該權限的功能時才要求。開啟取得封面和「**快速儲存時儲存封面**」後，快速儲存快捷鍵還會讀取該分頁的預覽圖片標籤，並可能擷取一次該分頁的畫面作為新書籤的封面，只保存在這部裝置上。

## 瀏覽器會要求哪些權限，以及原因 [#what-your-browser-will-ask-and-why]

安裝 Bookmark Scout 時，瀏覽器只會顯示一行說明。其他權限只會在你使用需要該權限的功能時，先在 Bookmark Scout 中顯示簡短說明後才要求。如果你拒絕，只有該功能會維持關閉。下表引用 Chrome 繁體中文介面的實際用語，並說明 Firefox 提示的內容。

| 瀏覽器顯示的內容 (Chrome 和 Edge / Firefox) | 時機 | 原因 |
| --- | --- | --- |
| 「讀取及變更你的書籤」/ 讀取及修改書籤 | 安裝時 | 儲存、搜尋和整理書籤 |
| 「讀取你所瀏覽網站的圖示」(僅限 Chrome 和 Edge) | 你在「**重新整理網站圖示**」中按一下「**顯示瀏覽器圖示**」，或開啟「**使用瀏覽器的圖示快取**」時 | 在書籤旁顯示瀏覽器已儲存的圖示。不會下載任何內容 |
| 「讀取你的瀏覽記錄」/ 存取瀏覽器分頁 | 你從側邊面板儲存目前網頁或要求資料夾建議時 | 得知你目前所在的網頁。工具列按鈕和快速儲存快捷鍵不需要任何權限，因此說明會先建議使用這兩者 |
| 「讀取以及變更你在所有 example.com 網站的資料」，或「讀取及變更你在多個網站上的資料」/ 存取 example.com 網域中網站的資料 | 你執行「**檢查失效連結**」、「**中繼資料擷取工具**」或「**重新整理網站圖示**」時 | 要求該次執行中加入書籤的網頁，只限於這些網頁所屬的網站 |
| 「讀取及變更你在所有網站上的所有資料」/ 存取所有網站的資料 | 工具的一次執行涵蓋超過 20 個網站，或你開啟「**讀取網頁內容**」時 | 要求任何網站上的網頁 |
| 「讀取及變更你在所有網站上的所有資料」/ 存取所有網站的資料 | 你開啟「**瀏覽時擷取封面**」時 | 在你正在檢視的分頁中載入已加入書籤的網頁時，不需按一下即可擷取其畫面，而瀏覽器只在擁有所有網頁的存取權時才允許這樣做。畫面只保存在這部裝置上，同樣的存取權也讓網站工具不必詢問即可執行 |
| 「讀取以及變更你在api.example.com的資料」/ 存取 api.example.com 的資料 | 你按一下「**驗證服務**」或「**重新整理模型**」時 | 連線到你的 AI 供應商位址 |
| 「與合作原生應用程式建立連線」/ 與 Firefox 以外的程式交換訊息 | 你開啟「**允許本機 AI 代理**」時 | 與你電腦上的 bookmark-scout-mcp 程式通訊 |
| 僅限 Firefox：提示說開發者想要收集驗證資訊、書籤和瀏覽活動 | 你開啟「**AI 功能**」時 | 你的 API 金鑰、書籤和資料夾名稱，以及目前網頁的標題和網址會傳送給你的 AI 供應商。這個提示所說的開發者，指的是你所選的 AI 供應商；Bookmark Scout 不會收到任何資料 |
| 僅限 Firefox：同一提示，內容改為網站內容 | 你開啟「**讀取網頁內容**」時 | 網頁文字會傳送給你的 AI 供應商 |
| 僅限 Firefox：同一提示，內容改為驗證資訊 | 你按一下「**驗證服務**」或「**重新整理模型**」時 | 你的 API 金鑰會傳送給你的 AI 供應商 |
| 僅限 Firefox：同一提示，內容改為書籤和瀏覽活動 | 你開啟「**允許本機 AI 代理**」時 | 你電腦上的 AI 代理可以查詢的內容 |

「**右鍵選單**」在 Chrome 和 Edge 中也是選用權限，但沒有警告訊息，因此瀏覽器會直接加入，不會詢問。

## 安裝時授予 [#granted-at-install]

| 權限 | 瀏覽器 | 原因 |
| --- | --- | --- |
| `bookmarks` | 全部 | 顯示和搜尋書籤，並在你於彈出式視窗、側邊面板、書籤管理員或右鍵選單中操作時，建立、編輯、移動和刪除書籤 |
| `storage` | 全部 | 儲存設定，並只在這部裝置上儲存 AI 供應商設定、標籤、摘要、已儲存的搜尋、最近使用的資料夾、最近的搜尋，以及使用「**重新整理網站圖示**」儲存的網站圖示 |
| `activeTab` | 全部 | 在你按一下工具列按鈕或右鍵選單，或按下快速儲存快捷鍵時，讀取該分頁的標題和網址，以便儲存目前所在的網頁。不會讀取其他分頁，也不會讀取瀏覽記錄。開啟「取得封面」後，彈出式視窗中的「**將目前畫面設為封面**」按鈕也會擷取該分頁的一張畫面，保留前你會先看到它。 開啟「索引網頁內文」後，彈出式視窗中的「**索引此網頁的內文**」按鈕會讀取該分頁顯示的內文，保留前你會先看到它。開啟取得封面和「**快速儲存時儲存封面**」後，快速儲存快捷鍵還會讀取該分頁的預覽圖片標籤，並可能不經檢視擷取一次該分頁的畫面作為新書籤的封面；私密視窗中絕不會這樣做。 |
| `scripting` | 全部 | 使用快速儲存快捷鍵後，只在該分頁中顯示通知。不會從網頁讀取任何內容。開啟「索引網頁內文」後，按一下彈出式視窗中的「**索引此網頁的內文**」按鈕，會在該分頁中執行一個函式，傳回網頁目前顯示的樣子 (不含你在輸入欄位中輸入的內容)，以便在這部裝置上讀取其內文 |
| `sidePanel` | Chrome、Edge | 提供側邊面板檢視畫面。Firefox 則將同一個頁面宣告為側欄 |
| `offscreen` | Chrome、Edge | 在隱藏的擴充功能頁面中執行 AI 快速儲存的要求、本機 AI 代理程式對頁面的讀取、**中繼資料擷取工具** 對頁面標題的讀取、**索引網頁內文** 對頁面內文的讀取，以及 **AI 資料夾重組** 的要求，工作結束時瀏覽器會關閉該頁面。Firefox 的背景頁面會自行處理這項工作 |
| `alarms` | 全部 | 依定時喚醒背景，讓 **檢查失效連結** 等背景工作在瀏覽器停止背景後繼續進行。不會顯示提示 |
| `contextMenus` | Firefox | Firefox 不允許擴充功能日後再要求這項權限。即使如此，選單仍要在你開啟「**右鍵選單**」後才會出現 |

在 Chrome 和 Edge 中，擴充功能也會以 Bookmark Scout 書籤管理員取代瀏覽器的書籤頁面。這是頁面覆寫，而不是權限。Firefox 不允許這麼做，因此在 Firefox 中要從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員；請參閱「[瀏覽器支援](/browser-support)」。

## 需要時才要求 [#asked-for-when-you-need-it]

| 權限 | 瀏覽器 | 要求時機 |
| --- | --- | --- |
| `tabs` | 全部 | 你從側邊面板儲存目前網頁或要求資料夾建議時。會先顯示簡短說明，並建議改用工具列彈出式視窗和快速儲存快捷鍵，這兩者一律不需要這項權限 |
| `contextMenus` | Chrome、Edge | 你在「[設定](/settings#data)」中開啟「**右鍵選單**」時。這項設定預設為關閉，且 Chrome 授予這項權限時不會顯示提示 |
| `favicon` | Chrome、Edge | 你在「**重新整理網站圖示**」中按一下「**顯示瀏覽器圖示**」，或在「[設定](/settings#appearance)」中開啟「**使用瀏覽器的圖示快取**」時，用於顯示瀏覽器已儲存的圖示。會先顯示簡短說明 |
| 資料分享同意 | Firefox | 每項功能只會要求分享它所傳送的資料：「**AI 功能**」為你的 API 金鑰、書籤，以及目前網頁的標題和網址；「**讀取網頁內容**」為網頁文字；「**驗證服務**」為你的 API 金鑰。會先顯示簡短說明，指出資料會傳送給你的 AI 供應商，而不是 Bookmark Scout |
| `nativeMessaging` | 全部 | 你在[設定](/settings#agent-bridge)中開啟**允許本機 AI 代理**時，讓擴充功能可以與你電腦上的 bookmark-scout-mcp 程式通訊。會先顯示簡短說明；在 Firefox 中，同一提示也會請你同意與該程式共用書籤資料 |

如果你拒絕，該功能會維持關閉，也不會傳送任何資料。如果你之後在瀏覽器的擴充功能設定中撤銷權限，該功能就會關閉；再次開啟時會重新要求權限。

## 選用網站存取權 [#optional-website-access]

擴充功能也宣告了 `http://*/*`、`https://*/*` 和 `<all_urls>` 的存取權，但安裝時不會授予任何一項。瀏覽器會在你需要時才詢問：

- 「**檢查失效連結**」、「**中繼資料擷取工具**」和「**重新整理網站圖示**」會在你執行時，只要求存取該次執行中書籤所屬的網站，每個網站都包含其子網域。執行範圍超過 20 個網站時，則會改為要求存取所有網站。先前已允許的網站不會再次詢問。要求傳送時不會附帶 Cookie，且只會讀取網頁的 head 部分來取得標題和圖示連結。如果你拒絕，就不會掃描任何內容。重新導向到該次執行範圍以外網站的連結無法追蹤，因此「**檢查失效連結**」會將其標示為「**需手動檢查**」，而不是失效。請參閱「[找出並修復失效連結](/guides/dead-links)」和「[重新整理網站圖示](/guides/clean-up#refresh-site-icons)」。
- 「**索引網頁內文**」也以同樣的方式，為它讀取的書籤所在網站要求存取權限。
- 「**取得封面**」也以同樣的方式，為它讀取的書籤所在網站要求存取權限；其他網站上的圖片，只有在你也允許該網站時才會下載。
- 「**瀏覽時擷取封面**」會在你開啟時要求存取所有網頁 (`<all_urls>`)：瀏覽器只在擁有此存取權時，才允許擴充功能不需按一下就擷取分頁畫面。只會擷取你正在檢視的分頁中已加入書籤的網頁，絕不擷取「**永不擷取這些網站**」中的網站；除非你開啟「**也在無痕視窗中擷取**」並允許擴充功能在無痕視窗中執行，否則不在無痕視窗中擷取；畫面只保存在這部裝置上。授予此存取權期間，上述工具不再為其網站要求權限。請參閱「[在卡片上顯示封面](/guides/clean-up#capture-covers-while-you-browse)」。
- AI 設定中的「**讀取網頁內容**」會在你開啟時要求存取所有網站，讓 AI 工具能在不附帶 Cookie 的情況下下載網頁，並將主要文字傳送給你的 AI 供應商。絕不會讀取區域網路上的網頁。請參閱「[讀取網頁內容](/guides/ai-tools#read-page-content)」。
- AI 設定中的「**驗證服務**」和「**重新整理模型**」只會要求存取該供應商的位址。請參閱「[設定 AI 工具](/guides/ai-tools)」。

如要撤銷存取權，請開啟瀏覽器中這個擴充功能的頁面 (例如開啟 `chrome://extensions/`，然後按一下 Bookmark Scout 的「**詳細資料**」；或在 Firefox 的 `about:addons` 中開啟「**權限**」)，並變更網站存取權或權限。

## 不會要求的權限 [#what-is-not-requested]

- 沒有宣告任何內容指令碼，除了你開啟的上述功能外，也不存取網頁內容
- 沒有瀏覽記錄、下載或 Cookie 權限
- 安裝時不授予主機存取權

使用權限時資料的去向，請參閱「[隱私權](/privacy)」。向各商店提交的各項權限說明，請參閱存放區中的 <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink>。
