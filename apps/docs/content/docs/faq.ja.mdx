## よくある質問 [#questions]

### Bookmark Scout は無料ですか? [#is-bookmark-scout-free]

はい。<License /> ライセンスの無料オープンソースで、広告もアカウントも有料プランもありません。お金がかかる可能性があるのは、オプションの AI 機能だけです。AI 機能は自分の AI 企業のアカウントを使うため、その企業から使うたびに料金を請求されることがあります。

### AI を使う必要はありますか? [#do-i-need-to-use-ai]

いいえ。AI はオプションです。保存、検索、整理、クリーンアップ、インポートとエクスポートは、すべて AI なしで使えます。AI は[設定](/settings#ai)でオンにするまでオフのままです。使うには、OpenAI、Anthropic、Google などの AI 企業のアカウントと、そのアカウントから発行されるキー（API キー）が必要です。このキーによって、Bookmark Scout がそのアカウントを使えるようになります。こうした企業の多くは使うたびに料金を請求しますが、通常は少額です。Ollama のように自分のコンピューター上で動く AI プログラムなら無料ですが、ある程度高性能なコンピューターが必要です。AI ツールが扱うブックマークのタイトルとアドレスは、選んだ企業に送られます。[AI ツールの設定](/guides/ai-tools)をご覧ください。

### ブックマークはどこかに送信されますか? [#does-it-send-my-bookmarks-anywhere]

開発者には送信されません。Bookmark Scout のサーバーは存在しません。データがブラウザの外に出るのは、自分でオンにした AI ツールを使ったとき（プロバイダーに送られます）か、リンク切れチェックやタイトルの取得を実行したとき（ブックマークしたウェブサイトにリクエストを送ります）、ローカル AI エージェントにブックマークを調べさせたとき（エージェントは求めた内容をコンピューター上のプログラムを通じて受け取ります）だけです。[プライバシー](/privacy)をご覧ください。

### 確認なしでブックマークを変更しませんか? [#will-it-change-my-bookmarks-without-asking]

しません。重複のクリーンアップ、URL のクリーンアップ、リンク切れの修復、取得したタイトル、AI による再整理、インポートは、いずれも書き込む前に確認画面を表示します。**AI に質問** とローカル AI エージェントは、変更を計画として示し、承認を待ちます。削除は初期設定で確認を求めます。削除、クリーンアップ、インポートはそのメッセージから元に戻せ、ブックマークマネージャーでの変更は <Shortcut id="manager.undo" /> で元に戻せます。

### どのブラウザのストアで入手できますか? [#which-browser-stores-list-it]

<StoreAvailability />

各ストアは拡張機能を掲載する前に審査を行います。お使いのブラウザのストアにまだ掲載されていない場合は、[手動でインストール](/installation#install-from-a-github-release)できます（上級者向け）。

### Firefox で使えますか? [#does-it-work-in-firefox]

Firefox Add-ons からはまだ入手できません。Firefox 版はまもなく登場します。それまでは、一時的なアドオンとして[手動でインストール](/installation#firefox)できますが、Firefox を再起動すると削除されます。インストールすれば、いくつかの違いはあるものの使えます。Firefox では拡張機能がブックマークページを置き換えられないため、クリーンアップツール、インポートとエクスポート、保存した検索を含む Bookmark Scout のマネージャーは、ポップアップの **ブックマークマネージャーを開く** から開きます。また、ブラウザのアイコンキャッシュは使えません。[ブラウザ対応](/browser-support)をご覧ください。

### Microsoft Edge で使えますか? [#does-it-work-in-microsoft-edge]

Microsoft Edge アドオンからはまだ入手できません。Edge 版はまもなく登場します。それまでは[手動でインストール](/installation#edge)でき、インストールすれば Chrome とほぼ同じように使えます。[ブラウザ対応](/browser-support)をご覧ください。

### スマートフォンで使えますか? [#does-it-work-on-my-phone]

使えません。Bookmark Scout はコンピューターのブラウザ向けの拡張機能です。スマートフォンやタブレットのブラウザでは動きません。

### Safari に対応しないのはなぜですか? [#why-not-safari]

Safari Web Extensions は、Bookmark Scout の土台である `bookmarks` API を実装していないためです。

## トラブルシューティング [#troubleshooting]

### ブックマークマネージャーはどこにありますか? [#where-is-the-bookmarks-manager]

Chrome では、ブラウザ自体のブックマークページを開きます（たとえば <Shortcut id="browser.open_bookmarks_manager" /> で）。Bookmark Scout はこのページを自身のマネージャーに置き換えます。**ツール** サイドバーが隠れている場合は、マネージャーのヘッダーにある **ツールを表示** をクリックします。

### Firefox から Bookmark Scout が消えた [#bookmark-scout-disappeared-from-firefox]

Firefox は再起動すると一時的なアドオンを削除します。[インストール](/installation)の手順に従って、`about:debugging#/runtime/this-firefox` からもう一度読み込んでください。

### サイトアイコンが表示されない [#site-icons-are-missing]

[設定](/settings#appearance)で **ファビコンを表示** がオンになっているか確認してください。Chrome と Edge はサイトごとにキャッシュしたアイコンを表示するため、最近アクセスしていないサイトには汎用の地球儀アイコンが表示されます。Firefox には拡張機能向けのアイコン API がありません。どのブラウザでも、[サイトアイコンを更新](/guides/clean-up#refresh-site-icons)を使うと各サイト自身のアイコンをダウンロードし、このデバイスに保存できます。

### API キーが保存されない [#my-api-key-was-not-saved]

選んだ AI 企業（サービスのプロバイダー）のキーの形式に合わないキーは拒否されて保存されず、その旨のメッセージが表示されます。サービスのプロバイダーが、キーを発行した企業になっているか確認してください。[AI ツールの設定](/guides/ai-tools#turn-on-ai)をご覧ください。

### 正常なサイトなのにリンク切れチェックで手動確認が必要と表示される [#the-dead-link-check-says-a-working-site-needs-a-manual-check]

サインインを求めるサイト、リクエスト数を制限しているサイト、自動チェックをブロックするサイト、サーバーエラーが起きているサイトは、ブラウザでは開けることが多いため、**手動で確認** に表示されます。リンクを開いて確認してください。**リンク切れ確定** になるのは、ページが見つからない、接続が拒否された、ホストが不明、リダイレクトがループしている場合だけです。[リンク切れの検出と修復](/guides/dead-links#read-the-results)をご覧ください。

### スキャン中にコンソールに「Failed to load resource」と表示される [#the-console-shows-failed-to-load-resource-during-a-scan]

Chrome は、失敗したリクエストごとに、ページのデベロッパーコンソールに 1 行を記録します。拡張機能はこの行を抑止できません。また、この行はスキャンに問題が起きたことを意味するものではありません。

### マネージャーでの並べ替えがポップアップに反映されない [#reordering-in-the-manager-does-not-show-in-the-popup]

ポップアップにブラウザの保存された順序が反映されるのは、並び順が **フォルダ優先** のときだけです。**追加日順** と **アルファベット順** では一覧が並べ替えられ続けます。[設定](/settings#behavior)で **並び順** を変更してください。

### 表示されている数より多くの一致があると検索に表示される [#search-says-there-are-more-matches-than-it-shows]

結果は **最大検索結果数**（初期設定は 20）で打ち切られます。検索を絞り込むか、[設定](/settings#search)で上限を増やしてください。

### 別のコンピューターでタグ、要約、保存した検索が見つからない [#my-tags-summaries-or-saved-searches-are-missing-on-another-computer]

これらは作成したデバイスにのみ保存され、同期されません。移すには、ブックマークを JSON でエクスポートし（タグと要約は、インポートで作成されるブックマークに引き継がれます）、[設定](/settings)の下部にある **設定をバックアップ** でバックアップを保存します（保存した検索が含まれます）。設定は、ブラウザの同期がオンならブラウザのアカウントを通じて同期されます。

### 誤って削除してしまった [#i-deleted-something-by-mistake]

10 秒以内にメッセージの **元に戻す** をクリックしてください。その項目と中に含まれるすべての項目、保存したタグと要約が復元されます。復元した項目の追加日は新しくなります。ブックマークマネージャーでは、そこで行った削除や、AI に質問またはローカル AI エージェントによる削除も、ブラウザを閉じるまで <Shortcut id="manager.undo" /> で元に戻せます。[マネージャーでの選択、元に戻す、やり直し](/guides/save-and-organize#select-undo-and-redo-in-the-manager)をご覧ください。

### クイック保存のショートカットが反応しない [#the-quick-save-shortcut-does-nothing]

ほかの拡張機能がすでに <Shortcut id="commands.quick-save" /> や <Shortcut id="commands.ai-quick-save" /> を使っている場合、ブラウザは Bookmark Scout のショートカットにキーを割り当てないままにし、ポップアップに **クイック保存のショートカットが未設定です** と表示されます。**設定する** をクリックするか、[設定](/settings#quick-save)の **保存と検索** にある **キーボードショートカット** を開いて、別のキーを選んでください。ブラウザ自体のページなど、拡張機能が何も表示できないページでは、通知の代わりにツールバーのアイコンに結果が表示されます。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)をご覧ください。

### アップデート後に設定が消えた [#my-settings-are-gone-after-an-update]

通常、アップデートしても設定はそのまま残ります。ただし、バージョン 0.3.3 へのアップデートでは、Bookmark Scout の保存データが新しい形式に移行され、古いデータは変換されずに削除されました。このアップデート後は、設定は初期値に戻り、AI サービスとその API キーは追加し直す必要があり、カスタムプロンプト、保存した検索、最近の検索とフォルダ、タグと要約、保存したサイトアイコンは失われています。ブックマーク自体は変更されていません。アップデート前に[設定](/settings)の下部にある **設定をバックアップ**（当時の名前は **エクスポート**）で設定を保存していた場合は、**設定を復元** でそのファイルを開いてください。
