로드맵 문서가 실제 구현과 어긋나지 않도록 현재 저장소의 상태를 요약한 페이지입니다.

## 구현됨 [#implemented]

- WXT, React, TypeScript, Zustand, Base UI 프리미티브 기반의 shadcn/ui 컴포넌트, 브라우저 북마크 API로 만든 브라우저 확장 프로그램
- Chrome을 주요 대상으로 하며 Firefox와 Edge 빌드 대상 제공
- 팝업의 북마크 검색, 폴더 필터링, 드래그 앤 드롭 정리, 빠른 추가, 폴더 만들기, 펼치기/접기 컨트롤
- 팝업, 사이드 패널, 관리자에서 확인 대화 상자(기본적으로 켜짐, 설정에서 선택 가능)를 거쳐 삭제하며, 10초 동안의 실행 취소로 하위 항목 전체와 저장된 태그 및 요약을 복원
- Chrome 사이드 패널 진입점
- 팝업, 사이드 패널, 관리자의 키보드 단축키: 검색, 트리와 표 탐색, 현재 페이지 저장, 상위 폴더로 이동, 저장된 검색 열기, `?` 도움말 대화 상자. Ctrl/Cmd 조합은 사용하지 않으며, 입력 중이거나 대화 상자가 열려 있는 동안에는 일시 중지
- 폴더 트리, 이동 경로, 북마크 표, 도구 사이드바가 있는 사용자 지정 북마크 페이지 대체
- 관리자의 저장된 검색(스마트 뷰): 필터, 정렬, 폴더 범위만 로컬 저장소에 저장하고 실제 북마크 트리에 대해 평가하며, 삭제된 폴더는 건너뜀
- 저장된 북마크 순서를 바꾸지 않고 추가일 순, 자연스러운 알파벳순, 폴더 우선 정렬을 설정 가능
- 외관, 언어, 검색, 동작, 고급 UI 크기, AI, AI 도구, 유지보수, 메타데이터, 보안, 분석, 데이터, 컨텍스트 메뉴 설정이 있는 옵션 페이지
- `chrome.storage.sync`를 통한 설정 저장
- 설정 파일에 정의된 AI 제공업체: OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, OpenRouter, Ollama, CLIProxyAPI, 사용자 지정 OpenAI 호환 엔드포인트
- AI 폴더 추천. 제안된 새 폴더 경로를 검토한 뒤 만들고 현재 페이지를 그곳에 저장하는 기능 포함
- 저장된 태그와 요약을 포함하는 AI 컨텍스트 패킹, 태그 제안, 요약, 폴더 재구성(기본적으로 적용 전에 미리 보기)
- 북마크 유지 관리 도구: 중복 정리, URL 정리, 깨진 링크 검사(깨진 링크 확인됨과 직접 확인 필요로 구분하고, 삭제, 리디렉션 대상, Wayback Machine 사본, URL 편집으로 검토 후 복구하며 실행 취소 가능), 메타데이터 가져오기(검토한 제목은 적용하고 설명은 미리 보기만 제공), 개인정보 검사, 통계
- 사이트 아이콘 새로 고침: 선택적 웹사이트 접근을 허용한 뒤 북마크한 사이트 자체에서 웹사이트당 아이콘 하나를 내려받고(타사 아이콘 서비스는 사용하지 않음), 검토한 아이콘을 용량 제한 안에서 로컬 저장소에 저장하며, 팝업, 사이드 패널, 관리자에서 브라우저 아이콘 캐시보다 우선해 표시. 저장된 아이콘은 지울 수 있음
- 북마크 내보내기와 AI 컨텍스트 내보내기 전에 선택적으로 가리기가 가능한 개인정보 검토
- HTML 또는 JSON에서 북마크 가져오기. 대상 폴더, 개수, 중복 미리 보기, 중복 처리 방식 선택, 실행 취소 지원
- HTML, JSON, Markdown, CSV로 북마크 내보내기
- 링크용 마우스 오른쪽 버튼 컨텍스트 메뉴 저장 흐름
- 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어, 독일어, 프랑스어, 브라질 포르투갈어로 제공되는 확장 프로그램과 홍보 사이트
- Fumadocs 문서 사이트
- 팝업, 관리자, 설정, 유지 관리, 보고서, 가져오기/내보내기, 라우트 모의 및 로컬 서버 기반 네트워크 도구, 모의 제공업체 기반 AI 도구에 대한 단위 테스트와 무인 Chromium E2E 테스트
- 같은 Playwright 테스트 모음을 Microsoft Edge에서 Edge 빌드로 실행(`nx run extension:test:e2e:edge`)하고, 테스트 9개로 이루어진 Firefox 스모크 테스트 모음을 Firefox 빌드로 실행(`nx run extension:test:e2e:firefox`): 팝업 검색과 폴더 만들기, 팝업의 저장된 사이트 아이콘, 사이드 패널 페이지, 팝업과 사이드 패널에서 관리자 열기, 관리자 로드와 필터링, 설정 저장, JSON 내보내기 후 다시 가져오기, 통계 및 개인정보 보고서
- 모든 설정을 해당 설정을 읽는 코드와 그 설정을 바꾸는 테스트에 연결한 설정-동작 매트릭스(`apps/extension/tests/settings-matrix.ts`)

## 일부 구현됨 [#partial]

- 북마크 태그와 요약: **북마크 세부정보**에서 편집할 수 있고 검토한 AI 제안에서 저장할 수 있지만, 확장 프로그램의 로컬 저장소에만 저장됩니다. 동기화되지 않으며, 검색할 수 없고, 북마크 내보내기에 포함되지 않습니다.
- AI 도구 제한(태그 수와 스타일, 요약 길이, 재구성 폴더 제한)은 제공업체에 지시 사항으로 전달되며, 결과가 이를 지키는지는 확인하지 않습니다. 실제 제공업체와의 호환성은 직접 확인합니다.
- Firefox 런타임 테스트는 전체 테스트 모음이 아니라 스모크 테스트 모음입니다. Playwright는 `moz-extension://` 페이지를 열 수 없으므로, Firefox 테스트는 geckodriver(Selenium)로 일반 Firefox를 제어하고 실제 부가 기능 ID로 빌드를 임시 부가 기능으로 설치합니다. 따라서 Firefox 부가 기능에 제출되는 매니페스트를 그대로 테스트합니다. 컨텍스트 메뉴 저장(Chromium 테스트는 서비스 워커에서 `contextMenus.onClicked`를 발생시키지만, Firefox 빌드는 테스트 하네스가 스크립트로 제어할 수 없는 MV2 백그라운드 페이지를 사용함), 드래그 앤 드롭, 키보드 단축키, 네트워크 도구, AI 도구, 로캘은 다루지 않습니다.
- Firefox API 차이: Firefox에는 `_favicon` 서비스가 없어 브라우저 아이콘 캐시를 사용할 수 없으므로, **사이트 아이콘 새로 고침**으로 저장한 아이콘이 없으면 북마크에 기본 아이콘이 표시됩니다. Firefox는 북마크 페이지를 대체할 수 없으므로 관리자와 **도구** 사이드바는 팝업의 **북마크 관리자 열기**로 엽니다. 사이드 패널 페이지는 Firefox 사이드바로 선언되어 있으며, 자동화로는 사이드바 자체를 열 수 없어 테스트에서는 이 페이지를 탭에서 로드합니다.
- 네 가지 도구의 범위 설정은 고정되어 있습니다. 자동 태그 지정과 콘텐츠 요약은 항상 현재 폴더를 사용하고, 중복 정리와 개인정보 스캐너는 항상 모든 북마크를 검사합니다.

## 계획됨 [#planned]

- Firefox 런타임 테스트 범위 확대: 컨텍스트 메뉴, 드래그 앤 드롭, 키보드 단축키, 네트워크 도구, AI 도구, 로캘
- Chrome 웹 스토어, Firefox 부가 기능, Edge 추가 기능에 스토어 제출. 등록 자료와 제출 체크리스트는 저장소의 <RepoLink tree="store">`store/` 폴더</RepoLink>에 있으며, 제출은 직접 진행하고 릴리스 승인이 필요합니다. Firefox 패키지에는 고유한 부가 기능 ID와 데이터 수집 선언이 포함되어 있습니다

## 문서 작성 규칙 [#documentation-rules]

- 기능 현황, 설치 경로, 브라우저 지원, 개인정보 보호 관련 기대 사항, 구성이 바뀌면 문서를 업데이트합니다.
- AI 기능은 사용자가 직접 켜야 하며, 선택한 제공업체에 북마크 데이터를 보낼 수 있습니다.
- CI는 확장 프로그램 단위 테스트, Chromium 엔드 투 엔드 테스트 모음, Edge 테스트 모음, Firefox 스모크 테스트 모음을 별도 설정 없이 필수 검사로 실행합니다. 빌드가 통과했다고 해서 런타임 동작이 검증된 것은 아닙니다.
