로드맵 문서가 실제 구현과 어긋나지 않도록 현재 저장소의 상태를 요약한 페이지입니다.

## 구현됨 [#implemented]

- WXT, React, TypeScript, Zustand, Base UI 프리미티브 기반의 shadcn/ui 컴포넌트, 브라우저 북마크 API로 만든 브라우저 확장 프로그램
- Chrome을 주요 대상으로 하며 Firefox와 Edge 빌드 대상 제공
- 팝업의 북마크 검색, 폴더 필터링, 드래그 앤 드롭 정리, 빠른 추가, 폴더 만들기, 펼치기/접기 컨트롤. 가상화된 트리는 큰 라이브러리에서도 빠르게 반응하며, 다시 로드하지 않고 북마크 이벤트로 업데이트됨
- 폴더 이름이나 경로의 일부를 입력해 찾은 폴더에 저장. 일치 항목 순위, 오타 하나 허용, 최근 폴더 우선 표시
- 빠른 저장 단축키(<Shortcut id="commands.quick-save" />는 가장 잘 맞는 폴더, 마지막으로 사용한 폴더 또는 지정한 폴더에, <Shortcut id="commands.ai-quick-save" />는 첫 번째 AI 추천 폴더에 저장). 페이지 안의 알림에서 실행 취소, 이동, 다시 시도, AI 없이 저장을 제공하며, 알림을 표시할 수 없는 페이지에서는 툴바 배지와 팝업으로 표시. 설정에서 단축키를 지정하며, Firefox용 키 입력기, Chrome과 Edge에서 <Shortcut id="browser.bookmark_page" />를 지정하는 안내, 브라우저가 단축키에 키를 지정하지 않았을 때의 알림 포함
- 팝업, 사이드 패널, 관리자에서 확인 대화상자(기본적으로 켜짐, 설정에서 선택 가능)를 거쳐 삭제하며, 10초 동안의 실행 취소로 하위 항목 전체와 저장된 태그 및 요약을 복원
- 사이드 패널 진입점(Chrome과 Edge에서는 사이드 패널, Firefox에서는 사이드바)
- 새로 설치한 뒤 한 번만 열리고 업데이트 후에는 열리지 않는 환영 페이지
- 팝업과 사이드 패널의 키보드 단축키: 검색, 트리 탐색, 현재 페이지 저장. Cmd/Ctrl 조합은 사용하지 않음. 관리자에서는 Chrome 북마크 관리자의 키(`Cmd/Ctrl`를 사용한 모두 선택, 복사, 잘라내기, 붙여넣기, 실행 취소, 다시 실행, 탭에서 열기)와 <Shortcut id="manager.show_help" /> 도움말 대화상자. 모든 단축키는 `apps/extension/config/ui/shortcuts.toml`에 한 번만 정의되며, 문서, 웹사이트, README는 이 파일에서 키 텍스트를 가져와 표시함. 입력 중이거나 대화상자가 열려 있는 동안에는 일시 중지
- 폴더 트리, 이동 경로, 북마크 표, 도구 사이드바가 있는 사용자 지정 북마크 페이지 대체로, Chrome 관리자처럼 동작: `?id=`와 `?q=` 주소(Chrome의 폴더 링크 포함), 행 선택, 하나의 북마크 작업 레지스트리로 만들고 설정에서 사용자 지정할 수 있는 마우스 오른쪽 버튼 메뉴와 ⋯ 메뉴, 관리자 탭 간 잘라내기·복사·붙여넣기, 모두 탭/새 창/시크릿 창에서 열기, 이름순 정렬, 북마크나 폴더 추가, 행·폴더·링크의 드래그 앤 드롭, Chrome의 키를 쓰고 계정과 기기 섹션이 분리된 ARIA 폴더 트리, 좁은 창의 서랍형 패널, 세션 저장소에 보관되는 최근 100개 변경의 실행 취소 및 다시 실행 기록
- 관리자의 저장된 검색(스마트 뷰): 필터, 정렬, 폴더 범위만 로컬 저장소에 저장하고 실제 북마크 트리에 대해 평가하며, 삭제된 폴더는 건너뜀
- 저장된 북마크 순서를 바꾸지 않고 브라우저 순서(기본값), 추가일 순, 자연스러운 알파벳순, 폴더 우선 정렬을 설정 가능
- **기본 설정**(대부분의 사용자가 바꾸는 몇 가지 설정)으로 열리고, **고급 설정** 아래에 11개 범주(저장 및 검색, 외관, 동작, AI, AI 도구, 유지보수, 페이지 제목 및 아이콘, 보안, 분석, 가져오기 및 내보내기, 개발자용)가 더 있으며, 설정 검색, 목록 및 세그먼트 편집기, 접힌 고급 설정이 있는 설정 페이지
- 기본값에 대한 재정의로 저장되는 설정: 동기화 설정은 `chrome.storage.sync`에, 기기 설정은 로컬 저장소에 저장하며, 저장 값은 zod로 검증하는 버전 관리 봉투에 담고, 여러 페이지의 쓰기는 Web Locks로 순차 처리. 새 형식은 이전 저장 데이터를 변환하지 않고 대체함
- 설정 백업 파일(변경한 설정, 사용자 지정 프롬프트, 키를 제외한 AI 서비스, 저장된 검색, 관리자 열과 정렬) 및 복원
- 설정 파일에 정의된 AI 제공업체: OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, xAI, Azure OpenAI, OpenRouter, Ollama, CLIProxyAPI, 로컬 서버, models.dev 카탈로그의 약 200개 제공업체, 사용자 지정 OpenAI 호환 및 Anthropic 호환 엔드포인트
- 폴더 추천과 AI 빠른 저장을 위해 사용자의 컴퓨터에서 무료로 실행되는 서비스인 Chrome 내장 AI(Prompt API를 통한 Gemini Nano). 단어 일치 대체 방식과 설정의 기기 확인 포함
- AI 폴더 추천. 제안된 새 폴더 경로를 검토한 뒤 만들고 현재 페이지를 그곳에 저장하는 기능 포함
- 저장된 태그와 요약을 포함하는 AI 컨텍스트 패킹, 태그 제안, 요약, 폴더 재구성(적용 전에 항상 미리 보기). 각각 실행 취소 가능
- 편집기에 자리 표시자 목록(`{{today}}`, `{{language}}`, `{{aboutMe}}`, `{{existingTags}}`)이 있는 프롬프트 라이브러리, AI 출력 언어 설정, 모든 기본 제공 프롬프트에 쓰이는 내 소개 텍스트, 자동 태그 지정에 보내는 기존 태그 이름(끌 수 있음)
- 팝업과 사이드 패널의 AI에게 묻기: 북마크 작업 레지스트리의 읽기 도구(단어, 폴더, 태그, 사이트, 날짜로 검색, 폴더, 태그와 요약, 중복, 폴더 추천, 링크 확인, 페이지 읽기), 승인한 뒤에만 페이지를 저장하거나 이동·이름 변경·삭제·새 폴더 계획을 적용하는 쓰기 도구와 실행 취소, 최신 답변에 대해 메시지 입력란 위에 표시되는 제안 버튼, 설정의 **AI에게 묻기가 할 수 있는 일**
- `bookmark-scout-mcp` MCP 서버와 네이티브 메시징 호스트(`packages/mcp-bridge`)를 통한 로컬 AI 에이전트: 기기마다 기본적으로 꺼져 있고, 조회 시 민감한 값을 가리며, 변경은 **변경 허용**을 켰을 때만 가능하고 각 변경은 Bookmark Scout 창에서 승인
- 북마크 유지 관리 도구: 중복 정리, URL 정리, 깨진 링크 검사(깨진 링크 확인됨과 직접 확인 필요로 구분하고, 삭제, 리디렉션 대상, Wayback Machine 사본, URL 편집으로 검토 후 복구하며 실행 취소 가능), 메타데이터 가져오기(검토한 제목은 적용하고 설명은 미리 보기만 제공), 개인정보 검사, 통계
- 사이트 아이콘 새로 고침: 선택적 웹사이트 접근을 허용한 뒤 북마크한 사이트 자체에서 웹사이트당 아이콘 하나를 내려받고(타사 아이콘 서비스는 사용하지 않음), 검토한 아이콘을 용량 제한 안에서 로컬 저장소에 저장하며, 팝업, 사이드 패널, 관리자에서 브라우저 아이콘 캐시보다 우선해 표시. 저장된 아이콘은 지울 수 있음
- 북마크 내보내기와 AI 컨텍스트 내보내기 전에 선택적으로 가리기가 가능한 개인정보 검토
- HTML 또는 JSON에서 북마크 가져오기. 대상 폴더, 개수, 중복 미리 보기, 중복 처리 방식 선택, 실행 취소 지원
- HTML, JSON(각 북마크의 태그와 요약 포함), Markdown, CSV로 북마크 내보내기
- 링크용 마우스 오른쪽 버튼 컨텍스트 메뉴 저장 흐름
- 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어, 독일어, 프랑스어, 브라질 포르투갈어로 제공되는 확장 프로그램과 홍보 사이트
- Fumadocs 문서 사이트
- 팝업, 관리자, 설정, 유지 관리, 보고서, 가져오기/내보내기, 빠른 저장, 라우트 모의 및 로컬 서버 기반 네트워크 도구, 모의 제공업체 기반 AI 도구, 여러 화면에 걸친 사용자 흐름에 대한 단위 테스트와 무인 Chromium E2E 테스트
- 같은 Playwright 테스트 모음을 Microsoft Edge에서 Edge 빌드로 실행(`nx run extension:test:e2e:edge`)하고, 테스트 18개로 이루어진 Firefox 스모크 테스트 모음을 Firefox 빌드로 실행(`nx run extension:test:e2e:firefox`): 팝업 검색과 폴더 만들기, 팝업의 저장된 사이트 아이콘, 사이드 패널 페이지, 팝업과 사이드 패널에서 관리자 열기, 관리자 로드, 필터링, 주소, 실행 취소, 폴더 트리 키, 마우스 오른쪽 버튼 메뉴, 드래그 앤 드롭, 빠른 저장 단축키 알림과 키 입력기, AI 데이터 동의, 도구 실행 시 사이트별 웹사이트 접근, 설정 저장, JSON 내보내기 후 다시 가져오기, 통계 및 개인정보 보고서
- 컴파일된 `bookmark-scout-mcp` 바이너리를 Linux와 macOS에서 테스트 브라우저의 네이티브 호스트로 실행하는 브리지 엔드 투 엔드 테스트(`nx run extension:test:e2e:bridge`)
- 큰 라이브러리에서 지연 시간과 스크롤을 재는 성능 측정(`nx run extension:test:perf`, 매일 및 필요할 때 실행)과 실제 제공업체를 대상으로 하는 실시간 AI 테스트 모음(`nx run extension:test:live`, 필요할 때 실행)
- 모든 설정을 해당 설정을 읽는 코드와 그 설정을 바꾸는 테스트에 연결한 설정-동작 매트릭스(`apps/extension/tests/settings-matrix.ts`)

## 브라우저별 테스트 범위 [#what-is-tested-in-each-browser]

Chrome이 주요 대상입니다. Edge는 Chromium 기반이며 같은 엔드 투 엔드 테스트 모음을 실행하고, Firefox는 Manifest V2 빌드를 사용합니다.

- **Chrome (Chromium)**: 팝업, 사이드 패널, 관리자, 설정, 유지 관리 도구, 보고서, 가져오기와 내보내기, 키보드 단축키, 빠른 저장, 저장된 검색, 컨텍스트 메뉴 저장, 드래그 앤 드롭, 네트워크 도구, 모의 제공업체를 사용한 AI 도구, 그리고 이들 여러 기능에 걸친 사용 흐름에 대한 단위 테스트와 엔드 투 엔드 테스트가 있습니다. 브리지 테스트는 Linux와 macOS의 Chromium에서 확장 프로그램과 함께 `bookmark-scout-mcp` 프로그램을 실행합니다.
- **Edge**: 같은 엔드 투 엔드 테스트 모음을 Edge 빌드에서 실행합니다.
- **Firefox**: 스모크 테스트 모음이 팝업 검색과 폴더 만들기, 탭에서 로드한 사이드 패널 페이지, 팝업과 사이드 패널에서 관리자 열기, 관리자 페이지와 그 주소, `Delete`와 실행 취소, 폴더 트리 키, 마우스 오른쪽 버튼 메뉴, 드래그 앤 드롭(스크립트로 만든 드래그 이벤트 사용), 빠른 저장 단축키 알림과 키 입력기, AI 데이터 공유 동의, 도구 실행 시 해당 북마크의 사이트에만 접근을 요청하는 것, 설정 저장, JSON 내보내기 후 다시 가져오기, 통계 및 개인정보 보고서, 팝업에 표시되는 저장된 사이트 아이콘을 다룹니다. 페이지의 마우스 오른쪽 버튼 메뉴에서 저장하기, 그 밖의 키보드 단축키, 팝업의 드래그 앤 드롭, 빠른 저장 알림 자체, 로컬 AI 에이전트, 네트워크 도구와 AI 도구(**사이트 아이콘 새로 고침** 자체 포함)는 다루지 않습니다.

Edge 테스트 모음과 Firefox 스모크 테스트 모음은 Chromium 테스트 모음과 마찬가지로 필수 CI 검사입니다. 실제 AI 제공업체와 실제 웹사이트는 자동 테스트가 아니라 직접 확인합니다.

## 일부 구현됨 [#partial]

- 북마크 태그와 요약: **북마크 세부정보**에서 편집할 수 있고 검토한 AI 제안에서 저장할 수 있지만, 확장 프로그램의 로컬 저장소에만 저장됩니다. 동기화되지 않으며 검색할 수 없습니다. JSON 북마크 내보내기에는 포함되며, 그 파일을 가져오면 가져오기로 만들어지는 북마크에 복원됩니다.
- AI 도구 제한(태그 수와 스타일, 요약 길이, 재구성 폴더 제한)은 제공업체에 지시 사항으로 전달되며, 결과가 이를 지키는지는 확인하지 않습니다. 실제 제공업체와의 호환성은 직접 확인합니다.
- Firefox 런타임 테스트는 전체 테스트 모음이 아니라 스모크 테스트 모음입니다. Playwright는 `moz-extension://` 페이지를 열 수 없으므로, Firefox 테스트는 geckodriver(Selenium)로 일반 Firefox를 제어하고 실제 부가 기능 ID로 빌드를 임시 부가 기능으로 설치합니다. 따라서 Firefox 부가 기능에 제출되는 매니페스트를 그대로 테스트합니다. 컨텍스트 메뉴 저장(Chromium 테스트는 서비스 워커에서 `contextMenus.onClicked`를 발생시키지만, Firefox 빌드는 테스트 하네스가 스크립트로 제어할 수 없는 MV2 백그라운드 페이지를 사용함), 팝업의 드래그 앤 드롭(관리자의 드래그 앤 드롭은 스크립트로 만든 드래그 이벤트로 테스트함), 관리자의 `Delete`, 실행 취소, 폴더 트리 키 이외의 키보드 단축키, 네트워크 도구, AI 도구, 로컬 AI 에이전트, 로캘은 다루지 않습니다.
- Firefox API 차이: Firefox에는 `_favicon` 서비스가 없어 브라우저 아이콘 캐시를 사용할 수 없으므로, **사이트 아이콘 새로 고침**으로 저장한 아이콘이 없으면 북마크에 기본 아이콘이 표시됩니다. Firefox는 북마크 페이지를 대체할 수 없으므로 관리자와 **도구** 사이드바는 팝업의 **북마크 관리자 열기**로 엽니다. 사이드 패널 페이지는 Firefox 사이드바로 선언되어 있으며, 자동화로는 사이드바 자체를 열 수 없어 테스트에서는 이 페이지를 탭에서 로드합니다.
- 네 가지 도구의 범위 설정은 고정되어 있습니다. 자동 태그 지정과 콘텐츠 요약은 항상 현재 폴더를 사용하고, 중복 정리와 개인정보 스캐너는 항상 모든 북마크를 검사합니다.

## 문서 작성 규칙 [#documentation-rules]

- 기능 현황, 설치 경로, 브라우저 지원, 개인정보 보호 관련 기대 사항, 구성이 바뀌면 문서를 업데이트합니다.
- AI 기능은 사용자가 직접 켜야 하며, 선택한 제공업체에 북마크 데이터를 보낼 수 있습니다.
- CI는 확장 프로그램 단위 테스트, Chromium 엔드 투 엔드 테스트 모음, Edge 테스트 모음, Firefox 스모크 테스트 모음을 별도 설정 없이 필수 검사로 실행하고, 브리지나 확장 프로그램이 바뀌면 브리지 엔드 투 엔드 테스트도 실행합니다. 실제 AI 제공업체는 풀 리퀘스트가 아니라 필요할 때 실행하는 실시간 테스트 모음으로 확인합니다. 빌드가 통과했다고 해서 런타임 동작이 검증된 것은 아닙니다.
