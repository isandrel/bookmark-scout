## できること [#what-you-can-do-with-it]

- **正しいフォルダに保存する**: ポップアップやサイドパネルでフォルダ名の一部を入力します。ツリーの深い階層にあるフォルダや、`work/react` のようなパスでもかまいません。`↓` を押してから `Enter` を押すか、フォルダをクリックすると、表示中のページをそこに保存します。AI をオンにしている場合は、フォルダの提案を求めることもできます。[保存と整理](/guides/save-and-organize)をご覧ください。
- **何も開かずに保存する**: どのページでも `Alt+Shift+S` を押すと、そのページに最もよく一致するフォルダに保存します。ページ内に小さな通知が表示され、保存先と、**元に戻す**、ほかの移動先フォルダが示されます。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)をご覧ください。
- **探す**: ツールバーのポップアップやサイドパネルから、すべてのブックマークをタイトルや URL で検索できます。ブックマークマネージャーでは検索条件に名前を付けて保存できます。[検索と保存した検索](/guides/search)をご覧ください。
- **整理する**: 右クリックメニューからリンクを保存できます。ブックマークマネージャーは Chrome のものと同じように使え、選択、右クリックメニュー、切り取り・コピー・貼り付け、ドラッグ＆ドロップ、`Ctrl+Z` と `Ctrl+Y` による元に戻す・やり直しに対応しています。[保存と整理](/guides/save-and-organize)をご覧ください。
- **クリーンアップする**: 重複したブックマークを削除し、トラッキングパラメータを取り除き、リンク切れを見つけて修復できます。[重複とトラッキング URL のクリーンアップ](/guides/clean-up)と[リンク切れの検出と修復](/guides/dead-links)をご覧ください。
- **ライブラリを移す**: HTML、JSON、Markdown、CSV にエクスポートでき、HTML や JSON はプレビューしてからインポートできます。[インポートとエクスポート](/guides/import-export)をご覧ください。
- **AI は使いたいときだけ**: AI ツールは初期設定でオフです。オンにする場合は、プロバイダーを自分で選び、自分のキーを使います。**AI に質問** はブックマークについての質問に答え、ブックマークを変更するのは、提示した計画を承認したときだけです。[AI ツールの設定](/guides/ai-tools)をご覧ください。
- **ローカル AI エージェントと連携する**: Claude Code、Codex、Cursor など、コンピューター上の AI エージェントにブックマークを調べさせ、エージェントが求める変更はブラウザで 1 つずつ承認できます。初期設定ではオフです。[ローカル AI エージェントと使う](/guides/local-agents)をご覧ください。

## データの行き先 [#where-your-data-goes]

Bookmark Scout にはアカウントも専用のサーバーもありません。ブックマークはブラウザの中にとどまります。データがブラウザの外に出るのは、リンク切れの確認や、自分でオンにした AI ツールなど、ネットワークが必要な機能を使ったときだけです。その場合も、データは自分で選んだウェブサイトやプロバイダーへ直接送られます。ローカル AI エージェントは、許可した場合に、調べた内容をコンピューター上のプログラムを通じて受け取ります。[プライバシーの概要](/privacy)をお読みください。

## ブラウザ [#browsers]

主な対象は Chrome です。Edge も Chromium ベースで、同じエンドツーエンドテストを実行しています。Firefox ではブックマークページを置き換えられないため、マネージャーはポップアップのボタンから開きます。また、ブラウザの機能がいくつか異なります。詳しくは[ブラウザ対応](/browser-support)をご覧ください。
