## できること [#what-you-can-do-with-it]

- **探す**: ツールバーのポップアップやサイドパネルから、すべてのブックマークをタイトルや URL で検索できます。ブックマークマネージャーでは検索条件に名前を付けて保存できます。[検索と保存した検索](/guides/search)をご覧ください。
- **整理する**: 表示中のページやリンクを任意のフォルダに保存し、フォルダをドラッグして整え、削除しても元に戻せます。[保存と整理](/guides/save-and-organize)をご覧ください。
- **クリーンアップする**: 重複したブックマークを削除し、トラッキングパラメータを取り除き、リンク切れを見つけて修復できます。[重複とトラッキング URL のクリーンアップ](/guides/clean-up)と[リンク切れの検出と修復](/guides/dead-links)をご覧ください。
- **ライブラリを移す**: HTML、JSON、Markdown、CSV にエクスポートでき、HTML や JSON はプレビューしてからインポートできます。[インポートとエクスポート](/guides/import-export)をご覧ください。
- **AI は使いたいときだけ**: AI ツールは初期設定でオフです。オンにする場合は、プロバイダーを自分で選び、自分のキーを使います。[AI ツールの設定](/guides/ai-tools)をご覧ください。

## データの行き先 [#where-your-data-goes]

Bookmark Scout にはアカウントも専用のサーバーもありません。ブックマークはブラウザの中にとどまります。データがブラウザの外に出るのは、リンク切れの確認や、自分でオンにした AI ツールなど、ネットワークが必要な機能を使ったときだけです。その場合も、データは自分で選んだウェブサイトやプロバイダーへ直接送られます。[プライバシーの概要](/privacy)をお読みください。

## ブラウザ [#browsers]

主な対象は Chrome です。Edge も Chromium ベースで、同じエンドツーエンドテストを実行しています。Firefox ではブックマークページを置き換えられないため、マネージャーはポップアップのボタンから開きます。また、ブラウザの機能がいくつか異なります。詳しくは[ブラウザ対応](/browser-support)をご覧ください。
