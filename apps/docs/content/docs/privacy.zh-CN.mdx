## 概要 [#in-short]

- **无需账号，没有服务器。** Bookmark Scout 在你的浏览器中运行。开发者不会从扩展程序收到任何内容。
- **没有遥测。** 扩展程序中没有分析功能、没有崩溃报告，也没有广告。
- **在你开启前 AI 始终关闭**，开启后，请求会从你的浏览器直接发送给你选择的服务商。在 Firefox 中，开启时还会请求你同意共享这些数据。
- **本地 AI 智能体仅在你允许时可用。** 开启**允许本地 AI 智能体**（默认关闭）后，你电脑上的 AI 智能体（如 Claude Code）可以通过 bookmark-scout-mcp 程序查找你的书签，但不能更改它们。
- **需要时才请求权限。** 安装时，扩展程序只请求缺少后就无法运行的权限；标签页访问、右键菜单、浏览器的图标缓存和网站访问权限都会在你首次使用相应功能时才请求。请参阅[权限](/permissions)。

## 扩展程序会读取的内容 [#what-the-extension-reads]

- 你的书签，用于显示、搜索、修改、移动、删除、导入和导出书签。
- 当前标签页的标题和网址，在你保存当前所在的网页或请求文件夹建议时读取。
- 在 Chrome 和 Edge 中开启**使用浏览器的图标缓存**后，从浏览器自身的图标缓存中读取的网站图标。
- 你通过**刷新网站图标**从各个已加入书签的网站下载的网站图标。

它不会读取你访问的网页的内容。

## 扩展程序会存储的内容 [#what-it-stores]

| 数据 | 存储位置 | 是否同步 |
| --- | --- | --- |
| 你改过默认值的设置，包括 AI 是否开启；不包括 AI 服务商、模型或 API 密钥 | 浏览器同步存储空间 | 是，开启浏览器同步后通过你的浏览器账号同步 |
| 设备专属设置：快速保存选定的文件夹、图标存储上限、AI 活动记录、询问 AI 的联网搜索 | 本设备上的本地存储空间 | 否 |
| 本地 AI 智能体设置（是否开启、隐藏隐私值、已关闭的查找）以及此浏览器配置文件的随机 ID | 此设备的本地存储 | 否 |
| 自定义提示词（**AI 工具**中的**提示词**）：每个提示词的名称、任务和正文，以及每个任务使用哪个提示词；最多 10 个 | 浏览器同步存储空间 | 与设置相同 |
| 书签管理器中的书签表格：显示的列、列的顺序和排序方式 | 浏览器同步存储空间 | 与设置相同 |
| 书签表格的列宽和每页条数 | 本设备上的本地存储空间 | 否 |
| AI 服务：每个服务的名称、服务商和模型 | 本设备上的本地存储空间 | 否 |
| AI 连接设置：API 密钥、API 地址、额外请求头、服务商特有的字段 | 本设备上的本地存储空间 | 否，也绝不会写入备份文件 |
| 从你的 AI 服务获取的模型列表，保留 7 天 | 本设备上的本地存储空间 | 否 |
| AI 活动记录，仅在开启**记录请求**期间（默认关闭，每台设备单独设置）：最近的 AI 请求，以及发送的内容和返回的内容，其中包含书签标题、网址、文件夹路径，开启**读取网页内容**时还包含网页文本。API 密钥等凭据会在保存前移除；关闭记录即删除 | 本设备上的本地存储空间 | 否 |
| 标签、摘要、已保存的搜索、最近文件夹、最近搜索 | 本设备上的本地存储空间 | 否 |
| 通过**刷新网站图标**保存的网站图标，默认最多 4096 KB | 本设备上的本地存储空间 | 否 |
| 最近一次快速保存（网页的标题和网址以及保存位置），用于**撤消**和**移动到** | 本设备上的会话存储空间，关闭浏览器即清除 | 否 |

工具侧栏的扫描结果只在其对话框打开期间保留。卸载扩展程序会移除它存储的内容；你的书签会保留在浏览器中。

设置页面底部的**导出**会把你更改过的设置、自定义提示词、AI 服务（名称、服务商和模型）、已保存的搜索以及表格的列和排序保存为备份文件。其中绝不包含 API 密钥或其他 AI 连接设置，文件也不加密。请参阅[设置](/settings)。

## 数据何时会离开你的浏览器 [#when-data-leaves-your-browser]

仅在你使用以下功能时，并且只会发送到所列的目的地：

| 功能 | 发送到 | 发送的内容 |
| --- | --- | --- |
| AI 文件夹推荐 | 你配置的 AI 服务商 | 当前网页的标题和网址，以及你的文件夹名称。开启**读取网页内容**后，还包括网页正文 |
| 自动标签、内容摘要、AI 文件夹重组 | 你配置的 AI 服务商 | 所选范围内书签的标题、网址和文件夹路径。开启**读取网页内容**后，自动标签和内容摘要还会发送每个网页的正文；AI 文件夹重组永远不会发送 |
| 询问 AI | 你配置的 AI 服务商 | 你的消息和目前为止的对话内容，以及 AI 为回答问题而查找的内容：匹配的书签（包括所在文件夹、添加日期、标签和摘要）、文件夹名称、当前网页的标题和网址、它检查过的书签链接是否仍然有效；开启**读取网页内容**后，还包括它读取的网页文本。开启网页搜索后，服务商还会搜索网络。对话不会被保存 |
| 检查失效链接、元数据获取、询问 AI 的链接检查 | 各个已加入书签的网站 | 在你允许网站访问后，发送一个不带 Cookie 的网页请求 |
| 刷新网站图标 | 各个已加入书签的网站 | 在你允许网站访问后，每个网站请求一个已加入书签的网页，并请求该网站域名下的一个图标文件，均不带 Cookie。不使用任何第三方图标服务 |
| 本地 AI 智能体，仅在开启**允许本地 AI 智能体**时（默认关闭） | 你电脑上的 bookmark-scout-mcp 程序，以及你在那里运行的 AI 智能体 | 智能体请求的内容：匹配的书签（含文件夹、添加日期、标签和摘要）、文件夹名称、当前网页的标题和 URL、书签链接是否仍然有效（在你允许访问网站之后），以及开启**读取网页内容**时网页的文字。除非你关闭此项，标题和 URL 中的隐私值会被隐藏。智能体可能会把读取的内容发送给它自己的 AI 服务商。开启**记录请求**时，每次查找都会出现在 AI 活动中 |

在你自己电脑上运行的服务商（例如 Ollama）会将 AI 请求保留在你的计算机上。书签导出、**AI 上下文打包**文件和设置备份都会以文件形式保存在你的电脑上，不会上传到任何地方。JSON 格式的书签导出还包含每个书签的标签和摘要；书签导出和 AI 上下文导出前的隐私检查可以先对敏感值进行脱敏。每个 AI 工具发送的具体数据列在[设置 AI 工具](/guides/ai-tools#what-each-tool-sends)中，每项权限的说明见[权限](/permissions)。
