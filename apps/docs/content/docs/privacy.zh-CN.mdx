## 概要 [#in-short]

- **无需账号，没有服务器。** Bookmark Scout 在你的浏览器中运行。开发者不会从扩展程序收到任何内容。
- **没有遥测。** 扩展程序中没有分析功能、没有崩溃报告，也没有广告。
- **在你开启前 AI 始终关闭**，开启后，请求会从你的浏览器直接发送给你选择的服务商。在 Firefox 中，开启时还会请求你同意共享这些数据。使用 Chrome 内置 AI 时，文件夹推荐会留在你的电脑上。
- **本地 AI 智能体仅在你允许时可用。** 开启**允许本地 AI 智能体**（默认关闭）后，你电脑上的 AI 智能体（如 Claude Code）可以通过 bookmark-scout-mcp 程序查找你的书签，只有开启**允许更改**后才能更改，且每次更改都要经你批准。
- **需要时才请求权限。** 安装时，扩展程序只请求缺少后就无法运行的权限；标签页访问、右键菜单、浏览器的图标缓存和网站访问权限都会在你首次使用相应功能时才请求。请参阅[权限](/permissions)。

## 扩展程序会读取的内容 [#what-the-extension-reads]

- 你的书签，用于显示、搜索、修改、移动、删除、导入和导出书签。
- 当前标签页的标题和网址，在你保存当前所在的网页（通过弹出窗口、侧边栏或快速保存快捷键）或请求文件夹建议时读取。
- 在 Chrome 和 Edge 中开启**使用浏览器的图标缓存**后，从浏览器自身的图标缓存中读取的网站图标。
- 你通过**刷新网站图标**从各个已加入书签的网站下载的网站图标。
- 书签网页的正文：在你运行**索引网页正文**时，从本次运行的每个网页读取。或者在你点击弹出窗口中的“**索引此网页的正文**”时，读取你正在查看的标签页的正文（与你看到的一致）。
- 书签网页的头部及其指定的预览图：在你运行**获取封面**时，从本次运行的每个网页读取。或者在弹出窗口中点击“**用当前画面作为封面**”时，截取你正在查看的标签页画面。
- 你在正在查看的标签页中打开的已加入书签网页的画面：在它加载完成后，且仅在**浏览时捕获封面**开启期间（默认关闭）截取；绝不截取**永不捕获这些网站**中的网站，只有在你还开启了**也在无痕窗口中捕获**且浏览器允许扩展程序在隐私窗口中运行时，才会在隐私窗口中截取。开启期间，当前标签页中加载的每个网页的地址都会与你的书签比对，但不会保留。
- 在**启用获取封面**和**快速保存时保存封面**开启时快速保存网页，会为它保存封面：该标签页中网页指定的预览图片（只从网页自己的网站或你允许的网站下载），或在你按下快捷键时截取的该标签页画面，不经预览直接保存。私密窗口中以及**永不捕获这些网站**或**从不读取这些网站**中的网站都不会这样做。封面只保存在此设备上。

它不会读取你访问的网页的内容，除非你在弹出窗口中点击“**索引此网页的正文**”，这时会读取你正在查看的标签页的正文，保存前你会先看到它；另外，**浏览时捕获封面**开启期间，它会截取已加入书签网页的画面，这些截图只保存在此设备上。按下快速保存快捷键后，它会在该标签页中显示自己的通知，该通知不会从网页读取任何内容。开启**快速保存时保存封面**和获取封面后，快速保存还会读取网页的预览图片标签，并可能截取该标签页的画面，如上所述。

| --- | --- | --- |
| 你改过默认值的设置，包括 AI 是否开启；不包括 AI 服务商、模型或 API 密钥 | 浏览器同步存储空间 | 是，开启浏览器同步后通过你的浏览器账号同步 |
| 设备专属设置：快速保存选定的文件夹、图标存储上限、AI 活动记录、询问 AI 的联网搜索 | 本设备上的本地存储空间 | 否 |
| 本地 AI 智能体设置（是否开启、隐藏隐私值、已关闭的查找）以及此浏览器配置文件的随机 ID | 本设备上的本地存储空间 | 否 |
| 自定义提示词（**AI 工具**中的**提示词**）：每个提示词的名称、任务和正文，以及每个任务使用哪个提示词；最多 10 个 | 浏览器同步存储空间 | 与设置相同 |
| 关于我（**AI** 设置）：你写的关于自己的内容；最多 1,000 个字符 | 浏览器同步存储空间 | 与设置相同；有内容时还会随 AI 请求发送给你的 AI 服务商 |
| 书签管理器中的书签表格：显示的列、列的顺序和排序方式 | 浏览器同步存储空间 | 与设置相同 |
| 书签表格的列宽和每页条数 | 本设备上的本地存储空间 | 否 |
| AI 服务：每个服务的名称、服务商和模型 | 本设备上的本地存储空间 | 否 |
| AI 连接设置：API 密钥、API 地址、额外请求头、服务商特有的字段 | 本设备上的本地存储空间 | 否。备份文件包含 API 地址和服务商特有的字段；只有当你选择**AI 服务密钥**并确认警告时，才会包含 API 密钥和额外请求头，并且除非你关闭，否则会用密码保护 |
| 从你的 AI 服务获取的模型列表，保留 7 天 | 本设备上的本地存储空间 | 否 |
| AI 活动记录，仅在开启**记录请求**期间（默认关闭，每台设备单独设置）：最近的 AI 请求，以及发送的内容和返回的内容，其中包含书签标题、网址、文件夹路径，开启**读取网页内容**时还包含网页文本。API 密钥等凭据会在保存前移除；关闭记录即删除 | 本设备上的本地存储空间 | 否 |
| 标签、摘要、已保存的搜索、智能规则、智能规则所做更改（自动添加的标签和移动，以及经审阅的运行添加了标签的书签）的列表、每条规则的上次运行及其发现规则意见不一的书签、最近文件夹、最近搜索 | 本设备上的本地存储空间 | 否 |
| 通过**刷新网站图标**保存的网站图标，默认最多 4 MB | 本设备上的本地存储空间 | 否 |
| 用**索引网页正文**或“**索引此网页的正文**”保存的网页正文，以及读取方式（下载，或来自你的标签页）、读取它的地址、正文的指纹和是否被截断；删除书签、撤销扩展程序对其网站的访问权限，或将其网站加入 **从不读取这些网站** 时删除 | 此设备上的 IndexedDB | 否 |
| 用**获取封面**、**用当前画面作为封面**或**浏览时捕获封面**保存的封面，各自注明来源，以及**快速保存时保存封面**保存的封面；只有选择**封面**时才会写入备份文件；删除书签时随之删除 | 此设备上的 IndexedDB | 否 |
| 最近一次快速保存（网页的标题和网址以及保存位置，以及它替换的封面的副本，以便**移除封面**把它放回），用于**撤消**和**移动到** | 本设备上的会话存储空间，关闭浏览器即清除 | 否 |
| 书签管理器的撤消历史记录（你在其中更改过的书签，以及已删除书签的副本及其标签和摘要），用于撤消和重做 | 本设备上的会话存储空间，关闭浏览器即清除 | 否 |
| 书签更改历史记录：你的书签何时更改了什么，无论是 Bookmark Scout 所做还是从其他地方观察到的（标题、网址、文件夹以及每次更改的结果），保留一段时间；以及每个书签最近一次看到时的标题、网址和文件夹副本，用于判断 Bookmark Scout 之外发生的更改。另外还保存 Bookmark Scout 删除的每个项目的副本（包括里面的内容、标签和摘要），以便从历史记录中恢复；副本随对应的更改一起删除。历史记录还会列出你恢复的每个备份：哪些内容、合并还是替换、每项新增、更改或删除了多少项，以及文件名。不在备份文件中 | 此设备上的 IndexedDB | 否 |
| **撤消导入**的安全副本：在**恢复设置**更改任何内容之前，你导入的各项内容原有的数据（设置、提示词、AI 服务，以及在你导入密钥时被替换的 API 密钥，还有被替换的封面）；24 小时后、使用**撤消导入**时或下一次恢复时删除。不在备份文件中 | 此设备上的 IndexedDB | 否 |
| 后台任务（关闭页面后仍继续运行的工具，例如 **检查失效链接**、**元数据获取**、**刷新网站图标**、**索引网页正文** 或 **AI 文件夹重组**，或者大规模的 **智能规则** 运行）：它检查的书签（标题、网址和文件夹）及每项结果（例如页面的标题和描述、网站的图标、页面的可读正文、AI 服务建议的移动，或它要应用的已审阅更改：哪个书签，以及新的标题、网址、文件夹或标签），以便重启后继续任务，并让你稍后查看结果；保留一段有限的时间，或直到你在 **后台任务** 中删除该任务。不包含在备份文件中。保存审阅结果后，或删除对应书签、撤销其网站的访问权限、在**从不读取这些网站**中加入其网站时，页面的可读正文会被删除 | 此设备上的 IndexedDB | 否 |

工具侧栏的扫描结果只在其对话框打开期间保留。卸载扩展程序会移除它存储的内容；你的书签会保留在浏览器中。

设置页面底部的**备份设置**会把你选择的内容保存为备份文件：你更改过的设置、此电脑自己的设置（除非你选择，否则不会选中）、已保存的搜索以及表格的列和排序、自定义提示词和“关于我”、智能规则、AI 服务（名称、服务商、模型、API 地址以及服务商特有的字段），以及封面（每张封面图片及其书签的地址、来源和保存时间）。只有当你选择**AI 服务密钥**并确认任何拿到文件的人都能使用它们时，文件中才会包含 API 密钥和额外请求头；此时，除非你关闭，否则它们会用密码保护。你也可以用密码保护整个文件。密码绝不会被保存或发送，忘记的密码也无法找回。文件保存在你的电脑上，不会发送到任何地方。见[备份和恢复设置](/guides/import-export#back-up-and-restore-settings)。

## 数据何时会离开你的浏览器 [#when-data-leaves-your-browser]

仅在你使用以下功能时，并且只会发送到所列的目的地：

| 功能 | 发送到 | 发送的内容 |
| --- | --- | --- |
| AI 文件夹推荐，包括 AI 快速保存快捷键 | 你配置的 AI 服务商 | 当前网页的标题和网址，以及你的文件夹名称。开启**读取网页内容**后，还包括网页正文 |
| 自动标签、内容摘要、AI 文件夹重组 | 你配置的 AI 服务商 | 所选范围内书签的标题、网址和文件夹路径。开启**读取网页内容**后，自动标签和内容摘要还会发送每个网页的正文；AI 文件夹重组永远不会发送。除非关闭**发送现有标签**，自动标签还会发送你最常用的标签名称 |
| 询问 AI | 你配置的 AI 服务商 | 你的消息和目前为止的对话内容，以及 AI 为回答问题而查找的内容：匹配的书签（包括所在文件夹、添加日期、标签和摘要）、文件夹名称、当前网页的标题和网址、它检查过的书签链接是否仍然有效；开启**读取网页内容**后，还包括它读取的网页文本。开启网页搜索后，服务商还会搜索网络。对话不会被保存 |
| 检查失效链接、元数据获取、询问 AI 的链接检查 | 各个已加入书签的网站 | 在你允许网站访问后，发送一个不带 Cookie 的网页请求 |
| 刷新网站图标 | 各个已加入书签的网站 | 在你允许网站访问后，每个网站请求一个已加入书签的网页，并请求该网站域名下的一个图标文件，均不带 Cookie。不使用任何第三方图标服务 |
| 索引网页正文 | 本次运行中的每个书签网页，同一地址只请求一次；除非你关闭 **跳过含登录信息或机密的地址**，否则不请求包含用户名和密码或令牌等敏感参数的地址；从不请求 **从不读取这些网站** 中的网站 | 在你允许访问网站后，不带 Cookie 请求该网页；对于回应繁忙的网站，在其指定的短暂等待之后再次请求，最多几次。可读正文只保存在此设备上 |
| 获取封面 | 本次运行中的每个书签网页及其指定的图片 | 仅在你允许的网站上，不带 Cookie 和网页地址请求网页头部及其图片。小副本保存在此设备上 |
| 快速保存时保存封面（仅在获取封面开启时） | 你快速保存的网页，当它在自己的网站或你允许的网站上指定了预览图片时 | 请求该图片，不带 Cookie，也不带网页地址。一份小副本（或改为标签页的截图）保存在此设备上 |
| 本地 AI 智能体，仅在开启**允许本地 AI 智能体**时（默认关闭） | 你电脑上的 bookmark-scout-mcp 程序，以及你在那里运行的 AI 智能体 | 智能体请求的内容：匹配的书签（含文件夹、添加日期、标签和摘要）、文件夹名称、当前网页的标题和网址、书签链接是否仍然有效（在你允许访问网站之后），以及开启**读取网页内容**时网页的文字。除非你关闭此项，标题和网址中的隐私值会被隐藏。智能体可能会把读取的内容发送给它自己的 AI 服务商。开启**记录请求**时，每次查找都会出现在 AI 活动中 |

使用服务商的每项 AI 功能，在**关于我**（AI 设置）有内容时也会发送它；默认为空。

在你自己电脑上运行的服务商（例如 Ollama）会将 AI 请求保留在你的计算机上。Chrome 内置 AI 也一样：它用你电脑上的 Chrome 自带模型生成文件夹推荐，无需 API 密钥；该模型由 Chrome 在你要求时从 Google 下载一次，不含你的任何数据。书签导出、**AI 上下文打包**文件和设置备份都会以文件形式保存在你的电脑上，不会上传到任何地方。JSON 格式的书签导出还包含每个书签的标签和摘要；书签导出和 AI 上下文导出前的隐私检查可以先对敏感值进行脱敏。每个 AI 工具发送的具体数据列在[设置 AI 工具](/guides/ai-tools#what-each-tool-sends)中，每项权限的说明见[权限](/permissions)。
