## Kurz gesagt [#in-short]

- **Kein Konto und kein Server.** Bookmark Scout läuft in Ihrem Browser. Der Entwickler erhält nichts von der Erweiterung.
- **Keine Telemetrie.** Keine Analyse, keine Absturzberichte und keine Werbung in der Erweiterung.
- **KI bleibt aus, bis Sie sie aktivieren**, und dann gehen Anfragen direkt von Ihrem Browser an den von Ihnen gewählten Anbieter. In Firefox werden Sie beim Aktivieren außerdem um Ihre Einwilligung gebeten, diese Daten zu teilen. Mit der integrierten KI von Chrome bleiben Ordnervorschläge auf Ihrem Computer.
- **Lokale KI-Agenten nur, wenn Sie sie zulassen.** Mit **Lokale KI-Agenten zulassen** (standardmäßig aus) können KI-Agenten auf Ihrem Computer, etwa Claude Code, Ihre Lesezeichen über das Programm bookmark-scout-mcp nachschlagen; ändern können sie sie nur mit **Änderungen erlauben**, jede Änderung erst nach Ihrer Zustimmung.
- **Berechtigungen erst bei Bedarf.** Bei der Installation fragt die Erweiterung nur nach dem, ohne das sie nicht funktioniert; Zugriff auf Tabs, das Rechtsklickmenü, der Symbol-Cache des Browsers und der Zugriff auf Websites werden erst angefragt, wenn Sie die Funktion zum ersten Mal verwenden. Siehe [Berechtigungen](/permissions).

## Was die Erweiterung liest [#what-the-extension-reads]

- Ihre Lesezeichen, um sie anzuzeigen, zu durchsuchen, zu bearbeiten, zu verschieben, zu löschen, zu importieren und zu exportieren.
- Titel und URL des aktiven Tabs, wenn Sie die aktuelle Seite speichern (über das Pop-up, die Seitenleiste oder ein Tastenkürzel zum Schnellspeichern) oder einen Ordnervorschlag anfordern.
- Website-Symbole aus dem eigenen Symbol-Cache des Browsers, in Chrome und Edge, sobald Sie **Symbol-Cache des Browsers verwenden** aktivieren.
- Website-Symbole, die Sie mit **Website-Symbole aktualisieren** herunterladen, von der jeweiligen gespeicherten Website.
- Der Text gespeicherter Seiten, wenn Sie **Seitentext indexieren** ausführen, von jeder Seite des Laufs. Oder der Text des Tabs, den Sie gerade ansehen, so wie Sie ihn sehen, wenn Sie im Pop-up auf **Text dieser Seite indexieren** klicken.
- Der Kopf gespeicherter Seiten und das Vorschaubild, das jede angibt, wenn Sie **Titelbilder laden** ausführen, von jeder Seite des Laufs. Oder ein Bild des Tabs, den Sie gerade ansehen, wenn Sie im Pop-up auf **Diese Ansicht als Titelbild verwenden** klicken.
- Ein Bild einer gespeicherten Seite, die Sie im Tab öffnen, den Sie gerade ansehen, sobald sie geladen ist, solange **Titelbilder beim Surfen aufnehmen** aktiviert ist (standardmäßig aus); nie von einer Website in **Diese Websites nie aufnehmen**, und in einem privaten Fenster nur, wenn Sie zusätzlich **Auch in privaten Fenstern aufnehmen** einschalten und Ihr Browser die Erweiterung dort ausführen lässt. Solange es aktiviert ist, wird die Adresse jeder Seite, die in Ihrem aktiven Tab lädt, mit Ihren Lesezeichen verglichen und nicht behalten.
- Wenn Sie eine Seite schnell speichern, während **Titelbilder laden aktivieren** und **Beim Schnellspeichern ein Titelbild speichern** an sind, ein Titelbild dafür: das Vorschaubild, das die Seite in diesem Tab nennt, nur von ihrer eigenen Website oder einer erlaubten Website geladen, oder ein Bild dieses Tabs, beim Drücken des Tastenkürzels aufgenommen und ohne Prüfung behalten. Nie in einem privaten Fenster und nie auf einer Website unter **Diese Websites nie aufnehmen** oder **Diese Websites nie lesen**. Es bleibt auf diesem Gerät.

Sie liest nicht den Inhalt der Seiten, die Sie besuchen, außer dem Text des Tabs, den Sie gerade ansehen, wenn Sie im Pop-up auf **Text dieser Seite indexieren** klicken (Sie sehen ihn, bevor er behalten wird), und den Bildern, die **Titelbilder beim Surfen aufnehmen** von gespeicherten Seiten aufnimmt, solange es aktiviert ist; diese bleiben auf diesem Gerät. Nach einem Tastenkürzel zum Schnellspeichern zeigt sie in diesem Tab ihre eigene Benachrichtigung an, die nichts aus der Seite liest. Mit **Beim Schnellspeichern ein Titelbild speichern** und „Titelbilder laden“ liest das Schnellspeichern außerdem die Vorschaubild-Tags der Seite und kann ein Bild dieses Tabs aufnehmen, wie oben beschrieben.

## Wann Daten Ihren Browser verlassen [#when-data-leaves-your-browser]

Nur wenn Sie eine dieser Funktionen verwenden, und nur an das genannte Ziel:

| Funktion | Ziel | Was gesendet wird |
| --- | --- | --- |
| KI-Ordnervorschläge, einschließlich des KI-Tastenkürzels zum Schnellspeichern | Der von Ihnen eingerichtete KI-Anbieter | Titel und URL der aktuellen Seite sowie Ihre Ordnernamen. Mit aktiviertem **Seiteninhalt lesen** auch der Haupttext der Seite |
| Automatische Tags, Inhaltszusammenfassung, KI-Ordnerneuordnung | Der von Ihnen eingerichtete KI-Anbieter | Titel, URLs und Ordnerpfade der Lesezeichen im Bereich. Mit aktiviertem **Seiteninhalt lesen** senden Automatische Tags und Inhaltszusammenfassung zusätzlich den Haupttext jeder Seite; die KI-Ordnerneuordnung tut das nie. Automatische Tags sendet außerdem die Namen Ihrer meistverwendeten Tags, sofern **Vorhandene Tags senden** nicht deaktiviert ist |
| KI fragen | Der von Ihnen eingerichtete KI-Anbieter | Ihre Nachrichten und der bisherige Gesprächsverlauf sowie das, was die KI für die Antwort nachschlägt: passende Lesezeichen (mit Ordner, Datum des Hinzufügens, Tags und Zusammenfassung), Ordnernamen, Titel und URL der aktuellen Seite, ob von ihr geprüfte gespeicherte Links noch funktionieren und mit aktiviertem **Seiteninhalt lesen** der Text der Seiten, die sie liest. Ist die Websuche aktiviert, sucht der Anbieter zusätzlich im Web. Das Gespräch wird nicht gespeichert |
| Defekte Links prüfen, Metadatenabruf, Linkprüfung in KI fragen | Jede gespeicherte Website | Eine Anfrage nach der Seite, ohne Cookies, nachdem Sie den Zugriff auf Websites erlaubt haben |
| Website-Symbole aktualisieren | Jede gespeicherte Website | Eine Anfrage nach einer gespeicherten Seite pro Website und nach einer Symboldatei auf der Domain dieser Website, ohne Cookies, nachdem Sie den Zugriff auf Websites erlaubt haben. Es wird kein Symboldienst von Dritten verwendet |
| Seitentext indexieren | Jede gespeicherte Seite des Laufs, einmal je Adresse; keine Adresse mit einem Benutzernamen und Passwort oder einem sensiblen Parameter wie einem Token, außer Sie schalten **Adressen mit Anmeldedaten oder Geheimnissen überspringen** aus; nie eine Website unter **Diese Websites nie lesen** | Eine Anfrage für die Seite, ohne Cookies, nachdem Sie den Websitezugriff erlaubt haben; eine Website, die meldet, dass sie ausgelastet ist, wird nach der kurzen Wartezeit, die sie nennt, höchstens ein paar Mal erneut angefragt. Ihr lesbarer Text bleibt auf diesem Gerät |
| Titelbilder laden | Jede gespeicherte Seite des Laufs und das Bild, das sie angibt | Eine Anfrage für den Kopf der Seite und für ihr Bild, ohne Cookies und ohne die Adresse der Seite, nur auf Websites, die Sie erlaubt haben. Eine kleine Kopie bleibt auf diesem Gerät |
| Beim Schnellspeichern ein Titelbild speichern, nur mit „Titelbilder laden“ | Die Seite, die Sie schnell speichern, wenn sie ein Vorschaubild auf ihrer eigenen oder einer erlaubten Website nennt | Eine Anfrage für dieses Bild, ohne Cookies und ohne die Adresse der Seite. Eine kleine Kopie, oder stattdessen ein Bild des Tabs, bleibt auf diesem Gerät |
| Lokale KI-Agenten, nur mit **Lokale KI-Agenten zulassen** (standardmäßig aus) | Das Programm bookmark-scout-mcp auf Ihrem Computer und die KI-Agenten, die Sie dort ausführen | Was ein Agent anfragt: passende Lesezeichen (mit Ordnern, Hinzufügedatum, Tags und Zusammenfassungen), Ordnernamen, Titel und URL der aktuellen Seite, ob Lesezeichen-Links noch funktionieren (nachdem Sie den Zugriff auf Websites erlaubt haben) und bei aktiviertem **Seiteninhalt lesen** den Text einer Seite. Private Werte in Titeln und URLs werden ausgeblendet, sofern Sie das nicht ausschalten. Agenten können Gelesenes an ihren eigenen KI-Anbieter senden. Jede Abfrage steht in der KI-Aktivität, solange **Anfragen aufzeichnen** aktiviert ist |

Jede KI-Funktion, die einen Anbieter nutzt, sendet außerdem Ihren Text unter **Über mich** (KI-Einstellungen), solange er nicht leer ist; standardmäßig ist er leer.

Ein Anbieter, der auf Ihrem eigenen Computer läuft, etwa Ollama, hält KI-Anfragen auf Ihrem Rechner. Das gilt auch für die integrierte KI von Chrome: Sie erstellt Ordnervorschläge mit dem eigenen Modell von Chrome auf Ihrem Computer, ohne API-Schlüssel, und Chrome lädt dieses Modell einmal von Google herunter, wenn Sie es wünschen, ohne Ihre Daten. Lesezeichenexporte, Dateien aus **KI-Kontextpaket** und die Sicherung der Einstellungen werden als Dateien auf Ihrem Computer gespeichert und nirgendwohin hochgeladen. Ein JSON-Lesezeichenexport enthält auch die Tags und die Zusammenfassung jedes Lesezeichens; bei Lesezeichen- und KI-Kontextexporten kann eine Datenschutzprüfung sensible Werte vorher schwärzen. Welche Daten jedes KI-Tool genau sendet, steht unter [KI-Tools einrichten](/guides/ai-tools#what-each-tool-sends), und jede Berechtigung wird unter [Berechtigungen](/permissions) erklärt.
