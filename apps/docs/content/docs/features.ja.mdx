現在提供している機能のリファレンス一覧です。手順については、各セクションにリンクしたガイドをご覧ください。部分的な機能や予定している機能は[プロジェクトの状況](/status)に、各ブラウザで使える機能は[ブラウザ対応](/browser-support)に記載しています。

## 動作する場所 [#where-it-runs]

| 画面 | 内容 |
| --- | --- |
| ポップアップ | ツールバーのボタン: 検索、フォルダツリー、保存、AI によるフォルダの提案 |
| サイドパネル | ブラウザのサイドパネル（Firefox ではサイドバー）に表示される同じ画面。ブラウズ中も開いたままです |
| ブックマークマネージャー | Chrome と Edge でブラウザのブックマークページを置き換えます: フォルダツリー、パンくずリスト、ブックマークの表、**ツール** サイドバー。狭いウィンドウでは、フォルダツリーと **ツール** は表の上に重ねて開きます。深いフォルダパスでは、途中のフォルダが **…** メニューにまとめられます |
| 設定 | 拡張機能のオプションページで、10 個のタブがあります。[設定](/settings)をご覧ください |
| すべてのページ | `Alt+Shift+S` と `Alt+Shift+D` で、表示中のページをクイック保存します。ページ内に通知が表示されます |
| 右クリックメニュー | **右クリックメニュー** をオンにすると、任意のリンクで **ブックマークの保存先...** が使えます |

## 探す [#find]

- 入力と同時にタイトルと URL を検索し、一致した部分を強調表示します。**その他の検索オプション** から、大文字/小文字の区別、単語全体、パターン検索（正規表現）のオプションを使えます。一致するフォルダは自動的に開きます。
- このデバイスに保存される最近の検索。消去したりオフにしたりできます。
- マネージャーの表のフィルター（タイトル、URL、種類、フォルダ、ドメイン、追加日）と、任意の列での並べ替え。
- 保存した検索: 名前を付けたフィルターのセットで、開くたびに現在のブックマークに対して評価されます。最大 50 件まで、このデバイスに保存されます。

ガイド: [検索と保存した検索](/guides/search)

## 保存と整理 [#save-and-organize]

- 現在のページを任意のフォルダに保存します。同じフォルダに二重に保存することはなく、使ったフォルダを表示する **最近** パネルがあります。
- フォルダ名の一部や `work/react` のようなパスを入力し、結果の上に表示される一致したフォルダのいずれかに保存します。
- どのページでも `Alt+Shift+S` でクイック保存できます。保存先は、ページに最もよく一致するフォルダ（デバイス上で順位付け）、最後に使ったフォルダ、自分で選んだフォルダのいずれかです。`Alt+Shift+D` は AI の最初の提案に保存します。ページ内の通知には、**元に戻す** と、**移動先** の下にほかのフォルダが表示されます。Chrome と Edge では、クイック保存に `Ctrl+D` を割り当てられます。
- 右クリックメニューから、最近のフォルダやブックマークバーにリンクを保存します。
- フォルダの作成、ブックマークとフォルダのドラッグ＆ドロップ、マネージャーでの複数項目の一括移動ができます。
- 追加日順、自然なアルファベット順、フォルダ優先で並べ替えられます。ブラウザに保存されている順序は変わりません。
- 名前と URL を編集し、**ブックマークの詳細** でタグと要約を追加できます。
- 任意の確認付きで削除でき、10 秒間は元に戻せます。元に戻すとフォルダ内のすべての項目が復元されます。
- マネージャーでは、表の列幅をドラッグや矢印キーで変更でき、**表示をリセット** でレイアウトを元に戻せます。
- マネージャーのアドレスにはフォルダや検索が含まれる（`?id=`、`?q=`）ため、**戻る**、**進む**、ブックマークしたリンクが使え、Chrome 自体のフォルダへのリンクも開けます。**このフォルダへのリンクをコピー** でリンクをコピーできます。
- Chrome がブックマークを Google アカウントとこのデバイスのみの両方に保存している場合、マネージャーのフォルダツリーには Chrome と同じように 2 つのセクションに分けて表示されます。
- **リンクを開く場所** で、クリックしたリンクを新しいタブ、バックグラウンドのタブ、現在のタブのどれで開くかを選べます。

ガイド: [保存と整理](/guides/save-and-organize)

## クリーンアップ [#clean-up]

- **重複クリーナー**: 照合方法を設定して重複を見つけ、確認した後に余分なコピーを削除します。元に戻せます。
- **URLクリーナー**: プレビューした後に `utm_source` などのトラッキングパラメータを取り除きます。
- **リンク切れチェック**: リンク切れが確定したものと手動での確認が必要なものを区別し、削除、リダイレクト先の使用、Wayback Machine のリンクの使用、URL の編集で修復します。元に戻せます。
- **メタデータ取得**: 実際のページの head 部分だけを読み取ってタイトルを提案し、選んだものを適用します。説明は確認用に表示されるだけで、保存されることはありません。
- **サイトアイコンを更新**: 確認した後に各ウェブサイト自身のアイコンをダウンロードします。ブラウザにキャッシュがない場合や Firefox でも、ブックマークにアイコンが表示されます。アイコンはこのデバイスに保存され、消去できます。
- **プライバシースキャナー**: トークン、機密パラメータ、メールアドレス、UUID を含む URL（オプションでタイトルも）を検出します。
- **ブックマーク統計**: フォルダ単位またはすべてのブックマークについて、上位のドメインとフォルダ、プロトコル、重複、フォルダの階層の深さを表示します。

ガイド: [重複とトラッキング URL のクリーンアップ](/guides/clean-up)、[リンク切れの検出と修復](/guides/dead-links)

## インポートとエクスポート [#import-and-export]

- HTML、JSON、Markdown、CSV にエクスポートします。プライバシーの確認画面で、ファイル内の機密性のある値を伏せ字にできます。
- インポート先フォルダ、件数、重複のプレビューを確認してから HTML や JSON をインポートします。元に戻せます。
- JSON のエクスポートには各ブックマークのタグと要約が含まれ、そのファイルをインポートすると復元されます。
- 拡張機能の設定、カスタムプロンプト、AI サービス（API キーを除く）、保存した検索、マネージャーの表の列を JSON ファイルにバックアップし、復元できます。

ガイド: [インポートとエクスポート](/guides/import-export)

## AI ツール（任意） [#ai-tools-optional]

初期設定でオフです。OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter、または models.dev カタログにあるほか約 200 のプロバイダーで自分のキーを使えます。Ollama、CLIProxyAPI、任意の OpenAI 互換エンドポイントも使えます。

- ポップアップでのフォルダの提案（新しいフォルダパスも確認してから作成します）と、`Alt+Shift+D` のクイック保存ショートカット。
- ポップアップとサイドパネルの **AI に質問**: ブックマーク、フォルダ、タグ、要約の検索、重複の検出、リンクの確認によって質問に答えます。ページを保存し、移動、名前の変更、削除、新しいフォルダを計画として提案します。計画は承認するまで何も変更せず、各変更は元に戻せます。回答の最後には、次にできることのボタンが表示されます。設定の **AI に質問でできること** で、任意の検索や変更をオフにできます。
- 現在のフォルダを対象とする **自動タグ付け** と **コンテンツ要約**。確認した後にだけ保存され、元に戻せます。
- **AIフォルダ整理**。何かを移動する前にプレビューし、元に戻せます。
- **AIコンテキストパッカー**。AI チャット用にブックマークを Markdown や XML で書き出し、AI がオフでも使えます。

タグと要約はこのデバイスに保存されます。同期されず、ポップアップでの検索対象にもなりませんが、AI に質問で調べることができ、JSON のブックマークエクスポートにも含まれます。ガイド: [AI ツールの設定](/guides/ai-tools)

## ローカル AI エージェント（任意） [#local-ai-agents-optional]

デバイスごとに、初期設定でオフです。**ローカル AI エージェントを許可** をオンにすると、Claude Code、Codex、Cursor など、コンピューター上の AI エージェントが、`bookmark-scout-mcp` プログラムを通じて Bookmark Scout の検索機能を使えます。このプログラムは、ブラウザのネイティブ メッセージングで拡張機能に接続する MCP サーバーです。**変更を許可** もオンにすると、エージェントはページを保存したり変更を提案したりできます。各変更は Bookmark Scout のウィンドウで承認されるまで待機し、マネージャーで元に戻せます。タイトルや URL に含まれる非公開の値は、初期設定でエージェントから隠されます。

ガイド: [ローカル AI エージェントと使う](/guides/local-agents)

## キーボードと言語 [#keyboard-and-language]

- どのページでも使えるクイック保存ショートカット。ブラウザのショートカット設定で変更でき、Firefox では Bookmark Scout の設定で直接変更できます。
- ポップアップとサイドパネルのショートカットは `Ctrl` や `Cmd` を使いません。マネージャーでは Chrome のブックマーク マネージャーと同じキー（すべて選択、元に戻す、やり直し、タブで開く）が使え、`?` でヘルプダイアログを表示できます。[キーボードショートカット](/guides/keyboard-shortcuts)をご覧ください。
- マネージャーでの Chrome と同じ選択操作: クリック、`Ctrl`+クリック、`Shift`+クリック、`Ctrl+A`。矢印キーで表とフォルダツリーを移動でき、フォルダツリーはスクリーンリーダーでツリーとして読み上げられます。
- マネージャーでの編集、移動、削除を、ブラウザのセッション中は `Ctrl+Z` と `Ctrl+Y` で元に戻したりやり直したりできます。
- マネージャーの行とフォルダの右クリックメニュー: 切り取り、コピー、貼り付け、すべてをタブ、新しいウィンドウ、シークレット ウィンドウで開く、名前の変更、削除。さらに **名前順に並べ替え** と **ブックマークを追加**、**フォルダを追加** があります。設定の **ブックマークマネージャーのメニュー** で、表示するコマンドとその順序を選べます。
- マネージャーでの Chrome と同じドラッグ＆ドロップ: 表やツリーのフォルダへのドロップ、ブラウザの順序での行の間へのドロップ、ほかのページからのリンクのドロップ。`Ctrl/Cmd+C`、`X`、`V` でコピー、移動、貼り付けができます。
- システム、ライト、ダークのテーマ。
- 英語、簡体字中国語、繁体字中国語、日本語、韓国語、スペイン語、ドイツ語、フランス語、ブラジルポルトガル語。
