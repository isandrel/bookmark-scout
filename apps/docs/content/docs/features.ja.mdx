現在提供している機能のリファレンス一覧です。手順については、各セクションにリンクしたガイドをご覧ください。部分的な機能や予定している機能は[プロジェクトの状況](/status)に、各ブラウザで使える機能は[ブラウザ対応](/browser-support)に記載しています。

## 動作する場所 [#where-it-runs]

| 画面 | 内容 |
| --- | --- |
| ポップアップ | ツールバーのボタン: 検索、フォルダツリー、保存、AI によるフォルダの提案 |
| サイドパネル | ブラウザのサイドパネル（Firefox ではサイドバー）に表示される同じ画面。ブラウズ中も開いたままです |
| ブックマークマネージャー | Chrome と Edge でブラウザのブックマークページを置き換えます: フォルダツリー、パンくずリスト、ブックマークの表、**ツール** サイドバー。狭いウィンドウでは、フォルダツリーと **ツール** は表の上に重ねて開きます。深いフォルダパスでは、途中のフォルダが **…** メニューにまとめられます |
| 設定 | 拡張機能の設定ページです。最初に **基本設定** があり、**詳細設定** の下にさらに 11 個のタブがあります。[設定](/settings)をご覧ください |
| すべてのページ | <Shortcut id="commands.quick-save" /> と <Shortcut id="commands.ai-quick-save" /> で、表示中のページをクイック保存します。ページ内に通知が表示されます |
| 右クリックメニュー | **右クリックメニュー** をオンにすると、リンクで **ブックマークの保存先...** が使えます。**メニューを表示する場所** で選べば、ページや選択したテキストでも使えます |

## 探す [#find]

- ポップアップ、サイドパネル、マネージャーで、入力と同時にタイトル、アドレス、フォルダ、タグ、要約を検索し、一致した部分を強調表示します。`tag:`、`domain:`、`after:` などの演算子で検索を絞り込み、`OR` で 2 つの語句のどちらかを見つけ、かっこでそれらをまとめます。マネージャーの **検索構文** に一覧があります。ポップアップでは一致するフォルダが自動的に開き、**その他の検索オプション** でタイトルに対する大文字/小文字の区別、単語全体、パターン検索（正規表現）を使えます。
- このデバイスに保存される最近の検索。消去したりオフにしたりできます。
- マネージャーの **フィルター**（種類、ドメイン、フォルダ、追加日、ウェブアドレス）。それぞれ削除できるチップとして表示され、任意の列で並べ替えられます。検索がアドレス、タグ、要約、ページ本文で見つけた行やカードには、どこで一致したかが表示されます。
- 保存した検索: 名前を付けたフィルターのセットで、開くたびに現在のブックマークに対して評価されます。最大 50 件まで、このデバイスに保存されます。
- **ページ本文の索引** をオンにすると、索引を作成したページの中の単語も検索で見つかります。`content:` はページ本文だけを探し、`has:content` は本文のあるブックマークを見つけます。[ページの中を検索](/guides/clean-up#search-inside-pages) を参照してください。
- マネージャーでは、**カード** に各ブックマークがカバー画像、タグ、要約とともに表示され、リストには **タグ** と **要約** の列を追加できます。**プレビュー**（<Shortcut id="manager.preview" />）でブックマークの詳細を表示します。ポップアップとサイドパネルでは、ブックマークにポインタを合わせると詳細がカードで表示されます（**ポインタを合わせて詳細を表示**）。

ガイド: [検索と保存した検索](/guides/search)

## 保存と整理 [#save-and-organize]

- 現在のページを任意のフォルダに保存します。同じフォルダに二重に保存することはなく、使ったフォルダを表示する **最近** パネルがあります。
- フォルダ名の一部や `work/react` のようなパスを入力し、結果の上に表示される一致したフォルダのいずれかに保存します。
- どのページでも <Shortcut id="commands.quick-save" /> でクイック保存できます。保存先は、ページに最もよく一致するフォルダ（デバイス上で順位付け）、最後に使ったフォルダ、自分で選んだフォルダのいずれかです。<Shortcut id="commands.ai-quick-save" /> は AI の最初の提案に保存します。ページ内の通知には、**元に戻す** と、**移動先** の下にほかのフォルダが表示されます。Chrome と Edge では、クイック保存に <Shortcut id="browser.bookmark_page" /> を割り当てられます。
- 右クリックメニューから、最近のフォルダやブックマークバーにリンク、ページ、選択したテキストを保存します。
- フォルダの作成、ブックマークとフォルダのドラッグ＆ドロップ、マネージャーでの複数項目の一括移動ができます。
- ブックマークをブラウザ自体の順序（既定）、追加日順、自然なアルファベット順、フォルダ優先で表示できます。ブラウザに保存されている順序は変わりません。
- 名前と URL を編集し、**ブックマークの詳細** でタグと要約を追加できます。
- 任意の確認付きで削除でき、10 秒間は元に戻せます。元に戻すとフォルダ内のすべての項目が復元されます。
- マネージャーでは、表の列幅をドラッグや矢印キーで変更でき、**表示をリセット** でレイアウトを元に戻せます。
- マネージャーのアドレスにはフォルダや検索が含まれる（`?id=`、`?q=`）ため、**戻る**、**進む**、ブックマークしたリンクが使え、Chrome 自体のフォルダへのリンクも開けます。**このフォルダへのリンクをコピー** でリンクをコピーできます。
- Chrome がブックマークを Google アカウントとこのデバイスのみの両方に保存している場合、マネージャーのフォルダツリーには Chrome と同じように 2 つのセクションに分けて表示されます。
- **リンクを開く場所** で、クリックしたリンクを新しいタブ、バックグラウンドのタブ、現在のタブのどれで開くかを選べます。各リンクの後ろの小さなアイコンで、どれが適用されるかがわかります（**リンクを開く場所を表示**）。

ガイド: [保存と整理](/guides/save-and-organize)

## クリーンアップ [#clean-up]

- **重複クリーナー**: 照合方法を設定して重複を見つけ、確認した後に余分なコピーを削除します。元に戻せます。
- **URLクリーナー**: プレビューした後に `utm_source` などのトラッキングパラメータを取り除きます。
- **スマートルール**: `domain:github.com` のような検索として書くルールで、確認のうえタグを追加し、ブックマークをフォルダに移動します。元に戻すこともできます。**アドレスやタイトルで試す** で、実行する前にルールが一致するかを確認できます。大きな実行はバックグラウンドで適用され、設定には各ルールの前回の実行と競合が表示されます。オンにすると、**新しいブックマークにタグを付ける** は追加された新しいブックマークにタグを付け、**新しいブックマークを移動する** は、新しいブックマークを自動で移動するよう設定したルールのフォルダにそれらを移動します。[スマートルールでタグ付けと移動](/guides/clean-up#tag-and-move-with-smart-rules) を参照してください。
- **リンク切れチェック**: リンク切れが確定したものと手動での確認が必要なものを区別し、削除、リダイレクト先の使用、Wayback Machine のリンクの使用、URL の編集で修復します。元に戻せます。 バックグラウンドで実行されるので、マネージャーを閉じても続き、**バックグラウンドのタスク** で一時停止、再開、キャンセルができます。
- **メタデータ取得**: 実際のページの head 部分だけを読み取ってタイトルを提案し、選んだものを適用します。説明は確認用に表示されるだけで、保存されることはありません。**リンク切れチェック** と同じくバックグラウンドで実行されます。
- **サイトアイコンを更新**: 確認した後に各ウェブサイト自身のアイコンをダウンロードします。ブラウザにキャッシュがない場合や Firefox でも、ブックマークにアイコンが表示されます。アイコンはこのデバイスに保存され、消去できます。**リンク切れチェック** と同じくバックグラウンドで実行されます。
- **ページ本文の索引**（オンにするまでオフ）: 確認のうえ、選んだページの読み取れる本文をこの端末に保存し、検索でページ内の単語を見つけられるようにします。`content:` と `has:content` も使えます。バックグラウンドで実行され、選んだサイトだけを読み込み、ログインページは分けて一覧表示し、混雑しているサイトには後でもう一度取得します。設定の **失敗したものを再試行** と **古いものを更新** でページを読み込み直せ、ポップアップの **このページの本文を索引に追加** は表示中のタブの本文を保存します。[ページの中を検索](/guides/clean-up#search-inside-pages) を参照してください。
- **カバー画像の取得**（オンにするまでオフ）: 確認のうえ、各ページが自ら指定しているプレビュー画像の小さなコピーをこの端末に保存し、マネージャーの **カード** とリストの **カバー画像** 列に表示します。**閲覧中にカバー画像を撮影**（オンにするまでオフ）は、ブックマークしたページを開いたときに、そのページのスクリーンショットをカバー画像として撮影します。**カバー画像のソース** で、2 つのどちらを優先するか、または一方だけを使うかを選びます。ポップアップの **この画面をカバー画像にする** は表示中のタブの画像を保存し、**クイック保存でカバー画像も保存**（既定はオフ）はクイック保存のときにカバー画像を保存します。ブックマークのメニューには **カバー画像を取得** と **カバー画像を削除** があり、カバー画像のないカードにはサイトのアイコンと名前のタイルが表示されます。[カードにカバー画像を表示](/guides/clean-up#show-covers-on-cards) を参照してください。
- **プライバシースキャナー**: トークン、機密パラメータ、メールアドレス、UUID を含む URL（オプションでタイトルも）を検出します。
- **ブックマーク統計**: フォルダ単位またはすべてのブックマークについて、上位のドメインとフォルダ、プロトコル、重複、フォルダの階層の深さを表示します。

ガイド: [ブックマークのクリーンアップと充実](/guides/clean-up)、[リンク切れの検出と修復](/guides/dead-links)

## インポートとエクスポート [#import-and-export]

- HTML、JSON、Markdown、CSV にエクスポートします。プライバシーの確認画面で、ファイル内の機密性のある値を伏せ字にできます。
- インポート先フォルダ、件数、重複のプレビューを確認してから HTML や JSON をインポートします。元に戻せます。
- JSON のエクスポートには各ブックマークのタグと要約が含まれ、そのファイルをインポートすると復元されます。
- Bookmark Scout 自身のデータから選んだ項目をファイルにバックアップできます。設定、このパソコンの設定、保存した検索と表の表示、カスタムプロンプトと自己紹介、スマートルール、AI サービス、カバー画像があり、API キーは選択したときだけ含まれます。復元時は項目ごとの変更内容を確認し、統合するか置き換えるかを選べ、元に戻すこともできます。[設定のバックアップと復元](/guides/import-export#back-up-and-restore-settings)をご覧ください。

ガイド: [インポートとエクスポート](/guides/import-export)

## AI ツール（任意） [#ai-tools-optional]

初期設定でオフです。OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter、または models.dev カタログにあるほか約 200 のプロバイダーで自分のキーを使えます。Ollama、CLIProxyAPI、任意の OpenAI 互換エンドポイントも使えます。Chrome では、**内蔵 AI** が Chrome 自身のモデルを使い、パソコン上でキーなしに無料でフォルダを提案します。

- ポップアップでのフォルダの提案（新しいフォルダパスも確認してから作成します）と、<Shortcut id="commands.ai-quick-save" /> のクイック保存ショートカット。
- ポップアップとサイドパネルの **AI に質問**: ブックマーク、フォルダ、タグ、要約の検索、重複の検出、リンクの確認によって質問に答えます。ページを保存し、移動、名前の変更、削除、新しいフォルダを計画として提案します。計画は承認するまで何も変更せず、各変更は元に戻せます。回答の最後には、次にできることのボタンが表示されます。設定の **AI に質問でできること** で、任意の検索や変更をオフにできます。
- 現在のフォルダを対象とする **自動タグ付け** と **コンテンツ要約**。確認した後にだけ保存され、元に戻せます。
- **AIフォルダ整理**。何かを移動する前にプレビューし、元に戻せます。
- **AIコンテキストパッカー**。AI チャット用にブックマークを Markdown や XML で書き出し、AI がオフでも使えます。
- **AI の出力言語** で、タグ、要約、新しいフォルダ名の言語を選べます。**自己紹介** で、すべての AI 機能に自分のことを少し伝えられます。プロンプトライブラリでは、各ツールのプロンプトを書き換えられ、`{{today}}` や `{{existingTags}}` などのプレースホルダーの一覧も表示されます。

タグと要約はこのデバイスに保存されます。同期はされませんが、[検索](/guides/search#search-words-and-operators)の対象になり、AI に質問で調べることもでき、JSON のブックマークエクスポートにも含まれます。ガイド: [AI ツールの設定](/guides/ai-tools)

## ローカル AI エージェント（任意） [#local-ai-agents-optional]

デバイスごとに、初期設定でオフです。**ローカル AI エージェントを許可** をオンにすると、Claude Code、Codex、Cursor など、コンピューター上の AI エージェントが、`bookmark-scout-mcp` プログラムを通じて Bookmark Scout の検索機能を使えます。このプログラムは、ブラウザのネイティブ メッセージングで拡張機能に接続する MCP サーバーです。**変更を許可** もオンにすると、エージェントはページを保存したり変更を提案したりできます。各変更は Bookmark Scout のウィンドウで承認されるまで待機し、マネージャーで元に戻せます。タイトルや URL に含まれる非公開の値は、初期設定でエージェントから隠されます。

ガイド: [ローカル AI エージェントと使う](/guides/local-agents)

## キーボードと言語 [#keyboard-and-language]

- どのページでも使えるクイック保存ショートカット。ブラウザのショートカット設定で変更でき、Firefox では Bookmark Scout の設定で直接変更できます。
- マネージャー、ポップアップ、サイドパネルのショートカットのキー。[設定](/settings#page-shortcuts)でデバイスごとに変更できます。
- ポップアップとサイドパネルのショートカットは `Ctrl` や `Cmd` を使いません。マネージャーでは Chrome のブックマーク マネージャーと同じキー（すべて選択、元に戻す、やり直し、タブで開く）が使え、<Shortcut id="manager.show_help" /> でヘルプダイアログを表示できます。[キーボードショートカット](/guides/keyboard-shortcuts)をご覧ください。
- マネージャーでの Chrome と同じ選択操作: クリック、<Shortcut id="mouse.select_toggle" />、<Shortcut id="mouse.select_range" />、<Shortcut id="manager.select_all" />。矢印キーで表とフォルダツリーを移動でき、フォルダツリーはスクリーンリーダーでツリーとして読み上げられます。
- マネージャーでの編集、移動、削除を、ブラウザのセッション中は <Shortcut id="manager.undo" /> と <Shortcut id="manager.redo" /> で元に戻したりやり直したりできます。
- マネージャーの行とフォルダの右クリックメニュー: 切り取り、コピー、貼り付け、すべてをタブ、新しいウィンドウ、シークレット ウィンドウで開く、名前の変更、削除。さらに **名前順に並べ替え** と **ブックマークを追加**、**フォルダを追加** があります。設定の **ブックマークマネージャーのメニュー** で、表示するコマンドとその順序を選べます。
- ポップアップとサイドパネルを自分好みに: 表示する部分、ツールバーのボタン、行の高さ、ホバーカードの詳細（[ポップアップ](/settings#popup)）と、行のコマンド（[ポップアップのブックマーク操作とフォルダ操作](/settings#popup-menus)）。
- ツールサイドバーを自分好みに: 表示するツール、その順序、開いたときのタブ（[ツールサイドバー](/settings#tools-sidebar)）。**通知の表示位置** では、**元に戻す** などのメッセージを出す場所を選べます（[通知](/settings#notifications)）。
- マネージャーでの Chrome と同じドラッグ＆ドロップ: 表やツリーのフォルダへのドロップ、ブラウザの順序での行の間へのドロップ、ほかのページからのリンクのドロップ。<Shortcut id="manager.copy" />、<Shortcut id="manager.cut" />、<Shortcut id="manager.paste" /> でコピー、移動、貼り付けができます。
- システム、ライト、ダークのテーマ。
