---
title: Browserunterstützung
description: Was in Chrome, Microsoft Edge und Firefox funktioniert, wo Sie die Erweiterung für jeden Browser bekommen und warum Safari nicht unterstützt wird.
---

Bookmark Scout funktioniert am besten in Chrome, wo es im Chrome Web Store erhältlich ist. Edge bietet dieselben Funktionen, außer wo unten anders angegeben. Firefox bietet etwas weniger, weil es Erweiterungen bei Lesezeichen weniger erlaubt. Alle drei laufen auf einem Computer; Smartphones und Tablets werden nicht unterstützt.

## Wo Sie es bekommen [#where-to-get-it]

<StoreAvailability />

Wo ein Store Bookmark Scout noch nicht führt, können Sie es [von Hand installieren](/installation#install-from-a-github-release). Das Material für die Store-Einträge wird im <RepoLink tree="store">`store/`-Ordner</RepoLink> des Repositorys vorbereitet, und jeder Store prüft eine Erweiterung, bevor er sie aufnimmt.

## Was wo funktioniert [#feature-matrix]

Diese Tabelle beruht auf den Manifesten der für jeden Browser erstellten Erweiterung und den Browserprüfungen in ihrem Code.

| Funktion | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| Pop-up in der Symbolleiste mit Suche und Speichern | Ja | Ja | Ja |
| Tastenkürzel zum Schnellspeichern mit einer Benachrichtigung auf der Seite | Ja. Ändern Sie die Tasten unter `chrome://extensions/shortcuts`, wo Sie dem Schnellspeichern auch <Shortcut id="browser.bookmark_page" /> zuweisen können | Ja. Ändern Sie die Tasten unter `edge://extensions/shortcuts`, einschließlich <Shortcut id="browser.bookmark_page" /> | Ja. Ändern Sie die Tasten in den Einstellungen von Bookmark Scout oder unter **Tastenkombinationen für Erweiterungen verwalten** in Firefox. Firefox behält <Shortcut id="browser.bookmark_page" /> und <Shortcut id="browser.bookmark_all_tabs" /> für sich |
| Seitenleiste | Ja | Ja | Ja, in der Firefox-Sidebar: Wählen Sie Bookmark Scout in der Sidebar aus |
| Lesezeichen-Manager und Tools-Leiste | Ersetzt die Lesezeichenseite des Browsers und öffnet sich über **Lesezeichen-Manager öffnen** im Pop-up und in der Seitenleiste | Öffnet sich über **Lesezeichen-Manager öffnen**. Ob Edge die Ersetzung auch auf seine Favoritenseite anwendet, wurde nicht geprüft. | Öffnet sich über **Lesezeichen-Manager öffnen** im Pop-up. Firefox kann seine Lesezeichenseite nicht ersetzen. |
| Gespeicherte Suchen, Wartungstools, Import und Export, Statistik, KI-Tools im Manager | Ja | Ja | Ja, im Manager. Automatisierte Tests decken Import und Export, die Berichte, „Defekte Links prüfen“, „Metadatenabruf“, „Seitentext indexieren“, „Titelbilder laden“, „Intelligente Regeln“ und „KI-Ordnerneuordnung“ ab; die übrigen Tools werden manuell geprüft. |
| Einstellungsseite | Ja | Ja | Ja |
| „KI fragen“ und die anderen KI-Tools | Ja | Ja | Ja, nachdem Sie der Datenweitergabe an Ihren KI-Anbieter zugestimmt haben |
| Integrierte KI, kostenlos auf Ihrem Computer, für Ordnervorschläge | Ja, ab Chrome 138 auf einem Computer, der das Modell von Chrome ausführen kann | Nur, wenn Edge dieselbe integrierte KI anbietet; nicht geprüft | Nein: Firefox hat keine integrierte KI |
| Lokale KI-Agenten über `bookmark-scout-mcp` (für Entwickler) | Ja | Ja | Ja; `bookmark-scout-mcp install` meldet es auch bei Firefox an. Nicht durch automatisierte Tests abgedeckt |
| Im Inkognitofenster aus dem Manager öffnen | Ja | Ja, als InPrivate-Fenster | Ja, als privates Fenster, wenn die Erweiterung in privaten Fenstern erlaubt ist |
| Rechtsklickmenü zum Speichern von Links, Seiten oder markiertem Text | Ja, nachdem Sie **Rechtsklickmenü** aktiviert haben (ohne Nachfrage) | Ebenso | Ja, nachdem Sie **Rechtsklickmenü** aktiviert haben |
| Website-Symbole neben Lesezeichen | Mit **Website-Symbole aktualisieren** gespeicherte Symbole sowie Symbole aus dem Symbol-Cache des Browsers, sobald Sie **Symbol-Cache des Browsers verwenden** aktivieren | Ebenso | Nur mit **Website-Symbole aktualisieren** gespeicherte Symbole; das Tool läuft im Manager. Firefox bietet Erweiterungen keine Favicon-API, daher zeigen andere Lesezeichen ein allgemeines Symbol. |
| Optionaler Zugriff auf Websites für die Linkprüfung, das Abrufen von Titeln, das Aktualisieren von Website-Symbolen, das Indexieren von Seitentext und das Laden von Titelbildern | Wird angefragt, wenn Sie das Tool ausführen | Ebenso | Ebenso |
| Beim Surfen aufgenommene Titelbilder (**Titelbilder beim Surfen aufnehmen**) | Ja, nachdem Sie den Zugriff auf alle Seiten erlaubt haben | Ebenso | Ebenso |

Wie viel in jedem Browser durch automatisierte Tests abgedeckt ist, steht unter [Projektstatus](/status#what-is-tested-in-each-browser).

## Safari [#safari]

Safari wird nicht unterstützt. Safari Web Extensions implementieren die `bookmarks`-API nicht, von der jeder Teil von Bookmark Scout abhängt.
