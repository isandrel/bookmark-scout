Bookmark Scout бесплатен, без аккаунта и без рекламы. Он работает в браузере на компьютере, но не на телефонах и планшетах.

## Установка в Chrome [#add-it-to-chrome]

<Steps>
<Step>
<StoreListing browser="chrome" />

На странице расширения нажмите **Установить**, затем **Установить расширение**. Chrome запросит только одно разрешение: просмотр и изменение закладок. Другие функции запрашивают дополнительные разрешения, только когда вы впервые ими пользуетесь, и объясняют зачем; см. [Разрешения](/permissions).
</Step>
<Step>
Закрепите значок: нажмите кнопку **Расширения** со значком пазла в правой части панели инструментов, затем значок булавки рядом с Bookmark Scout.
</Step>
<Step>
Сохраните первую страницу: см. [Первое сохранение](/first-save).
</Step>
</Steps>

Сразу после установки в новой вкладке откроется страница **Bookmark Scout готов к работе** с теми же первыми шагами: закрепить значок, сохранить страницу, и клавиши быстрого сохранения (или кнопка **Настроить**, если другое расширение уже использует эти клавиши). В Chrome и Edge она также предлагает отдать быстрому сохранению сочетание <Shortcut id="browser.bookmark_page" />. Эта страница открывается только один раз, при первой установке Bookmark Scout, и никогда после обновления. Кнопка **Прочитать руководство** на ней открывает [Сохранение и упорядочивание](/guides/save-and-organize), а **Открыть настройки** — [Настройки](/settings).

Копия из магазина обновляется сама.

## После установки [#after-installing]

- Нажмите на значок Bookmark Scout на любой странице, чтобы сохранить её или найти закладку. Начните с [Первое сохранение](/first-save).
- Нажмите <Shortcut id="commands.quick-save" /> на любой странице, чтобы сохранить её, ничего не открывая. См. [Сохранение с помощью сочетания клавиш](/guides/save-and-organize#quick-save).
- В Chrome Bookmark Scout заменяет страницу закладок браузера своим диспетчером закладок. Открывайте его как раньше, например сочетанием <Shortcut id="browser.open_bookmarks_manager" />, или кнопкой **Открыть диспетчер закладок** во всплывающем окне. На его боковой панели **Инструменты** собраны инструменты очистки.
- Настройки открываются во вкладке: нажмите правой кнопкой мыши на значок на панели инструментов и выберите **Параметры**. См. [Настройки](/settings).

## Обновление [#updating]

Копия, установленная из магазина, обновляется сама, и обновления сохраняют ваши настройки. Одно из прошлых обновлений, до версии 0.3.3, было исключением: оно однократно сбросило собственные сохранённые данные Bookmark Scout, но не ваши закладки; см. [Частые вопросы](/faq#my-settings-are-gone-after-an-update).

Чтобы в любой момент сохранить копию своих настроек, своих промптов, ИИ-сервисов, сохранённых поисков и других выбранных вами частей, используйте **Создать резервную копию** внизу страницы [Настройки](/settings).

## Для опытных: установка вручную с GitHub [#install-from-a-github-release]

Пользуйтесь этим способом, только если Bookmark Scout ещё нет в магазине вашего браузера, или чтобы протестировать выпуск. Копия, установленная так, не обновляется сама: чтобы обновить её, скачайте более новый выпуск и повторите шаги.

В каждом <RepoLink path="/releases">выпуске на GitHub</RepoLink> есть отдельный файл для каждого браузера:

| Браузер | Файл |
| --- | --- |
| Chrome | `bookmark-scout-<version>-chrome.crx` или `bookmark-scout-<version>-chrome.zip` |
| Microsoft Edge | `bookmark-scout-<version>-edge.zip` |
| Firefox | `bookmark-scout-<version>-firefox.zip` |

Скачайте его из <ReleaseLink />, затем выполните шаги для своего браузера.

<Tabs items={["Chrome", "Edge", "Firefox"]}>
<Tab value="Chrome" id="chrome">

<Steps>
<Step>
Скачайте `bookmark-scout-<version>-chrome.crx` или `bookmark-scout-<version>-chrome.zip`. Если вы используете ZIP, распакуйте его в папку, которую не будете удалять: Chrome загружает расширение из этой папки.
</Step>
<Step>
Откройте `chrome://extensions/` и включите **Режим разработчика** (справа вверху).
</Step>
<Step>
Перетащите файл CRX на страницу или нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
</Step>
<Step>
Закрепите Bookmark Scout на панели инструментов через меню «Расширения» со значком пазла.
</Step>
</Steps>

</Tab>
<Tab value="Edge" id="edge">

<Steps>
<Step>
Скачайте `bookmark-scout-<version>-edge.zip` и распакуйте его в папку, которую не будете удалять.
</Step>
<Step>
Откройте `edge://extensions/` и включите **Режим разработчика**.
</Step>
<Step>
Нажмите **Загрузить распакованное расширение** и выберите распакованную папку.
</Step>
<Step>
Включите показ Bookmark Scout на панели инструментов через меню «Расширения» со значком пазла (значок глаза рядом с ним).
</Step>
</Steps>

</Tab>
<Tab value="Firefox" id="firefox">

<Steps>
<Step>
Скачайте `bookmark-scout-<version>-firefox.zip` и распакуйте его.
</Step>
<Step>
Откройте `about:debugging#/runtime/this-firefox`.
</Step>
<Step>
Нажмите **Загрузить временное дополнение** и выберите распакованный файл `manifest.json`.
</Step>
</Steps>

<Callout type="warn" title="Ограничения Firefox">
Firefox удаляет временные дополнения при перезапуске, поэтому после каждого перезапуска его нужно загружать снова. Страница **Bookmark Scout готов к работе** для временного дополнения не открывается. Кроме того, Firefox не позволяет заменить свою страницу закладок, поэтому открывайте диспетчер закладок (с инструментами, сохранёнными поисками, импортом и экспортом) кнопкой **Открыть диспетчер закладок** во всплывающем окне. См. [Поддержка браузеров](/browser-support).
</Callout>

</Tab>
</Tabs>
