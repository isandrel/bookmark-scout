---
title: Ihr erstes Lesezeichen
description: Fügen Sie Bookmark Scout zu Chrome hinzu, heften Sie es an und speichern Sie Ihre erste Seite im richtigen Ordner, indem Sie einen Teil des Ordnernamens eingeben. Danach speichern Sie mit einem einzigen Tastendruck.
---

Das dauert etwa eine Minute. Sie brauchen Chrome auf einem Computer und mindestens einen Lesezeichenordner.

<Steps>
<Step>
### Bookmark Scout zu Chrome hinzufügen [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

Klicken Sie im Store-Eintrag auf **Zu Chrome hinzufügen** und dann auf **Erweiterung hinzufügen**. Chrome fragt nur nach einer Sache: Ihre Lesezeichen lesen und ändern zu dürfen. Danach öffnet sich in einem neuen Tab eine Seite mit dem Titel **Bookmark Scout ist bereit**, die die folgenden Schritte kurz zusammenfasst; sie zeigt die Tasten, die Ihr Tastenkürzel zum Schnellspeichern tatsächlich bekommen hat. Sie verwenden Firefox oder Edge? Siehe [Installieren](/installation#firefox-and-edge).
</Step>
<Step>
### Das Symbol anheften [#pin-the-icon]

Klicken Sie rechts in der Symbolleiste von Chrome auf die Schaltfläche **Erweiterungen** mit dem Puzzleteil und dann auf die Stecknadel neben Bookmark Scout. Das Symbol bleibt nun in der Symbolleiste, nur einen Klick entfernt.
</Step>
<Step>
### Die aktuelle Seite speichern [#save-the-page-you-are-on]

Öffnen Sie eine Seite, die Sie behalten möchten, und klicken Sie auf das Bookmark-Scout-Symbol. Die Zeile unter dem Suchfeld, **Zu speichernde Seite**, zeigt den Titel der Seite.

Geben Sie einen Teil eines Ordnernamens ein, etwa `pas` für einen Ordner namens Pasta. Passende Ordner erscheinen unter **In Ordner speichern**, der am besten passende zuerst. Der erste ist hervorgehoben: Drücken Sie `Enter`, um dort zu speichern, oder klicken Sie auf einen beliebigen Ordner. **Lesezeichen hinzugefügt** bestätigt das Speichern.
</Step>
<Step>
### Beim nächsten Mal genügt eine Taste [#next-time-press-one-key]

Drücken Sie auf einer beliebigen Seite <Shortcut id="commands.quick-save" />. Bookmark Scout speichert die Seite in dem Ordner, der am besten zu ihr passt, ohne etwas zu öffnen. Eine kleine Nachricht in der Ecke der Seite zeigt, wo sie gelandet ist. Klicken Sie darin auf **Rückgängig**, um das Speichern zurückzunehmen, oder wählen Sie unter **Verschieben nach** einen anderen Ordner.
</Step>
</Steps>

<Screenshot name="popup" />

## Wenn etwas anders aussieht [#if-something-is-different]

- **Der gewünschte Ordner wird nicht angezeigt.** Geben Sie einen anderen Teil seines Namens ein oder ein paar Buchstaben des Ordners, in dem er liegt, etwa `recipes pas`. Ein kleiner Tippfehler ist kein Problem.
- **Die Taste bewirkt nichts.** Vielleicht verwendet eine andere Erweiterung sie bereits. Klicken Sie auf das Bookmark-Scout-Symbol: Die Zeile **Kein Kürzel zum Schnellspeichern festgelegt** enthält **Einrichten**. Siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save).
- **Die Seite war schon gespeichert.** Bookmark Scout speichert sie nicht doppelt; die Nachricht zeigt, wo sie liegt.
