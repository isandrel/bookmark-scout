---
title: Compatibilité des navigateurs
description: Ce qui fonctionne dans Chrome, Microsoft Edge et Firefox, où l'obtenir pour chacun, et pourquoi Safari n'est pas pris en charge.
---

Bookmark Scout fonctionne au mieux dans Chrome, où il est disponible sur le Chrome Web Store. Edge offre les mêmes fonctionnalités, sauf indication contraire ci-dessous. Firefox en offre un peu moins, car il laisse les extensions faire moins de choses avec les favoris. Tous les trois fonctionnent sur un ordinateur ; les téléphones et les tablettes ne sont pas pris en charge.

## Où l'obtenir [#where-to-get-it]

<StoreAvailability />

Lorsqu'une boutique ne propose pas encore Bookmark Scout, vous pouvez [l'installer manuellement](/installation#install-from-a-github-release). Les éléments des fiches sont préparés dans le <RepoLink tree="store">dossier `store/`</RepoLink> du dépôt, et chaque boutique examine une extension avant de la proposer.

## Ce qui fonctionne où [#feature-matrix]

Ce tableau est établi à partir des manifestes de l'extension compilée pour chaque navigateur et des vérifications propres à chaque navigateur dans son code.

| Fonctionnalité | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| Fenêtre pop-up de la barre d'outils, avec recherche et enregistrement | Oui | Oui | Oui |
| Raccourcis d'enregistrement rapide avec une notification dans la page | Oui. Modifiez les touches sur `chrome://extensions/shortcuts`, où vous pouvez aussi attribuer `Ctrl+D` à l'enregistrement rapide | Oui. Modifiez les touches sur `edge://extensions/shortcuts`, y compris `Ctrl+D` | Oui. Modifiez les touches dans les Paramètres de Bookmark Scout ou dans **Gérer les raccourcis d'extensions** de Firefox. Firefox se réserve `Ctrl+D` et `Ctrl+Shift+D` |
| Panneau latéral | Oui | Oui | Oui, dans la barre latérale de Firefox : choisissez Bookmark Scout dans la barre latérale |
| Gestionnaire de favoris et barre latérale Outils | Remplace la page Favoris du navigateur, et s'ouvre depuis **Ouvrir le gestionnaire de favoris** dans la fenêtre pop-up et le panneau latéral | S'ouvre depuis **Ouvrir le gestionnaire de favoris**. Il n'a pas été vérifié si Edge applique aussi ce remplacement à sa page Favoris. | S'ouvre depuis **Ouvrir le gestionnaire de favoris** dans la fenêtre pop-up. Firefox ne permet pas de remplacer sa page de favoris. |
| Recherches enregistrées, outils de maintenance, importation et exportation, statistiques, outils d'IA du gestionnaire | Oui | Oui | Oui, dans le gestionnaire. Des tests automatisés couvrent l'importation, l'exportation et les rapports ; les autres outils sont vérifiés manuellement. |
| Page des paramètres | Oui | Oui | Oui |
| Demander à l'IA et les autres outils d'IA | Oui | Oui | Oui, après avoir accepté de partager des données avec votre fournisseur d'IA |
| Agents d'IA locaux via `bookmark-scout-mcp` (pour les développeurs) | Oui | Oui | Oui ; `bookmark-scout-mcp install` l'enregistre aussi auprès de Firefox. Non couvert par les tests automatisés |
| Ouverture dans une fenêtre de navigation privée depuis le gestionnaire | Oui | Oui, dans une fenêtre InPrivate | Oui, dans une fenêtre de navigation privée, lorsque l'extension est autorisée dans les fenêtres privées |
| Menu du clic droit pour enregistrer des liens | Oui, après activation du **Menu du clic droit** (une autorisation est demandée) | Idem | Oui, après activation du **Menu du clic droit** |
| Icônes de site à côté des favoris | Icônes enregistrées avec **Actualiser les icônes de site**, et icônes du cache du navigateur une fois l'option **Utiliser le cache d'icônes du navigateur** activée | Idem | Uniquement les icônes enregistrées avec **Actualiser les icônes de site**, qui s'exécute dans le gestionnaire. Firefox n'offre aucune API d'icônes de site aux extensions : les autres favoris affichent donc une icône générique. |
| Accès facultatif aux sites Web pour la vérification des liens morts, la récupération des titres et l'actualisation des icônes de site | Demandé lorsque vous lancez l'outil | Idem | Idem |

La part de chaque navigateur couverte par des tests automatisés est indiquée dans [État du projet](/status#what-is-tested-in-each-browser).

## Safari [#safari]

Safari n'est pas pris en charge. Les extensions Web Safari n'implémentent pas l'API `bookmarks`, dont dépend chaque partie de Bookmark Scout.
