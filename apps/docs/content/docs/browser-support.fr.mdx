Chrome est la cible principale. Edge repose sur Chromium et offre les mêmes fonctionnalités, sauf indication contraire ci-dessous. Firefox utilise une version Manifest V2 dotée de moins de fonctionnalités.

## Ce qui est testé [#what-is-tested]

- **Chrome (Chromium)** : tests unitaires et tests de bout en bout pour la fenêtre pop-up, le panneau latéral, le gestionnaire, les paramètres, les outils de maintenance, les rapports, l'importation et l'exportation, les raccourcis clavier, l'enregistrement rapide, les recherches enregistrées, l'enregistrement depuis le menu contextuel, le glisser-déposer, les outils réseau, les outils d'IA avec des fournisseurs simulés, et des parcours qui en combinent plusieurs. Des tests du pont exécutent le programme `bookmark-scout-mcp` avec l'extension dans Chromium sous Linux et macOS.
- **Edge** : la même suite de bout en bout s'exécute sur la version Edge.
- **Firefox** : une suite de tests de fumée couvre la recherche et la création de dossiers dans la fenêtre pop-up, la page du panneau latéral chargée dans un onglet, l'ouverture du gestionnaire depuis la fenêtre pop-up et le panneau latéral, la page du gestionnaire avec son adresse, `Delete` et l'annulation, les touches de l'arborescence des dossiers, le menu contextuel et le glisser-déposer (à partir d'événements de glissement simulés par script), l'avertissement et l'enregistreur de touches du raccourci d'enregistrement rapide, le consentement au partage de données avec l'IA, l'enregistrement d'un paramètre, un aller-retour d'exportation et d'importation JSON, les rapports de statistiques et de confidentialité, ainsi que les icônes de site enregistrées dans la fenêtre pop-up. L'enregistrement depuis le menu contextuel d'une page, les autres raccourcis clavier, le glisser-déposer dans la fenêtre pop-up, la notification d'enregistrement rapide elle-même, les agents d'IA locaux, ainsi que les outils réseau et d'IA (y compris **Actualiser les icônes de site** lui-même) ne sont pas couverts.

La suite Edge et la suite de tests de fumée Firefox sont des vérifications CI obligatoires, comme la suite Chromium. Les vrais fournisseurs d'IA et les sites Web réels sont vérifiés manuellement, et non par des tests automatisés.

## Safari [#safari]

Safari n'est pas pris en charge. Les extensions Web Safari n'implémentent pas l'API `bookmarks`, dont dépend chaque partie de Bookmark Scout.
