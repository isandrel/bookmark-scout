## 常见问题 [#questions]

### Bookmark Scout 免费吗？ [#is-bookmark-scout-free]

是的。它基于 <License /> 许可证免费开源，没有广告，无需账号，也没有付费套餐。唯一可能花钱的是可选的 AI 功能：它们使用你自己在某家 AI 公司的账号，该公司可能会按每次使用收费。

### 我必须使用 AI 吗？ [#do-i-need-to-use-ai]

不必。AI 是可选的。保存、搜索、整理、清理以及导入和导出都无需 AI 即可使用，而且在你于[设置](/settings#ai)中开启之前，AI 始终处于关闭状态。如果要使用 AI，你需要一个 AI 公司（例如 OpenAI、Anthropic 或 Google）的账号，以及该账号提供的一个密钥（API 密钥），让 Bookmark Scout 可以使用这个账号。这些公司大多按每次使用收费，金额通常很小；在你自己电脑上运行的 AI 程序（例如 Ollama）不花钱，但需要性能相当强的电脑。AI 工具处理的书签标题和地址会发送给你选择的公司。请参阅[设置 AI 工具](/guides/ai-tools)。

### 它会把我的书签发送到任何地方吗？ [#does-it-send-my-bookmarks-anywhere]

不会发送给开发者：Bookmark Scout 没有服务器。只有当你使用已开启的 AI 工具（数据会发送给你的服务商），运行失效链接检查或标题获取（会请求已加入书签的网站），或让本地 AI 智能体查找你的书签（它们会通过你电脑上的一个程序获得所请求的内容）时，数据才会离开你的浏览器。请参阅[隐私](/privacy)。

### 它会在不询问的情况下更改我的书签吗？ [#will-it-change-my-bookmarks-without-asking]

不会。重复书签清理、网址清理、失效链接修复、获取的标题、AI 重组和导入，都会在写入任何内容之前先显示供你审阅的内容。**询问 AI** 和本地 AI 智能体会以方案的形式展示更改，并等待你批准。删除默认会要求确认，删除、清理和导入都可以在随后出现的消息中撤消，书签管理器中的更改也可以用 `Ctrl+Z` 撤消。

### 哪些浏览器商店已上架？ [#which-browser-stores-list-it]

<StoreAvailability />

每个商店都会先审核扩展程序，再将其上架。如果你所用浏览器的商店还没有上架，你可以[手动安装](/installation#install-from-a-github-release)（进阶操作）。

### 它能在 Firefox 中使用吗？ [#does-it-work-in-firefox]

目前还不能从 Firefox 附加组件商店获取：Firefox 版本即将推出。在此之前，可以将它作为临时附加组件[手动安装](/installation#firefox)，但 Firefox 重启时会将其移除。安装后，它可以正常使用，只有几处不同：Firefox 不允许扩展程序替换其书签页面，因此请通过弹出窗口中的**打开书签管理器**打开 Bookmark Scout 书签管理器（其中包含清理工具、导入和导出以及已保存的搜索）；此外也无法使用浏览器的图标缓存。请参阅[浏览器支持](/browser-support)。

### 它能在 Microsoft Edge 中使用吗？ [#does-it-work-in-microsoft-edge]

目前还不能从 Microsoft Edge 加载项商店获取：Edge 版本即将推出。在此之前，可以[手动安装](/installation#edge)，安装后的使用方式与 Chrome 基本相同。请参阅[浏览器支持](/browser-support)。

### 它能在我的手机上使用吗？ [#does-it-work-on-my-phone]

不能。Bookmark Scout 是用于电脑浏览器的扩展程序。手机和平板电脑上的浏览器无法运行它。

### 为什么不支持 Safari？ [#why-not-safari]

Safari Web Extensions 未实现 Bookmark Scout 所依赖的 `bookmarks` API。

## 故障排除 [#troubleshooting]

### 书签管理器在哪里？ [#where-is-the-bookmarks-manager]

在 Chrome 中，打开浏览器自带的书签页面，例如按 `Ctrl+Shift+O`（在 macOS 上按 `Cmd+Option+B`）。Bookmark Scout 会将其替换为自己的书签管理器。如果**工具**侧栏处于隐藏状态，请点击书签管理器顶部的**显示工具**。

### Bookmark Scout 从 Firefox 中消失了 [#bookmark-scout-disappeared-from-firefox]

Firefox 重启时会移除临时附加组件。请按照[安装](/installation)中的说明，从 `about:debugging#/runtime/this-firefox` 重新载入。

### 网站图标不显示 [#site-icons-are-missing]

请检查[设置](/settings#appearance)中的**显示网站图标**是否已开启。Chrome 和 Edge 会显示它们为每个网站缓存的图标，因此你最近没有访问过的网站会显示通用的地球图标。Firefox 没有面向扩展程序的图标 API。在任何浏览器中，[刷新网站图标](/guides/clean-up#refresh-site-icons)都会下载每个网站自己的图标，并将其保存在本设备上。

### 我的 API 密钥没有保存 [#my-api-key-was-not-saved]

如果密钥看起来不像所选 AI 公司（即该服务的服务商）的密钥，它会被拒绝且不会保存，同时会显示一条提示消息。请检查该服务的服务商是否就是给你密钥的那家公司。请参阅[设置 AI 工具](/guides/ai-tools#turn-on-ai)。

### 失效链接检查提示某个正常的网站需要手动检查 [#the-dead-link-check-says-a-working-site-needs-a-manual-check]

要求登录、限制请求频率、阻止自动检查或出现服务器错误的网站会列在**需手动检查**下，因为它们在浏览器中通常仍然可以正常访问。打开链接即可确认。只有页面不存在、拒绝连接、主机未知和重定向循环的情况才会计为**确认失效**。请参阅[查找并修复失效链接](/guides/dead-links#read-the-results)。

### 扫描期间控制台显示“Failed to load resource” [#the-console-shows-failed-to-load-resource-during-a-scan]

Chrome 会在网页的开发者控制台中为每个失败的请求记录一行日志。扩展程序无法屏蔽这些日志，它们也不表示扫描出了问题。

### 在书签管理器中调整的顺序没有显示在弹出窗口中 [#reordering-in-the-manager-does-not-show-in-the-popup]

只有使用**文件夹优先**排序时，弹出窗口才会显示浏览器中保存的顺序。**添加日期**和**按字母顺序**排序会持续对列表重新排序。请在[设置](/settings#behavior)中更改**排序方式**。

### 搜索提示匹配项比显示的更多 [#search-says-there-are-more-matches-than-it-shows]

结果数量以**最大搜索结果数**（默认为 20）为上限。请缩小搜索范围，或在[设置](/settings#search)中提高上限。

### 我的标签、摘要或已保存的搜索在另一台电脑上不见了 [#my-tags-summaries-or-saved-searches-are-missing-on-another-computer]

它们只保存在你创建它们的设备上，不会同步。如需迁移，请将书签导出为 JSON（导入时，标签和摘要会随新建的书签一起恢复），并用[设置](/settings)底部的**备份设置**保存备份（其中包含已保存的搜索）。开启浏览器同步后，设置会通过你的浏览器账号同步。

### 我误删了内容 [#i-deleted-something-by-mistake]

请在 10 秒内点击消息中的**撤消**。这会恢复该项目、其中的所有内容以及它已保存的标签和摘要；恢复的项目会获得新的添加日期。在书签管理器中，`Ctrl+Z`（在 Mac 上为 `Cmd+Z`）也可以撤消在书签管理器中、或由“询问 AI”或本地 AI 智能体执行的删除，直到浏览器关闭为止。请参阅[在书签管理器中选择、撤消和重做](/guides/save-and-organize#select-undo-and-redo-in-the-manager)。

### 快速保存快捷键不起作用 [#the-quick-save-shortcut-does-nothing]

如果其他扩展程序已经占用了 `Alt+Shift+S` 或 `Alt+Shift+D`，浏览器就不会给 Bookmark Scout 的快捷键分配按键，弹出窗口会显示**未设置快速保存快捷键**。点击**去设置**，或在[设置](/settings#quick-save)的**保存与搜索**下打开**键盘快捷键**，选择其他按键。在扩展程序无法显示任何内容的页面上（例如浏览器自带的页面），工具栏图标会显示结果，而不是显示通知。请参阅[用键盘快捷键保存](/guides/save-and-organize#quick-save)。

### 更新后我的设置不见了 [#my-settings-are-gone-after-an-update]

更新通常会保留你的设置。有一次更新（升级到 0.3.3 版）将 Bookmark Scout 保存的数据迁移到了新格式，旧数据被删除而没有转换。此后，设置会恢复为默认值，AI 服务及其 API 密钥需要重新添加，自定义提示词、已保存的搜索、最近的搜索和文件夹、标签和摘要以及已保存的网站图标都已丢失。书签本身不受影响。如果更新前用[设置](/settings)底部的**备份设置**（当时名为**导出**）保存过设置，请用**恢复设置**打开该文件。
