## In short

- **No account and no server.** Bookmark Scout runs inside your browser. The developer receives nothing from the extension.
- **No telemetry.** No analytics, crash reporting, or ads in the extension.
- **AI is off until you turn it on**, and then requests go straight from your browser to the provider you chose. In Firefox, turning it on also asks for your consent to share that data. With Chrome's built-in AI, folder suggestions stay on your computer.
- **Local AI agents only if you allow them.** With **Allow local AI agents** on (off by default), AI agents on your computer, such as Claude Code, can look up your bookmarks through the bookmark-scout-mcp program; they change them only with **Allow changes** on, each change after your approval.
- **Permissions when you need them.** At install the extension asks only for what it cannot work without; tab access, the right-click menu, the browser's icon cache, and website access are asked for when you first use the feature. See [Permissions](/permissions).

## What the extension reads

- Your bookmarks, to show, search, edit, move, delete, import, and export them.
- The title and URL of the active tab, when you save the page you are on (from the popup, the side panel, or a quick save shortcut) or ask for a folder suggestion.
- Site icons from the browser's own icon cache, in Chrome and Edge, once you turn on **Use the browser's icon cache**.
- Site icons you download with **Refresh Site Icons**, from each bookmarked website.
- The text of bookmarked pages, when you run **Index Page Text**, from each page in the run. Or the text of the tab you are viewing, as you see it, when you click **Index this page's text** in the popup.
- The head of bookmarked pages and the preview image each one names, when you run **Fetch Covers**, from each page in the run. Or a picture of the tab you are viewing, when you click **Use this view as the cover** in the popup.
- A picture of a bookmarked page you open in the tab you are viewing, once it has loaded, while **Capture Covers While Browsing** is on (off by default); never of a site on **Never Capture These Sites**, and in a private window only if you also turn on **Also Capture in Private Windows** and your browser lets the extension run there. While it is on, the address of each page that loads in your active tab is compared with your bookmarks and not kept.

It does not read the content of the pages you visit, except the text of the tab you are viewing when you click **Index this page's text** in the popup, which you see before it is kept, and the pictures **Capture Covers While Browsing** takes of bookmarked pages while it is on, which stay on this device. After a quick save shortcut it shows its own notification in that tab, which reads nothing from the page.

| Device settings: the folder chosen for quick save, the icon storage limit, AI activity recording, and Ask AI's web search | Local storage on this device | No |
| Local AI agent settings (on or off, hiding private values, the lookups turned off) and a random id for this browser profile | Local storage on this device | No |

| About me (**AI** settings): what you wrote about yourself; up to 1,000 characters | Browser sync storage | Same as settings, and sent to your AI provider with AI requests while it has text |

| AI services: each service's name, provider, and model | Local storage on this device | No |

Not in the backup file | IndexedDB on this device | No |

Scan results from the Tools sidebar are kept only while their dialog is open. Uninstalling the extension removes what it stored; your bookmarks stay in the browser.

**Back up settings** at the bottom of Settings saves a backup file with the settings you changed, your custom prompts, About me, AI services (name, provider, model, Base URL, and provider-specific fields), saved searches, smart rules, and the table's columns and sort. It never holds API keys or extra headers, and it is not encrypted. See [Settings](/settings).

## When data leaves your browser

Only when you use one of these, and only to the place named:

| Feature | Goes to | What is sent |
| --- | --- | --- |
| AI folder recommendations, including the AI quick save shortcut | The AI provider you configured | The current page's title and URL, and your folder names. With **Read page content** on, also the page's main text |
| Auto-Tagging, Content Summarizer, AI Folder Reorganization | The AI provider you configured | Titles, URLs, and folder paths of the bookmarks in scope. With **Read page content** on, Auto-Tagging and Content Summarizer also send each page's main text; AI Folder Reorganization never does. Auto-Tagging also sends the names of your most used tags unless **Send Existing Tags** is off |
| Ask AI | The AI provider you configured | Your messages and the conversation so far, and what the AI looks up to answer: matching bookmarks (with their folders, dates added, tags, and summaries), folder names, the current page's title and URL, whether bookmarked links it checks still work, and with **Read page content** on, the text of pages it reads. With its web search on, the provider also searches the web. The conversation is not saved |
| Check Dead Links, Metadata Fetcher, Ask AI link checks | Each bookmarked website | A request for the page, without cookies, after you allow website access |
| Refresh Site Icons | Each bookmarked website | A request for one bookmarked page per site and for an icon file on that site's domain, without cookies, after you allow website access. No third-party icon service is used |
| Index Page Text | Each bookmarked page in the run, once per address; not an address that holds a user name and password or a sensitive parameter such as a token, unless you turn off **Skip Addresses with Sign-in Details or Secrets**; never a site in **Never Read These Sites** | A request for the page, without cookies, after you allow website access; a site that says it is busy is asked again after the short wait it names, a few times at most. Its readable text stays on this device |
| Fetch Covers | Each bookmarked page in the run, and the image it names | A request for the page's head and for its image, without cookies or the page's address, only on sites you allowed. A small copy stays on this device |
| Local AI agents, only with **Allow local AI agents** on (off by default) | The bookmark-scout-mcp program on your computer, and the AI agents you run there | What an agent asks for: matching bookmarks (with their folders, dates added, tags, and summaries), folder names, the current page's title and URL, whether bookmarked links still work (after you allow website access), and with **Read page content** on, a page's text. Private values in titles and URLs are hidden unless you turn that off. Agents may send what they read to their own AI provider. Each lookup is in AI activity while **Record requests** is on |

Every AI feature that uses a provider also sends your **About me** text (**AI** settings) while it has any; it is empty by default.

A provider running on your own computer, such as Ollama, keeps AI requests on your machine. So does Chrome's built-in AI: it runs folder suggestions on Chrome's own model on your computer, with no API key, and Chrome downloads that model from Google once, when you ask it to, without any of your data. Bookmark exports, **AI Context Packer** files, and the settings backup are saved as files on your computer and uploaded nowhere. A JSON bookmark export also holds each bookmark's tags and summary; for bookmark and AI context exports, a privacy review can redact sensitive values first. The exact data each AI tool sends is listed in [Set up AI tools](/guides/ai-tools#what-each-tool-sends), and each permission is explained in [Permissions](/permissions).
