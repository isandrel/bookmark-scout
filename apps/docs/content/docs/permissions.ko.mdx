아래는 브라우저별로 빌드한 확장 프로그램에 포함된 권한입니다. Bookmark Scout에는 콘텐츠 스크립트가 없으므로 방문하는 페이지를 읽지 않습니다. 설치할 때는 동작하는 데 꼭 필요한 권한만 요청하며, 나머지는 해당 기능을 켜거나 실행할 때 요청합니다.

## 설치할 때 부여되는 권한 [#granted-at-install]

| 권한 | 브라우저 | 이유 |
| --- | --- | --- |
| `bookmarks` | 전체 | 북마크를 표시하고 검색하며, 팝업, 사이드 패널, 관리자, 마우스 오른쪽 버튼 메뉴에서 사용자가 작업할 때 북마크를 만들고, 편집하고, 이동하고, 삭제합니다 |
| `storage` | 전체 | 설정을 저장하고, 이 기기에만 AI 제공업체 설정, 태그, 요약, 저장된 검색, 최근 폴더, 최근 검색, **사이트 아이콘 새로 고침**으로 저장한 사이트 아이콘을 저장합니다 |
| `activeTab` | 전체 | 툴바 버튼이나 마우스 오른쪽 버튼 메뉴를 클릭했을 때 해당 탭의 제목과 URL을 읽어, 보고 있는 페이지를 저장할 수 있게 합니다. 다른 탭이나 방문 기록은 읽지 않습니다 |
| `sidePanel` | Chrome, Edge | 사이드 패널 화면을 제공합니다. Firefox에서는 같은 페이지를 사이드바로 선언합니다 |
| `contextMenus` | Firefox | Firefox에서는 확장 프로그램이 이 권한을 나중에 요청할 수 없습니다. 메뉴는 **컨텍스트 메뉴**를 켠 뒤에만 나타납니다 |

Chrome과 Edge에서는 확장 프로그램이 브라우저의 북마크 페이지를 Bookmark Scout 관리자로 대체하기도 합니다. 이는 권한이 아니라 페이지 대체(page override)입니다. Firefox는 이를 허용하지 않으므로 팝업의 **북마크 관리자 열기**로 관리자를 엽니다. [브라우저 지원](/browser-support)을 참고하세요.

## 필요할 때 요청하는 권한 [#asked-for-when-you-need-it]

| 권한 | 브라우저 | 요청 시점 |
| --- | --- | --- |
| `tabs` | 전체 | 사이드 패널에서 현재 페이지를 저장하거나 폴더 추천을 요청할 때. 먼저 짧은 설명이 표시됩니다. 툴바 팝업에서는 필요하지 않습니다 |
| `contextMenus` | Chrome, Edge | [설정](/settings#data)에서 **컨텍스트 메뉴**를 켤 때. 기본적으로 꺼져 있으며, Chrome은 확인 창 없이 부여합니다 |
| `favicon` | Chrome, Edge | 브라우저가 이미 저장한 아이콘을 표시하기 위해 [설정](/settings#appearance)에서 **브라우저 아이콘 캐시 사용**을 켤 때 |
| 데이터 공유 동의 | Firefox | **AI 기능**이나 **페이지 내용 읽기**를 켜거나 **서비스 확인**을 클릭할 때. Firefox는 확장 프로그램이 AI 제공업체에 무엇이든 보내기 전에 확인합니다 |

거부하면 해당 기능은 꺼진 상태로 유지되며 아무것도 전송되지 않습니다. 나중에 브라우저의 확장 프로그램 설정에서 권한을 회수하면 해당 기능이 꺼지며, 다시 켜면 권한을 다시 요청합니다.

## 선택적 웹사이트 접근 [#optional-website-access]

확장 프로그램은 `http://*/*`와 `https://*/*`에 대한 접근도 선언하지만, 설치할 때는 어느 것도 부여되지 않습니다. 필요한 시점에 브라우저가 묻습니다.

- **깨진 링크 확인**, **메타데이터 가져오기**, **사이트 아이콘 새로 고침**은 북마크가 어느 사이트든 가리킬 수 있으므로 처음 실행할 때 웹사이트 접근 권한을 요청합니다. 요청은 쿠키 없이 전송되며, 제목과 아이콘 링크를 얻기 위해 페이지의 head만 읽습니다. 거부하면 아무것도 검사하지 않습니다. [깨진 링크 찾기와 복구](/guides/dead-links)와 [사이트 아이콘 새로 고침](/guides/clean-up#refresh-site-icons)을 참고하세요.
- AI 설정의 **페이지 내용 읽기**는 켤 때 웹사이트 접근 권한을 요청합니다. 이 권한으로 AI 도구가 쿠키 없이 페이지를 내려받아 본문을 AI 제공업체에 보낼 수 있습니다. 로컬 네트워크의 페이지는 읽지 않습니다. [페이지 내용 읽기](/guides/ai-tools#read-page-content)를 참고하세요.
- AI 설정의 **서비스 확인**과 **모델 새로 고침**은 해당 제공업체 주소 하나에 대한 접근만 요청합니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

접근 권한을 회수하려면 브라우저의 확장 프로그램 페이지(예: `chrome://extensions/`에서 Bookmark Scout의 **세부정보**, 또는 Firefox `about:addons`의 **권한**)를 열고 사이트 접근이나 권한을 변경하세요.

## 요청하지 않는 권한 [#what-is-not-requested]

- 페이지 내용 접근 권한과 콘텐츠 스크립트 없음
- 방문 기록, 다운로드, 쿠키 권한 없음
- 설치 시 호스트 접근 권한 없음

권한을 사용할 때 데이터가 어디로 가는지는 [개인정보 보호](/privacy)에서 다룹니다. 스토어에 제출한 각 권한의 사용 근거는 저장소의 <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink>에 있습니다.
