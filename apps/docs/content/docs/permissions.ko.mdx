아래는 브라우저별로 빌드한 확장 프로그램에 포함된 권한입니다. Bookmark Scout는 콘텐츠 스크립트를 선언하지 않으며 방문하는 페이지는 요청할 때만 읽습니다(팝업의 **이 페이지 본문 색인**이 그 탭에 보이는 본문을 읽고, **탐색 중 표지 캡처**를 켜면 여는 북마크한 페이지의 화면을 찍으며 그 이미지는 이 기기에 남음). 빠른 저장 단축키를 누른 뒤에는 그 탭에 자체 알림을 표시하기만 합니다. 설치할 때는 동작하는 데 꼭 필요한 권한만 요청하며, 나머지는 해당 기능을 켜거나 실행할 때 요청합니다. 표지 가져오기와 **빠른 저장 시 표지 저장**이 켜져 있으면 빠른 저장 단축키가 그 탭의 미리보기 이미지 태그도 읽고, 새 북마크의 표지로 그 탭의 그림을 한 장 찍을 수 있으며 이는 이 기기에만 저장됩니다.

## 브라우저가 요청하는 권한과 그 이유 [#what-your-browser-will-ask-and-why]

Bookmark Scout를 설치하면 브라우저에 한 줄이 표시됩니다. 그 밖의 권한은 필요한 기능을 사용할 때만, Bookmark Scout의 짧은 설명이 먼저 표시된 뒤에 요청합니다. 거부하면 해당 기능만 꺼진 상태로 유지됩니다. 표는 Chrome의 한국어 문구를 그대로 인용하고, Firefox의 문구는 풀어서 설명합니다.

| 브라우저 표시 문구(Chrome과 Edge / Firefox) | 요청 시점 | 이유 |
| --- | --- | --- |
| "북마크 조회 및 변경" / 북마크를 읽고 수정하는 권한 | 설치할 때 | 북마크를 저장하고, 검색하고, 정리합니다 |
| "방문하는 웹사이트의 아이콘 조회"(Chrome과 Edge만 해당) | **사이트 아이콘 새로 고침**에서 **브라우저 아이콘 표시**를 클릭하거나 **브라우저 아이콘 캐시 사용**을 켤 때 | 브라우저가 이미 저장한 아이콘을 북마크 옆에 표시합니다. 아무것도 내려받지 않습니다 |
| "방문 기록 확인" / 브라우저 탭에 접근하는 권한 | 사이드 패널에서 현재 페이지를 저장하거나 폴더 추천을 요청할 때 | 어떤 페이지를 보고 있는지 확인합니다. 툴바 버튼과 빠른 저장 단축키는 권한이 필요 없으므로 설명에서 이 둘을 먼저 안내합니다 |
| "모든 example.com 사이트의 데이터를 읽고 변경" 또는 "여러 웹사이트의 데이터를 읽고 변경" / example.com 도메인에 속한 사이트의 데이터에 접근하는 권한 | **깨진 링크 확인**, **메타데이터 가져오기**, **사이트 아이콘 새로 고침**, **페이지 본문 색인**, **표지 가져오기**를 실행할 때 | 해당 실행에 포함된 북마크 페이지를 그 사이트에서만 요청합니다 |
| "모든 웹사이트에 있는 전체 내 데이터 읽기 및 변경" / 모든 웹사이트의 데이터에 접근하는 권한 | 도구 실행이 20개가 넘는 사이트를 포함하거나 **페이지 내용 읽기**를 켤 때 | 어느 사이트의 페이지든 요청합니다 |
| "모든 웹사이트에 있는 전체 내 데이터 읽기 및 변경" / 모든 웹사이트의 데이터에 접근하는 권한 | **탐색 중 표지 캡처**를 켤 때 | 보고 있는 탭에서 북마크한 페이지가 로드될 때 클릭 없이 그 화면을 찍습니다. 브라우저는 모든 페이지에 대한 접근 권한이 있을 때만 이를 허용합니다. 이미지는 이 기기에 남으며, 같은 접근 권한으로 웹사이트 도구도 묻지 않고 실행됩니다 |
| "api.example.com의 데이터를 읽고 변경" / api.example.com의 데이터에 접근하는 권한 | **서비스 확인**이나 **모델 새로 고침**을 클릭할 때 | AI 제공업체의 주소에 연결합니다 |
| "협력 중인 기본 애플리케이션과 통신" / Firefox 이외의 프로그램과 메시지를 주고받는 권한 | **로컬 AI 에이전트 허용**을 켤 때 | 컴퓨터의 bookmark-scout-mcp 프로그램과 통신합니다 |
| Firefox만 해당: 개발자가 확장 프로그램이 인증 정보, 북마크, 탐색 활동을 수집하려 한다고 알리는 확인 창 | **AI 기능**을 켤 때 | API 키, 북마크와 폴더 이름, 현재 페이지의 제목과 URL이 AI 제공업체로 전송됩니다. 이 확인 창에서 말하는 개발자는 사용자가 선택한 AI 제공업체이며, Bookmark Scout는 아무것도 받지 않습니다 |
| Firefox만 해당: 같은 확인 창에 웹사이트 콘텐츠가 표시됨 | **페이지 내용 읽기**를 켤 때 | 페이지 본문이 AI 제공업체로 전송됩니다 |
| Firefox만 해당: 같은 확인 창에 인증 정보가 표시됨 | **서비스 확인**이나 **모델 새로 고침**을 클릭할 때 | API 키가 AI 제공업체로 전송됩니다 |
| Firefox만 해당: 같은 확인 창에 북마크와 탐색 활동이 표시됨 | **로컬 AI 에이전트 허용**을 켤 때 | 컴퓨터의 AI 에이전트가 조회할 수 있는 항목입니다 |

마우스 오른쪽 버튼 메뉴(**마우스 오른쪽 버튼 메뉴**)도 Chrome과 Edge에서 선택 권한이지만 경고가 없으므로 브라우저가 묻지 않고 추가합니다.

## 설치할 때 부여되는 권한 [#granted-at-install]

| 권한 | 브라우저 | 이유 |
| --- | --- | --- |
| `bookmarks` | 전체 | 북마크를 표시하고 검색하며, 팝업, 사이드 패널, 관리자, 마우스 오른쪽 버튼 메뉴에서 사용자가 작업할 때 북마크를 만들고, 편집하고, 이동하고, 삭제합니다 |
| `storage` | 전체 | 설정을 저장하고, 이 기기에만 AI 제공업체 설정, 태그, 요약, 저장된 검색, 최근 폴더, 최근 검색, **사이트 아이콘 새로 고침**으로 저장한 사이트 아이콘을 저장합니다 |
| `activeTab` | 전체 | 툴바 버튼이나 마우스 오른쪽 버튼 메뉴를 클릭하거나 빠른 저장 단축키를 눌렀을 때 해당 탭의 제목과 URL을 읽어, 보고 있는 페이지를 저장할 수 있게 합니다. 다른 탭이나 방문 기록은 읽지 않습니다. 표지 가져오기가 켜져 있으면 팝업의 **이 화면을 표지로 사용** 버튼으로 그 탭의 화면을 한 장 찍으며, 보관하기 전에 확인할 수 있습니다. 페이지 본문 색인이 켜져 있으면 팝업의 **이 페이지 본문 색인** 버튼으로 그 탭에 보이는 본문을 읽으며, 보관하기 전에 확인할 수 있습니다. 표지 가져오기와 **빠른 저장 시 표지 저장**이 켜져 있으면 빠른 저장 단축키가 그 탭의 미리보기 이미지 태그도 읽고, 검토 없이 그 탭의 그림을 한 장 찍어 새 북마크의 표지로 쓸 수 있습니다. 시크릿 창에서는 하지 않습니다. |
| `scripting` | 전체 | 빠른 저장 단축키를 누른 뒤 그 탭에만 알림을 표시합니다. 페이지에서 아무것도 읽지 않습니다. 페이지 본문 색인이 켜져 있으면, 팝업의 **이 페이지 본문 색인** 버튼을 클릭한 뒤 그 탭에서 함수 하나를 실행해 입력란에 입력한 내용을 뺀, 보이는 그대로의 페이지를 받아 이 기기에서 본문을 읽습니다 |
| `sidePanel` | Chrome, Edge | 사이드 패널 화면을 제공합니다. Firefox에서는 같은 페이지를 사이드바로 선언합니다 |
| `offscreen` | Chrome, Edge | AI 빠른 저장의 요청, 로컬 AI 에이전트의 페이지 읽기, **메타데이터 가져오기**의 페이지 제목 읽기, **페이지 본문 색인**의 페이지 본문 읽기, **AI 폴더 재구성**의 요청을 숨겨진 확장 프로그램 페이지에서 실행하며, 작업이 끝나면 브라우저가 이 페이지를 닫습니다. Firefox에서는 백그라운드 페이지가 직접 처리합니다 |
| `alarms` | 전체 | 타이머로 백그라운드를 깨워, 브라우저가 백그라운드를 멈춘 뒤에도 **깨진 링크 확인** 같은 백그라운드 작업을 이어 갑니다. 확인 창은 표시되지 않습니다 |
| `contextMenus` | Firefox | Firefox에서는 확장 프로그램이 이 권한을 나중에 요청할 수 없습니다. 메뉴는 **마우스 오른쪽 버튼 메뉴**를 켠 뒤에만 나타납니다 |

Chrome과 Edge에서는 확장 프로그램이 브라우저의 북마크 페이지를 Bookmark Scout 관리자로 대체하기도 합니다. 이는 권한이 아니라 페이지 대체(page override)입니다. Firefox는 이를 허용하지 않으므로 팝업의 **북마크 관리자 열기**로 관리자를 엽니다. [브라우저 지원](/browser-support)을 참고하세요.

## 필요할 때 요청하는 권한 [#asked-for-when-you-need-it]

| 권한 | 브라우저 | 요청 시점 |
| --- | --- | --- |
| `tabs` | 전체 | 사이드 패널에서 현재 페이지를 저장하거나 폴더 추천을 요청할 때. 먼저 짧은 설명이 표시되며, 이 권한이 필요 없는 툴바 팝업과 빠른 저장 단축키를 안내합니다 |
| `contextMenus` | Chrome, Edge | [설정](/settings#context-menu)에서 **마우스 오른쪽 버튼 메뉴**를 켤 때. 기본적으로 꺼져 있으며, Chrome은 확인 창 없이 부여합니다 |
| `favicon` | Chrome, Edge | 브라우저가 이미 저장한 아이콘을 표시하기 위해 **사이트 아이콘 새로 고침**에서 **브라우저 아이콘 표시**를 클릭하거나 [설정](/settings#appearance)에서 **브라우저 아이콘 캐시 사용**을 켤 때. 먼저 짧은 설명이 표시됩니다 |
| 데이터 공유 동의 | Firefox | 각 기능은 자신이 보내는 데이터에 대해서만 요청합니다. **AI 기능**은 API 키, 북마크, 현재 페이지의 제목과 URL, **페이지 내용 읽기**는 페이지 본문, **서비스 확인**은 API 키에 대해 요청합니다. 먼저 짧은 설명에서 데이터가 Bookmark Scout가 아니라 AI 제공업체로 전송된다고 알려 줍니다 |
| `nativeMessaging` | 전체 | [설정](/settings#agent-bridge)에서 **로컬 AI 에이전트 허용**을 켤 때. 확장 프로그램이 컴퓨터의 bookmark-scout-mcp 프로그램과 통신할 수 있게 합니다. 먼저 짧은 설명이 표시되며, Firefox에서는 같은 요청에서 북마크 데이터를 그 프로그램과 공유하는 데 대한 동의도 묻습니다 |

거부하면 해당 기능은 꺼진 상태로 유지되며 아무것도 전송되지 않습니다. 나중에 브라우저의 확장 프로그램 설정에서 권한을 회수하면 해당 기능이 꺼지며, 다시 켜면 권한을 다시 요청합니다.

## 선택적 웹사이트 접근 [#optional-website-access]

확장 프로그램은 `http://*/*`, `https://*/*`, `<all_urls>`에 대한 접근도 선언하지만, 설치할 때는 어느 것도 부여되지 않습니다. 필요한 시점에 브라우저가 묻습니다.

- **깨진 링크 확인**, **메타데이터 가져오기**, **사이트 아이콘 새로 고침**은 실행할 때 해당 실행에 포함된 북마크의 사이트(각 사이트의 하위 도메인 포함)에 대한 접근만 요청합니다. 20개가 넘는 사이트를 대상으로 하는 실행은 대신 모든 웹사이트에 대한 접근을 요청합니다. 이전에 허용한 사이트는 다시 요청하지 않습니다. 요청은 쿠키 없이 전송되며, 제목과 아이콘 링크를 얻기 위해 페이지의 head만 읽습니다. 거부하면 아무것도 검사하지 않습니다. 실행 범위 밖의 사이트로 리디렉션되는 링크는 따라갈 수 없으므로 **깨진 링크 확인**은 이를 깨진 링크가 아니라 **직접 확인 필요**로 표시합니다. [깨진 링크 찾기와 복구](/guides/dead-links)와 [사이트 아이콘 새로 고침](/guides/clean-up#refresh-site-icons)을 참고하세요.
- **페이지 본문 색인**도 읽는 북마크의 사이트에 대해 같은 방식으로 요청합니다.
- **표지 가져오기**도 읽는 북마크의 사이트에 대해 같은 방식으로 요청합니다. 다른 사이트에 있는 이미지는 그 사이트도 허용했을 때만 내려받습니다.
- **탐색 중 표지 캡처**는 켤 때 모든 페이지에 대한 접근 권한(`<all_urls>`)을 요청합니다. 브라우저는 이 권한이 있을 때만 확장 프로그램이 클릭 없이 탭 화면을 찍도록 허용합니다. 보고 있는 탭의 북마크한 페이지만 찍고, **캡처하지 않을 사이트**의 사이트는 절대 찍지 않습니다. 시크릿 창에서는 **비공개 창에서도 캡처**를 켜고 그곳에서 확장 프로그램 실행을 허용한 경우에만 찍습니다. 이미지는 이 기기에 남습니다. 이 권한이 부여되어 있는 동안에는 위 도구들이 사이트 접근 권한을 묻지 않습니다. [카드에 표지 표시](/guides/clean-up#capture-covers-while-you-browse)를 참고하세요.
- AI 설정의 **페이지 내용 읽기**는 켤 때 모든 웹사이트에 대한 접근 권한을 요청합니다. 이 권한으로 AI 도구가 쿠키 없이 페이지를 내려받아 본문을 AI 제공업체에 보낼 수 있습니다. **로컬 네트워크 페이지 건너뛰기**가 켜져 있는 동안(기본값은 켜짐) 로컬 네트워크의 페이지는 읽지 않습니다. [페이지 내용 읽기](/guides/ai-tools#read-page-content)를 참고하세요.
- AI 설정의 **서비스 확인**과 **모델 새로 고침**은 해당 제공업체 주소 하나에 대한 접근만 요청합니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

접근 권한을 회수하려면 브라우저의 확장 프로그램 페이지(예: `chrome://extensions/`에서 Bookmark Scout의 **세부정보**, 또는 Firefox `about:addons`의 **권한**)를 열고 사이트 접근이나 권한을 변경하세요.

## 요청하지 않는 권한 [#what-is-not-requested]

- 선언된 콘텐츠 스크립트 없음, 그리고 위에서 켠 기능 외에는 페이지 내용 접근 없음
- 방문 기록, 다운로드, 쿠키 권한 없음
- 설치 시 호스트 접근 권한 없음

권한을 사용할 때 데이터가 어디로 가는지는 [개인정보 보호](/privacy)에서 다룹니다. 스토어에 제출한 각 권한의 사용 근거는 저장소의 <RepoLink file="store/permissions.md">`store/permissions.md`</RepoLink>에 있습니다.
