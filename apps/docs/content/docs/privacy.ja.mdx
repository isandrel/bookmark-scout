## 要点 [#in-short]

- **アカウントもサーバーもありません。** Bookmark Scout はブラウザの中で動作します。開発者が拡張機能から何かを受け取ることはありません。
- **テレメトリーはありません。** 拡張機能にはアクセス解析、クラッシュレポート、広告のいずれもありません。
- **AI はオンにするまでオフです。** オンにした後は、リクエストがブラウザから選んだプロバイダーへ直接送られます。Firefox では、オンにするときに、そのデータの共有への同意も求めます。Chrome の内蔵 AI を使う場合、フォルダの提案はパソコンの外に出ません。
- **ローカル AI エージェントは許可した場合のみ。** **ローカル AI エージェントを許可**をオンにすると（初期設定はオフ）、コンピューター上の AI エージェント（Claude Code など）が bookmark-scout-mcp プログラムを通じてブックマークを調べられます。ブックマークを変更できるのは**変更を許可**がオンの場合だけで、変更ごとにあなたの承認が必要です。
- **権限は必要なときに求めます。** インストール時に拡張機能が求めるのは、動作に欠かせない権限だけです。タブへのアクセス、右クリックメニュー、ブラウザのアイコンキャッシュ、ウェブサイトへのアクセスは、その機能を初めて使うときに求めます。[権限](/permissions)をご覧ください。

## 拡張機能が読み取る情報 [#what-the-extension-reads]

- ブックマーク: 表示、検索、編集、移動、削除、インポート、エクスポートのため。
- アクティブなタブのタイトルと URL: 表示中のページを（ポップアップ、サイドパネル、クイック保存ショートカットから）保存するとき、またはフォルダの提案を求めるとき。
- ブラウザ自身のアイコンキャッシュにあるサイトアイコン: Chrome と Edge で、**ブラウザのアイコンキャッシュを使う** をオンにした後。
- **サイトアイコンを更新** でダウンロードするサイトアイコン: ブックマークした各ウェブサイトから取得します。
- ブックマークしたページの本文（**ページ本文の索引** を実行したとき、実行対象の各ページから）。また、ポップアップで **このページの本文を索引に追加** をクリックしたときは、表示中のタブの本文（あなたが見ているとおりの内容）。
- ブックマークしたページのヘッダー部分と、各ページが指定するプレビュー画像（**カバー画像の取得** を実行したとき、実行対象の各ページから）。 または、ポップアップで **この画面をカバー画像にする** をクリックしたときに撮影する、表示中のタブの画面。
- 表示中のタブで開いたブックマーク済みのページの画面（読み込みが終わった後。**閲覧中にカバー画像を撮影** がオンの間のみ。既定はオフ）。**撮影しないサイト** のサイトは決して撮影せず、プライベートウィンドウで撮影するのは、**プライベートウィンドウでも撮影** もオンにして、ブラウザが拡張機能にそこでの実行を許可している場合だけです。オンの間は、アクティブなタブで読み込まれた各ページのアドレスをブックマークと照合しますが、保存はしません。
- **カバー画像の取得を有効にする** と **クイック保存でカバー画像も保存** がオンのときにページをクイック保存すると、そのカバー画像：そのタブのページが指定するプレビュー画像（ページ自身のサイトか許可したサイトからだけダウンロード）か、ショートカットを押したときに撮ったそのタブの画像を、確認なしで保存します。プライベートウィンドウや、**撮影しないサイト**、**読み込まないサイト** のサイトでは行いません。この端末にのみ保存されます。

アクセスしたページの内容は読み取りません。ただし、ポップアップで **このページの本文を索引に追加** をクリックしたときは表示中のタブの本文を読み取り、保存する前に確認できます。また、**閲覧中にカバー画像を撮影** がオンの間はブックマーク済みのページの画面を撮影しますが、その画像はこの端末にだけ保存されます。クイック保存ショートカットの後は、そのタブに自身の通知を表示しますが、この通知はページから何も読み取りません。**クイック保存でカバー画像も保存** とカバー画像の取得がオンのときは、上記のとおり、クイック保存でページのプレビュー画像のタグも読み取り、そのタブの画像を撮影することがあります。

## 保存する情報 [#what-it-stores]

| データ | 保存先 | 同期 |
| --- | --- | --- |
| 既定値から変更した設定（AI のオン・オフを含む。AI プロバイダー、モデル、API キーは含まない） | ブラウザの同期ストレージ | あり。ブラウザの同期がオンなら、ブラウザのアカウントを通じて同期 |
| デバイスごとの設定: クイック保存に選んだフォルダ、アイコンの保存容量上限、AI アクティビティの記録、AI に質問のウェブ検索 | このデバイスのローカルストレージ | なし |
| ローカル AI エージェントの設定（オン／オフ、非公開の値を隠す、オフにした検索）と、このブラウザープロファイル用のランダムな ID | このデバイスのローカルストレージ | なし |
| カスタムプロンプト（**AIツール** の **プロンプト**）: 各プロンプトの名前、タスク、本文と、各タスクが使うプロンプト（最大 10 件） | ブラウザの同期ストレージ | 設定と同じ |
| 自己紹介（**AI** の設定）: 自分について書いた内容（最大 1,000 文字） | ブラウザの同期ストレージ | 設定と同じ。内容がある間は AI へのリクエストとともに AI プロバイダーに送信 |
| マネージャーのブックマークの表: 表示する列、列の順序、並べ替え | ブラウザの同期ストレージ | 設定と同じ |
| ブックマークの表の列幅と 1 ページの表示件数 | このデバイスのローカルストレージ | なし |
| AI サービス: 各サービスの名前、プロバイダー、モデル | このデバイスのローカルストレージ | なし |
| AI の接続設定: API キー、ベース URL、追加ヘッダー、プロバイダー固有の項目 | このデバイスのローカルストレージ | なし。バックアップファイルにはベース URL とプロバイダー固有の項目が含まれるが、API キーと追加ヘッダーは含まれない |
| AI サービスから取得したモデル一覧（7 日間保持） | このデバイスのローカルストレージ | なし |
| AI アクティビティ（**リクエストを記録** がオンの間のみ。既定はオフ、デバイスごとに設定）: 直近の AI リクエストと、送信した内容および返ってきた内容。ブックマークのタイトル、URL、フォルダパスを含み、**ページの内容を読む** がオンならページの本文も含む。API キーなどの認証情報は保存前に取り除かれ、記録をオフにすると削除される | このデバイスのローカルストレージ | なし |
| タグ、要約、保存した検索、スマートルール、スマートルールによる変更（自動のタグ付けと移動、および確認して実行したルールがタグを付けたブックマーク）の一覧、各ルールの前回の実行と、その実行でルール同士が食い違ったブックマーク、最近のフォルダ、最近の検索 | このデバイスのローカルストレージ | なし |
| **サイトアイコンを更新** で保存したサイトアイコン（初期設定で最大 4 MB） | このデバイスのローカルストレージ | なし |
| **ページ本文の索引** または **このページの本文を索引に追加** で保存したページ本文。読み込み方 (ダウンロードか、タブから読み込んだか)、読み込んだアドレス、本文のフィンガープリント、切り詰めたかどうかも保存します。ブックマークを削除したとき、そのウェブサイトへの拡張機能のアクセスを取り消したとき、またはそのサイトを **読み込まないサイト** に追加したときに削除 | この端末の IndexedDB | なし |
| **カバー画像の取得**、**この画面をカバー画像にする**、**閲覧中にカバー画像を撮影** で保存したカバー画像（それぞれの取得元とともに）、および **クイック保存でカバー画像も保存** で保存したカバー画像。バックアップファイルに含まれるのは **カバー画像を含める** をチェックしたときだけ | この端末の IndexedDB | なし |
| 最後のクイック保存（ページのタイトルと URL、保存先）。**元に戻す** と **移動先** のため | このデバイスのセッションストレージ。ブラウザを閉じると消去 | なし |
| マネージャーの元に戻す履歴（マネージャーで変更したブックマークと、削除したブックマークのコピーとそのタグと要約）。元に戻すとやり直しのため | このデバイスのセッションストレージ。ブラウザを閉じると消去 | なし |
| ブックマークの変更履歴: Bookmark Scout が行ったか、ほかで行われたことを検出したかにかかわらず、いつブックマークの何が変わったか（タイトル、URL、フォルダ、各変更の結果）。一定期間保持します。また、Bookmark Scout 以外での変更を知るため、各ブックマークのタイトル、URL、フォルダを最後に見た状態で保存します。また、Bookmark Scout が削除した項目のコピー（中身、タグ、要約を含む）を、履歴から復元できるように保存します。コピーは対応する変更とともに削除されます。バックアップファイルには含まれません | このデバイスの IndexedDB | いいえ |
| バックグラウンドのタスク（ページを閉じても動き続ける **リンク切れチェック**、**メタデータ取得**、**サイトアイコンを更新**、**ページ本文の索引**、**AIフォルダ整理** などのツールや、大規模な **スマートルール** の実行）：チェックするブックマーク（タイトル、URL、フォルダ）と、ページのタイトルや説明、サイトのアイコン、ページの本文、AI サービスが提案した移動、適用する確認済みの変更 (どのブックマークを、どのタイトル、アドレス、フォルダ、タグにするか) などの各結果。再起動後もタスクを続け、後で結果を確認できるようにするためです。一定期間、または **バックグラウンドのタスク** でタスクを削除するまで保存します。バックアップファイルには含まれません | このデバイスの IndexedDB | いいえ |

ツール サイドバーのスキャン結果は、そのダイアログが開いている間だけ保持されます。拡張機能をアンインストールすると、拡張機能が保存したデータは削除されます。ブックマーク自体はブラウザに残ります。

設定ページ下部の **設定をバックアップ** は、変更した設定、カスタムプロンプト、自己紹介、AI サービス（名前、プロバイダー、モデル、ベース URL、プロバイダー固有の項目）、保存した検索、スマートルール、表の列と並べ替えをバックアップファイルに保存します。API キーと追加ヘッダーは含まれず、ファイルは暗号化されません。[設定](/settings)をご覧ください。カバー画像が保存されている間は、カバー画像も含めるかどうか（**カバー画像を含める**、既定でオン）を確認します。含めた場合、ファイルには各カバー画像と、そのブックマークのアドレス、入手元、保存日時も入ります。[バックアップのカバー画像](/guides/import-export#covers-in-a-backup) を参照してください。

## データがブラウザの外に出るとき [#when-data-leaves-your-browser]

以下の機能を使ったときだけ、記載した送信先にだけ送られます。

| 機能 | 送信先 | 送信される内容 |
| --- | --- | --- |
| AI によるフォルダの提案（AI クイック保存ショートカットを含む） | 設定した AI プロバイダー | 現在のページのタイトルと URL、フォルダ名。**ページの内容を読む** がオンの場合は、ページの本文も |
| 自動タグ付け、コンテンツ要約、AIフォルダ整理 | 設定した AI プロバイダー | 範囲内にあるブックマークのタイトル、URL、フォルダパス。**ページの内容を読む** がオンの場合、自動タグ付けとコンテンツ要約は各ページの本文も送信します。AIフォルダ整理が本文を送信することはありません。自動タグ付けは、**既存のタグを送信** がオフでない限り、よく使うタグの名前も送信します |
| AI に質問 | 設定した AI プロバイダー | 自分のメッセージとそれまでの会話、そして AI が回答のために調べたもの: 一致するブックマーク（フォルダ、追加日、タグ、要約を含む）、フォルダ名、現在のページのタイトルと URL、AI が確認したブックマークのリンクがまだ有効かどうか。**ページの内容を読む** がオンの場合は、AI が読んだページのテキストも。Web 検索をオンにした場合は、プロバイダーが Web も検索します。会話は保存されません |
| リンク切れチェック、メタデータ取得、AI に質問のリンク確認 | ブックマークした各ウェブサイト | ウェブサイトへのアクセスを許可した後、Cookie なしでページをリクエストします |
| サイトアイコンを更新 | ブックマークした各ウェブサイト | ウェブサイトへのアクセスを許可した後、Cookie なしで、サイトごとにブックマークしたページ 1 つと、そのサイトのドメインにあるアイコンファイルをリクエストします。サードパーティのアイコンサービスは使いません |
| ページ本文の索引 | 実行対象の各ブックマークのページ。同じアドレスは 1 回だけ。ユーザー名とパスワード、またはトークンなどの機密パラメータを含むアドレスは、**ログイン情報や秘密を含むアドレスをスキップ** をオフにしない限り取得しません。**読み込まないサイト** のサイトは取得しません | ウェブサイトへのアクセスを許可した後、Cookie なしでページを要求します。混雑していると応答したサイトには、示された短い待ち時間の後に数回まで要求し直します。読み取れる本文はこの端末に残ります |
| カバー画像の取得 | 実行対象の各ブックマークのページと、そのページが指定する画像 | 許可したサイトに限り、Cookie もページのアドレスも付けずに、ページのヘッダー部分と画像を要求します。小さなコピーはこの端末に残ります |
| クイック保存でカバー画像も保存（カバー画像の取得がオンのときのみ） | クイック保存したページ（自身のサイトか許可したサイトにあるプレビュー画像を指定している場合） | その画像のリクエスト。Cookie もページのアドレスも送りません。小さなコピー、または代わりにタブの画像がこの端末に保存されます |
| ローカル AI エージェント（**ローカル AI エージェントを許可**がオンの場合のみ、初期設定はオフ） | コンピューター上の bookmark-scout-mcp プログラムと、そこで実行する AI エージェント | エージェントが求めたもの: 一致するブックマーク（フォルダ、追加日、タグ、要約を含む）、フォルダ名、現在のページのタイトルと URL、ブックマークしたリンクがまだ有効かどうか（ウェブサイトへのアクセスを許可した後）、そして**ページの内容を読む**がオンの場合はページのテキスト。タイトルと URL の非公開の値は、オフにしない限り隠されます。エージェントは読み取った内容を自身の AI プロバイダーに送信する場合があります。**リクエストを記録**がオンの間、各検索は AI アクティビティに残ります |

プロバイダーを使う AI 機能はすべて、**自己紹介**（AI の設定）に内容がある間はそれも送信します。初期値は空です。

Ollama のように自分のコンピューターで動くプロバイダーを使えば、AI のリクエストは手元のマシンから出ません。Chrome の内蔵 AI も同じです。フォルダの提案をこのパソコン上の Chrome 自身のモデルで行い、API キーは使いません。モデルは、あなたが求めたときに Chrome が Google から一度だけダウンロードし、そこにあなたのデータは含まれません。ブックマークのエクスポート、**AIコンテキストパッカー** のファイル、設定のバックアップは自分のコンピューターにファイルとして保存され、どこにもアップロードされません。JSON 形式のブックマークのエクスポートには、各ブックマークのタグと要約も含まれます。ブックマークと AI コンテキストのエクスポートでは、保存前にプライバシーの確認画面で機密性のある値を伏せ字にできます。各 AI ツールが送信する正確なデータは[AI ツールの設定](/guides/ai-tools#what-each-tool-sends)に、各権限の説明は[権限](/permissions)に記載しています。

## このドキュメントサイト [#this-docs-site]

このドキュメントは静的サイトで、アクセス解析もアカウントもなく、独自の Cookie も使いません。フォントは Google Fonts ではなくこのサイトから配信しています。ホスティング事業者はプライバシーポリシーに記載しています。
