## 要点 [#in-short]

- **アカウントもサーバーもありません。** Bookmark Scout はブラウザの中で動作します。開発者が拡張機能から何かを受け取ることはありません。
- **テレメトリーはありません。** 拡張機能にはアクセス解析、クラッシュレポート、広告のいずれもありません。
- **AI はオンにするまでオフです。** オンにした後は、リクエストがブラウザから選んだプロバイダーへ直接送られます。Firefox では、オンにするときに、そのデータの共有への同意も求めます。
- **権限は必要なときに求めます。** インストール時に拡張機能が求めるのは、動作に欠かせない権限だけです。タブへのアクセス、右クリックメニュー、ブラウザのアイコンキャッシュ、ウェブサイトへのアクセスは、その機能を初めて使うときに求めます。[権限](/permissions)をご覧ください。

## 拡張機能が読み取る情報 [#what-the-extension-reads]

- ブックマーク: 表示、検索、編集、移動、削除、インポート、エクスポートのため。
- アクティブなタブのタイトルと URL: 表示中のページを保存するとき、またはフォルダの提案を求めるとき。
- ブラウザ自身のアイコンキャッシュにあるサイトアイコン: Chrome と Edge で、**ブラウザのアイコンキャッシュを使う** をオンにした後。
- **サイトアイコンを更新** でダウンロードするサイトアイコン: ブックマークした各ウェブサイトから取得します。

アクセスしたページの内容は読み取りません。

## 保存する情報 [#what-it-stores]

| データ | 保存先 | 同期 |
| --- | --- | --- |
| 設定（AI のオン・オフ、選んだプロバイダーとモデルを含む） | ブラウザの同期ストレージ | あり。ブラウザの同期がオンなら、ブラウザのアカウントを通じて同期 |
| マネージャーのブックマークの表のレイアウト | ブラウザの同期ストレージ | 設定と同じ |
| AI プロバイダーの設定: API キー、ベース URL、追加ヘッダー | このデバイスのローカルストレージ | なし |
| タグ、要約、保存した検索、最近のフォルダ、最近の検索 | このデバイスのローカルストレージ | なし |
| **サイトアイコンを更新** で保存したサイトアイコン（初期設定で最大 4096 KB） | このデバイスのローカルストレージ | なし |

ツール サイドバーのスキャン結果は、そのダイアログが開いている間だけ保持されます。拡張機能をアンインストールすると、拡張機能が保存したデータは削除されます。ブックマーク自体はブラウザに残ります。

## データがブラウザの外に出るとき [#when-data-leaves-your-browser]

以下の機能を使ったときだけ、記載した送信先にだけ送られます。

| 機能 | 送信先 | 送信される内容 |
| --- | --- | --- |
| AI によるフォルダの提案 | 設定した AI プロバイダー | 現在のページのタイトルと URL、フォルダ名。**ページの内容を読む** がオンの場合は、ページの本文も |
| 自動タグ付け、コンテンツ要約、AIフォルダ整理 | 設定した AI プロバイダー | 範囲内にあるブックマークのタイトル、URL、フォルダパス。**ページの内容を読む** がオンの場合、自動タグ付けとコンテンツ要約は各ページの本文も送信します。AIフォルダ整理が本文を送信することはありません |
| AI に質問 | 設定した AI プロバイダー | 自分のメッセージとそれまでの会話、そして AI が回答のために調べたもの: 一致するブックマーク、フォルダ名、現在のページのタイトルと URL。**ページの内容を読む** がオンの場合は、AI が読んだページのテキストも。Web 検索をオンにした場合は、プロバイダーが Web も検索します。会話は保存されません |
| リンク切れチェック、メタデータ取得 | ブックマークした各ウェブサイト | ウェブサイトへのアクセスを許可した後、Cookie なしでページをリクエストします |
| サイトアイコンを更新 | ブックマークした各ウェブサイト | ウェブサイトへのアクセスを許可した後、Cookie なしで、サイトごとにブックマークしたページ 1 つと、そのサイトのドメインにあるアイコンファイルをリクエストします。サードパーティのアイコンサービスは使いません |

Ollama のように自分のコンピューターで動くプロバイダーを使えば、AI のリクエストは手元のマシンから出ません。エクスポート（**AIコンテキストパッカー** を含む）は自分のコンピューターにファイルとして保存され、どこにもアップロードされません。保存前に、プライバシーの確認画面で機密性のある値を伏せ字にできます。各 AI ツールが送信する正確なデータは[AI ツールの設定](/guides/ai-tools#what-each-tool-sends)に、各権限の説明は[権限](/permissions)に記載しています。

## このドキュメントサイト [#this-docs-site]

このドキュメントは静的サイトで、アクセス解析もアカウントもなく、独自の Cookie も使いません。フォントは Google Fonts ではなくこのサイトから配信しています。ホスティング事業者はプライバシーポリシーに記載しています。
