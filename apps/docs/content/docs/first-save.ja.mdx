---
title: はじめての保存
description: Bookmark Scout を Chrome に追加してアイコンを固定し、フォルダ名の一部を入力して、最初のページを正しいフォルダに保存します。そのあとは、キーひとつで保存できます。
---

1 分ほどで終わります。必要なのは、コンピューターの Chrome と、ブックマークフォルダが 1 つ以上あることだけです。

<Steps>
<Step>
### Bookmark Scout を Chrome に追加する [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

掲載ページで **Chrome に追加** をクリックし、続けて **拡張機能を追加** をクリックします。Chrome が求める許可は 1 つだけで、ブックマークの読み取りと変更です。続いて新しいタブで **Bookmark Scout の準備ができました** というページが開き、以下の手順が簡単にまとめて表示されます。このページには、クイック保存のショートカットに実際に割り当てられたキーも表示されます。Firefox や Edge をお使いの場合は、[インストール](/installation#firefox-and-edge)をご覧ください。
</Step>
<Step>
### アイコンを固定する [#pin-the-icon]

Chrome のツールバー右側にある、パズルピースの形の **拡張機能** ボタンをクリックし、Bookmark Scout の横にあるピンをクリックします。これでアイコンがツールバーに常に表示され、ワンクリックで開けます。
</Step>
<Step>
### 表示中のページを保存する [#save-the-page-you-are-on]

残しておきたいページを開き、Bookmark Scout のアイコンをクリックします。検索ボックスの下の行 **保存するページ** に、そのページのタイトルが表示されます。

フォルダ名の一部を入力します。たとえば「Pasta」というフォルダなら `pas` と入力します。一致するフォルダが **フォルダに保存** の下に、よく一致する順に表示されます。最初のフォルダが強調表示されます。`Enter` を押すとそこに保存され、ほかのフォルダはクリックして保存できます。**ブックマークを追加しました** と表示されれば保存は完了です。
</Step>
<Step>
### 次からはキーひとつで [#next-time-press-one-key]

どのページでも <Shortcut id="commands.quick-save" /> を押します。Bookmark Scout は何も開かずに、そのページに最もよく合うフォルダへ保存します。ページの隅に小さなメッセージが表示され、保存先を教えてくれます。保存を取り消すにはメッセージ内の **元に戻す** をクリックし、別のフォルダに移すには **移動先** からフォルダを選びます。
</Step>
</Steps>

## うまくいかないときは [#if-something-is-different]

- **目的のフォルダが表示されない。** 名前の別の部分を入力するか、そのフォルダが入っているフォルダの名前を数文字加えてみてください（例: `recipes pas`）。小さな入力ミスがあっても見つかります。
- **キーを押しても何も起きない。** ほかの拡張機能がすでにそのキーを使っている可能性があります。Bookmark Scout のアイコンを開くと、**クイック保存のショートカットが未設定です** という行に **設定する** があります。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)をご覧ください。
- **そのページはすでに保存されていた。** Bookmark Scout は同じページを 2 回保存しません。メッセージで保存場所を知らせます。
