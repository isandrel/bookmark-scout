---
title: Votre premier enregistrement
description: Ajoutez Bookmark Scout à Chrome, épinglez-le et enregistrez votre première page dans le bon dossier en saisissant une partie du nom du dossier. Ensuite, enregistrez avec une seule touche.
---

Cela prend environ une minute. Il vous faut Chrome sur un ordinateur et au moins un dossier de favoris.

<Steps>
<Step>
### Ajouter Bookmark Scout à Chrome [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

Sur la fiche, cliquez sur **Ajouter à Chrome**, puis sur **Ajouter l'extension**. Chrome ne demande qu'une seule chose : lire et modifier vos favoris. Une page intitulée **Bookmark Scout est prêt** s'ouvre ensuite dans un nouvel onglet avec un résumé des étapes ci-dessous ; elle affiche les touches réellement attribuées à votre raccourci d'enregistrement rapide. Vous utilisez Firefox ou Edge ? Consultez [Installation](/installation#firefox-and-edge).
</Step>
<Step>
### Épingler l'icône [#pin-the-icon]

Cliquez sur le bouton **Extensions** en forme de pièce de puzzle, à droite de la barre d'outils de Chrome, puis sur l'épingle à côté de Bookmark Scout. Son icône reste désormais dans la barre d'outils, à un clic de vous.
</Step>
<Step>
### Enregistrer la page que vous consultez [#save-the-page-you-are-on]

Ouvrez une page que vous souhaitez conserver et cliquez sur l'icône de Bookmark Scout. La ligne sous le champ de recherche, **Page à enregistrer**, affiche le titre de la page.

Saisissez une partie du nom d'un dossier, par exemple `fin` pour un dossier nommé Fine-tuning. Les dossiers correspondants apparaissent sous **Enregistrer dans un dossier**, le meilleur en premier. Le premier est mis en évidence : appuyez sur `Enter` pour y enregistrer la page, ou cliquez sur n'importe quel dossier. **Favori ajouté** confirme l'enregistrement.
</Step>
<Step>
### La prochaine fois, appuyez sur une touche [#next-time-press-one-key]

Sur n'importe quelle page, appuyez sur <Shortcut id="commands.quick-save" />. Bookmark Scout enregistre la page dans le dossier qui lui correspond le mieux, sans rien ouvrir. Un petit message dans le coin de la page indique où elle a été enregistrée. Cliquez sur **Annuler** dans ce message pour annuler l'enregistrement, ou choisissez un autre dossier sous **Déplacer vers**.
</Step>
</Steps>

## Si quelque chose est différent [#if-something-is-different]

- **Le dossier voulu n'apparaît pas.** Saisissez une autre partie de son nom, ou quelques lettres du dossier qui le contient, par exemple `llms fin`. Une petite faute de frappe ne pose pas de problème.
- **La touche ne fait rien.** Une autre extension l'utilise peut-être déjà. Ouvrez l'icône de Bookmark Scout : la ligne **Raccourci d’enregistrement rapide non défini** propose **Le définir**. Consultez [Enregistrer avec un raccourci clavier](/guides/save-and-organize#quick-save).
- **La page était déjà enregistrée.** Bookmark Scout ne l'enregistre pas deux fois ; le message indique où elle se trouve.
