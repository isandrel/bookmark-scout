Open the settings page from the extension's **Options** entry, for example by right-clicking the toolbar icon in Chrome and choosing **Options**. Changes save as you make them.

## Using the settings page

- The page opens on **Essentials**, the few settings most people change. Every other tab is listed under **Advanced**, and each setting on **Essentials** is also in its own tab there: changing it in either place changes the same setting.
- **Search settings...** at the top finds a setting in any tab and says how many match.
- Each tab is split into titled sections. A tool's on/off switch sits next to its heading; while it is off, the rest of its settings are folded away. Technical settings, such as timeouts and file name lengths, are under **Advanced settings**, which stays closed until you open it or a search finds something in it.
- A changed setting is marked **Modified**, with a button to reset it to its default. **Reset All** resets every setting.
- **Back up settings** saves a backup file with the settings you changed, custom prompts, AI services (name, provider, model, **Base URL**, and provider-specific fields; never API keys or **Extra Headers JSON**), saved searches, smart rules, and the manager table's columns and sort. **Restore settings** restores a backup, replacing each part the file holds, or merges a plain settings file onto your settings; after restoring a backup, enter API keys and extra headers again under [AI](#ai) for the services marked **Needs setup**. Neither touches your bookmarks. **Export Bookmarks** next to them opens the bookmarks manager on its export tool; see [Import and export](/guides/import-export).
- Settings you change are stored in the browser's sync storage, so they follow you to other devices when browser sync is on. A few that belong to one device stay on it: the folder chosen for quick save, **Icon Storage Limit**, AI activity recording, and Ask AI's web search. AI services, with their API keys, **Base URL**, and **Extra Headers JSON**, also stay on this device. See [Privacy](/privacy).

### Bookmark manager menus [#manager-menus]

Choose which commands the manager's right-click and ⋯ menus show, and drag a command by its handle to reorder it within its group. The handle is also a button whose menu moves the command to the top, up, down, or to the bottom, so the keyboard works too. **Restore defaults** brings back the full menu. **View Details** or **Copy Bookmark ID** always stays, so the menu has a command for any bookmark or folder; where none of the commands you kept applies, the menu says **No actions available**.

## AI [#ai]

AI is off by default. These settings matter only after you turn on **AI Features**; until then, the AI settings here and on the **AI Tools** tab are greyed out under a note saying so. You can still change them. Until the default service is set up, an **AI is optional** box at the top says what AI does, what it needs, what it may cost, and what is sent, with a link to [Set up AI tools](/guides/ai-tools).

| Setting | Default | What it does |
| --- | --- | --- |
| **AI Features** | Off | Turn on the AI tools and the popup's folder recommendations. In Firefox, turning it on asks for your consent to share your API key, bookmarks, and the current page's title and URL with your AI provider |
| **AI services** | None | The providers you add, each with its own model and key; AI tools use the default service, except that **Built-in AI** only suggests folders: while it is the default, the other tools use the first other service that is turned on |

Below these, the provider panel holds **API Key**, **Base URL**, **Custom Model**, and **Extra Headers JSON**, with **Verify Service** and **Refresh Models**. The folder limits are sent to the provider as instructions, and its output is not checked against them. See [Set up AI tools](/guides/ai-tools).

### About me [#about-me]

**About me** (empty by default) is a few words about you, such as "I'm a teacher; I save lesson material", up to 1,000 characters. While it has text, the built-in prompts of every AI feature send it to your AI provider, so results fit you better; a custom prompt sends it only if it uses `{{aboutMe}}`. It syncs through your browser account and is saved when you leave the field.

### What Ask AI may do [#ask-ai-actions]

Every lookup and change Ask AI can make is listed here, and all are on by default. Turn one off and Ask AI is not offered it at all. Applying a plan of changes always asks you first, whatever you choose here.

### AI activity [#ai-activity]

**Record requests** (off by default, for this device only) keeps the last 50 AI requests on this device, with API keys and credential headers removed, so you can see exactly what was sent. Turning it off deletes the log. See [See what was sent](/guides/ai-tools#see-what-was-sent).

## AI Tools [#ai-tools]

**Prompts**, at the top of this tab, is the prompt library: read each tool's built-in prompt, or write your own with placeholders such as `{{language}}`. See [Write your own prompts](/guides/ai-tools#write-your-own-prompts).

Each tool has an **Enable** switch (on by default). Turning one off hides it from the manager's **Tools** sidebar.

## Maintenance [#maintenance]

| Tool | Settings and defaults |
| --- | --- |
| **Duplicate Cleaner** | **Match Strategy** Normalized URL; **Normalize www**, **Ignore Protocol**, and **Ignore Trailing Slash** on; **Keep Rule** Oldest; **Max Groups** <SettingDefault path="maintenance.duplicates.max_groups" />. Always scans all bookmarks |
| **URL Cleaner** | **Remove Fragments** off; **Sort Query Parameters** and **Deduplicate Query Parameters** on; **Preserve Parameters** and **Remove Parameters** lists |
| **Smart Rules** | Your rules, in the order they run: **Add rule** or **Start from a template**, then each rule's name, search, tags, and folder, turned on or off; drag a rule to change which move wins. Templates start turned off. See [Tag and move with Smart Rules](/guides/clean-up#tag-and-move-with-smart-rules) |
| **Check Dead Links** | **Request Timeout** <SettingDefault path="maintenance.dead_links.request_timeout_ms" seconds /> s; **Concurrency** <SettingDefault path="maintenance.dead_links.concurrency" />; **Retry Count** <SettingDefault path="maintenance.dead_links.retry_count" />; **Follow Redirects** on; **Success Status Codes** <SettingDefault path="maintenance.dead_links.success_statuses" />; **Default for confirmed dead links**, **Default for links to check manually**, and **Default for redirected links** Keep as is |
| **Background tasks** | **Apply in the Background Above** <SettingDefault path="maintenance.background_tasks.apply_in_background_above" />: reviewed changes to more bookmarks than this are applied in the background, in parts, and keep going when you close the page; each part is one change in the [History](/guides/save-and-organize), undone there |

Tools start on **All Bookmarks**, so a scan from the folder the manager opens on does not miss the others; change a tool's **Default Scope** to start on the open folder instead. **AI Folder Reorganization** starts on the open folder, because a plan for every bookmark sends them all to your AI provider. At the manager's top level, where no folder is open, every tool starts on **All Bookmarks**.

Lists such as **Remove Parameters** are edited as chips: type a name and press Enter, or pick a suggestion. **Success Status Codes** is a checklist of common codes, and you can add others. Each list holds up to 20 entries, and a parameter name up to 32 characters (letters, digits, and URL punctuation), so settings fit in browser sync. The default lists are on [Clean up duplicates and tracking URLs](/guides/clean-up#strip-tracking-parameters). See also [Find and repair dead links](/guides/dead-links).

## For developers [#developers]

### Local AI agents [#agent-bridge]

**Allow local AI agents** (off by default, for this device only) lets AI agents on your computer, such as Claude Code, Codex, or Cursor, look up your bookmarks through the bookmark-scout-mcp program, which you install and register with `bookmark-scout-mcp install`. It does not need **AI Features**. Turning it on asks your browser to let the extension talk to that program. **Allow changes** (off by default) also lets them save pages and propose moves, renames, deletions, and new folders; each change opens a Bookmark Scout window where you approve or decline it, and you can undo it in the bookmark manager. The panel below the switch shows whether the program is running.

**Hide private values** (on by default) replaces sensitive URL parameters, tokens, and email addresses in the titles and URLs agents receive, using the Privacy Scanner's list. **What local agents may do** lists every lookup, all on by default; one you turn off is not offered to agents at all.
