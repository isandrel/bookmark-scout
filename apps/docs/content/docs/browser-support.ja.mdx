主な対象は Chrome です。Edge は Chromium ベースで、以下に記載した点を除いて同じ機能を備えています。Firefox では Manifest V2 のビルドを使い、使える機能は少なくなります。

## 機能一覧 [#feature-matrix]

この表は、ブラウザごとにビルドした拡張機能のマニフェストと、コード内のブラウザ判定に基づいています。

| 機能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 検索と保存ができるツールバーのポップアップ | 対応 | 対応 | 対応 |
| ページ内に通知を表示するクイック保存ショートカット | 対応。`chrome://extensions/shortcuts` でキーを変更でき、クイック保存に `Ctrl+D` を割り当てることもできます | 対応。`edge://extensions/shortcuts` でキーを変更でき、`Ctrl+D` も割り当てられます | 対応。Bookmark Scout の設定か、Firefox の **拡張機能のショートカットキーの管理** でキーを変更します。`Ctrl+D` と `Ctrl+Shift+D` は Firefox 自身が使います |
| サイドパネル | 対応 | 対応 | 対応（Firefox のサイドバー）: サイドバーで Bookmark Scout を選択します |
| ブックマークマネージャーとツール サイドバー | ブラウザのブックマークページを置き換えます。ポップアップとサイドパネルの **ブックマークマネージャーを開く** からも開けます | **ブックマークマネージャーを開く** から開きます。Edge がお気に入りページにも置き換えを適用するかどうかは確認されていません。 | ポップアップの **ブックマークマネージャーを開く** から開きます。Firefox はブックマークページを置き換えられません。 |
| 保存した検索、メンテナンスツール、インポートとエクスポート、統計、マネージャーの AI ツール | 対応 | 対応 | マネージャー内で対応。インポートとエクスポート、レポートは自動テストで確認され、その他のツールは手動で確認されています。 |
| 設定ページ | 対応 | 対応 | 対応 |
| AI に質問とその他の AI ツール | 対応 | 対応 | 対応（AI プロバイダーとのデータ共有に同意した後） |
| `bookmark-scout-mcp` によるローカル AI エージェント | 対応 | 対応 | 対応。`bookmark-scout-mcp install` で Firefox にも登録されます。自動テストの対象外です |
| マネージャーからシークレット ウィンドウで開く | 対応 | 対応（InPrivate ウィンドウ） | 対応（プライベートウィンドウ。拡張機能のプライベートウィンドウでの実行が許可されている場合） |
| リンクを保存する右クリックメニュー | 対応（**コンテキストメニュー** をオンにした後。権限の許可を求めます） | 同じ | 対応（**コンテキストメニュー** をオンにした後） |
| ブックマークの横のサイトアイコン | **サイトアイコンを更新** で保存したアイコンと、**ブラウザのアイコンキャッシュを使う** をオンにした後はブラウザのアイコンキャッシュのアイコン | 同じ | **サイトアイコンを更新**（マネージャーで実行）で保存したアイコンのみ。Firefox には拡張機能向けのファビコン API がないため、それ以外のブックマークには汎用のアイコンが表示されます。 |
| リンク切れチェック、タイトル取得、サイトアイコン更新のための任意のウェブサイトへのアクセス | ツールの実行時に求めます | 同じ | 同じ |

## テストされている範囲 [#what-is-tested]

- **Chrome（Chromium）**: ポップアップ、サイドパネル、マネージャー、設定、メンテナンスツール、レポート、インポートとエクスポート、キーボードショートカット、クイック保存、保存した検索、コンテキストメニューからの保存、ドラッグ＆ドロップ、ネットワークツール、モックのプロバイダーを使った AI ツール、それらのいくつかをまたぐ一連の操作について、ユニットテストとエンドツーエンドテストがあります。ブリッジのテストでは、Linux と macOS の Chromium で `bookmark-scout-mcp` プログラムを拡張機能と一緒に実行します。
- **Edge**: 同じエンドツーエンドテストを Edge のビルドで実行します。
- **Firefox**: スモークテストで、ポップアップでの検索とフォルダ作成、タブで読み込んだサイドパネルのページ、ポップアップとサイドパネルからのマネージャーの起動、マネージャーのページ（アドレス、`Delete` と元に戻す、フォルダツリーのキー、右クリックメニュー、スクリプトで発生させたドラッグイベントによるドラッグ＆ドロップ）、クイック保存ショートカットの通知とキーの記録、AI のデータ共有への同意、設定の保存、JSON のエクスポートとインポートの往復、統計とプライバシーのレポート、ポップアップに表示される保存済みのサイトアイコンを確認しています。ページ上の右クリックメニューからの保存、その他のキーボードショートカット、ポップアップでのドラッグ＆ドロップ、クイック保存の通知そのもの、ローカル AI エージェント、ネットワークツールと AI ツール（**サイトアイコンを更新** 自体を含む）は対象外です。

Edge のテストと Firefox のスモークテストは、Chromium のテストと同様に CI の必須チェックです。実際の AI プロバイダーと実際のウェブサイトは、自動テストではなく手動で確認しています。

## Safari [#safari]

Safari には対応していません。Safari Web Extensions は `bookmarks` API を実装しておらず、Bookmark Scout のすべての機能がこの API に依存しているためです。
