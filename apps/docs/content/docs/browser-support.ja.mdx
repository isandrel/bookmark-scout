title: ブラウザ対応
description: Chrome、Microsoft Edge、Firefox でそれぞれ何が使えるか、各ブラウザで何がテストされているか、Safari に対応していない理由を説明します。
---

主な対象は Chrome です。Edge は Chromium ベースで、以下に記載した点を除いて同じ機能を備えています。Firefox では Manifest V2 のビルドを使い、使える機能は少なくなります。

## 機能一覧 [#feature-matrix]

この表は、ブラウザごとにビルドした拡張機能のマニフェストに基づいています。

| 機能 | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| 検索と保存ができるツールバーのポップアップ | 対応 | 対応 | 対応 |
| サイドパネル | 対応 | 対応 | 非対応。ページは Firefox のサイドバーとして宣言されていますが、Firefox では何もテストされていません。 |
| ブックマークマネージャーとツール サイドバー | ブラウザのブックマークページを置き換えます。ポップアップとサイドパネルの **ブックマークマネージャーを開く** からも開けます | **ブックマークマネージャーを開く** から開きます。Edge がお気に入りページにも置き換えを適用するかどうかは確認されていません。 | ポップアップの **ブックマークマネージャーを開く** から開きます。Firefox はブックマークページを置き換えられません。 |
| 保存した検索、メンテナンスツール、インポートとエクスポート、統計、マネージャーの AI ツール | 対応 | 対応 | マネージャー内で対応。インポートとエクスポート、レポートは自動テストで確認され、その他のツールは手動で確認されています。 |
| 設定ページ | 対応 | 対応 | 対応 |
| リンクを保存する右クリックメニュー | 対応（**コンテキストメニュー** をオンにした後。権限の許可を求めます） | 同じ | 対応（**コンテキストメニュー** をオンにした後） |
| ブックマークの横のサイトアイコン | **サイトアイコンを更新** で保存したアイコンと、**ブラウザのアイコンキャッシュを使う** をオンにした後はブラウザのアイコンキャッシュのアイコン | 同じ | **サイトアイコンを更新**（マネージャーで実行）で保存したアイコンのみ。Firefox には拡張機能向けのファビコン API がないため、それ以外のブックマークには汎用のアイコンが表示されます。 |
| リンク切れチェック、タイトル取得、サイトアイコン更新のための任意のウェブサイトへのアクセス | ツールの実行時に求めます | 同じ | 同じ |

## テストされている範囲 [#what-is-tested]

- **Chrome（Chromium）**: ポップアップ、サイドパネル、マネージャー、設定、メンテナンスツール、レポート、インポートとエクスポート、キーボードショートカット、保存した検索、コンテキストメニューからの保存、ドラッグ＆ドロップ、ネットワークツール、モックのプロバイダーを使った AI ツールについて、ユニットテストとエンドツーエンドテストがあります。
- **Edge**: 同じエンドツーエンドテストを Edge のビルドで実行します。
- **Firefox**: スモークテストで、ポップアップでの検索とフォルダ作成、タブで読み込んだサイドパネルのページ、ポップアップとサイドパネルからのマネージャーの起動、マネージャーのページ、設定の保存、JSON のエクスポートとインポートの往復、統計とプライバシーのレポート、ポップアップに表示される保存済みのサイトアイコンを確認しています。コンテキストメニュー、ドラッグ＆ドロップ、キーボードショートカット、ネットワークツールと AI ツール（**サイトアイコンを更新** 自体を含む）は対象外です。

Edge のテストと Firefox のスモークテストは、Chromium のテストと同様に CI の必須チェックです。実際の AI プロバイダーと実際のウェブサイトは、自動テストではなく手動で確認しています。

## Safari [#safari]

Safari には対応していません。Safari Web Extensions は `bookmarks` API を実装しておらず、Bookmark Scout のすべての機能がこの API に依存しているためです。
