## 可以用它做什麼 [#what-you-can-do-with-it]

- **尋找**：從工具列彈出式視窗或側邊面板，依標題或網址搜尋所有書籤，並在書籤管理員中保留已命名的搜尋。請參閱「[搜尋和已儲存的搜尋](/guides/search)」。
- **整理**：將目前網頁或連結儲存至任何資料夾、拖曳資料夾調整結構，刪除後也可以復原。請參閱「[儲存和整理](/guides/save-and-organize)」。
- **清理**：移除重複書籤、清除追蹤參數，以及找出並修復失效連結。請參閱「[清理重複書籤和追蹤網址](/guides/clean-up)」和「[找出並修復失效連結](/guides/dead-links)」。
- **搬移書籤庫**：匯出為 HTML、JSON、Markdown 或 CSV，並在預覽後匯入 HTML 或 JSON。請參閱「[匯入和匯出](/guides/import-export)」。
- **只在需要時使用 AI**：AI 工具預設為關閉。開啟後，由你選擇供應商並使用自己的金鑰。請參閱「[設定 AI 工具](/guides/ai-tools)」。

## 資料的去向 [#where-your-data-goes]

Bookmark Scout 沒有帳戶，也沒有自己的伺服器。書籤會留在瀏覽器中。只有在使用需要網路的功能時 (例如檢查失效連結，或使用已開啟的 AI 工具)，資料才會離開瀏覽器，並直接傳送至你選擇的網站或供應商。請閱讀「[隱私權摘要](/privacy)」。

## 瀏覽器 [#browsers]

Chrome 是主要支援的瀏覽器。Edge 同樣以 Chromium 為基礎，並執行相同的端對端測試套件。Firefox 無法取代其書籤頁面，因此書籤管理員要從彈出式視窗中的按鈕開啟，部分瀏覽器功能也有所不同。詳情請參閱「[瀏覽器支援](/browser-support)」。
