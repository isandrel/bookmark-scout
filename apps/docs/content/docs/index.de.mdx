Bookmark Scout ist eine kostenlose Browsererweiterung, die jede Seite, die Sie speichern, im richtigen Lesezeichenordner ablegt. Klicken Sie auf das Symbol, geben Sie ein paar Buchstaben eines Ordnernamens ein, und die Seite landet dort. Bookmark Scout funktioniert bereits heute in Chrome.

<StartHere />

## Was Sie damit tun können [#what-you-can-do-with-it]

- **Im richtigen Ordner speichern**: Geben Sie einen Teil eines Ordnernamens ein, auch eines Ordners, der tief in anderen Ordnern liegt, und wählen Sie ihn aus der Liste, um die aktuelle Seite zu speichern. Siehe [Ihr erstes Lesezeichen](/first-save).
- **Mit einer Taste speichern**: Drücken Sie auf einer beliebigen Seite <Shortcut id="commands.quick-save" />, um sie im am besten passenden Ordner zu speichern. Eine kleine Nachricht auf der Seite zeigt, wo sie gelandet ist, mit **Rückgängig** und weiteren Ordnern, in die Sie sie verschieben können. Siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save).
- **Finden**: Durchsuchen Sie alle Lesezeichen nach einem Wort in ihrem Titel oder ihrer Adresse, über die Schaltfläche in der Symbolleiste oder die Seitenleiste. Siehe [Suche und gespeicherte Suchen](/guides/search).
- **Ordnen**: eine Lesezeichenseite, die wie die von Chrome funktioniert, mit Drag-and-drop, Rechtsklickmenüs, Ausschneiden, Kopieren und Einfügen sowie Rückgängigmachen mit <Shortcut id="manager.undo" />. Siehe [Speichern und ordnen](/guides/save-and-organize).
- **Bereinigen**: Entfernen Sie doppelte Lesezeichen, räumen Sie Adressen voller Tracking-Codes auf, und finden Sie Links, die nicht mehr funktionieren. Siehe [Duplikate und Tracking-URLs bereinigen](/guides/clean-up) und [Defekte Links finden und reparieren](/guides/dead-links).
- **Lesezeichen mitnehmen**: Exportieren Sie sie in eine Datei, oder übernehmen Sie sie nach einer Vorschau aus einem anderen Browser. Siehe [Import und Export](/guides/import-export).
- **KI nutzen, nur wenn Sie möchten**: KI bleibt aus, bis Sie sie einschalten, und sie braucht ein Konto bei einem KI-Unternehmen, das für die Nutzung Geld verlangen kann. Sie kann einen Ordner vorschlagen oder Fragen zu Ihren Lesezeichen beantworten und ändert nichts ohne Ihre Zustimmung. Siehe [KI-Tools einrichten](/guides/ai-tools).

## Wohin Ihre Daten gehen [#where-your-data-goes]

Bookmark Scout hat kein Konto und keinen eigenen Server. Ihre Lesezeichen bleiben in Ihrem Browser. Daten verlassen den Browser nur, wenn Sie eine Funktion verwenden, die das Internet braucht, etwa die Prüfung auf defekte Links oder ein KI-Tool, das Sie eingeschaltet haben. Sie gehen dann direkt an die Website oder das KI-Unternehmen, das Sie gewählt haben. Lesen Sie die [Datenschutz-Zusammenfassung](/privacy).

Bookmark Scout stammt von einem unabhängigen Entwickler: kein Unternehmen, keine Werbung, kein Konto, und der Code ist Open Source.
