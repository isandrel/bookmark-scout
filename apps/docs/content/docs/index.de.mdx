## Was Sie damit tun können [#what-you-can-do-with-it]

- **Im richtigen Ordner speichern**: Geben Sie im Pop-up oder in der Seitenleiste einen Teil eines Ordnernamens ein, auch eines Ordners tief im Baum, oder einen Pfad wie `work/react`, und drücken Sie dann `↓` und `Enter` oder klicken Sie auf den Ordner, um die aktuelle Seite dort zu speichern. Wenn KI aktiviert ist, können Sie sich auch einen Ordner vorschlagen lassen. Siehe [Speichern und ordnen](/guides/save-and-organize).
- **Speichern, ohne etwas zu öffnen**: Drücken Sie auf einer beliebigen Seite `Alt+Shift+S`, um sie im am besten passenden Ordner zu speichern. Eine kleine Benachrichtigung auf der Seite zeigt, wo sie gelandet ist, mit **Rückgängig** und weiteren Ordnern, in die Sie sie verschieben können. Siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save).
- **Finden**: Durchsuchen Sie alle Lesezeichen nach Titel oder URL über das Pop-up in der Symbolleiste oder die Seitenleiste, und speichern Sie benannte Suchen im Lesezeichen-Manager. Siehe [Suche und gespeicherte Suchen](/guides/search).
- **Ordnen**: Speichern Sie Links über das Rechtsklickmenü, und verwenden Sie einen Lesezeichen-Manager, der wie der von Chrome funktioniert, mit Auswahl, Rechtsklickmenüs, Ausschneiden, Kopieren und Einfügen, Drag-and-drop sowie Rückgängigmachen und Wiederholen mit `Ctrl+Z` und `Ctrl+Y`. Siehe [Speichern und ordnen](/guides/save-and-organize).
- **Bereinigen**: Löschen Sie doppelte Lesezeichen, entfernen Sie Tracking-Parameter, und finden und reparieren Sie defekte Links. Siehe [Duplikate und Tracking-URLs bereinigen](/guides/clean-up) und [Defekte Links finden und reparieren](/guides/dead-links).
- **Sammlung mitnehmen**: Exportieren Sie nach HTML, JSON, Markdown oder CSV, und importieren Sie HTML oder JSON nach einer Vorschau. Siehe [Import und Export](/guides/import-export).
- **KI nutzen, nur wenn Sie möchten**: KI-Tools sind standardmäßig deaktiviert. Wenn Sie sie aktivieren, wählen Sie den Anbieter und verwenden Ihren eigenen Schlüssel. **KI fragen** beantwortet Fragen zu Ihren Lesezeichen und ändert sie erst, nachdem Sie seinem Plan zugestimmt haben. Siehe [KI-Tools einrichten](/guides/ai-tools).
- **Mit lokalen KI-Agenten arbeiten**: Lassen Sie KI-Agenten auf Ihrem Computer, etwa Claude Code, Codex oder Cursor, Ihre Lesezeichen nachschlagen, und bestätigen Sie jede Änderung, die sie anfordern, im Browser. Standardmäßig deaktiviert. Siehe [Mit lokalen KI-Agenten verwenden](/guides/local-agents).

## Wohin Ihre Daten gehen [#where-your-data-goes]

Bookmark Scout hat kein Konto und keinen eigenen Server. Ihre Lesezeichen bleiben in Ihrem Browser. Daten verlassen den Browser nur, wenn Sie eine Funktion verwenden, die das Netzwerk benötigt, etwa die Prüfung auf defekte Links oder ein KI-Tool, das Sie aktiviert haben. Sie gehen dann direkt an die Website oder den Anbieter, den Sie gewählt haben. Lokale KI-Agenten erhalten, wenn Sie sie zulassen, das, was sie nachschlagen, über ein Programm auf Ihrem Computer. Lesen Sie die [Datenschutz-Zusammenfassung](/privacy).

## Browser [#browsers]

Chrome ist die primäre Zielplattform. Edge basiert ebenfalls auf Chromium und durchläuft dieselbe End-to-End-Testsuite. In Firefox, das seine Lesezeichenseite nicht ersetzen kann, öffnet sich der Manager über eine Schaltfläche im Pop-up, und einige Browserfunktionen unterscheiden sich. Details finden Sie unter [Browserunterstützung](/browser-support).
