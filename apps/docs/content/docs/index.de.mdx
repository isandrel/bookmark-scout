## Was Sie damit tun können [#what-you-can-do-with-it]

- **Finden**: Durchsuchen Sie alle Lesezeichen nach Titel oder URL über das Pop-up in der Symbolleiste oder die Seitenleiste, und speichern Sie benannte Suchen im Lesezeichen-Manager. Siehe [Suche und gespeicherte Suchen](/guides/search).
- **Ordnen**: Speichern Sie die aktuelle Seite oder einen Link in einem beliebigen Ordner, bringen Sie Ordner per Drag-and-drop in Form, und löschen Sie mit der Möglichkeit, dies rückgängig zu machen. Siehe [Speichern und ordnen](/guides/save-and-organize).
- **Bereinigen**: Löschen Sie doppelte Lesezeichen, entfernen Sie Tracking-Parameter, und finden und reparieren Sie defekte Links. Siehe [Duplikate und Tracking-URLs bereinigen](/guides/clean-up) und [Defekte Links finden und reparieren](/guides/dead-links).
- **Sammlung mitnehmen**: Exportieren Sie nach HTML, JSON, Markdown oder CSV, und importieren Sie HTML oder JSON nach einer Vorschau. Siehe [Import und Export](/guides/import-export).
- **KI nutzen, nur wenn Sie möchten**: KI-Tools sind standardmäßig deaktiviert. Wenn Sie sie aktivieren, wählen Sie den Anbieter und verwenden Ihren eigenen Schlüssel. Siehe [KI-Tools einrichten](/guides/ai-tools).

## Wohin Ihre Daten gehen [#where-your-data-goes]

Bookmark Scout hat kein Konto und keinen eigenen Server. Ihre Lesezeichen bleiben in Ihrem Browser. Daten verlassen den Browser nur, wenn Sie eine Funktion verwenden, die das Netzwerk benötigt, etwa die Prüfung auf defekte Links oder ein KI-Tool, das Sie aktiviert haben. Sie gehen dann direkt an die Website oder den Anbieter, den Sie gewählt haben. Lesen Sie die [Datenschutz-Zusammenfassung](/privacy).

## Browser [#browsers]

Chrome ist die primäre Zielplattform. Edge basiert ebenfalls auf Chromium und durchläuft dieselbe End-to-End-Testsuite. In Firefox, das seine Lesezeichenseite nicht ersetzen kann, öffnet sich der Manager über eine Schaltfläche im Pop-up, und einige Browserfunktionen unterscheiden sich. Details finden Sie unter [Browserunterstützung](/browser-support).
