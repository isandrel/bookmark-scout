---
title: Поддержка браузеров
description: Что работает в Chrome, Microsoft Edge и Firefox, где взять расширение для каждого из них и почему Safari не поддерживается.
---

Лучше всего Bookmark Scout работает в Chrome, где он доступен в Интернет-магазине Chrome. В Edge есть те же функции, кроме отмеченных ниже. В Firefox набор функций немного меньше, потому что он позволяет расширениям делать с закладками меньше. Все три браузера работают на компьютере; телефоны и планшеты не поддерживаются.

## Где взять [#where-to-get-it]

<StoreAvailability />

Если в магазине Bookmark Scout ещё нет, его можно [установить вручную](/installation#install-from-a-github-release). Материалы для страниц в магазинах готовятся в <RepoLink tree="store">папке `store/`</RepoLink> репозитория, и каждый магазин проверяет расширение перед публикацией.

## Что где работает [#feature-matrix]

Эта таблица составлена по манифестам собранного расширения для каждого браузера и по проверкам браузера в его коде.

| Функция | Chrome | Edge | Firefox |
| --- | --- | --- | --- |
| Всплывающее окно на панели инструментов с поиском и сохранением | Да | Да | Да |
| Сочетания клавиш быстрого сохранения с уведомлением на странице | Да. Клавиши меняются на странице `chrome://extensions/shortcuts`, где быстрому сохранению можно также отдать <Shortcut id="browser.bookmark_page" /> | Да. Клавиши меняются на странице `edge://extensions/shortcuts`, включая <Shortcut id="browser.bookmark_page" /> | Да. Клавиши меняются в настройках Bookmark Scout или в разделе Firefox **Управление горячими клавишами расширений**. Firefox оставляет <Shortcut id="browser.bookmark_page" /> и <Shortcut id="browser.bookmark_all_tabs" /> за собой |
| Боковая панель | Да | Да | Да, в боковой панели Firefox: выберите в ней Bookmark Scout |
| Диспетчер закладок и боковая панель «Инструменты» | Заменяет страницу закладок браузера и открывается кнопкой **Открыть диспетчер закладок** во всплывающем окне и боковой панели | Открывается кнопкой **Открыть диспетчер закладок**. Применяет ли Edge эту замену и к своей странице «Избранное», не проверялось. | Открывается кнопкой **Открыть диспетчер закладок** во всплывающем окне. Firefox не позволяет заменить свою страницу закладок. |
| Сохранённые поиски, инструменты обслуживания, импорт и экспорт, статистика, инструменты ИИ в диспетчере | Да | Да | Да, в диспетчере. Автоматические тесты покрывают импорт, экспорт и отчёты; остальные инструменты проверяются вручную. |
| Страница настроек | Да | Да | Да |
| «Спросить ИИ» и другие инструменты ИИ | Да | Да | Да, после того как вы согласитесь передавать данные своему ИИ-провайдеру |
| Встроенный ИИ, бесплатный, на вашем компьютере, для подсказок папок | Да, Chrome 138 или новее на компьютере, где может работать модель Chrome | Только если Edge предлагает такой же встроенный ИИ; не проверялось | Нет: в Firefox нет встроенного ИИ |
| Локальные ИИ-агенты через `bookmark-scout-mcp` (для разработчиков) | Да | Да | Да; `bookmark-scout-mcp install` регистрирует его и в Firefox. Автоматическими тестами не покрыто |
| Открытие в режиме инкогнито из диспетчера | Да | Да, в окне InPrivate | Да, в приватном окне, если расширению разрешено работать в приватных окнах |
| Контекстное меню для сохранения ссылок | Да, после того как вы включите **Контекстное меню** (запрашивает разрешение) | То же | Да, после того как вы включите **Контекстное меню** |
| Значки сайтов рядом с закладками | Значки, сохранённые инструментом **Обновление значков сайтов**, и из кеша значков браузера, если вы включите **Использовать кеш значков браузера** | То же | Только значки, сохранённые инструментом **Обновление значков сайтов**, который работает в диспетчере. В Firefox нет API значков сайтов для расширений, поэтому у остальных закладок стандартный значок. |
| Необязательный доступ к сайтам для проверки неработающих ссылок, загрузки названий и обновления значков сайтов | Запрашивается при запуске инструмента | То же | То же |

Насколько каждый браузер покрыт автоматическими тестами, описано в разделе [Состояние проекта](/status#what-is-tested-in-each-browser).

## Safari [#safari]

Safari не поддерживается. Веб-расширения Safari не реализуют API `bookmarks`, от которого зависит каждая часть Bookmark Scout.
