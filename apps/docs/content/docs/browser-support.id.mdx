title: Dukungan browser
description: Apa yang berfungsi di Chrome, Microsoft Edge, dan Firefox, di mana mendapatkannya untuk masing-masing browser, dan mengapa Safari tidak didukung.
---

Bookmark Scout berfungsi paling baik di Chrome, tempat ekstensi ini tersedia dari Chrome Web Store. Edge memiliki fitur yang sama, kecuali yang disebutkan di bawah. Firefox memiliki fitur yang sedikit lebih sedikit, karena Firefox membatasi apa yang bisa dilakukan ekstensi dengan bookmark. Ketiganya berjalan di komputer; ponsel dan tablet tidak didukung.

## Tempat mendapatkannya [#where-to-get-it]

<StoreAvailability />

Jika store belum menyediakan Bookmark Scout, Anda bisa [menginstalnya secara manual](/installation#install-from-a-github-release). Materi untuk halaman store disiapkan di <RepoLink tree="store">folder `store/`</RepoLink> repositori, dan setiap store meninjau ekstensi sebelum menampilkannya.

## Safari [#safari]

Safari tidak didukung. Safari Web Extensions tidak mengimplementasikan API `bookmarks`, yang menjadi dasar setiap bagian Bookmark Scout.
