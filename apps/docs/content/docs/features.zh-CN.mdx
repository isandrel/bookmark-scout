## 运行位置 [#where-it-runs]

| 界面 | 说明 |
| --- | --- |
| 弹出窗口 | 工具栏按钮：搜索、文件夹树、保存书签和 AI 文件夹推荐 |
| 侧边栏 | 在浏览器侧边栏（Firefox 中为侧栏）中显示的相同视图，浏览网页时可保持打开 |
| 书签管理器 | 在 Chrome 和 Edge 中替换浏览器的书签页面：包含文件夹树、路径导航、书签表格和**工具**侧栏 |
| 设置 | 扩展程序的选项页面，共有十一个标签页。请参阅[设置](/settings) |
| 右键菜单 | 开启**右键菜单**后，可在任意链接上使用**将书签保存到…** |

## 查找 [#find]

- 输入时即时搜索标题和网址，支持区分大小写、全字匹配和正则表达式选项，并高亮显示匹配内容。包含匹配项的文件夹会自动展开。
- 本设备上的最近搜索记录，可以清除或关闭。
- 书签管理器中的表格筛选器，可按标题、网址、类型、文件夹、域名和添加日期筛选，并可按任意列排序。
- 已保存的搜索：命名的筛选条件组合，每次打开时都会针对你的书签重新计算。最多 50 个，保存在本设备上。

指南：[搜索和已保存的搜索](/guides/search)。

## 保存和整理 [#save-and-organize]

- 将当前网页保存到任意文件夹，同一文件夹中不会重复保存，并提供列出你用过的文件夹的**最近**面板。
- 通过右键菜单将链接保存到最近使用的文件夹或书签栏。
- 在书签管理器中创建文件夹、拖放书签和文件夹，以及一次移动多项。
- 按添加日期、自然字母顺序或文件夹优先排序，不会改变浏览器中存储的顺序。
- 修改名称和网址，并在**书签详情**中添加标签和摘要。
- 删除时可选择是否确认，并可在 10 秒内撤消，撤消会恢复文件夹中的全部内容。
- 在书签管理器中，可以拖动或使用方向键调整表格列宽；**重置视图**可恢复默认布局。

指南：[保存和整理](/guides/save-and-organize)。

## 清理 [#clean-up]

- **重复书签清理**：使用可配置的匹配方式查找重复书签，经你确认后移除多余的副本，并支持撤消。
- **网址清理**：在预览后去除 `utm_source` 等跟踪参数。
- **检查失效链接**：将确认失效的链接与需要手动检查的链接区分开，并可通过删除、跟随重定向、使用 Wayback Machine 链接或修改网址来修复，支持撤消。
- **元数据获取**：根据在线网页建议标题（仅读取网页的 head 部分），并应用你选中的建议。描述仅供查看，永远不会保存。
- **刷新网站图标**：经你确认后下载每个网站自己的图标，这样即使浏览器没有缓存图标，书签也能显示图标，在 Firefox 中同样如此。图标保存在本设备上，可以清除。
- **隐私扫描**：标记包含令牌、敏感参数、电子邮件地址或 UUID 的网址，也可选择同时扫描标题。
- **书签统计**：针对某个文件夹或全部书签，统计热门域名和文件夹、协议、重复项以及文件夹的嵌套深度。

指南：[清理重复书签和跟踪网址](/guides/clean-up)以及[查找并修复失效链接](/guides/dead-links)。

## 导入和导出 [#import-and-export]

- 导出为 HTML、JSON、Markdown 或 CSV，导出前会进行隐私检查，可对文件中的敏感值进行脱敏。
- 预览目标文件夹、数量和重复项后导入 HTML 或 JSON，并支持撤消。
- 以 JSON 文件导出和导入扩展程序的设置。

指南：[导入和导出](/guides/import-export)。

## AI 工具（可选） [#ai-tools-optional]

默认关闭。可使用你自己的密钥接入 OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter，或 models.dev 目录中的约 200 个其他服务商，也可以使用 Ollama、CLIProxyAPI 或任何兼容 OpenAI 的端点。

- 弹出窗口中的文件夹推荐，包括需经你确认的新文件夹路径。
- 针对当前文件夹的**自动标签**和**内容摘要**，仅在你审阅后才会保存。
- **AI 文件夹重组**，在移动任何内容之前先进行预览。
- **AI 上下文打包**，将书签导出为 Markdown 或 XML 以供 AI 对话使用，在 AI 关闭时也能使用。

标签和摘要保存在本设备上。它们不会同步，不可搜索，也不会包含在书签导出文件中。指南：[设置 AI 工具](/guides/ai-tools)。

## 键盘和语言 [#keyboard-and-language]

- 弹出窗口、侧边栏和书签管理器中的快捷键均不使用 `Ctrl` 或 `Cmd`，书签管理器中可按 `?` 打开帮助对话框。请参阅[键盘快捷键](/guides/keyboard-shortcuts)。
- 跟随系统、浅色或深色主题。
- 英语、简体中文、繁体中文、日语、韩语、西班牙语、德语、法语和巴西葡萄牙语。
