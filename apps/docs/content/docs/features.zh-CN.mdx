## 运行位置 [#where-it-runs]

| 界面 | 说明 |
| --- | --- |
| 弹出窗口 | 工具栏按钮：搜索、文件夹树、保存书签和 AI 文件夹推荐 |
| 侧边栏 | 在浏览器侧边栏（Firefox 中为侧栏）中显示的相同视图，浏览网页时可保持打开 |
| 书签管理器 | 在 Chrome 和 Edge 中替换浏览器的书签页面：包含文件夹树、路径导航、书签表格和**工具**侧栏。窗口较窄时，文件夹树和**工具**会覆盖在表格上方打开；较深的文件夹路径会将中间的文件夹收进 **…** 菜单 |
| 设置 | 扩展程序的设置页面：最先显示**常用设置**，另外十一个标签页位于**高级设置**下。请参阅[设置](/settings) |
| 任意网页 | <Shortcut id="commands.quick-save" /> 和 <Shortcut id="commands.ai-quick-save" /> 可快速保存当前网页，并在页面中显示通知 |
| 右键菜单 | 开启**右键菜单**后，可在任意链接上使用**将书签保存到…** |

## 查找 [#find]

- 输入时即时搜索标题和网址，**更多搜索选项**下提供区分大小写、全字匹配和模式搜索（正则表达式）选项，并高亮显示匹配内容。包含匹配项的文件夹会自动展开。
- 本设备上的最近搜索记录，可以清除或关闭。
- 书签管理器中的表格筛选器，可按标题、网址、类型、文件夹、域名和添加日期筛选，并可按任意列排序。
- 已保存的搜索：命名的筛选条件组合，每次打开时都会针对你的书签重新计算。最多 50 个，保存在本设备上。

指南：[搜索和已保存的搜索](/guides/search)。

## 保存和整理 [#save-and-organize]

- 将当前网页保存到任意文件夹，同一文件夹中不会重复保存，并提供列出你用过的文件夹的**最近**面板。
- 输入文件夹名称的一部分，或 `work/react` 这样的路径，然后保存到结果上方列出的某个匹配文件夹。
- 在任意网页上按 <Shortcut id="commands.quick-save" /> 快速保存，保存位置可以是与网页最匹配的文件夹（在你的设备上排序）、上次使用的文件夹或你指定的文件夹；<Shortcut id="commands.ai-quick-save" /> 会保存到 AI 建议的第一个文件夹。页面中的通知提供**撤消**，并可在**移动到**下选择其他文件夹。在 Chrome 和 Edge 中，可以将 <Shortcut id="browser.bookmark_page" /> 设为快速保存快捷键。
- 通过右键菜单将链接保存到最近使用的文件夹或书签栏。
- 在书签管理器中创建文件夹、拖放书签和文件夹，以及一次移动多项。
- 按浏览器自身的顺序（默认）、添加日期、自然字母顺序或文件夹优先显示书签，不会改变浏览器中存储的顺序。
- 修改名称和网址，并在**书签详情**中添加标签和摘要。
- 删除时可选择是否确认，并可在 10 秒内撤消，撤消会恢复文件夹中的全部内容。
- 在书签管理器中，可以拖动或使用方向键调整表格列宽；**重置视图**可恢复默认布局。
- 书签管理器的地址会标明当前文件夹或搜索（`?id=`、`?q=`），因此**返回**、**前进**和已加入书签的链接都能正常使用，Chrome 自带的文件夹链接也能打开，**复制此文件夹的链接**可复制这样的链接。
- 当 Chrome 同时将书签保存在你的 Google 账号中和仅保存在本设备上时，书签管理器的文件夹树会像 Chrome 一样分两个部分显示它们。
- **链接打开位置**用于选择点击的链接在新标签页、后台标签页还是当前标签页中打开。

指南：[保存和整理](/guides/save-and-organize)。

## 清理 [#clean-up]

- **重复书签清理**：使用可配置的匹配方式查找重复书签，经你确认后移除多余的副本，并支持撤消。
- **网址清理**：在预览后去除 `utm_source` 等跟踪参数。
- **智能规则**：以搜索形式编写的规则（例如 `domain:github.com`），在审阅后添加标签并把书签移动到文件夹，可撤消。参见[用智能规则添加标签和移动](/guides/clean-up#tag-and-move-with-smart-rules)。
- **检查失效链接**：将确认失效的链接与需要手动检查的链接区分开，并可通过删除、跟随重定向、使用 Wayback Machine 链接或修改网址来修复，支持撤消。它在后台运行，关闭管理器后仍会继续，可在**后台任务**中暂停、继续或取消。
- **元数据获取**：根据在线网页建议标题（仅读取网页的 head 部分），并应用你选中的建议。描述仅供查看，永远不会保存。它与**检查失效链接**一样在后台运行。
- **刷新网站图标**：经你确认后下载每个网站自己的图标，这样即使浏览器没有缓存图标，书签也能显示图标，在 Firefox 中同样如此。图标保存在本设备上，可以清除。它与**检查失效链接**一样在后台运行。
- **索引网页正文**（开启前默认关闭）：审阅后在此设备上保存所选网页的可读正文，让搜索也能找到网页中的词语，并支持 `content:` 和 `has:content`。参见[在网页中搜索](/guides/clean-up#search-inside-pages)。
- **获取封面**（开启前默认关闭）：审阅后在此设备上保存每个网页为自己指定的预览图的小副本，并在书签管理器的**卡片**中显示。参见[在卡片上显示封面](/guides/clean-up#show-covers-on-cards)。
- **隐私扫描**：标记包含令牌、敏感参数、电子邮件地址或 UUID 的网址，也可选择同时扫描标题。
- **书签统计**：针对某个文件夹或全部书签，统计热门域名和文件夹、协议、重复项以及文件夹的嵌套深度。

指南：[清理重复书签和跟踪网址](/guides/clean-up)以及[查找并修复失效链接](/guides/dead-links)。

## 导入和导出 [#import-and-export]

- 导出为 HTML、JSON、Markdown 或 CSV，导出前会进行隐私检查，可对文件中的敏感值进行脱敏。
- 预览目标文件夹、数量和重复项后导入 HTML 或 JSON，并支持撤消。
- JSON 导出文件会保留每个书签的标签和摘要，导入这样的文件时会恢复它们。
- 将扩展程序的设置、自定义提示词、AI 服务（不含 API 密钥）、已保存的搜索和书签管理器表格的列备份为 JSON 文件，并可恢复。

指南：[导入和导出](/guides/import-export)。

## AI 工具（可选） [#ai-tools-optional]

默认关闭。可使用你自己的密钥接入 OpenAI、Anthropic、Google、Groq、Mistral AI、DeepSeek、xAI、Azure OpenAI、OpenRouter，或 models.dev 目录中的约 200 个其他服务商，也可以使用 Ollama、CLIProxyAPI 或任何兼容 OpenAI 的端点。在 Chrome 中，**内置 AI** 会使用 Chrome 自己的模型免费推荐文件夹，在你的电脑上运行，无需密钥。

- 弹出窗口中的文件夹推荐，包括需经你确认的新文件夹路径，以及 <Shortcut id="commands.ai-quick-save" /> 快速保存快捷键。
- 弹出窗口和侧边栏中的**询问 AI**：通过搜索书签、文件夹、标签和摘要、查找重复项以及检查链接来回答问题；可以保存网页，并以方案的形式提议移动、重命名、删除和新建文件夹，在你批准之前不做任何更改，每项更改都可撤消；回答末尾还会附上下一步操作的按钮。设置中的**询问 AI 可以执行的操作**可关闭任何查询或更改。
- 针对当前文件夹的**自动标签**和**内容摘要**，仅在你审阅后才会保存，并支持撤消。
- **AI 文件夹重组**，在移动任何内容之前先进行预览，并支持撤消。
- **AI 上下文打包**，将书签导出为 Markdown 或 XML 以供 AI 对话使用，在 AI 关闭时也能使用。
- **AI 输出语言**用于选择标签、摘要和新文件夹名称的语言；**关于我**让每项 AI 功能对你有一些了解；提示词库则可以改写每个工具的提示词，并提供 `{{today}}` 和 `{{existingTags}}` 等占位符的列表。

标签和摘要保存在本设备上。它们不会同步，但[搜索](/guides/search#search-words-and-operators)能按它们找到书签，“询问 AI”可以查询它们，JSON 书签导出文件也会包含它们。指南：[设置 AI 工具](/guides/ai-tools)。

## 本地 AI 智能体（可选） [#local-ai-agents-optional]

默认关闭，需在每台设备上分别开启。开启**允许本地 AI 智能体**后，你电脑上的 AI 智能体（如 Claude Code、Codex 或 Cursor）可以通过 `bookmark-scout-mcp` 程序使用 Bookmark Scout 的查询功能。该程序是一个 MCP 服务器，通过浏览器的原生消息传递与扩展程序通信。同时开启**允许更改**后，它们还可以保存网页并提议更改，每项更改都要在 Bookmark Scout 窗口中等你批准，并可在书签管理器中撤消。默认情况下，标题和网址中的隐私值不会提供给它们。

指南：[配合本地 AI 智能体使用](/guides/local-agents)。

## 键盘和语言 [#keyboard-and-language]

- 可在任意网页上使用的快速保存快捷键，可在浏览器的快捷键设置中更改；在 Firefox 中可直接在 Bookmark Scout 的设置中更改。
- 弹出窗口和侧边栏中的快捷键均不使用 `Ctrl` 或 `Cmd`；书签管理器使用 Chrome 书签管理器的按键（全选、撤消、重做、在标签页中打开），并可按 <Shortcut id="manager.show_help" /> 打开帮助对话框。请参阅[键盘快捷键](/guides/keyboard-shortcuts)。
- 书签管理器中的选择方式与 Chrome 一致：点击、`Cmd`+点击（Windows 和 Linux 上为 `Ctrl`+点击）、`Shift`+点击和 <Shortcut id="manager.select_all" />；方向键可在表格和文件夹树中移动，屏幕阅读器会将文件夹树识别为树结构。
- 用 <Shortcut id="manager.undo" /> 和 <Shortcut id="manager.redo" /> 撤消和重做书签管理器中的修改、移动和删除，在整个浏览器会话中有效。
- 书签管理器的行和文件夹上的右键菜单：剪切、复制和粘贴，在标签页、新窗口或无痕式窗口中全部打开，重命名和删除；另有**按名称排序**以及**添加新书签**或**添加新文件夹**。设置中的**书签管理器菜单**可选择菜单显示哪些命令及其顺序。
- 书签管理器中的拖放方式与 Chrome 一致：可拖到表格或文件夹树中的文件夹上，按浏览器顺序拖到行之间，也可以从其他网页拖入链接；<Shortcut id="manager.copy" />、<Shortcut id="manager.cut" /> 和 <Shortcut id="manager.paste" /> 用于复制、移动和粘贴。
- 跟随系统、浅色或深色主题。
