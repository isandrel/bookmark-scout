---
title: 第一次儲存
description: 將 Bookmark Scout 加到 Chrome 並固定圖示，然後輸入資料夾名稱的一部分，把第一個網頁儲存到正確的資料夾。之後只要按一個鍵就能儲存。
---

這大約只需要一分鐘。你需要一台電腦上的 Chrome，以及至少一個書籤資料夾。

<Steps>
<Step>
### 將 Bookmark Scout 加到 Chrome [#add-bookmark-scout-to-chrome]

<StoreListing browser="chrome" />

在商店資訊頁面上按一下「**加到 Chrome**」，然後按一下「**新增擴充功能**」。Chrome 只會要求一項權限：讀取和變更你的書籤。接著，新分頁中會開啟一個標題為「**Bookmark Scout 已準備就緒**」的頁面，簡要列出下方的步驟；頁面上會顯示快速儲存快捷鍵實際取得的按鍵。使用 Firefox 或 Edge 嗎？請參閱「[安裝](/installation#firefox-and-edge)」。
</Step>
<Step>
### 固定圖示 [#pin-the-icon]

按一下 Chrome 工具列右側拼圖形狀的「**擴充功能**」按鈕，然後按一下 Bookmark Scout 旁的圖釘。它的圖示就會一直留在工具列上，按一下就能開啟。
</Step>
<Step>
### 儲存目前所在的網頁 [#save-the-page-you-are-on]

開啟任何想保留的網頁，然後按一下 Bookmark Scout 圖示。搜尋框下方的那一行「**要儲存的頁面**」會顯示網頁標題。

輸入資料夾名稱的一部分，例如輸入 `pas` 來找名為 Pasta 的資料夾。相符的資料夾會出現在「**儲存到資料夾**」下方，最相符的排在最前面。第一個資料夾會醒目顯示：按 `Enter` 即可儲存到那裡，也可以直接點選任一資料夾。看到「**已新增書籤**」就表示已儲存。
</Step>
<Step>
### 下次只要按一個鍵 [#next-time-press-one-key]

在任何網頁上按 <Shortcut id="commands.quick-save" />。Bookmark Scout 會將網頁儲存到最適合的資料夾，不會開啟任何視窗。網頁角落會出現一則小訊息，說明儲存的位置。按一下其中的「**復原**」即可取消這次儲存，或在「**移動到**」下方選擇其他資料夾。
</Step>
</Steps>

<Screenshot name="popup" />

## 如果情況不一樣 [#if-something-is-different]

- **沒有列出你要的資料夾。** 改輸入名稱的其他部分，或加上它所在資料夾名稱的幾個字，例如 `recipes pas`。打錯一個小字也沒關係。
- **按鍵沒有反應。** 可能有其他擴充功能已經使用這個按鍵。按一下 Bookmark Scout 圖示：「**未設定快速儲存快捷鍵**」那一行有「**前往設定**」。請參閱「[用鍵盤快捷鍵儲存](/guides/save-and-organize#quick-save)」。
- **這個網頁已經儲存過了。** Bookmark Scout 不會重複儲存；訊息會告訴你它在哪裡。
