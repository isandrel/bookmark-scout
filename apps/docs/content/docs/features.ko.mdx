## 실행되는 곳 [#where-it-runs]

| 화면 | 설명 |
| --- | --- |
| 팝업 | 툴바 버튼: 검색, 폴더 트리, 저장, AI 폴더 추천 |
| 사이드 패널 | 같은 화면을 브라우저의 사이드 패널(Firefox에서는 사이드바)에 표시하며, 웹을 탐색하는 동안 계속 열려 있음 |
| 북마크 관리자 | Chrome과 Edge에서 브라우저의 북마크 페이지를 대체: 폴더 트리, 이동 경로, 북마크 표, **도구** 사이드바. 좁은 창에서는 폴더 트리와 **도구**가 표 위에 열리며, 깊은 폴더 경로는 중간 폴더를 **…** 메뉴로 접음 |
| 설정 | 확장 프로그램의 설정 페이지. 맨 앞에 **기본 설정**이 있고, **고급 설정** 아래에 탭 11개가 더 있음. [설정](/settings) 참고 |
| 모든 페이지 | <Shortcut id="commands.quick-save" />와 <Shortcut id="commands.ai-quick-save" />로 보고 있는 페이지를 빠른 저장하며, 페이지 안에 알림이 표시됨 |
| 마우스 오른쪽 버튼 메뉴 | **마우스 오른쪽 버튼 메뉴**를 켜면 모든 링크에서 **북마크 저장 위치...** 사용 가능 |

## 찾기 [#find]

- 입력하는 즉시 제목과 URL을 검색하며, **검색 옵션 더 보기**에서 대소문자 구분, 전체 단어 일치, 패턴 검색(정규식) 옵션을 지원하고 일치하는 부분을 강조 표시합니다. 일치하는 폴더는 자동으로 펼쳐집니다.
- 이 기기의 최근 검색 기록을 지우거나 끌 수 있습니다.
- 관리자의 표 필터로 제목, URL, 유형, 폴더, 도메인, 추가한 날짜를 걸러 내고, 어느 열로든 정렬할 수 있습니다.
- 저장된 검색: 이름을 붙인 필터 모음으로, 열 때마다 북마크에 다시 적용됩니다. 최대 50개까지 이 기기에 저장됩니다.

가이드: [검색과 저장된 검색](/guides/search).

## 저장과 정리 [#save-and-organize]

- 현재 페이지를 원하는 폴더에 저장하며, 같은 폴더에 두 번 저장하지 않습니다. **최근** 패널에 최근 사용한 폴더가 표시됩니다.
- 폴더 이름의 일부나 `work/react` 같은 경로를 입력하고, 결과 위에 나열된 일치하는 폴더 중 하나에 저장합니다.
- 어느 페이지에서나 <Shortcut id="commands.quick-save" />로 빠른 저장하면 페이지에 가장 잘 맞는 폴더(기기 안에서 순위 계산), 마지막으로 사용한 폴더, 또는 직접 고른 폴더에 저장됩니다. <Shortcut id="commands.ai-quick-save" />는 첫 번째 AI 추천 폴더에 저장합니다. 페이지 안의 알림에서 **실행 취소**와 **이동** 아래의 다른 폴더를 고를 수 있습니다. Chrome과 Edge에서는 빠른 저장에 <Shortcut id="browser.bookmark_page" />를 지정할 수 있습니다.
- 마우스 오른쪽 버튼 메뉴로 링크를 최근 폴더나 북마크바에 저장합니다.
- 관리자에서 폴더를 만들고, 북마크와 폴더를 드래그 앤 드롭하고, 여러 항목을 한 번에 옮깁니다.
- 브라우저에 저장된 순서를 바꾸지 않고 북마크를 브라우저 자체의 순서(기본값), 추가한 날짜순, 자연스러운 알파벳순, 폴더 우선으로 표시합니다.
- 이름과 URL을 편집하고, **북마크 세부정보**에서 태그와 요약을 추가합니다.
- 선택적인 확인 단계와 10초 동안의 실행 취소로 삭제하며, 실행 취소하면 폴더 안의 모든 항목이 복원됩니다.
- 관리자에서 표의 열 너비를 끌거나 화살표 키로 조절하며, **보기 초기화**로 레이아웃을 되돌립니다.
- 관리자의 주소에 폴더나 검색이 표시되므로(`?id=`, `?q=`) **뒤로**, **앞으로**, 북마크한 링크가 동작하고, Chrome 자체의 폴더 링크도 열리며, **이 폴더 링크 복사**로 링크를 복사할 수 있습니다.
- Chrome이 북마크를 Google 계정과 이 기기에만 나누어 보관하는 경우, 관리자의 폴더 트리도 Chrome처럼 두 섹션으로 나누어 표시합니다.
- **링크 열기 위치**에서 클릭한 링크를 새 탭, 백그라운드 탭, 현재 탭 중 어디에서 열지 고릅니다. 각 링크 뒤의 작은 아이콘으로 어느 쪽인지 알 수 있습니다(**링크 열기 위치 표시**).

가이드: [저장과 정리](/guides/save-and-organize).

## 정돈 [#clean-up]

- **중복 정리**: 일치 기준을 설정해 중복을 찾고, 검토한 뒤 남는 사본을 제거하며 실행 취소할 수 있습니다.
- **URL 정리**: `utm_source` 같은 추적 매개변수를 미리 본 뒤 제거합니다.
- **스마트 규칙**: `domain:github.com` 같은 검색으로 작성하는 규칙으로, 검토 후 태그를 추가하고 북마크를 폴더로 옮기며 실행 취소할 수 있습니다. [스마트 규칙으로 태그 추가와 이동](/guides/clean-up#tag-and-move-with-smart-rules)을 참고하세요.
- **깨진 링크 확인**: 깨진 것으로 확인된 링크와 직접 확인이 필요한 링크를 구분하고, 삭제, 리디렉션 따라가기, Wayback Machine 링크 사용, URL 편집으로 복구하며 실행 취소할 수 있습니다. 백그라운드에서 실행되므로 관리자를 닫아도 계속되며, **백그라운드 작업**에서 일시 중지, 다시 시작, 취소할 수 있습니다.
- **메타데이터 가져오기**: 실제 페이지에서 페이지의 head만 읽어 제목을 제안하고, 선택한 제목만 적용합니다. 설명은 검토용으로만 표시되며 저장되지 않습니다. **깨진 링크 확인**처럼 백그라운드에서 실행됩니다.
- **사이트 아이콘 새로 고침**: 검토한 뒤 각 웹사이트의 아이콘을 내려받아, 브라우저에 캐시된 아이콘이 없을 때와 Firefox에서도 북마크에 표시합니다. 아이콘은 이 기기에 저장되며 지울 수 있습니다. **깨진 링크 확인**처럼 백그라운드에서 실행됩니다.
- **페이지 본문 색인**(켜기 전에는 꺼짐): 검토 후 고른 페이지의 읽을 수 있는 본문을 이 기기에 보관해 검색이 페이지 안의 단어를 찾게 합니다. `content:`와 `has:content`도 쓸 수 있습니다. [페이지 안에서 검색](/guides/clean-up#search-inside-pages)을 참고하세요.
- **표지 가져오기**(켜기 전에는 꺼짐): 검토 후 각 페이지가 스스로 지정한 미리 보기 이미지의 작은 복사본을 이 기기에 보관하고, 관리자의 **카드**에 표시합니다. [카드에 표지 표시](/guides/clean-up#show-covers-on-cards)를 참고하세요.
- **개인정보 스캐너**: 토큰, 민감한 매개변수, 이메일 주소, UUID가 포함된 URL과, 선택하면 제목도 찾아 표시합니다.
- **북마크 통계**: 한 폴더 또는 전체 북마크에 대해 상위 도메인과 폴더, 프로토콜, 중복, 폴더 깊이를 보여 줍니다.

가이드: [중복과 추적 URL 정리](/guides/clean-up), [깨진 링크 찾기와 복구](/guides/dead-links).

## 가져오기와 내보내기 [#import-and-export]

- HTML, JSON, Markdown, CSV로 내보내며, 개인정보 검토 단계에서 파일의 민감한 값을 가릴 수 있습니다.
- 대상 폴더, 개수, 중복을 미리 본 뒤 HTML이나 JSON을 가져오며, 실행 취소할 수 있습니다.
- JSON 내보내기에는 각 북마크의 태그와 요약이 유지되며, 그런 파일을 가져오면 태그와 요약이 복원됩니다.
- 확장 프로그램 설정, 사용자 지정 프롬프트, AI 서비스(API 키 제외), 저장된 검색, 관리자 표의 열을 JSON 파일로 백업하고 복원합니다.

가이드: [가져오기와 내보내기](/guides/import-export).

## AI 도구(선택 사항) [#ai-tools-optional]

기본적으로 꺼져 있습니다. OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, xAI, Azure OpenAI, OpenRouter, 또는 models.dev 카탈로그의 약 200개 제공업체에 내 API 키를 사용하거나, Ollama, CLIProxyAPI, 기타 OpenAI 호환 엔드포인트를 사용할 수 있습니다. Chrome에서는 **내장 AI**가 Chrome 자체 모델로 내 컴퓨터에서 키 없이 무료로 폴더를 추천합니다.

- 팝업의 폴더 추천(검토를 거쳐 새 폴더 경로도 만들 수 있음)과 <Shortcut id="commands.ai-quick-save" /> 빠른 저장 단축키.
- 팝업과 사이드 패널의 **AI에게 묻기**: 북마크, 폴더, 태그, 요약을 검색하고, 중복을 찾고, 링크를 확인해 질문에 답합니다. 페이지를 저장하고 이동, 이름 변경, 삭제, 새 폴더를 계획으로 제안하며, 이 계획은 승인하기 전까지 아무것도 바꾸지 않고 각 변경은 실행 취소할 수 있습니다. 답변 끝에는 다음에 할 일을 버튼으로 보여 줍니다. 설정의 **AI에게 묻기가 할 수 있는 일**에서 어떤 조회나 변경이든 끌 수 있습니다.
- 현재 폴더에 대한 **자동 태그 지정**과 **콘텐츠 요약**. 검토한 뒤에만 저장되며 실행 취소할 수 있습니다.
- **AI 폴더 재구성**. 무엇이든 옮기기 전에 미리 보여 주며 실행 취소할 수 있습니다.
- **AI 컨텍스트 패커**. 북마크를 AI 채팅용 Markdown이나 XML로 내보내며, AI가 꺼져 있어도 동작합니다.
- **AI 출력 언어**로 태그, 요약, 새 폴더 이름의 언어를 고르고, **내 소개**로 모든 AI 기능에 나에 대해 조금 알려 주며, 프롬프트 라이브러리에서 각 도구의 프롬프트를 다시 쓸 수 있습니다. 편집기에는 `{{today}}`, `{{existingTags}}` 같은 자리 표시자 목록이 있습니다.

태그와 요약은 이 기기에만 저장됩니다. 동기화되지는 않지만 [검색](/guides/search#search-words-and-operators)으로 이를 기준으로 북마크를 찾을 수 있고, AI에게 묻기는 이를 조회할 수 있으며 JSON 북마크 내보내기에도 포함됩니다. 가이드: [AI 도구 설정](/guides/ai-tools).

## 로컬 AI 에이전트(선택 사항) [#local-ai-agents-optional]

기기마다 기본적으로 꺼져 있습니다. **로컬 AI 에이전트 허용**을 켜면 Claude Code, Codex, Cursor 같은 이 컴퓨터의 AI 에이전트가 `bookmark-scout-mcp` 프로그램을 통해 Bookmark Scout의 조회 기능을 사용합니다. 이 프로그램은 브라우저의 네이티브 메시징으로 확장 프로그램에 연결되는 MCP 서버입니다. **변경 허용**도 켜면 에이전트가 페이지를 저장하고 변경을 제안할 수 있으며, 각 변경은 Bookmark Scout 창에서 승인을 기다리고 관리자에서 실행 취소할 수 있습니다. 제목과 URL에 있는 민감한 값은 기본적으로 에이전트에게 가려집니다.

가이드: [로컬 AI 에이전트와 함께 사용](/guides/local-agents).

## 키보드와 언어 [#keyboard-and-language]

- 어느 페이지에서나 쓸 수 있는 빠른 저장 단축키. 브라우저의 단축키 설정에서 바꿀 수 있으며, Firefox에서는 Bookmark Scout 설정에서 바로 바꿀 수 있습니다.
- 팝업과 사이드 패널의 단축키는 `Ctrl`이나 `Cmd`를 사용하지 않으며, 관리자에서는 Chrome 북마크 관리자의 키(모두 선택, 실행 취소, 다시 실행, 탭에서 열기)를 쓰고 <Shortcut id="manager.show_help" />로 도움말 대화상자를 엽니다. [키보드 단축키](/guides/keyboard-shortcuts)를 참고하세요.
- 관리자에서 Chrome처럼 선택: 클릭, `Cmd`+클릭(Windows와 Linux에서는 `Ctrl`+클릭), `Shift`+클릭, <Shortcut id="manager.select_all" />. 화살표 키로 표와 폴더 트리를 이동하며, 화면 낭독기는 폴더 트리를 트리로 읽습니다.
- 관리자에서 한 편집, 이동, 삭제를 <Shortcut id="manager.undo" />와 <Shortcut id="manager.redo" />로 실행 취소하고 다시 실행하며, 브라우저 세션 내내 유지됩니다.
- 관리자의 행과 폴더에 있는 마우스 오른쪽 버튼 메뉴: 잘라내기, 복사, 붙여넣기, 모두 탭/새 창/시크릿 창에서 열기, 이름 바꾸기, 삭제, 그리고 **이름순 정렬**과 **새 북마크 추가** 또는 **새 폴더 추가**. 설정의 **북마크 관리자 메뉴**에서 표시할 명령과 순서를 고릅니다.
- 관리자에서 Chrome처럼 드래그 앤 드롭: 표나 트리의 폴더 위로, 브라우저 순서에 따라 행 사이로, 다른 페이지의 링크를 안으로 끌어올 수 있습니다. <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" />, <Shortcut id="manager.paste" />로 복사, 이동, 붙여넣기를 합니다.
- 시스템, 라이트, 다크 테마.
- <Languages of="extension" />.
