## Where it runs

| Surface | What it is |
| --- | --- |
| Popup | The toolbar button: search, the folder tree, saving, and AI folder recommendations |
| Side panel | The same view in the browser's side panel (the sidebar in Firefox), which stays open while you browse |
| Bookmarks manager | Replaces the browser's bookmarks page in Chrome and Edge: folder tree, breadcrumbs, a bookmark table, and the **Tools** sidebar. In a narrow window the folder tree and **Tools** open over the table; a deep folder path folds its middle folders into a **…** menu |
| Settings | The extension's settings page: **Essentials** first, then eleven more tabs under **Advanced**. See [Settings](/settings) |
| Any page | <Shortcut id="commands.quick-save" /> and <Shortcut id="commands.ai-quick-save" /> quick save the page you are on, with a notification in the page |
| Right-click menu | **Save bookmark to...** on any link, once you turn on **Right-Click Menu** |

## Find

- Search titles and URLs as you type, with match case, whole word, and pattern search (regular expression) options under **More search options**, and highlighted matches. Matching folders open automatically.
- Recent searches on this device, which you can clear or turn off.
- Table filters in the manager for title, URL, type, folder, domain, and date added, with sorting by any column.
- Saved searches: named filter sets that are evaluated against your bookmarks each time you open them. Up to 50, kept on this device.

Guide: [Search and saved searches](/guides/search).

## Save and organize

- Save the current page into any folder, never twice into the same folder, with a **Recent** panel of folders you used.
- Type part of a folder's name, or a path such as `work/react`, and save to one of the matching folders listed above the results.
- Quick save with <Shortcut id="commands.quick-save" /> on any page, to the folder that matches the page best (ranked on your device), the last used folder, or a folder you choose; <Shortcut id="commands.ai-quick-save" /> saves to the first AI suggestion. A notification in the page offers **Undo** and other folders under **Move to**. In Chrome and Edge you can give quick save <Shortcut id="browser.bookmark_page" />.
- Save links from the right-click menu into a recent folder or the Bookmarks Bar.
- Create folders, drag and drop bookmarks and folders, and move several at once in the manager.
- Show bookmarks in the browser's own order (the default), by date added, in natural alphabetical order, or folders first, without changing the browser's stored order.
- Edit names and URLs, and add tags and a summary in **Bookmark Details**.
- Delete with an optional confirmation and a 10-second undo that restores everything inside a folder.
- In the manager, resize table columns by dragging or with the arrow keys; **Reset view** restores the layout.
- The manager's address names the folder or search (`?id=`, `?q=`), so **Back**, **Forward**, and bookmarked links work, Chrome's own folder links open, and **Copy link to this folder** copies one.
- When Chrome keeps bookmarks both in your Google Account and only on this device, the manager's folder tree shows them in two sections, as Chrome's does.
- **Open links in** chooses whether clicked links open in a new tab, a background tab, or the current tab.

Guide: [Save and organize](/guides/save-and-organize).

## Clean up

- **Duplicate Cleaner**: finds duplicates with configurable matching, and removes the extra copies after a review, with undo.
- **URL Cleaner**: strips tracking parameters such as `utm_source` after a preview.
- **Smart Rules**: rules you write as searches, such as `domain:github.com`, that add tags and move bookmarks to a folder after a review, with undo. See [Tag and move with Smart Rules](/guides/clean-up#tag-and-move-with-smart-rules).
- **Check Dead Links**: separates confirmed dead links from ones that need a manual check, and repairs them by deleting, following a redirect, using a Wayback Machine link, or editing the URL, with undo. It runs in the background, so it keeps going after you close the manager, and can be paused, resumed, or cancelled under **Background tasks**.
- **Metadata Fetcher**: suggests titles from the live pages, reading only the page head, and applies the ones you select. Descriptions are shown for review and never saved. It runs in the background, like **Check Dead Links**.
- **Refresh Site Icons**: downloads each website's own icon, after a review, so bookmarks show it even when the browser has none cached, and in Firefox. Icons stay on this device and can be cleared. It runs in the background, like **Check Dead Links**.
- **Index Page Text** (off until you turn it on): keeps the readable text of the pages you choose on this device, after a review, so search finds words inside them, with `content:` and `has:content`. See [Search inside pages](/guides/clean-up#search-inside-pages).
- **Fetch Covers** (off until you turn it on): keeps a small copy of the preview image each page names for itself on this device, after a review, and the manager's **Cards** show it. See [Show covers on cards](/guides/clean-up#show-covers-on-cards).
- **Privacy Scanner**: flags URLs, and optionally titles, that contain tokens, sensitive parameters, email addresses, or UUIDs.
- **Bookmark Statistics**: top domains and folders, protocols, duplicates, and how deep your folders go, for a folder or all bookmarks.

Guides: [Clean up duplicates and tracking URLs](/guides/clean-up) and [Find and repair dead links](/guides/dead-links).

## Import and export

- Export to HTML, JSON, Markdown, or CSV, with a privacy review that can redact sensitive values from the file.
- Import HTML or JSON after a preview of the target folder, counts, and duplicates, with undo.
- JSON exports keep each bookmark's tags and summary, and importing such a file restores them.
- Back up the extension's settings, custom prompts, AI services (without API keys), saved searches, and the manager table's columns to a JSON file, and restore them.

Guide: [Import and export](/guides/import-export).

## AI tools (optional)

Off by default. Bring your own key for OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, xAI, Azure OpenAI, OpenRouter, or about 200 more providers from the models.dev catalog, or use Ollama, CLIProxyAPI, or any OpenAI-compatible endpoint. In Chrome, **Built-in AI** suggests folders for free with Chrome's own model, on your computer and without a key.

- Folder recommendations in the popup, including a reviewed new folder path, and the <Shortcut id="commands.ai-quick-save" /> quick save shortcut.
- **Ask AI** in the popup and side panel: answers questions by searching your bookmarks, folders, tags, and summaries, finding duplicates, and checking links; saves pages and proposes moves, renames, deletions, and new folders as a plan that changes nothing until you approve it, each change undoable; and ends answers with buttons for what to do next. **What Ask AI may do** in Settings turns off any lookup or change.
- **Auto-Tagging** and **Content Summarizer** for the current folder, saved only after you review them, with undo.
- **AI Folder Reorganization**, previewed before anything moves, with undo.
- **AI Context Packer**, which exports bookmarks as Markdown or XML for an AI chat and works with AI turned off.
- **AI output language** chooses the language of tags, summaries, and new folder names; **About me** tells every AI feature a little about you; and the prompt library lets you rewrite each tool's prompt, with a list of placeholders such as `{{today}}` and `{{existingTags}}`.

Tags and summaries stay on this device. They are not synced, but [search](/guides/search#search-words-and-operators) finds bookmarks by them, Ask AI can look them up, and JSON bookmark exports include them. Guide: [Set up AI tools](/guides/ai-tools).

## Local AI agents (optional)

Off by default, on each device. With **Allow local AI agents** on, AI agents on your computer, such as Claude Code, Codex, or Cursor, use Bookmark Scout's lookups through the `bookmark-scout-mcp` program, an MCP server that reaches the extension through the browser's native messaging. With **Allow changes** also on, they can save pages and propose changes, each of which waits for your approval in a Bookmark Scout window and can be undone in the manager. Private values in titles and URLs are hidden from them by default.

Guide: [Use with local AI agents](/guides/local-agents).

## Keyboard and language

- Quick save shortcuts on any page, which you can change in the browser's shortcut settings, or in Firefox right in Bookmark Scout's Settings.
- Shortcuts in the popup and side panel that never use `Ctrl` or `Cmd`, and in the manager the keys of Chrome's bookmark manager (select all, undo, redo, open in tabs), with a <Shortcut id="manager.show_help" /> help dialog there. See [Keyboard shortcuts](/guides/keyboard-shortcuts).
- Selection in the manager like Chrome's: click, `Cmd`+click (`Ctrl`+click on Windows and Linux), `Shift`+click, and <Shortcut id="manager.select_all" />; the arrow keys move through the table and the folder tree, which screen readers hear as a tree.
- Undo and redo of the manager's edits, moves, and deletions with <Shortcut id="manager.undo" /> and <Shortcut id="manager.redo" />, for the whole browser session.
- Right-click menus on the manager's rows and folders: cut, copy, and paste, open all in tabs, a new window, or an incognito window, rename, and delete; plus **Sort by name** and **Add new bookmark** or **folder**. **Bookmark manager menus** in Settings chooses which commands they show, and in what order.
- Drag and drop in the manager like Chrome's: onto folders in the table or tree, between rows in browser order, and links in from other pages; <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" />, and <Shortcut id="manager.paste" /> copy, move, and paste.
- System, light, or dark theme.
