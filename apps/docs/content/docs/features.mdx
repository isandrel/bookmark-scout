## Where it runs

| Surface | What it is |
| --- | --- |
| Popup | The toolbar button: search, the folder tree, saving, and AI folder recommendations |
| Side panel | The same view in the Chrome or Edge side panel, which stays open while you browse |
| Bookmarks manager | Replaces the browser's bookmarks page in Chrome and Edge: folder tree, breadcrumbs, a bookmark table, and the **Tools** sidebar |
| Settings | The extension's options page, with eleven tabs. See [Settings](/settings) |
| Right-click menu | **Save bookmark to...** on any link |

## Find

- Search titles and URLs as you type, with match case, whole word, and regular expression options, and highlighted matches. Matching folders open automatically.
- Recent searches on this device, which you can clear or turn off.
- Table filters in the manager for title, URL, type, folder, domain, and date added, with sorting by any column.
- Saved searches: named filter sets that are evaluated against your bookmarks each time you open them. Up to 50, kept on this device.

Guide: [Search and saved searches](/guides/search).

## Save and organize

- Save the current page into any folder, never twice into the same folder, with a **Recent** panel of folders you used.
- Save links from the right-click menu into a recent folder or the Bookmarks Bar.
- Create folders, drag and drop bookmarks and folders, and move several at once in the manager.
- Sort by date added, natural alphabetical order, or folders first, without changing the browser's stored order.
- Edit names and URLs, and add tags and a summary in **Bookmark Details**.
- Delete with an optional confirmation and a 10-second undo that restores everything inside a folder.
- In the manager, resize table columns by dragging or with the arrow keys; **Reset view** restores the layout.

Guide: [Save and organize](/guides/save-and-organize).

## Clean up

- **Duplicate Cleaner**: finds duplicates with configurable matching, and removes the extra copies after a review, with undo.
- **URL Cleaner**: strips tracking parameters such as `utm_source` after a preview.
- **Check Dead Links**: separates confirmed dead links from ones that need a manual check, and repairs them by deleting, following a redirect, using a Wayback Machine link, or editing the URL, with undo.
- **Metadata Fetcher**: suggests titles from the live pages, reading only the page head, and applies the ones you select. Descriptions are shown for review and never saved.
- **Refresh Site Icons**: downloads each website's own icon, after a review, so bookmarks show it even when the browser has none cached, and in Firefox. Icons stay on this device and can be cleared.
- **Privacy Scanner**: flags URLs, and optionally titles, that contain tokens, sensitive parameters, email addresses, or UUIDs.
- **Bookmark Statistics**: top domains and folders, protocols, duplicates, and how deep your folders go, for a folder or all bookmarks.

Guides: [Clean up duplicates and tracking URLs](/guides/clean-up) and [Find and repair dead links](/guides/dead-links).

## Import and export

- Export to HTML, JSON, Markdown, or CSV, with a privacy review that can redact sensitive values from the file.
- Import HTML or JSON after a preview of the target folder, counts, and duplicates, with undo.
- Export and import the extension's settings as a JSON file.

Guide: [Import and export](/guides/import-export).

## AI tools (optional)

Off by default. Bring your own key for OpenAI, Anthropic, Google, Groq, Mistral AI, DeepSeek, xAI, Azure OpenAI, OpenRouter, or about 200 more providers from the models.dev catalog, or use Ollama, CLIProxyAPI, or any OpenAI-compatible endpoint.

- Folder recommendations in the popup, including a reviewed new folder path.
- **Auto-Tagging** and **Content Summarizer** for the current folder, saved only after you review them.
- **AI Folder Reorganization**, previewed before anything moves.
- **AI Context Packer**, which exports bookmarks as Markdown or XML for an AI chat and works with AI turned off.

Tags and summaries stay on this device. They are not synced, searchable, or included in bookmark exports. Guide: [Set up AI tools](/guides/ai-tools).

## Keyboard and language

- Shortcuts in the popup, side panel, and manager that never use `Ctrl` or `Cmd`, with a `?` help dialog in the manager. See [Keyboard shortcuts](/guides/keyboard-shortcuts).
- System, light, or dark theme.
- English, Japanese, and Korean.
