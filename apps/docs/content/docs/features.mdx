# Features

## ✅ Implemented

### 🤖 AI Folder Recommendations
Smart folder suggestions powered by OpenAI, Anthropic, Google AI, Groq, Mistral, DeepSeek, OpenRouter, Ollama, CLIProxyAPI, or a custom OpenAI-compatible provider. AI recommendations analyze the current page title and URL to suggest bookmark folders.

AI features are disabled by default. Enable them in **Settings → AI**, select a provider, and enter an API key when the provider requires one.

API keys, Base URL, and extra headers are stored only in the browser's local extension storage. Keys that do not match the provider's format and Base URLs that are not `http://` or `https://` are rejected and never saved. The configured Base URL and headers apply to every request, including **Verify Service**, which asks the browser for access to that provider's origin when you click it.

### 🧠 AI Tools
Use AI from the bookmarks manager to:

- export selected bookmarks as Markdown or XML context for LLMs
- suggest tags for a folder
- generate bookmark summaries
- plan folder reorganization before applying changes

AI tools can send bookmark titles, URLs, folder paths, and selected bookmark context to the configured provider. Review generated results before applying organization changes.

### 🔍 Instant Search
Quickly find bookmarks with debounced search and folder filtering. Search settings control the result limit, whether matching folders and their parents open automatically, and whether recent searches are remembered on this device. Clearing the search restores the folders you had open before searching.

### 📂 Drag & Drop
Organize bookmarks and folders with intuitive drag-and-drop.

### ⚡ Quick Add
Save the current tab to any folder with one click.

### 📱 Side Panel
Access your bookmarks from Chrome's side panel.

### 🗂️ Full Bookmarks Manager
Bookmark Scout overrides Chrome's default bookmarks page with a custom manager that includes a folder tree, breadcrumb navigation, table-based bookmark browsing, and a right-side tools panel. Each table row's menu can open a link in a new tab, edit a bookmark's title and URL or a folder's name, and delete items with the same confirmation setting and short undo window as the popup. Permanent root folders such as the Bookmarks Bar cannot be edited or deleted.

### ↕️ Configurable Sorting
Choose date added, natural alphabetical, or folders-first ordering in Settings. The selection applies to bookmark tables and nested folder views without changing the browser's stored bookmark order. In the popup and side panel, **Group by Folders** lists subfolders before bookmarks at each level and applies the sort order within each group; turn it off to mix folders and bookmarks in one sorted list.

### ⚙️ Options Page
Configure appearance, language, search behavior, delete confirmations, popup sizing, AI providers, AI models, maintenance tools, metadata tools, privacy scanning, statistics, import/export defaults, and context-menu behavior.

### 🌙 Theme Settings
Use system, light, or dark theme mode from the options page.

### 🔗 Duplicate Cleaner
Scan all bookmarks for duplicates with configurable matching rules and remove extra copies after review.

### 🧹 URL Cleaner
Preview and apply URL cleanup for tracking parameters, duplicate query parameters, sorted query parameters, and preserved parameter allowlists.

### 💀 Dead Link Checker
Scan selected bookmark scopes for unreachable links with configurable timeout, concurrency, retry, redirect, and success-status settings.

### 🧾 Metadata Fetcher
Fetch bookmark metadata such as page titles, favicons, and descriptions for selected scopes.

### 🛡️ Privacy Scanner
Detect sensitive query parameters, URL fragments, emails, and UUIDs in bookmark data.

### 📊 Bookmark Statistics
View domain, folder, protocol, duplicate, depth, and top-item statistics for a folder or all bookmarks.

### 📤 Import/Export
Export bookmarks as HTML, JSON, Markdown, or CSV. Import bookmark files from HTML or JSON.

### 🖱️ Context Menu Save
Save links from the browser right-click menu into recent folders or the default Bookmarks Bar.

### ⚙️ Settings Sync
Extension settings are stored through `chrome.storage.sync`, so preferences can sync through the browser account where supported.

### 🌍 i18n
Multi-language support: English, Japanese, Korean.
