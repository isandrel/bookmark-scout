通过扩展程序的**选项**入口打开设置页面，例如在 Chrome 中右键点击工具栏图标，然后选择**选项**。更改会即时保存。

## 使用设置页面 [#using-the-settings-page]

- 设置页面打开时显示**常用设置**，即大多数人会更改的几项设置。其他标签页都列在**高级设置**下，**常用设置**中的每项设置也在各自的标签页中：在任一处更改，改的都是同一项设置。
- 使用顶部的**搜索设置…**，可在所有标签页中查找设置，并显示匹配的数量。输入的每个词都必须匹配，顺序不限，不区分大小写和重音符号。匹配的词会在所在位置高亮显示，含有匹配项的标签页会高亮显示数量；如果设置是在未显示的文字中匹配的（例如说明或设置 ID），其下方会有一条简短的提示说明在哪里匹配。有些设置也能用它们的其他叫法找到，例如用“夜间模式”找到**主题**。搜索范围、词语匹配方式和显示内容可在[设置搜索](#settings-search)中更改。
- 每个标签页都分成带标题的小节。工具的开关在小节标题旁边，关闭时该工具的其他设置会收起。超时、文件名长度等技术性设置放在**高级设置**里，默认收起，打开它或搜索到其中的设置时才会展开。
- 已更改的设置会标记为**已修改**，并附有将其重置为默认值的按钮。**重置所有快捷键**会重置所有设置。
- **备份设置**会将你选择的内容保存为备份文件：设置、此电脑的设置、已保存的搜索和表格视图、提示词和“关于我”、智能规则、AI 服务（包括**API 地址**和服务商特有的字段）、封面，以及仅在你选择并确认后才包含的 AI 服务密钥（默认用密码保护）。**恢复设置**会显示备份中每项内容会带来哪些更改，让你选择内容并**合并**或**替换**，并为**撤消导入**保留一份安全副本；它也会把只含设置值的文件合并到当前设置中。两者都不会影响你的书签。旁边的**导出书签**会在书签管理器中打开导出工具。见[备份和恢复设置](/guides/import-export#back-up-and-restore-settings)。
- 设置存储在浏览器的同步存储空间中，因此开启浏览器同步后，设置会随你同步到其他设备。适合某一块屏幕的设置，或指向每台电脑上各不相同的内容的设置，只保存在你更改它们的设备上：弹出窗口和书签管理器的布局、管理器和弹出窗口快捷键、智能规则、存储上限、浏览时或快速保存时截取封面、快速保存选定的文件夹、AI 活动记录、询问 AI 时的网络搜索，以及本地 AI 智能体。下文中每一项都注明了这一点（**仅保存在此设备上**等）。AI 服务及其 API 密钥、**API 地址**和**额外请求头 JSON** 也只保存在本设备上。请参阅[隐私](/privacy)。
- 在可勾选和重新排序的列表中（弹出窗口的组成部分、按钮和悬停卡片的内容，卡片和预览的内容，侧边栏工具，菜单，以及右键菜单的条目），后续版本新增的项目会一直显示，直到你将其隐藏；你隐藏的项目会保持隐藏。

## 保存与搜索 [#search]

### 匹配的文件夹 [#folder-matches]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **匹配的文件夹** | 开启 | 搜索时，在结果上方列出名称匹配的文件夹，方便把当前网页保存到那里 |
| **匹配文件夹数量上限** | <SettingDefault path="search.folder_matches.max" /> | 最多列出多少个匹配的文件夹 |
| **允许拼写错误** | 开启 | 4 个字母及以上的搜索词，与文件夹名相差一个字母也能匹配 |

### 搜索 [#searching]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **搜索延迟** | <SettingDefault path="search.search.debounce_ms" /> ms | 停止输入后，弹出窗口等待多长时间再开始搜索 |
| **最大搜索结果数** | 20 个结果 | 最多显示的匹配项数量；如有更多匹配项，会显示提示 |
| **搜索时展开文件夹** | 开启 | 展开包含匹配项的文件夹 |
| **搜索历史记录** | 开启 | 在本设备上记住最近的搜索 |
| **保留的最近搜索** | <SettingDefault path="search.search.history_max" /> | 记住的最近搜索数量 |

请参阅[搜索和已保存的搜索](/guides/search)。

### 保存 [#saving]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **最近文件夹** | 开启 | 在弹出窗口中显示最近使用的文件夹；右键菜单有自己的**菜单中的最近文件夹数** |
| **最近文件夹数量上限** | <SettingDefault path="search.saving.recent_folders_max" /> | 显示多少个最近文件夹 |
| **默认文件夹名称** | 新建文件夹 | 新文件夹的初始名称 |

请参阅[保存和整理](/guides/save-and-organize)。

### 快速保存快捷键 [#quick-save]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **快速保存文件夹** | 最佳匹配 | <Shortcut id="commands.quick-save" /> 将当前网页保存到哪里：与网页最匹配的文件夹、上次使用的文件夹或指定文件夹。AI 快捷键始终使用 AI 的建议 |
| **保存到的文件夹** | 未选择 | 选择**指定文件夹**时使用的文件夹。如果该文件夹被删除，快速保存会使用上次使用的文件夹。仅保存在此设备上 |
| **提供的其他文件夹** | <SettingDefault path="search.quick_save.alternatives" /> | 快速保存通知提供多少个其他文件夹用于移动网页 |
| **通知显示时长** | <SettingDefault path="search.quick_save.notification_ms" seconds /> 秒 | 快速保存通知自动关闭前显示多久；指针悬停时保持打开 |
| **快速保存时保存封面** | 关闭 | 快速保存后，同时为书签保存封面：网页自带的图片（只从该网站或你允许的网站下载），或在你按下快捷键时截取的标签页截图，不经预览。仅在**启用获取封面**开启时有效；私密窗口中以及**永不捕获这些网站**或**从不读取这些网站**中的网站都不会保存。通知会提供**移除封面**，**撤销**会连同书签一起移除封面。只保存在此设备上。开启时会显示下面两项设置 |
| **快速保存封面来源** | 与封面来源相同 | 快速保存保留哪种封面：按照[封面来源](#fetch-covers)的顺序，或仅用于快速保存的其中一个选项 |
| **书签已有封面时** | 保留 | **保留**会留下书签已有的封面；**替换**会用新封面取代它。用**用当前画面作为封面**保存的封面永远不会被替换 |

在它们下方，**键盘快捷键**会显示每个快捷键在你的浏览器中对应的按键，并提供**更改快捷键**。在 Firefox 中，还可以直接在这里输入新按键，或将其重置为默认值。在 Chrome 和 Edge 中，这里还会说明如何将 <Shortcut id="browser.bookmark_page" /> 设为快速保存快捷键。请参阅[用键盘快捷键保存](/guides/save-and-organize#quick-save)和[用书签键快速保存](/guides/save-and-organize#ctrl-d)。

### 右键菜单 [#context-menu]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **右键菜单** | 关闭 | 在浏览器的右键菜单中显示**将书签保存到…**。在 Chrome 和 Edge 中，开启此项会添加可选的右键菜单权限，不会弹出提示 |
| **菜单显示位置** | 链接 | 右键单击时在哪里显示菜单：**链接**（保存链接）、**页面**（保存当前页面）和**选中的文字**（保存页面，使用**链接文字**命名时以选中的文字命名）。都不需要其他权限 |
| **书签名称来源** | 链接文字 | 通过右键菜单保存时，以链接文字、网页标题或链接网址作为书签名称 |
| **菜单中的最近文件夹数** | <SettingDefault path="search.context_menu.recent_max" /> | 菜单列出的最近文件夹数量，与弹出窗口的**最近文件夹数量上限**分开设置 |

**菜单项**选择菜单提供的项目及其顺序：**最近文件夹**（子菜单）和**书签栏**。勾选项目即可显示，拖动其手柄（或使用手柄菜单）可移动位置；**恢复默认设置**会按最初的顺序重新显示两者。

### 设置搜索 [#settings-search]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **搜索范围** | 名称、说明、关键词、设置 ID | 本页顶部的搜索在每个设置的哪些文字中查找 |
| **词语匹配** | 所有词语，顺序不限 | 输入的每个词可以按任意顺序出现在任意位置，还是整个搜索内容必须按输入原样匹配 |
| **高亮匹配项** | 开启 | 标出你搜索的词语，以及有匹配项的标签页 |
| **说明隐藏的匹配** | 开启 | 匹配的文字未显示（例如说明或设置 ID）时，在设置下方说明在哪里找到 |
| **在标签页上显示匹配数** | 开启 | 在每个标签页旁显示其中有多少个设置匹配 |

## 外观 [#appearance]

### 语言、主题和图标 [#language-theme-and-icons]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **语言** | 浏览器设置 | <Languages of="extension" join="or" />，也可跟随浏览器 |

### 弹出窗口 [#popup]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **弹出窗口宽度** | <SettingDefault path="appearance.popup.width" /> px | 浏览器最多允许 800 px |
| **弹出窗口高度** | <SettingDefault path="appearance.popup.height" /> px | 浏览器最多允许 600 px |
| **截断长度** | <SettingDefault path="appearance.popup.truncate_length" /> 个字符 | 缩短弹出窗口中 AI 建议标题栏里显示的网页标题 |
| **树形列表密度** | 宽松 | 弹出窗口和侧边栏中树形列表的行为 **宽松** 或 **紧凑**。仅保存在此设备上 |
| **悬停时显示详细信息** | 开启 | 在弹出窗口或侧边栏中，将指针停在书签上或用方向键移到书签，卡片会显示其完整标题和网址、文件夹、标签、摘要、已保存的封面和添加日期。按 `Esc` 关闭卡片。关闭后，行的标题和网址以普通提示显示 |

表格下方的三个列表用于安排弹出窗口和侧边栏。勾选一项即可显示，拖动其手柄即可移动；手柄也是一个按钮，其菜单可将该项移到最前、上移、下移或移到最后。**恢复默认设置** 会恢复每个列表的常用顺序。这些列表仅保存在此设备上。

- **弹出窗口的组成部分**：搜索框下方从上到下显示的内容：当前页面、后台任务、上次快速保存、最近的文件夹、AI 文件夹建议、匹配的文件夹、书签、提示和按键提示。书签始终显示；其他部分可移到书签的上方或下方。
- **工具栏按钮**：搜索框旁边的按钮：**全部展开**（搜索时）、书签管理器、主题，以及 AI 按钮（设置好 AI 后）。
- **详情卡片内容**：详情卡片依次显示的内容：标题、网址、封面、标签、摘要、文件夹和添加日期。标题、网址和封面排在最前时，它们共用卡片最上面一行。

## 行为 [#behavior]

### 树状列表与排序 [#tree-and-sorting]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **排序方式** | 浏览器顺序 | **浏览器顺序**（与书签栏一致）、**添加日期**（最新的在前）、**按字母顺序**或**文件夹优先**。在你按某一列排序之前，书签管理器的表格也使用这个顺序。只改变 Bookmark Scout 显示书签的方式，不会改变浏览器中存储的顺序 |
| **按文件夹分组** | 开启 | 在弹出窗口和侧边栏中，每一层级都先列出子文件夹，再列出书签 |
| **树中的拖放** | 开启 | 在弹出窗口和侧边栏中拖动书签和文件夹来移动它们，并可将网页中的链接拖到侧边栏的文件夹上保存。关闭后可避免误拖动行；仍可在书签管理器中移动 |
| **打开时展开** | 无 | 打开弹出窗口或侧边栏时展开哪些文件夹：**无**、**书签栏**，或 **保持上次的状态**（上次关闭时展开的文件夹，记在此设备上） |

### 链接 [#links]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **链接打开位置** | 新标签页 | **新标签页**、**后台新标签页**或**当前标签页**：在 Bookmark Scout 中点击链接时在哪里打开。中键点击和 <Shortcut id="mouse.open_in_background" />仍按浏览器的方式打开 |
| **显示链接打开位置** | 开启 | 在每个链接后面，以及弹出窗口和侧边栏中指针所指的书签行上，显示一个小图标，表明点击后在哪里打开：从方框伸出的箭头表示新标签页，叠放的图层表示后台标签页，箭头表示当前标签页。将指针移到图标上可查看说明。关闭后不再显示图标 |
| **超过此数量时先确认** | <SettingDefault path="behavior.links.confirm_open_above" /> | 一次打开的书签多于此数量时（Enter、**全部打开**）先询问，与 Chrome 的管理器相同；文件夹按其中直接包含的书签计数 |

### 工具侧栏 [#tools-sidebar]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **管理器视图** | 列表 | **列表**显示表格；**卡片**以卡片网格显示相同的行，选择、按键和菜单都相同。也可以用**查看**旁边的两个按钮切换。只保存在此设备上 |
| **工具侧栏布局** | 标签页 | **标签页**每次显示一个分区，**全部**显示所有工具；**单个列表**依次显示所有分区。仅保存在此设备上 |
| **初始标签页** | 维护 | 工具侧栏以**标签页**显示时打开的标签页：**全部**、某个分区或**数据**。若该标签页没有可显示的工具，则打开第一个有工具的标签页。仅保存在此设备上 |

**侧栏工具**选择工具侧栏显示哪些工具，以及它们在各分区内的顺序：取消勾选某个工具即可隐藏其卡片，拖动其手柄（或使用手柄菜单）可移动位置。隐藏的工具仍保持开启，因此**智能规则**、**索引网页正文**和**获取封面**会继续进行自动工作；要关闭某个工具，请使用它自己的开关。**恢复默认设置**会按最初的顺序重新显示所有工具。仅保存在此设备上。

### 书签管理器 [#manager-view]

| 设置 | 默认值 | 作用 |

## AI [#ai]

AI 默认关闭。只有在你开启 **AI 功能**后，这些设置才会生效；在此之前，此处以及 **AI 工具**标签页中的 AI 设置会显示为灰色，上方有一条提示说明这一点。你仍然可以更改它们。在设置好默认服务之前，顶部会显示 **AI 是可选的** 提示框，说明 AI 能做什么、需要什么、可能产生哪些费用以及会发送哪些内容，并附有[设置 AI 工具](/guides/ai-tools)的链接。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **AI 功能** | 关闭 | 开启 AI 工具和弹出窗口中的文件夹推荐。在 Firefox 中，开启时会请求你同意与 AI 服务商共享你的 API 密钥、书签以及当前网页的标题和网址 |
| **AI 服务** | 无 | 你添加的服务商，各有自己的模型和密钥；AI 工具使用默认服务；**内置 AI** 只负责推荐文件夹，所以它是默认服务时，其他工具会使用第一个已开启的其他服务 |

在这些设置下方，服务商面板中包含 **API 密钥**、**API 地址**、**自定义模型**和**额外请求头 JSON**，以及**验证服务**和**刷新模型**。文件夹相关的限制会作为指令发送给服务商，但不会检查服务商的输出是否遵守这些限制。请参阅[设置 AI 工具](/guides/ai-tools)。

**API 密钥** 下方的 **需要 API 密钥** 一开始与服务商的要求一致。关闭后可以不带密钥使用服务，例如位于会自行添加密钥的代理或网关之后的服务。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **启用获取封面** | 关闭 | 在工具侧边栏中显示**获取封面** |

| **永不捕获这些网站** | 无 | 浏览时永不截图的网站，各自包括其子域名。输入 `example.com` 这样的网站，或粘贴一个地址。“从不读取这些网站”中的网站也不会截取。 |

## 开发者选项 [#developers]

### 本地 AI 智能体 [#agent-bridge]

**允许本地 AI 智能体**（默认关闭，仅限此设备）让你电脑上的 AI 智能体（如 Claude Code、Codex 或 Cursor）通过 bookmark-scout-mcp 程序查找你的书签。该程序需要你安装，并用 `bookmark-scout-mcp install` 注册。它不需要开启 **AI 功能**。开启此项时，浏览器会请你允许扩展与该程序通信。**允许更改**（默认关闭）还让它们可以保存网页，并提议移动、重命名、删除和新建文件夹；每次更改都会打开 Bookmark Scout 窗口，由你批准或拒绝，你也可以在书签管理器中撤消。开关下方的面板会显示该程序是否正在运行。

**隐藏隐私值**（默认开启）会按照隐私扫描的列表，替换智能体收到的标题和网址中的敏感网址参数、令牌和电子邮件地址。**本地智能体可以执行的操作**列出了每一类查找，默认全部开启；关闭的查找将完全不会提供给智能体。
