通过扩展程序的**选项**入口打开设置页面，例如在 Chrome 中右键点击工具栏图标，然后选择**选项**。更改会即时保存。

## 使用设置页面 [#using-the-settings-page]

- 使用顶部的**搜索设置…**，可在所有标签页中查找设置，并显示匹配的数量。
- 已更改的设置会标记为**已修改**，并附有将其重置为默认值的按钮。**全部重置**会重置所有设置。
- **导出**会将你的设置保存为 JSON 文件，**导入**则从这样的文件中恢复设置。两者都不会影响你的书签。
- 设置存储在浏览器的同步存储空间中，因此开启浏览器同步后，设置会随你同步到其他设备。AI 服务商的 API 密钥、**API 地址**和**额外请求头 JSON** 例外：它们只保存在本设备上。请参阅[隐私](/privacy)。

## 外观 [#appearance]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **语言** | 浏览器设置 | 英语、简体中文、繁体中文、日语、韩语、西班牙语、德语、法语或巴西葡萄牙语，也可跟随浏览器 |
| **主题** | 跟随系统 | 跟随系统、浅色或深色，应用于所有已打开的 Bookmark Scout 页面 |
| **显示网站图标** | 开启 | 在弹出窗口和侧边栏中的书签旁显示网站图标 |
| **使用浏览器的图标缓存** | 关闭 | Chrome 和 Edge：对于没有通过**刷新网站图标**保存图标的网站，也显示浏览器已缓存的图标。开启时会请求读取网站图标的权限。Firefox 没有面向扩展程序的图标缓存，因此不会显示此项 |
| **网站图标大小** | 16px（小） | 16、24 或 32 像素 |

## 搜索 [#search]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **搜索延迟** | 300 ms | 停止输入后，弹出窗口等待多长时间再开始搜索 |
| **最大搜索结果数** | 20 个结果 | 最多显示的匹配项数量；如有更多匹配项，会显示提示 |
| **搜索时展开文件夹** | 开启 | 展开包含匹配项的文件夹 |
| **搜索历史记录** | 开启 | 在本设备上记住最近的搜索 |

请参阅[搜索和已保存的搜索](/guides/search)。

## 行为 [#behavior]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **排序方式** | 添加日期 | **添加日期**、**按字母顺序**或**文件夹优先**。只改变 Bookmark Scout 显示书签的方式，不会改变浏览器中存储的顺序 |
| **按文件夹分组** | 开启 | 在弹出窗口和侧边栏中，每一层级都先列出子文件夹，再列出书签 |
| **删除前确认** | 开启 | 删除前先询问。无论是否开启，每次删除都可在 10 秒内撤消 |
| **默认文件夹名称** | 新建文件夹 | 新文件夹的初始名称 |
| **最近文件夹** | 开启 | 在弹出窗口和右键菜单中显示最近使用的文件夹 |
| **最近文件夹数量上限** | 5 | 显示多少个最近文件夹 |

请参阅[保存和整理](/guides/save-and-organize)。

## 高级 [#advanced]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **弹出窗口宽度** | 400 px | 浏览器最多允许 800 px |
| **弹出窗口高度** | 500 px | 浏览器最多允许 600 px |
| **截断长度** | 50 个字符 | 缩短弹出窗口中 AI 建议标题栏里显示的网页标题 |
| **通知显示时长** | 4000 ms | 消息保持显示的时长。撤消消息有自己独立的 10 秒时限 |

## AI [#ai]

AI 默认关闭。只有在你开启 **AI 功能**后，这些设置才会生效。

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **AI 功能** | 关闭 | 开启 AI 工具和弹出窗口中的文件夹推荐。在 Firefox 中，开启时会请求你同意共享 AI 服务商所需的数据 |
| **打开时自动推荐** | 关闭 | 每次打开弹出窗口时都请求文件夹推荐 |
| **读取网页内容** | 关闭 | 向文件夹推荐、自动标签和内容摘要发送每个网页的正文，而不仅仅是标题和网址。开启时会请求网站访问权限 |
| **AI 服务商**和 **AI 模型** | OpenAI，GPT-4o Mini | 所有 AI 工具使用的服务商和模型 |
| **最大推荐数** | 5 | 最多请求多少条文件夹推荐 |
| **最大类别数** | 不限 | 重组方案最多可以创建多少个顶层文件夹 |
| **每个文件夹的最少项数**和**每个文件夹的最多项数** | 1 和不限 | 重组方案的文件夹大小目标 |

在这些设置下方，服务商面板中包含 **API 密钥**、**API 地址**、**自定义模型**和**额外请求头 JSON**，以及**验证服务**和**刷新模型**。文件夹相关的限制会作为指令发送给服务商，但不会检查服务商的输出是否遵守这些限制。请参阅[设置 AI 工具](/guides/ai-tools)。

## AI 工具 [#ai-tools]

每个工具都有一个**启用**开关（默认开启）。关闭某个工具后，它会从书签管理器的**工具**侧栏中隐藏。

| 工具 | 设置和默认值 |
| --- | --- |
| **AI 上下文打包** | **输出格式** Markdown；**包含文件夹路径**、**包含日期**、**包含已保存的标签**和**包含已保存的摘要**开启；**最大项数** 200；**最大深度** 8；**摘录长度** 240 |
| **自动标签** | **最少标签数** 2；**最多标签数** 5；**标签样式** kebab-case；**合并方式**追加；**移除重复标签**开启 |
| **内容摘要** | **摘要长度** 160；**包含域名提示**开启；**合并方式**替换 |
| **AI 文件夹重组** | **始终先预览**开启；**最低置信度** 0.55（低于此值的移动会被舍弃）；**批次大小**每次请求 100 个书签 |

无论**默认范围**如何设置，自动标签和内容摘要始终作用于当前文件夹。

## 维护 [#maintenance]

| 工具 | 设置和默认值 |
| --- | --- |
| **重复书签清理** | **匹配策略**规范化网址；**统一 www**、**忽略协议**和**忽略末尾斜杠**开启；**保留规则**最早的；**最大组数** 500。始终扫描所有书签 |
| **网址清理** | **移除片段**关闭；**排序查询参数**和**去除重复查询参数**开启；**保留的参数**和**移除的参数**列表 |
| **检查失效链接** | **请求超时** 8000 ms；**并发数** 4；**重试次数** 1；**跟随重定向**开启；**成功状态码** 200、201、202、204、301、302、307、308 |

**移除的参数**等列表使用以逗号分隔的值。默认列表见[清理重复书签和跟踪网址](/guides/clean-up#strip-tracking-parameters)。另请参阅[查找并修复失效链接](/guides/dead-links)。

## 元数据与内容 [#metadata--content]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **启用元数据获取** | 开启 | 在工具侧栏中显示**元数据获取** |
| **覆盖标题** | 关闭 | 也为已有标题的书签提供新标题 |
| **获取描述** | 开启 | 在审阅时显示网页描述。描述永远不会保存 |
| **请求超时** | 8000 ms | 针对每个网页。**刷新网站图标**也使用此设置 |
| **并发数** | 4 | 同时请求的网页数。**刷新网站图标**也使用此设置 |
| **启用“刷新网站图标”** | 开启 | 在工具侧栏中显示**刷新网站图标** |
| **默认范围** | 当前文件夹 | 网站图标刷新开始时使用的范围 |
| **首选图标大小** | 32px | 当网页列出多个图标时，下载最接近此大小的图标 |
| **图标文件大小上限** | 64 KB | 超过此大小的图标文件不会下载或保存 |
| **图标存储上限** | 4096 KB | 本设备上已保存图标的总大小；超出时会先移除最早保存的图标 |

## 安全 [#security]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **启用隐私扫描** | 开启 | 在工具侧栏中显示**隐私扫描**。它始终扫描所有书签 |
| **扫描标题** | 关闭 | 除网址外，也检查标题 |
| **扫描查询参数**和**扫描片段** | 开启 | 检查每个网址中的这些部分 |
| **敏感参数** | `token`, `access_token`, `refresh_token`, `auth`, `authorization`, `api_key`, `apikey`, `key`, `secret`, `password`, `pwd`, `code`, `session` | 要标记的参数名称 |
| **检测电子邮件地址**和**检测 UUID** | 开启 | 标记电子邮件地址和类似 UUID 的值 |

## 分析 [#analytics]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **启用统计** | 开启 | 在工具侧栏中显示**书签统计** |
| **包含域名**、**包含文件夹**、**包含重复项**、**包含协议**、**包含层级分布** | 开启 | 报告中的各个部分；关闭的部分会被隐藏 |
| **前 N 项** | 10 | 热门域名和热门文件夹列表的长度 |

## 数据 [#data]

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **显示导出工具**和**显示导入工具** | 开启 | 在工具侧栏中显示它们 |
| **默认导出格式** | HTML | 打开导出工具时选中的格式 |
| **文件名前缀** | `bookmarks_` | 每个导出文件名的开头 |
| **文件名最大长度** | 50 | 生成的文件名的最大长度 |
| **JSON 缩进大小**、**HTML 缩进大小**、**Markdown 缩进大小** | 2、4、2 | 各格式中每一层级缩进的空格数 |
| **包含日期**和**包含网址** | 开启 | 在导出文件中包含这些信息 |
| **右键菜单** | 关闭 | 右键点击链接时显示**将书签保存到…**。在 Chrome 和 Edge 中，开启此项会添加可选的右键菜单权限，不会弹出提示 |
| **书签名称来源** | 链接文字 | 通过右键菜单保存时，以链接文字、网页标题或链接网址作为书签名称 |

请参阅[导入和导出](/guides/import-export)。
