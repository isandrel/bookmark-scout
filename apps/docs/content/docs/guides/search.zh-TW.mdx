## 從彈出式視窗或側邊面板搜尋 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
按一下工具列中的 Bookmark Scout 圖示。也可以在瀏覽器的側邊面板 (Firefox 中為側邊欄) 中開啟 Bookmark Scout，瀏覽網頁時側邊面板會保持開啟。
</Step>
<Step>
在頂端的搜尋框中輸入文字。搜尋框中顯示「**輸入資料夾名稱來儲存此頁面…**」，也可以用來搜尋書籤 (按下 <Shortcut id="popup.focus_search" /> 即可跳到搜尋框)。結果會隨著輸入即時顯示在所屬的資料夾中，相符的內容會醒目顯示。每個字詞都必須符合標題、網址、資料夾或標籤和摘要中的某一處；請參閱[搜尋字詞和運算子](#search-words-and-operators)。
</Step>
<Step>
使用搜尋框內的「**更多搜尋選項**」按鈕縮小比對範圍：「**大小寫須相符**」、「**全字拼寫須相符**」和「**進階模式搜尋（規則運算式）**」，最後一項會將搜尋內容視為規則運算式。只要其中任何一項開啟，這個按鈕就會醒目顯示。這些選項只會依輸入原樣搜尋標題，不使用運算子。
</Step>
<Step>
按一下書籤，或使用方向鍵移至書籤並按下 `Enter`，即可在新分頁中開啟。
</Step>
</Steps>

注意事項：

- 全字比對會將空格、標點符號和文字系統的切換視為字詞邊界，因此 `C++` 這類詞彙和日文字詞也能相符。
- 無效、過長，或重複部分能以多種方式比對同一段文字（可能讓頁面卡住）的規則運算式會顯示警告，並以一般文字搜尋。
- 書籤列等永久資料夾是容器，名稱絕不會列為相符結果。
- 相符結果超過結果上限時，會顯示提示說明目前顯示的數量。請縮小搜尋範圍，或在「[設定](/settings)」中提高「**搜尋結果上限**」。
- 清除搜尋 (按一下清除按鈕，或在搜尋框中按下 `Esc`) 後，會還原先前展開的資料夾。
- 最近的搜尋會記錄在這部裝置上。按一下空白的搜尋框，或在搜尋框中按下 <Shortcut id="popup.recent_searches" />，即可列出最近的搜尋。可以從該清單中清除，或在設定中關閉「**搜尋記錄**」。
- 將指標停在書籤上，或用方向鍵移到書籤，就會看到一張卡片，顯示其完整標題和網址、資料夾、標籤、摘要、已儲存的封面和新增日期。可以把指標移到卡片上閱讀較長的摘要，按 `Esc` 關閉卡片。顯示卡片不會下載任何內容。可在[設定](/settings#popup)中關閉「**游標停留時顯示詳細資訊**」。

## 搜尋字詞和運算子 [#search-words-and-operators]

彈出式視窗、側邊面板和書籤管理員中的搜尋框會以相同方式讀取搜尋內容。它們只搜尋這個瀏覽器中的書籤，不會傳送任何資料。

- 每個字詞都必須符合，各自可以出現在任何位置：標題、網址、資料夾路徑，或書籤的標籤和摘要。`食譜 湯` 會找到「食譜」資料夾中名為「湯」的書籤。
- 引號會讓字詞連在一起比對：`"react hooks"`。
- 在前面加上 `-` 會排除符合的項目：`食譜 -蛋糕` 或 `-tag:封存`。
- 兩個搜尋字詞之間的大寫 `OR` 表示符合其一即可：`tag:react OR tag:vue`。它比空格結合得更緊，所以 `domain:github.com tag:react OR tag:vue` 會找到帶有其中任一標籤的 GitHub 頁面。小寫的 `or` 仍是要尋找的一般字詞。
- 括號可以組合搜尋字詞：`domain:github.com (tag:react OR tag:vue) -tag:archived`。在括號前加上 `-` 會排除整組符合的項目：`-(tag:old OR tag:archive)`。字詞內的括號（例如 `f(x)`）會當成文字搜尋。
- 符合資料夾名稱的字詞會找到該資料夾。在彈出式視窗中，其中的書籤會顯示在該資料夾內；`folder:` 會列出其中的所有內容。如果其他條件排除了該資料夾本身（如 `work is:bookmark`），則會改為找到其中符合的書籤。
- 不是運算子的文字會依輸入原樣搜尋，例如 `C++`、`10:30` 或網址。Bookmark Scout 不認得的運算子（例如 `foo:bar`）也一樣。無法讀取的值（例如無效的日期）會略過。括號未關閉，或 `OR` 的某一側沒有搜尋字詞時，搜尋框下方會顯示提示。巢狀過深的括號或過長的 `OR` 清單會被截斷，並顯示提示。

| 搜尋 | 找到的項目 |
| --- | --- |
| `title:react` | 包含該文字的標題；`title:"react hooks"` 可包含多個字詞 |
| `url:github` | 包含該文字的網址 |
| `domain:github.com` | 該網站上的書籤，包括其子網域 |
| `folder:工作` 或 `path:工作` | 名稱完全相同的資料夾中的所有內容（任何層級）；`folder:"工作 / 文件"` 表示另一個資料夾中的資料夾；名稱中含斜線的資料夾（如 `folder:CI/CD`）也能找到 |
| `tag:稍後閱讀` | 帶有完全相同標籤的書籤 |
| `summary:食譜` | 包含該文字的摘要 |
| `content:食譜` | 你用「**索引網頁內文**」索引的網頁內文 |
| `is:bookmark` 或 `is:folder` | 只有書籤，或只有資料夾 |
| `is:untagged` | 沒有標籤的書籤 |
| `has:tags` 或 `has:summary` | 有標籤的項目，或有摘要的項目 |
| `has:content` | 網頁內文已索引的書籤 |
| `after:2026-01-31` 或 `before:2026-01-31` | 在該日當天或之後新增的項目，或在當天或之前新增的項目 |
| `tag:react OR tag:vue` | 符合任一側的書籤；`OR` 必須大寫 |
| `(tag:react OR tag:vue) -tag:old` | 以括號組合的搜尋字詞：有 react 或 vue 標籤，且沒有 old 標籤 |

標籤和摘要是你在「**書籤詳細資料**」中新增的，或從「**自動加上標籤**」和「**內容摘要工具**」的建議中保留的。這些資料只會留在這部裝置上。

開啟「**索引網頁內文**」後，一般字詞也會比對已索引網頁的內文 (排在標題、網址、標籤和摘要之後)；在彈出式視窗中這樣找到的結果會顯示比對處附近的文字以及內文的來源：「**已下載的網頁**」或「**來自你的分頁的網頁**」。請參閱[在網頁中搜尋](/guides/clean-up#search-inside-pages)。

加上引號的詞組只會在網頁內文的同一段落內比對。「**索引網頁內文**」關閉時，使用 `content:` 或 `has:content` 的搜尋會在搜尋框下方提示，而不是什麼都找不到。「詢問 AI」和本機 AI 代理程式從不搜尋網頁內文：在那裡 `content:` 和 `has:content` 什麼都找不到，回答中也會說明這一點。

## 在書籤管理員中篩選 [#filter-in-the-bookmarks-manager]

書籤管理員的表格提供更精確的篩選器。在 Chrome 中，開啟瀏覽器的書籤頁面即可進入，一開始會顯示你的書籤列。在[設定](/settings#manager-view)中設定 **起始資料夾**，可以改為開啟上次開啟的資料夾或你選擇的資料夾。

- 「**搜尋標題、網址、資料夾和標籤**」會讀取[搜尋字詞和運算子](#search-words-and-operators)，並列出符合的資料夾和書籤。按下 <Shortcut id="manager.focus_filter" /> 可直接跳到這個搜尋框。搜尋框結尾的「**搜尋語法**」按鈕會列出運算子，選擇一個即可加入搜尋。如果搜尋是透過網址、標籤、摘要或網頁內文而不是標題找到某一列，標題下方會像彈出式視窗中一樣註明符合的位置。
- 「**篩選**」包含其他所有篩選條件：「**僅限目前資料夾**」、「**類型**」、「**網域**」、「**資料夾**」(只保留你選取的資料夾中的項目)、「**新增日期**」和「**篩選網址...**」(只比對網址)。每個使用中的篩選條件都會以標籤顯示在工具列下方，按一下其 **×** 即可移除；「**重設**」會清除所有篩選條件和搜尋。搜尋中的問題 (例如無效的日期) 會在工具列下方說明。
- 「**僅限目前資料夾**」會將篩選範圍限制在目前所在的資料夾。關閉時，篩選器會搜尋所有書籤，每個結果的標題下方會顯示其所在的資料夾，頂端的路徑則會顯示「**所有資料夾中的結果**」。
- 按一下任一欄的標頭即可依該欄排序。表格不是瀏覽器順序時，「**瀏覽器順序**」旁的文字會說明目前的排序；按一下「**瀏覽器順序**」即可恢復。
- 表格會顯示「**標題**」、「**網址**」和「**新增日期**」，每頁 50 列。可以在「**查看**」中開啟「**類型**」、「**資料夾路徑**」等其他欄，並在表格下方選擇每頁的列數。要調整欄的順序，可在「**查看**」中拖曳欄的控點，或使用旁邊的箭頭按鈕。也可以在表格中將欄標題拖曳到新位置，或透過欄標題的選單將該欄左移或右移。新的檢視，以及用 **查看** > **重設檢視** 重設後的檢視，會使用[設定](/settings#manager-table)中的 **預設欄位**、**預設每頁列數** 和 **預設排序**；你在這裡改過的部分會維持你的設定。
- 同樣在「**查看**」中的「**標籤**」和「**摘要**」欄，會顯示每個書籤已儲存的標籤（前幾個，其餘以 **+N** 計數）和摘要的前幾行。將指標停在被截斷的摘要上，或用方向鍵移到它所在的列，即可在卡片中閱讀全文；按 `Esc` 關閉卡片。
- 同樣在「**查看**」中的「**封面**」欄，會在核取方塊之後以小圖顯示每個書籤已儲存的封面；沒有封面的列保持空白。將指標停在小圖上，或用 `Tab` 移到小圖，即可看到放大的封面以及標題和封面來源；按 `Esc` 關閉。按一下小圖會開啟該書籤的「**預覽**」。
- 「**查看**」旁的兩個按鈕可在清單和「**卡片**」之間切換。卡片以格狀排列顯示相同的列、篩選、排序、選取和選單：左右鍵一次移動一張卡片，上下鍵一次移動一列卡片，按兩下可開啟資料夾或連結。所選檢視會儲存在這部裝置上。卡片會顯示書籤已儲存的封面（沒有時顯示一個圖塊，在從該網站選取的顏色上顯示網站的圖示和名稱）、標題和網址、前幾個標籤（其餘的以 **+N** 標籤計數），以及摘要的前幾行；資料夾卡片會顯示資料夾中有多少項目。顯示卡片時不會下載任何內容。在[設定](/settings#manager-cards)中可以選擇卡片顯示的內容、順序、卡片寬度，以及顯示多少個標籤和幾行摘要。
- 書籤選單（「**⋯**」按鈕或右鍵選單）中的「**預覽**」，或在目前的卡片或列上按 <Shortcut id="manager.preview" />，會顯示書籤已儲存的封面、網址、資料夾、標籤和摘要，並提供「**在新分頁中開啟**」、「**複製**」和「**編輯**」。顯示時不會下載任何內容。按 <Shortcut id="manager.preview_previous" /> 和 <Shortcut id="manager.preview_next" />，或按一下預覽頂端的箭頭按鈕，可顯示本頁的上一個或下一個書籤；會略過資料夾，並在第一個和最後一個書籤停下。`Tab` 只在預覽內移動，按 `Esc` 關閉並回到所顯示書籤的卡片。在[設定](/settings#manager-preview)中可以選擇它顯示的內容，在[書籤管理器選單](/settings#manager-menus)中可以安排它的按鈕。
- 在跨資料夾的搜尋中，列的選單會提供「**在資料夾中顯示**」：這會清除篩選條件，並開啟包含該項目的資料夾，同時選取該項目。
- 拖曳資料夾側欄或 **工具** 側欄的內側邊緣可調整寬度，也可以聚焦邊緣後使用方向鍵；寬度保存在這部裝置上。[設定](/settings#manager-view)中的 **開啟時的側欄** 可以讓它們依你離開時的樣子重新開啟。

## 連結到資料夾或搜尋 [#link-to-a-folder-or-a-search]

書籤管理員的網址會跟著你檢視的內容變更，因此瀏覽器的「**上一頁**」和「**下一頁**」可以在資料夾和搜尋之間切換，你也可以將檢視畫面加入書籤或分享出去。

- `?id=` 指定開啟的資料夾，與 Chrome 本身的書籤管理員相同：`chrome://bookmarks/?id=12` 會在 Chrome 中開啟資料夾 12，`edge://favorites/?id=12` 則會在 Edge 中開啟。Chrome 154 到 156 以長 ID 指定書籤列、其他書籤和行動裝置書籤的連結，也能開啟這些資料夾。沒有 `?id=` 時，書籤管理員會開啟書籤列；按一下資料夾路徑開頭的「**書籤**」可查看最上層。沒有 `?id=` 時，可以用[設定](/settings#manager-view)中的 **起始資料夾** 改為開啟其他資料夾，而不是書籤列。
- `?q=` 是搜尋：`chrome://bookmarks/?q=react` 會開啟書籤管理員並搜尋「react」，`?q=tag:reading` 則會搜尋該標籤。在「**搜尋標題、網址、資料夾和標籤**」中輸入文字時，網址會跟著變更，而一次連續輸入算作一個「**上一頁**」步驟。搜尋優先於資料夾；勾選「**僅限目前資料夾**」時，資料夾仍會套用。
- 標頭中資料夾路徑旁和資料夾列選單中的「**複製此資料夾的連結**」會複製該網址。在 Firefox 中，則會複製書籤管理員頁面本身的網址。即使你在資料夾之間移動，Chrome 和 Edge 仍會繼續顯示你開啟書籤管理員時使用的網址。
- 分頁標題會顯示資料夾名稱，搜尋時則會顯示搜尋內容。

## 儲存搜尋 [#save-a-search]

已儲存的搜尋會以一個名稱保留書籤管理員目前的篩選條件、排序和資料夾範圍，方便日後重新開啟相同的檢視畫面。

<Steps>
<Step>
至少設定一個篩選條件：標題、網址、類型、資料夾、網域或新增日期。
</Step>
<Step>
按一下表格工具列中的「**已儲存的搜尋**」，或按下 <Shortcut id="manager.open_saved_searches" />。
</Step>
<Step>
在「**為這個搜尋命名**」中輸入名稱，然後按一下「**儲存**」。
</Step>
</Steps>

如要使用已儲存的搜尋，請開啟「**已儲存的搜尋**」並選擇該項目。它的篩選條件和排序會取代目前的設定；如果它限定在某個資料夾，書籤管理員會回到該資料夾。每個項目都可以重新命名或刪除，刪除後也可以從隨後顯示的訊息中復原。拖曳項目的控點可調整順序，也可以開啟控點的選單用鍵盤移動。

搜尋框中的文字會依輸入原樣儲存，包括運算子。在搜尋框支援運算子之前儲存的搜尋，只會在標題和網址中尋找文字。現在，如果文字包含多個字詞或冒號，開啟時會加上引號，因此仍能找到以前找到的所有書籤。在支援 `OR` 和括號之前儲存的搜尋，開啟時也會因為同樣的原因把它們放在引號中。

已儲存的搜尋只會儲存篩選條件的定義，絕不會複製書籤，因此其結果一律與目前的書籤相符。如果它指定的資料夾已被刪除，系統會略過該資料夾，其他篩選條件仍會套用，並會顯示訊息說明略過了幾個資料夾。

已儲存的搜尋會保留在這個瀏覽器的擴充功能本機儲存空間中，不會同步，因為篩選條件可能會透露你加入書籤的內容，而且各裝置的資料夾 ID 也不相同。最多可以保留 50 個。

<Callout title="Firefox">
在 Firefox 中，請從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員。
</Callout>
