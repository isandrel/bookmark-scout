## 從彈出式視窗或側邊面板搜尋 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
按一下工具列中的 Bookmark Scout 圖示。在 Chrome 和 Edge 中，也可以在瀏覽器的側邊面板中開啟 Bookmark Scout，瀏覽網頁時側邊面板會保持開啟。
</Step>
<Step>
在「**搜尋書籤...**」中輸入文字 (或按下 `/` 跳到搜尋框)。結果會隨著輸入即時顯示在所屬的資料夾中，相符的內容會醒目顯示。
</Step>
<Step>
使用搜尋框內的三個按鈕縮小比對範圍：「**大小寫須相符**」、「**全字拼寫須相符**」和「**使用規則運算式**」。
</Step>
<Step>
按一下書籤，或使用方向鍵移至書籤並按下 `Enter`，即可在新分頁中開啟。
</Step>
</Steps>

<Screenshot name="popup" />

注意事項：

- 全字比對會將空格、標點符號和文字系統的切換視為字詞邊界，因此 `C++` 這類詞彙和日文字詞也能相符。
- 無效的規則運算式會顯示警告，並以一般文字搜尋。
- 書籤列等永久資料夾是容器，名稱絕不會列為相符結果。
- 相符結果超過結果上限時，會顯示提示說明目前顯示的數量。請縮小搜尋範圍，或在「[設定](/settings)」中提高「**搜尋結果上限**」。
- 清除搜尋 (按一下清除按鈕，或在搜尋框中按下 `Esc`) 後，會還原先前展開的資料夾。
- 最近的搜尋會記錄在這部裝置上。按一下空白的搜尋框，或在搜尋框中按下 `Alt+↓`，即可列出最近的搜尋。可以從該清單中清除，或在設定中關閉「**搜尋記錄**」。

## 在書籤管理員中篩選 [#filter-in-the-bookmarks-manager]

書籤管理員的表格提供更精確的篩選器。在 Chrome 中，開啟瀏覽器的書籤頁面即可進入。

- 「**篩選標題...**」和「**篩選網址...**」會比對這兩欄中的文字。按下 `/` 可跳到標題篩選器。
- 「**類型**」、「**上層 ID**」、「**網域**」和「**新增日期**」可以進一步縮小列出的項目。
- 「**僅限目前資料夾**」會將篩選範圍限制在目前所在的資料夾。關閉時，篩選器會搜尋所有書籤。
- 按一下任一欄的標頭即可依該欄排序。

## 儲存搜尋 [#save-a-search]

已儲存的搜尋會以一個名稱保留書籤管理員目前的篩選條件、排序和資料夾範圍，方便日後重新開啟相同的檢視畫面。

<Steps>
<Step>
至少設定一個篩選條件：標題、網址、類型、資料夾、網域或新增日期。
</Step>
<Step>
按一下表格工具列中的「**已儲存的搜尋**」，或按下 `s`。
</Step>
<Step>
在「**為這個搜尋命名**」中輸入名稱，然後按一下「**儲存**」。
</Step>
</Steps>

如要使用已儲存的搜尋，請開啟「**已儲存的搜尋**」並選擇該項目。它的篩選條件和排序會取代目前的設定；如果它限定在某個資料夾，書籤管理員會回到該資料夾。每個項目都可以重新命名或刪除，刪除後也可以從隨後顯示的訊息中復原。

已儲存的搜尋只會儲存篩選條件的定義，絕不會複製書籤，因此其結果一律與目前的書籤相符。如果它指定的資料夾已被刪除，系統會略過該資料夾，其他篩選條件仍會套用，並會顯示訊息說明略過了幾個資料夾。

已儲存的搜尋會保留在這個瀏覽器的擴充功能本機儲存空間中，不會同步，因為篩選條件可能會透露你加入書籤的內容，而且各裝置的資料夾 ID 也不相同。最多可以保留 50 個。

<Callout title="Firefox">
在 Firefox 中，請從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員。
</Callout>
