## ポップアップやサイドパネルから検索する [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
ツールバーの Bookmark Scout アイコンをクリックします。ブラウザのサイドパネル（Firefox ではサイドバー）で Bookmark Scout を開くこともできます。サイドパネルはブラウズ中も開いたままです。
</Step>
<Step>
**ブックマークを検索...** に入力します（`/` を押すとそこへ移動します）。入力と同時に、結果がそれぞれのフォルダの中に表示され、一致した部分が強調表示されます。
</Step>
<Step>
検索ボックス内の 3 つのボタン、**大文字/小文字を区別**、**単語全体を検索**、**正規表現を使用** で一致の条件を絞り込みます。
</Step>
<Step>
ブックマークをクリックするか、矢印キーで移動して `Enter` を押すと、新しいタブで開きます。
</Step>
</Steps>

<Screenshot name="popup" />

知っておくと便利なこと:

- 単語全体の一致では、スペース、句読点、文字体系の切り替わりを単語の区切りとして扱います。そのため、`C++` のような語や日本語の単語も一致します。
- 正しくない正規表現を入力すると警告が表示され、通常のテキストとして検索されます。
- ブックマークバーなどの固定フォルダは入れ物であり、名前で一致することはありません。
- 一致する項目が結果の上限より多い場合は、表示されている件数が示されます。検索を絞り込むか、[設定](/settings)で **最大検索結果数** を増やしてください。
- 検索をクリアすると（クリアボタン、または検索ボックスで `Esc`）、検索前に開いていたフォルダが元に戻ります。
- 最近の検索はこのデバイスに記憶されます。空の検索ボックスをクリックするか、検索ボックスで `Alt+↓` を押すと一覧が表示されます。その一覧から消去するか、設定で **検索履歴** をオフにしてください。

## ブックマークマネージャーで絞り込む [#filter-in-the-bookmarks-manager]

マネージャーの表には、より細かいフィルターがあります。Chrome では、ブラウザのブックマークページを開くとマネージャーが表示されます。

- **タイトルで絞り込み...** と **URLで絞り込み...** は、それぞれの列のテキストに一致します。`/` を押すとタイトルのフィルターへ移動します。
- **種類**、**親フォルダ**、**ドメイン**、**追加日** で行をさらに絞り込めます。
- **現在のフォルダのみ** をオンにすると、フィルターの対象が今いるフォルダに限られます。オフの場合、フィルターはすべてのブックマークを対象にします。
- 列の見出しから、任意の列で並べ替えられます。

## 検索を保存する [#save-a-search]

保存した検索は、マネージャーの現在のフィルター、並べ替え、フォルダの範囲を名前を付けて残すもので、後で同じ表示を開き直せます。

<Steps>
<Step>
フィルターを 1 つ以上設定します（タイトル、URL、種類、フォルダ、ドメイン、追加日）。
</Step>
<Step>
表のツールバーで **保存した検索** をクリックするか、`s` を押します。
</Step>
<Step>
**この検索に名前を付ける** に名前を入力し、**保存** をクリックします。
</Step>
</Steps>

使うときは、**保存した検索** を開いて選びます。そのフィルターと並べ替えが現在のものに置き換わり、1 つのフォルダに限定されていた場合はマネージャーがそのフォルダに戻ります。各項目は名前の変更や削除ができ、削除はその後に表示されるメッセージから元に戻せます。

保存した検索に保存されるのはフィルターの定義だけで、ブックマークのコピーは保存されません。そのため、結果は常に現在のブックマークと一致します。指定されたフォルダが削除されていた場合、そのフォルダはスキップされ、ほかのフィルターは引き続き適用されます。スキップしたフォルダの数はメッセージで示されます。

保存した検索は、このブラウザの拡張機能のローカルストレージに保存され、同期されません。フィルターから何をブックマークしているかがわかってしまうことがあり、またフォルダ ID はデバイスごとに異なるためです。最大 50 件まで保存できます。

<Callout title="Firefox">
Firefox では、ポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。
</Callout>
