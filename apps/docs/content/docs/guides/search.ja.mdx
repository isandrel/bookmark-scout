## ポップアップやサイドパネルから検索する [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
ツールバーの Bookmark Scout アイコンをクリックします。ブラウザのサイドパネル（Firefox ではサイドバー）で Bookmark Scout を開くこともできます。サイドパネルはブラウズ中も開いたままです。
</Step>
<Step>
上部の検索ボックスに入力します。検索ボックスには **フォルダ名を入力してこのページを保存…** と表示されていますが、ブックマークの検索にも使えます（<Shortcut id="popup.focus_search" /> を押すとそこへ移動します）。入力と同時に、結果がそれぞれのフォルダの中に表示され、一致した部分が強調表示されます。すべての単語が、タイトル、アドレス、フォルダ、タグと要約のいずれかに一致する必要があります。[検索語と演算子](#search-words-and-operators)を参照してください。
</Step>
<Step>
検索ボックス内のボタン **その他の検索オプション** で一致の条件を絞り込みます。**大文字/小文字を区別**、**単語全体を検索**、**高度なパターン検索（正規表現）** があり、最後のものは検索語を正規表現として扱います。いずれかがオンの間は、ボタンが強調表示されます。これらのオプションは、入力どおりにタイトルだけを検索し、演算子は使いません。
</Step>
<Step>
ブックマークをクリックするか、矢印キーで移動して `Enter` を押すと、新しいタブで開きます。
</Step>
</Steps>

知っておくと便利なこと:

- 単語全体の一致では、スペース、句読点、文字体系の切り替わりを単語の区切りとして扱います。そのため、`C++` のような語や日本語の単語も一致します。
- 正しくない正規表現を入力すると警告が表示され、通常のテキストとして検索されます。
- ブックマークバーなどの固定フォルダは入れ物であり、名前で一致することはありません。
- 一致する項目が結果の上限より多い場合は、表示されている件数が示されます。検索を絞り込むか、[設定](/settings)で **最大検索結果数** を増やしてください。
- 検索をクリアすると（クリアボタン、または検索ボックスで `Esc`）、検索前に開いていたフォルダが元に戻ります。
- 最近の検索はこのデバイスに記憶されます。空の検索ボックスをクリックするか、検索ボックスで <Shortcut id="popup.recent_searches" /> を押すと一覧が表示されます。その一覧から消去するか、設定で **検索履歴** をオフにしてください。

## 検索語と演算子 [#search-words-and-operators]

ポップアップ、サイドパネル、マネージャーの検索ボックスは、検索を同じように読み取ります。検索するのはこのブラウザーのブックマークだけで、どこにも何も送信しません。

- すべての単語が、それぞれどこかに一致する必要があります。対象はタイトル、ウェブアドレス、フォルダのパス、ブックマークのタグと要約です。`レシピ スープ` は、「レシピ」フォルダにある「スープ」という名前のブックマークを見つけます。
- 引用符で囲むと、単語をひと続きで探します: `"react hooks"`。
- 先頭に `-` を付けると、一致するものを除外します: `レシピ -ケーキ`、`-tag:アーカイブ`。
- 2 つの語句の間に大文字の `OR` を置くと、どちらか一方に一致するものを探します: `tag:react OR tag:vue`。これはスペースより強く結び付くため、`domain:github.com tag:react OR tag:vue` はどちらかのタグが付いた GitHub のページを見つけます。小文字の `or` は通常の検索語として扱います。
- かっこで語句をまとめられます: `domain:github.com (tag:react OR tag:vue) -tag:archived`。かっこの前に `-` を付けると、そのまとまりに一致するものを除外します: `-(tag:old OR tag:archive)`。`f(x)` のように単語の中にあるかっこは、テキストとして検索します。
- フォルダ名に一致する単語は、そのフォルダを見つけます。ポップアップでは、その中のブックマークがフォルダの中に表示されます。中身をすべて一覧にするには `folder:` を使います。
- 演算子ではないテキストは、`C++`、`10:30`、ウェブアドレスなど、入力どおりに検索します。`foo:bar` のように Bookmark Scout が知らない演算子も同様です。無効な日付など、読み取れない値は無視されます。かっこが閉じていない場合や、`OR` の片側に語句がない場合は、検索ボックスの下に注意が表示されます。深すぎるかっこの入れ子や長すぎる `OR` の並びは途中で打ち切られ、注意が表示されます。

| 検索 | 見つかるもの |
| --- | --- |
| `title:react` | そのテキストを含むタイトル。`title:"react hooks"` で複数の単語を指定できます |
| `url:github` | そのテキストを含むウェブアドレス |
| `domain:github.com` | そのサイトのブックマーク（サブドメインを含む） |
| `folder:仕事` または `path:仕事` | 名前が完全に一致するフォルダ内のすべて（階層の深さは問いません）。`folder:"仕事 / 資料"` は、別のフォルダの中にあるフォルダを指定します |
| `tag:あとで読む` | そのタグが付いたブックマーク（完全一致） |
| `summary:レシピ` | そのテキストを含む要約 |
| `content:レシピ` | **ページ本文の索引** で索引を作ったページの本文 |
| `is:bookmark` または `is:folder` | ブックマークだけ、またはフォルダだけ |
| `is:untagged` | タグのないブックマーク |
| `has:tags` または `has:summary` | タグのある項目、または要約のある項目 |
| `has:content` | ページ本文の索引があるブックマーク |
| `after:2026-01-31` または `before:2026-01-31` | その日以降、またはその日以前に追加された項目 |
| `tag:react OR tag:vue` | どちらか一方に一致するブックマーク。`OR` は大文字で入力します |
| `(tag:react OR tag:vue) -tag:old` | かっこでまとめた語句。react または vue のタグがあり、old のタグがないもの |

タグと要約は、**ブックマークの詳細** で追加したもの、または **自動タグ付け** と **コンテンツ要約** ツールの提案から残したものです。この端末にのみ保存されます。

**ページ本文の索引** がオンのとき、通常の単語は索引済みページの本文にも一致します（タイトル、アドレス、タグ、要約より後の順位）。ポップアップでこの方法で見つかった結果には、一致した前後の文字が表示されます。[ページの中を検索](/guides/clean-up#search-inside-pages) を参照してください。

## ブックマークマネージャーで絞り込む [#filter-in-the-bookmarks-manager]

マネージャーの表には、より細かいフィルターがあります。Chrome では、ブラウザのブックマークページを開くとマネージャーが表示されます。最初はブックマークバーが開きます。

- **タイトル・アドレス・フォルダ・タグを検索** は、[検索語と演算子](#search-words-and-operators)を読み取り、一致するフォルダとブックマークを一覧にします。<Shortcut id="manager.focus_filter" /> を押すと、この検索ボックスへ移動します。末尾の **検索構文** ボタンで演算子の一覧を開けます。選ぶと検索に追加されます。 タイトルではなくアドレス、タグ、要約、ページ本文で見つかった行には、ポップアップと同じようにタイトルの下に一致した場所が表示されます。
- **フィルター** には、ほかのすべての絞り込みがあります: **現在のフォルダのみ**、**種類**、**ドメイン**、選んだフォルダの項目だけを残す **フォルダ**、**追加日**、ウェブアドレスだけに一致する **URLで絞り込み...**。使用中の絞り込みはツールバーの下にチップとして表示され、その **×** で解除できます。**リセット** はすべての絞り込みと検索を消去します。無効な日付など、検索の問題はツールバーの下で説明されます。
- **現在のフォルダのみ** をオンにすると、フィルターの対象が今いるフォルダに限られます。オフの場合、フィルターはすべてのブックマークを対象にし、各結果のタイトルの下にそのフォルダが表示され、上部のパスには **すべてのフォルダの結果** と表示されます。
- 列の見出しから、任意の列で並べ替えられます。表がブラウザの順序になっていないときは、**ブラウザの順序** の横に現在の並び順が表示されます。**ブラウザの順序** をクリックすると元に戻ります。
- 表には **タイトル**、**URL**、**追加日** が表示され、1 ページに 50 行が並びます。**種類**、**フォルダのパス** などの列は **表示** でオンにでき、1 ページの行数は表の下で選べます。列の順番は、**表示** でハンドルをドラッグするか、横の矢印ボタンで変えられます。表の列見出しをドラッグして移動したり、見出しのメニューから左右に移動したりすることもできます。
- **表示** の横にある 2 つのボタンで、リストと **カード** を切り替えます。カードは同じ行、絞り込み、並べ替え、選択、メニューをカードのグリッドで表示します。左右キーで 1 枚ずつ、上下キーで 1 行ずつ移動し、ダブルクリックでフォルダやリンクを開きます。選択はこの端末に保存されます。
- ブックマークのメニュー（**⋯** ボタンまたは右クリックメニュー）の **プレビュー**、またはフォーカス中のカードや行で <Shortcut id="manager.preview" /> を押すと、保存済みのカバー画像、アドレス、フォルダ、タグ、要約が表示され、**新しいタブで開く**、**コピー**、**編集** を選べます。表示のために何もダウンロードしません。`Tab` はプレビューの中だけを移動し、`Esc` で閉じるとカードに戻ります。
- フォルダをまたぐ検索では、行のメニューに **フォルダ内に表示** があります。フィルターを解除して項目を含むフォルダを開き、その項目を選択します。

## フォルダや検索へのリンク [#link-to-a-folder-or-a-search]

マネージャーのアドレスは表示中の内容に合わせて変わるため、ブラウザの **戻る** と **進む** でフォルダや検索を行き来でき、表示をブックマークしたり共有したりできます。

- `?id=` は、Chrome 自体のマネージャーと同じく、開いているフォルダを示します。Chrome では `chrome://bookmarks/?id=12`、Edge では `edge://favorites/?id=12` でフォルダ 12 が開きます。ブックマークバー、その他のブックマーク、モバイルのブックマークを長い ID で示していた Chrome 154～156 のリンクでも、これらのフォルダが開きます。`?id=` がない場合、マネージャーはブックマークバーを開きます。フォルダのパスの先頭にある **ブックマーク** をクリックすると最上位の階層が表示されます。
- `?q=` は検索です。`chrome://bookmarks/?q=react` を開くと、「react」で検索した状態のマネージャーが開き、`?q=tag:reading` ではそのタグで検索します。**タイトル・アドレス・フォルダ・タグを検索** に入力している間はアドレスもそれに合わせて変わり、一続きの入力が **戻る** の 1 ステップになります。検索はフォルダより優先されますが、**現在のフォルダのみ** がオンの場合はフォルダも適用されます。
- ヘッダーのフォルダパスの横とフォルダの行のメニューにある **このフォルダへのリンクをコピー** で、そのアドレスをコピーします。Firefox では、マネージャーのページ自体のアドレスをコピーします。Chrome と Edge では、フォルダを移動しても、マネージャーを開いたときのアドレスがそのまま表示されます。
- タブのタイトルにはフォルダ名が、検索中は検索内容が表示されます。

## 検索を保存する [#save-a-search]

保存した検索は、マネージャーの現在のフィルター、並べ替え、フォルダの範囲を名前を付けて残すもので、後で同じ表示を開き直せます。

<Steps>
<Step>
フィルターを 1 つ以上設定します（タイトル、URL、種類、フォルダ、ドメイン、追加日）。
</Step>
<Step>
表のツールバーで **保存した検索** をクリックするか、<Shortcut id="manager.open_saved_searches" /> を押します。
</Step>
<Step>
**この検索に名前を付ける** に名前を入力し、**保存** をクリックします。
</Step>
</Steps>

使うときは、**保存した検索** を開いて選びます。そのフィルターと並べ替えが現在のものに置き換わり、1 つのフォルダに限定されていた場合はマネージャーがそのフォルダに戻ります。各項目は名前の変更や削除ができ、削除はその後に表示されるメッセージから元に戻せます。項目のハンドルをドラッグすると順番を変えられ、ハンドルのメニューを使えばキーボードでも移動できます。

検索ボックスのテキストは、演算子も含めて入力どおりに保存されます。検索ボックスが演算子を読み取るようになる前に保存した検索は、テキストをタイトルとアドレスからだけ探していました。そうした検索は、テキストに複数の単語やコロンが含まれる場合は引用符で囲んだ状態で開くため、以前見つけたブックマークはすべて引き続き見つかります。`OR` とかっこに対応する前に保存した検索も、同じ理由でそれらを引用符で囲んだ状態で開きます。

保存した検索に保存されるのはフィルターの定義だけで、ブックマークのコピーは保存されません。そのため、結果は常に現在のブックマークと一致します。指定されたフォルダが削除されていた場合、そのフォルダはスキップされ、ほかのフィルターは引き続き適用されます。スキップしたフォルダの数はメッセージで示されます。

保存した検索は、このブラウザの拡張機能のローカルストレージに保存され、同期されません。フィルターから何をブックマークしているかがわかってしまうことがあり、またフォルダ ID はデバイスごとに異なるためです。最大 50 件まで保存できます。

<Callout title="Firefox">
Firefox では、ポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。
</Callout>
