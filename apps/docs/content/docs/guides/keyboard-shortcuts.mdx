---
title: Keyboard shortcuts
description: Search, move through folders, save the current page, and work the manager's table without the mouse.
---

Shortcuts in the popup and side panel never use `Ctrl` or `Cmd`, so the browser's own shortcuts with those keys, such as opening a new tab or the address bar, keep working. The bookmarks manager replaces the browser's own, so it also takes that manager's `Cmd` shortcuts (`Ctrl` on Windows and Linux): select all, copy, cut, paste, undo, redo, and open in new tabs. Shortcuts pause while you type in a text field (`Esc` in the search box is the exception), while an input method is composing text, and while a dialog or menu is open.

## On any page

These work with no Bookmark Scout window open. Your browser owns them, so you can change or remove them in its shortcut settings; see [Save with a keyboard shortcut](/guides/save-and-organize#quick-save). In Chrome and Edge you can also give quick save the browser's bookmark key, <Shortcut id="browser.bookmark_page" />; see [Use the bookmark key for quick save](/guides/save-and-organize#ctrl-d).

| Key | Action |
| --- | --- |
| <Shortcut id="commands.quick-save" /> | Quick save the current page to the folder from **Quick Save Folder** |
| <Shortcut id="commands.ai-quick-save" /> | Quick save the current page to the folder AI suggests |

In the notification that follows, `Tab` reaches **Undo** and the other folders, and `Esc` closes it.

## Popup and side panel

Hover the search box for a reminder.

| Key | Action |
| --- | --- |
| <Shortcut id="popup.focus_search" /> | Focus the search box |
| `Esc` in the search box | Clear the search; press again to leave the box |
| `↓` in the search box | Move to the first folder |
| `Enter` in the search box | Save the current page into the first folder under **Save to folder**, which is highlighted; with no folder listed, keep the search in recent searches |
| <Shortcut id="popup.recent_searches" /> in the empty search box | Show recent searches; `↓` / `↑` pick one, `Enter` searches it, `Tab` reaches **Clear** |
| `↓` / `↑`, `Home` / `End` | Move between visible folders and bookmarks (`↑` on the first row returns to search) |
| `→` / `←` | Open or close a folder; on an open folder `→` moves to its first item, and `←` moves to the parent folder |
| `Enter` on a folder | Save the current page into that folder (a page already saved there is not duplicated) |
| `Enter` on a bookmark | Open it in a new tab |
| `Space` on a folder | Open or close it |

Press <Shortcut id="manager.show_help" />, or click the keyboard button in the header, to see this list in the manager. The keys follow Chrome's bookmark manager.

| Key | Action |
| --- | --- |
| <Shortcut id="manager.focus_filter" /> | Focus the search box |
| <Shortcut id="manager.parent_folder" /> | Go to the parent folder |
| `↓` / `↑`, `Home` / `End` | Move between rows and select the row; with `Shift`, extend the selection; with `Cmd` (`Ctrl` on Windows and Linux), move without selecting |
| <Shortcut id="manager.next_row" />, <Shortcut id="manager.previous_row" /> | Move to the next or previous row |
| `Space` | Select or unselect the focused row |
| <Shortcut id="manager.preview" /> | Preview the focused bookmark: its stored cover, address, folder, tags, and summary, with **Open in new tab**, **Copy**, and **Edit**; `Esc` closes it and returns to the row or card |
| <Shortcut id="manager.select_all" /> | Select every row the filters show, on every page |
| <Shortcut id="manager.clear_selection" /> | Clear the selection, or close a dialog or menu |
| <Shortcut id="manager.open" /> | Open the selected folder, or the selected bookmarks in tabs |
| <Shortcut id="manager.open_in_new_tabs" /> | Open the selection in new background tabs |
| <Shortcut id="manager.open_in_new_window" /> | Open the selection in a new window |
| <Shortcut id="manager.rename" /> | Edit the selected bookmark, or rename the folder |
| <Shortcut id="manager.delete" /> | Delete the selection |
| <Shortcut id="manager.undo" /> | Undo the last change |
| <Shortcut id="manager.redo" /> | Redo |

| <Shortcut id="manager.open_saved_searches" /> | Open saved searches |

With the mouse, as in the browser's own manager:

| Gesture | Action |
| --- | --- |
| <Shortcut id="mouse.select_toggle" /> | Add a row to the selection, or take it out |
| <Shortcut id="mouse.select_range" /> | Select every row from the last one clicked to this one |
| <Shortcut id="mouse.open_in_background" /> | Open a link in a new background tab (the browser's own) |

In the folder tree on the left, which is also one `Tab` stop:

| Key | Action |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Move between the folders shown |
| `→` / `←` | Open or close a folder; on an open folder `→` moves to its first subfolder, and on a closed one `←` moves to the parent folder |
| <Shortcut id="manager.open" />, or `Space` | Show the folder in the table |
| <Shortcut id="manager.rename" /> | Rename the folder |
| <Shortcut id="manager.delete" /> | Delete the folder |
| <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" /> | Copy or cut the folder |
| <Shortcut id="manager.paste" /> | Paste into the folder |

The table is one stop when you press `Tab`; the arrow keys move between its rows. Opening more than <SettingDefault path="behavior.links.confirm_open_above" /> tabs at once asks first; a folder opens the bookmarks directly inside it. In the table, focus the edge of a column header and press `←` or `→` to resize that column.

Keyboard shortcuts are covered by the Chromium and Edge automated tests, not by the Firefox ones.
