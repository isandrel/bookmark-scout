---
title: Keyboard shortcuts
description: Search, move through folders, save the current page, and work the manager's table without the mouse.
---

Shortcuts in the popup and side panel never use `Ctrl` or `Cmd`, so browser shortcuts such as `Ctrl/Cmd+L`, `T`, `W`, `N`, `R`, and `D` keep working. The bookmarks manager replaces the browser's own, so it also takes that manager's `Ctrl` shortcuts (`Cmd` on a Mac): select all, undo, redo, and open in new tabs. Shortcuts pause while you type in a text field (`Esc` in the search box is the exception), while an input method is composing text, and while a dialog or menu is open.

## On any page

These work with no Bookmark Scout window open. Your browser owns them, so you can change or remove them in its shortcut settings; see [Save with a keyboard shortcut](/guides/save-and-organize#quick-save).

| Key | Action |
| --- | --- |
| `Alt+Shift+S` (`⌥⇧S` on a Mac) | Quick save the current page to the folder from **Quick Save Folder** |
| `Alt+Shift+D` (`⌥⇧D` on a Mac) | Quick save the current page to the folder AI suggests |

In the notification that follows, `Tab` reaches **Undo** and the other folders, and `Esc` closes it.

## Popup and side panel

Hover the search box for a reminder.

| Key | Action |
| --- | --- |
| `/` | Focus the search box |
| `Esc` in the search box | Clear the search; press again to leave the box |
| `↓` in the search box | Move to the first folder |
| `Alt+↓` in the empty search box | Show recent searches; `↓` / `↑` pick one, `Enter` searches it, `Tab` reaches **Clear** |
| `↓` / `↑`, `Home` / `End` | Move between visible folders and bookmarks (`↑` on the first row returns to search) |
| `→` / `←` | Open or close a folder; on an open folder `→` moves to its first item, and `←` moves to the parent folder |
| `Enter` on a folder | Save the current page into that folder (a page already saved there is not duplicated) |
| `Enter` on a bookmark | Open it in a new tab |
| `Space` on a folder | Open or close it |

## Bookmarks manager

Press `?`, or click the keyboard button in the header, to see this list in the manager. The keys follow Chrome's bookmark manager; where a Mac differs, its key is second.

| Key | Action |
| --- | --- |
| `/` | Focus the title filter |
| `Backspace` or `Alt+↑` | Go to the parent folder |
| `↓` / `↑`, `Home` / `End` | Move between rows and select the row; with `Shift`, extend the selection; with `Ctrl` (`Cmd`), move without selecting |
| `j` / `k` | Move to the next or previous row |
| `Space` | Select or unselect the focused row |
| `Ctrl+A` / `Cmd+A` | Select every row the filters show, on every page |
| `Esc` | Clear the selection, or close a dialog or menu |
| `Enter` / `Cmd+O` | Open the selected folder, or the selected bookmarks in tabs |
| `Ctrl+Enter` / `Cmd+Enter` | Open the selection in new background tabs |
| `Shift+Enter` | Open the selection in a new window |
| `F2` / `Enter` | Edit the selected bookmark, or rename the folder |
| `Delete` / `Delete` or `Cmd+Backspace` | Delete the selection |
| `Ctrl+Z` / `Cmd+Z` | Undo the last change |
| `Ctrl+Y` or `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Redo |
| `s` | Open saved searches |
| `?` | Show the keyboard shortcuts |

The table is one stop when you press `Tab`; the arrow keys move between its rows. Opening more than 15 tabs at once asks first; a folder opens the bookmarks directly inside it. In the table, focus the edge of a column header and press `←` or `→` to resize that column.

Keyboard shortcuts are covered by the Chromium and Edge automated tests, not by the Firefox ones.
