두 도구 모두 북마크 관리자의 **도구** 사이드바에서 **데이터** 아래에 있습니다.

<Callout title="Firefox">
Firefox에서는 팝업의 **북마크 관리자 열기**로 관리자를 엽니다.
</Callout>

## 북마크 내보내기 [#export-bookmarks]

<Steps>
<Step>
**북마크 내보내기**에서 **형식**을 고릅니다: **HTML (Chrome)**, **JSON**, **Markdown**, **CSV**.
</Step>
<Step>
현재 폴더 또는 모든 북마크를 선택하고 **내보내기**를 클릭합니다.
</Step>
<Step>
파일에 개인 정보일 수 있는 값이 포함되면 먼저 검토 화면이 열립니다. **원본 내보내기**, **가려서 내보내기**, **취소** 중 하나를 선택하세요.
</Step>
</Steps>

검토 단계에서는 민감한 쿼리 매개변수, URL 프래그먼트 안의 토큰, 이메일이나 토큰처럼 보이는 값, URL 안의 사용자 이름이나 비밀번호를 찾습니다. 가려서 내보내기를 선택하면 내려받는 파일에서만 해당 값이 `REDACTED`로 바뀌며, 북마크 자체는 바뀌지 않습니다. 민감한 값이 없으면 바로 내려받습니다.

파일 관련 세부 사항:

- 파일 이름은 **파일 이름 접두사**(기본값 `bookmarks_`)로 시작하며, ASCII가 아닌 폴더 이름도 그대로 유지합니다.
- CSV 파일은 UTF-8 바이트 순서 표시(BOM)로 시작합니다. Folder 열은 폴더를 `/`로 연결하며, 폴더 이름 안의 `/`는 `\/`로, 백슬래시는 `\\`로 기록합니다.
- **날짜 포함**, **URL 포함**과 형식별 들여쓰기 크기는 [설정](/settings)의 **데이터** 탭에 있습니다.

태그와 요약은 북마크 내보내기에 포함되지 않습니다. 태그와 요약이 포함된 북마크를 AI 도구에 넘기려면 **AI 컨텍스트 패커**를 사용하세요. [AI 도구 설정](/guides/ai-tools#export-context-for-an-ai-chat)을 참고하세요.

## 북마크 가져오기 [#import-bookmarks]

<Steps>
<Step>
**북마크 가져오기**에서 **가져오기**를 클릭하고, 브라우저에서 내보낸 파일 같은 HTML 또는 JSON 북마크 파일을 선택합니다.
</Step>
<Step>
**가져오기 미리보기**를 검토합니다. 대상 폴더, 만들어지거나 건너뛸 북마크와 폴더의 수, 그리고 대상 폴더나 다른 북마크 위치, 같은 파일의 앞부분에 이미 있는 URL이 표시됩니다.
</Step>
<Step>
필요하면 **가져올 위치**를 바꿉니다. 처음에는 관리자에서 열려 있는 폴더로 설정됩니다.
</Step>
<Step>
**중복 항목** 처리 방법을 고릅니다: 어디든 이미 있는 북마크 건너뛰기, 대상 폴더에 이미 있는 북마크만 건너뛰기, 모두 가져오기.
</Step>
<Step>
**가져오기**를 클릭합니다. 만들어진 항목, 건너뛴 항목, 실패한 항목의 수가 메시지로 표시되며, 10초 동안 **실행 취소**할 수 있습니다.
</Step>
</Steps>

**가져오기**를 클릭하기 전에는 아무것도 쓰지 않습니다. 미리 보기가 열려 있는 동안 북마크가 바뀌면, 가져오기를 적용하지 않고 미리 보기를 새로 고칩니다.

## 설정 파일은 별도입니다 [#settings-files-are-separate]

설정 페이지 맨 아래의 **내보내기**와 **가져오기** 버튼은 Bookmark Scout의 설정을 JSON 파일로 저장하고 복원합니다. 북마크는 건드리지 않습니다.
