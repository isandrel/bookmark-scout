두 도구 모두 북마크 관리자의 **도구** 사이드바에서 **데이터** 아래에 있습니다.

<Callout title="Firefox">
Firefox에서는 팝업의 **북마크 관리자 열기**로 관리자를 엽니다.
</Callout>

## 북마크 내보내기 [#export-bookmarks]

<Steps>
<Step>
**북마크 내보내기**에서 **형식**을 고릅니다: **HTML (Chrome)**, **JSON**, **Markdown**, **CSV**.
</Step>
<Step>
현재 폴더 또는 모든 북마크를 선택하고 **내보내기**를 클릭합니다.
</Step>
<Step>
파일에 개인 정보일 수 있는 값이 포함되면 먼저 검토 화면이 열립니다. **원본 내보내기**, **가려서 내보내기**, **취소** 중 하나를 선택하세요.
</Step>
</Steps>

검토 단계에서는 민감한 쿼리 매개변수, URL 프래그먼트 안의 토큰, 이메일이나 토큰처럼 보이는 값, URL 안의 사용자 이름이나 비밀번호를 찾습니다. 가려서 내보내기를 선택하면 내려받는 파일에서만 해당 값이 `REDACTED`로 바뀌며, 북마크 자체는 바뀌지 않습니다. 민감한 값이 없으면 바로 내려받습니다.

파일 관련 세부 사항:

- 파일 이름은 **파일 이름 접두사**(기본값 `bookmarks_`)로 시작하며, ASCII가 아닌 폴더 이름도 그대로 유지합니다.
- CSV 파일은 UTF-8 바이트 순서 표시(BOM)로 시작합니다. Folder 열은 폴더를 `/`로 연결하며, 폴더 이름 안의 `/`는 `\/`로, 백슬래시는 `\\`로 기록합니다.
- Firefox에만 있는 구분선은 HTML(`<HR>`)과 JSON에 구분선으로 기록되고, 그 파일을 Firefox에서 가져오면 구분선으로 돌아옵니다. Markdown과 CSV에는 들어가지 않으며, 구분선이 없는 Chrome과 Edge에서는 가져올 때 제외되고 미리 보기에 그 수가 표시됩니다.
- **날짜 포함**, **URL 포함**과 형식별 들여쓰기 크기는 [설정](/settings)의 **데이터** 탭에 있습니다.

JSON으로 내보내면 각 북마크의 태그와 요약이 함께 저장됩니다. 그 파일을 가져오면 가져오기로 만들어지는 북마크에 태그와 요약이 적용되지만, 중복으로 건너뛴 북마크에는 적용되지 않습니다. HTML, Markdown, CSV 내보내기에는 포함되지 않습니다. 태그와 요약이 포함된 북마크를 AI 도구에 넘기려면 **AI 컨텍스트 패커**를 사용하세요. [AI 도구 설정](/guides/ai-tools#export-context-for-an-ai-chat)을 참고하세요.

## 북마크 가져오기 [#import-bookmarks]

<Steps>
<Step>
**북마크 가져오기**에서 **가져오기**를 클릭하고, 브라우저에서 내보낸 파일 같은 HTML 또는 JSON 북마크 파일을 선택합니다. 파일을 **북마크 가져오기** 카드에 놓아도 됩니다.
</Step>
<Step>
**가져오기 미리보기**를 검토합니다. 대상 폴더, 만들어지거나 건너뛸 북마크와 폴더의 수, 그리고 대상 폴더나 다른 북마크 위치, 같은 파일의 앞부분에 이미 있는 URL이 표시됩니다.
</Step>
<Step>
필요하면 **가져올 위치**를 바꿉니다. 처음에는 관리자에서 열려 있는 폴더로 설정됩니다.
</Step>
<Step>
**중복 항목** 처리 방법을 고릅니다: 어디든 이미 있는 북마크 건너뛰기, 대상 폴더에 이미 있는 북마크만 건너뛰기, 모두 가져오기.
</Step>
<Step>
**가져오기**를 클릭합니다. 만들어진 항목, 건너뛴 항목, 실패한 항목의 수가 메시지로 표시되며, 10초 동안 **실행 취소**할 수 있습니다. 실행 취소는 가져온 그대로 남아 있는 항목만 지웁니다. 그 뒤에 이름을 바꾸거나 옮기거나 태그를 바꾸거나 항목을 추가한 가져온 항목은 그대로 남고, 메시지에서 유지한 항목으로 셉니다.
</Step>
</Steps>

**가져오기**를 클릭하기 전에는 아무것도 쓰지 않습니다. 미리 보기가 열려 있는 동안 북마크가 바뀌면, 가져오기를 적용하지 않고 미리 보기를 새로 고칩니다.

## 설정 백업과 복원 [#back-up-and-restore-settings]

설정 페이지 맨 아래의 **설정 백업**과 **설정 복원** 버튼은 Bookmark Scout 자체 데이터를 백업 파일로 저장하고 복원합니다. 북마크, 태그, 요약은 절대 건드리지 않습니다. 북마크는 위의 도구로 내보내세요. 백업 파일을 설정 페이지 아무 곳에나 놓아도 복원됩니다.

### 백업에 담기는 것 [#what-a-backup-holds]

**설정 백업**은 백업의 항목을 나열하고, 각 항목에 무엇이 들었는지, 몇 개인지, 대략 얼마나 큰지 보여 줍니다. 원하는 항목을 선택하거나 **모두 선택**과 **모두 해제**를 사용하세요.

- **이 화면을 표지로 사용**으로 고른 표지가 우선합니다. 파일에 있는 더 새로운, 역시 직접 고른 표지로만 바뀌고, 파일에 있는 직접 고른 표지는 직접 고르지 않은 표지를 바꿉니다. 그 밖에는 더 새로운 표지가 이깁니다. 미래 날짜는 오늘로 칩니다. **표지 저장 공간**은 그대로 적용되어, 넘치면 오래된 표지부터 삭제되고 직접 고른 표지는 마지막에 삭제됩니다.
- **설정**: 변경한 설정 중 동기화되는 설정. 메뉴와 목록도 포함됩니다.
- **이 컴퓨터의 설정**: 레이아웃, 사이드바, 키보드 키, 빠른 저장 폴더처럼 컴퓨터 한 대에 맞춰 보관하는 설정. 화면과 키보드 하나에 맞춘 것이라 처음에는 선택되지 않습니다.
- **저장된 검색과 표 보기**, **프롬프트와 내 소개**, **스마트 규칙**, **AI 서비스**(이름, 제공업체, 모델, 기본 URL, 제공업체별 항목).
- **표지**(**큰 용량** 표시): 주소별 표지 이미지. 표지는 동기화되지 않고 북마크 내보내기에도 들어가지 않으므로, 다른 컴퓨터로 옮기려면 백업을 사용합니다.
- **AI 서비스 키**: API 키와 추가 헤더. 직접 선택하지 않으면 절대 선택되지 않습니다. 선택하면 파일을 가진 사람은 누구나 키를 사용해 요금을 발생시킬 수 있다는 경고가 나오고, 저장하기 전에 확인해야 합니다.

저장한 항목은 이 컴퓨터에서 다음번 선택이 됩니다([설정](/settings#data)의 **새 백업에 포함할 항목**). 파일 이름에는 `bookmark-scout-backup_2026-10-23_all.json`처럼 날짜와 항목이 들어가며, 파일은 컴퓨터에 저장되고 어디에도 보내지 않습니다.

### 비밀번호 보호 [#password-protection]

- **AI 서비스 키**를 선택하면 **API 키를 비밀번호로 보호**가 켜진 상태로 시작합니다. 끄려면 키를 일반 텍스트로 읽을 수 있게 된다는 점을 확인해야 합니다.
- **이 백업을 비밀번호로 보호**는 모든 항목을 암호화합니다. 설정의 **새 백업을 비밀번호로 보호**를 켜면 처음부터 켜진 상태로 시작합니다.
- 비밀번호는 12자 이상이어야 합니다. 비밀번호는 저장되지 않으며, 잊어버리면 복구할 수 없습니다. 비밀번호 없이는 Bookmark Scout를 포함해 누구도 보호된 항목을 열 수 없습니다.
- 항목 목록은 읽을 수 있는 상태로 남으므로, **설정 복원**은 비밀번호를 묻기 전에 파일에 무엇이 들었는지 보여 줍니다. 비밀번호가 틀리거나 저장한 뒤 파일이 바뀌었으면 보호된 항목에서는 아무것도 가져오지 않습니다.

### 복원하기 [#restoring]

1. **설정 복원**을 클릭하고 파일을 고릅니다. 아직 아무것도 바뀌지 않습니다.
2. 각 항목에 파일에 든 개수와, 가져오면 추가, 변경, 그대로 유지될 개수가 표시됩니다. 더 새로운 버전의 Bookmark Scout에서 만든 항목은 지원되지 않는다고 표시되고 건너뜁니다. 보호된 항목을 열려면 비밀번호를 입력하세요.
3. 가져올 항목을 고릅니다. **이 컴퓨터의 설정**과 **AI 서비스 키**는 처음에 선택되어 있지 않으며, 키는 다시 확인을 요청합니다.
4. 항목마다 **병합**(파일에 있는 것을 추가하고 업데이트하며, 이 기기에만 있는 것은 유지) 또는 **교체**(항목을 파일과 똑같이 만들어 이 기기에만 있는 것을 제거, 먼저 확인을 요청)를 고릅니다.
5. 병합하면 여기와 파일 양쪽에서 바뀐 항목(프롬프트, 스마트 규칙, 저장된 검색, AI 서비스)이 나열됩니다. 전체 또는 하나씩 더 새로운 것을 유지할지, 파일의 것을 사용할지, 이 기기의 것을 유지할지 고르세요. **이 화면을 표지로 사용**으로 고른 표지는 파일에 있는 더 새로운, 역시 직접 고른 표지로만 바뀝니다.
6. **가져오기**를 클릭합니다. 결과에 각 항목이 추가, 변경, 제거, 유지, 건너뛴 것이 나옵니다. 파일에 키가 없던 AI 서비스는 [AI](/settings#ai)에서 키를 입력할 때까지 **설정 필요**로 표시됩니다.

### 가져오기 실행 취소 [#undo-import]

Bookmark Scout는 가져오기 전에 가져오기로 바뀌는 내용의 안전 사본을 24시간 동안 보관합니다. 결과 화면과 설정 맨 아래의 **가져오기 실행 취소**를 누르면 표지를 포함해 모두 되돌립니다. 가져오기는 북마크 관리자의 **북마크 기록**(필터 **백업**)에도 각 항목과 개수와 함께 나오며, 그곳의 **가져오기 실행 취소**도 같은 일을 합니다. 24시간이 지나거나 다른 백업을 복원하면 기록은 남지만, 더 이상 실행 취소할 수 없는 이유가 표시됩니다.

항목 구분이 생기기 전의 오래된 백업 파일도 복원할 수 있습니다.
