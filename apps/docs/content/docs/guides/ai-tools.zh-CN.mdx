AI 功能**默认关闭**，不使用 AI 也能使用 Bookmark Scout 的全部功能。开启后，请求会使用你自己的 API 密钥，从你的浏览器直接发送给你选择的服务商。Bookmark Scout 没有自己的 AI 服务。

<Callout type="warn" title="开启 AI 之前">
AI 工具会将书签标题、网址以及文件夹名称或路径发送给你配置的服务商。服务商会按照其自身的条款处理这些数据，并且使用 API 可能会产生费用。请在应用每条建议之前先进行审阅。
</Callout>

## 开启 AI [#turn-on-ai]

<Steps>
<Step>
打开 Bookmark Scout 的设置（在 Chrome 中，右键点击工具栏图标并选择**选项**），然后转到 **AI** 标签页。
</Step>
<Step>
开启 **AI 功能**。
</Step>
<Step>
在 **AI 服务**下，打开已有的服务，或点击**添加服务**并选择一个服务商。选择器带有搜索框，并将服务商分为**推荐**、**本地服务器**、**自定义**和**更多服务商（models.dev）**，共四组。然后选择 **AI 模型**。
</Step>
<Step>
如果服务商需要，请输入你的 **API 密钥**。离开该输入框时密钥即会保存，并且只存储在本设备上。不符合服务商格式的密钥会被拒绝，也不会保存。
</Step>
<Step>
可选：点击**刷新模型**加载服务商当前的模型列表，或点击**验证服务**检查服务商是否可以访问、是否接受该密钥以及是否提供所选模型。两者都会读取服务商的模型列表，不产生任何费用；只有对于没有模型列表的服务商（例如 Azure OpenAI），验证才会发送一条简短的测试提示词。首次使用时，浏览器会请求访问该服务商的地址。刷新后的列表会保留在模型选择器中，直到你再次刷新。
</Step>
</Steps>

<Screenshot name="options-ai" />

设置会自动保存。AI 服务及其 API 密钥、**API 地址**和**额外请求头 JSON** 都保存在此浏览器的本地存储中，永远不会同步。其他 AI 设置（例如 AI 是否开启）会在浏览器支持的情况下通过你的浏览器账号同步。

## 使用多个服务 [#use-more-than-one-service]

你可以保存任意数量的服务，甚至可以为同一个服务商保存多个服务：例如一个工作用代理和一个家用代理，各自使用自己的密钥、地址和模型。

- 所有 AI 工具都使用**默认**服务。在某个服务的菜单中选择**设为默认**；如果开启了多个服务，也可以通过弹出窗口中星光按钮旁的箭头选择一个。
- 使用服务的开关将其关闭，即可在弹出窗口中隐藏该服务而不删除它。
- **创建副本**会复制一个服务，包括其密钥。**删除**会从本设备中移除该服务及其密钥。
- **API 地址**、**额外请求头 JSON** 以及服务商专用的字段（例如 OpenAI 的组织）都位于**更多设置**下。

**AI 服务商**选择器带有搜索框。额外的服务商来自扩展程序随附的开放 [models.dev](https://models.dev) 目录副本，因此选择其中一个时不会向 models.dev 发送任何内容；请求只会发送给你选择的服务商。

**API 地址**会替换每个请求所用的服务商地址，例如用于通过代理访问。它必须以 `http://` 或 `https://` 开头。**额外请求头 JSON** 会为每个请求添加请求头，**自定义模型**则为接受任意模型名称的服务商设置模型 ID。

### 本地服务器 [#local-servers]

本地服务器必须接受来自扩展程序的请求：

- **Ollama**：设置 `OLLAMA_ORIGINS=chrome-extension://*,moz-extension://*` 并重启 Ollama。如果不设置，Ollama 会返回 403，验证结果会提示服务器拒绝了扩展程序。
- **LM Studio**：在服务器设置中开启 **Enable CORS**，或使用 `lms server start --cors` 启动它。
- **LocalAI**：请设置 API 密钥；它的 CSRF 检查会拒绝来自浏览器的无密钥请求。
- **text-generation-webui**：使用 `--api` 启动它。
- **CLIProxyAPI**：按默认配置即可接受扩展程序的请求。请在点击**验证服务**之前启动它；如果它没有运行，验证结果会提示无法连接到 `localhost:8317`。

### 检查失败时 [#when-a-check-fails]

验证和刷新会指出可能的原因：密钥被拒绝（401，或 Google 和 xAI 返回的 400）、API 地址错误（404）、服务商正在限制请求频率（429，这仍表示密钥有效）、服务器拒绝了扩展程序的来源、8 秒内没有响应，或该地址未提供服务商 API。

## 编写自己的提示词 [#write-your-own-prompts]

每个 AI 工具一开始都使用内置提示词。如需更改某个工具的行为，请依次前往**选项**、**AI 工具**、**提示词**：

1. 如需先阅读某个工具的内置提示词，请点击其旁边的眼睛图标。在这里或在查看器中点击**自定义**，编辑器会打开，并以内置提示词作为起点。
2. 编辑文本。点击 `{{maxTags}}` 等变量即可插入；工具会根据你的设置填入相应的值。**使用当前设置预览**会显示结果。
3. 点击**保存提示词**。新的提示词会成为该工具的提示词。

每个工具可以保留任意数量的提示词，并通过工具的菜单在它们之间切换；选择**默认（内置）**，即可恢复为原始提示词。你的提示词会通过浏览器账号在你的各个设备间同步，因此每个提示词都必须小于 7 KB。Bookmark Scout 会在你的提示词后面附加自己的输出格式规则，因此即使你的提示词要求其他格式，结果仍能正常加载。

## 每个工具发送的内容 [#what-each-tool-sends]

| 工具 | 位置 | 发送给服务商的内容 |
| --- | --- | --- |
| 文件夹推荐 | 弹出窗口中搜索框旁的星光按钮（仅在 AI 开启时显示） | 当前网页的标题和网址，以及你的书签文件夹名称。开启**读取网页内容**后，还包括网页正文 |
| **自动标签** | 书签管理器 > 工具 > **AI 与智能** | 当前文件夹中书签的标题、网址和文件夹路径；开启**读取网页内容**后，还包括每个网页的正文 |
| **内容摘要** | 书签管理器 > 工具 > **AI 与智能** | 当前文件夹中书签的标题、网址和文件夹路径；开启**读取网页内容**后，还包括每个网页的正文 |
| **AI 文件夹重组** | 书签管理器 > 工具 > **AI 与智能** | 你所选范围内书签的标题、网址和文件夹路径 |
| **询问 AI** | 弹出窗口和侧边栏中搜索框旁的聊天按钮（仅在 AI 开启时显示） | 你的消息和目前为止的对话内容，以及它查找的内容：匹配的书签、文件夹名称、当前网页的标题和网址；开启**读取网页内容**后，还包括它读取的网页文本 |
| **AI 上下文打包** | 书签管理器 > 工具 > **AI 与智能** | 不发送任何内容。它会在你的电脑上保存一个文件，在 AI 关闭时也能使用。 |

开启**打开时自动推荐**后，每次打开弹出窗口时都会请求文件夹推荐。保持关闭则只在你点击按钮时才发送请求。

## 读取网页内容 [#read-page-content]

标题和网址并不总能说明网页的内容。在**选项** > **AI** 中开启**读取网页内容**后，文件夹推荐、**自动标签**和**内容摘要**还会发送每个网页的正文。开启时会请求网站访问权限；如果你拒绝，此项将保持关闭。

- Bookmark Scout 会自行下载每个网页，且不携带你的 Cookie，因此获取的是网站未登录状态下的版本。它只保留文章正文，不包括菜单、脚本、图片或链接地址。
- 每个网页最多发送约 3,000 个字符，每次运行工具最多读取 40 个网页。大型文件夹中靠后的书签只会发送标题和网址，无法加载的网页也是如此。
- 永远不会读取你本地网络中的网页，例如 `localhost`、私有 IP 地址和 `.local` 名称，因此内网网页不会被发送到云端服务商。
- 网页文本来自网络，可能包含针对 AI 的指令。Bookmark Scout 会告诉模型仅将其视为数据，并且每条建议在保存前仍需经过你的审阅。

## 询问 AI [#ask-ai]

点击弹出窗口或侧边栏中搜索框旁的聊天按钮，即可询问有关你的书签、当前所在网页或任何其他内容的问题。它使用你的默认 AI 服务；可通过其顶部的菜单切换服务。

- 为了回答问题，AI 可以搜索你的书签、列出你的文件夹、查看当前网页，并在开启**读取网页内容**后读取网页。它只能读取，永远不会添加、移动或删除书签。它执行的每一步都会显示在对话中。
- OpenAI、Anthropic、Google Gemini 和 xAI 还可以搜索网络。使用消息框旁的地球按钮开启此功能；在你开启之前它会保持关闭，并且搜索由服务商自行执行。
- 对话只在聊天打开期间保留。**新对话**会清除对话，关闭弹出窗口则会结束对话。
- 它遵循的指令是提示词库中的**询问 AI** 提示词，因此你可以像查看或替换其他提示词一样查看或替换它。

## 查看发送的内容 [#see-what-was-sent]

如需准确查看某个工具发送了什么以及服务商返回了什么，请前往**选项** > **AI**，在 **AI 活动记录**下开启**记录请求**。之后每次 AI 调用都会显示其来源、地址、状态和时间；打开某条记录可查看请求头以及请求和响应正文，也可以将其复制为 JSON 用于错误报告。

记录功能默认关闭。日志保存在本设备上，并且只保留最近的调用。API 密钥、名称表明是凭据的请求头（例如包含 `key`、`token`、`secret`、`auth` 或 `cookie` 的请求头），以及你在**额外请求头 JSON** 中设置的所有请求头，都会在存储前被替换为 `[redacted]`，但请求中的书签标题和网址会被保留，因此用完后请关闭记录功能：关闭时也会删除日志。

## 使用文件夹推荐保存网页 [#save-a-page-with-a-folder-recommendation]

点击弹出窗口中的星光按钮。选择推荐的现有文件夹会将网页保存到该文件夹。选择推荐的新文件夹会打开**确认新文件夹**，其中显示完整路径和该网页；**创建文件夹并保存**只会创建缺少的文件夹并保存网页。如果网页已在该文件夹中，则不会重复保存；如果路径中的某个文件夹名称已被某个书签使用，则不会创建任何内容。**取消**不会做任何更改。

## 建议标签和摘要 [#suggest-tags-and-summaries]

使用**分析**运行**自动标签**或**内容摘要**。建议会显示出来供你审阅，只有在你点击**保存建议的标签**或**保存建议的摘要**后才会保存。**合并方式**决定保存的建议是追加到你已有的内容之后，还是替换已有内容。

已保存的标签和摘要存放在此浏览器的本地存储中。你也可以在**书签详情**中手动修改它们。它们不会同步，不可搜索，也不会包含在书签导出文件中。

设置中的标签数量和样式、摘要长度以及重组限制会作为指令发送给服务商；不会检查服务商的输出是否遵守这些限制。

## 重组文件夹 [#reorganize-folders]

**AI 文件夹重组**会询问服务商每个书签应归入哪个文件夹。开启**始终先预览**（默认开启）时，方案会以书签移动列表的形式打开，移入新文件夹的操作会单独标记并计数；在你点击**应用更改**之前，不会做任何更改。

- **应用更改**会移动书签，并创建方案中指定的新文件夹。如果同一位置已存在同名文件夹，则会改用该文件夹。
- 预览后被你移动、更改了网址或删除的书签会被跳过并留在原处，因此方案永远不会覆盖较新的更改。当方案只应用了一部分时，消息会统计已移动的书签、新文件夹以及跳过和失败的项目，并列出被跳过的书签名称。
- 点击消息中或审阅界面中的**撤消**，可将书签移回原处，并移除仍为空的新文件夹。在此期间被你再次移动过的书签会留在你放置的位置。

## 导出供 AI 对话使用的上下文 [#export-context-for-an-ai-chat]

**AI 上下文打包**会将所选书签导出为 Markdown 或 XML，你可以将其粘贴到任何 AI 对话中。导出内容可以包含文件夹路径、日期以及你已保存的标签和摘要（**包含已保存的标签**和**包含已保存的摘要**）。与书签导出一样，如果文件中会包含可能涉及隐私的值，它会打开隐私检查界面。

<Callout title="Firefox">
在 Firefox 中，请通过工具栏弹出窗口中的**打开书签管理器**打开书签管理器，以使用其中的 AI 工具。Firefox 自动化测试未覆盖 AI 功能。
</Callout>
