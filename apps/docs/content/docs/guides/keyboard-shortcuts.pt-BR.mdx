---
title: Atalhos de teclado
description: Pesquise, navegue entre as pastas, salve a página atual e use a tabela do gerenciador sem o mouse.
---

Os atalhos do pop-up e do painel lateral nunca usam `Ctrl` nem `Cmd`, então os atalhos do próprio navegador com essas teclas, como abrir uma nova guia ou ir para a barra de endereço, continuam funcionando. O gerenciador de favoritos substitui o do próprio navegador, então também assume os atalhos com `Cmd` desse gerenciador (`Ctrl` no Windows e no Linux): selecionar tudo, copiar, recortar, colar, desfazer, refazer e abrir em novas guias. Os atalhos ficam pausados enquanto você digita em um campo de texto (`Esc` na caixa de pesquisa é a exceção), enquanto um método de entrada está compondo texto e enquanto uma caixa de diálogo ou um menu está aberto.

## Em qualquer página [#on-any-page]

Estes atalhos funcionam sem nenhuma janela do Bookmark Scout aberta. Eles pertencem ao navegador, então você pode alterá-los ou removê-los nas configurações de atalhos dele; consulte [Salvar com um atalho de teclado](/guides/save-and-organize#quick-save). No Chrome e no Edge, você também pode atribuir ao salvamento rápido a tecla de favoritos do navegador, <Shortcut id="browser.bookmark_page" />; consulte [Usar a tecla de favoritos para salvar rapidamente](/guides/save-and-organize#ctrl-d).

| Tecla | Ação |
| --- | --- |
| <Shortcut id="commands.quick-save" /> | Salvar rapidamente a página atual na pasta definida em **Pasta de salvamento rápido** |
| <Shortcut id="commands.ai-quick-save" /> | Salvar rapidamente a página atual na pasta sugerida pela IA |

Na notificação que aparece em seguida, `Tab` chega a **Desfazer** e às outras pastas, e `Esc` a fecha.

## Pop-up e painel lateral [#popup-and-side-panel]

Passe o cursor sobre a caixa de pesquisa para ver um lembrete.

| Tecla | Ação |
| --- | --- |
| <Shortcut id="popup.focus_search" /> | Ir para a caixa de pesquisa |
| `Esc` na caixa de pesquisa | Limpar a pesquisa; pressione de novo para sair da caixa |
| `↓` na caixa de pesquisa | Ir para a primeira pasta |
| `Enter` na caixa de pesquisa | Salvar a página atual na primeira pasta de **Salvar na pasta**, que fica destacada; sem nenhuma pasta, a pesquisa fica nas pesquisas recentes |
| <Shortcut id="popup.recent_searches" /> na caixa de pesquisa vazia | Mostrar as pesquisas recentes; `↓` / `↑` escolhem uma, `Enter` pesquisa a escolhida, `Tab` chega a **Limpar** |
| `↓` / `↑`, `Home` / `End` | Navegar entre as pastas e os favoritos visíveis (`↑` na primeira linha volta para a pesquisa) |
| `→` / `←` | Abrir ou fechar uma pasta; em uma pasta aberta, `→` vai para o primeiro item dela, e `←` vai para a pasta superior |
| `Enter` em uma pasta | Salvar a página atual nessa pasta (uma página já salva lá não é duplicada) |
| `Enter` em um favorito | Abri-lo em uma nova guia |
| `Space` em uma pasta | Abri-la ou fechá-la |

| <Shortcut id="manager.select_all" /> | Selecionar todas as linhas que os filtros mostram, em todas as páginas |
| <Shortcut id="manager.clear_selection" /> | Limpar a seleção, ou fechar uma caixa de diálogo ou um menu |
| <Shortcut id="manager.open" /> | Abrir a pasta selecionada, ou os favoritos selecionados em guias |

Com o mouse, como no gerenciador do próprio navegador:

| Gesto | Ação |
| --- | --- |
| <Shortcut id="mouse.select_toggle" /> | Adicionar uma linha à seleção ou tirá-la |
| <Shortcut id="mouse.select_range" /> | Selecionar todas as linhas desde a última clicada até esta |
| <Shortcut id="mouse.open_in_background" /> | Abrir um link em uma nova guia em segundo plano (recurso do navegador) |

Na árvore de pastas à esquerda, que também é uma única parada de `Tab`:

| Tecla | Ação |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Navegar entre as pastas mostradas |
| `→` / `←` | Abrir ou fechar uma pasta; em uma pasta aberta, `→` vai para a primeira subpasta dela e, em uma pasta fechada, `←` vai para a pasta superior |
| <Shortcut id="manager.open" />, ou `Space` | Mostrar a pasta na tabela |
| <Shortcut id="manager.rename" /> | Renomear a pasta |
| <Shortcut id="manager.delete" /> | Excluir a pasta |
| <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" /> | Copiar ou recortar a pasta |
| <Shortcut id="manager.paste" /> | Colar dentro da pasta |

A tabela é uma única parada quando você pressiona `Tab`; as teclas de seta navegam entre as linhas dela. Abrir mais de <SettingDefault path="behavior.links.confirm_open_above" /> guias de uma vez pede confirmação antes; uma pasta abre os favoritos que estão diretamente dentro dela. Na tabela, coloque o foco na borda do cabeçalho de uma coluna e pressione `←` ou `→` para redimensionar essa coluna.

Os atalhos de teclado são cobertos pelos testes automatizados do Chromium e do Edge, não pelos do Firefox.
