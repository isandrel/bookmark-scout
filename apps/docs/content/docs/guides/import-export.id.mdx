Kedua alat ini ada di bilah samping **Alat** di pengelola bookmark, di bawah **Data**.

<Callout title="Firefox">
Di Firefox, buka pengelola dengan **Buka pengelola bookmark** di popup.
</Callout>

## Mengekspor bookmark [#export-bookmarks]

<Steps>
<Step>
Di **Ekspor Bookmark**, pilih **Format**: **HTML (Chrome)**, **JSON**, **Markdown**, atau **CSV**.
</Step>
<Step>
Pilih folder saat ini atau semua bookmark, lalu klik **Ekspor**.
</Step>
<Step>
Jika file akan berisi nilai yang mungkin bersifat pribadi, tinjauan terbuka lebih dulu. Pilih **Ekspor asli**, **Ekspor yang disamarkan**, atau **Batal**.
</Step>
</Steps>

Tinjauan ini mencari parameter kueri yang sensitif, token di fragmen URL, nilai yang mirip email dan token, serta nama pengguna atau sandi di dalam URL. Ekspor yang disamarkan mengganti nilai-nilai itu dengan `REDACTED` hanya di file yang diunduh; bookmark Anda tidak berubah. Ekspor tanpa data sensitif langsung diunduh.

Detail file:

- Nama file diawali dengan **Awalan Nama File** (default `bookmarks_`) dan mempertahankan nama folder non-ASCII.
- File CSV diawali dengan byte order mark UTF-8. Kolom Folder menggabungkan folder dengan `/`, dan menulis `/` di dalam nama folder sebagai `\/` serta garis miring terbalik sebagai `\\`.
- Pemisah, yang hanya ada di Firefox, ditulis sebagai pemisah di HTML (`<HR>`) dan JSON dan kembali menjadi pemisah saat Anda mengimpor file itu di Firefox. Markdown dan CSV tidak menyertakannya, dan Chrome serta Edge, yang tidak punya pemisah, tidak menyertakannya saat impor; pratinjau menghitungnya.
- **Sertakan Tanggal** dan **Sertakan URL**, serta ukuran indentasi untuk setiap format, ada di tab **Data** di [Setelan](/settings).

Ekspor JSON menyertakan tag dan ringkasan setiap bookmark, dan mengimpor file itu memberikannya ke bookmark yang dibuatnya, tetapi tidak ke bookmark yang dilewati sebagai duplikat. Ekspor HTML, Markdown, dan CSV tidak menyertakannya. Untuk menyerahkan bookmark beserta tag dan ringkasannya ke alat AI, gunakan **Pengemas Konteks AI**; lihat [Menyiapkan alat AI](/guides/ai-tools#export-context-for-an-ai-chat).

## Mengimpor bookmark [#import-bookmarks]

<Steps>
<Step>
Di **Impor Bookmark**, klik **Impor** lalu pilih file bookmark HTML atau JSON, seperti file yang diekspor dari browser. Anda juga bisa melepas file ke kartu **Impor Bookmark**.
</Step>
<Step>
Tinjau **Pratinjau impor**. Pratinjau menampilkan folder tujuan, berapa bookmark dan folder yang akan dibuat atau dilewati, dan URL mana yang sudah ada di folder tujuan, di tempat lain di bookmark Anda, atau sebelumnya di file yang sama.
</Step>
<Step>
Ubah **Impor ke** jika perlu. Awalnya berisi folder yang terbuka di pengelola.
</Step>
<Step>
Pilih cara menangani **Duplikat**: lewati bookmark yang sudah ada di mana pun, lewati hanya yang sudah ada di folder tujuan, atau impor semuanya.
</Step>
<Step>
Klik **Impor**. Sebuah pesan mencantumkan berapa item yang dibuat, dilewati, dan gagal, dengan **Urungkan** selama 10 detik. Urungkan hanya menghapus apa yang masih persis seperti hasil impor: item hasil impor yang sejak itu Anda ganti namanya, pindahkan, beri tag ulang, atau tambahi isinya tetap ada, dan pesannya menghitungnya sebagai dipertahankan.
</Step>
</Steps>

Tidak ada yang ditulis sampai Anda mengklik **Impor**. Jika bookmark Anda berubah selama pratinjau terbuka, pratinjau diperbarui alih-alih diterapkan.

## Mencadangkan dan memulihkan setelan [#back-up-and-restore-settings]

Tombol **Cadangkan setelan** dan **Pulihkan setelan** di bagian bawah halaman Setelan menyimpan dan memulihkan file cadangan berisi data milik Bookmark Scout sendiri. Keduanya tidak pernah menyentuh bookmark, tag, atau ringkasan Anda; ekspor bookmark dengan alat di atas. Anda juga bisa melepas file cadangan di mana saja di halaman Setelan untuk memulihkannya.

### Isi cadangan [#what-a-backup-holds]

**Cadangkan setelan** mencantumkan bagian-bagian cadangan, masing-masing dengan isinya, jumlah item, dan perkiraan ukurannya. Pilih yang Anda inginkan, atau gunakan **Pilih semua** dan **Kosongkan pilihan**:

- Sampul yang Anda pilih dengan **Gunakan tampilan ini sebagai sampul** diutamakan: sampul itu hanya diganti oleh sampul pilihan yang lebih baru dari file, dan sampul pilihan dari file mengganti sampul yang bukan pilihan; selain itu, yang lebih baru menang. Tanggal di masa depan dihitung sebagai hari ini. **Penyimpanan Sampul** tetap berlaku, jadi sampul terlama dihapus jika melewatinya, dan sampul pilihan paling akhir.
- **Setelan**: setelan yang Anda ubah dan ikut disinkronkan, termasuk menu dan daftar.
- **Setelan komputer ini**: setelan yang disimpan untuk satu komputer, seperti tata letak, bilah samping, tombol keyboard, dan folder simpan cepat. Tidak dipilih di awal, karena setelan ini cocok untuk satu layar dan keyboard.
- **Penelusuran tersimpan dan tampilan tabel**, **Prompt dan Tentang saya**, **Aturan Pintar**, dan **Layanan AI** (nama, penyedia, model, URL Dasar, dan kolom khusus penyedia).
- **Sampul**, ditandai **Besar**: gambar sampul, menurut alamat. Sampul tidak pernah disinkronkan dan ekspor bookmark tidak memuatnya, jadi cadangan adalah cara membawanya ke komputer lain.
- **Kunci layanan AI**: kunci API dan header tambahan, tidak pernah dipilih kecuali Anda memilihnya. Memilihnya memunculkan peringatan bahwa siapa pun yang memiliki file itu dapat menggunakan kunci tersebut dan menimbulkan biaya, dan Anda mengonfirmasi sebelum menyimpan.

Bagian yang Anda simpan menjadi pilihan berikutnya di komputer ini (**Bagian dalam Cadangan Baru** di [Setelan](/settings#data)). Nama file berisi tanggal dan bagiannya, seperti `bookmark-scout-backup_2026-10-23_all.json`, dan file disimpan di komputer Anda; tidak ada yang dikirim ke mana pun.

### Perlindungan kata sandi [#password-protection]

- Saat **Kunci layanan AI** dipilih, **Lindungi kunci API dengan kata sandi** langsung aktif; menonaktifkannya meminta Anda mengonfirmasi bahwa kunci akan dapat dibaca sebagai teks biasa.
- **Lindungi cadangan ini dengan kata sandi** mengenkripsi setiap bagian. **Lindungi Cadangan Baru dengan Kata Sandi** di Setelan membuatnya aktif sejak awal.
- Kata sandi harus terdiri dari minimal 12 karakter. Kata sandi tidak pernah disimpan, dan kata sandi yang terlupa tidak dapat dipulihkan: tidak ada yang bisa membuka bagian yang dilindungi tanpanya, bahkan Bookmark Scout pun tidak.
- Daftar bagian tetap dapat dibaca, jadi **Pulihkan setelan** menampilkan isi file sebelum meminta kata sandi. Kata sandi yang salah, atau file yang diubah setelah disimpan, membuat tidak ada yang diimpor dari bagian yang dilindungi.

### Memulihkan [#restoring]

1. Klik **Pulihkan setelan** dan pilih file. Belum ada yang berubah.
2. Setiap bagian menampilkan berapa item di dalam file dan berapa yang akan ditambahkan, diubah, atau dibiarkan apa adanya jika diimpor. Bagian dari versi Bookmark Scout yang lebih baru dicantumkan sebagai tidak didukung dan dilewati. Masukkan kata sandi untuk membuka bagian yang dilindungi.
3. Pilih bagian yang akan diimpor. **Setelan komputer ini** dan **Kunci layanan AI** tidak dipilih di awal; kunci kembali meminta konfirmasi Anda.
4. Untuk setiap bagian, pilih **Gabungkan** (menambahkan dan memperbarui apa yang ada di file, mempertahankan apa yang hanya ada di perangkat ini) atau **Ganti** (membuat bagian itu persis seperti di file, menghapus apa yang hanya ada di perangkat ini; Anda mengonfirmasi lebih dulu).
5. Dengan Gabungkan, item yang diubah di sini dan juga di file (prompt, aturan pintar, penelusuran tersimpan, layanan AI) dicantumkan: pertahankan yang lebih baru, gunakan dari file, atau pertahankan milik perangkat ini, untuk semuanya sekaligus atau satu per satu. Sampul yang Anda pilih dengan **Gunakan tampilan ini sebagai sampul** hanya diganti oleh sampul pilihan yang lebih baru dari file.
6. Klik **Impor**. Hasilnya mencantumkan apa yang ditambahkan, diubah, dihapus, dipertahankan, dan dilewati oleh setiap bagian. Layanan AI yang kuncinya tidak ada di file menampilkan **Perlu disiapkan** sampai Anda memasukkannya di [AI](/settings#ai).

### Urungkan impor [#undo-import]

Sebelum mengimpor, Bookmark Scout menyimpan salinan pengaman dari apa yang diubah oleh impor, selama 24 jam. **Urungkan impor**, di hasil impor dan di bagian bawah Setelan, mengembalikan semuanya, termasuk sampul. Impor itu juga tercantum di **Histori bookmark** pengelola bookmark (filter **Cadangan**), dengan setiap bagian dan jumlahnya, dan **Urungkan impor** di sana melakukan hal yang sama. Setelah 24 jam, atau setelah Anda memulihkan cadangan lain, catatannya tetap ada tetapi menyebutkan mengapa Urungkan tidak lagi tersedia.

File cadangan lama, dari sebelum ada bagian, tetap bisa dipulihkan.
