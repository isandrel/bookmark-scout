title: 匯入和匯出
description: 經過隱私確認後將書籤匯出為 HTML、JSON、Markdown 或 CSV，並在顯示重複項目的預覽後匯入 HTML 或 JSON 檔案。
---

這兩項工具都位於書籤管理員「**工具**」側欄的「**資料**」下。

<Callout title="Firefox">
在 Firefox 中，請從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員。
</Callout>

## 匯出書籤 [#export-bookmarks]

<Steps>
<Step>
在「**匯出書籤**」中選擇「**格式**」：「**HTML (Chrome)**」、「**JSON**」、「**Markdown**」或「**CSV**」。
</Step>
<Step>
選擇目前資料夾或所有書籤，然後按一下「**匯出**」。
</Step>
<Step>
如果檔案中會包含可能屬於私人的值，系統會先開啟確認畫面。請選擇「**匯出原始內容**」、「**遮蔽後匯出**」或「**取消**」。
</Step>
</Steps>

確認時會尋找敏感的查詢參數、網址片段中的權杖、類似電子郵件地址和權杖的值，以及網址中的使用者名稱或密碼。遮蔽後匯出只會在下載的檔案中將這些值替換為 `REDACTED`；書籤本身不會變更。沒有敏感內容的匯出會直接下載。

檔案詳細資訊：

- 檔案名稱以「**檔案名稱前置字串**」(預設為 `bookmarks_`) 開頭，並保留非 ASCII 的資料夾名稱。
- CSV 檔案以 UTF-8 位元組順序標記 (BOM) 開頭。「資料夾」欄會以 `/` 連接資料夾，並將資料夾名稱中的 `/` 寫成 `\/`、反斜線寫成 `\\`。
- 只有 Firefox 才有的分隔線，在 HTML（`<HR>`）和 JSON 中會作為分隔線寫出，在 Firefox 中匯入該檔案時仍是分隔線。Markdown 和 CSV 不包含分隔線；沒有分隔線的 Chrome 和 Edge 在匯入時會略過它們，預覽會顯示數量。
- 「**包含日期**」和「**包含網址**」以及各格式的縮排大小，都位於「[設定](/settings)」的「**資料**」分頁中。

JSON 匯出檔案會包含每個書籤的標籤和摘要。匯入該檔案時，新建立的書籤會取得這些標籤和摘要，但因重複而略過的書籤不會。HTML、Markdown 和 CSV 匯出檔案不包含這些資料。如要將書籤連同標籤和摘要交給 AI 工具，請使用「**AI 脈絡打包工具**」；請參閱「[設定 AI 工具](/guides/ai-tools#export-context-for-an-ai-chat)」。

## 匯入書籤 [#import-bookmarks]

<Steps>
<Step>
在「**匯入書籤**」中按一下「**匯入**」，然後選擇 HTML 或 JSON 書籤檔案，例如從瀏覽器匯出的檔案。也可以把檔案拖放到「**匯入書籤**」卡片上。
</Step>
<Step>
確認「**匯入預覽**」。預覽會顯示目標資料夾、將建立或略過的書籤和資料夾數量，以及哪些網址已存在於目標資料夾中、書籤的其他位置，或同一個檔案中較前面的位置。
</Step>
<Step>
視需要變更「**匯入至**」。預設為書籤管理員中目前開啟的資料夾。
</Step>
<Step>
選擇如何處理「**重複項目**」：略過已存在於任何位置的書籤、只略過已在目標資料夾中的書籤，或全部匯入。
</Step>
<Step>
按一下「**匯入**」。訊息會列出已建立、已略過和失敗的項目數量，並提供 10 秒內可使用的「**復原**」。復原只會刪除仍與匯入時完全相同的項目：匯入後你改過名稱、移動過、改過標籤或在其中新增過內容的項目會保留，訊息中會計為保留。
</Step>
</Steps>

在你按一下「**匯入**」之前，不會寫入任何內容。如果書籤在預覽開啟期間有所變更，預覽會重新整理，而不會直接套用。

## 備份和還原設定 [#back-up-and-restore-settings]

設定頁面底部的「**備份設定**」和「**還原設定**」按鈕會將 Bookmark Scout 本身的資料儲存為備份檔案，或從備份檔案還原。這兩個按鈕絕不會影響你的書籤、標籤或摘要；要匯出書籤，請使用上方的工具。也可以把備份檔案拖放到設定頁面的任何位置來還原。

### 備份包含的內容 [#what-a-backup-holds]

「**備份設定**」會列出備份的各項內容，每項都顯示包含什麼、有多少項目，以及大約多大。選取你需要的內容，或使用「**全選**」和「**全部取消**」：

- 用「**將目前畫面設為封面**」選擇的封面優先：只會被檔案中較新的、同樣是手動選擇的封面取代；檔案中手動選擇的封面會取代不是手動選擇的封面；其他情況以較新的為準。未來的日期以今天計算。「**封面儲存空間**」仍然適用，超出時會從最舊的封面開始刪除，手動選擇的封面最後刪除。
- 「**設定**」：你變更過、會同步的設定，包括選單和清單。
- 「**這台電腦的設定**」：只為一台電腦保存的設定，例如版面配置、側邊欄、鍵盤按鍵和快速儲存資料夾。預設不選取，因為這些設定適合一台電腦的螢幕和鍵盤。
- 「**已儲存的搜尋和表格檢視**」、「**提示詞和「關於我」**」、「**智慧規則**」和「**AI 服務**」（名稱、供應商、模型、基礎網址和供應商專屬欄位）。
- 「**封面**」，標有「**較大**」：依網址保存的封面圖片。封面不會同步，書籤匯出也不包含封面，因此要把它們帶到另一台電腦，只能透過備份。
- 「**AI 服務金鑰**」：API 金鑰和額外標頭，除非你主動選取，否則絕不會選取。選取時會警告：任何拿到檔案的人都能使用這些金鑰並產生費用，儲存前需要你確認。

你儲存的內容會成為這台電腦上下次的選擇（[設定](/settings#data)中的「**新備份包含的內容**」）。檔案名稱包含日期和所選內容，例如 `bookmark-scout-backup_2026-10-23_all.json`，並儲存在你的電腦上；不會傳送到任何地方。

### 密碼保護 [#password-protection]

- 選取「**AI 服務金鑰**」時，「**用密碼保護 API 金鑰**」會預設開啟；關閉時會要求你確認金鑰將以純文字形式可供讀取。
- 「**用密碼保護這份備份**」會加密所有內容。設定中的「**用密碼保護新備份**」可讓它預設開啟。
- 密碼至少需要 12 個字元。密碼絕不會被儲存，忘記的密碼也無法找回：沒有密碼，任何人都無法開啟受保護的內容，Bookmark Scout 也不能。
- 內容清單仍可讀取，因此「**還原設定**」會先顯示檔案包含什麼，再要求輸入密碼。如果密碼錯誤，或檔案在儲存後遭到變更，受保護的內容一律不會匯入。

### 還原 [#restoring]

1. 按一下「**還原設定**」並選擇檔案。此時還不會有任何變更。
2. 每項內容都會顯示檔案中有多少項目，以及匯入後會新增、變更或維持不變的項目數。來自較新版本 Bookmark Scout 的內容會標示為不支援並略過。輸入密碼即可解鎖受保護的內容。
3. 選取要匯入的內容。「**這台電腦的設定**」和「**AI 服務金鑰**」預設不選取；選取金鑰時會再次要求你確認。
4. 為每項內容選擇「**合併**」（新增和更新檔案中的內容，保留只有這部裝置上有的內容）或「**取代**」（讓該項內容與檔案完全一致，移除只有這部裝置上有的內容；會先請你確認）。
5. 選擇合併時，會列出在這部裝置和檔案中都變更過的項目（提示詞、智慧規則、已儲存的搜尋、AI 服務）：可以對全部或逐項選擇保留較新的、使用檔案中的，或保留這部裝置的。用「**將目前畫面設為封面**」選擇的封面，只會被檔案中較新的、同樣是手動選擇的封面取代。
6. 按一下「**匯入**」。結果會列出每項內容新增、變更、移除、保留和略過了什麼。檔案中沒有金鑰的 AI 服務會顯示「**需要設定**」，直到你在「[AI](/settings#ai)」中輸入金鑰。

指定資料夾的設定（例如快速儲存資料夾）只有在這台電腦上有路徑相同的資料夾時才會還原，並指向那個資料夾；否則維持這台電腦上原本的設定。寫入任何內容之前會先檢查每項內容，無法完整匯入的那項內容會維持原樣。

### 復原匯入 [#undo-import]

匯入前，Bookmark Scout 會將匯入所變更內容的安全副本保留 24 小時。結果中和設定底部的「**復原匯入**」會將一切放回原狀，包括封面。這次匯入也會記錄在書籤管理員的「**書籤記錄**」中（篩選條件為「**備份**」），並顯示每項內容及其數量，那裡的「**復原匯入**」效果相同。24 小時後，或在你還原另一份備份之後，記錄仍會保留，但會說明為什麼不再提供復原。

分項備份推出之前的舊備份檔案仍然可以還原。
