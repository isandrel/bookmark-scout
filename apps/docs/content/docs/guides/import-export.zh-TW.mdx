title: 匯入和匯出
description: 經過隱私確認後將書籤匯出為 HTML、JSON、Markdown 或 CSV，並在顯示重複項目的預覽後匯入 HTML 或 JSON 檔案。
---

這兩項工具都位於書籤管理員「**工具**」側欄的「**資料**」下。

<Callout title="Firefox">
在 Firefox 中，請從彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員。
</Callout>

## 匯出書籤 [#export-bookmarks]

<Steps>
<Step>
在「**匯出書籤**」中選擇「**格式**」：「**HTML (Chrome)**」、「**JSON**」、「**Markdown**」或「**CSV**」。
</Step>
<Step>
選擇目前資料夾或所有書籤，然後按一下「**匯出**」。
</Step>
<Step>
如果檔案中會包含可能屬於私人的值，系統會先開啟確認畫面。請選擇「**匯出原始內容**」、「**遮蔽後匯出**」或「**取消**」。
</Step>
</Steps>

確認時會尋找敏感的查詢參數、網址片段中的權杖、類似電子郵件地址和權杖的值，以及網址中的使用者名稱或密碼。遮蔽後匯出只會在下載的檔案中將這些值替換為 `REDACTED`；書籤本身不會變更。沒有敏感內容的匯出會直接下載。

檔案詳細資訊：

- 檔案名稱以「**檔案名稱前置字串**」(預設為 `bookmarks_`) 開頭，並保留非 ASCII 的資料夾名稱。
- CSV 檔案以 UTF-8 位元組順序標記 (BOM) 開頭。「資料夾」欄會以 `/` 連接資料夾，並將資料夾名稱中的 `/` 寫成 `\/`、反斜線寫成 `\\`。
- 只有 Firefox 才有的分隔線，在 HTML（`<HR>`）和 JSON 中會作為分隔線寫出，在 Firefox 中匯入該檔案時仍是分隔線。Markdown 和 CSV 不包含分隔線；沒有分隔線的 Chrome 和 Edge 在匯入時會略過它們，預覽會顯示數量。
- 「**包含日期**」和「**包含網址**」以及各格式的縮排大小，都位於「[設定](/settings)」的「**資料**」分頁中。

JSON 匯出檔案會包含每個書籤的標籤和摘要。匯入該檔案時，新建立的書籤會取得這些標籤和摘要，但因重複而略過的書籤不會。HTML、Markdown 和 CSV 匯出檔案不包含這些資料。如要將書籤連同標籤和摘要交給 AI 工具，請使用「**AI 脈絡打包工具**」；請參閱「[設定 AI 工具](/guides/ai-tools#export-context-for-an-ai-chat)」。

## 匯入書籤 [#import-bookmarks]

<Steps>
<Step>
在「**匯入書籤**」中按一下「**匯入**」，然後選擇 HTML 或 JSON 書籤檔案，例如從瀏覽器匯出的檔案。也可以把檔案拖放到「**匯入書籤**」卡片上。
</Step>
<Step>
確認「**匯入預覽**」。預覽會顯示目標資料夾、將建立或略過的書籤和資料夾數量，以及哪些網址已存在於目標資料夾中、書籤的其他位置，或同一個檔案中較前面的位置。
</Step>
<Step>
視需要變更「**匯入至**」。預設為書籤管理員中目前開啟的資料夾。
</Step>
<Step>
選擇如何處理「**重複項目**」：略過已存在於任何位置的書籤、只略過已在目標資料夾中的書籤，或全部匯入。
</Step>
<Step>
按一下「**匯入**」。訊息會列出已建立、已略過和失敗的項目數量，並提供 10 秒內可使用的「**復原**」。復原只會刪除仍與匯入時完全相同的項目：匯入後你改過名稱、移動過、改過標籤或在其中新增過內容的項目會保留，訊息中會計為保留。
</Step>
</Steps>

在你按一下「**匯入**」之前，不會寫入任何內容。如果書籤在預覽開啟期間有所變更，預覽會重新整理，而不會直接套用。

## 設定檔案是分開的 [#settings-files-are-separate]

設定頁面底部的「**備份設定**」和「**還原設定**」按鈕會將 Bookmark Scout 的設定、自訂提示詞、AI 服務（不含 API 金鑰）和已儲存的搜尋儲存為備份檔案，或從備份檔案還原。這兩個按鈕不會影響書籤、標籤或摘要。備份包含的內容請參閱「[設定](/settings)」。也可以把備份檔案拖放到設定頁面的任何位置來還原。

### 備份中的封面 [#covers-in-a-backup]

封面不會同步，書籤匯出也不包含封面，因此要把它們帶到另一台電腦，只能透過備份。

- 存有封面時，「**備份設定**」會詢問是否「**包含封面**」，並顯示封面數量和檔案大約會增加多少。核取方塊預設勾選；可在[設定](/settings#data)中用「**在備份中包含封面**」變更。檔案中每個網址保存一張封面，從最新的開始，直到備份上限。
- 還原包含封面的備份時，會先顯示檢查結果：檔案中有多少封面，其中多少與這部裝置上網址相同的書籤相符、多少不相符，以及多少書籤會取得封面、封面被取代或保留自己的封面。取消勾選「**還原封面**」即可只還原備份的其餘部分。
- 用「**將目前畫面設為封面**」選擇的封面優先：只會被檔案中較新的、同樣是手動選擇的封面取代；檔案中手動選擇的封面會取代不是手動選擇的封面；其他情況以較新的為準。未來的日期以今天計算。「**封面儲存空間**」仍然適用，超出時會從最舊的封面開始刪除，手動選擇的封面最後刪除。
- 還原後無法撤銷。封面只會留在你儲存的檔案中，不會傳送到任何地方。
