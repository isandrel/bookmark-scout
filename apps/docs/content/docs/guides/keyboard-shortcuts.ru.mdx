---
title: Быстрые клавиши
description: Ищите, перемещайтесь по папкам, сохраняйте текущую страницу и работайте с таблицей диспетчера без мыши.
---

Сочетания клавиш во всплывающем окне и боковой панели никогда не используют `Ctrl` или `Cmd`, поэтому собственные сочетания браузера с этими клавишами, например открытие новой вкладки или адресной строки, продолжают работать. Диспетчер закладок заменяет собственный диспетчер браузера, поэтому он берёт на себя и его сочетания с `Cmd` (`Ctrl` в Windows и Linux): выделить всё, копировать, вырезать, вставить, отменить, повторить и открыть в новых вкладках. Сочетания клавиш не срабатывают, пока вы вводите текст в текстовое поле (исключение — `Esc` в поле поиска), пока метод ввода составляет текст и пока открыт диалог или меню.

Клавиши сочетаний всплывающего окна, боковой панели и диспетчера можно изменить в [Настройки > Поведение > Быстрые клавиши диспетчера и всплывающего окна](/settings#page-shortcuts); на этой странице перечислены исходные клавиши.

## На любой странице [#on-any-page]

Эти сочетания работают, даже когда ни одно окно Bookmark Scout не открыто. Ими управляет браузер, поэтому их можно изменить или удалить в настройках сочетаний клавиш браузера; см. [Сохранение с помощью сочетания клавиш](/guides/save-and-organize#quick-save). В Chrome и Edge можно также отдать быстрому сохранению клавишу закладки браузера, <Shortcut id="browser.bookmark_page" />; см. [Клавиша закладки для быстрого сохранения](/guides/save-and-organize#ctrl-d).

| Клавиши | Действие |
| --- | --- |
| <Shortcut id="commands.quick-save" /> | Быстро сохранить текущую страницу в папку из параметра **Папка для быстрого сохранения** |
| <Shortcut id="commands.ai-quick-save" /> | Быстро сохранить текущую страницу в папку, предложенную ИИ |

В появившемся уведомлении `Tab` переходит к **Отменить** и другим папкам, а `Esc` закрывает его.

## Всплывающее окно и боковая панель [#popup-and-side-panel]

Наведите указатель на поле поиска, чтобы увидеть подсказку.

| Клавиши | Действие |
| --- | --- |
| <Shortcut id="popup.focus_search" /> | Перейти в поле поиска |
| `Esc` в поле поиска | Очистить поиск; повторное нажатие выводит из поля |
| `↓` в поле поиска | Перейти к первой папке |
| `Enter` в поле поиска | Сохранить текущую страницу в первую папку в разделе **Сохранить в папку** (она выделена); если папок в списке нет — сохранить запрос в недавних запросах |
| <Shortcut id="popup.recent_searches" /> в пустом поле поиска | Показать недавние запросы; `↓` / `↑` выбирают запрос, `Enter` выполняет поиск, `Tab` переходит к **Очистить** |
| `↓` / `↑`, `Home` / `End` | Перемещаться между видимыми папками и закладками (`↑` на первой строке возвращает в поиск) |
| `→` / `←` | Раскрыть или свернуть папку; на раскрытой папке `→` переходит к её первому элементу, а `←` — к родительской папке |
| `Enter` на папке | Сохранить текущую страницу в эту папку (если страница там уже есть, дубликат не создаётся) |
| `Enter` на закладке | Открыть её в новой вкладке |
| `Space` на папке | Раскрыть или свернуть её |

## Диспетчер закладок [#bookmarks-manager]

Нажмите <Shortcut id="manager.show_help" /> или кнопку с клавиатурой в заголовке, чтобы увидеть этот список в диспетчере. Клавиши такие же, как в диспетчере закладок Chrome.

| Клавиши | Действие |
| --- | --- |
| <Shortcut id="manager.focus_filter" /> | Перейти в поле поиска |
| <Shortcut id="manager.parent_folder" /> | Перейти в родительскую папку |
| `↓` / `↑`, `Home` / `End` | Перемещаться между строками и выделять строку; с `Shift` — расширять выделение; с `Cmd` (`Ctrl` в Windows и Linux) — перемещаться без выделения |
| <Shortcut id="manager.next_row" />, <Shortcut id="manager.previous_row" /> | Перейти к следующей или предыдущей строке |
| `Space` | Выделить строку в фокусе или снять с неё выделение |
| <Shortcut id="manager.preview" /> | Предпросмотр закладки в фокусе: сохранённая обложка, адрес, папка, теги и краткое содержание, с кнопками **Открыть в новой вкладке**, **Копировать** и **Изменить**; `Esc` закрывает его и возвращает к строке или карточке |
| <Shortcut id="manager.preview_previous" />, <Shortcut id="manager.preview_next" /> | В предпросмотре показать предыдущую или следующую закладку на странице, пропуская папки (также кнопками со стрелками вверху); затем `Esc` возвращает к строке или карточке показанной закладки |
| <Shortcut id="manager.select_all" /> | Выделить все строки, показанные фильтрами, на всех страницах |
| <Shortcut id="manager.clear_selection" /> | Снять выделение или закрыть диалог или меню |
| <Shortcut id="manager.open" /> | Открыть выделенную папку или выделенные закладки во вкладках |
| <Shortcut id="manager.open_in_new_tabs" /> | Открыть выделение в новых фоновых вкладках |
| <Shortcut id="manager.open_in_new_window" /> | Открыть выделение в новом окне |
| <Shortcut id="manager.rename" /> | Изменить выделенную закладку или переименовать папку |
| <Shortcut id="manager.delete" /> | Удалить выделение |
| <Shortcut id="manager.undo" /> | Отменить последнее изменение |
| <Shortcut id="manager.redo" /> | Повторить |
| <Shortcut id="manager.copy" /> | Копировать выделение; его URL попадают в буфер обмена |
| <Shortcut id="manager.cut" /> | Вырезать выделение, чтобы переместить его вставкой |
| <Shortcut id="manager.paste" /> | Вставить после выделения или в конец папки; URL, скопированные в другом приложении, становятся закладками |
| <Shortcut id="manager.open_saved_searches" /> | Открыть сохранённые поиски |
| <Shortcut id="manager.show_help" /> | Показать быстрые клавиши |
| Клавиша контекстного меню или <Shortcut id="browser.context_menu" /> | Открыть контекстное меню строки или папки в фокусе |

Мышью, как в собственном диспетчере браузера:

| Жест | Действие |
| --- | --- |
| <Shortcut id="mouse.select_toggle" /> | Добавить строку в выделение или убрать её из него |
| <Shortcut id="mouse.select_range" /> | Выделить все строки от последней нажатой до этой |
| <Shortcut id="mouse.open_in_background" /> | Открыть ссылку в новой фоновой вкладке (стандартное поведение браузера) |

В дереве папок слева, которое тоже является одной остановкой клавиши `Tab`:

| Клавиши | Действие |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Перемещаться между показанными папками |
| `→` / `←` | Раскрыть или свернуть папку; на раскрытой папке `→` переходит к её первой вложенной папке, а на свёрнутой `←` переходит к родительской папке |
| <Shortcut id="manager.open" /> или `Space` | Показать папку в таблице |
| <Shortcut id="manager.rename" /> | Переименовать папку |
| <Shortcut id="manager.delete" /> | Удалить папку |
| <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" /> | Копировать или вырезать папку |
| <Shortcut id="manager.paste" /> | Вставить в папку |

Таблица — одна остановка при нажатии `Tab`; клавиши со стрелками перемещают между её строками. Если сразу открывается больше <SettingDefault path="behavior.links.confirm_open_above" /> вкладок, сначала появляется вопрос; папка открывает закладки, лежащие прямо в ней. В таблице переведите фокус на край заголовка столбца и нажмите `←` или `→`, чтобы изменить ширину столбца.

Быстрые клавиши покрыты автоматическими тестами Chromium и Edge, но не тестами Firefox.
