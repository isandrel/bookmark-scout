---
title: 鍵盤快速鍵
description: 不使用滑鼠即可搜尋、在資料夾之間移動、儲存目前網頁，以及操作書籤管理員的表格。
---

Bookmark Scout 的快速鍵一律不使用 `Ctrl` 或 `Cmd`，因此 `Ctrl/Cmd+L`、`T`、`W`、`N`、`R` 和 `D` 等瀏覽器快速鍵仍可正常使用。在文字欄位中輸入時 (搜尋框中的 `Esc` 除外)、輸入法正在組字時，以及對話方塊或選單開啟時，這些快速鍵會暫停作用。

## 彈出式視窗和側邊面板 [#popup-and-side-panel]

將游標移到搜尋框上即可查看提示。

| 按鍵 | 動作 |
| --- | --- |
| `/` | 將焦點移至搜尋框 |
| 在搜尋框中按 `Esc` | 清除搜尋；再按一次即可離開搜尋框 |
| 在搜尋框中按 `↓` | 移至第一個資料夾 |
| 在空白的搜尋框中按 `Alt+↓` | 顯示最近的搜尋；以 `↓` / `↑` 選擇、按 `Enter` 搜尋，按 `Tab` 可移至「**清除**」 |
| `↓` / `↑`、`Home` / `End` | 在顯示的資料夾和書籤之間移動 (在第一列按 `↑` 會回到搜尋框) |
| `→` / `←` | 展開或收合資料夾；在已展開的資料夾上按 `→` 會移至其第一個項目，按 `←` 則會移至上層資料夾 |
| 在資料夾上按 `Enter` | 將目前網頁儲存至該資料夾 (已儲存在該處的網頁不會重複儲存) |
| 在書籤上按 `Enter` | 在新分頁中開啟書籤 |
| 在資料夾上按 `Space` | 展開或收合資料夾 |

## 書籤管理員 [#bookmarks-manager]

在書籤管理員中按下 `?`，或按一下標頭中的鍵盤按鈕，即可查看這份清單。

| 按鍵 | 動作 |
| --- | --- |
| `/` | 將焦點移至標題篩選器 |
| `Backspace` 或 `Alt+↑` | 前往上層資料夾 |
| `j` / `k` | 移至表格的下一列或上一列 (資料夾列，或書籤列的動作選單) |
| 在資料夾列上按 `Enter` | 開啟資料夾 |
| `s` | 開啟已儲存的搜尋 |
| `?` | 顯示鍵盤快速鍵 |
| `Esc` | 關閉對話方塊或選單 |

在表格中，將焦點移至欄標頭的邊緣，然後按下 `←` 或 `→` 即可調整該欄的寬度。

Chromium 和 Edge 的自動化測試涵蓋鍵盤快速鍵，Firefox 的自動化測試則不涵蓋。
