---
title: Tastenkombinationen
description: Suchen, durch Ordner navigieren, die aktuelle Seite speichern und die Tabelle des Managers ohne Maus bedienen.
---

Tastenkombinationen im Pop-up und in der Seitenleiste verwenden nie `Ctrl` oder `Cmd`, sodass die eigenen Tastenkombinationen des Browsers mit diesen Tasten, etwa zum Öffnen eines neuen Tabs oder der Adressleiste, weiter funktionieren. Der Lesezeichen-Manager ersetzt den des Browsers und übernimmt daher auch dessen `Cmd`-Tastenkombinationen (`Ctrl` unter Windows und Linux): alles auswählen, kopieren, ausschneiden, einfügen, rückgängig machen, wiederholen und in neuen Tabs öffnen. Tastenkombinationen pausieren, während Sie in ein Textfeld tippen (`Esc` im Suchfeld ist die Ausnahme), während eine Eingabemethode Text zusammensetzt und während ein Dialog oder Menü geöffnet ist.

Die Tasten der Kürzel in Pop-up, Seitenleiste und Manager können Sie unter [Einstellungen > Verhalten > Tastenkürzel in Manager und Pop-up](/settings#page-shortcuts) ändern; diese Seite nennt die Tasten, mit denen sie beginnen.

## Auf jeder Seite [#on-any-page]

Diese funktionieren, ohne dass ein Fenster von Bookmark Scout geöffnet ist. Sie gehören Ihrem Browser, daher können Sie sie in dessen Tastenkürzel-Einstellungen ändern oder entfernen; siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save). In Chrome und Edge können Sie dem Schnellspeichern auch die Lesezeichentaste des Browsers zuweisen, <Shortcut id="browser.bookmark_page" />; siehe [Die Lesezeichentaste zum Schnellspeichern verwenden](/guides/save-and-organize#ctrl-d).

| Taste | Aktion |
| --- | --- |
| <Shortcut id="commands.quick-save" /> | Die aktuelle Seite schnell in dem Ordner aus **Ordner für Schnellspeichern** speichern |
| <Shortcut id="commands.ai-quick-save" /> | Die aktuelle Seite schnell in dem Ordner speichern, den die KI vorschlägt |

In der anschließenden Benachrichtigung erreicht `Tab` **Rückgängig** und die anderen Ordner, und `Esc` schließt sie.

## Pop-up und Seitenleiste [#popup-and-side-panel]

Bewegen Sie den Mauszeiger auf das Suchfeld, um eine Kurzübersicht zu sehen.

| Taste | Aktion |
| --- | --- |
| <Shortcut id="popup.focus_search" /> | Suchfeld fokussieren |
| `Esc` im Suchfeld | Suche löschen; erneut drücken, um das Feld zu verlassen |
| `↓` im Suchfeld | Zum ersten Ordner wechseln |
| `Enter` im Suchfeld | Aktuelle Seite im ersten, hervorgehobenen Ordner unter **In Ordner speichern** speichern; ohne passenden Ordner wird die Suche unter den letzten Suchen gemerkt |
| <Shortcut id="popup.recent_searches" /> im leeren Suchfeld | Letzte Suchen anzeigen; mit `↓` / `↑` eine auswählen, mit `Enter` danach suchen, mit `Tab` zu **Löschen** gelangen |
| `↓` / `↑`, `Home` / `End` | Zwischen sichtbaren Ordnern und Lesezeichen wechseln (`↑` in der ersten Zeile kehrt zur Suche zurück) |
| `→` / `←` | Ordner öffnen oder schließen; bei einem geöffneten Ordner wechselt `→` zum ersten Element und `←` zum übergeordneten Ordner |
| `Enter` auf einem Ordner | Aktuelle Seite in diesem Ordner speichern (eine dort bereits gespeicherte Seite wird nicht doppelt angelegt) |
| `Enter` auf einem Lesezeichen | In einem neuen Tab öffnen |
| `Space` auf einem Ordner | Öffnen oder schließen |

## Lesezeichen-Manager [#bookmarks-manager]

Drücken Sie <Shortcut id="manager.show_help" /> oder klicken Sie auf die Tastatur-Schaltfläche in der Kopfzeile, um diese Liste im Manager anzuzeigen. Die Tasten folgen dem Lesezeichen-Manager von Chrome.

| Taste | Aktion |
| --- | --- |
| <Shortcut id="manager.focus_filter" /> | Suchfeld auswählen |
| <Shortcut id="manager.parent_folder" /> | Zum übergeordneten Ordner wechseln |
| `↓` / `↑`, `Home` / `End` | Zwischen Zeilen wechseln und die Zeile auswählen; mit `Shift` die Auswahl erweitern; mit `Cmd` (`Ctrl` unter Windows und Linux) wechseln, ohne auszuwählen |
| <Shortcut id="manager.next_row" />, <Shortcut id="manager.previous_row" /> | Zur nächsten oder vorherigen Zeile wechseln |
| `Space` | Die fokussierte Zeile auswählen oder die Auswahl aufheben |
| <Shortcut id="manager.preview" /> | Vorschau des fokussierten Lesezeichens: gespeichertes Titelbild, Adresse, Ordner, Tags und Zusammenfassung, mit **In neuem Tab öffnen**, **Kopieren** und **Bearbeiten**; `Esc` schließt sie und kehrt zur Zeile oder Karte zurück |
| <Shortcut id="manager.preview_previous" />, <Shortcut id="manager.preview_next" /> | In der Vorschau das vorherige oder nächste Lesezeichen der Seite anzeigen, Ordner werden übersprungen (auch mit den Pfeilschaltflächen oben); `Esc` kehrt dann zur Zeile oder Karte des angezeigten Lesezeichens zurück |
| <Shortcut id="manager.select_all" /> | Jede Zeile auswählen, die die Filter zeigen, auf jeder Seite |
| <Shortcut id="manager.clear_selection" /> | Auswahl aufheben oder einen Dialog oder ein Menü schließen |
| <Shortcut id="manager.open" /> | Den ausgewählten Ordner oder die ausgewählten Lesezeichen in Tabs öffnen |
| <Shortcut id="manager.open_in_new_tabs" /> | Die Auswahl in neuen Hintergrund-Tabs öffnen |
| <Shortcut id="manager.open_in_new_window" /> | Die Auswahl in einem neuen Fenster öffnen |
| <Shortcut id="manager.rename" /> | Das ausgewählte Lesezeichen bearbeiten oder den Ordner umbenennen |
| <Shortcut id="manager.delete" /> | Die Auswahl löschen |
| <Shortcut id="manager.undo" /> | Die letzte Änderung rückgängig machen |
| <Shortcut id="manager.redo" /> | Wiederholen |
| <Shortcut id="manager.copy" /> | Die Auswahl kopieren; ihre URLs kommen in die Zwischenablage |
| <Shortcut id="manager.cut" /> | Die Auswahl ausschneiden, um sie mit Einfügen zu verschieben |
| <Shortcut id="manager.paste" /> | Nach der Auswahl oder am Ende des Ordners einfügen; in einer anderen App kopierte URLs werden zu Lesezeichen |
| <Shortcut id="manager.open_saved_searches" /> | Gespeicherte Suchen öffnen |
| <Shortcut id="manager.show_help" /> | Tastenkombinationen anzeigen |
| Menütaste oder <Shortcut id="browser.context_menu" /> | Das Rechtsklickmenü für die fokussierte Zeile oder den fokussierten Ordner öffnen |

Mit der Maus, wie im Lesezeichenmanager des Browsers:

| Geste | Aktion |
| --- | --- |
| <Shortcut id="mouse.select_toggle" /> | Eine Zeile zur Auswahl hinzufügen oder daraus entfernen |
| <Shortcut id="mouse.select_range" /> | Alle Zeilen von der zuletzt angeklickten bis zu dieser auswählen |
| <Shortcut id="mouse.open_in_background" /> | Einen Link in einem neuen Hintergrundtab öffnen (Funktion des Browsers) |

Im Ordnerbaum links, der ebenfalls ein einziger `Tab`-Stopp ist:

| Taste | Aktion |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Zwischen den angezeigten Ordnern wechseln |
| `→` / `←` | Ordner öffnen oder schließen; bei einem geöffneten Ordner wechselt `→` zum ersten Unterordner, bei einem geschlossenen wechselt `←` zum übergeordneten Ordner |
| <Shortcut id="manager.open" /> oder `Space` | Den Ordner in der Tabelle anzeigen |
| <Shortcut id="manager.rename" /> | Den Ordner umbenennen |
| <Shortcut id="manager.delete" /> | Den Ordner löschen |
| <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" /> | Den Ordner kopieren oder ausschneiden |
| <Shortcut id="manager.paste" /> | In den Ordner einfügen |

Die Tabelle ist ein einziger Stopp, wenn Sie `Tab` drücken; die Pfeiltasten wechseln zwischen ihren Zeilen. Wenn mehr als <SettingDefault path="behavior.links.confirm_open_above" /> Tabs auf einmal geöffnet werden sollen, wird zuerst nachgefragt; ein Ordner öffnet die Lesezeichen, die direkt darin liegen. Fokussieren Sie in der Tabelle den Rand einer Spaltenüberschrift und drücken Sie `←` oder `→`, um die Breite dieser Spalte zu ändern.

Tastenkombinationen werden von den automatisierten Tests für Chromium und Edge abgedeckt, nicht von denen für Firefox.
