---
title: Tastenkombinationen
description: Suchen, durch Ordner navigieren, die aktuelle Seite speichern und die Tabelle des Managers ohne Maus bedienen.
---

Die Tastenkombinationen von Bookmark Scout verwenden nie `Ctrl` oder `Cmd`, sodass Browser-Tastenkombinationen wie `Ctrl/Cmd+L`, `T`, `W`, `N`, `R` und `D` weiter funktionieren. Sie pausieren, während Sie in ein Textfeld tippen (`Esc` im Suchfeld ist die Ausnahme), während eine Eingabemethode Text zusammensetzt und während ein Dialog oder Menü geöffnet ist.

## Pop-up und Seitenleiste [#popup-and-side-panel]

Bewegen Sie den Mauszeiger auf das Suchfeld, um eine Kurzübersicht zu sehen.

| Taste | Aktion |
| --- | --- |
| `/` | Suchfeld fokussieren |
| `Esc` im Suchfeld | Suche löschen; erneut drücken, um das Feld zu verlassen |
| `↓` im Suchfeld | Zum ersten Ordner wechseln |
| `Alt+↓` im leeren Suchfeld | Letzte Suchen anzeigen; mit `↓` / `↑` eine auswählen, mit `Enter` danach suchen, mit `Tab` zu **Löschen** gelangen |
| `↓` / `↑`, `Home` / `End` | Zwischen sichtbaren Ordnern und Lesezeichen wechseln (`↑` in der ersten Zeile kehrt zur Suche zurück) |
| `→` / `←` | Ordner öffnen oder schließen; bei einem geöffneten Ordner wechselt `→` zum ersten Element und `←` zum übergeordneten Ordner |
| `Enter` auf einem Ordner | Aktuelle Seite in diesem Ordner speichern (eine dort bereits gespeicherte Seite wird nicht doppelt angelegt) |
| `Enter` auf einem Lesezeichen | In einem neuen Tab öffnen |
| `Space` auf einem Ordner | Öffnen oder schließen |

## Lesezeichen-Manager [#bookmarks-manager]

Drücken Sie `?` oder klicken Sie auf die Tastatur-Schaltfläche in der Kopfzeile, um diese Liste im Manager anzuzeigen.

| Taste | Aktion |
| --- | --- |
| `/` | Titelfilter fokussieren |
| `Backspace` oder `Alt+↑` | Zum übergeordneten Ordner wechseln |
| `j` / `k` | Zur nächsten oder vorherigen Tabellenzeile wechseln (eine Ordnerzeile oder das Aktionsmenü einer Lesezeichenzeile) |
| `Enter` auf einer Ordnerzeile | Ordner öffnen |
| `s` | Gespeicherte Suchen öffnen |
| `?` | Tastenkombinationen anzeigen |
| `Esc` | Dialog oder Menü schließen |

Fokussieren Sie in der Tabelle den Rand einer Spaltenüberschrift und drücken Sie `←` oder `→`, um die Breite dieser Spalte zu ändern.

Tastenkombinationen werden von den automatisierten Tests für Chromium und Edge abgedeckt, nicht von denen für Firefox.
