---
title: Tastenkombinationen
description: Suchen, durch Ordner navigieren, die aktuelle Seite speichern und die Tabelle des Managers ohne Maus bedienen.
---

Tastenkombinationen im Pop-up und in der Seitenleiste verwenden nie `Ctrl` oder `Cmd`, sodass Browser-Tastenkombinationen wie `Ctrl/Cmd+L`, `T`, `W`, `N`, `R` und `D` weiter funktionieren. Der Lesezeichen-Manager ersetzt den des Browsers und übernimmt daher auch dessen `Ctrl`-Tastenkombinationen (`Cmd` auf einem Mac): alles auswählen, kopieren, ausschneiden, einfügen, rückgängig machen, wiederholen und in neuen Tabs öffnen. Tastenkombinationen pausieren, während Sie in ein Textfeld tippen (`Esc` im Suchfeld ist die Ausnahme), während eine Eingabemethode Text zusammensetzt und während ein Dialog oder Menü geöffnet ist.

## Auf jeder Seite [#on-any-page]

Diese funktionieren, ohne dass ein Fenster von Bookmark Scout geöffnet ist. Sie gehören Ihrem Browser, daher können Sie sie in dessen Tastenkürzel-Einstellungen ändern oder entfernen; siehe [Mit einem Tastenkürzel speichern](/guides/save-and-organize#quick-save). In Chrome und Edge können Sie dem Schnellspeichern auch die Lesezeichentaste des Browsers zuweisen, `Ctrl+D` (`⌘D` auf einem Mac); siehe [Ctrl+D zum Schnellspeichern verwenden](/guides/save-and-organize#ctrl-d).

| Taste | Aktion |
| --- | --- |
| `Alt+Shift+S` (`⌥⇧S` auf einem Mac) | Die aktuelle Seite schnell in dem Ordner aus **Ordner für Schnellspeichern** speichern |
| `Alt+Shift+D` (`⌥⇧D` auf einem Mac) | Die aktuelle Seite schnell in dem Ordner speichern, den die KI vorschlägt |

In der anschließenden Benachrichtigung erreicht `Tab` **Rückgängig** und die anderen Ordner, und `Esc` schließt sie.

## Pop-up und Seitenleiste [#popup-and-side-panel]

Bewegen Sie den Mauszeiger auf das Suchfeld, um eine Kurzübersicht zu sehen.

| Taste | Aktion |
| --- | --- |
| `/` | Suchfeld fokussieren |
| `Esc` im Suchfeld | Suche löschen; erneut drücken, um das Feld zu verlassen |
| `↓` im Suchfeld | Zum ersten Ordner wechseln |
| `Alt+↓` im leeren Suchfeld | Letzte Suchen anzeigen; mit `↓` / `↑` eine auswählen, mit `Enter` danach suchen, mit `Tab` zu **Löschen** gelangen |
| `↓` / `↑`, `Home` / `End` | Zwischen sichtbaren Ordnern und Lesezeichen wechseln (`↑` in der ersten Zeile kehrt zur Suche zurück) |
| `→` / `←` | Ordner öffnen oder schließen; bei einem geöffneten Ordner wechselt `→` zum ersten Element und `←` zum übergeordneten Ordner |
| `Enter` auf einem Ordner | Aktuelle Seite in diesem Ordner speichern (eine dort bereits gespeicherte Seite wird nicht doppelt angelegt) |
| `Enter` auf einem Lesezeichen | In einem neuen Tab öffnen |
| `Space` auf einem Ordner | Öffnen oder schließen |

## Lesezeichen-Manager [#bookmarks-manager]

Drücken Sie `?` oder klicken Sie auf die Tastatur-Schaltfläche in der Kopfzeile, um diese Liste im Manager anzuzeigen. Die Tasten folgen dem Lesezeichen-Manager von Chrome; wo ein Mac abweicht, steht seine Taste an zweiter Stelle.

| Taste | Aktion |
| --- | --- |
| `/` | Titelfilter fokussieren |
| `Backspace` oder `Alt+↑` | Zum übergeordneten Ordner wechseln |
| `↓` / `↑`, `Home` / `End` | Zwischen Zeilen wechseln und die Zeile auswählen; mit `Shift` die Auswahl erweitern; mit `Ctrl` (`Cmd`) wechseln, ohne auszuwählen |
| `j` / `k` | Zur nächsten oder vorherigen Zeile wechseln |
| `Space` | Die fokussierte Zeile auswählen oder die Auswahl aufheben |
| `Ctrl+A` / `Cmd+A` | Jede Zeile auswählen, die die Filter zeigen, auf jeder Seite |
| `Esc` | Auswahl aufheben oder einen Dialog oder ein Menü schließen |
| `Enter` / `Cmd+O` | Den ausgewählten Ordner oder die ausgewählten Lesezeichen in Tabs öffnen |
| `Ctrl+Enter` / `Cmd+Enter` | Die Auswahl in neuen Hintergrund-Tabs öffnen |
| `Shift+Enter` | Die Auswahl in einem neuen Fenster öffnen |
| `F2` / `Enter` | Das ausgewählte Lesezeichen bearbeiten oder den Ordner umbenennen |
| `Delete` / `Delete` oder `Cmd+Backspace` | Die Auswahl löschen |
| `Ctrl+Z` / `Cmd+Z` | Die letzte Änderung rückgängig machen |
| `Ctrl+Y` oder `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Wiederholen |
| `Ctrl+C` / `Cmd+C` | Die Auswahl kopieren; ihre URLs kommen in die Zwischenablage |
| `Ctrl+X` / `Cmd+X` | Die Auswahl ausschneiden, um sie mit Einfügen zu verschieben |
| `Ctrl+V` / `Cmd+V` | Nach der Auswahl oder am Ende des Ordners einfügen; in einer anderen App kopierte URLs werden zu Lesezeichen |
| `s` | Gespeicherte Suchen öffnen |
| `?` | Tastenkombinationen anzeigen |
| Menütaste oder `Shift+F10` | Das Rechtsklickmenü für die fokussierte Zeile oder den fokussierten Ordner öffnen |

Im Ordnerbaum links, der ebenfalls ein einziger `Tab`-Stopp ist:

| Taste | Aktion |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Zwischen den angezeigten Ordnern wechseln |
| `→` / `←` | Ordner öffnen oder schließen; bei einem geöffneten Ordner wechselt `→` zum ersten Unterordner, bei einem geschlossenen wechselt `←` zum übergeordneten Ordner |
| `Enter` oder `Space` / `Cmd+O` oder `Space` | Den Ordner in der Tabelle anzeigen |
| `F2` / `Enter` | Den Ordner umbenennen |
| `Delete` / `Delete` oder `Cmd+Backspace` | Den Ordner löschen |
| `Ctrl+C`, `Ctrl+X` / `Cmd+C`, `Cmd+X` | Den Ordner kopieren oder ausschneiden |
| `Ctrl+V` / `Cmd+V` | In den Ordner einfügen |

Die Tabelle ist ein einziger Stopp, wenn Sie `Tab` drücken; die Pfeiltasten wechseln zwischen ihren Zeilen. Wenn mehr als 15 Tabs auf einmal geöffnet werden sollen, wird zuerst nachgefragt; ein Ordner öffnet die Lesezeichen, die direkt darin liegen. Fokussieren Sie in der Tabelle den Rand einer Spaltenüberschrift und drücken Sie `←` oder `→`, um die Breite dieser Spalte zu ändern.

Tastenkombinationen werden von den automatisierten Tests für Chromium und Edge abgedeckt, nicht von denen für Firefox.
