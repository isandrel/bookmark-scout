title: 导入和导出
description: 将书签导出为 HTML、JSON、Markdown 或 CSV，导出前会进行隐私检查；导入 HTML 或 JSON 文件前会显示包含重复项的预览。
---

这两个工具都位于书签管理器的**工具**侧栏中的**数据**下。

<Callout title="Firefox">
在 Firefox 中，请通过弹出窗口中的**打开书签管理器**打开书签管理器。
</Callout>

## 导出书签 [#export-bookmarks]

<Steps>
<Step>
在**导出书签**中选择一种**格式**：**HTML (Chrome)**、**JSON**、**Markdown** 或 **CSV**。
</Step>
<Step>
选择当前文件夹或所有书签，然后点击**导出**。
</Step>
<Step>
如果文件中会包含可能涉及隐私的值，会先打开检查界面。请选择**按原样导出**、**脱敏导出**或**取消**。
</Step>
</Steps>

检查会查找敏感的查询参数、网址片段中的令牌、类似电子邮件地址和令牌的值，以及网址中包含的用户名或密码。脱敏导出只会在下载的文件中将这些值替换为 `REDACTED`；你的书签不会改变。不含敏感内容的导出会直接下载。

文件详情：

- 文件名以**文件名前缀**（默认为 `bookmarks_`）开头，并保留非 ASCII 字符的文件夹名称。
- CSV 文件以 UTF-8 字节顺序标记（BOM）开头。Folder 列用 `/` 连接各级文件夹，并将文件夹名称中的 `/` 写为 `\/`，将反斜杠写为 `\\`。
- 只有 Firefox 才有的分隔线，在 HTML（`<HR>`）和 JSON 中会作为分隔线写出，在 Firefox 中导入该文件时仍是分隔线。Markdown 和 CSV 不包含分隔线；没有分隔线的 Chrome 和 Edge 在导入时会略过它们，预览会显示数量。
- **包含日期**和**包含网址**以及各格式的缩进大小，位于[设置](/settings#data)的**导入与导出**标签页中。

JSON 导出文件会包含每个书签的标签和摘要。导入该文件时，新建的书签会获得这些标签和摘要，但作为重复项跳过的书签不会。HTML、Markdown 和 CSV 导出文件不包含它们。如需将书签连同其标签和摘要一起提供给 AI 工具，请使用 **AI 上下文打包**；请参阅[设置 AI 工具](/guides/ai-tools#export-context-for-an-ai-chat)。

## 导入书签 [#import-bookmarks]

<Steps>
<Step>
在**导入书签**中点击**导入**，然后选择一个 HTML 或 JSON 书签文件，例如从浏览器导出的文件。也可以把文件拖放到**导入书签**卡片上。
</Step>
<Step>
查看**导入预览**。它会显示目标文件夹、将创建或跳过的书签和文件夹数量，以及哪些网址已存在于目标文件夹中、书签的其他位置或同一文件的前面部分。
</Step>
<Step>
如有需要，请更改**导入到**。其初始值为书签管理器中当前打开的文件夹。
</Step>
<Step>
选择如何处理**重复项**：跳过已存在于任何位置的书签、只跳过已存在于目标文件夹中的书签，或全部导入。
</Step>
<Step>
点击**导入**。消息会列出创建、跳过和失败的项目数量，并在 10 秒内提供**撤消**。撤消只会删除仍与导入时完全相同的项目：导入后你改过名称、移动过、改过标签或往里添加过内容的项目会保留，消息中计为保留。
</Step>
</Steps>

在你点击**导入**之前，不会写入任何内容。如果预览打开期间你的书签发生了变化，预览会刷新，而不会直接应用。

## 备份和恢复设置 [#back-up-and-restore-settings]

设置页面底部的**备份设置**和**恢复设置**按钮会把 Bookmark Scout 自己的数据保存为备份文件，或从备份文件恢复。它们绝不会影响你的书签、标签或摘要；要导出书签，请使用上面的工具。也可以把备份文件拖放到设置页面的任意位置来恢复。

### 备份包含的内容 [#what-a-backup-holds]

**备份设置**会列出备份的各项内容，每项都显示包含什么、有多少项以及大约多大。选择你需要的内容，或使用**全选**和**全不选**：

- 用**用当前画面作为封面**选择的封面优先：只会被文件中更新的、同样是手动选择的封面替换；文件中手动选择的封面会替换不是手动选择的封面；其他情况以较新的为准。未来的日期按今天计算。**封面存储空间**仍然适用，超出时会从最旧的封面开始删除，手动选择的封面最后删除。
- **设置**：你更改过的、会同步的设置，包括菜单和列表。
- **此电脑的设置**：只为一台电脑保存的设置，例如布局、侧边栏、键盘按键和快速保存文件夹。默认不选中，因为它们适合一台电脑的屏幕和键盘。
- **已保存的搜索和表格视图**、**提示词和“关于我”**、**智能规则**和**AI 服务**（名称、服务商、模型、API 地址以及服务商特有的字段）。
- **封面**，标有**较大**：按地址保存的封面图片。封面不会同步，书签导出也不包含封面，因此要把它们带到另一台电脑，只能通过备份。
- **AI 服务密钥**：API 密钥和额外请求头，除非你主动选择，否则绝不会选中。选择它们时会警告：任何拿到文件的人都能使用这些密钥并产生费用，保存前需要你确认。

你保存的内容会成为此电脑上下次的选择（[设置](/settings#data)中的**新备份包含的内容**）。文件名包含日期和所选内容，例如 `bookmark-scout-backup_2026-10-23_all.json`，并保存在你的电脑上；不会发送到任何地方。

### 密码保护 [#password-protection]

- 选择**AI 服务密钥**时，**用密码保护 API 密钥**默认开启；关闭它时会要求你确认密钥将以纯文本形式可被读取。
- **用密码保护此备份**会加密所有内容。设置中的**用密码保护新备份**可让它默认开启。
- 密码至少需要 12 个字符。密码绝不会被保存，忘记的密码也无法找回：没有密码，任何人都无法打开受保护的内容，Bookmark Scout 也不能。
- 内容列表始终可读，因此**恢复设置**会先显示文件包含什么，再要求输入密码。如果密码错误，或文件在保存后被更改，受保护的内容一律不会导入。

### 恢复 [#restoring]

1. 点击**恢复设置**并选择文件。此时还不会有任何更改。
2. 每项内容都会显示文件中有多少项，以及导入后会新增、更改或保持不变的项数。来自较新版本 Bookmark Scout 的内容会标为不支持并跳过。输入密码即可解锁受保护的内容。
3. 选择要导入的内容。**此电脑的设置**和**AI 服务密钥**默认不选中；选择密钥时会再次要求你确认。
4. 为每项内容选择**合并**（新增和更新文件中的内容，保留仅此设备上有的内容）或**替换**（让该项内容与文件完全一致，删除仅此设备上有的内容；会先请你确认）。
5. 选择合并时，会列出在此设备和文件中都更改过的项目（提示词、智能规则、已保存的搜索、AI 服务）：可以对全部或逐项选择保留较新的、使用文件中的，或保留此设备的。用**用当前画面作为封面**选择的封面，只会被文件中更新的、同样是手动选择的封面替换。
6. 点击**导入**。结果会列出每项内容新增、更改、删除、保留和跳过了什么。文件中没有密钥的 AI 服务会显示**需要设置**，直到你在 [AI](/settings#ai) 中输入密钥。

指定文件夹的设置（例如快速保存文件夹）只有在此电脑上存在路径相同的文件夹时才会恢复，并指向那个文件夹；否则保持此电脑上原来的设置。写入任何内容之前会先检查每项内容，无法完整导入的那项内容会保持原样。

### 撤消导入 [#undo-import]

导入前，Bookmark Scout 会把导入所更改内容的安全副本保留 24 小时。结果中和设置底部的**撤消导入**会把一切恢复原样，包括封面。这次导入也会记录在书签管理器的**书签历史记录**中（筛选条件为**备份**），并显示每项内容及其数量，那里的**撤消导入**效果相同。24 小时后，或在你恢复另一个备份之后，记录仍会保留，但会说明为什么不再提供撤消。

分项备份推出之前的旧备份文件仍然可以恢复。
