どちらのツールも、ブックマークマネージャーの **ツール** サイドバーの **データ** にあります。

<Callout title="Firefox">
Firefox では、ポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。
</Callout>

## ブックマークをエクスポートする [#export-bookmarks]

<Steps>
<Step>
**ブックマークを書き出す** で **形式** を選びます: **HTML（Chrome）**、**JSON**、**Markdown**、**CSV**。
</Step>
<Step>
現在のフォルダかすべてのブックマークを選び、**エクスポート** をクリックします。
</Step>
<Step>
ファイルに個人的な情報かもしれない値が含まれる場合は、先に確認画面が開きます。**元のままエクスポート**、**編集してエクスポート**、**キャンセル** のいずれかを選びます。
</Step>
</Steps>

確認画面では、機密性のあるクエリパラメータ、URL フラグメント内のトークン、メールアドレスやトークンのような値、URL に含まれるユーザー名やパスワードを探します。編集してエクスポートすると、ダウンロードされるファイルの中だけでこれらの値が `REDACTED` に置き換えられ、ブックマーク自体は変わりません。機密情報が含まれないエクスポートは、そのままダウンロードされます。

ファイルの詳細:

- ファイル名は **ファイル名の接頭辞**（初期値 `bookmarks_`）で始まり、ASCII 以外の文字を含むフォルダ名もそのまま使われます。
- CSV ファイルは UTF-8 のバイトオーダーマークで始まります。Folder 列ではフォルダを `/` でつなぎ、フォルダ名に含まれる `/` は `\/`、バックスラッシュは `\\` と書き出します。
- Firefox にしかない区切り線は、HTML（`<HR>`）と JSON に区切り線として書き出され、そのファイルを Firefox でインポートすると区切り線として戻ります。Markdown と CSV には含まれません。区切り線のない Chrome と Edge ではインポート時に省かれ、プレビューにその数が表示されます。
- **日付を含める**、**URLを含める**、各形式のインデント幅は、[設定](/settings#data)の **インポートとエクスポート** タブにあります。

JSON でエクスポートすると、各ブックマークのタグと要約も含まれます。そのファイルをインポートすると、作成されるブックマークにはタグと要約が引き継がれますが、重複としてスキップされたブックマークには引き継がれません。HTML、Markdown、CSV のエクスポートには含まれません。タグと要約を含めてブックマークを AI ツールに渡すには、**AIコンテキストパッカー** を使います。[AI ツールの設定](/guides/ai-tools#export-context-for-an-ai-chat)をご覧ください。

## ブックマークをインポートする [#import-bookmarks]

<Steps>
<Step>
**ブックマークを読み込む** で **インポート** をクリックし、ブラウザからエクスポートしたファイルなど、HTML または JSON のブックマークファイルを選びます。ファイルを **ブックマークを読み込む** カードにドロップしても読み込めます。
</Step>
<Step>
**インポートのプレビュー** を確認します。インポート先フォルダ、作成またはスキップされるブックマークとフォルダの数、そしてどの URL がインポート先フォルダ、ブックマーク内のほかの場所、同じファイル内の前の位置にすでにあるかが表示されます。
</Step>
<Step>
必要に応じて **インポート先** を変更します。初期値はマネージャーで開いているフォルダです。
</Step>
<Step>
**重複** の扱いを選びます: どこかにすでにあるブックマークをスキップする、インポート先フォルダにすでにあるものだけをスキップする、またはすべてをインポートする。
</Step>
<Step>
**インポート** をクリックします。作成、スキップ、失敗した項目の件数がメッセージに表示され、10 秒間 **元に戻す** を使えます。元に戻すと、インポートで作成されたときのままの項目だけが削除されます。その後に名前の変更、移動、タグの変更、項目の追加をした項目は残り、メッセージでは残した項目として数えられます。
</Step>
</Steps>

**インポート** をクリックするまで何も書き込まれません。プレビューを開いている間にブックマークが変更された場合は、適用されずにプレビューが更新されます。

## 設定のバックアップと復元 [#back-up-and-restore-settings]

設定ページの下部にある **設定をバックアップ** と **設定を復元** ボタンは、Bookmark Scout 自身のデータをバックアップファイルとして保存、復元します。ブックマーク、タグ、要約には一切影響しません。ブックマークは上のツールでエクスポートしてください。バックアップファイルを設定ページのどこかにドロップしても復元できます。

### バックアップに含まれるもの [#what-a-backup-holds]

**設定をバックアップ** には、バックアップの項目が、それぞれの内容、件数、おおよそのサイズとともに一覧表示されます。必要な項目を選ぶか、**すべて選択** と **すべて解除** を使います。

- **この画面をカバー画像にする** で選んだカバー画像が優先されます。ファイル内のより新しい、同じく選んだカバー画像でだけ置き換わり、ファイル内の選んだカバー画像は、選んでいないカバー画像を置き換えます。それ以外は、より新しいものが優先されます。未来の日付は今日として扱います。**カバー画像の保存容量** は引き続き適用され、超えた分は古いカバー画像から削除され、選んだカバー画像は最後に削除されます。
- **設定**: 変更した設定のうち同期されるもの。メニューや一覧も含みます。
- **このパソコンの設定**: レイアウト、サイドバー、キーボードのキー、クイック保存のフォルダなど、1 台のパソコンごとに保存される設定。1 つの画面とキーボードに合わせたものなので、最初は選択されていません。
- **保存した検索と表の表示**、**プロンプトと自己紹介**、**スマートルール**、**AI サービス**（名前、プロバイダー、モデル、ベース URL、プロバイダー固有の項目）。
- **カバー画像**（**サイズ大** の表示付き）: アドレスごとのカバー画像。カバー画像は同期されず、ブックマークのエクスポートにも含まれないため、別のパソコンへ移すにはバックアップを使います。
- **AI サービスのキー**: API キーと追加ヘッダー。自分で選択しない限り選択されません。選択すると、ファイルを持っている人は誰でもキーを使って料金を発生させられるという警告が表示され、保存する前に確認します。

保存した項目は、このパソコンでの次回の選択になります（[設定](/settings#data) の **新しいバックアップに含める項目**）。ファイル名には日付と項目が入り（例: `bookmark-scout-backup_2026-10-23_all.json`）、ファイルはパソコンに保存されます。どこにも送信されません。

### パスワードによる保護 [#password-protection]

- **AI サービスのキー** を選択すると、**API キーをパスワードで保護** が最初からオンになります。オフにすると、キーがプレーンテキストで読める状態になることの確認を求められます。
- **このバックアップをパスワードで保護** は、すべての項目を暗号化します。設定の **新しいバックアップをパスワードで保護** をオンにすると、最初からオンになります。
- パスワードは 12 文字以上必要です。パスワードは保存されず、忘れたパスワードは復旧できません。パスワードがなければ、保護された項目は誰にも開けません。Bookmark Scout にも開けません。
- 項目の一覧は読める状態のままなので、**設定を復元** はパスワードを求める前にファイルの内容を表示します。パスワードが間違っている場合や、保存後にファイルが変更された場合は、保護された項目から何もインポートされません。

### 復元 [#restoring]

1. **設定を復元** をクリックしてファイルを選びます。この時点では何も変わりません。
2. 各項目に、ファイル内の件数と、インポートした場合に追加、変更、またはそのまま残る件数が表示されます。新しいバージョンの Bookmark Scout で作られた項目は、未対応として表示され、スキップされます。保護された項目のロックを解除するには、パスワードを入力します。
3. インポートする項目を選びます。**このパソコンの設定** と **AI サービスのキー** は最初は選択されていません。キーについては改めて確認を求められます。
4. 項目ごとに、**統合**（ファイルにあるものを追加、更新し、この端末にしかないものは残す）または **置換**（項目をファイルの内容とまったく同じにし、この端末にしかないものは削除する。先に確認があります）を選びます。
5. 統合では、この端末とファイルの両方で変更されたもの（プロンプト、スマートルール、保存した検索、AI サービス）が一覧表示されます。すべてまとめて、または 1 件ずつ、新しいほうを残すか、ファイルのものを使うか、この端末のものを残すかを選びます。**この画面をカバー画像にする** で選んだカバー画像は、ファイル内のより新しい、同じく選んだカバー画像でだけ置き換わります。
6. **インポート** をクリックします。結果には、各項目で追加、変更、削除、維持、スキップされたものが表示されます。ファイルにキーが含まれていなかった AI サービスは、[AI](/settings#ai) でキーを入力するまで **要設定** と表示されます。

クイック保存のフォルダなど、フォルダを指定する設定は、このパソコンに同じパスのフォルダがある場合にだけ復元され、そのフォルダを指すようになります。ない場合は、このパソコンでの設定のまま変わりません。書き込む前にすべての項目が確認され、まるごとインポートできない項目は元のまま残ります。

### インポートを元に戻す [#undo-import]

インポートの前に、Bookmark Scout はインポートで変更される内容の安全用コピーを 24 時間保持します。結果の画面と設定の下部にある **インポートを元に戻す** で、カバー画像も含めてすべて元に戻せます。インポートはブックマークマネージャーの **ブックマークの履歴**（フィルター **バックアップ**）にも記録され、各項目とその件数が表示されます。そこにある **インポートを元に戻す** でも同じことができます。24 時間が過ぎるか、別のバックアップを復元すると、記録は残りますが、元に戻せなくなった理由が表示されます。

項目に分かれる前の古いバックアップファイルも、引き続き復元できます。
