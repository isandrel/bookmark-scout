どちらのツールも、ブックマークマネージャーの **ツール** サイドバーの **データ** にあります。

<Callout title="Firefox">
Firefox では、ポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。
</Callout>

## ブックマークをエクスポートする [#export-bookmarks]

<Steps>
<Step>
**ブックマークを書き出す** で **形式** を選びます: **HTML（Chrome）**、**JSON**、**Markdown**、**CSV**。
</Step>
<Step>
現在のフォルダかすべてのブックマークを選び、**エクスポート** をクリックします。
</Step>
<Step>
ファイルに個人的な情報かもしれない値が含まれる場合は、先に確認画面が開きます。**元のままエクスポート**、**編集してエクスポート**、**キャンセル** のいずれかを選びます。
</Step>
</Steps>

確認画面では、機密性のあるクエリパラメータ、URL フラグメント内のトークン、メールアドレスやトークンのような値、URL に含まれるユーザー名やパスワードを探します。編集してエクスポートすると、ダウンロードされるファイルの中だけでこれらの値が `REDACTED` に置き換えられ、ブックマーク自体は変わりません。機密情報が含まれないエクスポートは、そのままダウンロードされます。

ファイルの詳細:

- ファイル名は **ファイル名の接頭辞**（初期値 `bookmarks_`）で始まり、ASCII 以外の文字を含むフォルダ名もそのまま使われます。
- CSV ファイルは UTF-8 のバイトオーダーマークで始まります。Folder 列ではフォルダを `/` でつなぎ、フォルダ名に含まれる `/` は `\/`、バックスラッシュは `\\` と書き出します。
- **日付を含める**、**URLを含める**、各形式のインデント幅は、[設定](/settings)の **データ** タブにあります。

JSON でエクスポートすると、各ブックマークのタグと要約も含まれます。そのファイルをインポートすると、作成されるブックマークにはタグと要約が引き継がれますが、重複としてスキップされたブックマークには引き継がれません。HTML、Markdown、CSV のエクスポートには含まれません。タグと要約を含めてブックマークを AI ツールに渡すには、**AIコンテキストパッカー** を使います。[AI ツールの設定](/guides/ai-tools#export-context-for-an-ai-chat)をご覧ください。

## ブックマークをインポートする [#import-bookmarks]

<Steps>
<Step>
**ブックマークを読み込む** で **インポート** をクリックし、ブラウザからエクスポートしたファイルなど、HTML または JSON のブックマークファイルを選びます。ファイルを **ブックマークを読み込む** カードにドロップしても読み込めます。
</Step>
<Step>
**インポートのプレビュー** を確認します。インポート先フォルダ、作成またはスキップされるブックマークとフォルダの数、そしてどの URL がインポート先フォルダ、ブックマーク内のほかの場所、同じファイル内の前の位置にすでにあるかが表示されます。
</Step>
<Step>
必要に応じて **インポート先** を変更します。初期値はマネージャーで開いているフォルダです。
</Step>
<Step>
**重複** の扱いを選びます: どこかにすでにあるブックマークをスキップする、インポート先フォルダにすでにあるものだけをスキップする、またはすべてをインポートする。
</Step>
<Step>
**インポート** をクリックします。作成、スキップ、失敗した項目の件数がメッセージに表示され、10 秒間 **元に戻す** を使えます。
</Step>
</Steps>

**インポート** をクリックするまで何も書き込まれません。プレビューを開いている間にブックマークが変更された場合は、適用されずにプレビューが更新されます。

## 設定ファイルは別扱い [#settings-files-are-separate]

設定ページの下部にある **設定をバックアップ** と **設定を復元** ボタンは、Bookmark Scout の設定、カスタムプロンプト、AI サービス（API キーを除く）、保存した検索をバックアップファイルとして保存、復元します。ブックマーク、タグ、要約には影響しません。バックアップの内容は[設定](/settings)をご覧ください。バックアップファイルを設定ページのどこかにドロップしても復元できます。
