---
title: Import and export
description: Export bookmarks as HTML, JSON, Markdown, or CSV with a privacy review, and import HTML or JSON files after a preview that shows duplicates.
---

Both tools are in the **Tools** sidebar of the bookmarks manager, under **Data**.

<Callout title="Firefox">
In Firefox, open the manager with **Open bookmark manager** in the popup.
</Callout>

## Export bookmarks

<Steps>
<Step>
In **Export Bookmarks**, pick a **Format**: **HTML (Chrome)**, **JSON**, **Markdown**, or **CSV**.
</Step>
<Step>
Choose the current folder or all bookmarks, and click **Export**.
</Step>
<Step>
If the file would contain values that may be private, a review opens first. Choose **Export original**, **Export redacted**, or **Cancel**.
</Step>
</Steps>

The review looks for sensitive query parameters, tokens in URL fragments, email-like and token-like values, and user names or passwords inside URLs. A redacted export replaces those values with `REDACTED` in the downloaded file only; your bookmarks do not change. Exports with nothing sensitive download directly.

File details:

- File names start with **Filename Prefix** (default `bookmarks_`) and keep non-ASCII folder names.
- CSV files start with a UTF-8 byte order mark. The Folder column joins folders with `/`, and writes a `/` inside a folder name as `\/` and a backslash as `\\`.
- Separators, which only Firefox has, are written as separators in HTML (`<HR>`) and JSON and come back as separators when you import that file in Firefox. Markdown and CSV leave them out, and Chrome and Edge, which have no separators, leave them out of an import; the preview counts them.
- **Include Dates** and **Include URLs**, and the indent sizes for each format, are on the **Data** tab of [Settings](/settings).

A JSON export includes each bookmark's tags and summary, and importing that file gives them to the bookmarks it creates, but not to ones it skips as duplicates. HTML, Markdown, and CSV exports leave them out. To hand bookmarks with their tags and summaries to an AI tool, use **AI Context Packer**; see [Set up AI tools](/guides/ai-tools#export-context-for-an-ai-chat).

## Import bookmarks

<Steps>
<Step>
In **Import Bookmarks**, click **Import** and choose an HTML or JSON bookmark file, such as one exported from a browser. You can also drop the file onto the **Import Bookmarks** card.
</Step>
<Step>
Review the **Import preview**. It shows the target folder, how many bookmarks and folders will be created or skipped, and which URLs already exist in the target folder, elsewhere in your bookmarks, or earlier in the same file.
</Step>
<Step>
Change **Import into** if needed. It starts as the folder open in the manager.
</Step>
<Step>
Choose how to handle **Duplicates**: skip bookmarks that already exist anywhere, skip only those already in the target folder, or import everything.
</Step>
<Step>
Click **Import**. A message lists how many items were created, skipped, and failed, with **Undo** for 10 seconds. Undo removes only what is still exactly as the import made it: an imported item you renamed, moved, re-tagged, or added to since stays, and the message counts it as kept.
</Step>
</Steps>

Nothing is written until you click **Import**. If your bookmarks change while the preview is open, the preview is refreshed instead of applied.

## Back up and restore settings [#back-up-and-restore-settings]

The **Back up settings** and **Restore settings** buttons at the bottom of the Settings page save and restore a backup file of Bookmark Scout's own data. They never touch your bookmarks, tags, or summaries; export bookmarks with the tool above. You can also drop a backup file anywhere on the Settings page to restore it.

### What a backup holds [#what-a-backup-holds]

**Back up settings** lists the parts of a backup, each with what it holds, how many items, and about how large it is. Select the ones you want, or use **Select all** and **Select none**:

- A cover you picked with **Use this view as the cover** ranks first: it is replaced only by a newer picked cover from the file, and a picked cover from the file replaces one that was not picked; otherwise the newer cover wins. A date in the future counts as today. **Cover Storage** still applies, so the oldest covers are removed past it, the ones you picked last.
- **Settings**: the settings you changed that sync, including the menus and lists.
- **This computer's settings**: settings kept for one computer, such as the layout, sidebars, keyboard keys, and the quick save folder. Not selected at first, because they suit one screen and keyboard.
- **Saved searches and table view**, **Prompts and About me**, **Smart Rules**, and **AI services** (name, provider, model, Base URL, and provider-specific fields).
- **Covers**, marked **Large**: the cover pictures, by address. Covers never sync and bookmark exports do not hold them, so a backup is how they reach another computer.
- **AI service keys**: the API keys and extra headers, never selected unless you select them. Selecting them warns that anyone with the file can use the keys and run up charges, and you confirm before saving.

The parts you save become the selection next time on this computer (**Parts in New Backups** in [Settings](/settings#data)). The file is named with the date and the parts, such as `bookmark-scout-backup_2026-10-23_all.json`, and is saved on your computer; nothing is sent anywhere.

### Password protection [#password-protection]

- With **AI service keys** selected, **Protect the API keys with a password** starts on; turning it off asks you to confirm that the keys will be readable as plain text.
- **Protect this backup with a password** encrypts every part. **Protect New Backups With a Password** in Settings starts it on.
- The password needs at least 12 characters. It is never stored, and a forgotten password cannot be recovered: nobody can open the protected parts without it, not even Bookmark Scout.
- The list of parts stays readable, so **Restore settings** shows what the file holds before asking for the password. A wrong password, or a file changed after it was saved, imports nothing from the protected parts.

### Restoring [#restoring]

1. Click **Restore settings** and pick the file. Nothing changes yet.
2. Each part shows how many items are in the file and how many importing it would add, change, or leave as they are. A part from a newer version of Bookmark Scout is listed as not supported and skipped. Enter the password to unlock protected parts.
3. Pick the parts to import. **This computer's settings** and **AI service keys** start unselected; the keys again ask you to confirm.
4. For each part, choose **Merge** (adds and updates what the file has, keeps what only this device has) or **Replace** (makes the part exactly what the file has, removing what only this device has; you confirm first).
5. With Merge, items changed both here and in the file (prompts, Smart Rules, saved searches, AI services) are listed: keep the newer one, use the file's, or keep this device's, for all of them or each one. A cover you picked with **Use this view as the cover** is replaced only by a newer picked cover from the file.
6. Click **Import**. The result lists what each part added, changed, removed, kept, and skipped. AI services whose keys were not in the file show **Needs setup** until you enter them in [AI](/settings#ai).

### Undo import [#undo-import]

Before importing, Bookmark Scout keeps a safety copy of what the import changes, for 24 hours. **Undo import**, in the result and at the bottom of Settings, puts it all back, covers included. The import is also listed in the bookmark manager's **History** (filter **Backups**), with each part and its counts, and **Undo import** there does the same. After 24 hours, or once you restore another backup, the record stays but says why Undo is no longer offered.

Older backup files, from before parts, still restore.
