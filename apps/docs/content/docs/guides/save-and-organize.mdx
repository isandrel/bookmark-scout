## Save the page you are on

<Steps>
<Step>
Open the popup or the side panel on the page you want to keep.
</Step>
<Step>
Hover the folder you want and click **Add current page**. With the keyboard, move to the folder and press `Enter`.
</Step>
</Steps>

To find a folder by name, type part of it in the search box. **Save to folder** lists the matching folders above the results, with the folders they are in. Press `↓` and then `Enter`, or click one, to save the page there. Several words also match the folders around it (`react hooks`), and a word of 4 letters or more may have one typo. Turn the list off, or change how many folders it shows, with **Folder Matches**, **Maximum Folder Matches**, and **Allow Typos** in [Settings](/settings).

<Screenshot name="popup" />

The **Recent** panel lists recently used folders; click one to save the current page there. Turn it off, or change how many folders it shows, with **Recent Folders** and **Recent Folders Max** in [Settings](/settings).

A page that is already in the folder is not saved twice; the message says it is already there.

The toolbar popup reads the page you clicked it on without asking. The side panel stays open while you switch tabs, so the first time you save from it, Bookmark Scout explains and then asks for access to your tabs. If you decline, nothing is saved.

## Save with a keyboard shortcut [#quick-save]

Press `Alt+Shift+S` on any page to save it without opening Bookmark Scout. A small notification in the top corner of the page says which folder it went to, with **Undo** and a few other folders under **Move to**. It closes on its own after a few seconds; hovering it or tabbing to it keeps it open, and `Esc` closes it. It never takes the keyboard from the page.

Where the page goes is **Quick Save Folder** in [Settings](/settings#quick-save):

- **Best match** (the default) compares the page's title, site, and address with your folder names, the folders around them, and the titles and sites of the bookmarks already in each folder, all on your device. Chinese, Japanese, and Korean titles work too. **Move to** offers the next best folders.
- **Last used** saves to the folder you saved to most recently; **Move to** offers your other recent folders.
- **Chosen folder** always saves to the folder you pick in **Folder to Save To**.

When no folder matches well, or the chosen folder was deleted, the page goes to your last used folder, then the bookmarks bar, and the notification says so.

Press `Alt+Shift+D` to save the page to the folder AI suggests instead. It uses the same AI service, page reading, and suggestion count as the popup's AI suggestions, and sends the same data (see [Set up AI tools](/guides/ai-tools)). The notification shows **Choosing a folder with AI...** while it waits, then lists the other suggestions under **Move to**; a suggested folder that does not exist yet is created, and **Undo** removes it again. With AI off or not set up, nothing is saved and the notification offers **Open AI settings**.

A page you have already bookmarked is not saved again: the notification says where it is and offers to move it.

Some pages do not let extensions show anything on them, such as the browser's own pages, the extension store, and the PDF viewer. There the toolbar icon shows ✓ or ✗ for a moment, and the popup opens (where the browser allows it) with the same **Undo** and **Move to**.

Your browser owns the keys, so change them there: **Change shortcuts** in Settings opens `chrome://extensions/shortcuts` in Chrome or `edge://extensions/shortcuts` in Edge. In Firefox, open `about:addons`, click the gear button, and choose **Manage Extension Shortcuts**. If another extension already uses a key, the browser leaves the shortcut unset and Settings shows **Not set**.

## Save a link with the right-click menu

First turn on **Context Menu** in [Settings](/settings#data); it is off by default. Then right-click any link on a page and choose **Save bookmark to...**, then pick one of your recent folders or the Bookmarks Bar. **Bookmark Name Source** in Settings chooses whether the bookmark is named after the link text, the page title, or the link URL. Turn the menu off with **Context Menu** (both are on the **Data** tab).

## Create folders

Hover a folder in the popup or side panel and click **Add folder**, then type the name. New folders start with the **Default Folder Name** from Settings.

## Move bookmarks and folders

- **Drag and drop** in the popup or side panel. Dropping beside an item in another folder moves it into that folder. A folder cannot be moved into itself or one of its subfolders.
- **Several at once** in the manager: select rows in the table, then use **Move to folder** and choose the destination. Items are added at the end of that folder.
- **Reorder** in the manager: turn on **Browser order**, clear any column sort, then use the **Move up**, **Move down**, **Move to top**, and **Move to bottom** buttons on the row. They need the table to show one folder, so clear filters or check **Current folder only**.

Reordering changes the browser's saved order. The popup shows that order only with the **Folders First** sort; date and alphabetical sorting keep re-sorting the list, and the confirmation says so.

The popup and side panel refresh on their own when bookmarks change elsewhere, such as in the manager or in the browser's own bookmark UI.

## Sort the tree

Choose **Date Added**, **Alphabetical** (natural order, so `2` comes before `10`), or **Folders First** with **Sort Order** in Settings. Sorting changes only how Bookmark Scout shows the tree, never the browser's stored order. **Group by Folders** lists subfolders before bookmarks at each level of the popup and side panel.

## Edit a bookmark

In the manager, open a row's menu and choose **Edit** to change a bookmark's name and URL, or a folder's name. **View Details** shows the full path, dates, and ID, and is where you add **Tags** and a **Summary**.

Tags and summaries are stored only in this browser's local extension storage. They are not synced or searchable. JSON bookmark exports include them, and AI context exports can too; see [Import and export](/guides/import-export) and [Set up AI tools](/guides/ai-tools).

## Delete and undo

Delete a bookmark or folder from the popup, the side panel, or a manager row's menu, or select several rows in the manager and delete them together.

- **Confirm Before Delete** is on by default and shows a dialog naming what will be removed. Turn it off on the **Behavior** tab of Settings to delete immediately.
- Every deletion shows **Undo** for 10 seconds. Undo restores the item, everything inside it, and its saved tags and summaries. A restored item is recreated, so it gets a new date added.
- Permanent folders such as the Bookmarks Bar cannot be edited or deleted.
