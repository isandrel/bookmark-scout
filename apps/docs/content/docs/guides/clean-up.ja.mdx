どちらのツールも、ブックマークマネージャーの **ツール** サイドバーの **メンテナンス** にあります。Chrome では、ブラウザのブックマークページを開き、サイドバーが隠れている場合はマネージャーのヘッダーにある **ツールを表示** をクリックします。

<Callout title="Firefox">
Firefox では拡張機能が Firefox 自体のブックマークページを置き換えられないため、ツールバーのポップアップの **ブックマークマネージャーを開く** でマネージャーを開き、ツール サイドバーを開いてください。
</Callout>

## 重複したブックマークを削除する [#remove-duplicate-bookmarks]

<Steps>
<Step>
**重複クリーナー** で **スキャン** をクリックします。スキャンは常にすべてのブックマークを対象にします。
</Step>
<Step>
グループを確認します。各グループには共通のアドレスが一度だけ表示され、その下に各ブックマークがフォルダと追加日とともに並びます。**保持** の印は **保持ルール** に従って付きますが、ラジオボタンで別のものを選べます。ほかのコピーにはそれぞれ **削除** のチェックボックスがあり、最初はチェックされています。残したいコピーやグループのチェックを外します。
</Step>
<Step>
**重複 N 件を削除** をクリックするとチェックしたコピーが削除されます。何も変更しない場合は **キャンセル** をクリックします。
</Step>
<Step>
気が変わった場合は、10 秒以内にメッセージの **元に戻す** をクリックすると、削除したものが復元されます。後からでも、ブックマークマネージャーで <Shortcut id="manager.undo" /> を押すと復元できます。
</Step>
</Steps>

<Screenshot name="duplicates" />

何を重複とみなすかは、[設定](/settings)の **メンテナンス** タブで設定します。

| 設定 | 初期値 | 内容 |
| --- | --- | --- |
| **照合方法** | 正規化したURL | **URLが完全一致**、**正規化したURL**、**タイトル + URL**、**タイトルのみ** のいずれかで比較します |
| **wwwを正規化** | オン | `www.example.com` と `example.com` を同じホストとして扱います |
| **プロトコルを無視** | オン | `http` と `https` の URL を重複として扱います |
| **末尾のスラッシュを無視** | オン | 末尾の `/` の有無だけが異なる URL を重複として扱います |
| **保持ルール** | 最も古いもの | 各グループで **最も古いもの**、**最も新しいもの**、**最初に見つかったもの** のいずれかを残します |
| **最大グループ数** | <SettingDefault path="maintenance.duplicates.max_groups" /> | 1 回のスキャンで返すグループの最大数です |

削除の前に、各グループはもう一度確認されます。**保持** の印が付いたブックマークが削除されていたり、別の場所を指すようになっていたりした場合、そのグループ全体には手を加えず、スキップしたグループの数がメッセージで示されます。**タイトルのみ** で照合している場合、グループに異なる URL が含まれていると警告が表示されます。そのコピーを削除すると、別々のページを削除することになるためです。

## トラッキングパラメータを取り除く [#strip-tracking-parameters]

<Steps>
<Step>
**URLクリーナー** の範囲メニューで現在のフォルダかすべてのブックマークを選び、**クリーン** をクリックします。
</Step>
<Step>
変更される URL を、クリーンする理由（`utm_*` などの **削除するパラメータ** の項目、重複したパラメータ、フラグメント）ごとに確認します。最初はすべて **クリーン** です。残したいものは 1 件ずつ、または **選択した項目を設定…** でまとめて **そのまま残す** にします。
</Step>
<Step>
**N 件の URL をクリーン** をクリックすると **クリーン** のままの URL を更新します。何も変更しない場合はダイアログを閉じます。
</Step>
</Steps>

プレビューの後にブックマークが変更された場合、そのブックマークはスキップされ、件数がメッセージに含まれます。メッセージの **元に戻す** をクリックするか、ブックマークマネージャーで <Shortcut id="manager.undo" /> を押すと、元の URL に戻ります。その後に再び変更されたブックマークはそのままになります。

ルールは設定の **メンテナンス** タブにあります。

- **削除するパラメータ**: 取り除くパラメータです。初期設定のリストは <SettingDefault path="maintenance.url_cleaner.remove_params" /> です。末尾が `*` の名前は、その文字列で始まるすべての名前に一致します。
- **保持するパラメータ**: 削除しないパラメータです。初期設定: <SettingDefault path="maintenance.url_cleaner.preserve_params" />。
- **クエリパラメータの重複を削除**（初期設定でオン）は、繰り返し出てくるパラメータを削除します。
- **クエリパラメータを並べ替え**（初期設定でオン）は、残ったパラメータをアルファベット順に並べ替えます。
- **フラグメントを削除**（初期設定でオフ）は、`#section` のような部分も削除します。

## サイトアイコンを更新する [#refresh-site-icons]

Bookmark Scout がサイトのアイコンを持つまで、ブックマークには汎用の地球儀アイコンが表示されます。Chrome と Edge でいちばん手軽なのは、**サイトアイコンを更新** カードの **ブラウザのアイコンを表示**、または[設定](/settings#appearance)の **ブラウザのアイコンキャッシュを使う** です。アクセスしたサイトについてブラウザがすでに保存しているアイコンを表示し、ブラウザが求めるのはサイトアイコンの読み取りだけです。ブラウザにアイコンがないサイトや、拡張機能にアイコンキャッシュを提供しない Firefox では、ツール サイドバーの **ページのタイトルとアイコン** にある **サイトアイコンを更新** が、各サイト自身のアイコンをダウンロードします。

<Steps>
<Step>
範囲メニューで現在のフォルダかすべてのブックマークを選び、**更新** をクリックします。確認が表示されたら、その範囲のサイトへのアクセスを許可してください（20 を超えるサイトを含む範囲では、すべてのウェブサイトへのアクセスを求めます）。許可しなかった場合、リクエストは送信されません。
</Step>
<Step>
サイトをタブごとに確認します: **新しいアイコン**、**同じアイコン**、**アイコンなし**、**失敗** があり、それぞれ件数が表示されます。ウェブリンクではないためスキップしたブックマークの件数も表示されます。見つかったアイコンは最初 **アイコンを保存** になっています。**スキップ** に変えるか、複数選択して **選択した項目を設定…** を使います。
</Step>
<Step>
**保存**（たとえば **アイコン 12 件を保存**）をクリックすると、**アイコンを保存** のままのアイコンを残します。何も残さない場合はダイアログを閉じます。
</Step>
</Steps>

範囲内のウェブサイト（オリジン）ごとに、ツールはブックマークしたページを 1 つ Cookie なしでリクエストし、その head 部分だけを読み取ります。そして、ページに記載されたアイコンのうち **優先するアイコンサイズ** に最も近いもの、またはサイトの `/favicon.ico` をダウンロードします。使われるのはブックマーク自身のドメインにあるアイコンファイルだけで、サードパーティのアイコンサービスは使いません。**アイコンファイルの最大サイズ**（<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> KB）を超えるファイルや画像でないファイルはスキップされます。

更新はバックグラウンドで実行されます。マネージャーを閉じても続き、カードと **バックグラウンドのタスク** に進行状況が表示され、**一時停止**、**再開**、**キャンセル** ができます。結果は **結果を見る** から確認でき、**保存** をクリックするまで何も保存されません。

保存したアイコンはこのブラウザのローカルストレージに保存され、同期されません。ポップアップ、サイドパネル、マネージャーに表示され、ブラウザがキャッシュしたアイコンより優先されます。カードには保存済みの件数が表示され、**保存したアイコンを消去** ですべて削除できます。合計が **アイコンの保存容量上限**（4 MB）に達すると、古いアイコンから削除されます。後の更新で失敗したサイトは、以前に保存したアイコンをそのまま使います。

<Callout title="Firefox">
Firefox でこのツールを実行するには、ツールバーのポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。そこでアイコンを保存すると、ポップアップとサイドパネルにも表示されます。
</Callout>

## スマートルールでタグ付けと移動 [#tag-and-move-with-smart-rules]

スマートルールは、検索ボックスと同じ単語と[演算子](/guides/search#search-words-and-operators)を使った検索でブックマークを見つけ、タグを追加する、フォルダに移動する、またはその両方を行います。ルールが勝手に動くことはありません。実行するたびに確認画面が開き、適用したものだけが変わります。

<Steps>
<Step>
[設定](/settings#maintenance) の **スマートルール** で **ルールを追加** をクリックします。GitHub のページ、YouTube の動画、チュートリアルにタグを付けるルールなら **テンプレートから始める** も使えます。テンプレートは最初オフです。
</Step>
<Step>
ルールに名前と検索（`domain:github.com`、`folder:あとで読む -tag:既読` など）を付けます。エディターには、現在一致するブックマークの数が表示されます。カンマ区切りのタグ、移動先のフォルダ、またはその両方を指定して保存します。
</Step>
<Step>
マネージャーのツールサイドバーで、**スマートルール** カードの範囲を選び、**実行** をクリックします。
</Step>
<Step>
ブックマークをタブごとに確認します: **変更**、**競合**（2 つのルールが別々のフォルダに移動しようとしている）、**ブロック**（フォルダがない、または管理されている）、**適用済み**。変更は最初 **適用**、競合は **スキップ** になっています。1 件ずつ、または **選択した項目を設定…** で変え、**適用**（たとえば **12 件の変更を適用**）をクリックします。
</Step>
</Steps>

知っておくと便利なこと:

- ルールは一覧の順に実行されます。一致したルールはすべてタグを追加し、ブックマークを移動するルールは最初のものが優先されます。後のルールが指定したフォルダは競合として表示されます。ルールをドラッグすると順序を変えられます。
- ブックマークにすでにあるタグは、表記が違っても追加されません。フォルダにタグを付けたり、フォルダを移動したりすることはありません。
- 適用後のメッセージの **元に戻す** で、移動とタグの両方が元に戻ります。移動は履歴の 1 つの変更になります。
- ルールはこの端末に保存され、**設定をバックアップ** に含まれます。別の端末で復元したルールは、そこにフォルダがある場合だけブックマークを移動します。ない場合は、フォルダを選び直すまで移動はブロックされます。
## ページの中を検索 [#search-inside-pages]

**ページ本文の索引** は、ブックマークしたページの読み取れる本文をこの端末に保存し、ページの中にしかない単語でも検索で見つけられるようにします。オンにするまでオフで、索引を作るページはダウンロードされます。

<Steps>
<Step>
[設定](/settings#index-page-text) で **ページ本文の索引を有効にする** をオンにします。
</Step>
<Step>
マネージャーのツールサイドバーで、**ページ本文の索引** カードの範囲を選び、**索引を作成** をクリックします。確認されたら、その範囲のサイトへのアクセスを許可します。
</Step>
<Step>
ページをタブごとに確認します: **本文あり**、**本文なし**、**失敗**、**索引済み**（以前に同じアドレスから作成済み）、**スキップ**（ウェブページではない、またはローカルネットワーク上）。本文のあるページは最初 **本文を保存** になっています。**保存**（たとえば **12 ページの本文を保存**）をクリックします。
</Step>
</Steps>

その後は、ポップアップ、サイドパネル、マネージャーでそのブックマークを本文から検索できます。`content:` はページ本文だけを探し、`has:content` は本文のあるブックマークを見つけます。ブックマークのアドレスが変わると、そのページはもう一度読み取られます。設定の **ページ本文を削除** で索引を削除しても、ブックマーク、タグ、履歴はそのままです。

## 関連するツール [#related-tools]

- [リンク切れの検出と修復](/guides/dead-links)では、ブックマークしたページが今も読み込めるかを確認します。
- **プライバシースキャナー**（**セキュリティ** の下）は、トークン、メールアドレス、UUID、機密パラメータを含む URL（**タイトルをスキャン** がオンの場合はタイトルも）を検出します。確認画面では **高**、**中**、**低** に分けて表示されます。各項目は最初 **そのまま残す** になっており、**ブックマークを削除** に変えた項目（1 件ずつ、または **選択した項目を設定…** で）は **削除** をクリックすると削除され、元に戻せます。通常のページ内リンクや、Gmail の `#inbox` のようなアプリのアドレスは検出されません。
- **メタデータ取得**（**ページのタイトルとアイコン** の下）は、実際のページからページタイトルを提案し、選んだものだけを適用します。リンク切れチェックと同じウェブサイトへのアクセス権限を使います。これもバックグラウンドで実行され、タイトルは **結果を見る** から確認できます。
