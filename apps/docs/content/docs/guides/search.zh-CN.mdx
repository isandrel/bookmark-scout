## 在弹出窗口或侧边栏中搜索 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
点击工具栏中的 Bookmark Scout 图标。在 Chrome 和 Edge 中，你也可以在浏览器的侧边栏中打开 Bookmark Scout，浏览网页时侧边栏会保持打开。
</Step>
<Step>
在搜索框中输入内容：搜索框显示为**搜索书签…**，也可以按 `/` 直接跳转到该框。结果会在输入时即时显示在各自的文件夹中，每个匹配项都会高亮显示。
</Step>
<Step>
使用搜索框内的三个按钮缩小匹配范围：**区分大小写**、**全字匹配**和**使用正则表达式**。
</Step>
<Step>
点击某个书签，或使用方向键移到该书签上并按 `Enter`，即可在新标签页中打开它。
</Step>
</Steps>

<Screenshot name="popup" />

注意事项：

- 全字匹配会将空格、标点符号和文字类型的切换视为词边界，因此 `C++` 之类的词语和日语词语都能匹配。
- 无效的正则表达式会显示警告，并按纯文本进行搜索。
- 书签栏等固定文件夹属于容器，永远不会按名称匹配。
- 当匹配项多于结果数量上限时，会显示一条提示，说明显示了多少项。请缩小搜索范围，或在[设置](/settings)中提高**最大搜索结果数**。
- 清空搜索（点击清除按钮，或在搜索框中按 `Esc`）会恢复你之前展开的文件夹。
- 最近的搜索会保存在本设备上。点击空白的搜索框，或在搜索框中按 `Alt+↓`，即可列出最近的搜索。你可以在该列表中清除它们，或在设置中关闭**搜索历史记录**。

## 在书签管理器中筛选 [#filter-in-the-bookmarks-manager]

书签管理器的表格提供更精确的筛选器。在 Chrome 中，打开浏览器的书签页面即可进入书签管理器。

- **筛选标题…**、**筛选网址…**：分别匹配这两列中的文字。按 `/` 可跳转到标题筛选器。
- **类型**、**父级 ID**、**域名**和**添加日期**可进一步缩小显示的行。
- **仅当前文件夹**会将筛选范围限制在你所在的文件夹中。关闭后，筛选器会搜索所有书签。
- 点击任意列的列标题即可按该列排序。

## 保存搜索 [#save-a-search]

已保存的搜索会以一个名称保存书签管理器当前的筛选条件、排序和文件夹范围，方便你以后重新打开同一视图。

<Steps>
<Step>
至少设置一个筛选条件：标题、网址、类型、文件夹、域名或添加日期。
</Step>
<Step>
点击表格工具栏中的**已保存的搜索**，或按 `s`。
</Step>
<Step>
在**为此搜索命名**中输入名称，然后点击**保存**。
</Step>
</Steps>

如需使用某个已保存的搜索，请打开**已保存的搜索**并选择它。它的筛选条件和排序会替换当前的设置；如果它限定在某个文件夹中，书签管理器会返回该文件夹。每个条目都可以重命名或删除，删除后可以在随后出现的消息中撤消。

已保存的搜索存储的是筛选条件的定义，而不是书签的副本，因此其结果始终与你当前的书签一致。如果它指定的某个文件夹已被删除，该文件夹会被跳过，其他筛选条件仍然有效，并会显示一条消息说明跳过了多少个文件夹。

已保存的搜索保存在此浏览器的本地扩展程序存储中，不会同步，因为其中的筛选条件可能透露你收藏的内容，而且不同设备上的文件夹 ID 也不相同。最多可以保存 50 个。

<Callout title="Firefox">
在 Firefox 中，请通过弹出窗口中的**打开书签管理器**打开书签管理器。
</Callout>
