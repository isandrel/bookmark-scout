## 在弹出窗口或侧边栏中搜索 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
点击工具栏中的 Bookmark Scout 图标。你也可以在浏览器的侧边栏（Firefox 中为侧栏）中打开 Bookmark Scout，浏览网页时侧边栏会保持打开。
</Step>
<Step>
在顶部的搜索框中输入内容。搜索框中显示**输入文件夹名称来保存此页面…**，它同样可以搜索你的书签（按 <Shortcut id="popup.focus_search" /> 可直接跳转到该框）。结果会在输入时即时显示在各自的文件夹中，每个匹配项都会高亮显示。每个词都必须匹配标题、网址、文件夹或标签和摘要中的某一处；参见[搜索词和运算符](#search-words-and-operators)。
</Step>
<Step>
使用搜索框内的**更多搜索选项**按钮缩小匹配范围：**区分大小写**、**全字匹配**和**高级模式搜索（正则表达式）**，后者会把搜索内容当作正则表达式处理。只要其中任何一项开启，该按钮就会高亮显示。这些选项只按输入原样搜索标题，不使用运算符。
</Step>
<Step>
点击某个书签，或使用方向键移到该书签上并按 `Enter`，即可在新标签页中打开它。
</Step>
</Steps>

注意事项：

- 全字匹配会将空格、标点符号和文字类型的切换视为词边界，因此 `C++` 之类的词语和日语词语都能匹配。
- 无效的正则表达式会显示警告，并按纯文本进行搜索。
- 书签栏等固定文件夹属于容器，永远不会按名称匹配。
- 当匹配项多于结果数量上限时，会显示一条提示，说明显示了多少项。请缩小搜索范围，或在[设置](/settings)中提高**最大搜索结果数**。
- 清空搜索（点击清除按钮，或在搜索框中按 `Esc`）会恢复你之前展开的文件夹。
- 最近的搜索会保存在本设备上。点击空白的搜索框，或在搜索框中按 <Shortcut id="popup.recent_searches" />，即可列出最近的搜索。你可以在该列表中清除它们，或在设置中关闭**搜索历史记录**。

## 搜索词和运算符 [#search-words-and-operators]

弹出窗口、侧边栏和书签管理器中的搜索框以相同方式读取搜索内容。它们只搜索此浏览器中的书签，不会向任何地方发送数据。

- 每个词都必须匹配，各自可以出现在任意位置：标题、网址、文件夹路径，或书签的标签和摘要。`菜谱 汤` 会找到“菜谱”文件夹中名为“汤”的书签。
- 引号会让词语连在一起匹配：`"react hooks"`。
- 在前面加 `-` 会排除匹配的内容：`菜谱 -蛋糕` 或 `-tag:归档`。
- 两个搜索词之间的大写 `OR` 表示满足其一即可：`tag:react OR tag:vue`。它比空格结合得更紧，所以 `domain:github.com tag:react OR tag:vue` 会找到带有其中任一标签的 GitHub 页面。小写的 `or` 仍是要查找的普通词语。
- 括号可以组合搜索词：`domain:github.com (tag:react OR tag:vue) -tag:archived`。在括号前加 `-` 会排除整组匹配的内容：`-(tag:old OR tag:archive)`。词语内部的括号（例如 `f(x)`）按文字搜索。
- 与文件夹名称匹配的词会找到该文件夹。在弹出窗口中，其中的书签显示在该文件夹内；`folder:` 会列出其中的全部内容。
- 不是运算符的文字会按输入原样搜索，例如 `C++`、`10:30` 或网址。Bookmark Scout 不认识的运算符（例如 `foo:bar`）也一样。无法读取的值（例如无效日期）会被跳过。括号未闭合，或 `OR` 的某一侧没有搜索词时，搜索框下方会给出提示。嵌套过深的括号或过长的 `OR` 列表会被截断，并附有提示。

| 搜索 | 查找内容 |
| --- | --- |
| `title:react` | 包含该文字的标题；`title:"react hooks"` 可以包含多个词 |
| `url:github` | 包含该文字的网址 |
| `domain:github.com` | 该网站上的书签，包括其子域名 |
| `folder:工作` 或 `path:工作` | 名称完全相同的文件夹中的所有内容（任意层级）；`folder:"工作 / 文档"` 表示另一个文件夹中的文件夹 |
| `tag:稍后阅读` | 带有完全相同标签的书签 |
| `summary:菜谱` | 包含该文字的摘要 |
| `content:菜谱` | 你用**索引网页正文**索引的网页正文 |
| `is:bookmark` 或 `is:folder` | 只有书签，或只有文件夹 |
| `is:untagged` | 没有标签的书签 |
| `has:tags` 或 `has:summary` | 有标签的项目，或有摘要的项目 |
| `has:content` | 网页正文已索引的书签 |
| `after:2026-01-31` 或 `before:2026-01-31` | 在该日期当天或之后添加的项目，或在当天或之前添加的项目 |
| `tag:react OR tag:vue` | 匹配任一侧的书签；`OR` 必须大写 |
| `(tag:react OR tag:vue) -tag:old` | 用括号组合的搜索词：带有 react 或 vue 标签，且没有 old 标签 |

标签和摘要是你在**书签详情**中添加的，或从**自动标签**和**内容摘要**工具的建议中保留的。它们只保存在此设备上。

开启**索引网页正文**后，普通词语也会匹配已索引网页的正文（排在标题、网址、标签和摘要之后）；弹出窗口中这样找到的结果会显示匹配处附近的文字。参见[在网页中搜索](/guides/clean-up#search-inside-pages)。

加引号的短语只在网页正文的同一段落内匹配。**索引网页正文**关闭时，使用 `content:` 或 `has:content` 的搜索会在搜索框下方提示这一点，而不是什么也找不到。

## 在书签管理器中筛选 [#filter-in-the-bookmarks-manager]

书签管理器的表格提供更精确的筛选器。在 Chrome 中，打开浏览器的书签页面即可进入书签管理器，它会先打开你的书签栏。

- **搜索标题、网址、文件夹和标签**：读取[搜索词和运算符](#search-words-and-operators)，列出匹配的文件夹和书签。按 <Shortcut id="manager.focus_filter" /> 可直接跳到这个搜索框。搜索框末尾的**搜索语法**按钮会列出运算符，选择一个即可添加到搜索中。如果搜索是通过网址、标签、摘要或网页正文而不是标题找到某一行，标题下方会像弹出窗口中一样注明匹配位置。
- **筛选**包含其他所有筛选条件：**仅当前文件夹**、**类型**、**域名**、**文件夹**（只保留你选中的文件夹中的项目）、**添加日期**和<strong>筛选网址…</strong>（只匹配网址）。每个正在使用的筛选条件都会以标签形式显示在工具栏下方，点击其 **×** 即可移除；**重置**会清除所有筛选条件和搜索。搜索中的问题（例如无效日期）会在工具栏下方说明。
- **仅当前文件夹**会将筛选范围限制在你所在的文件夹中。关闭后，筛选器会搜索所有书签，每个结果的标题下方会显示其所在的文件夹，顶部的路径会显示**所有文件夹中的结果**。
- 点击任意列的列标题即可按该列排序。表格不是浏览器顺序时，**浏览器顺序**旁边的文字会说明当前的排序；点击**浏览器顺序**即可恢复。
- 表格显示**标题**、**网址**和**添加日期**，每页 50 行。可以在**查看**中打开**类型**、**文件夹路径**等其他列，并在表格下方选择每页的行数。要调整列的顺序，可在**查看**中拖动列的手柄，或使用旁边的箭头按钮。也可以在表格中拖动列标题到新位置，或通过列标题的菜单将该列左移或右移。
- **查看**旁边的两个按钮可在列表和**卡片**之间切换。卡片以网格显示相同的行、筛选、排序、选择和菜单：左右键一次移动一张卡片，上下键一次移动一行卡片，双击可打开文件夹或链接。所选视图保存在此设备上。卡片会显示书签已保存的封面（没有时在该位置显示网站图标）、标题和网址、前几个标签（其余的以 **+N** 标签计数）以及摘要的前几行；文件夹卡片显示文件夹中有多少项。显示卡片不会下载任何内容。
- 书签菜单（**⋯** 按钮或右键菜单）中的**预览**，或在当前卡片或行上按 <Shortcut id="manager.preview" />，会显示书签已保存的封面、网址、文件夹、标签和摘要，并提供**在新标签页中打开**、**复制**和**修改**。显示时不会下载任何内容。按 <Shortcut id="manager.preview_previous" /> 和 <Shortcut id="manager.preview_next" />，或点按预览顶部的箭头按钮，可显示本页的上一个或下一个书签；会跳过文件夹，并在第一个和最后一个书签处停下。`Tab` 只在预览内移动，按 `Esc` 关闭并回到所显示书签的卡片。
- 在跨文件夹搜索时，行菜单中提供**在文件夹中显示**：它会清除筛选条件，打开包含该项目的文件夹，并选中该项目。

## 链接到文件夹或搜索 [#link-to-a-folder-or-a-search]

书签管理器的地址会跟随你正在查看的内容变化，因此浏览器的**返回**和**前进**可以在文件夹和搜索之间逐步切换，你也可以将某个视图加入书签或分享出去。

- `?id=` 表示打开的文件夹，与 Chrome 自带的书签管理器相同：在 Chrome 中，`chrome://bookmarks/?id=12` 会打开文件夹 12，在 Edge 中则是 `edge://favorites/?id=12`。Chrome 154 到 156 生成的链接用很长的 ID 表示书签栏、其他书签和移动设备书签，这些链接同样可以打开相应的文件夹。没有 `?id=` 时，书签管理器会打开书签栏；点击文件夹路径开头的**书签**可查看最顶层。
- `?q=` 表示搜索：`chrome://bookmarks/?q=react` 会打开书签管理器并搜索“react”，`?q=tag:reading` 则搜索该标签。在**搜索标题、网址、文件夹和标签**中输入时，地址会随之更新，连续输入一次只算一步**返回**。搜索优先于文件夹；勾选**仅当前文件夹**时，文件夹仍然有效。
- **复制此文件夹的链接**位于顶部的文件夹路径旁边和文件夹行的菜单中，可复制该地址。在 Firefox 中，它复制的是书签管理器页面本身的地址。Chrome 和 Edge 会一直显示你打开书签管理器时使用的地址，即使你在文件夹之间切换也是如此。
- 标签页标题会显示文件夹名称，搜索时则显示搜索内容。

## 保存搜索 [#save-a-search]

已保存的搜索会以一个名称保存书签管理器当前的筛选条件、排序和文件夹范围，方便你以后重新打开同一视图。

<Steps>
<Step>
至少设置一个筛选条件：标题、网址、类型、文件夹、域名或添加日期。
</Step>
<Step>
点击表格工具栏中的**已保存的搜索**，或按 <Shortcut id="manager.open_saved_searches" />。
</Step>
<Step>
在**为此搜索命名**中输入名称，然后点击**保存**。
</Step>
</Steps>

如需使用某个已保存的搜索，请打开**已保存的搜索**并选择它。它的筛选条件和排序会替换当前的设置；如果它限定在某个文件夹中，书签管理器会返回该文件夹。每个条目都可以重命名或删除，删除后可以在随后出现的消息中撤消。拖动条目的手柄可调整顺序，也可以打开手柄的菜单用键盘移动。

搜索框中的文字会按输入原样保存，包括运算符。在搜索框支持运算符之前保存的搜索只在标题和网址中查找文字。现在，如果文字包含多个词或冒号，打开时会加上引号，因此仍能找到以前找到的所有书签。在支持 `OR` 和括号之前保存的搜索，打开时也会出于同样的原因把它们放在引号中。

已保存的搜索存储的是筛选条件的定义，而不是书签的副本，因此其结果始终与你当前的书签一致。如果它指定的某个文件夹已被删除，该文件夹会被跳过，其他筛选条件仍然有效，并会显示一条消息说明跳过了多少个文件夹。

已保存的搜索保存在此浏览器的本地扩展程序存储中，不会同步，因为其中的筛选条件可能透露你收藏的内容，而且不同设备上的文件夹 ID 也不相同。最多可以保存 50 个。

<Callout title="Firefox">
在 Firefox 中，请通过弹出窗口中的**打开书签管理器**打开书签管理器。
</Callout>
