## 在弹出窗口或侧边栏中搜索 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
点击工具栏中的 Bookmark Scout 图标。你也可以在浏览器的侧边栏（Firefox 中为侧栏）中打开 Bookmark Scout，浏览网页时侧边栏会保持打开。
</Step>
<Step>
在顶部的搜索框中输入内容。搜索框中显示**输入文件夹名称来保存此页面…**，它同样可以搜索你的书签（按 <Shortcut id="popup.focus_search" /> 可直接跳转到该框）。结果会在输入时即时显示在各自的文件夹中，每个匹配项都会高亮显示。
</Step>
<Step>
使用搜索框内的**更多搜索选项**按钮缩小匹配范围：**区分大小写**、**全字匹配**和**高级模式搜索（正则表达式）**，后者会把搜索内容当作正则表达式处理。只要其中任何一项开启，该按钮就会高亮显示。
</Step>
<Step>
点击某个书签，或使用方向键移到该书签上并按 `Enter`，即可在新标签页中打开它。
</Step>
</Steps>

注意事项：

- 全字匹配会将空格、标点符号和文字类型的切换视为词边界，因此 `C++` 之类的词语和日语词语都能匹配。
- 无效的正则表达式会显示警告，并按纯文本进行搜索。
- 书签栏等固定文件夹属于容器，永远不会按名称匹配。
- 当匹配项多于结果数量上限时，会显示一条提示，说明显示了多少项。请缩小搜索范围，或在[设置](/settings)中提高**最大搜索结果数**。
- 清空搜索（点击清除按钮，或在搜索框中按 `Esc`）会恢复你之前展开的文件夹。
- 最近的搜索会保存在本设备上。点击空白的搜索框，或在搜索框中按 <Shortcut id="popup.recent_searches" />，即可列出最近的搜索。你可以在该列表中清除它们，或在设置中关闭**搜索历史记录**。

## 在书签管理器中筛选 [#filter-in-the-bookmarks-manager]

书签管理器的表格提供更精确的筛选器。在 Chrome 中，打开浏览器的书签页面即可进入书签管理器，它会先打开你的书签栏。

- **搜索标题和网址**：匹配书签标题或网址中的文字。按 <Shortcut id="manager.focus_filter" /> 可直接跳到这个搜索框。
- **类型**、**域名**和**添加日期**可进一步缩小显示的行。**更多筛选**中还有<strong>筛选网址…</strong>（只匹配网址）和**文件夹**（只保留你选中的文件夹中的项目）。
- **仅当前文件夹**会将筛选范围限制在你所在的文件夹中。关闭后，筛选器会搜索所有书签，每个结果的标题下方会显示其所在的文件夹，顶部的路径会显示**所有文件夹中的结果**。
- 点击任意列的列标题即可按该列排序。表格不是浏览器顺序时，**浏览器顺序**旁边的文字会说明当前的排序；点击**浏览器顺序**即可恢复。
- 表格显示**标题**、**网址**和**添加日期**，每页 50 行。可以在**查看**中打开**类型**、**文件夹路径**等其他列，并在表格下方选择每页的行数。要调整列的顺序，可在**查看**中拖动列的手柄，或使用旁边的箭头按钮。也可以在表格中拖动列标题到新位置，或通过列标题的菜单将该列左移或右移。
- 在跨文件夹搜索时，行菜单中提供**在文件夹中显示**：它会清除筛选条件，打开包含该项目的文件夹，并选中该项目。

## 链接到文件夹或搜索 [#link-to-a-folder-or-a-search]

书签管理器的地址会跟随你正在查看的内容变化，因此浏览器的**返回**和**前进**可以在文件夹和搜索之间逐步切换，你也可以将某个视图加入书签或分享出去。

- `?id=` 表示打开的文件夹，与 Chrome 自带的书签管理器相同：在 Chrome 中，`chrome://bookmarks/?id=12` 会打开文件夹 12，在 Edge 中则是 `edge://favorites/?id=12`。Chrome 154 到 156 生成的链接用很长的 ID 表示书签栏、其他书签和移动设备书签，这些链接同样可以打开相应的文件夹。没有 `?id=` 时，书签管理器会打开书签栏；点击文件夹路径开头的**书签**可查看最顶层。
- `?q=` 表示搜索：`chrome://bookmarks/?q=react` 会打开书签管理器，并在标题和网址中搜索“react”。在**搜索标题和网址**中输入时，地址会随之更新，连续输入一次只算一步**返回**。搜索优先于文件夹；勾选**仅当前文件夹**时，文件夹仍然有效。
- **复制此文件夹的链接**位于顶部的文件夹路径旁边和文件夹行的菜单中，可复制该地址。在 Firefox 中，它复制的是书签管理器页面本身的地址。Chrome 和 Edge 会一直显示你打开书签管理器时使用的地址，即使你在文件夹之间切换也是如此。
- 标签页标题会显示文件夹名称，搜索时则显示搜索内容。

## 保存搜索 [#save-a-search]

已保存的搜索会以一个名称保存书签管理器当前的筛选条件、排序和文件夹范围，方便你以后重新打开同一视图。

<Steps>
<Step>
至少设置一个筛选条件：标题、网址、类型、文件夹、域名或添加日期。
</Step>
<Step>
点击表格工具栏中的**已保存的搜索**，或按 <Shortcut id="manager.open_saved_searches" />。
</Step>
<Step>
在**为此搜索命名**中输入名称，然后点击**保存**。
</Step>
</Steps>

如需使用某个已保存的搜索，请打开**已保存的搜索**并选择它。它的筛选条件和排序会替换当前的设置；如果它限定在某个文件夹中，书签管理器会返回该文件夹。每个条目都可以重命名或删除，删除后可以在随后出现的消息中撤消。拖动条目的手柄可调整顺序，也可以打开手柄的菜单用键盘移动。

已保存的搜索存储的是筛选条件的定义，而不是书签的副本，因此其结果始终与你当前的书签一致。如果它指定的某个文件夹已被删除，该文件夹会被跳过，其他筛选条件仍然有效，并会显示一条消息说明跳过了多少个文件夹。

已保存的搜索保存在此浏览器的本地扩展程序存储中，不会同步，因为其中的筛选条件可能透露你收藏的内容，而且不同设备上的文件夹 ID 也不相同。最多可以保存 50 个。

<Callout title="Firefox">
在 Firefox 中，请通过弹出窗口中的**打开书签管理器**打开书签管理器。
</Callout>
