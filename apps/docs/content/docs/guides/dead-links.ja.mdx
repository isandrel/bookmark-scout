---
title: リンク切れの検出と修復
description: ブックマークのリンク切れをスキャンし、手動で確認が必要なものを把握して、削除、リダイレクト先の使用、アーカイブ版の使用、URL の編集で修復します。
---

**リンク切れチェック** は、ブックマークマネージャーの **ツール** サイドバーの **メンテナンス** にあります。ブックマークした各ページにリクエストを送り、今も読み込めるかを確認します。

<Callout title="Firefox">
Firefox では、ポップアップの **ブックマークマネージャーを開く** でマネージャーを開きます。
</Callout>

## スキャンを実行する [#run-a-scan]

<Steps>
<Step>
**リンク切れチェック** の範囲メニューで現在のフォルダかすべてのブックマークを選び、**スキャン** をクリックします。
</Step>
<Step>
初回は、ウェブサイトへのアクセスが必要な理由を Bookmark Scout が説明します。**アクセスを許可** をクリックし、ブラウザの確認画面で許可してください。**後で** を選んだり許可しなかったりした場合、スキャンは行われません。
</Step>
<Step>
結果が出るまで待ちます。上部の概要に、リンク切れが確定したもの、手動での確認が必要なもの、リダイレクトされたものの件数が表示されます。
</Step>
</Steps>

ウェブサイトへのアクセスは任意で、インストール時には許可されません。リクエストは Cookie なしで送信され、アクセス権限はブラウザの拡張機能の設定で取り消せます。[権限](/permissions)をご覧ください。

## 結果の見方 [#read-the-results]

| 結果 | 意味 |
| --- | --- |
| **リンク切れ確定** | ページが見つからない（404 または 410）、接続が拒否された、ホストが見つからない、またはリダイレクトがループした |
| **手動で確認** | ブラウザでは開けることが多いもの: サインインが必要またはアクセス拒否（401、403、407）、リクエスト制限（429）、サイトが自動チェックを拒否（405 または 501）、サーバーエラー（5xx）、その他の HTTP エラー、またはタイムアウト |
| **リダイレクト** | リンクは有効だが、今は別の場所を指している。リダイレクト先が表示される |
| **スキップ** | ブックマークレットなど、Web リンクではないもの |

`HEAD` リクエストでエラーが返った場合は、一部のサーバーが `HEAD` に対応していないため、報告する前に `GET` で確認し直します。

<Callout type="info" title="Chrome のコンソールメッセージ">
Chrome は、失敗したリクエストごとに、ページのデベロッパーコンソールに「Failed to load resource」という行を 1 つ記録します。拡張機能はこの行を抑止できません。スキャン自体は何も記録しません。
</Callout>

## リンクを修復する [#repair-links]

<Steps>
<Step>
**修復を確認** をクリックします。失敗したリンク、タイムアウトしたリンク、リダイレクトされたリンクがすべて一覧表示されます。
</Step>
<Step>
それぞれについて処理を選びます。

- **そのまま残す**（初期値です。ほかを選ばない限り何も変わりません）
- **ブックマークを削除**
- **リダイレクト先に置き換え**（スキャンでリダイレクトが検出された場合のみ表示されます）
- **アーカイブ版に置き換え (Wayback Machine)**: ブックマークの URL を `https://web.archive.org/web/<original URL>` に変更します。このリンクはローカルで組み立てられ、確認はされないため、そのページが一度もアーカイブされていない可能性もあります。
- **URL を編集**: 現在の URL と異なる、有効な `http` または `https` の URL だけを受け付けます。
</Step>
<Step>
削除されるブックマーク、URL が置き換えられるブックマーク、そのまま残るブックマークの件数の概要を確認し、**N 件の変更を適用** をクリックします。
</Step>
</Steps>

適用するまで何も変更されません。各変更の前にブックマークをもう一度読み取り、スキャン後に削除または編集されたものはスキップして一覧に示します。そのため、古いスキャン結果が新しい編集を上書きすることはありません。

メッセージ内、または一部だけ適用された後のダイアログ内にある **元に戻す** を使うと、10 秒以内なら削除したブックマークを復元し、置き換えた URL を元に戻せます（その後に再度編集された URL は除きます）。

## スキャンを調整する [#tune-the-scan]

[設定](/settings)の **メンテナンス** タブで調整します。

| 設定 | 初期値 |
| --- | --- |
| **リクエストのタイムアウト** | 1 リクエストあたり 8 秒 |
| **同時実行数** | 同時に 4 リクエスト |
| **再試行回数** | 1 回 |
| **リダイレクトをたどる** | オン |
| **成功とみなすステータスコード** | 200, 201, 202, 204, 301, 302, 307, 308 |
