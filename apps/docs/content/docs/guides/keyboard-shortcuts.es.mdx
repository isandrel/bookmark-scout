---
title: Combinaciones de teclas
description: Busca, recorre las carpetas, guarda la página actual y maneja la tabla del administrador sin el ratón.
---

Las combinaciones de teclas de la ventana emergente y el panel lateral nunca usan `Ctrl` ni `Cmd`, así que los atajos del navegador como `Ctrl/Cmd+L`, `T`, `W`, `N`, `R` y `D` siguen funcionando. El administrador de marcadores reemplaza al del navegador, así que también adopta las combinaciones con `Ctrl` de ese administrador (`Cmd` en un Mac): seleccionar todo, copiar, cortar, pegar, deshacer, rehacer y abrir en pestañas nuevas. Las combinaciones de teclas se pausan mientras escribes en un campo de texto (`Esc` en el cuadro de búsqueda es la excepción), mientras un editor de métodos de entrada está componiendo texto y mientras hay un diálogo o un menú abierto.

## En cualquier página [#on-any-page]

Funcionan sin ninguna ventana de Bookmark Scout abierta. Pertenecen al navegador, así que puedes cambiarlas o quitarlas en su configuración de atajos; consulta [Guardar con un atajo de teclado](/guides/save-and-organize#quick-save). En Chrome y Edge también puedes asignar al guardado rápido la tecla de marcadores del navegador, `Ctrl+D` (`⌘D` en un Mac); consulta [Usar Ctrl+D para el guardado rápido](/guides/save-and-organize#ctrl-d).

| Tecla | Acción |
| --- | --- |
| `Alt+Shift+S` (`⌥⇧S` en un Mac) | Guardado rápido de la página actual en la carpeta que indica **Carpeta de guardado rápido** |
| `Alt+Shift+D` (`⌥⇧D` en un Mac) | Guardado rápido de la página actual en la carpeta que sugiere la IA |

En la notificación que aparece después, `Tab` llega a **Deshacer** y a las demás carpetas, y `Esc` la cierra.

## Ventana emergente y panel lateral [#popup-and-side-panel]

Coloca el puntero sobre el cuadro de búsqueda para ver un recordatorio.

| Tecla | Acción |
| --- | --- |
| `/` | Ir al cuadro de búsqueda |
| `Esc` en el cuadro de búsqueda | Borrar la búsqueda; púlsala otra vez para salir del cuadro |
| `↓` en el cuadro de búsqueda | Ir a la primera carpeta |
| `Alt+↓` en el cuadro de búsqueda vacío | Mostrar las búsquedas recientes; `↓` / `↑` eligen una, `Enter` la busca y `Tab` llega a **Borrar** |
| `↓` / `↑`, `Home` / `End` | Moverse entre las carpetas y los marcadores visibles (`↑` en la primera fila vuelve a la búsqueda) |
| `→` / `←` | Abrir o cerrar una carpeta; en una carpeta abierta, `→` va a su primer elemento y `←` va a la carpeta superior |
| `Enter` en una carpeta | Guardar la página actual en esa carpeta (una página que ya está guardada allí no se duplica) |
| `Enter` en un marcador | Abrirlo en una pestaña nueva |
| `Space` en una carpeta | Abrirla o cerrarla |

## Administrador de marcadores [#bookmarks-manager]

Pulsa `?`, o haz clic en el botón del teclado del encabezado, para ver esta lista en el administrador. Las teclas siguen las del administrador de marcadores de Chrome; cuando en un Mac son distintas, la tecla del Mac va en segundo lugar.

| Tecla | Acción |
| --- | --- |
| `/` | Ir al filtro de títulos |
| `Backspace` o `Alt+↑` | Ir a la carpeta superior |
| `↓` / `↑`, `Home` / `End` | Moverse entre las filas y seleccionar la fila; con `Shift`, ampliar la selección; con `Ctrl` (`Cmd`), moverse sin seleccionar |
| `j` / `k` | Ir a la fila siguiente o anterior |
| `Space` | Seleccionar o deseleccionar la fila enfocada |
| `Ctrl+A` / `Cmd+A` | Seleccionar todas las filas que muestran los filtros, en todas las páginas |
| `Esc` | Borrar la selección, o cerrar un diálogo o un menú |
| `Enter` / `Cmd+O` | Abrir la carpeta seleccionada, o los marcadores seleccionados en pestañas |
| `Ctrl+Enter` / `Cmd+Enter` | Abrir la selección en pestañas nuevas en segundo plano |
| `Shift+Enter` | Abrir la selección en una ventana nueva |
| `F2` / `Enter` | Editar el marcador seleccionado o cambiar el nombre de la carpeta |
| `Delete` / `Delete` o `Cmd+Backspace` | Eliminar la selección |
| `Ctrl+Z` / `Cmd+Z` | Deshacer el último cambio |
| `Ctrl+Y` o `Ctrl+Shift+Z` / `Cmd+Shift+Z` | Rehacer |
| `Ctrl+C` / `Cmd+C` | Copiar la selección; sus URLs van al portapapeles |
| `Ctrl+X` / `Cmd+X` | Cortar la selección, para moverla al pegar |
| `Ctrl+V` / `Cmd+V` | Pegar después de la selección, o al final de la carpeta; las URLs copiadas en otra aplicación se convierten en marcadores |
| `s` | Abrir las búsquedas guardadas |
| `?` | Mostrar las combinaciones de teclas |
| Tecla de menú o `Shift+F10` | Abrir el menú contextual de la fila o carpeta enfocada |

En el árbol de carpetas de la izquierda, que también es una sola parada de `Tab`:

| Tecla | Acción |
| --- | --- |
| `↓` / `↑`, `Home` / `End` | Moverse entre las carpetas visibles |
| `→` / `←` | Abrir o cerrar una carpeta; en una carpeta abierta, `→` va a su primera subcarpeta, y en una cerrada, `←` va a la carpeta superior |
| `Enter` o `Space` / `Cmd+O` o `Space` | Mostrar la carpeta en la tabla |
| `F2` / `Enter` | Cambiar el nombre de la carpeta |
| `Delete` / `Delete` o `Cmd+Backspace` | Eliminar la carpeta |
| `Ctrl+C`, `Ctrl+X` / `Cmd+C`, `Cmd+X` | Copiar o cortar la carpeta |
| `Ctrl+V` / `Cmd+V` | Pegar dentro de la carpeta |

La tabla es una sola parada cuando pulsas `Tab`; las teclas de flecha se mueven entre sus filas. Abrir más de 15 pestañas a la vez pide confirmación primero; una carpeta abre los marcadores que están directamente dentro de ella. En la tabla, enfoca el borde del encabezado de una columna y pulsa `←` o `→` para cambiar el ancho de esa columna.

Las combinaciones de teclas están cubiertas por las pruebas automatizadas de Chromium y Edge, no por las de Firefox.
