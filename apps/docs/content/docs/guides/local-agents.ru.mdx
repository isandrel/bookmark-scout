<Callout title="Для разработчиков">
Эта страница для тех, кто уже пользуется ИИ-помощниками для программирования или другими ИИ-агентами на своём компьютере. Для настройки нужен терминал. Чтобы сохранять, находить или очищать закладки, ничего из этого не требуется.
</Callout>

ИИ-агенты, которые работают на вашем компьютере, могут работать с закладками через Bookmark Scout: находить закладки, перечислять папки, проверять ссылки, подсказывать папки для страницы, а если вы разрешите, — сохранять страницы и перемещать, переименовывать или удалять закладки. Агент общается с небольшой программой **bookmark-scout-mcp**, которая связывается с расширением через механизм обмена сообщениями с нативными приложениями (native messaging) вашего браузера. Ничто не прослушивает сеть, и у Bookmark Scout нет сервера.

<Callout type="warn" title="Что видит агент">
Пока доступ включён, агент может читать названия закладок, URL, названия папок, сохранённые теги и описания, а также название и URL текущей страницы; при включённом параметре **Читать содержимое страниц** — ещё и текст страниц. Агент может отправлять прочитанное своему ИИ-провайдеру. Конфиденциальные значения в названиях и URL по умолчанию скрыты. См. [Конфиденциальность](/privacy).
</Callout>

## Настройка [#set-it-up]

<Steps>
<Step>
Получите **bookmark-scout-mcp**. Бинарные файлы для Linux, macOS и Windows прикрепляются к <RepoLink path="/releases">выпуску на GitHub</RepoLink>, как только выпуск их включает; поместите файл для своей системы в `PATH` под именем `bookmark-scout-mcp`. До тех пор, если у вас установлен [Bun](https://bun.sh), соберите программу из клона репозитория: выполните `bun install`, затем `bun run --cwd packages/mcp-bridge compile` — команда запишет `packages/mcp-bridge/dist/bookmark-scout-mcp`.
</Step>
<Step>
Зарегистрируйте программу в своих браузерах:

```sh
bookmark-scout-mcp install
```

Команда записывает манифест обмена сообщениями с нативными приложениями для каждого найденного браузера (Chrome, Edge, Chromium, Brave, Vivaldi и Firefox; в Windows также значение реестра для вашего пользователя) и выводит, как добавить программу в ваш агент. Добавьте `--browser chrome`, чтобы выбрать браузеры, или `--dry-run`, чтобы увидеть, что будет записано.
</Step>
<Step>
В настройках Bookmark Scout перейдите в раздел **Для разработчиков** > **Локальные ИИ-агенты** и включите **Разрешить доступ локальным ИИ-агентам**. Браузер попросит разрешить расширению обмениваться данными с программой. После этого панель под переключателем покажет **Готово**. Включать функции ИИ не нужно.
</Step>
<Step>
Добавьте мост в свой агент (см. ниже) и спросите его о своих закладках.
</Step>
</Steps>

## Добавление в агент [#add-it-to-your-agent]

**Claude Code**

```sh
claude mcp add --scope user bookmark-scout -- bookmark-scout-mcp serve
```

**Codex**, в `~/.codex/config.toml`:

```toml
[mcp_servers.bookmark-scout]
command = "bookmark-scout-mcp"
args = ["serve"]
```

**Cursor**: [добавьте в Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=bookmark-scout&config=eyJjb21tYW5kIjoiYm9va21hcmstc2NvdXQtbWNwIiwiYXJncyI6WyJzZXJ2ZSJdfQ==) или поместите это в `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "bookmark-scout": {
      "command": "bookmark-scout-mcp",
      "args": ["serve"]
    }
  }
}
```

`bookmark-scout-mcp install` выводит эти фрагменты с полным путём к программе. Если подключено несколько браузеров или профилей, агент использует последний подключённый; добавьте `--browser edge` или `--profile <id>` после `serve`, чтобы выбрать.

## Разрешение агентам изменять закладки [#let-agents-change-bookmarks]

Агенты только ищут, пока вы не включите также **Разрешить изменения**. Тогда они могут сохранять страницы, предлагать перемещения, переименования, удаления и новые папки в виде плана и отменять собственные изменения. **Каждое изменение ждёт вас**: открывается окно Bookmark Scout, которое показывает изменение в том виде, в каком оно будет выполнено, с названием, которое дал агент. Ничего не происходит, пока вы не нажмёте **Подтвердить**; **Отклонить**, закрытие окна или пять минут без ответа ничего не меняют. Подтверждённое изменение можно отменить в диспетчере закладок клавишами <Shortcut id="manager.undo" />.

В разделе **Что могут делать локальные агенты** выключите любой поиск или любое изменение, которыми агенты не должны пользоваться. **Скрывать личные значения** (по умолчанию включено) заменяет конфиденциальные параметры URL, токены и адреса электронной почты в том, что получают агенты, используя список проверки конфиденциальности.

Когда в разделе **Активность ИИ** включено **Записывать запросы**, каждый вызов агента отображается там с именем агента.

## Устранение неполадок [#troubleshooting]

- `bookmark-scout-mcp doctor` показывает, где программа зарегистрирована, какие браузеры подключены, и фрагменты конфигурации для агентов.
- На панели написано, что **программа-мост не установлена**: снова выполните `bookmark-scout-mcp install`, затем нажмите **Повторить**. У сборки расширения для разработки свой id; добавьте его с помощью `--extension-id <id>`.
- Агент сообщает, что ни один браузер не подключён: держите браузер открытым с включённым переключателем; инструмент моста `bridgeStatus` сообщает, что он видит.
- Чтобы посмотреть, что запустил браузер, перед запуском браузера задайте в `BOOKMARK_SCOUT_MCP_LOG` путь к файлу; программа будет записывать туда свои сообщения.

## Удаление [#remove-it]

Выключите **Разрешить доступ локальным ИИ-агентам**, удалите сервер из агента (`claude mcp remove bookmark-scout`) и выполните `bookmark-scout-mcp uninstall`, чтобы удалить записанные программой манифесты и значения реестра.
