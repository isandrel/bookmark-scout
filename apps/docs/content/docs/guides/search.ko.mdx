## 팝업이나 사이드 패널에서 검색 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
툴바에서 Bookmark Scout 아이콘을 클릭합니다. 웹을 탐색하는 동안 계속 열려 있는 브라우저의 사이드 패널(Firefox에서는 사이드바)에서 Bookmark Scout를 열 수도 있습니다.
</Step>
<Step>
맨 위의 검색창에 입력합니다. 검색창에는 <strong>폴더 이름을 입력해 이 페이지 저장…</strong>이라고 적혀 있으며, 북마크도 함께 검색합니다(<Shortcut id="popup.focus_search" />를 누르면 바로 이동합니다). 입력하는 즉시 결과가 폴더별로 표시되며 일치하는 부분이 강조 표시됩니다. 모든 단어가 제목, 주소, 폴더, 태그와 요약 중 어딘가에 일치해야 합니다. [검색어와 연산자](#search-words-and-operators)를 참고하세요.
</Step>
<Step>
검색창 안의 버튼 **검색 옵션 더 보기**로 일치 조건을 좁힙니다. **대소문자 구분**, **전체 단어 일치**, 그리고 검색어를 정규식으로 처리하는 <strong>고급 패턴 검색(정규식)</strong>이 있습니다. 이 중 하나라도 켜져 있으면 버튼이 강조 표시됩니다. 이 옵션들은 입력한 그대로 제목만 검색하며, 연산자는 쓰지 않습니다.
</Step>
<Step>
북마크를 클릭하거나, 화살표 키로 이동한 뒤 `Enter`를 눌러 새 탭에서 엽니다.
</Step>
</Steps>

알아 두면 좋은 점:

- 전체 단어 일치는 공백, 문장 부호, 문자 체계가 바뀌는 지점을 단어 경계로 취급하므로 `C++` 같은 용어나 일본어 단어도 일치합니다.
- 잘못된 정규식은 경고를 표시하고 일반 텍스트로 검색합니다.
- 북마크바 같은 고정 폴더는 다른 항목을 담는 용도이므로 이름으로는 일치하지 않습니다.
- 일치 항목이 결과 한도보다 많으면 몇 개가 표시되었는지 안내 문구가 나타납니다. 검색어를 구체적으로 바꾸거나 [설정](/settings)에서 **최대 검색 결과**를 늘리세요.
- 검색어를 지우면(지우기 버튼 또는 검색창에서 `Esc`) 이전에 열려 있던 폴더가 다시 열립니다.
- 최근 검색은 이 기기에 기억됩니다. 빈 검색창을 클릭하거나 검색창에서 <Shortcut id="popup.recent_searches" />를 누르면 목록이 표시됩니다. 이 목록에서 지우거나 설정에서 **검색 기록**을 끌 수 있습니다.

## 검색어와 연산자 [#search-words-and-operators]

팝업, 사이드 패널, 관리자의 검색창은 검색을 같은 방식으로 읽습니다. 이 브라우저의 북마크만 검색하며, 아무것도 보내지 않습니다.

- 모든 단어가 각각 어딘가에 일치해야 합니다: 제목, 웹 주소, 폴더 경로, 북마크의 태그와 요약. `레시피 수프`는 "레시피" 폴더에 있는 "수프"라는 북마크를 찾습니다.
- 따옴표는 단어를 붙여서 찾습니다: `"토마토 수프"`.
- 앞에 `-`를 붙이면 일치하는 항목을 뺍니다: `레시피 -케이크` 또는 `-tag:보관`.
- 두 검색어 사이에 대문자 `OR`를 넣으면 둘 중 하나와 일치하는 항목을 찾습니다: `tag:react OR tag:vue`. 이는 공백보다 강하게 묶이므로 `domain:github.com tag:react OR tag:vue`는 두 태그 중 하나가 있는 GitHub 페이지를 찾습니다. 소문자 `or`는 일반 검색어입니다.
- 괄호로 검색어를 묶을 수 있습니다: `domain:github.com (tag:react OR tag:vue) -tag:archived`. 묶음 앞에 `-`를 붙이면 그 묶음과 일치하는 항목을 뺍니다: `-(tag:old OR tag:archive)`. `f(x)`처럼 단어 안에 있는 괄호는 텍스트로 검색합니다.
- 폴더 이름과 일치하는 단어는 그 폴더를 찾습니다. 팝업에서는 그 안의 북마크가 폴더 안에 표시되며, `folder:`는 그 안의 모든 항목을 나열합니다.
- 연산자가 아닌 텍스트는 `C++`, `10:30`, 웹 주소처럼 입력한 그대로 검색합니다. `foo:bar`처럼 Bookmark Scout가 모르는 연산자도 마찬가지입니다. 잘못된 날짜처럼 읽을 수 없는 값은 건너뜁니다. 괄호가 닫히지 않았거나 `OR` 한쪽에 검색어가 없으면 검색창 아래에 안내가 표시됩니다. 너무 깊이 중첩된 괄호나 너무 긴 `OR` 목록은 중간에서 잘리며 안내가 표시됩니다.

| 검색 | 찾는 항목 |
| --- | --- |
| `title:react` | 그 텍스트가 들어 있는 제목. `title:"react hooks"`처럼 여러 단어를 쓸 수 있습니다 |
| `url:github` | 그 텍스트가 들어 있는 웹 주소 |
| `domain:github.com` | 그 사이트의 북마크(하위 도메인 포함) |
| `folder:업무` 또는 `path:업무` | 이름이 정확히 같은 폴더 안의 모든 항목(깊이와 상관없음). `folder:"업무 / 문서"`는 다른 폴더 안의 폴더를 가리킵니다 |
| `tag:읽을거리` | 그 태그가 정확히 붙은 북마크 |
| `summary:레시피` | 그 텍스트가 들어 있는 요약 |
| `content:레시피` | **페이지 본문 색인**으로 색인한 페이지의 본문 |
| `is:bookmark` 또는 `is:folder` | 북마크만, 또는 폴더만 |
| `is:untagged` | 태그가 없는 북마크 |
| `has:tags` 또는 `has:summary` | 태그가 있는 항목, 또는 요약이 있는 항목 |
| `has:content` | 페이지 본문이 색인된 북마크 |
| `after:2026-01-31` 또는 `before:2026-01-31` | 그날이나 그 이후에 추가된 항목, 또는 그날이나 그 이전에 추가된 항목 |
| `tag:react OR tag:vue` | 양쪽 중 하나와 일치하는 북마크. `OR`는 대문자로 입력합니다 |
| `(tag:react OR tag:vue) -tag:old` | 괄호로 묶은 검색어: react 또는 vue 태그가 있고 old 태그는 없는 항목 |

태그와 요약은 **북마크 세부정보**에서 추가했거나 **자동 태그 지정**과 **콘텐츠 요약** 도구의 제안에서 남긴 것입니다. 이 기기에만 저장됩니다.

**페이지 본문 색인**이 켜져 있으면 일반 단어도 색인한 페이지의 본문과 일치합니다(제목, 주소, 태그, 요약 다음 순위). 이렇게 찾은 팝업 결과에는 일치한 부분 주변의 글이 표시됩니다. [페이지 안에서 검색](/guides/clean-up#search-inside-pages)을 참고하세요.

## 북마크 관리자에서 필터링 [#filter-in-the-bookmarks-manager]

관리자의 표에는 더 정밀한 필터가 있습니다. Chrome에서는 브라우저의 북마크 페이지를 열면 관리자가 나타나며, 처음에는 북마크바가 열립니다.

- **제목, 주소, 폴더, 태그 검색**은 [검색어와 연산자](#search-words-and-operators)를 읽고, 일치하는 폴더와 북마크를 나열합니다. <Shortcut id="manager.focus_filter" />를 누르면 이 검색창으로 이동합니다. 끝에 있는 **검색 구문** 버튼은 연산자 목록을 보여 주며, 하나를 고르면 검색에 추가됩니다. 제목이 아니라 주소, 태그, 요약, 페이지 본문으로 찾은 행은 팝업처럼 제목 아래에 어디서 찾았는지 표시합니다.
- **필터**에는 다른 모든 필터가 있습니다: **현재 폴더만**, **유형**, **도메인**, 선택한 폴더의 항목만 남기는 **폴더**, **추가한 날짜**, 웹 주소만 검색하는 <strong>URL 필터...</strong>. 사용 중인 필터는 도구 모음 아래에 칩으로 표시되며, <strong>×</strong>를 누르면 그 필터가 제거됩니다. **초기화**는 모든 필터와 검색을 지웁니다. 잘못된 날짜처럼 검색에 문제가 있으면 도구 모음 아래에 설명이 나옵니다.
- **현재 폴더만**은 필터를 현재 폴더로 제한합니다. 끄면 모든 북마크에서 검색하며, 각 결과의 제목 아래에 그 폴더가 표시되고 맨 위의 경로에는 **모든 폴더의 결과**라고 표시됩니다.
- 열 머리글을 클릭해 어느 열로든 정렬할 수 있습니다. 표가 브라우저 순서가 아닐 때는 **브라우저 순서** 옆에 현재 정렬 순서가 표시됩니다. **브라우저 순서**를 클릭하면 원래대로 돌아갑니다.
- 표에는 **제목**, **URL**, **추가한 날짜**가 표시되며 한 페이지에 50행이 나옵니다. **유형**, **폴더 경로** 등 다른 열은 **보기**에서 켤 수 있고, 페이지당 행 수는 표 아래에서 고를 수 있습니다. 열 순서는 **보기**에서 핸들을 끌거나 옆의 화살표 버튼으로 바꿀 수 있습니다. 표에서 열 머리글을 끌어 다른 위치로 옮기거나, 머리글 메뉴에서 왼쪽이나 오른쪽으로 옮길 수도 있습니다.
- **보기** 옆의 두 버튼으로 목록과 **카드**를 바꿉니다. 카드는 같은 행, 필터, 정렬, 선택, 메뉴를 카드 그리드로 보여 줍니다. 왼쪽/오른쪽 키는 카드 하나씩, 위/아래 키는 카드 한 줄씩 움직이며, 두 번 클릭하면 폴더나 링크가 열립니다. 선택한 보기는 이 기기에 저장됩니다.
- 북마크 메뉴(**⋯** 버튼 또는 오른쪽 클릭 메뉴)의 **미리 보기**나, 포커스된 카드 또는 행에서 <Shortcut id="manager.preview" />를 누르면 북마크의 저장된 표지, 주소, 폴더, 태그, 요약이 나타나고 **새 탭에서 열기**, **복사**, **편집**을 쓸 수 있습니다. 보여 주려고 아무것도 내려받지 않습니다. `Tab`은 미리 보기 안에서만 움직이고, `Esc`로 닫으면 카드로 돌아갑니다.
- 여러 폴더에 걸쳐 검색할 때는 행의 메뉴에 **폴더에서 보기**가 있습니다. 필터를 지우고 항목이 들어 있는 폴더를 열어 그 항목을 선택합니다.

## 폴더나 검색으로 연결되는 링크 [#link-to-a-folder-or-a-search]

관리자의 주소는 보고 있는 화면을 따라가므로, 브라우저의 **뒤로**와 **앞으로**로 폴더와 검색 사이를 오갈 수 있고, 화면을 북마크하거나 공유할 수 있습니다.

- `?id=`는 Chrome 자체 관리자처럼 열린 폴더를 나타냅니다. Chrome에서는 `chrome://bookmarks/?id=12`로, Edge에서는 `edge://favorites/?id=12`로 폴더 12를 엽니다. 북마크바, 기타 북마크, 모바일 북마크를 긴 ID로 나타내던 Chrome 154~156의 링크로도 해당 폴더가 열립니다. `?id=`가 없으면 관리자는 북마크바를 엽니다. 폴더 경로 맨 앞의 **북마크**를 누르면 최상위 단계가 표시됩니다.
- `?q=`는 검색입니다. `chrome://bookmarks/?q=react`를 열면 "react"를 검색하는 관리자가 열리고, `?q=tag:reading`은 그 태그를 검색합니다. **제목, 주소, 폴더, 태그 검색**에 입력하는 동안 주소가 따라 바뀌며, 한 번에 이어서 입력한 내용은 **뒤로** 한 단계가 됩니다. 검색이 폴더보다 우선하며, **현재 폴더만**을 선택하면 폴더도 계속 적용됩니다.
- 머리글의 폴더 경로 옆과 폴더 행의 메뉴에 있는 **이 폴더 링크 복사**는 그 주소를 복사합니다. Firefox에서는 관리자 페이지 자체의 주소를 복사합니다. Chrome과 Edge는 폴더 사이를 이동해도 관리자를 처음 열 때의 주소를 계속 표시합니다.
- 탭 제목에는 폴더 이름이, 검색하는 동안에는 검색어가 표시됩니다.

## 검색 저장 [#save-a-search]

저장된 검색은 관리자의 현재 필터, 정렬, 폴더 범위를 이름과 함께 보관하므로, 나중에 같은 화면을 다시 열 수 있습니다.

<Steps>
<Step>
필터를 하나 이상 설정합니다: 제목, URL, 유형, 폴더, 도메인, 추가한 날짜.
</Step>
<Step>
표 툴바에서 **저장된 검색**을 클릭하거나 <Shortcut id="manager.open_saved_searches" />를 누릅니다.
</Step>
<Step>
**이 검색의 이름 입력**에 이름을 입력하고 **저장**을 클릭합니다.
</Step>
</Steps>

사용하려면 **저장된 검색**을 열고 원하는 항목을 선택합니다. 저장된 필터와 정렬이 현재 필터와 정렬을 대체하며, 한 폴더로 범위가 제한된 검색이었다면 관리자가 그 폴더로 돌아갑니다. 각 항목은 이름을 바꾸거나 삭제할 수 있으며, 삭제는 이어서 표시되는 메시지에서 실행 취소할 수 있습니다. 항목의 핸들을 끌어 순서를 바꾸거나, 핸들의 메뉴로 키보드로 옮길 수 있습니다.

검색창의 텍스트는 연산자를 포함해 입력한 그대로 저장됩니다. 검색창이 연산자를 읽기 전에 저장한 검색은 텍스트를 제목과 주소에서만 찾았습니다. 이런 검색은 이제 텍스트에 여러 단어나 콜론이 있으면 따옴표로 묶어 열리므로, 전에 찾던 북마크를 모두 계속 찾습니다. `OR`와 괄호를 읽기 전에 저장한 검색도 같은 이유로 이들을 따옴표로 감싼 채 열립니다.

저장된 검색은 북마크의 사본이 아니라 필터 정의만 저장하므로, 결과는 항상 현재 북마크 상태와 일치합니다. 검색에 지정된 폴더가 삭제되었으면 그 폴더는 건너뛰고 나머지 필터는 그대로 적용되며, 몇 개의 폴더를 건너뛰었는지 메시지로 알려 줍니다.

저장된 검색은 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. 필터를 보면 어떤 것을 북마크하는지 알 수 있고, 폴더 ID가 기기마다 다르기 때문입니다. 최대 50개까지 보관할 수 있습니다.
