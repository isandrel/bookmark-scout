## 팝업이나 사이드 패널에서 검색 [#search-from-the-popup-or-side-panel]

<Steps>
<Step>
툴바에서 Bookmark Scout 아이콘을 클릭합니다. 웹을 탐색하는 동안 계속 열려 있는 브라우저의 사이드 패널(Firefox에서는 사이드바)에서 Bookmark Scout를 열 수도 있습니다.
</Step>
<Step>
<strong>북마크 검색...</strong>에 입력합니다(`/`를 누르면 바로 이동합니다). 입력하는 즉시 결과가 폴더별로 표시되며 일치하는 부분이 강조 표시됩니다.
</Step>
<Step>
검색창 안의 세 버튼 **대소문자 구분**, **전체 단어 일치**, **정규식 사용**으로 일치 조건을 좁힙니다.
</Step>
<Step>
북마크를 클릭하거나, 화살표 키로 이동한 뒤 `Enter`를 눌러 새 탭에서 엽니다.
</Step>
</Steps>

<Screenshot name="popup" />

알아 두면 좋은 점:

- 전체 단어 일치는 공백, 문장 부호, 문자 체계가 바뀌는 지점을 단어 경계로 취급하므로 `C++` 같은 용어나 일본어 단어도 일치합니다.
- 잘못된 정규식은 경고를 표시하고 일반 텍스트로 검색합니다.
- 북마크바 같은 고정 폴더는 다른 항목을 담는 용도이므로 이름으로는 일치하지 않습니다.
- 일치 항목이 결과 한도보다 많으면 몇 개가 표시되었는지 안내 문구가 나타납니다. 검색어를 구체적으로 바꾸거나 [설정](/settings)에서 **최대 검색 결과**를 늘리세요.
- 검색어를 지우면(지우기 버튼 또는 검색창에서 `Esc`) 이전에 열려 있던 폴더가 다시 열립니다.
- 최근 검색은 이 기기에 기억됩니다. 빈 검색창을 클릭하거나 검색창에서 `Alt+↓`를 누르면 목록이 표시됩니다. 이 목록에서 지우거나 설정에서 **검색 기록**을 끌 수 있습니다.

## 북마크 관리자에서 필터링 [#filter-in-the-bookmarks-manager]

관리자의 표에는 더 정밀한 필터가 있습니다. Chrome에서는 브라우저의 북마크 페이지를 열면 관리자가 나타납니다.

- <strong>제목 필터...</strong>와 <strong>URL 필터...</strong>는 해당 열의 텍스트와 일치하는 항목을 찾습니다. `/`를 누르면 제목 필터로 이동합니다.
- **유형**, **상위 폴더**, **도메인**, **추가한 날짜**로 행을 더 좁힐 수 있습니다.
- **현재 폴더만**은 필터를 현재 폴더로 제한합니다. 끄면 모든 북마크에서 검색합니다.
- 열 머리글을 클릭해 어느 열로든 정렬할 수 있습니다.

## 검색 저장 [#save-a-search]

저장된 검색은 관리자의 현재 필터, 정렬, 폴더 범위를 이름과 함께 보관하므로, 나중에 같은 화면을 다시 열 수 있습니다.

<Steps>
<Step>
필터를 하나 이상 설정합니다: 제목, URL, 유형, 폴더, 도메인, 추가한 날짜.
</Step>
<Step>
표 툴바에서 **저장된 검색**을 클릭하거나 `s`를 누릅니다.
</Step>
<Step>
**이 검색의 이름 입력**에 이름을 입력하고 **저장**을 클릭합니다.
</Step>
</Steps>

사용하려면 **저장된 검색**을 열고 원하는 항목을 선택합니다. 저장된 필터와 정렬이 현재 필터와 정렬을 대체하며, 한 폴더로 범위가 제한된 검색이었다면 관리자가 그 폴더로 돌아갑니다. 각 항목은 이름을 바꾸거나 삭제할 수 있으며, 삭제는 이어서 표시되는 메시지에서 실행 취소할 수 있습니다.

저장된 검색은 북마크의 사본이 아니라 필터 정의만 저장하므로, 결과는 항상 현재 북마크 상태와 일치합니다. 검색에 지정된 폴더가 삭제되었으면 그 폴더는 건너뛰고 나머지 필터는 그대로 적용되며, 몇 개의 폴더를 건너뛰었는지 메시지로 알려 줍니다.

저장된 검색은 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. 필터를 보면 어떤 것을 북마크하는지 알 수 있고, 폴더 ID가 기기마다 다르기 때문입니다. 최대 50개까지 보관할 수 있습니다.

<Callout title="Firefox">
Firefox에서는 팝업의 **북마크 관리자 열기**로 관리자를 엽니다.
</Callout>
