这两个工具都位于书签管理器的**工具**侧栏中的**维护**下。在 Chrome 中，打开浏览器的书签页面；如果侧栏处于隐藏状态，请点击书签管理器顶部的**显示工具**。

<Callout title="Firefox">
Firefox 不允许扩展程序替换其自带的书签页面，因此在 Firefox 中，请通过工具栏弹出窗口中的**打开书签管理器**打开书签管理器，然后打开工具侧栏。
</Callout>

## 移除重复书签 [#remove-duplicate-bookmarks]

<Steps>
<Step>
在**重复书签清理**中点击**扫描**。它始终检查所有书签。
</Step>
<Step>
审阅各个组。每个组只显示一次共同的网址，然后列出每个书签及其文件夹和添加日期。标有**保留**的书签按**保留规则**选出，你也可以用单选按钮改选另一个；其余每个副本都有一个**移除**复选框，默认勾选。取消勾选某个副本或某个组，即可保留它们。
</Step>
<Step>
点击**移除 N 个重复项**删除勾选的副本，或点击**取消**不做任何更改。
</Step>
<Step>
改变主意了？请在 10 秒内点击消息中的**撤消**，恢复已移除的书签。之后，在书签管理器中按 <Shortcut id="manager.undo" /> 也能恢复。
</Step>
</Steps>

<Screenshot name="duplicates" />

哪些书签算作重复，在[设置](/settings)的**维护**标签页中设置：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **匹配策略** | 规范化网址 | 按**完全相同的网址**、**规范化网址**、**标题 + 网址**或**仅标题**进行比较 |
| **统一 www** | 开启 | 将 `www.example.com` 和 `example.com` 视为同一主机 |
| **忽略协议** | 开启 | 将 `http` 和 `https` 版本视为重复 |
| **忽略末尾斜杠** | 开启 | 将末尾带有和不带 `/` 的网址视为重复 |
| **保留规则** | 最早的 | 在每个组中保留**最早的**、**最新的**或**最先找到的**书签 |
| **最大组数** | <SettingDefault path="maintenance.duplicates.max_groups" /> | 单次扫描最多返回的组数 |

移除任何内容之前，都会再次检查每个组。如果标为**保留**的书签已被删除或现在指向其他地方，整个组都不会被改动，并且消息会说明跳过了多少个组。使用**仅标题**匹配时，如果某个组包含不同的网址，会显示警告，因为移除这些副本会删除不同的网页。

## 去除跟踪参数 [#strip-tracking-parameters]

<Steps>
<Step>
在**网址清理**中，从范围菜单中选择当前文件夹或所有书签，然后点击**清理**。
</Step>
<Step>
按清理原因（**移除的参数**中的条目，例如 `utm_*`、重复参数或片段）分组查看将要更改的网址。每个网址默认是**清理**；要保留的网址，可单独设置，或用<strong>将所选设为…</strong>批量设为**保持不变**。
</Step>
<Step>
点击**清理 N 个网址**更新仍为**清理**的网址，或关闭对话框不做任何更改。
</Step>
</Steps>

如果某个书签在预览后发生了变化，它会被跳过，并计入消息中的数量。点击消息中的**撤消**，或在书签管理器中按 <Shortcut id="manager.undo" />，可恢复原来的网址；此后再次更改过的书签会保持原样。

规则位于设置的**维护**标签页中：

- **移除的参数**：要去除的参数。默认列表为 <SettingDefault path="maintenance.url_cleaner.remove_params" />。以 `*` 结尾的名称会匹配所有以此开头的名称。
- **保留的参数**：永远不会被移除的参数。默认值：<SettingDefault path="maintenance.url_cleaner.preserve_params" />。
- **去除重复查询参数**（默认开启）会移除重复出现的参数。
- **排序查询参数**（默认开启）会按字母顺序排列剩余的参数。
- **移除片段**（默认关闭）还会移除 `#section` 之类的部分。

## 刷新网站图标 [#refresh-site-icons]

在 Bookmark Scout 获得某个网站的图标之前，书签会显示通用的地球图标。在 Chrome 和 Edge 中，最快的方法是点击**刷新网站图标**卡片上的**显示浏览器图标**，或在[设置](/settings#appearance)中开启**使用浏览器的图标缓存**：这会显示浏览器已为你访问的网站保存的图标，并且浏览器只会请求读取网站图标的权限。对于浏览器没有图标的网站，以及在不向扩展程序提供图标缓存的 Firefox 中，工具侧栏中**页面标题与图标**下的**刷新网站图标**会下载每个网站自己的图标。

<Steps>
<Step>
从范围菜单中选择当前文件夹或所有书签，然后点击**刷新**。在系统询问时，请允许访问该范围内的网站（范围内超过 20 个网站时会请求访问所有网站）；如果你拒绝，则不会发出任何请求。
</Step>
<Step>
按标签页查看各网站：**新图标**、**图标相同**、**无图标**和**失败**，每个都显示数量，还会说明有多少个书签因不是网页链接而被跳过。找到的图标默认设为**保存图标**；可以把某一项改为**跳过**，或选中多项后使用**将所选设为…**。
</Step>
<Step>
点击**保存**（例如**保存 12 个图标**）保留仍设为**保存图标**的图标，或关闭对话框不保留任何图标。
</Step>
</Steps>

对于范围内的每个网站（源），该工具会在不携带 Cookie 的情况下请求一个已加入书签的网页，只读取其 head 部分，并下载该网页列出的图标中最接近**首选图标大小**的那个，或者该网站的 `/favicon.ico`。只会使用书签所在域名下的图标文件，从不使用第三方图标服务。超过**图标文件大小上限**（<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> KB）或不是图片的文件会被跳过。

刷新在后台运行：关闭管理器后仍会继续，其卡片和**后台任务**会显示进度，并可**暂停**、**继续**或**取消**。结果会在**查看结果**中等你查看；在你点击**保存**之前不会保存任何内容。

已保存的图标存储在此浏览器的本地存储中，不会同步，并会显示在弹出窗口、侧边栏和书签管理器中。它们优先于浏览器缓存的图标。卡片上会显示已保存的图标数量；**清除已保存的图标**会将其全部删除。当总大小达到**图标存储上限**（4 MB）时，会先移除最早保存的图标。如果某个网站在之后的刷新中失败，会继续保留之前保存的图标。

<Callout title="Firefox">
在 Firefox 中，请通过工具栏弹出窗口中的**打开书签管理器**打开书签管理器来运行此工具。在那里保存图标后，弹出窗口和侧边栏就会显示这些图标。
</Callout>

## 用智能规则添加标签和移动 [#tag-and-move-with-smart-rules]

智能规则用与搜索框相同的词语和[运算符](/guides/search#search-words-and-operators)搜索书签，然后为它们添加标签、移动到文件夹，或两者都做。规则只在你开启了下文所述的设置时才会自行运行；否则每次运行都是一次审阅，由你决定应用哪些更改。

<Steps>
<Step>
在[设置](/settings#maintenance)的**智能规则**中点击**添加规则**；也可以点击**从模板开始**，为 GitHub 页面、YouTube 视频或教程添加标签，或者移动 **Work / Reading** 文件夹中的书签。模板默认关闭。移动书签的模板还没有文件夹，因此会在编辑器中打开：选择文件夹之前，它无法开启或保存。
</Step>
<Step>
为规则设置名称和搜索，例如 `domain:github.com`、`folder:稍后阅读 -tag:已读` 或 `(domain:github.com OR domain:gitlab.com) -tag:archived`。编辑器会显示当前匹配的书签数量，或指出搜索的问题，例如括号未闭合；搜索能被读取之前，规则无法保存。在**用网址或标题测试**中输入网址或标题，可以查看搜索是否匹配它；这在你的设备上判断，不会保存或发送任何内容。添加标签（每个标签后按 Enter 键或输入逗号）、选择要移动到的文件夹，或两者都设置，然后保存。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**智能规则**卡片上选择范围，然后点击**运行**：当前显示的文件夹、所有书签，或在管理器中有内容时选择**搜索结果**（搜索框列出的书签）或**所选书签**。范围在点击时确定，范围外的书签绝不会被审阅或更改。
</Step>
<Step>
按标签页审阅书签：**更改**、**冲突**（两条规则会把它移动到不同的文件夹）、**已阻止**（它的文件夹已不存在或受管理，或在该文件夹中另一条规则会再次移动它）和**已完成**。更改默认设为**应用**，冲突默认设为**跳过**；可以逐个或使用<strong>将所选设为…</strong>修改，然后点击**应用**（例如**应用 12 项更改**）。
</Step>
</Steps>

须知：

- 规则按列表顺序运行。每条匹配的规则都会添加它的标签；第一条移动书签的规则优先，后面规则指定的文件夹会显示为冲突。拖动规则可以改变顺序。
- 运行结果会稳定下来：已在某条匹配规则指定的文件夹中的书签会留在那里；只有在新文件夹中、带着新标签时没有任何规则会再次移动它，才会移动书签。因此连续运行两次规则，书签也不会来回移动。
- 规则逐个处理书签：网址相同但位于不同文件夹的两个书签会分别匹配和更改。
- 书签已有的标签，无论写法如何，都不会重复添加。文件夹不会被添加标签，也不会被移动。
- 应用后消息中的**撤消**会同时恢复移动和标签。这些移动在历史记录中是一项更改。此次运行还会连同它添加了标签的书签列在设置的“**由规则更改**”中，之后仍可在那里用**撤消**移除仍在的这些标签；它的移动在历史记录中撤消。
- 标签和移动分开保存，因此消息会分别统计添加了标签、移动、跳过和失败的数量。没有历史记录就绝不移动：如果无法保存这条记录，就不移动任何书签，标签仍会添加，消息也会说明。
- 应用时会先重新检查每个书签。审阅后被删除、重命名、改了网址或移到别处的书签会被跳过，并保留你的更改；审阅后规则被编辑、关闭或删除的书签也是如此（重命名规则不算）。消息会说明跳过了多少。已经是审阅结果状态的书签不会再次更改。
- 更改的书签多于**超过此数量时在后台应用**（设置中的“**后台任务**”）的运行，会由后台任务分批应用，标签和移动一起处理。关闭管理器后、浏览器重启后它都会继续，你可以在“**后台任务**”中暂停、继续或取消它；取消会保留已完成的部分。每一批的移动是历史记录中的一项更改，此次运行的标签会在添加前记录，并列在“**由规则更改**”中。如果浏览器在应用某一批时停止，任务会等待你点击**继续**，届时会重新检查每个剩余书签，因此不会重复添加标签或移动。关闭智能规则会暂停任务，直到你重新开启并继续；期间被编辑或关闭的规则，其书签会被跳过。
- 在设置中，每条规则会显示其上次经审阅的运行：时间，以及添加了标签、移动和未处理的书签数量。“**上次运行中的冲突**”会列出两条规则会移到不同文件夹的书签，以及它们指定的文件夹；**审阅**会在该书签所在的文件夹中打开管理器，并准备好在那里运行智能规则。
- 规则只保存在此设备上，并包含在**备份设置**中。在其他设备上恢复的规则，只有在那台设备上存在对应文件夹时才会移动书签；否则在你重新选择文件夹之前，它的移动会被阻止。如果该文件夹在那里的 ID 不同，只要只有一个文件夹是这个路径，规则就会按路径找到它。
- 在设置中开启**为新书签添加标签**后，已启用的规则会为“**新书签来源**”允许的每个新书签加上标签。默认是“**用 Bookmark Scout 保存的**”：通过快速保存、弹出窗口、管理器或 Ask AI 保存的书签。选择“**任何来源**”可包含来自浏览器星标、其他扩展程序或同步的书签；浏览器不会告知书签的来源，因此它们会被同样对待。它绝不会移动书签。一次添加的大量书签（同步或导入）以及在设置不允许时添加的书签都会保持不变。每次自动添加的标签都会列在设置的“**由规则更改**”中，并可用“撤消”移除这些标签。
- 不经审阅的移动需要你另外做两项选择，与添加标签无关：在规则的文件夹旁勾选**自动移动新书签**，并在设置中开启**移动新书签**。规则列表会在这类规则下显示“**自动移动新书签**”。之后规则匹配的新书签会移到该文件夹，且只会移到该文件夹：如果文件夹被删除、重命名、移动或受管理，规则会提示自动移动已停止，在你重新选择文件夹并保存规则之前不会移动任何书签；绝不会改用路径相同的其他文件夹。与运行时一样，由第一条移动书签的规则决定，两条规则要移到不同文件夹的书签保持不动。Bookmark Scout 保存的书签（快速保存、管理器）留在原处，因此自动移动需要把“**新书签来源**”设为“**任何来源**”；一次添加的大量书签和几秒内又被移动过的书签也会留在原处。每批移动在[历史记录](/guides/save-and-organize)中是一项来自 Bookmark Scout 的更改，名为“智能规则，自动”，如果无法保存这条记录，就不移动任何书签。每次移动也会列在“**由规则更改**”中，在那里撤消会把书签移回之前的文件夹，除非它此后又被移动过。
- 在搜索支持 `OR` 和括号之前保存的规则，仍会找到原来找到的书签：它们会作为加引号的文字读取。

## 在网页中搜索 [#search-inside-pages]

**索引网页正文**会在此设备上保存书签网页的可读正文，让搜索也能找到只出现在网页中的词语。开启前它默认关闭，并且会下载每个要索引的网页。

<Steps>
<Step>
在[设置](/settings#index-page-text)中开启**启用索引网页正文**。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**索引网页正文**卡片上选择范围，然后点击**索引**。然后选择要读取的网站：每个有网页要下载的网站都会列出，并显示其书签数，起初全部勾选。取消勾选要略过的网站（可用**全选**、**全不选**，列表较长时还可筛选），然后点击带网站数的开始按钮（例如**开始（2 个网站）**）。如有提示，请允许访问这些网站；不会请求或下载其他网站。索引在后台运行：关闭管理器后仍会继续，其卡片和**后台任务**会显示进度，并可**暂停**、**继续**或**取消**；之后网页会在**查看结果**中等你查看。
</Step>
<Step>
按标签页审阅网页：**有正文**、**无正文**、**登录页面**（网页要求登录而没有显示内容；其正文绝不会保存）、**已重定向**（该网址会把你带到另一个网址，而那个网址不会被打开，因此不会联系你未允许的网站；请改为给它指向的网址添加书签）、**失败**、**已索引**（之前从同一网址索引过）、**未选择**（位于你略过的网站，因此从未下载）和**已跳过**（不是网页，或位于本地网络）。有正文的网页默认设为**保存正文**；点击**保存**（例如**保存 12 个网页的正文**）。在把网页列为已重定向之前，会先尝试它的 `https:` 网址以及加上或去掉 `www.` 的网址，只限书签自己的网站，且不会继续跟随重定向；以这种方式读取的网页会显示**读取自**和读取时使用的网址。如果保存时本设备上扩展的存储空间用完，之前已保存的网页会保留，并有消息说明有多少未保存；请释放磁盘空间，或在设置中使用**删除网页正文**，然后重新索引。
</Step>
</Steps>

之后，就能在弹出窗口、侧边栏和书签管理器中按正文搜索到这些书签。`content:` 只在网页正文中查找，`has:content` 会找到有正文的书签。书签网址改变后，网页会重新读取。在设置中点击**删除网页正文**会删除索引；书签、标签和历史记录保持不变。在网页正文中找到的结果会说明正文的来源：**已下载的网页**或**来自你的标签页的网页**。“询问 AI”和本地 AI 代理从不搜索网页正文，网页正文只保存在此设备上：在那里 `content:` 和 `has:content` 什么也找不到，回答中也会说明这一点。

索引下载网页时不带你的 Cookie，因此只有登录后才能阅读的网页会显示其登录页面，并归入**登录页面**。要索引你在这类网页上看到的内容，请打开该网页：当网页已加入书签且开启了索引网页正文时，弹出窗口中显示网页保存位置的那一行有一个按钮“**索引此网页的正文**”，它会读取标签页显示的正文并显示出来，同时提醒你检查是否含有私密内容。只有点击“**保存正文**”后才会保留。只会从工具栏弹出窗口读取，绝不读取隐私窗口或登录页面，并且只在读取前后标签页都显示该书签网页时读取；如果期间标签页换成了其他网页，则不会保留任何内容。

地址相同的书签共用一次下载，并各自保留自己的正文。另有两种情况单独列出：**不是网页**（该地址返回 PDF 等文件，不会下载），以及 **已跳过** 中包含用户名和密码、或包含隐私扫描 **敏感参数** 中所列参数（例如令牌）的地址：网站会收到这些内容，因此在设置中的 **跳过含登录信息或机密的地址** 开启时（默认）不会请求。正文按段落以纯文本保存，所以加引号的短语只在同一段落内匹配。对于回应繁忙并指定了短暂等待时间的网站，会在等待之后再次请求，最多几次；之后该网页会列在 **失败** 下。要让“索引网页正文”完全不碰某个网站，请在[设置](/settings#index-page-text)的 **从不读取这些网站** 中加入它：它及其子域名的网页从不下载，也不会从标签页读取，会连同原因列在 **已跳过** 下，并且已从该网站索引的正文会被删除。

[设置](/settings#index-page-text)中的 **网页正文索引** 面板会显示可索引的书签中已索引多少、有多少已过期（读取自以前的地址或由旧版本读取；下次运行时会重新读取），以及上次运行失败了多少。**重试失败项** 会在后台只对这些书签重新运行“索引网页正文”，并且只请求访问它们的网站；请在卡片的 **查看结果** 中保存正文。撤销扩展程序对某个网站的访问权限会删除从该网站索引的正文，删除书签也会删除它的正文。面板还会显示上次索引正文的时间，**刷新已过期项** 会以同样的方式重新读取已过期的网页。

## 在卡片上显示封面 [#show-covers-on-cards]

**获取封面**会保存网页为自己指定的预览图（Open Graph 或 Twitter 卡片图片）的小副本，让书签管理器的**卡片**显示它。开启前它默认关闭。显示卡片时不会下载任何内容：没有已保存封面的卡片会显示一个图块，在从该网站选取的颜色上显示网站的图标和名称，由你的电脑在本地绘制。

<Steps>
<Step>
在[设置](/settings#fetch-covers)中开启**启用获取封面**。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**获取封面**卡片上选择范围，然后点击**获取**。如有提示，请允许访问该范围内的网站。
</Step>
<Step>
按标签页审阅网页：**有封面**（附图片）、**无封面**、**图片不可用**（网页指定的图片不是支持的图片格式、太大或无法读取）、**在其他网站**（图片位于你未允许的网站）、**已重定向**（该网址会把你带到另一个网址，而那个网址不会被打开；与索引网页正文一样，会先尝试它的 `https:` 和 `www.` 网址）、**失败**、**已获取**和**已跳过**。找到的封面默认设为**保存封面**；点击**保存**（例如**保存 12 个封面**）。如果保存时本设备上扩展的存储空间用完，之前已保存的封面会保留，并有消息说明有多少未保存；请释放磁盘空间，或在设置中使用**删除封面**，然后重新获取。
</Step>
</Steps>

用**查看**旁的按钮将书签管理器切换到**卡片**即可看到封面。在列表中，**查看**里的**封面**列会以小图显示封面；将指针停在小图上即可查看大图。封面属于获取它的网址，因此网址改变的书签在重新获取前会显示图标。封面只保存在此设备上，不会进入备份或导出；在设置中点击**删除封面**即可移除，书签、标签和历史记录保持不变。

也可以用当前网页作为封面：当网页已加入书签且开启了获取封面时，弹出窗口中显示网页保存位置的那一行末尾有一个按钮“**用当前画面作为封面**”，它会截取标签页的画面并显示出来，同时提醒你检查是否含有私密内容。只有点击“**保存封面**”后才会保留。只会从工具栏弹出窗口截取，绝不截取隐私窗口，并且只在标签页仍显示该书签网页时截取。

书签菜单（右键或 ⋯，在列表或卡片中，也可用于多选）或其“预览”中的“获取封面”只对这些书签运行获取封面，审阅界面和对其网站的访问请求都相同；用“用当前画面作为封面”保存的封面会列在“你选定的”下并保留。在“获取封面”卡片上，“所选书签”会对管理器中的选择执行同样操作。“移除封面”删除书签的封面（多选时为每个所选书签的封面）：卡片会立即显示占位图，消息中的“撤消”会放回同一封面。

### 浏览时捕获封面 [#capture-covers-while-you-browse]

在[设置](/settings#fetch-covers)的获取封面下开启**浏览时捕获封面**，无需获取即可得到封面。当一个没有封面的已加入书签的网页在你正在查看的标签页中加载完成时，Bookmark Scout 会稍等片刻，确认标签页仍显示该网页，然后截取它的截图作为该书签的封面。开启时会请求浏览器授予访问所有网页的权限，因为这是浏览器允许扩展程序无需点击即可截取标签页画面的唯一方式；同样的权限也让读取网站的工具无需再次询问即可运行。

- 除非你还开启了**也在无痕窗口中捕获**，并且浏览器允许 Bookmark Scout 在其中运行，否则不在隐私窗口中截图；绝不截取扩展程序或浏览器自身的页面、本地文件，或你没有加入书签的网页。
- 截图会显示网页当时显示的任何内容，例如账号页面或消息。把你不想被截图的网站加入**永不捕获这些网站**（一个网站包括其子域名），并可在设置中用**删除封面**删除任何封面。“从不读取这些网站”中的网站也不会截取。
- **封面来源**决定两者都可用时以哪个封面为准。选择“**网页图片优先，其次截图**”（默认）时，截图绝不会替换“获取封面”保存的图片，而“获取封面”会替换截图。“**截图优先**”对浏览时截取的截图正好相反，“**仅网页图片**”则不截图。用“用当前画面作为封面”保存的封面不会被“获取封面”或浏览时的截图自动替换，只有你再保存一张图片时才会替换。选择**仅截图**时只使用截图：“获取封面”不会读取任何网页，其预览中会说明这一点。
- 浏览时截取的截图早于**重新截取早于此时间的截图**设定的时间后，会在你下次访问时重新截取（设为 0 则从不重新截取）。等待多久由**捕获前等待**和**截图间隔**决定。与所有封面一样，截图只保存在此设备上，绝不会发送到任何地方。关闭该设置即可停止；访问权限请在浏览器的扩展程序设置中移除。

书签的**预览**和详细信息卡片会注明其封面的来源：网页自带的图片、你的标签页截图，或浏览时捕获的截图，以及保存的日期。快速保存时截取的画面也会注明。

### 快速保存时保存封面 [#save-a-cover-with-quick-save]

开启获取封面后，快速保存快捷键还会为所保存的网页保存封面（[设置](/settings#quick-save)中的**快速保存时保存封面**，默认关闭，且仅在获取封面也开启时有效）：网页自带的预览图片（在该网页的网站或你允许的网站上时），或在你按下快捷键的那一刻、通知出现之前截取的标签页截图。它遵循**封面来源**，除非**快速保存封面来源**为快速保存设置了单独的顺序；书签已有的封面会保留，除非**书签已有封面时**设为替换；用**用当前画面作为封面**保存的封面永远不会被替换。截图不经预览直接保存，因此通知会提供**移除封面**，**撤销**会连同书签一起移除封面。私密窗口中以及**永不捕获这些网站**或**从不读取这些网站**中的网站都不会截取。设置中的**封面图片质量**决定所有封面的保存质量。

## 相关工具 [#related-tools]

- [查找并修复失效链接](/guides/dead-links)会检查已加入书签的网页是否仍能加载。
- **隐私扫描**（位于**安全**下）会标记包含令牌、电子邮件地址、UUID 或敏感参数的网址（如果开启了**扫描标题**，还包括标题）。审阅时会按**高**、**中**、**低**分组；每一项默认设为**保持不变**，改为**删除书签**的项（逐个或使用**将所选设为…**）会在你点击**删除**后删除，并可撤销。普通的页内链接和应用地址（例如 Gmail 的 `#inbox`）不会被标记。
- **元数据获取**（位于**页面标题与图标**下）会根据在线网页建议网页标题，并只应用你选中的建议。它使用与失效链接检查相同的网站访问权限。它同样在后台运行，标题会在**查看结果**中等你查看。
