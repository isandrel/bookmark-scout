description: 经审阅后移除重复书签，先预览再从书签网址中去除 utm_source 等跟踪参数，并刷新缺失的网站图标。
---

这两个工具都位于书签管理器的**工具**侧栏中的**维护**下。在 Chrome 中，打开浏览器的书签页面；如果侧栏处于隐藏状态，请点击书签管理器顶部的**显示工具**。

<Callout title="Firefox">
Firefox 不允许扩展程序替换其自带的书签页面，因此在 Firefox 中，请通过工具栏弹出窗口中的**打开书签管理器**打开书签管理器，然后打开工具侧栏。
</Callout>

## 移除重复书签 [#remove-duplicate-bookmarks]

<Steps>
<Step>
在**重复书签清理**中点击**扫描**。它始终检查所有书签。
</Step>
<Step>
审阅各个组。每个组只显示一次共同的网址，然后列出每个书签及其文件夹和添加日期。标有**保留**的书签按**保留规则**选出，你也可以用单选按钮改选另一个；其余每个副本都有一个**移除**复选框，默认勾选。取消勾选某个副本或某个组，即可保留它们。
</Step>
<Step>
点击**移除 N 个重复项**删除勾选的副本，或点击**取消**不做任何更改。
</Step>
<Step>
改变主意了？请在 10 秒内点击消息中的**撤消**，恢复已移除的书签。之后，在书签管理器中按 <Shortcut id="manager.undo" /> 也能恢复。
</Step>
</Steps>

<Screenshot name="duplicates" />

哪些书签算作重复，在[设置](/settings)的**维护**标签页中设置：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| **匹配策略** | 规范化网址 | 按**完全相同的网址**、**规范化网址**、**标题 + 网址**或**仅标题**进行比较 |
| **统一 www** | 开启 | 将 `www.example.com` 和 `example.com` 视为同一主机 |
| **忽略协议** | 开启 | 将 `http` 和 `https` 版本视为重复 |
| **忽略末尾斜杠** | 开启 | 将末尾带有和不带 `/` 的网址视为重复 |
| **保留规则** | 最早的 | 在每个组中保留**最早的**、**最新的**或**最先找到的**书签 |
| **最大组数** | <SettingDefault path="maintenance.duplicates.max_groups" /> | 单次扫描最多返回的组数 |

移除任何内容之前，都会再次检查每个组。如果标为**保留**的书签已被删除或现在指向其他地方，整个组都不会被改动，并且消息会说明跳过了多少个组。使用**仅标题**匹配时，如果某个组包含不同的网址，会显示警告，因为移除这些副本会删除不同的网页。

## 去除跟踪参数 [#strip-tracking-parameters]

<Steps>
<Step>
在**网址清理**中，从范围菜单中选择当前文件夹或所有书签，然后点击**清理**。
</Step>
<Step>
按清理原因（**移除的参数**中的条目，例如 `utm_*`、重复参数或片段）分组查看将要更改的网址。每个网址默认是**清理**；要保留的网址，可单独设置，或用**将所选设为…**批量设为**保持不变**。
</Step>
<Step>
点击**清理 N 个网址**更新仍为**清理**的网址，或关闭对话框不做任何更改。
</Step>
</Steps>

如果某个书签在预览后发生了变化，它会被跳过，并计入消息中的数量。点击消息中的**撤消**，或在书签管理器中按 <Shortcut id="manager.undo" />，可恢复原来的网址；此后再次更改过的书签会保持原样。

规则位于设置的**维护**标签页中：

- **移除的参数**：要去除的参数。默认列表为 <SettingDefault path="maintenance.url_cleaner.remove_params" />。以 `*` 结尾的名称会匹配所有以此开头的名称。
- **保留的参数**：永远不会被移除的参数。默认值：<SettingDefault path="maintenance.url_cleaner.preserve_params" />。
- **去除重复查询参数**（默认开启）会移除重复出现的参数。
- **排序查询参数**（默认开启）会按字母顺序排列剩余的参数。
- **移除片段**（默认关闭）还会移除 `#section` 之类的部分。

## 刷新网站图标 [#refresh-site-icons]

在 Bookmark Scout 获得某个网站的图标之前，书签会显示通用的地球图标。在 Chrome 和 Edge 中，最快的方法是点击**刷新网站图标**卡片上的**显示浏览器图标**，或在[设置](/settings#appearance)中开启**使用浏览器的图标缓存**：这会显示浏览器已为你访问的网站保存的图标，并且浏览器只会请求读取网站图标的权限。对于浏览器没有图标的网站，以及在不向扩展程序提供图标缓存的 Firefox 中，工具侧栏中**页面标题与图标**下的**刷新网站图标**会下载每个网站自己的图标。

<Steps>
<Step>
从范围菜单中选择当前文件夹或所有书签，然后点击**刷新**。在系统询问时，请允许访问该范围内的网站（范围内超过 20 个网站时会请求访问所有网站）；如果你拒绝，则不会发出任何请求。
</Step>
<Step>
按标签页查看各网站：**新图标**、**图标相同**、**无图标**和**失败**，每个都显示数量，还会说明有多少个书签因不是网页链接而被跳过。找到的图标默认设为**保存图标**；可以把某一项改为**跳过**，或选中多项后使用**将所选设为…**。
</Step>
<Step>
点击**保存**（例如**保存 12 个图标**）保留仍设为**保存图标**的图标，或关闭对话框不保留任何图标。
</Step>
</Steps>

对于范围内的每个网站（源），该工具会在不携带 Cookie 的情况下请求一个已加入书签的网页，只读取其 head 部分，并下载该网页列出的图标中最接近**首选图标大小**的那个，或者该网站的 `/favicon.ico`。只会使用书签所在域名下的图标文件，从不使用第三方图标服务。超过**图标文件大小上限**（<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> KB）或不是图片的文件会被跳过。

刷新在后台运行：关闭管理器后仍会继续，其卡片和**后台任务**会显示进度，并可**暂停**、**继续**或**取消**。结果会在**查看结果**中等你查看；在你点击**保存**之前不会保存任何内容。

已保存的图标存储在此浏览器的本地存储中，不会同步，并会显示在弹出窗口、侧边栏和书签管理器中。它们优先于浏览器缓存的图标。卡片上会显示已保存的图标数量；**清除已保存的图标**会将其全部删除。当总大小达到**图标存储上限**（4 MB）时，会先移除最早保存的图标。如果某个网站在之后的刷新中失败，会继续保留之前保存的图标。

<Callout title="Firefox">
在 Firefox 中，请通过工具栏弹出窗口中的**打开书签管理器**打开书签管理器来运行此工具。在那里保存图标后，弹出窗口和侧边栏就会显示这些图标。
</Callout>

## 用智能规则添加标签和移动 [#tag-and-move-with-smart-rules]

智能规则用与搜索框相同的词语和[运算符](/guides/search#search-words-and-operators)搜索书签，然后为它们添加标签、移动到文件夹，或两者都做。规则从不自行运行：每次运行都是一次审阅，由你决定应用哪些更改。

<Steps>
<Step>
在[设置](/settings#maintenance)的**智能规则**中点击**添加规则**；也可以点击**从模板开始**，为 GitHub 页面、YouTube 视频或教程添加标签。模板默认关闭。
</Step>
<Step>
为规则设置名称和搜索，例如 `domain:github.com` 或 `folder:稍后阅读 -tag:已读`。编辑器会显示当前匹配的书签数量。添加用逗号分隔的标签、选择要移动到的文件夹，或两者都设置，然后保存。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**智能规则**卡片上选择范围，然后点击**运行**。
</Step>
<Step>
按标签页审阅书签：**更改**、**冲突**（两条规则会把它移动到不同的文件夹）、**已阻止**（它的文件夹已不存在或受管理）和**已完成**。更改默认设为**应用**，冲突默认设为**跳过**；可以逐个或使用**将所选设为…**修改，然后点击**应用**（例如**应用 12 项更改**）。
</Step>
</Steps>

须知：

- 规则按列表顺序运行。每条匹配的规则都会添加它的标签；第一条移动书签的规则优先，后面规则指定的文件夹会显示为冲突。拖动规则可以改变顺序。
- 书签已有的标签，无论写法如何，都不会重复添加。文件夹不会被添加标签，也不会被移动。
- 应用后消息中的**撤消**会同时恢复移动和标签。这些移动在历史记录中是一项更改。
- 规则只保存在此设备上，并包含在**备份设置**中。在其他设备上恢复的规则，只有在那台设备上存在对应文件夹时才会移动书签；否则在你重新选择文件夹之前，它的移动会被阻止。
- 在设置中开启**为新书签添加标签**后，无论书签来自 Bookmark Scout、浏览器的星标、其他扩展程序还是同步，已启用的规则都会在书签添加时为其加上标签，因为浏览器不会告知书签的来源。只会添加标签；规则的移动要等你审阅后运行。一次添加的大量书签（同步或导入）以及在设置关闭时添加的书签都会保持不变。

## 在网页中搜索 [#search-inside-pages]

**索引网页正文**会在此设备上保存书签网页的可读正文，让搜索也能找到只出现在网页中的词语。开启前它默认关闭，并且会下载每个要索引的网页。

<Steps>
<Step>
在[设置](/settings#index-page-text)中开启**启用索引网页正文**。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**索引网页正文**卡片上选择范围，然后点击**索引**。如有提示，请允许访问该范围内的网站。
</Step>
<Step>
按标签页审阅网页：**有正文**、**无正文**、**失败**、**已索引**（之前从同一网址索引过）和**已跳过**（不是网页，或位于本地网络）。有正文的网页默认设为**保存正文**；点击**保存**（例如**保存 12 个网页的正文**）。
</Step>
</Steps>

之后，就能在弹出窗口、侧边栏和书签管理器中按正文搜索到这些书签。`content:` 只在网页正文中查找，`has:content` 会找到有正文的书签。书签网址改变后，网页会重新读取。在设置中点击**删除网页正文**会删除索引；书签、标签和历史记录保持不变。

## 在卡片上显示封面 [#show-covers-on-cards]

**获取封面**会保存网页为自己指定的预览图（Open Graph 或 Twitter 卡片图片）的小副本，让书签管理器的**卡片**显示它。开启前它默认关闭。显示卡片时不会下载任何内容：没有已保存封面的卡片仍显示网站图标。

<Steps>
<Step>
在[设置](/settings#fetch-covers)中开启**启用获取封面**。
</Step>
<Step>
在书签管理器的工具侧边栏中，在**获取封面**卡片上选择范围，然后点击**获取**。如有提示，请允许访问该范围内的网站。
</Step>
<Step>
按标签页审阅网页：**有封面**（附图片）、**无封面**、**在其他网站**（图片位于你未允许的网站）、**失败**、**已获取**和**已跳过**。找到的封面默认设为**保存封面**；点击**保存**（例如**保存 12 个封面**）。
</Step>
</Steps>

用**查看**旁的按钮将书签管理器切换到**卡片**即可看到封面。封面属于获取它的网址，因此网址改变的书签在重新获取前会显示图标。封面只保存在此设备上，不会进入备份或导出；在设置中点击**删除封面**即可移除，书签、标签和历史记录保持不变。

也可以用当前网页作为封面：当网页已加入书签且开启了获取封面时，弹出窗口中显示网页保存位置的那一行末尾有一个按钮“**用当前画面作为封面**”，它会截取标签页的画面并显示出来，同时提醒你检查是否含有私密内容。只有点击“**保存封面**”后才会保留。只会从工具栏弹出窗口截取，绝不截取隐私窗口，并且只在标签页仍显示该书签网页时截取。

## 相关工具 [#related-tools]

- [查找并修复失效链接](/guides/dead-links)会检查已加入书签的网页是否仍能加载。
- **隐私扫描**（位于**安全**下）会标记包含令牌、电子邮件地址、UUID 或敏感参数的网址（如果开启了**扫描标题**，还包括标题）。审阅时会按**高**、**中**、**低**分组；每一项默认设为**保持不变**，改为**删除书签**的项（逐个或使用**将所选设为…**）会在你点击**删除**后删除，并可撤销。普通的页内链接和应用地址（例如 Gmail 的 `#inbox`）不会被标记。
- **元数据获取**（位于**页面标题与图标**下）会根据在线网页建议网页标题，并只应用你选中的建议。它使用与失效链接检查相同的网站访问权限。它同样在后台运行，标题会在**查看结果**中等你查看。
