두 도구 모두 북마크 관리자의 **도구** 사이드바에서 **유지 관리** 아래에 있습니다. Chrome에서는 브라우저의 북마크 페이지를 열고, 사이드바가 숨겨져 있으면 관리자 머리글의 **도구 표시**를 클릭하세요.

<Callout title="Firefox">
Firefox는 확장 프로그램이 브라우저 자체의 북마크 페이지를 대체하도록 허용하지 않으므로, 툴바 팝업의 **북마크 관리자 열기**로 관리자를 연 뒤 **도구** 사이드바를 여세요.
</Callout>

## 중복 북마크 제거 [#remove-duplicate-bookmarks]

<Steps>
<Step>
**중복 정리**에서 **검색**을 클릭합니다. 항상 모든 북마크를 검사합니다.
</Step>
<Step>
그룹을 검토합니다. 각 그룹에는 서로 일치하는 북마크가 나열되며, 남길 북마크에는 **유지** 표시가 붙습니다.
</Step>
<Step>
**중복 제거**를 클릭하면 모든 그룹에서 나머지 사본이 삭제되고, **취소**를 클릭하면 아무것도 바뀌지 않습니다.
</Step>
<Step>
마음이 바뀌었나요? 10초 안에 메시지의 **실행 취소**를 클릭하면 제거한 항목이 복원됩니다.
</Step>
</Steps>

<Screenshot name="duplicates" />

무엇을 중복으로 볼지는 [설정](/settings)의 **유지보수** 탭에서 정합니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **비교 방식** | 정규화된 URL | **정확한 URL**, **정규화된 URL**, **제목 + URL**, **제목만** 중 하나로 비교합니다 |
| **www 정규화** | 켜짐 | `www.example.com`과 `example.com`을 같은 호스트로 취급합니다 |
| **프로토콜 무시** | 켜짐 | `http`와 `https` 버전을 중복으로 취급합니다 |
| **끝 슬래시 무시** | 켜짐 | 끝에 `/`가 있는 URL과 없는 URL을 중복으로 취급합니다 |
| **유지 규칙** | 가장 오래된 항목 | 각 그룹에서 **가장 오래된 항목**, **가장 최근 항목**, **처음 발견된 항목** 중 하나를 남깁니다 |
| **최대 그룹 수** | 500 | 한 번의 검사에서 반환하는 최대 그룹 수 |

제거하기 전에 각 그룹을 다시 확인합니다. **유지** 표시가 붙은 북마크가 삭제되었거나 이제 다른 곳을 가리키면 그 그룹 전체를 건드리지 않으며, 몇 개의 그룹을 건너뛰었는지 메시지로 알려 줍니다. **제목만**으로 비교할 때 한 그룹에 서로 다른 URL이 있으면, 그 사본을 제거하면 서로 다른 페이지가 삭제되므로 경고가 표시됩니다.

## 추적 매개변수 제거 [#strip-tracking-parameters]

<Steps>
<Step>
**URL 정리**의 범위 메뉴에서 현재 폴더 또는 모든 북마크를 선택하고 **정리**를 클릭합니다.
</Step>
<Step>
바뀔 모든 URL의 미리 보기를 검토합니다.
</Step>
<Step>
**변경 사항 적용**을 클릭해 모두 업데이트하거나, 대화 상자를 닫아 아무것도 바꾸지 않습니다.
</Step>
</Steps>

미리 본 뒤 바뀐 북마크는 건너뛰며, 메시지에 그 수가 표시됩니다. URL 정리는 실행 취소할 수 없으므로 적용하기 전에 미리 보기를 확인하세요.

규칙은 설정의 **유지보수** 탭에 있습니다.

- **제거할 매개변수**: 제거할 매개변수입니다. 기본 목록은 `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `utm_id`, `gclid`, `fbclid`, `mc_cid`, `mc_eid`, `ref`, `ref_src`, `si`입니다.
- **유지할 매개변수**: 절대 제거하지 않는 매개변수입니다. 기본값: `id`, `page`, `q`, `p`, `lang`.
- **쿼리 매개변수 중복 제거**(기본적으로 켜짐)는 반복된 매개변수를 제거합니다.
- **쿼리 매개변수 정렬**(기본적으로 켜짐)은 남은 매개변수를 알파벳순으로 정렬합니다.
- **프래그먼트 제거**(기본적으로 꺼짐)는 `#section` 같은 부분도 제거합니다.

## 사이트 아이콘 새로 고침 [#refresh-site-icons]

북마크에는 브라우저가 사이트마다 캐시해 둔 아이콘이 표시됩니다. 최근에 방문하지 않은 사이트에는 기본 지구본 아이콘이 표시되며, Firefox는 확장 프로그램에 아이콘 캐시를 전혀 제공하지 않습니다. **도구** 사이드바의 **메타데이터 및 콘텐츠** 아래에 있는 **사이트 아이콘 새로 고침**은 대신 각 사이트의 아이콘을 직접 내려받습니다.

<Steps>
<Step>
범위 메뉴에서 현재 폴더 또는 모든 북마크를 선택하고 **새로 고침**을 클릭합니다. 처음에는 요청이 표시되면 웹사이트 접근을 허용하세요. 거부하면 아무것도 요청하지 않습니다.
</Step>
<Step>
결과를 검토합니다. **업데이트됨**, **변경 없음**, **아이콘 없음**, **실패**인 아이콘이 각각 몇 개인지, 웹 링크가 아니어서 **건너뜀** 처리된 북마크가 몇 개인지 표시됩니다.
</Step>
<Step>
**저장**(예: **아이콘 12개 저장**)을 클릭해 보관하거나, 대화 상자를 닫아 아무것도 보관하지 않습니다.
</Step>
</Steps>

범위 안의 각 웹사이트(origin)마다 이 도구는 북마크한 페이지 하나를 쿠키 없이 요청해 head만 읽고, 페이지에 나열된 아이콘 중 **선호하는 아이콘 크기**에 가장 가까운 아이콘이나 사이트의 `/favicon.ico`를 내려받습니다. 북마크와 같은 도메인의 아이콘 파일만 사용하며, 타사 아이콘 서비스는 사용하지 않습니다. **최대 아이콘 파일 크기**(64 KB)를 넘거나 이미지가 아닌 파일은 건너뜁니다.

저장된 아이콘은 이 브라우저의 로컬 저장소에 보관되며 동기화되지 않고, 팝업, 사이드 패널, 관리자에 표시됩니다. 브라우저가 캐시한 아이콘보다 우선합니다. 카드에 저장된 아이콘 수가 표시되며, **저장된 아이콘 지우기**를 누르면 모두 삭제됩니다. 전체 크기가 **아이콘 저장 용량 제한**(4096 KB)에 도달하면 가장 오래된 아이콘부터 삭제됩니다. 나중에 새로 고칠 때 실패한 사이트는 이전에 저장한 아이콘을 유지합니다.

<Callout title="Firefox">
Firefox에서 이 도구를 실행하려면 툴바 팝업의 **북마크 관리자 열기**로 관리자를 여세요. 거기서 아이콘을 저장하면 팝업과 사이드 패널에 표시됩니다.
</Callout>

## 관련 도구 [#related-tools]

- [깨진 링크 찾기와 복구](/guides/dead-links)는 북마크한 페이지가 아직 열리는지 확인합니다.
- **개인정보 스캐너**(**보안** 아래)는 토큰, 이메일 주소, UUID, 민감한 매개변수가 포함된 URL(**제목 검사**가 켜져 있으면 제목도)을 찾아 표시하므로, 직접 편집하거나 삭제할 수 있습니다.
- **메타데이터 가져오기**(**메타데이터 및 콘텐츠** 아래)는 실제 페이지에서 페이지 제목을 제안하고 선택한 제목만 적용합니다. 깨진 링크 확인과 같은 웹사이트 접근 권한을 사용합니다.
