두 도구 모두 북마크 관리자의 **도구** 사이드바에서 **유지 관리** 아래에 있습니다. Chrome에서는 브라우저의 북마크 페이지를 열고, 사이드바가 숨겨져 있으면 관리자 머리글의 **도구 표시**를 클릭하세요.

<Callout title="Firefox">
Firefox는 확장 프로그램이 브라우저 자체의 북마크 페이지를 대체하도록 허용하지 않으므로, 툴바 팝업의 **북마크 관리자 열기**로 관리자를 연 뒤 **도구** 사이드바를 여세요.
</Callout>

사이드바에 표시할 도구와 각 섹션 안에서의 순서는 [설정](/settings#tools-sidebar)의 **사이드바 도구**에서 고릅니다. 그곳에서 숨긴 도구도 자동 작업은 계속합니다. 같은 곳의 **시작 탭**에서 사이드바가 열릴 때의 탭을 고릅니다.

## 중복 북마크 제거 [#remove-duplicate-bookmarks]

<Steps>
<Step>
**중복 정리**에서 **검색**을 클릭합니다. 항상 모든 북마크를 검사합니다.
</Step>
<Step>
그룹을 검토합니다. 각 그룹은 공통 주소를 한 번 표시하고, 그 아래에 각 북마크를 폴더 및 추가 날짜와 함께 보여 줍니다. **유지** 표시는 **유지 규칙**을 따르지만 라디오 버튼으로 다른 북마크를 고를 수 있습니다. 나머지 사본에는 처음부터 체크된 **제거** 체크박스가 있습니다. 남기려는 사본이나 그룹의 체크를 해제하세요.
</Step>
<Step>
**중복 N개 제거**를 클릭하면 체크한 사본이 삭제되고, **취소**를 클릭하면 아무것도 바뀌지 않습니다.
</Step>
<Step>
마음이 바뀌었나요? 10초 안에 메시지의 **실행 취소**를 클릭하면 제거한 항목이 복원됩니다. 나중에 북마크 관리자에서 <Shortcut id="manager.undo" />를 눌러도 복원됩니다.
</Step>
</Steps>

<Screenshot name="duplicates" />

무엇을 중복으로 볼지는 [설정](/settings)의 **유지보수** 탭에서 정합니다.

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| **비교 방식** | 정규화된 URL | **정확한 URL**, **정규화된 URL**, **제목 + URL**, **제목만** 중 하나로 비교합니다 |
| **www 정규화** | 켜짐 | `www.example.com`과 `example.com`을 같은 호스트로 취급합니다 |
| **프로토콜 무시** | 켜짐 | `http`와 `https` 버전을 중복으로 취급합니다 |
| **끝 슬래시 무시** | 켜짐 | 끝에 `/`가 있는 URL과 없는 URL을 중복으로 취급합니다 |
| **유지 규칙** | 가장 오래된 항목 | 각 그룹에서 **가장 오래된 항목**, **가장 최근 항목**, **처음 발견된 항목** 중 하나를 남깁니다 |
| **최대 그룹 수** | <SettingDefault path="maintenance.duplicates.max_groups" /> | 한 번의 검사에서 반환하는 최대 그룹 수 |

제거하기 전에 각 그룹을 다시 확인합니다. **유지** 표시가 붙은 북마크가 삭제되었거나 이제 다른 곳을 가리키면 그 그룹 전체를 건드리지 않으며, 몇 개의 그룹을 건너뛰었는지 메시지로 알려 줍니다. **제목만**으로 비교할 때 한 그룹에 서로 다른 URL이 있으면, 그 사본을 제거하면 서로 다른 페이지가 삭제되므로 경고가 표시됩니다.

## 추적 매개변수 제거 [#strip-tracking-parameters]

<Steps>
<Step>
**URL 정리**의 범위 메뉴에서 현재 폴더 또는 모든 북마크를 선택하고 **정리**를 클릭합니다.
</Step>
<Step>
바뀔 URL을 정리 이유(`utm_*` 같은 **제거할 매개변수** 항목, 반복된 매개변수, 프래그먼트)별로 검토합니다. 처음에는 모두 **정리**입니다. 그대로 둘 URL은 하나씩 또는 <strong>선택 항목 설정…</strong>으로 한꺼번에 **그대로 유지**로 바꿉니다.
</Step>
<Step>
**URL N개 정리**를 클릭하면 **정리**로 남은 URL이 업데이트되고, 대화 상자를 닫으면 아무것도 바뀌지 않습니다.
</Step>
</Steps>

미리 본 뒤 바뀐 북마크는 건너뛰며, 메시지에 그 수가 표시됩니다. 메시지의 **실행 취소**를 클릭하거나 북마크 관리자에서 <Shortcut id="manager.undo" />를 누르면 이전 URL로 되돌아갑니다. 그 사이 다시 바뀐 북마크는 그대로 둡니다.

규칙은 설정의 **유지보수** 탭에 있습니다.

- **제거할 매개변수**: 제거할 매개변수입니다. 기본 목록은 <SettingDefault path="maintenance.url_cleaner.remove_params" />입니다. `*`로 끝나는 이름은 그 문자열로 시작하는 모든 이름과 일치합니다.
- **유지할 매개변수**: 절대 제거하지 않는 매개변수입니다. 기본값: <SettingDefault path="maintenance.url_cleaner.preserve_params" />.
- **쿼리 매개변수 중복 제거**(기본적으로 켜짐)는 반복된 매개변수를 제거합니다.
- **쿼리 매개변수 정렬**(기본적으로 켜짐)은 남은 매개변수를 알파벳순으로 정렬합니다.
- **프래그먼트 제거**(기본적으로 꺼짐)는 `#section` 같은 부분도 제거합니다.

## 사이트 아이콘 새로 고침 [#refresh-site-icons]

Bookmark Scout가 사이트의 아이콘을 갖기 전까지 북마크에는 기본 지구본 아이콘이 표시됩니다. Chrome과 Edge에서 가장 빠른 방법은 **사이트 아이콘 새로 고침** 카드의 **브라우저 아이콘 표시**나 [설정](/settings#appearance)의 **브라우저 아이콘 캐시 사용**입니다. 방문하는 사이트에 대해 브라우저가 이미 저장한 아이콘을 표시하며, 브라우저는 사이트 아이콘을 읽을 권한만 요청합니다. 브라우저에 아이콘이 없는 사이트와, 확장 프로그램에 아이콘 캐시를 제공하지 않는 Firefox에서는 **도구** 사이드바의 **페이지 세부 정보** 아래에 있는 **사이트 아이콘 새로 고침**이 각 사이트의 아이콘을 직접 내려받습니다.

<Steps>
<Step>
범위 메뉴에서 현재 폴더 또는 모든 북마크를 선택하고 **새로 고침**을 클릭합니다. 요청이 표시되면 해당 범위에 있는 사이트에 대한 접근을 허용하세요(20개가 넘는 사이트를 포함하는 범위는 모든 웹사이트에 대한 접근을 요청합니다). 거부하면 아무것도 요청하지 않습니다.
</Step>
<Step>
사이트를 탭별로 검토합니다: **새 아이콘**, **같은 아이콘**, **아이콘 없음**, **실패**에 각각 개수가 표시되고, 웹 링크가 아니어서 건너뛴 북마크 수도 안내됩니다. 찾은 아이콘은 처음에 **아이콘 저장**으로 설정되어 있습니다. 하나를 **건너뛰기**로 바꾸거나, 여러 개를 선택하고 <strong>선택 항목 설정…</strong>을 사용하세요.
</Step>
<Step>
**저장**(예: **아이콘 12개 저장**)을 클릭하면 **아이콘 저장**으로 남은 아이콘을 보관합니다. 아무것도 보관하지 않으려면 대화상자를 닫으세요.
</Step>
</Steps>

범위 안의 각 웹사이트(origin)마다 이 도구는 북마크한 페이지 하나를 쿠키 없이 요청해 head만 읽고, 페이지에 나열된 아이콘 중 **선호하는 아이콘 크기**에 가장 가까운 아이콘이나 사이트의 `/favicon.ico`를 내려받습니다. 북마크와 같은 도메인의 아이콘 파일만 사용하며, 타사 아이콘 서비스는 사용하지 않습니다. **최대 아이콘 파일 크기**(<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> KB)를 넘거나 이미지가 아닌 파일은 건너뜁니다.

새로 고침은 백그라운드에서 실행됩니다. 관리자를 닫아도 계속되며, 카드와 **백그라운드 작업**에 진행 상황이 표시되고 **일시 중지**, **다시 시작**, **취소**를 할 수 있습니다. 결과는 **결과 보기**에서 기다리며, **저장**을 누르기 전에는 아무것도 저장되지 않습니다.

저장된 아이콘은 이 브라우저의 로컬 저장소에 보관되며 동기화되지 않고, 팝업, 사이드 패널, 관리자에 표시됩니다. 브라우저가 캐시한 아이콘보다 우선합니다. 카드에 저장된 아이콘 수가 표시되며, **저장된 아이콘 지우기**를 누르면 모두 삭제됩니다. 전체 크기가 **아이콘 저장 용량 제한**(4 MB)에 도달하면 가장 오래된 아이콘부터 삭제됩니다. 나중에 새로 고칠 때 실패한 사이트는 이전에 저장한 아이콘을 유지합니다.

<Callout title="Firefox">
Firefox에서 이 도구를 실행하려면 툴바 팝업의 **북마크 관리자 열기**로 관리자를 여세요. 거기서 아이콘을 저장하면 팝업과 사이드 패널에 표시됩니다.
</Callout>

## 스마트 규칙으로 태그 추가와 이동 [#tag-and-move-with-smart-rules]

스마트 규칙은 검색창과 같은 단어와 [연산자](/guides/search#search-words-and-operators)로 북마크를 찾아 태그를 추가하거나, 폴더로 옮기거나, 둘 다 합니다. 규칙은 아래에서 설명하는 설정을 켠 경우에만 스스로 실행됩니다. 그 밖에는 실행할 때마다 검토 화면이 열리고, 적용한 것만 바뀝니다.

<Steps>
<Step>
[설정](/settings#maintenance)의 **스마트 규칙**에서 **규칙 추가**를 클릭합니다. GitHub 페이지, YouTube 동영상, 튜토리얼에 태그를 추가하는 규칙이나 **Work / Reading** 폴더의 북마크를 옮기는 규칙은 **템플릿으로 시작**으로 만들 수도 있습니다. 템플릿은 처음에 꺼져 있습니다. 옮기는 템플릿은 아직 폴더가 없어서 편집기에서 열리며, 폴더를 고르기 전에는 켜거나 저장할 수 없습니다.
</Step>
<Step>
규칙에 이름과 검색(예: `domain:github.com`, `folder:읽을거리 -tag:읽음`, `(domain:github.com OR domain:gitlab.com) -tag:archived`)을 정합니다. 편집기에 지금 일치하는 북마크 수나, 닫히지 않은 괄호처럼 검색의 문제가 표시됩니다. 검색을 읽을 수 있어야 규칙을 저장할 수 있습니다. **주소나 제목으로 테스트**에 웹 주소나 제목을 입력하면 검색이 그것과 일치하는지 확인할 수 있습니다. 이 확인은 기기에서 이루어지며, 아무것도 저장하거나 보내지 않습니다. 태그(하나마다 Enter 키를 누르거나 쉼표 입력), 옮길 폴더, 또는 둘 다 정하고 저장합니다.
</Step>
<Step>
관리자의 도구 사이드바에서 **스마트 규칙** 카드의 범위를 고르고 **실행**을 클릭합니다. 범위는 표시 중인 폴더, 모든 북마크, 또는 관리자에 있는 동안 **검색 결과**(검색 상자에 나열된 항목)나 **선택한 북마크**입니다. 범위는 클릭할 때 정해지며, 범위 밖의 북마크는 검토하거나 바꾸지 않습니다.
</Step>
<Step>
북마크를 탭별로 검토합니다: **변경**, **충돌**(두 규칙이 서로 다른 폴더로 옮기려 함), **차단됨**(폴더가 없거나 관리됨, 또는 그 폴더에서는 다른 규칙이 다시 옮김), **이미 적용됨**. 변경은 처음에 **적용**, 충돌은 **건너뛰기**로 설정되어 있습니다. 하나씩 또는 <strong>선택 항목 설정…</strong>으로 바꾼 다음 **적용**(예: **변경 12개 적용**)을 클릭합니다.
</Step>
</Steps>

알아 두면 좋은 점:

- 규칙은 목록 순서대로 실행됩니다. 일치하는 규칙은 모두 태그를 추가하고, 북마크를 옮기는 규칙은 처음 것이 우선하며, 뒤의 규칙이 정한 폴더는 충돌로 표시됩니다. 규칙을 끌어서 순서를 바꿀 수 있습니다.
- 실행 결과는 안정됩니다. 일치하는 규칙이 지정한 폴더에 이미 있는 북마크는 그대로 두고, 새 폴더와 새 태그에서 어떤 규칙도 다시 옮기지 않을 때만 옮깁니다. 그래서 규칙을 두 번 실행해도 북마크가 왔다 갔다 하지 않습니다.
- 규칙은 북마크를 하나씩 따로 다룹니다. 주소가 같은 북마크가 서로 다른 폴더에 있으면 각각 따로 판단하고 바꿉니다.
- 북마크에 이미 있는 태그는 표기가 달라도 다시 추가하지 않습니다. 폴더에는 태그를 추가하거나 폴더를 옮기지 않습니다.
- 적용한 뒤 메시지의 **실행 취소**는 이동과 태그를 모두 되돌립니다. 이동은 기록에서 하나의 변경입니다. 실행은 설정의 **규칙으로 변경됨**에도 태그를 추가한 북마크와 함께 표시되며, 거기서 **실행 취소**로 나중에도 아직 남아 있는 그 태그를 삭제할 수 있습니다. 이동은 기록에서 되돌립니다.
- 태그와 이동은 따로 저장되므로, 메시지에는 태그 추가, 이동, 건너뜀, 실패 수가 표시됩니다. 기록에 남기지 않고 옮기는 일은 없습니다. 그 기록을 저장할 수 없으면 아무것도 옮기지 않고, 태그는 추가하며, 메시지로 알려 줍니다.
- 적용할 때는 먼저 각 북마크를 다시 확인합니다. 검토 뒤 삭제되거나, 이름이 바뀌거나, 주소가 바뀌거나, 다른 곳으로 옮겨진 북마크는 건너뛰고 사용자의 변경을 그대로 둡니다. 검토 뒤 규칙이 편집되거나, 꺼지거나, 삭제된 북마크도 마찬가지입니다(규칙 이름 변경은 해당하지 않음). 메시지에 그 수가 표시됩니다. 이미 검토 결과대로인 북마크는 다시 바꾸지 않습니다. 검토 뒤 태그나 요약을 바꿔 규칙에 더 이상 맞지 않는 북마크도 건너뜁니다.
- **백그라운드 적용 기준**(설정의 **백그라운드 작업**)보다 많은 북마크를 바꾸는 실행은 백그라운드 작업이 태그와 이동을 함께 나누어 적용합니다. 관리자를 닫거나 브라우저를 다시 시작해도 계속되며, **백그라운드 작업**에서 일시 중지, 다시 시작, 취소할 수 있습니다. 취소해도 이미 적용한 내용은 그대로 남습니다. 각 부분의 이동은 기록에서 하나의 변경이며, 실행의 태그는 추가하기 전에 기록되어 **규칙으로 변경됨**에 표시됩니다. 부분을 적용하는 도중 브라우저가 멈추면 작업은 **다시 시작**을 기다리며, 다시 시작하면 남은 각 북마크를 다시 확인하므로 태그 추가나 이동이 두 번 일어나지 않습니다. 스마트 규칙을 끄면 다시 켜고 다시 시작할 때까지 작업이 일시 중지되며, 그사이 편집되거나 꺼진 규칙의 북마크는 건너뜁니다.
- 설정에서 각 규칙에는 마지막으로 검토한 실행이 표시됩니다. 언제 실행했는지와 태그를 추가한, 옮긴, 제외한 북마크 수입니다. **마지막 실행의 충돌**에는 두 규칙이 서로 다른 폴더로 옮기려 한 북마크가 각 규칙이 지정한 폴더와 함께 표시되며, **검토**를 누르면 그 북마크의 폴더에서 관리자가 열리고 거기서 바로 스마트 규칙을 실행할 수 있습니다.
- 규칙은 이 기기에 저장되며 **설정 백업**에 포함됩니다. 다른 기기에서 복원한 규칙은 그 기기에 폴더가 있을 때만 북마크를 옮기고, 없으면 폴더를 다시 고를 때까지 이동이 차단됩니다. 그 기기에서 폴더 ID가 다르면, 같은 경로의 폴더가 하나뿐일 때 그 경로로 폴더를 찾습니다.
- 설정에서 **새 북마크에 태그 추가**를 켜면, 사용 중인 규칙이 **적용할 새 북마크**에서 허용한 각 새 북마크에 태그를 붙입니다. 기본값은 **Bookmark Scout로 저장한 북마크**로, 빠른 저장, 팝업, 관리자, Ask AI로 저장한 북마크입니다. 브라우저의 별표, 다른 확장 프로그램, 동기화로 추가된 북마크도 포함하려면 **모든 곳**을 고르세요. 브라우저가 북마크의 출처를 알려 주지 않으므로 이들은 모두 똑같이 다룹니다. 아무것도 옮기지 않습니다. 한꺼번에 추가된 많은 북마크(동기화나 가져오기)와 설정에서 허용하지 않을 때 추가된 북마크는 그대로 둡니다. 자동으로 추가한 태그는 설정의 **규칙으로 변경됨**에 표시되며, 되돌리기로 그 태그를 삭제할 수 있습니다.
- 검토 없이 옮기려면 태그 추가와 별개로 두 가지를 직접 선택해야 합니다. 규칙의 폴더 옆에 있는 **새 북마크 자동으로 이동**과 설정의 **새 북마크 이동**입니다. 규칙 목록에서는 그런 규칙 아래에 **새 북마크를 자동으로 옮깁니다**가 표시됩니다. 그러면 규칙에 맞는 새 북마크는 그 폴더로만 옮겨집니다. 폴더가 삭제되거나 이름이 바뀌거나 옮겨지거나 관리되는 폴더가 되면, 규칙에 자동 이동이 멈췄다고 표시되고 폴더를 다시 선택해 규칙을 저장할 때까지 아무것도 옮기지 않습니다. 경로가 같은 다른 폴더를 대신 쓰지 않습니다. 실행할 때와 같이 북마크를 옮기는 첫 번째 규칙이 우선하며, 두 규칙이 서로 다른 폴더로 옮기려는 북마크는 그대로 둡니다. Bookmark Scout로 저장한 북마크(빠른 저장, 관리자)는 놓인 자리에 그대로 두므로, 자동 이동에는 **적용할 새 북마크**를 **모든 곳**으로 설정해야 합니다. 한꺼번에 추가된 많은 북마크와 몇 초 안에 다시 옮겨진 북마크도 그대로 둡니다. 이동은 묶음마다 [기록](/guides/save-and-organize)에 Bookmark Scout의 변경 하나로 "스마트 규칙, 자동"이라는 이름으로 남고, 그 기록을 저장할 수 없으면 아무것도 옮기지 않습니다. 각 이동은 **규칙으로 변경됨**에 표시됩니다. 거기서 되돌리면, 그 뒤에 옮겨지지 않은 경우 북마크를 이전 폴더로 되돌립니다.
- 검색이 `OR`와 괄호를 읽기 전에 저장한 규칙은 예전과 같은 북마크를 찾습니다. 이들은 따옴표로 감싼 텍스트로 읽힙니다.
- 규칙은 페이지 텍스트를 검색하지 않습니다. 규칙은 색인된 페이지 텍스트 없이 북마크를 비교하므로 `content:`나 `has:content`가 들어간 검색은 규칙에 저장할 수 없습니다([페이지 안에서 검색](#search-inside-pages)).

## 페이지 안에서 검색 [#search-inside-pages]

**페이지 본문 색인**은 북마크한 페이지의 읽을 수 있는 본문을 이 기기에 보관해, 페이지 안에만 있는 단어도 검색으로 찾게 합니다. 켜기 전에는 꺼져 있으며, 색인하는 페이지를 내려받습니다.

<Steps>
<Step>
[설정](/settings#index-page-text)에서 **페이지 본문 색인 사용**을 켭니다.
</Step>
<Step>
관리자의 도구 사이드바에서 **페이지 본문 색인** 카드의 범위를 고르고 **색인**을 클릭합니다. 이어서 읽을 사이트를 고릅니다. 내려받을 페이지가 있는 사이트가 북마크 수와 함께 나열되며, 처음에는 모두 체크되어 있습니다. 제외할 사이트의 체크를 해제하고(**모두 선택**, **모두 해제**, 목록이 길면 필터도 쓸 수 있음) 사이트 수가 표시된 시작 버튼(예: **사이트 2개로 시작**)을 클릭합니다. 요청이 오면 그 사이트에 대한 접근을 허용합니다. 다른 사이트는 요청하거나 내려받지 않습니다. 색인은 백그라운드에서 실행됩니다. 관리자를 닫아도 계속되며, 카드와 **백그라운드 작업**에 진행 상황이 표시되고 **일시 중지**, **다시 시작**, **취소**를 할 수 있습니다. 그 뒤 페이지는 **결과 보기**에서 기다립니다.
</Step>
<Step>
페이지를 탭별로 검토합니다: **본문 있음**, **본문 없음**, **로그인 페이지**(내용 대신 로그인을 요구한 페이지로, 본문은 저장되지 않음), **리디렉션됨**(다른 주소로 이동하는 페이지로, 그 주소는 열지 않으므로 허용하지 않은 사이트에는 연결하지 않음. 이동하는 주소를 북마크하세요), **실패**, **이미 색인됨**(전에 같은 주소에서 색인함), **선택 안 함**(제외한 사이트에 있어 내려받지 않음), **건너뜀**(웹 페이지가 아니거나, **로컬 네트워크 페이지 건너뛰기**가 켜져 있는 동안(기본값) 로컬 네트워크에 있음). 본문이 있는 페이지는 처음에 **본문 저장**으로 설정되어 있습니다. **저장**(예: **페이지 12개의 본문 저장**)을 클릭합니다. 페이지를 리디렉션됨으로 분류하기 전에 그 페이지의 `https:` 주소와 `www.`를 붙이거나 뺀 주소를 북마크 자체 사이트에서만 시도하며, 다시 리디렉션되면 따라가지 않습니다. 이렇게 읽은 페이지에는 "(주소)에서 읽음"이 표시됩니다. 저장하는 중에 이 기기의 확장 프로그램 저장 공간이 가득 차면 그때까지 저장한 페이지는 남고, 저장되지 않은 개수가 메시지로 표시됩니다. 디스크 공간을 확보하거나 설정에서 **페이지 본문 삭제**를 사용한 다음 다시 색인하세요.
</Step>
</Steps>

그러면 팝업, 사이드 패널, 관리자에서 그 북마크를 본문으로 찾을 수 있습니다. `content:`는 페이지 본문에서만 찾고, `has:content`는 본문이 있는 북마크를 찾습니다. 북마크 주소가 바뀌면 페이지를 다시 읽습니다. 설정의 **페이지 본문 삭제**로 색인을 지워도 북마크, 태그, 기록은 그대로입니다. 페이지 본문에서 찾은 결과에는 본문의 출처가 **다운로드한 페이지**인지 **탭에서 읽은 페이지**인지 표시됩니다. 'AI에게 묻기'와 로컬 AI 에이전트는 이 기기에만 남는 페이지 본문을 검색하지 않습니다. 거기서는 `content:`와 `has:content`가 아무것도 찾지 않으며, 답변에서 그렇다고 알려 줍니다.

색인은 쿠키 없이 페이지를 내려받으므로, 로그인해야만 읽을 수 있는 페이지는 대신 로그인 페이지를 보여 주며 **로그인 페이지**로 분류됩니다. 그런 페이지에서 보이는 내용을 색인하려면 페이지를 여세요. 페이지가 북마크되어 있고 페이지 본문 색인이 켜져 있으면, 팝업에서 페이지 저장 위치를 알려 주는 줄의 **이 페이지 본문 색인** 버튼이 탭에 보이는 본문을 읽고 개인적인 내용이 없는지 확인하라는 안내와 함께 보여 줍니다. **본문 저장**을 클릭할 때만 보관됩니다. 본문은 도구 모음 팝업에서만 읽으며, 시크릿 창이나 로그인 페이지에서는 읽지 않고, 읽기 전후에 탭이 북마크한 페이지를 표시하고 있을 때만 읽습니다. 그 사이에 탭이 다른 페이지로 바뀌면 아무것도 보관하지 않습니다.

주소가 같은 북마크는 다운로드 한 번을 함께 쓰고, 각자 자기 본문을 보관합니다. 두 가지 경우는 따로 표시됩니다. **웹 페이지 아님**(주소가 PDF 같은 파일로 응답하며, 다운로드하지 않음), 그리고 **건너뜀** 안에서 사용자 이름과 비밀번호나 개인정보 스캐너의 **민감한 매개변수**에 있는 매개변수(예: 토큰)가 든 주소입니다. 이런 주소는 사이트가 그 값을 받게 되므로, 설정의 **로그인 정보나 비밀이 든 주소 건너뛰기**가 켜져 있는 동안(기본값) 요청하지 않습니다. 본문은 단락별 일반 텍스트로 보관되므로, 따옴표로 묶은 구문은 한 단락 안에서만 일치합니다. 바쁘다고 응답하며 짧은 대기 시간을 알려 준 사이트에는 그 시간이 지난 뒤 몇 번까지 다시 요청하고, 그래도 안 되면 페이지를 **실패**에 표시합니다. 어떤 사이트를 페이지 본문 색인에서 아예 빼려면 [설정](/settings#index-page-text)의 **읽지 않을 사이트**에 추가하세요. 그 사이트와 하위 도메인의 페이지는 다운로드하지도 탭에서 읽지도 않고 이유와 함께 **건너뜀**에 표시되며, 그 사이트에서 이미 색인한 본문은 삭제됩니다.

[설정](/settings#index-page-text)의 **페이지 본문 색인** 패널에는 색인할 수 있는 북마크 중 색인된 수, 오래된 수(이전 주소나 이전 버전에서 읽음, 다음 실행 때 다시 읽음), 지난 실행에서 실패한 수가 표시됩니다. **실패한 항목 다시 시도**는 그 북마크만 대상으로 페이지 본문 색인을 백그라운드에서 다시 실행하며, 그 사이트에 대한 액세스만 요청합니다. 본문은 카드의 **결과 보기**에서 저장하세요. 웹사이트에 대한 확장 프로그램의 액세스를 거두면 그 사이트에서 색인한 본문이 삭제되고, 북마크를 삭제하면 그 본문도 삭제됩니다. 패널에는 마지막으로 본문을 색인한 시각도 표시되며, **오래된 항목 새로 고침**은 오래된 페이지를 같은 방식으로 다시 읽습니다.

## 카드에 표지 표시 [#show-covers-on-cards]

**표지 가져오기**는 페이지가 스스로 지정한 미리 보기 이미지(Open Graph 또는 Twitter 카드 이미지)의 작은 복사본을 보관해, 관리자의 **카드**에 표시되게 합니다. 켜기 전에는 꺼져 있습니다. 카드를 보여 줄 때는 아무것도 내려받지 않으며, 보관된 표지가 없는 카드는 사이트에서 고른 색 위에 사이트 아이콘과 이름을 담은 타일을 표시하며, 이 타일은 내 컴퓨터에서 그립니다.

<Steps>
<Step>
[설정](/settings#fetch-covers)에서 **표지 가져오기 사용**을 켭니다.
</Step>
<Step>
관리자의 도구 사이드바에서 **표지 가져오기** 카드의 범위를 고르고 **가져오기**를 클릭합니다. 요청이 오면 그 범위의 사이트에 대한 접근을 허용합니다.
</Step>
<Step>
페이지를 탭별로 검토합니다: **표지 있음**(그림 포함), **표지 없음**, **사용할 수 없는 이미지**(페이지가 지정한 이미지가 지원되지 않는 형식이거나 너무 크거나 읽을 수 없음), **다른 사이트**(허용하지 않은 사이트에 이미지가 있음), **리디렉션됨**(다른 주소로 이동하는 페이지로, 그 주소는 열지 않음. 페이지 본문 색인과 마찬가지로 `https:`와 `www.` 주소를 먼저 시도함), **실패**, **이미 가져옴**, **건너뜀**. 찾은 표지는 처음에 **표지 저장**으로 설정되어 있습니다. **저장**(예: **표지 12개 저장**)을 클릭합니다. 저장하는 중에 이 기기의 확장 프로그램 저장 공간이 가득 차면 그때까지 저장한 표지는 남고, 저장되지 않은 개수가 메시지로 표시됩니다. 디스크 공간을 확보하거나 설정에서 **표지 삭제**를 사용한 다음 다시 가져오세요.
</Step>
</Steps>

**보기** 옆 버튼으로 관리자를 **카드**로 바꾸면 표지가 보입니다. 목록에서는 **보기**의 **표지** 열이 작은 그림으로 보여 주며, 포인터를 올려 두면 더 크게 볼 수 있습니다. 표지는 가져온 주소에 속하므로, 주소가 바뀐 북마크는 다시 가져올 때까지 아이콘을 표시합니다. 표지는 이 기기에만 보관되고 동기화되지 않으며, 북마크 내보내기에도 들어가지 않습니다. 다른 컴퓨터로 옮기려면 백업에 포함하세요([백업에 담기는 것](/guides/import-export#what-a-backup-holds) 참고). 설정의 **표지 삭제**로 지워도 북마크, 태그, 기록은 그대로입니다. 북마크를 삭제하면 그 표지도 삭제됩니다. 한 번의 실행은 찾은 표지를 저장할 때까지 보관하므로, 한 번에 보관할 수 있는 만큼 찾으면 페이지 읽기를 멈춥니다. 남긴 북마크 수는 검토 화면에 표시되고, 다음 실행에서 읽습니다.

지금 보고 있는 페이지를 표지로 쓸 수도 있습니다. 페이지가 북마크되어 있고 표지 가져오기가 켜져 있으면, 팝업에서 페이지 저장 위치를 알려 주는 줄 끝의 **이 화면을 표지로 사용** 버튼이 탭 화면을 찍고 개인적인 내용이 없는지 확인하라는 안내와 함께 보여 줍니다. **표지 저장**을 클릭할 때만 보관됩니다. 도구 모음 팝업에서만 찍으며, 시크릿 창은 찍지 않고, 탭에 북마크한 페이지가 표시되어 있을 때만 찍습니다.

북마크 메뉴(오른쪽 클릭 또는 ⋯, 목록이나 카드에서, 여러 개를 선택해도)나 '미리 보기'의 '표지 가져오기'는 그 북마크에만 표지 가져오기를 실행합니다. 검토 화면과 사이트 접근 권한 요청은 같습니다. '이 화면을 표지로 사용'으로 저장한 표지는 '직접 선택함'에 표시되고 유지됩니다. '표지 가져오기' 카드의 '선택한 북마크'는 관리자에서 선택한 북마크에 같은 작업을 합니다. '표지 제거'는 북마크의 표지를 삭제합니다(선택한 경우 각 북마크의 표지). 카드는 바로 자리 표시 이미지로 바뀌고, 메시지의 '실행 취소'로 같은 표지를 되돌립니다.

### 탐색하면서 표지 캡처하기 [#capture-covers-while-you-browse]

[설정](/settings#fetch-covers)의 표지 가져오기 아래에서 **탐색 중 표지 캡처**를 켜면 가져오기를 실행하지 않아도 표지를 얻을 수 있습니다. 표지가 없는 북마크한 페이지가 보고 있는 탭에서 로드를 마치면, Bookmark Scout는 잠시 기다렸다가 탭이 여전히 그 페이지를 표시하는지 확인한 뒤 그 페이지의 스크린샷을 북마크의 표지로 찍습니다. 이 기능을 켜면 브라우저에 모든 페이지에 대한 접근 권한을 요청합니다. 브라우저가 클릭 없이 확장 프로그램이 탭 화면을 찍도록 허용하는 방법은 이것뿐이기 때문입니다. 같은 접근 권한으로 웹사이트를 읽는 도구도 다시 묻지 않고 실행됩니다.

- 시크릿 창에서는 **비공개 창에서도 캡처**도 켜고 브라우저가 Bookmark Scout의 실행을 그곳에서 허용한 경우에만 찍습니다. 확장 프로그램이나 브라우저 자체 페이지, 로컬 파일, 북마크하지 않은 페이지는 절대 찍지 않습니다.
- 스크린샷에는 계정 페이지나 메시지처럼 페이지에 보이던 내용이 그대로 담깁니다. 찍지 않았으면 하는 사이트는 **캡처하지 않을 사이트**에 추가하고(사이트를 추가하면 하위 도메인도 포함), 표지는 설정의 **표지 삭제**로 지우세요. '읽지 않을 사이트'에 있는 사이트도 캡처하지 않습니다.
- **표지 출처**는 둘 다 가능할 때 어느 표지를 쓸지 정합니다. **페이지 이미지 우선, 없으면 스크린샷**(기본값)에서는 스크린샷이 표지 가져오기로 저장한 이미지를 대체하지 않으며, 표지 가져오기는 스크린샷을 대체합니다. **스크린샷 우선**은 탐색 중에 찍은 스크린샷에 대해 그 반대로 동작하고, **페이지 이미지만**은 스크린샷을 찍지 않습니다. '이 화면을 표지로 사용'으로 저장한 표지는 표지 가져오기나 탐색 중 스크린샷으로 자동 대체되지 않으며, 직접 다른 이미지를 저장할 때만 바뀝니다. **스크린샷만**은 스크린샷만 사용합니다. 이때 표지 가져오기는 페이지를 읽지 않으며 검토 화면에서 이를 알립니다.
- 탐색 중에 찍은 스크린샷은 **다음보다 오래된 스크린샷 다시 찍기**에서 정한 기간보다 오래되면 다음에 방문할 때 다시 찍습니다(0이면 다시 찍지 않음). 얼마나 기다릴지는 **캡처 전 대기 시간**과 **캡처 간격**으로 정합니다. 스크린샷은 다른 모든 표지와 마찬가지로 이 기기에만 보관되며 어디에도 보내지 않습니다. 멈추려면 설정을 끄고, 접근 권한은 브라우저의 확장 프로그램 설정에서 제거하세요.

북마크의 **미리 보기**와 세부 정보 카드에는 표지를 어디서 가져왔는지(페이지 자체 이미지, 내 탭 화면, 탐색 중 캡처)와 저장한 날짜가 표시됩니다. 빠른 저장 시 찍은 그림도 그렇게 표시됩니다.

### 빠른 저장 시 표지 저장 [#save-a-cover-with-quick-save]

표지 가져오기가 켜져 있으면 빠른 저장 단축키가 저장하는 페이지의 표지도 저장합니다([설정](/settings#quick-save)의 **빠른 저장 시 표지 저장**, 기본값 꺼짐, 표지 가져오기도 켜져 있을 때만 작동). 페이지 자체 미리보기 이미지가 그 페이지의 사이트나 허용한 사이트에 있으면 그것을, 아니면 단축키를 누른 순간 알림이 나타나기 전에 찍은 탭 스크린샷을 씁니다. **빠른 저장 표지 출처**로 따로 순서를 정하지 않으면 **표지 출처**를 따르고, **북마크에 이미 표지가 있을 때**를 대체로 바꾸지 않으면 기존 표지를 유지하며, **이 화면을 표지로 사용**으로 저장한 표지는 대체하지 않습니다. 스크린샷은 검토 없이 저장되므로 알림에 **표지 제거**가 표시되고, **실행 취소**는 북마크와 함께 표지를 제거합니다. 시크릿 창이나 **캡처하지 않을 사이트**, **읽지 않을 사이트**의 사이트에서는 아무것도 찍지 않습니다. 설정의 **표지 이미지 품질**이 모든 표지의 저장 품질을 정합니다. 표지가 북마크에 있던 표지를 바꾼 경우 **표지 제거**는 이전 표지를 되돌려 놓습니다.

## 관련 도구 [#related-tools]

- [깨진 링크 찾기와 복구](/guides/dead-links)는 북마크한 페이지가 아직 열리는지 확인합니다.
- **개인정보 스캐너**(**보안** 아래)는 토큰, 이메일 주소, UUID, 민감한 매개변수가 포함된 URL(**제목 검사**가 켜져 있으면 제목도)을 찾아 표시합니다. 검토 화면은 **높음**, **보통**, **낮음**으로 나누어 보여 주며, 각 항목은 처음에 **그대로 유지**로 설정됩니다. **북마크 삭제**로 바꾼 항목(하나씩 또는 <strong>선택 항목 설정…</strong>으로)은 **삭제**를 클릭하면 삭제되며, 실행 취소할 수 있습니다. 일반적인 페이지 내 링크나 Gmail의 `#inbox` 같은 앱 주소는 표시하지 않습니다.
- **메타데이터 가져오기**(**페이지 세부 정보** 아래)는 실제 페이지에서 페이지 제목을 제안하고 선택한 제목만 적용합니다. 깨진 링크 확인과 같은 웹사이트 접근 권한을 사용합니다. 이것도 백그라운드에서 실행되며, 제목은 **결과 보기**에서 기다립니다.
