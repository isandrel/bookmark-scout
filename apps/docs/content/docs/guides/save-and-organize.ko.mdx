## 보고 있는 페이지 저장 [#save-the-page-you-are-on]

<Steps>
<Step>
보관하려는 페이지를 열고 툴바의 Bookmark Scout 아이콘을 클릭하거나, 사이드 패널을 엽니다.
</Step>
<Step>
검색창에 폴더 이름의 일부를 입력합니다. 결과 위의 **폴더에 저장**에 일치하는 폴더가 가장 잘 맞는 것부터, 그 폴더가 들어 있는 폴더와 함께 표시됩니다.
</Step>
<Step>
`Enter`를 누르면 강조 표시된 첫 번째 폴더에 저장되고, 폴더를 클릭해도 저장됩니다. 키보드로 다른 폴더를 고르려면 `↓`로 그 폴더까지 이동한 다음 `Enter`를 누릅니다.
</Step>
</Steps>

검색창 아래의 **저장할 페이지** 줄에는 저장할 페이지의 이름이 표시됩니다. 페이지가 이미 북마크되어 있으면 그 아래 **이미 저장된 위치** 줄에 폴더가 표시됩니다. 다른 폴더에 저장하면 사본이 하나 더 추가되고, 저장 후 메시지에서 이를 알려 줍니다. 여러 단어를 입력하면 폴더 주변의 폴더에도 일치하고(`ai agents`), 4글자 이상인 단어는 오타가 하나 있어도 일치합니다.

<Screenshot name="popup" />

폴더를 고르는 다른 방법도 있습니다.

- **최근**: **최근** 패널에는 최근에 저장한 폴더가 표시됩니다. 폴더를 클릭하면 페이지가 그곳에 저장됩니다.
- **찾아보기**: 트리에서 폴더에 마우스를 올리고 **현재 페이지 추가**를 클릭하거나, 화살표 키로 폴더로 이동한 뒤 `Enter`를 누릅니다.

이미 폴더에 있는 페이지는 다시 저장되지 않으며, 이미 있다는 메시지가 표시됩니다.

툴바 팝업은 팝업을 연 페이지를 묻지 않고 읽습니다. 사이드 패널은 탭을 바꾸는 동안에도 열려 있으므로, 사이드 패널에서 처음 저장할 때 Bookmark Scout가 이유를 설명한 뒤 탭 접근 권한을 요청합니다. 거부하면 아무것도 저장되지 않습니다. 툴바 아이콘과 아래의 빠른 저장 단축키는 이 권한 없이도 동작합니다.

이 목록들을 바꾸려면 [설정](/settings)을 사용하세요. **폴더에 저장**은 **폴더 일치 항목**, **최대 폴더 일치 항목 수**, **오타 허용**으로, **최근** 패널은 **최근 폴더**와 **최근 폴더 최대 수**로 바꿉니다.

## 키보드 단축키로 저장 [#quick-save]

어느 페이지에서나 <Shortcut id="commands.quick-save" />를 누르면 Bookmark Scout를 열지 않고 페이지를 저장합니다. 페이지 위쪽 모서리에 작은 알림이 나타나 어느 폴더에 저장되었는지 알려 주며, **실행 취소**와 **이동** 아래에 다른 폴더 몇 개를 보여 줍니다. 알림은 몇 초 뒤 저절로 닫힙니다. 마우스를 올리거나 Tab 키로 알림에 이동하면 계속 열려 있고, `Esc`를 누르면 닫힙니다. 알림이 페이지의 키보드 입력을 가져가지는 않습니다.

<Screenshot name="quick-save" />

페이지를 저장할 위치는 [설정](/settings#quick-save)의 **빠른 저장 폴더**에서 정합니다.

- **최적 일치**(기본값)는 페이지의 제목, 사이트, 주소를 폴더 이름, 그 주변 폴더, 각 폴더에 이미 있는 북마크의 제목과 사이트와 비교하며, 모든 비교는 기기 안에서 이루어집니다. 중국어, 일본어, 한국어 제목도 지원합니다. **이동**에는 그다음으로 잘 맞는 폴더가 표시됩니다.
- **최근 사용**은 가장 최근에 저장한 폴더에 저장하며, **이동**에는 다른 최근 폴더가 표시됩니다.
- **지정한 폴더**는 항상 **저장할 폴더**에서 고른 폴더에 저장합니다.

잘 맞는 폴더가 없거나 지정한 폴더가 삭제되었으면 마지막으로 사용한 폴더에, 그것도 없으면 북마크바에 저장하고 알림에서 이를 알려 줍니다.

<Shortcut id="commands.ai-quick-save" />를 누르면 대신 AI가 추천하는 폴더에 저장합니다. 팝업의 AI 추천과 같은 AI 서비스, 페이지 읽기 설정, 추천 수를 사용하며 같은 데이터를 보냅니다([AI 도구 설정](/guides/ai-tools) 참고). 기다리는 동안 알림에 <strong>AI가 폴더를 고르는 중...</strong>이 표시되고, 그다음 **이동** 아래에 다른 추천 폴더가 나열됩니다. 추천된 폴더가 아직 없으면 새로 만들어지며, **실행 취소**하면 다시 제거됩니다. AI가 꺼져 있거나 설정되지 않았으면 아무것도 저장되지 않고 알림에 **AI 설정 열기**가 표시됩니다. AI가 폴더를 고르지 못하면 알림에 AI에게 다시 묻는 **다시 시도**와, **빠른 저장 폴더**가 고르는 폴더에 페이지를 저장하는 **AI 없이 저장**이 표시됩니다. AI가 답하기 전에 페이지를 떠나면 결과는 대신 팝업의 페이지 제목 아래에 표시됩니다.

이미 북마크한 페이지는 다시 저장되지 않습니다. 알림에 북마크가 있는 위치가 표시되고 옮길 수 있게 해 줍니다.

**실행 취소**와 **이동**은 가장 최근의 빠른 저장에만 적용됩니다. 다른 탭에서 빠른 저장한 뒤 첫 번째 탭의 알림에서 **실행 취소**를 누르면, 더 최근의 빠른 저장이 이 항목을 대체했다고 알려 줍니다. 이 경우 그 북마크는 북마크 관리자에서 변경하세요.

브라우저 자체 페이지, 확장 프로그램 스토어, PDF 뷰어처럼 확장 프로그램이 아무것도 표시할 수 없는 페이지가 있고, 위에 그려진 내용을 가리는 페이지도 일부 있습니다. 이런 페이지에서는 툴바 아이콘에 잠시 ✓ 또는 ✗가 표시되고, 브라우저가 허용하는 경우 팝업이 열려 페이지 제목과 같은 버튼을 보여 줍니다.

키를 바꾸려면 [설정](/settings#quick-save)에서 **키보드 단축키**를 엽니다.

- **Chrome과 Edge**는 키를 브라우저가 직접 관리합니다. **단축키 변경**을 누르면 모든 확장 프로그램이 나열된 `chrome://extensions/shortcuts` 또는 `edge://extensions/shortcuts`가 열리며, 그곳에서 Bookmark Scout를 찾으세요.
- **Firefox**에서는 Bookmark Scout가 키를 지정할 수 있습니다. 단축키 칸을 클릭하고 새 키를 누르세요. `Command`, `Control`, `Option` 중 하나(Windows와 Linux에서는 `Ctrl`이나 `Alt`)를 누른 채로, 원하면 `Shift`를 더하고, 문자, 숫자, 기능 키, 화살표 키 중 하나를 누릅니다. 기능 키는 단독으로도 쓸 수 있습니다. `Esc`는 취소하고, `Tab`은 기록하지 않고 다음으로 넘어가며, 칸 옆의 초기화 버튼은 기본값을 복원합니다. Firefox가 사용할 수 없는 조합이면 칸 아래에 이유가 표시됩니다. **단축키 변경**을 누르면 대신 Firefox의 **확장 기능 단축키 관리** 페이지가 열립니다.

다른 확장 프로그램이 이미 그 키를 사용하고 있으면 브라우저가 단축키를 지정하지 않은 채로 두며, 설정에 **설정 안 됨**이 표시됩니다. 그러면 팝업과 사이드 패널의 단축키 안내 위에 **빠른 저장 단축키가 설정되지 않음**이 **설정하기**와 함께 표시되며, **설정하기**를 누르면 위에서 설명한 단축키 설정 위치로 이동합니다. 단축키를 원하지 않으면 **닫기** 버튼으로 이 줄을 닫으세요. 그 기기에서는 다시 표시되지 않습니다.

### 빠른 저장에 북마크 키 사용 [#ctrl-d]

<Shortcut id="browser.bookmark_page" />는 브라우저 자체의 북마크 대화상자를 열며, 어떤 브라우저도 확장 프로그램이 이 키를 기본 키로 가져가도록 허용하지 않으므로 빠른 저장은 <Shortcut id="commands.quick-save" />로 시작합니다.

- **Chrome과 Edge**에서는 직접 빠른 저장에 지정할 수 있습니다. 설정의 **키보드 단축키** 아래에 있는 **빠른 저장에 <Shortcut id="browser.bookmark_page" /> 사용**을 누르면 브라우저의 단축키 페이지가 열립니다. Bookmark Scout를 찾아 **현재 페이지 빠른 저장** 옆의 연필을 클릭하고 북마크 키를 누르세요. 이후 그 키를 누르면 북마크(또는 즐겨찾기) 대화상자 대신 빠른 저장으로 저장합니다. 대화상자를 되돌리려면 같은 페이지에서 그 단축키를 지우세요. 지정하기 전까지는 팝업과 사이드 패널에 지금 빠른 저장에 지정된 키가 **빠른 저장: 아무 페이지에서나 <Shortcut id="commands.quick-save" /> 누르기**처럼 표시되고, 함께 표시되는 **대신 <Shortcut id="browser.bookmark_page" /> 사용**을 누르면 설정에서 이 단계가 열립니다. **닫기**를 누르면 그 기기에서 이 줄이 숨겨집니다. Firefox에서는 이 줄에 키만 표시됩니다.
- **Firefox**는 확장 프로그램이 지정하더라도 <Shortcut id="browser.bookmark_page" />(이 페이지 북마크)와 <Shortcut id="browser.bookmark_all_tabs" />(모든 탭 북마크)를 항상 직접 처리하므로, 단축키 칸에서 두 조합을 모두 받지 않습니다.

## 마우스 오른쪽 버튼 메뉴로 링크 저장 [#save-a-link-with-the-right-click-menu]

먼저 [설정](/settings#data)에서 **마우스 오른쪽 버튼 메뉴**를 켭니다. 기본적으로 꺼져 있습니다. 그런 다음 페이지의 링크를 마우스 오른쪽 버튼으로 클릭하고 <strong>북마크 저장 위치...</strong>를 선택한 뒤, 최근 폴더 중 하나나 북마크바를 고릅니다. 설정의 **북마크 이름 출처**에서 북마크 이름을 링크 텍스트, 페이지 제목, 링크 URL 중 무엇으로 할지 정합니다. 메뉴는 **마우스 오른쪽 버튼 메뉴**로 끌 수 있습니다(둘 다 **데이터** 탭에 있습니다).

## 폴더 만들기 [#create-folders]

팝업이나 사이드 패널에서 폴더에 마우스를 올리고 **폴더 추가**를 클릭한 뒤 이름을 입력합니다. 새 폴더에는 설정의 **기본 폴더 이름**이 처음 이름으로 붙습니다.

## 북마크와 폴더 옮기기 [#move-bookmarks-and-folders]

- **드래그 앤 드롭**: 팝업이나 사이드 패널에서 사용합니다. 다른 폴더에 있는 항목 옆에 놓으면 그 폴더로 옮겨집니다. 폴더 안에서 순서를 바꾸는 것은 **브라우저 순서**(기본값)와 **폴더 우선** 정렬일 때 가능합니다. 다른 정렬에서는 놓으면 항목이 다른 폴더로 옮겨지며, 끄는 동안 이를 알려 주는 안내가 표시됩니다. 폴더를 자기 자신이나 하위 폴더로 옮길 수는 없습니다. 사이드 패널에서는 웹 페이지의 링크를 폴더에 놓으면 그곳에 북마크로 저장됩니다. 설정의 **트리에서 끌어서 놓기**로 둘 다 끌 수 있습니다.
- **드래그 앤 드롭**: 관리자에서 Chrome처럼 사용합니다. 행 하나나 선택한 여러 행을 폴더 행이나 폴더 트리의 폴더 위로 끌어다 놓으면 그곳으로 옮겨집니다. 트리에서 폴더의 위쪽과 아래쪽 가장자리에 놓으면 대신 그 폴더 옆에 놓입니다. 끄는 동안 트리의 닫힌 폴더 위에 마우스를 올리면 폴더가 열립니다. 표가 브라우저 순서로 표시되는 동안에는(아래 참고) 행 사이에 놓아 순서도 바꿀 수 있습니다. 한 번 놓을 때마다 <Shortcut id="manager.undo" /> 한 단계가 됩니다.
- **다른 페이지와 앱의 링크**: 링크나 URL이 들어 있는 텍스트를 관리자의 표나 트리의 폴더에 놓으면 그곳에 북마크됩니다. 행을 다른 앱이나 페이지로 끌어내면 그 URL이 함께 전달됩니다.
- **여러 항목 한 번에**: 관리자에서 표의 행을 선택한 뒤 **폴더로 이동**을 사용하고 대상 폴더를 고릅니다. 항목은 그 폴더의 맨 끝에 추가됩니다.
- **순서 변경**: 관리자의 표는 기본적으로 브라우저 순서로 표시됩니다. 열 기준으로 정렬했거나 다른 **정렬 순서**를 골랐다면 **브라우저 순서** 옆에 그 순서가 표시되며, **브라우저 순서**를 클릭하면 원래대로 돌아갑니다. 그런 다음 행을 끌거나 행의 **위로 이동**, **아래로 이동**, **맨 위로 이동**, **맨 아래로 이동** 버튼을 사용합니다. 표에 폴더 하나만 표시되어야 하므로 필터를 지우거나 **현재 폴더만**을 선택하세요.

순서를 바꾸면 브라우저에 저장된 순서가 바뀝니다. 팝업은 **브라우저 순서**(기본값)와 **폴더 우선** 정렬일 때 그 순서를 표시합니다. 날짜순과 알파벳순 정렬은 목록을 계속 다시 정렬합니다.

관리자나 브라우저 자체의 북마크 화면 등 다른 곳에서 북마크가 바뀌면 팝업과 사이드 패널이 자동으로 새로 고쳐집니다.

## 트리 정렬 [#sort-the-tree]

설정의 **정렬 순서**에서 **브라우저 순서**(기본값, 북마크바에 보이는 순서), **추가일 순**(최신 항목 먼저), **알파벳 순**(자연 정렬이므로 `2`가 `10`보다 앞에 옴), **폴더 우선** 중 하나를 고릅니다. 정렬은 Bookmark Scout에서 트리를 표시하는 방식만 바꾸며, 브라우저에 저장된 순서는 바꾸지 않습니다. 관리자의 표도 열 기준으로 정렬하기 전까지는 같은 순서를 사용합니다. **폴더별 그룹화**는 팝업과 사이드 패널의 각 단계에서 하위 폴더를 북마크보다 먼저 표시합니다.

## 북마크 편집 [#edit-a-bookmark]

관리자에서 행의 메뉴를 열고 **편집**을 선택하면 북마크의 이름과 URL, 또는 폴더의 이름을 바꿀 수 있습니다. **세부정보 보기**는 전체 경로, 날짜, ID를 보여 주며, 여기에서 **태그**와 **요약**을 추가합니다.

태그와 요약은 이 브라우저의 로컬 확장 프로그램 저장소에만 저장됩니다. 동기화되지는 않지만 [검색](/guides/search#search-words-and-operators)으로 이를 기준으로 북마크를 찾을 수 있습니다. JSON 북마크 내보내기에는 포함되며, AI 컨텍스트 내보내기에도 포함할 수 있습니다. [가져오기와 내보내기](/guides/import-export)와 [AI 도구 설정](/guides/ai-tools)을 참고하세요.

## 삭제와 실행 취소 [#delete-and-undo]

팝업, 사이드 패널, 관리자 행의 메뉴에서 북마크나 폴더를 삭제하거나, 관리자에서 여러 행을 선택해 한꺼번에 삭제할 수 있습니다.

- **삭제 전 확인**은 기본적으로 켜져 있으며, 삭제될 항목의 이름을 알려 주는 대화 상자를 표시합니다. 바로 삭제하려면 설정의 **동작** 탭에서 끄세요.
- 모든 삭제 후에는 10초 동안 **실행 취소**가 표시됩니다. 실행 취소하면 항목과 그 안의 모든 항목, 저장된 태그와 요약이 복원됩니다. 복원된 항목은 새로 만들어지므로 추가한 날짜가 새로 지정됩니다.
- 북마크바 같은 고정 폴더는 편집하거나 삭제할 수 없습니다.

## 관리자에서 선택, 실행 취소, 다시 실행 [#select-undo-and-redo-in-the-manager]

관리자의 표는 Chrome의 북마크 관리자처럼 동작합니다.

- 행을 클릭하면 선택되고, `Cmd`+클릭(Windows와 Linux에서는 `Ctrl`+클릭)하면 하나씩 추가하거나 제외하며, `Shift`+클릭하면 범위를 선택합니다. 체크박스도 사용할 수 있습니다. <Shortcut id="manager.select_all" />는 필터에 표시되는 모든 행을 모든 페이지에 걸쳐 선택하고, <Shortcut id="manager.clear_selection" />는 선택을 해제합니다.
- 폴더를 더블클릭하면 폴더가 열리고, 북마크를 더블클릭하면 탭에서 열립니다. 북마크를 가운데 클릭하면 백그라운드 탭에서 열립니다.
- <Shortcut id="manager.undo" />는 관리자에서 한 변경을 최근 것부터 하나씩 실행 취소합니다: 편집, 이동, 순서 변경, 삭제. 팝업과 사이드 패널에서 저장한 페이지, 만든 폴더, 끌어서 옮긴 항목, 그리고 AI에게 묻기나 로컬 AI 에이전트에서 승인한 변경도 실행 취소합니다. **도구** 사이드바의 도구(**중복 정리**, **URL 정리**, **깨진 링크 확인**의 복구, **메타데이터 가져오기**의 제목, **AI 폴더 재구성**)가 바꾼 내용도 한 단계로 실행 취소하며, 이는 도구 메시지의 **실행 취소**가 되돌리는 것과 같은 단계입니다. <Shortcut id="manager.redo" />는 다시 실행합니다. 선택한 항목을 한꺼번에 옮기는 것처럼 함께 바뀐 여러 항목은 한 단계입니다. 아주 큰 삭제는 압축해서 보관하며, 압축해도 너무 크면 이전 변경은 유지한 채 그 삭제만 기록에서 빠집니다. 이때는 알림에서 그 삭제의 **실행 취소**로만 되돌릴 수 있다고 알려 줍니다. 팝업과 사이드 패널에서의 삭제, 빠른 저장, 오른쪽 클릭 메뉴로 저장, 가져오기도 각각 한 단계이며, 출처와 함께 기록에 표시됩니다.
- 그 사이에 다른 방법(브라우저 자체의 북마크 화면, 다른 창, 동기화)으로 바뀐 항목은 실행 취소하지 않고 그 사실을 알려 줍니다.
- 기록은 모든 관리자 탭이 공유하며, 페이지를 다시 로드해도 유지되고, 브라우저를 닫으면 끝납니다. 최근 100개의 변경을 보관합니다.

왼쪽의 폴더 트리도 Chrome처럼 동작합니다. 화살표 키로 트리를 이동하고 폴더를 열고 닫으며, `Enter`를 누르면 폴더를 표에 표시합니다. Chrome이 북마크 일부는 Google 계정에, 나머지는 이 기기에만 보관하는 경우 트리에서 **계정에 저장됨**과 **이 기기에만 저장됨** 아래에 나누어 표시하며, 두 번째 섹션은 처음에 닫혀 있습니다.

전체 키 목록은 [키보드 단축키](/guides/keyboard-shortcuts#bookmarks-manager)에 있습니다.

## 무엇이 바뀌었는지 보기 [#history]

관리자 머리글의 **북마크 기록** 버튼을 누르면 이 기기에서 Bookmark Scout가 북마크에 한 모든 변경(편집, 이동, 삭제, 가져오기, 정리, 그리고 이를 실행 취소한 것)이 최신순으로 날짜별로 표시됩니다. 각 변경에는 출처(관리자, 도구, AI에게 묻기, 로컬 에이전트), 영향을 받은 항목 수, 시각이 나옵니다. 일부만 실행되었거나 중단되었거나 의도대로 다시 읽히지 않은 변경은 표시되어 **확인 필요**에서 찾을 수 있습니다.

변경을 열면 영향을 받은 각 항목이 나옵니다. 삭제된 항목은 원래 있던 폴더와 위치, 편집은 이전과 새 제목 또는 정확한 주소, 이동은 원래 위치와 옮긴 위치입니다. Bookmark Scout는 변경할 때마다 북마크를 다시 읽고 변경한 그대로인지 알려 줍니다. 브라우저 세션에 변경이 남아 있는 동안에는 **실행 취소**도 할 수 있으며, 브라우저를 다시 시작하면 변경은 목록에 남지만 실행 취소는 할 수 없습니다. 변경으로 삭제한 항목은 이 기기에 사본으로 보관되므로, 원래 폴더가 아직 있으면 **복원**으로 안의 내용과 태그, 요약까지 원래 자리로 되돌릴 수 있습니다. 복원은 그 자체로 하나의 변경으로 목록에 남고, 한 변경은 한 번만 실행 취소하거나 복원할 수 있습니다. 도구 결과에서는 **기록에서 보기**로 해당 변경을 열 수 있습니다.

Bookmark Scout 밖에서 한 변경(브라우저 북마크 관리자, 다른 확장 프로그램, 브라우저 동기화)도 **출처 알 수 없음**으로 표시됩니다. 브라우저는 누가 바꿨는지 알려 주지 않으므로 Bookmark Scout는 추측하지 않습니다. 동기화처럼 한꺼번에 일어난 변경은 하나의 항목입니다. Bookmark Scout가 지켜보지 않던 동안(확장 프로그램이 꺼져 있거나 설정에서 **다른 곳에서 한 변경도 기록**이 꺼진 경우)의 변경은 다음에 두 시점 사이의 차이로 **공백 이후 감지됨** 항목 하나로 표시되며, 각 변경이 언제 어떤 순서로 일어났는지는 알 수 없습니다. 둘 다 기록에서 실행 취소할 수 없습니다.

기록은 이 기기에만 남고, 동기화되지 않으며, 설정 백업에도 들어가지 않습니다. 이 버전부터 기록되며 확장 프로그램이 꺼져 있던 동안의 변경은 알 수 없습니다. JSON 파일로 내보내거나(북마크 제목과 주소가 들어 있음) 지울 수 있으며, 아직 확인이 필요한 변경은 남습니다.

## 관리자의 마우스 오른쪽 버튼 메뉴 [#right-click-menus-in-the-manager]

행이나 폴더 트리의 폴더를 마우스 오른쪽 버튼으로 클릭하면 Chrome 북마크 관리자와 같은 명령이 표시됩니다. 선택된 행을 마우스 오른쪽 버튼으로 클릭하면 선택 전체에 적용되고, 다른 행을 클릭하면 먼저 그 행을 선택합니다. 키보드에서는 메뉴 키나 <Shortcut id="browser.context_menu" />으로 엽니다. 행의 ⋯ 버튼을 누르면 그 행에 대해 같은 메뉴가 열립니다.

- **미리 보기**(북마크), **편집**(북마크) 또는 **이름 바꾸기**(폴더), **폴더에서 보기**(검색 결과), **세부정보 보기**.
- **잘라내기**, **복사**, **붙여넣기**. 복사하면 북마크의 URL이 한 줄에 하나씩(서식 있는 텍스트를 받는 앱에는 링크로도) 클립보드에 들어가므로 다른 앱에도 붙여 넣을 수 있습니다. 행의 메뉴에서 붙여넣기를 하면 표시된 폴더에서 그 행 뒤에 붙여 넣고, 트리에 있는 폴더의 메뉴에서는 그 폴더 안에 붙여 넣습니다. 복사한 항목은 붙여 넣는 시점의 상태로 사본이 만들어지며, 복사한 폴더 안의 모든 항목도 포함됩니다. 잘라낸 항목은 붙여 넣을 때 옮겨지고 그전까지는 제자리에 있습니다. 잘라내거나 복사한 항목은 브라우저를 닫기 전까지 어느 관리자 탭에서든, 다시 로드한 뒤에도 붙여 넣을 수 있습니다. 그 사이 삭제된 항목은 건너뛰며, 옮기지 못한 잘라낸 항목(자기 자신 안에 붙여 넣은 폴더)은 잘라낸 상태로 남습니다. 새 북마크 추가는 `example.com/path`처럼 스킴 없이 입력한 주소를 `https://`로 채워 줍니다. <Shortcut id="manager.copy" />, <Shortcut id="manager.cut" />, <Shortcut id="manager.paste" />는 선택한 항목에 같은 작업을 하며, 붙여넣기는 다른 앱에서 복사한 URL을 북마크로 만들기도 합니다.
- **새 탭에서 열기**, **새 창에서 열기**, **시크릿 창에서 열기**(Edge에서는 InPrivate 창, Firefox에서는 사생활 보호 창이며, Firefox에서는 확장 프로그램이 사생활 보호 창에서 허용되어 있어야 함). 여러 항목이나 폴더에서는 **모두 열기(12)** 형태로 표시되며, 선택한 북마크와 선택한 폴더 바로 안에 있는 북마크를 열고 하위 폴더 안의 북마크는 열지 않습니다. 탭이 15개를 넘으면 먼저 묻습니다.
- **이 폴더 링크 복사**와 **북마크 ID 복사**, 그리고 **삭제**.

표의 빈 공간을 마우스 오른쪽 버튼으로 클릭하거나 머리글의 **정리**(⋮)를 열면, 표시된 폴더의 끝에 **새 북마크 추가**나 **새 폴더 추가**를 하거나 **붙여넣기**를 할 수 있습니다. **정리**에는 브라우저 자체에서 폴더의 순서를 바꾸는 **이름순 정렬**도 있습니다: 폴더를 먼저, 그다음 이름순으로 자연 정렬합니다(`2`가 `10`보다 앞). 관리자의 다른 모든 변경처럼 <Shortcut id="manager.undo" />로 실행 취소할 수 있습니다.
