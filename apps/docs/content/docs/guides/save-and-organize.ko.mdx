## 보고 있는 페이지 저장 [#save-the-page-you-are-on]

<Steps>
<Step>
보관하려는 페이지에서 팝업이나 사이드 패널을 엽니다.
</Step>
<Step>
원하는 폴더에 마우스를 올리고 **현재 페이지 추가**를 클릭합니다. 키보드를 사용할 때는 폴더로 이동한 뒤 `Enter`를 누릅니다.
</Step>
</Steps>

**최근** 패널에는 최근 사용한 폴더가 표시되며, 폴더를 클릭하면 현재 페이지가 그곳에 저장됩니다. [설정](/settings)의 **최근 폴더**와 **최근 폴더 최대 수**로 패널을 끄거나 표시할 폴더 수를 바꿀 수 있습니다.

이미 폴더에 있는 페이지는 다시 저장되지 않으며, 이미 있다는 메시지가 표시됩니다.

툴바 팝업은 팝업을 연 페이지를 묻지 않고 읽습니다. 사이드 패널은 탭을 바꾸는 동안에도 열려 있으므로, 사이드 패널에서 처음 저장할 때 Bookmark Scout가 이유를 설명한 뒤 탭 접근 권한을 요청합니다. 거부하면 아무것도 저장되지 않습니다.

## 마우스 오른쪽 버튼 메뉴로 링크 저장 [#save-a-link-with-the-right-click-menu]

먼저 [설정](/settings#data)에서 **컨텍스트 메뉴**를 켭니다. 기본적으로 꺼져 있습니다. 그런 다음 페이지의 링크를 마우스 오른쪽 버튼으로 클릭하고 <strong>북마크 저장 위치...</strong>를 선택한 뒤, 최근 폴더 중 하나나 북마크바를 고릅니다. 설정의 **북마크 이름 출처**에서 북마크 이름을 링크 텍스트, 페이지 제목, 링크 URL 중 무엇으로 할지 정합니다. 메뉴는 **컨텍스트 메뉴**로 끌 수 있습니다(둘 다 **데이터** 탭에 있습니다).

## 폴더 만들기 [#create-folders]

팝업이나 사이드 패널에서 폴더에 마우스를 올리고 **폴더 추가**를 클릭한 뒤 이름을 입력합니다. 새 폴더에는 설정의 **기본 폴더 이름**이 처음 이름으로 붙습니다.

## 북마크와 폴더 옮기기 [#move-bookmarks-and-folders]

- **드래그 앤 드롭**: 팝업이나 사이드 패널에서 사용합니다. 다른 폴더에 있는 항목 옆에 놓으면 그 폴더로 옮겨집니다. 폴더를 자기 자신이나 하위 폴더로 옮길 수는 없습니다.
- **여러 항목 한 번에**: 관리자에서 표의 행을 선택한 뒤 **폴더로 이동**을 사용하고 대상 폴더를 고릅니다. 항목은 그 폴더의 맨 끝에 추가됩니다.
- **순서 변경**: 관리자에서 **브라우저 순서**를 켜고 열 정렬을 모두 해제한 뒤, 행의 **위로 이동**, **아래로 이동**, **맨 위로 이동**, **맨 아래로 이동** 버튼을 사용합니다. 표에 폴더 하나만 표시되어야 하므로 필터를 지우거나 **현재 폴더만**을 선택하세요.

순서를 바꾸면 브라우저에 저장된 순서가 바뀝니다. 팝업은 **폴더 우선** 정렬일 때만 그 순서를 표시합니다. 날짜순과 알파벳순 정렬은 목록을 계속 다시 정렬하며, 확인 메시지에서도 이를 알려 줍니다.

관리자나 브라우저 자체의 북마크 화면 등 다른 곳에서 북마크가 바뀌면 팝업과 사이드 패널이 자동으로 새로 고쳐집니다.

## 트리 정렬 [#sort-the-tree]

설정의 **정렬 순서**에서 **추가일 순**, **알파벳 순**(자연 정렬이므로 `2`가 `10`보다 앞에 옴), **폴더 우선** 중 하나를 고릅니다. 정렬은 Bookmark Scout에서 트리를 표시하는 방식만 바꾸며, 브라우저에 저장된 순서는 바꾸지 않습니다. **폴더별 그룹화**는 팝업과 사이드 패널의 각 단계에서 하위 폴더를 북마크보다 먼저 표시합니다.

## 북마크 편집 [#edit-a-bookmark]

관리자에서 행의 메뉴를 열고 **편집**을 선택하면 북마크의 이름과 URL, 또는 폴더의 이름을 바꿀 수 있습니다. **세부정보 보기**는 전체 경로, 날짜, ID를 보여 주며, 여기에서 **태그**와 **요약**을 추가합니다.

태그와 요약은 이 브라우저의 로컬 확장 프로그램 저장소에만 저장됩니다. 동기화되지 않고, 검색할 수 없으며, 북마크 내보내기에 포함되지 않습니다. AI 컨텍스트 내보내기에는 포함할 수 있습니다. [AI 도구 설정](/guides/ai-tools)을 참고하세요.

## 삭제와 실행 취소 [#delete-and-undo]

팝업, 사이드 패널, 관리자 행의 메뉴에서 북마크나 폴더를 삭제하거나, 관리자에서 여러 행을 선택해 한꺼번에 삭제할 수 있습니다.

- **삭제 전 확인**은 기본적으로 켜져 있으며, 삭제될 항목의 이름을 알려 주는 대화 상자를 표시합니다. 바로 삭제하려면 설정의 **동작** 탭에서 끄세요.
- 모든 삭제 후에는 10초 동안 **실행 취소**가 표시됩니다. 실행 취소하면 항목과 그 안의 모든 항목, 저장된 태그와 요약이 복원됩니다. 복원된 항목은 새로 만들어지므로 추가한 날짜가 새로 지정됩니다.
- 북마크바 같은 고정 폴더는 편집하거나 삭제할 수 없습니다.
