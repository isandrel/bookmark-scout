---
title: キーボードショートカット
description: マウスを使わずに、検索、フォルダ間の移動、現在のページの保存、マネージャーの表の操作ができます。
---

ポップアップとサイドパネルのショートカットは `Ctrl` や `Cmd` を使わないため、`Ctrl/Cmd+L`、`T`、`W`、`N`、`R`、`D` などのブラウザのショートカットはそのまま使えます。ブックマークマネージャーはブラウザ自体のマネージャーを置き換えるため、そのマネージャーの `Ctrl` ショートカット（Mac では `Cmd`）も使います: すべて選択、コピー、切り取り、貼り付け、元に戻す、やり直し、新しいタブで開く。テキスト入力欄に入力している間（検索ボックスでの `Esc` は例外）、IME で文字を変換している間、ダイアログやメニューが開いている間は、ショートカットは働きません。

## すべてのページ [#on-any-page]

これらは Bookmark Scout の画面を開いていなくても使えます。ブラウザが管理しているため、ブラウザのショートカット設定で変更や削除ができます。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)をご覧ください。Chrome と Edge では、ブラウザのブックマークのキー `Ctrl+D`（Mac では `⌘D`）をクイック保存に割り当てることもできます。[Ctrl+D でクイック保存する](/guides/save-and-organize#ctrl-d)をご覧ください。

| キー | 操作 |
| --- | --- |
| `Alt+Shift+S`（Mac では `⌥⇧S`） | 現在のページを **クイック保存のフォルダー** で決まるフォルダにクイック保存 |
| `Alt+Shift+D`（Mac では `⌥⇧D`） | 現在のページを AI が提案するフォルダにクイック保存 |

その後に表示される通知では、`Tab` で **元に戻す** とほかのフォルダに移動でき、`Esc` で通知を閉じます。

## ポップアップとサイドパネル [#popup-and-side-panel]

検索ボックスにポインターを合わせると、ショートカットの一覧が表示されます。

| キー | 操作 |
| --- | --- |
| `/` | 検索ボックスにフォーカス |
| 検索ボックスで `Esc` | 検索をクリア。もう一度押すと検索ボックスから離れる |
| 検索ボックスで `↓` | 最初のフォルダへ移動 |
| 空の検索ボックスで `Alt+↓` | 最近の検索を表示。`↓` / `↑` で選び、`Enter` で検索し、`Tab` で **クリア** に移動 |
| `↓` / `↑`、`Home` / `End` | 表示中のフォルダとブックマークの間を移動（最初の行で `↑` を押すと検索に戻る） |
| `→` / `←` | フォルダを開く、閉じる。開いているフォルダで `→` を押すと最初の項目へ、`←` を押すと親フォルダへ移動 |
| フォルダで `Enter` | 現在のページをそのフォルダに保存（すでに保存されているページは重複しない） |
| ブックマークで `Enter` | 新しいタブで開く |
| フォルダで `Space` | 開く、閉じる |

## ブックマークマネージャー [#bookmarks-manager]

マネージャーでこの一覧を表示するには、`?` を押すか、ヘッダーのキーボードボタンをクリックします。キーは Chrome のブックマーク マネージャーに準じています。Mac で異なる場合は、Mac のキーを 2 番目に示しています。

| キー | 操作 |
| --- | --- |
| `/` | タイトルフィルターにフォーカス |
| `Backspace` または `Alt+↑` | 親フォルダに移動 |
| `↓` / `↑`、`Home` / `End` | 行の間を移動して行を選択。`Shift` を押しながらで選択範囲を広げ、`Ctrl`（`Cmd`）を押しながらで選択せずに移動 |
| `j` / `k` | 次または前の行に移動 |
| `Space` | フォーカスのある行を選択または選択解除 |
| `Ctrl+A` / `Cmd+A` | フィルターに一致するすべての行を、すべてのページにわたって選択 |
| `Esc` | 選択を解除、またはダイアログやメニューを閉じる |
| `Enter` / `Cmd+O` | 選択したフォルダを開く、または選択したブックマークをタブで開く |
| `Ctrl+Enter` / `Cmd+Enter` | 選択した項目を新しいバックグラウンドタブで開く |
| `Shift+Enter` | 選択した項目を新しいウィンドウで開く |
| `F2` / `Enter` | 選択したブックマークを編集、またはフォルダの名前を変更 |
| `Delete` / `Delete` または `Cmd+Backspace` | 選択した項目を削除 |
| `Ctrl+Z` / `Cmd+Z` | 直前の変更を元に戻す |
| `Ctrl+Y` または `Ctrl+Shift+Z` / `Cmd+Shift+Z` | やり直し |
| `Ctrl+C` / `Cmd+C` | 選択した項目をコピー。URL がクリップボードに入る |
| `Ctrl+X` / `Cmd+X` | 選択した項目を切り取り、貼り付けで移動できるようにする |
| `Ctrl+V` / `Cmd+V` | 選択した項目の後ろ、またはフォルダの末尾に貼り付け。ほかのアプリでコピーした URL はブックマークになる |
| `s` | 保存した検索を開く |
| `?` | キーボードショートカットを表示 |
| メニューキーまたは `Shift+F10` | フォーカスのある行やフォルダの右クリックメニューを開く |

左側のフォルダツリー（これも `Tab` で 1 回の移動先）では、次のキーが使えます。

| キー | 操作 |
| --- | --- |
| `↓` / `↑`、`Home` / `End` | 表示されているフォルダの間を移動 |
| `→` / `←` | フォルダを開く、閉じる。開いているフォルダで `→` を押すと最初のサブフォルダへ、閉じているフォルダで `←` を押すと親フォルダへ移動 |
| `Enter` または `Space` / `Cmd+O` または `Space` | フォルダを表に表示 |
| `F2` / `Enter` | フォルダの名前を変更 |
| `Delete` / `Delete` または `Cmd+Backspace` | フォルダを削除 |
| `Ctrl+C`、`Ctrl+X` / `Cmd+C`、`Cmd+X` | フォルダをコピーまたは切り取り |
| `Ctrl+V` / `Cmd+V` | フォルダの中に貼り付け |

表は `Tab` で 1 回の移動先で、矢印キーで行の間を移動します。15 個を超えるタブを一度に開く場合は、先に確認します。フォルダを開くと、その直下にあるブックマークが開きます。表では、列見出しの端にフォーカスを合わせて `←` または `→` を押すと、その列の幅を変更できます。

キーボードショートカットは Chromium と Edge の自動テストで確認されていますが、Firefox の自動テストでは確認されていません。
