---
title: キーボードショートカット
description: マウスを使わずに、検索、フォルダ間の移動、現在のページの保存、マネージャーの表の操作ができます。
---

Bookmark Scout のショートカットは `Ctrl` や `Cmd` を使わないため、`Ctrl/Cmd+L`、`T`、`W`、`N`、`R`、`D` などのブラウザのショートカットはそのまま使えます。テキスト入力欄に入力している間（検索ボックスでの `Esc` は例外）、IME で文字を変換している間、ダイアログやメニューが開いている間は、ショートカットは働きません。

## ポップアップとサイドパネル [#popup-and-side-panel]

検索ボックスにポインターを合わせると、ショートカットの一覧が表示されます。

| キー | 操作 |
| --- | --- |
| `/` | 検索ボックスにフォーカス |
| 検索ボックスで `Esc` | 検索をクリア。もう一度押すと検索ボックスから離れる |
| 検索ボックスで `↓` | 最初のフォルダへ移動 |
| 空の検索ボックスで `Alt+↓` | 最近の検索を表示。`↓` / `↑` で選び、`Enter` で検索し、`Tab` で **クリア** に移動 |
| `↓` / `↑`、`Home` / `End` | 表示中のフォルダとブックマークの間を移動（最初の行で `↑` を押すと検索に戻る） |
| `→` / `←` | フォルダを開く、閉じる。開いているフォルダで `→` を押すと最初の項目へ、`←` を押すと親フォルダへ移動 |
| フォルダで `Enter` | 現在のページをそのフォルダに保存（すでに保存されているページは重複しない） |
| ブックマークで `Enter` | 新しいタブで開く |
| フォルダで `Space` | 開く、閉じる |

## ブックマークマネージャー [#bookmarks-manager]

マネージャーでこの一覧を表示するには、`?` を押すか、ヘッダーのキーボードボタンをクリックします。

| キー | 操作 |
| --- | --- |
| `/` | タイトルフィルターにフォーカス |
| `Backspace` または `Alt+↑` | 親フォルダに移動 |
| `j` / `k` | 表の次または前の行に移動（フォルダの行、またはブックマークの行の操作メニュー） |
| フォルダの行で `Enter` | フォルダを開く |
| `s` | 保存した検索を開く |
| `?` | キーボードショートカットを表示 |
| `Esc` | ダイアログやメニューを閉じる |

表では、列見出しの端にフォーカスを合わせて `←` または `→` を押すと、その列の幅を変更できます。

キーボードショートカットは Chromium と Edge の自動テストで確認されていますが、Firefox の自動テストでは確認されていません。
