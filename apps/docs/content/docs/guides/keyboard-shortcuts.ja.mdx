---
title: キーボードショートカット
description: マウスを使わずに、検索、フォルダ間の移動、現在のページの保存、マネージャーの表の操作ができます。
---

ポップアップとサイドパネルのショートカットは `Ctrl` や `Cmd` を使わないため、新しいタブやアドレスバーを開くなど、これらのキーを使うブラウザ自体のショートカットはそのまま使えます。ブックマークマネージャーはブラウザ自体のマネージャーを置き換えるため、そのマネージャーの `Cmd` ショートカット（Windows と Linux では `Ctrl`）も使います: すべて選択、コピー、切り取り、貼り付け、元に戻す、やり直し、新しいタブで開く。テキスト入力欄に入力している間（検索ボックスでの `Esc` は例外）、IME で文字を変換している間、ダイアログやメニューが開いている間は、ショートカットは働きません。

## すべてのページ [#on-any-page]

これらは Bookmark Scout の画面を開いていなくても使えます。ブラウザが管理しているため、ブラウザのショートカット設定で変更や削除ができます。[キーボードショートカットで保存する](/guides/save-and-organize#quick-save)をご覧ください。Chrome と Edge では、ブラウザのブックマークのキー <Shortcut id="browser.bookmark_page" /> をクイック保存に割り当てることもできます。[ブックマークのキーでクイック保存する](/guides/save-and-organize#ctrl-d)をご覧ください。

| キー | 操作 |
| --- | --- |
| <Shortcut id="commands.quick-save" /> | 現在のページを **クイック保存のフォルダ** で決まるフォルダにクイック保存 |
| <Shortcut id="commands.ai-quick-save" /> | 現在のページを AI が提案するフォルダにクイック保存 |

その後に表示される通知では、`Tab` で **元に戻す** とほかのフォルダに移動でき、`Esc` で通知を閉じます。

## ポップアップとサイドパネル [#popup-and-side-panel]

検索ボックスにポインターを合わせると、ショートカットの一覧が表示されます。

| キー | 操作 |
| --- | --- |
| <Shortcut id="popup.focus_search" /> | 検索ボックスにフォーカス |
| 検索ボックスで `Esc` | 検索をクリア。もう一度押すと検索ボックスから離れる |
| 検索ボックスで `↓` | 最初のフォルダへ移動 |
| 検索ボックスで `Enter` | 現在のページを **フォルダに保存** の最初のフォルダ（強調表示）に保存。一致するフォルダがないときは、検索を最近の検索に残す |
| 空の検索ボックスで <Shortcut id="popup.recent_searches" /> | 最近の検索を表示。`↓` / `↑` で選び、`Enter` で検索し、`Tab` で **クリア** に移動 |
| `↓` / `↑`、`Home` / `End` | 表示中のフォルダとブックマークの間を移動（最初の行で `↑` を押すと検索に戻る） |
| `→` / `←` | フォルダを開く、閉じる。開いているフォルダで `→` を押すと最初の項目へ、`←` を押すと親フォルダへ移動 |
| フォルダで `Enter` | 現在のページをそのフォルダに保存（すでに保存されているページは重複しない） |
| ブックマークで `Enter` | 新しいタブで開く |
| フォルダで `Space` | 開く、閉じる |

## ブックマークマネージャー [#bookmarks-manager]

マネージャーでこの一覧を表示するには、<Shortcut id="manager.show_help" /> を押すか、ヘッダーのキーボードボタンをクリックします。キーは Chrome のブックマーク マネージャーに準じています。

| キー | 操作 |
| --- | --- |
| <Shortcut id="manager.focus_filter" /> | 検索ボックスにフォーカス |
| <Shortcut id="manager.parent_folder" /> | 親フォルダに移動 |
| `↓` / `↑`、`Home` / `End` | 行の間を移動して行を選択。`Shift` を押しながらで選択範囲を広げ、`Cmd`（Windows と Linux では `Ctrl`）を押しながらで選択せずに移動 |
| <Shortcut id="manager.next_row" />、<Shortcut id="manager.previous_row" /> | 次または前の行に移動 |
| `Space` | フォーカスのある行を選択または選択解除 |
| <Shortcut id="manager.select_all" /> | フィルターに一致するすべての行を、すべてのページにわたって選択 |
| <Shortcut id="manager.clear_selection" /> | 選択を解除、またはダイアログやメニューを閉じる |
| <Shortcut id="manager.open" /> | 選択したフォルダを開く、または選択したブックマークをタブで開く |
| <Shortcut id="manager.open_in_new_tabs" /> | 選択した項目を新しいバックグラウンドタブで開く |
| <Shortcut id="manager.open_in_new_window" /> | 選択した項目を新しいウィンドウで開く |
| <Shortcut id="manager.rename" /> | 選択したブックマークを編集、またはフォルダの名前を変更 |
| <Shortcut id="manager.delete" /> | 選択した項目を削除 |
| <Shortcut id="manager.undo" /> | 直前の変更を元に戻す |
| <Shortcut id="manager.redo" /> | やり直し |
| <Shortcut id="manager.copy" /> | 選択した項目をコピー。URL がクリップボードに入る |
| <Shortcut id="manager.cut" /> | 選択した項目を切り取り、貼り付けで移動できるようにする |
| <Shortcut id="manager.paste" /> | 選択した項目の後ろ、またはフォルダの末尾に貼り付け。ほかのアプリでコピーした URL はブックマークになる |
| <Shortcut id="manager.open_saved_searches" /> | 保存した検索を開く |
| <Shortcut id="manager.show_help" /> | キーボードショートカットを表示 |
| メニューキーまたは <Shortcut id="browser.context_menu" /> | フォーカスのある行やフォルダの右クリックメニューを開く |

左側のフォルダツリー（これも `Tab` で 1 回の移動先）では、次のキーが使えます。

| キー | 操作 |
| --- | --- |
| `↓` / `↑`、`Home` / `End` | 表示されているフォルダの間を移動 |
| `→` / `←` | フォルダを開く、閉じる。開いているフォルダで `→` を押すと最初のサブフォルダへ、閉じているフォルダで `←` を押すと親フォルダへ移動 |
| <Shortcut id="manager.open" />、または `Space` | フォルダを表に表示 |
| <Shortcut id="manager.rename" /> | フォルダの名前を変更 |
| <Shortcut id="manager.delete" /> | フォルダを削除 |
| <Shortcut id="manager.copy" />、<Shortcut id="manager.cut" /> | フォルダをコピーまたは切り取り |
| <Shortcut id="manager.paste" /> | フォルダの中に貼り付け |

表は `Tab` で 1 回の移動先で、矢印キーで行の間を移動します。<SettingDefault path="behavior.links.confirm_open_above" /> 個を超えるタブを一度に開く場合は、先に確認します。フォルダを開くと、その直下にあるブックマークが開きます。表では、列見出しの端にフォーカスを合わせて `←` または `→` を押すと、その列の幅を変更できます。

キーボードショートカットは Chromium と Edge の自動テストで確認されていますが、Firefox の自動テストでは確認されていません。
