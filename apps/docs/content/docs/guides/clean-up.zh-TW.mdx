這兩項工具都位於書籤管理員「**工具**」側欄的「**維護**」下。在 Chrome 中，開啟瀏覽器的書籤頁面；如果側欄已隱藏，請按一下書籤管理員標頭中的「**顯示工具**」。

<Callout title="Firefox">
Firefox 不允許擴充功能取代其書籤頁面，因此在 Firefox 中，請從工具列彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員，然後開啟工具側欄。
</Callout>

在「[設定](/settings#tools-sidebar)」的「**側欄工具**」中選擇側欄顯示哪些工具，以及它們在各區段內的順序；在那裡隱藏的工具仍會繼續自動作業。同一處的「**初始分頁**」用於選擇側欄開啟時顯示的分頁。

## 移除重複書籤 [#remove-duplicate-bookmarks]

<Steps>
<Step>
在「**重複書籤清理工具**」中按一下「**掃描**」。這項工具一律檢查所有書籤。
</Step>
<Step>
確認各個群組。每個群組只顯示一次共同的網址，接著列出每個書籤及其資料夾和新增日期。標示為「**保留**」的書籤依「**保留規則**」選出，你也可以用選項按鈕改選另一個；其餘每個副本都有預設勾選的「**移除**」核取方塊。取消勾選某個副本或某個群組，即可保留它們。
</Step>
<Step>
按一下「**移除 N 個重複項目**」刪除勾選的副本，或按一下「**取消**」不做任何變更。
</Step>
<Step>
改變主意了嗎？請在 10 秒內按一下訊息中的「**復原**」，還原已移除的項目。之後在書籤管理員中按 <Shortcut id="manager.undo" /> 也能還原。
</Step>
</Steps>

<Screenshot name="duplicates" />

哪些書籤算是重複項目，是在「[設定](/settings)」的「**維護**」分頁中設定：

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **比對方式** | 正規化網址 | 依「**網址完全相同**」、「**正規化網址**」、「**標題 + 網址**」或「**僅標題**」比較 |
| **統一 www** | 開啟 | 將 `www.example.com` 和 `example.com` 視為同一個主機 |
| **忽略通訊協定** | 開啟 | 將 `http` 和 `https` 版本視為重複項目 |
| **忽略結尾斜線** | 開啟 | 將結尾有無 `/` 的網址視為重複項目 |
| **保留規則** | 最舊的 | 保留每個群組中「**最舊的**」、「**最新的**」或「**最先找到的**」書籤 |
| **群組數量上限** | <SettingDefault path="maintenance.duplicates.max_groups" /> | 單次掃描傳回的群組數量上限 |

移除任何項目之前，系統會再次檢查每個群組。如果標示為「**保留**」的書籤已被刪除或現在指向其他位置，整個群組都不會變更，訊息也會說明略過了幾個群組。使用「**僅標題**」比對時，如果群組中包含不同的網址，就會顯示警告，因為移除這些副本會刪除不同的網頁。

## 清除追蹤參數 [#strip-tracking-parameters]

<Steps>
<Step>
在「**網址清理工具**」的範圍選單中選擇目前資料夾或所有書籤，然後按一下「**清理**」。
</Step>
<Step>
依清理原因（「**移除參數**」中的項目，例如 `utm_*`、重複參數或片段）分組確認將變更的網址。每個網址預設為「**清理**」；要保留的網址，可個別設定，或用「**將所選設為…**」批次設為「**維持不變**」。
</Step>
<Step>
按一下「**清理 N 個網址**」更新仍為「**清理**」的網址，或關閉對話方塊不做任何變更。
</Step>
</Steps>

如果書籤在預覽後有所變更，就會被略過，並計入訊息中的數量。按一下訊息中的「**復原**」，或在書籤管理員中按 <Shortcut id="manager.undo" />，即可還原舊的網址；之後又有所變更的書籤則會維持原狀。

規則位於設定的「**維護**」分頁中：

- 「**移除參數**」：要清除的參數。預設清單為 <SettingDefault path="maintenance.url_cleaner.remove_params" />。以 `*` 結尾的名稱會符合所有以此開頭的名稱。
- 「**保留參數**」：一律不會移除的參數。預設值：<SettingDefault path="maintenance.url_cleaner.preserve_params" />。
- 「**移除重複的查詢參數**」(預設為開啟) 會移除重複出現的參數。
- 「**排序查詢參數**」(預設為開啟) 會依字母順序排列其餘的參數。
- 「**移除片段**」(預設為關閉) 也會移除 `#section` 這類部分。

## 重新整理網站圖示 [#refresh-site-icons]

在 Bookmark Scout 取得網站的圖示之前，書籤會顯示通用的地球圖示。在 Chrome 和 Edge 中，最快的方法是在「**重新整理網站圖示**」卡片上點選「**顯示瀏覽器圖示**」，或在「[設定](/settings#appearance)」中開啟「**使用瀏覽器的圖示快取**」：這會顯示瀏覽器已為你造訪的網站儲存的圖示，而且瀏覽器只會要求讀取網站圖示的權限。對於瀏覽器沒有圖示的網站，以及在完全不提供圖示快取給擴充功能使用的 Firefox 中，工具側欄「**頁面詳細資料**」下的「**重新整理網站圖示**」會下載各網站本身的圖示。

<Steps>
<Step>
在範圍選單中選擇目前資料夾或所有書籤，然後按一下「**重新整理**」。系統詢問時，請允許存取該範圍內的網站 (範圍超過 20 個網站時會要求存取所有網站)；如果你拒絕，就不會發出任何要求。
</Step>
<Step>
依分頁確認各網站：「**新圖示**」、「**圖示相同**」、「**沒有圖示**」和「**失敗**」，各自顯示數量，也會說明有多少書籤因不是網頁連結而略過。找到的圖示預設為「**儲存圖示**」；可以把其中一項改為「**略過**」，或選取多項後使用「**將所選設為…**」。
</Step>
<Step>
按一下「**儲存**」(例如「**儲存 12 個圖示**」) 保留仍設為「**儲存圖示**」的圖示，或關閉對話方塊不保留任何圖示。
</Step>
</Steps>

針對範圍內的每個網站 (來源)，這項工具會在不附帶 Cookie 的情況下要求一個已加入書籤的網頁、只讀取其 head 部分，並下載該網頁列出的圖示中最接近「**偏好的圖示大小**」的一個，或是網站的 `/favicon.ico`。只會使用書籤本身網域上的圖示檔案，絕不使用第三方圖示服務。超過「**圖示檔案大小上限**」(<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> KB) 或不是圖片的檔案會被略過。

重新整理會在背景執行：關閉管理員後仍會繼續，其卡片和「**背景工作**」會顯示進度，並可「**暫停**」、「**繼續**」或「**取消**」。結果會在「**查看結果**」中等你查看；在你按下「**儲存**」之前不會儲存任何內容。

已儲存的圖示會存放在這個瀏覽器的本機儲存空間中，不會同步，並會顯示在彈出式視窗、側邊面板和書籤管理員中。這些圖示的優先順序高於瀏覽器快取的圖示。卡片會顯示已儲存的圖示數量；「**清除已儲存的圖示**」會將其全部刪除。總大小達到「**圖示儲存空間上限**」(4 MB) 時，會先移除最舊的圖示。如果某個網站在之後重新整理時失敗，會保留先前儲存的圖示。

<Callout title="Firefox">
在 Firefox 中，請從工具列彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員，再執行這項工具。在該處儲存圖示後，彈出式視窗和側邊面板就會顯示這些圖示。
</Callout>

## 用智慧規則加上標籤和移動 [#tag-and-move-with-smart-rules]

智慧規則會用與搜尋框相同的字詞和[運算子](/guides/search#search-words-and-operators)找出書籤，然後為它們加上標籤、移到資料夾，或兩者都做。規則只會在你開啟了下文所述的設定時自行執行；否則每次執行都是一次確認，由你決定要套用哪些變更。

<Steps>
<Step>
在[設定](/settings#maintenance)的「**智慧規則**」中按一下「**新增規則**」；也可以按一下「**從範本開始**」，為 GitHub 網頁、YouTube 影片或教學加上標籤，或移動「**Work / Reading**」資料夾中的書籤。範本預設為關閉。移動書籤的範本還沒有資料夾，因此會在編輯器中開啟：選擇資料夾之前，無法開啟或儲存它。
</Step>
<Step>
為規則設定名稱和搜尋，例如 `domain:github.com`、`folder:稍後閱讀 -tag:已讀` 或 `(domain:github.com OR domain:gitlab.com) -tag:archived`。編輯器會顯示目前符合的書籤數量，或指出搜尋的問題，例如括號未關閉；在搜尋可以讀取之前，規則無法儲存。在「**用網址或標題測試**」中輸入網址或標題，即可查看搜尋是否符合；這會在你的裝置上判斷，不會儲存或傳送任何內容。加上標籤（每個標籤後按 Enter 鍵或輸入逗號）、選擇要移到的資料夾，或兩者都設定，然後儲存。
</Step>
<Step>
在書籤管理員的工具側邊欄中，於「**智慧規則**」卡片選擇範圍，然後按一下「**執行**」：目前顯示的資料夾、所有書籤，或在管理員中有內容時選擇「**搜尋結果**」(搜尋方塊列出的書籤) 或「**所選書籤**」。範圍在按下時決定，範圍外的書籤絕不會被確認或變更。
</Step>
<Step>
依分頁確認書籤：「**變更**」、「**衝突**」(兩條規則會把它移到不同的資料夾)、「**已封鎖**」(它的資料夾已不存在或受管理，或在該資料夾中另一條規則會再次移動它) 和「**已完成**」。變更預設為「**套用**」，衝突預設為「**略過**」；可以逐一或使用「**將所選設為…**」修改，再按一下「**套用**」(例如「**套用 12 項變更**」)。
</Step>
</Steps>

小提醒：

- 規則會依清單順序執行。每條符合的規則都會加上它的標籤；第一條移動書籤的規則優先，後面規則指定的資料夾會顯示為衝突。拖曳規則可以改變順序。
- 執行結果會穩定下來：已在某條符合規則指定的資料夾中的書籤會留在那裡；只有在新資料夾中、帶著新標籤時沒有任何規則會再次移動它，才會移動書籤。因此連續執行兩次規則，書籤也不會來回移動。
- 規則逐一處理書籤：網址相同但位於不同資料夾的兩個書籤會分別比對和變更。
- 書籤已有的標籤，不論寫法如何，都不會重複加上。資料夾不會被加上標籤，也不會被移動。
- 套用後訊息中的「**復原**」會同時還原移動和標籤。這些移動在記錄中是一項變更。這次執行也會連同它加上標籤的書籤列在設定的「**由規則變更**」中，之後仍可在那裡用「**復原**」移除仍在的這些標籤；它的移動在記錄中復原。
- 標籤和移動分開儲存，因此訊息會分別統計加上標籤、移動、略過和失敗的數量。沒有記錄就絕不移動：如果無法儲存這筆記錄，就不移動任何書籤，標籤仍會加上，訊息也會說明。
- 套用時會先重新檢查每個書籤。確認後被刪除、重新命名、改了網址或移到別處的書籤會被略過，並保留你的變更；確認後規則被編輯、關閉或刪除的書籤也是如此 (重新命名規則不算)。訊息會說明略過了多少。已經是確認結果狀態的書籤不會再次變更。確認後你變更了標籤或摘要、因而不再符合其規則的書籤也會被略過。
- 變更的書籤多於「**超過此數量時在背景套用**」(設定中的「**背景工作**」) 的執行，會由背景工作分批套用，標籤和移動一起處理。關閉管理員後、瀏覽器重新啟動後它都會繼續，你可以在「**背景工作**」中暫停、繼續或取消它；取消會保留已完成的部分。每一批的移動是記錄中的一項變更，這次執行的標籤會在加上前記錄，並列在「**由規則變更**」中。如果瀏覽器在套用某一批時停止，工作會等待你按下「**繼續**」，屆時會重新檢查每個剩餘書籤，因此不會重複加上標籤或移動。關閉智慧規則會暫停工作，直到你重新開啟並繼續；期間被編輯或關閉的規則，其書籤會被略過。
- 在設定中，每條規則會顯示其上次經確認的執行：時間，以及加上標籤、移動和未處理的書籤數量。「**上次執行中的衝突**」會列出兩條規則會移到不同資料夾的書籤，以及它們指定的資料夾；「**確認**」會在該書籤所在的資料夾中開啟管理員，並準備好在那裡執行智慧規則。
- 規則只會儲存在這部裝置上，並包含在「**備份設定**」中。在其他裝置還原的規則，只有在該裝置上有對應資料夾時才會移動書籤；否則在你重新選擇資料夾之前，它的移動會被封鎖。如果該資料夾在那裡的 ID 不同，只要只有一個資料夾是這個路徑，規則就會依路徑找到它。
- 在設定中開啟「**為新書籤加上標籤**」後，已啟用的規則會為「**新書籤來源**」允許的每個新書籤加上標籤。預設是「**用 Bookmark Scout 儲存的**」：透過快速儲存、彈出式視窗、管理員或 Ask AI 儲存的書籤。選擇「**任何來源**」可包含來自瀏覽器星號、其他擴充功能或同步的書籤；瀏覽器不會告知書籤的來源，因此它們會被同樣對待。它絕不會移動書籤。一次新增的大量書籤 (同步或匯入) 以及在設定不允許時新增的書籤都會保持不變。每次自動加上的標籤都會列在設定的「**由規則變更**」中，並可用「復原」移除這些標籤。
- 不經確認的移動需要你另外做兩項選擇，與加上標籤無關：在規則的資料夾旁勾選「**自動移動新書籤**」，並在設定中開啟「**移動新書籤**」。規則清單會在這類規則下顯示「**自動移動新書籤**」。之後規則符合的新書籤會移到該資料夾，而且只會移到該資料夾：如果資料夾被刪除、重新命名、移動或受管理，規則會提示自動移動已停止，在你重新選擇資料夾並儲存規則之前不會移動任何書籤；絕不會改用路徑相同的其他資料夾。與執行時一樣，由第一條移動書籤的規則決定，兩條規則要移到不同資料夾的書籤保持不動。Bookmark Scout 儲存的書籤 (快速儲存、管理員) 會留在原處，因此自動移動需要把「**新書籤來源**」設為「**任何來源**」；一次新增的大量書籤和幾秒內又被移動過的書籤也會留在原處。每批移動在[記錄](/guides/save-and-organize)中是一項來自 Bookmark Scout 的變更，名稱為「智慧規則，自動」，如果無法儲存這筆記錄，就不移動任何書籤。每次移動也會列在「**由規則變更**」中，在那裡復原會把書籤移回之前的資料夾，除非它此後又被移動過。
- 在搜尋支援 `OR` 和括號之前儲存的規則，仍會找到原本找到的書籤：它們會當成加上引號的文字讀取。
- 規則不搜尋頁面文字：包含 `content:` 或 `has:content` 的搜尋無法儲存到規則中，因為規則比對書籤時不使用已建立索引的頁面文字（[在網頁中搜尋](#search-inside-pages)）。

## 在網頁中搜尋 [#search-inside-pages]

「**索引網頁內文**」會在這部裝置上保存書籤網頁的可讀內文，讓搜尋也能找到只出現在網頁中的字詞。開啟前預設關閉，並且會下載每個要索引的網頁。

<Steps>
<Step>
在[設定](/settings#index-page-text)中開啟「**啟用索引網頁內文**」。
</Step>
<Step>
在書籤管理員的工具側邊欄中，於「**索引網頁內文**」卡片選擇範圍，然後按一下「**索引**」。然後選擇要讀取的網站：每個有網頁要下載的網站都會列出，並顯示其書籤數，起初全部勾選。取消勾選要略過的網站（可用「**全選**」、「**全部取消選取**」，清單較長時還可篩選），然後按一下顯示網站數的開始按鈕（例如「**開始（2 個網站）**」）。如有提示，請允許存取這些網站；不會要求或下載其他網站。索引會在背景執行：關閉管理員後仍會繼續，其卡片和「**背景工作**」會顯示進度，並可「**暫停**」、「**繼續**」或「**取消**」；之後網頁會在「**查看結果**」中等你查看。
</Step>
<Step>
依分頁確認網頁：「**有內文**」、「**沒有內文**」、「**登入頁面**」(網頁要求登入而沒有顯示內容；其內文絕不會儲存)、「**已重新導向**」(該網址會把你帶到另一個網址，而那個網址不會被開啟，因此不會連線到你未允許的網站；請改為替它導向的網址加入書籤)、「**失敗**」、「**已索引**」(之前從同一網址索引過)、「**未選擇**」(位於你略過的網站，因此從未下載) 和「**已略過**」(不是網頁，或位於區域網路且「**略過區域網路中的網頁**」已開啟，這是預設值)。有內文的網頁預設為「**儲存內文**」；按一下「**儲存**」(例如「**儲存 12 個網頁的內文**」)。在把網頁列為已重新導向之前，會先嘗試它的 `https:` 網址以及加上或去掉 `www.` 的網址，只限書籤自己的網站，且不會繼續跟隨重新導向；以這種方式讀取的網頁會顯示「**讀取自**」和讀取時使用的網址。如果儲存時這部裝置上擴充功能的儲存空間用完，之前已儲存的網頁會保留，並有訊息說明有多少未儲存；請釋放磁碟空間，或在設定中使用「**刪除網頁內文**」，然後重新建立索引。
</Step>
</Steps>

之後，就能在彈出式視窗、側邊面板和書籤管理員中依內文搜尋到這些書籤。`content:` 只在網頁內文中查找，`has:content` 會找到有內文的書籤。書籤網址變更後，網頁會重新讀取。在設定中按一下「**刪除網頁內文**」會刪除索引；書籤、標籤和記錄保持不變。在網頁內文中找到的結果會說明內文的來源：「**已下載的網頁**」或「**來自你的分頁的網頁**」。「詢問 AI」和本機 AI 代理程式從不搜尋網頁內文，網頁內文只保存在這部裝置上：在那裡 `content:` 和 `has:content` 什麼都找不到，回答中也會說明這一點。

索引下載網頁時不會帶上你的 Cookie，因此只有登入後才能閱讀的網頁會改為顯示其登入頁面，並歸入「**登入頁面**」。若要索引你在這類網頁上看到的內容，請開啟該網頁：當網頁已加入書籤且開啟「索引網頁內文」時，彈出式視窗中顯示網頁儲存位置的那一行有「**索引此網頁的內文**」按鈕，它會讀取分頁顯示的內文並顯示出來，同時提醒你確認其中沒有私人內容。只有按一下「**儲存內文**」才會保留。只會從工具列彈出式視窗讀取，絕不讀取無痕視窗或登入頁面，而且只在讀取前後分頁都顯示該書籤網頁時讀取；如果期間分頁換成其他網頁，就不會保留任何內容。

網址相同的書籤共用一次下載，並各自保留自己的內文。另有兩種情況會分開列出：**不是網頁** (該網址傳回 PDF 等檔案，不會下載)，以及「**已略過**」中包含使用者名稱和密碼、或包含隱私掃描工具「**敏感參數**」所列參數 (例如權杖) 的網址：網站會收到這些內容，因此在設定中的「**略過含登入資訊或機密的網址**」開啟時 (預設) 不會要求。內文會依段落以純文字保存，所以加上引號的詞組只會在同一段落內比對。對於回應忙碌並指定短暫等待時間的網站，會在等待之後再次要求，最多幾次；之後該網頁會列在「**失敗**」下。若要讓「索引網頁內文」完全不碰某個網站，請在[設定](/settings#index-page-text)的「**永不讀取這些網站**」中加入它：它及其子網域的網頁從不下載，也不會從分頁讀取，會連同原因列在「**已略過**」下，而且已從該網站索引的內文會被刪除。

[設定](/settings#index-page-text)中的「**網頁內文索引**」面板會顯示可索引的書籤中已索引多少、有多少已過期 (讀取自以前的網址或由舊版本讀取；下次執行時會重新讀取)，以及上次執行失敗了多少。「**重試失敗項目**」會在背景只對這些書籤重新執行「索引網頁內文」，並且只要求存取它們的網站；請在卡片的「**查看結果**」中儲存內文。撤銷擴充功能對某個網站的存取權會刪除從該網站索引的內文，刪除書籤也會刪除它的內文。面板也會顯示上次索引內文的時間，「**重新整理已過期項目**」會以同樣的方式重新讀取已過期的網頁。

## 在卡片上顯示封面 [#show-covers-on-cards]

「**取得封面**」會保存網頁為自己指定的預覽圖 (Open Graph 或 Twitter 卡片圖片) 的小型副本，讓書籤管理員的「**卡片**」顯示它。開啟前預設關閉。顯示卡片時不會下載任何內容：沒有已儲存封面的卡片會顯示一個圖塊，在從該網站選取的顏色上顯示網站的圖示和名稱，由你的電腦在本機繪製。

在[設定](/settings#fetch-covers)中開啟「**啟用取得封面**」。

<Step>

</Step>

用「**查看**」旁的按鈕將書籤管理員切換到「**卡片**」即可看到封面。在清單中，「**查看**」裡的「**封面**」欄會以小圖顯示封面；將指標停在小圖上即可查看大圖。封面屬於取得它的網址，因此網址變更的書籤在重新取得前會顯示圖示。封面只保存在這部裝置上，不會同步，書籤匯出也不包含封面；要把它們帶到另一台電腦，請在備份中包含封面（請見[備份包含的內容](/guides/import-export#what-a-backup-holds)）。在設定中按一下「**刪除封面**」即可移除，書籤、標籤和記錄保持不變。刪除書籤時，它的封面也會一併刪除。一次執行會保留找到的封面直到你儲存，因此找到單次執行可保留的數量後就不再讀取網頁；檢視中會說明留下了多少書籤，下次執行會讀取它們。

也可以將目前的網頁設為封面：當網頁已加入書籤且開啟「取得封面」時，彈出式視窗中顯示網頁儲存位置的那一行末端有「**將目前畫面設為封面**」按鈕，它會擷取分頁畫面並顯示出來，同時提醒你確認其中沒有私人內容。只有按一下「**儲存封面**」才會保留。只會從工具列彈出式視窗擷取，絕不擷取無痕視窗，而且只在分頁仍顯示該書籤網頁時擷取。

書籤選單（按右鍵或 ⋯，在清單或卡片中，也可用於多選）或其「預覽」中的「取得封面」只對這些書籤執行取得封面，審閱畫面和對其網站的存取要求都相同；用「將目前畫面設為封面」儲存的封面會列在「你選定的」之下並保留。在「取得封面」卡片上，「所選書籤」會對管理員中的選取項目執行相同操作。「移除封面」會刪除書籤的封面（多選時為每個所選書籤的封面）：卡片會立即顯示預留圖，訊息中的「復原」會放回同一封面。

### 瀏覽時擷取封面 [#capture-covers-while-you-browse]

在[設定](/settings#fetch-covers)的「取得封面」下方開啟「**瀏覽時擷取封面**」，不必取得也能有封面。當沒有封面的已加入書籤網頁在你正在檢視的分頁中載入完成時，Bookmark Scout 會稍候片刻，確認分頁仍顯示該網頁，再將它的螢幕截圖設為該書籤的封面。開啟時會向瀏覽器要求存取所有網頁的權限，因為這是瀏覽器允許擴充功能不需按一下就擷取分頁畫面的唯一方式；同樣的存取權也讓讀取網站的工具不必再次詢問即可執行。

- 除非你也開啟「**也在無痕視窗中擷取**」，且瀏覽器允許 Bookmark Scout 在其中執行，否則不在無痕視窗中擷取；也絕不擷取擴充功能或瀏覽器本身的頁面、本機檔案，或你未加入書籤的網頁。
- 螢幕截圖會顯示網頁當時顯示的任何內容，例如帳戶頁面或訊息。將不想被擷取的網站加入「**永不擷取這些網站**」(一個網站也涵蓋其子網域)，並可在設定中用「**刪除封面**」刪除任何封面。「永不讀取這些網站」中的網站也不會擷取。
- 「**封面來源**」決定兩者都可用時以哪個封面為準。選擇「**網頁圖片優先，其次截圖**」(預設) 時，截圖絕不會取代「取得封面」儲存的圖片，而「取得封面」會取代截圖。「**截圖優先**」對瀏覽時擷取的截圖正好相反，「**僅網頁圖片**」則不擷取截圖。用「將目前畫面設為封面」儲存的封面不會被「取得封面」或瀏覽時的截圖自動取代，只有你再儲存一張圖片時才會取代。選擇「**僅截圖**」時只使用截圖：「取得封面」不會讀取任何網頁，檢視畫面會說明這一點。
- 瀏覽時擷取的截圖早於「**重新擷取早於此時間的截圖**」設定的時間後，會在你下次造訪時重新擷取 (設為 0 則一律不重新擷取)。等待多久由「**擷取前等待**」和「**擷取間隔**」決定。和所有封面一樣，截圖只保存在這部裝置上，絕不會傳送到任何地方。關閉此設定即可停止；存取權請在瀏覽器的擴充功能設定中移除。

書籤的「**預覽**」和詳細資料卡片會註明封面的來源：網頁本身的圖片、你的分頁畫面，或瀏覽時擷取的畫面，以及儲存的日期。快速儲存時擷取的畫面也會註明。

### 快速儲存時儲存封面 [#save-a-cover-with-quick-save]

開啟取得封面後，快速儲存快捷鍵還會為所儲存的網頁儲存封面（[設定](/settings#quick-save)中的「**快速儲存時儲存封面**」，預設關閉，且僅在取得封面也開啟時有效）：網頁本身的預覽圖片（在該網頁的網站或你允許的網站上時），或在你按下快捷鍵的那一刻、通知出現之前擷取的分頁截圖。它依照「**封面來源**」，除非「**快速儲存封面來源**」為快速儲存設定了單獨的順序；書籤已有的封面會保留，除非「**書籤已有封面時**」設為取代；用「**將目前畫面設為封面**」儲存的封面永遠不會被取代。截圖不經檢視直接儲存，因此通知會提供「**移除封面**」，「**復原**」會連同書籤一起移除封面。私密視窗中以及「**永不擷取這些網站**」或「**永不讀取這些網站**」中的網站都不會擷取。設定中的「**封面圖片品質**」決定所有封面的儲存品質。如果新封面取代了書籤原有的封面，「**移除封面**」會把原來的封面放回。

## 相關工具 [#related-tools]

- 「[找出並修復失效連結](/guides/dead-links)」會檢查已加入書籤的網頁是否仍可載入。
- 「**隱私掃描工具**」(位於「**安全性**」下) 會標示含有權杖、電子郵件地址、UUID 或敏感參數的網址 (如果開啟「**掃描標題**」，也會標示標題)。確認畫面會依「**高**」、「**中**」、「**低**」分組；每一項預設為「**維持不變**」，改為「**刪除書籤**」的項目 (逐一或使用「**將所選設為…**」) 會在你按一下「**刪除**」後刪除，並可復原。一般的頁內連結和應用程式位址 (例如 Gmail 的 `#inbox`) 不會被標示。
- 「**中繼資料擷取工具**」(位於「**頁面詳細資料**」下) 會依據線上網頁建議網頁標題，並只套用你選取的標題。這項工具使用與失效連結檢查相同的網站存取權。它同樣在背景執行，標題會在「**查看結果**」中等你查看。
