description: 經確認後移除重複書籤、先預覽再從書籤網址中清除 utm_source 等追蹤參數，以及重新整理缺少的網站圖示。
---

這兩項工具都位於書籤管理員「**工具**」側欄的「**維護**」下。在 Chrome 中，開啟瀏覽器的書籤頁面；如果側欄已隱藏，請按一下書籤管理員標頭中的「**顯示工具**」。

<Callout title="Firefox">
Firefox 不允許擴充功能取代其書籤頁面，因此在 Firefox 中，請從工具列彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員，然後開啟工具側欄。
</Callout>

## 移除重複書籤 [#remove-duplicate-bookmarks]

<Steps>
<Step>
在「**重複書籤清理工具**」中按一下「**掃描**」。這項工具一律檢查所有書籤。
</Step>
<Step>
確認各個群組。每個群組會列出相符的書籤，並將要保留的書籤標示為「**保留**」。
</Step>
<Step>
按一下「**移除重複項目**」刪除每個群組中的其他副本，或按一下「**取消**」不做任何變更。
</Step>
<Step>
改變主意了嗎？請在 10 秒內按一下訊息中的「**復原**」，還原已移除的項目。
</Step>
</Steps>

<Screenshot name="duplicates" />

哪些書籤算是重複項目，是在「[設定](/settings)」的「**維護**」分頁中設定：

| 設定 | 預設值 | 作用 |
| --- | --- | --- |
| **比對方式** | 正規化網址 | 依「**網址完全相同**」、「**正規化網址**」、「**標題 + 網址**」或「**僅標題**」比較 |
| **統一 www** | 開啟 | 將 `www.example.com` 和 `example.com` 視為同一個主機 |
| **忽略通訊協定** | 開啟 | 將 `http` 和 `https` 版本視為重複項目 |
| **忽略結尾斜線** | 開啟 | 將結尾有無 `/` 的網址視為重複項目 |
| **保留規則** | 最舊的 | 保留每個群組中「**最舊的**」、「**最新的**」或「**最先找到的**」書籤 |
| **群組數量上限** | 500 | 單次掃描傳回的群組數量上限 |

移除任何項目之前，系統會再次檢查每個群組。如果標示為「**保留**」的書籤已被刪除或現在指向其他位置，整個群組都不會變更，訊息也會說明略過了幾個群組。使用「**僅標題**」比對時，如果群組中包含不同的網址，就會顯示警告，因為移除這些副本會刪除不同的網頁。

## 清除追蹤參數 [#strip-tracking-parameters]

<Steps>
<Step>
在「**網址清理工具**」的範圍選單中選擇目前資料夾或所有書籤，然後按一下「**清理**」。
</Step>
<Step>
確認預覽中列出的每個將變更的網址。
</Step>
<Step>
按一下「**套用變更**」更新所有網址，或關閉對話方塊不做任何變更。
</Step>
</Steps>

如果書籤在預覽後有所變更，就會被略過，並計入訊息中的數量。網址清理無法復原，因此請在套用前仔細確認預覽內容。

規則位於設定的「**維護**」分頁中：

- 「**移除參數**」：要清除的參數。預設清單為 `utm_source`、`utm_medium`、`utm_campaign`、`utm_term`、`utm_content`、`utm_id`、`gclid`、`fbclid`、`mc_cid`、`mc_eid`、`ref`、`ref_src` 和 `si`。
- 「**保留參數**」：一律不會移除的參數。預設值：`id`、`page`、`q`、`p` 和 `lang`。
- 「**移除重複的查詢參數**」(預設為開啟) 會移除重複出現的參數。
- 「**排序查詢參數**」(預設為開啟) 會依字母順序排列其餘的參數。
- 「**移除片段**」(預設為關閉) 也會移除 `#section` 這類部分。

## 重新整理網站圖示 [#refresh-site-icons]

書籤會顯示瀏覽器為各網站快取的圖示。最近沒有造訪的網站會顯示通用的地球圖示，而 Firefox 完全不提供圖示快取給擴充功能使用。工具側欄「**中繼資料與內容**」下的「**重新整理網站圖示**」則會改為下載各網站本身的圖示。

<Steps>
<Step>
在範圍選單中選擇目前資料夾或所有書籤，然後按一下「**重新整理**」。第一次使用時，請在系統詢問時允許網站存取權；如果你拒絕，就不會發出任何要求。
</Step>
<Step>
確認結果：有多少圖示「**已更新**」、「**未變更**」、「**找不到圖示**」或「**失敗**」，以及有多少書籤因為不是網頁連結而「**已略過**」。
</Step>
<Step>
按一下「**儲存**」(例如「**儲存 12 個圖示**」) 保留這些圖示，或關閉對話方塊不保留任何圖示。
</Step>
</Steps>

針對範圍內的每個網站 (來源)，這項工具會在不附帶 Cookie 的情況下要求一個已加入書籤的網頁、只讀取其 head 部分，並下載該網頁列出的圖示中最接近「**偏好的圖示大小**」的一個，或是網站的 `/favicon.ico`。只會使用書籤本身網域上的圖示檔案，絕不使用第三方圖示服務。超過「**圖示檔案大小上限**」(64 KB) 或不是圖片的檔案會被略過。

已儲存的圖示會存放在這個瀏覽器的本機儲存空間中，不會同步，並會顯示在彈出式視窗、側邊面板和書籤管理員中。這些圖示的優先順序高於瀏覽器快取的圖示。卡片會顯示已儲存的圖示數量；「**清除已儲存的圖示**」會將其全部刪除。總大小達到「**圖示儲存空間上限**」(4096 KB) 時，會先移除最舊的圖示。如果某個網站在之後重新整理時失敗，會保留先前儲存的圖示。

<Callout title="Firefox">
在 Firefox 中，請從工具列彈出式視窗中的「**開啟書籤管理員**」開啟書籤管理員，再執行這項工具。在該處儲存圖示後，彈出式視窗和側邊面板就會顯示這些圖示。
</Callout>

## 相關工具 [#related-tools]

- 「[找出並修復失效連結](/guides/dead-links)」會檢查已加入書籤的網頁是否仍可載入。
- 「**隱私掃描工具**」(位於「**安全性**」下) 會標示含有權杖、電子郵件地址、UUID 或敏感參數的網址 (如果開啟「**掃描標題**」，也會標示標題)，方便你自行編輯或刪除。
- 「**中繼資料擷取工具**」(位於「**中繼資料與內容**」下) 會依據線上網頁建議網頁標題，並只套用你選取的標題。這項工具使用與失效連結檢查相同的網站存取權。
