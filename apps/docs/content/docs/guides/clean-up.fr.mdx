title: Nettoyer les doublons et les URL de suivi
description: Supprimez les favoris en double après vérification, retirez des URL de vos favoris les paramètres de suivi tels que utm_source après un aperçu, et actualisez les icônes de site manquantes.
---

Ces deux outils se trouvent dans la barre latérale **Outils** du gestionnaire de favoris, sous **Maintenance**. Dans Chrome, ouvrez la page Favoris du navigateur, puis cliquez sur **Afficher les outils** dans l'en-tête du gestionnaire si la barre latérale est masquée.

<Callout title="Firefox">
Firefox ne permet pas aux extensions de remplacer sa propre page de favoris : ouvrez donc le gestionnaire avec **Ouvrir le gestionnaire de favoris** dans la fenêtre pop-up de la barre d'outils, puis ouvrez la barre latérale Outils.
</Callout>

## Supprimer les favoris en double [#remove-duplicate-bookmarks]

<Steps>
<Step>
Dans **Nettoyeur de doublons**, cliquez sur **Analyser**. L'outil vérifie toujours tous les favoris.
</Step>
<Step>
Vérifiez les groupes. Chaque groupe affiche une seule fois l’adresse commune, puis chaque favori avec son dossier et sa date d’ajout. Celui marqué **Conserver** suit la **Règle de conservation** jusqu’à ce que vous en choisissiez un autre avec son bouton radio ; chaque autre copie a une case **Supprimer**, cochée au départ. Décochez une copie, ou la case d’un groupe, pour la laisser telle quelle.
</Step>
<Step>
Cliquez sur **Supprimer N doublons** pour supprimer les copies cochées, ou sur **Annuler** pour ne rien modifier.
</Step>
<Step>
Vous avez changé d'avis ? Cliquez sur **Annuler** dans la notification dans les 10 secondes pour restaurer ce qui a été supprimé. Plus tard, <Shortcut id="manager.undo" /> dans le gestionnaire de favoris le restaure aussi.
</Step>
</Steps>

<Screenshot name="duplicates" />

Ce qui est considéré comme un doublon se règle dans l'onglet **Maintenance** des [Paramètres](/settings) :

| Paramètre | Valeur par défaut | Effet |
| --- | --- | --- |
| **Méthode de comparaison** | URL normalisée | Compare par **URL exacte**, **URL normalisée**, **Titre + URL** ou **Titre uniquement** |
| **Normaliser www** | Activé | Considère `www.example.com` et `example.com` comme le même hôte |
| **Ignorer le protocole** | Activé | Considère les versions `http` et `https` comme des doublons |
| **Ignorer la barre oblique finale** | Activé | Considère les URL avec et sans `/` final comme des doublons |
| **Règle de conservation** | Le plus ancien | Conserve le favori **Le plus ancien**, **Le plus récent** ou **Le premier trouvé** de chaque groupe |
| **Nombre maximal de groupes** | <SettingDefault path="maintenance.duplicates.max_groups" /> | Nombre maximal de groupes renvoyés par une analyse |

Avant toute suppression, chaque groupe est vérifié à nouveau. Si le favori marqué **Conserver** a été supprimé ou pointe désormais ailleurs, le groupe entier est laissé intact et la notification indique combien de groupes ont été ignorés. Avec la comparaison **Titre uniquement**, un avertissement s'affiche lorsqu'un groupe contient des URL différentes, car supprimer ces copies revient à supprimer des pages différentes.

## Retirer les paramètres de suivi [#strip-tracking-parameters]

<Steps>
<Step>
Dans **Nettoyeur d'URL**, choisissez le dossier actuel ou tous les favoris dans le menu de portée, puis cliquez sur **Nettoyer**.
</Step>
<Step>
Vérifiez les URL qui seraient modifiées, groupées par la règle qui les nettoie (une entrée de **Paramètres à supprimer** comme `utm_*`, un paramètre répété ou un fragment). Chacune commence sur **Nettoyer** ; passez-en une, ou toutes les sélectionnées avec **Appliquer à la sélection…**, sur **Laisser tel quel** pour ne pas y toucher.
</Step>
<Step>
Cliquez sur **Nettoyer N URL** pour mettre à jour celles restées sur **Nettoyer**, ou fermez la boîte de dialogue pour ne rien modifier.
</Step>
</Steps>

Si un favori a été modifié après l'aperçu, il est ignoré et comptabilisé dans la notification. Cliquez sur **Annuler** dans la notification, ou appuyez sur <Shortcut id="manager.undo" /> dans le gestionnaire de favoris, pour rétablir les anciennes URL ; un favori modifié de nouveau entre-temps est laissé tel quel.

Les règles se trouvent dans l'onglet **Maintenance** des paramètres :

- **Paramètres à supprimer** : paramètres à retirer. La liste par défaut est <SettingDefault path="maintenance.url_cleaner.remove_params" />. Un nom qui se termine par `*` inclut tous les noms qui commencent ainsi.
- **Paramètres à conserver** : paramètres qui ne sont jamais retirés. Par défaut : <SettingDefault path="maintenance.url_cleaner.preserve_params" />.
- **Dédoublonner les paramètres de requête** (activé par défaut) supprime les paramètres répétés.
- **Trier les paramètres de requête** (activé par défaut) trie les paramètres restants par ordre alphabétique.
- **Supprimer les fragments** (désactivé par défaut) supprime aussi les parties telles que `#section`.

## Actualiser les icônes de site [#refresh-site-icons]

Les favoris affichent un globe générique tant que Bookmark Scout n'a pas d'icône pour le site. Dans Chrome et Edge, le plus rapide est **Afficher les icônes du navigateur** sur la carte **Actualiser les icônes de site**, ou **Utiliser le cache d'icônes du navigateur** dans les [Paramètres](/settings#appearance) : les icônes que votre navigateur a déjà enregistrées pour les sites que vous consultez s'affichent, et le navigateur demande seulement à lire les icônes de site. Pour les sites dont le navigateur n'a pas d'icône, et dans Firefox, qui n'offre aucun cache d'icônes aux extensions, **Actualiser les icônes de site**, sous **Titres et icônes des pages** dans la barre latérale Outils, télécharge l'icône propre à chaque site.

<Steps>
<Step>
Choisissez le dossier actuel ou tous les favoris dans le menu de portée, puis cliquez sur **Actualiser**. Lorsque cela vous est demandé, autorisez l'accès aux sites de cette portée (une portée de plus de 20 sites demande l'accès à tous les sites Web) ; si vous refusez, aucune requête n'est envoyée.
</Step>
<Step>
Vérifiez les sites par onglet : **Nouvelle icône**, **Même icône**, **Aucune icône** et **Échec**, chacun avec son nombre, et une note indiquant combien de favoris ont été ignorés parce que ce ne sont pas des liens web. Chaque icône trouvée commence sur **Enregistrer l'icône** ; passez-en une sur **Ignorer**, ou sélectionnez-en plusieurs et utilisez **Appliquer à la sélection…**.
</Step>
<Step>
Cliquez sur **Enregistrer** (par exemple **Enregistrer 12 icônes**) pour conserver les icônes laissées sur **Enregistrer l'icône**, ou fermez la boîte de dialogue pour ne rien conserver.
</Step>
</Steps>

Pour chaque site Web (origine) compris dans la portée, l'outil demande une page enregistrée en favori sans cookies, n'en lit que l'en-tête, et télécharge l'icône indiquée par la page dont la taille est la plus proche de la **Taille d'icône préférée**, ou à défaut le fichier `/favicon.ico` du site. Seuls les fichiers d'icône situés sur le domaine du favori lui-même sont utilisés, jamais un service d'icônes tiers. Les fichiers qui dépassent la **Taille maximale du fichier d'icône** (<SettingDefault path="metadata_content.site_icons.max_icon_kb" /> Ko) ou qui ne sont pas des images sont ignorés.

L'actualisation s'exécute en arrière-plan : elle continue quand vous fermez le gestionnaire, et sa carte ainsi que **Tâches en arrière-plan** affichent sa progression, avec **Mettre en pause**, **Reprendre** et **Annuler**. Ses résultats attendent dans **Voir les résultats** ; rien n'est enregistré tant que vous ne cliquez pas sur **Enregistrer**.

Les icônes enregistrées sont stockées dans le stockage local de ce navigateur, ne sont pas synchronisées, et s'affichent dans la fenêtre pop-up, le panneau latéral et le gestionnaire. Elles ont la priorité sur l'icône en cache du navigateur. La carte indique combien d'icônes sont enregistrées ; **Effacer les icônes enregistrées** les supprime toutes. Lorsque le total atteint la **Limite de stockage des icônes** (4 Mo), les icônes les plus anciennes sont supprimées en premier. Un site dont l'actualisation échoue ultérieurement conserve l'icône enregistrée auparavant.

<Callout title="Firefox">
Dans Firefox, ouvrez le gestionnaire avec **Ouvrir le gestionnaire de favoris** dans la fenêtre pop-up de la barre d'outils pour lancer l'outil. Une fois les icônes enregistrées dans le gestionnaire, la fenêtre pop-up et le panneau latéral les affichent.
</Callout>

## Étiqueter et déplacer avec les Règles intelligentes [#tag-and-move-with-smart-rules]

Une règle intelligente trouve des favoris avec une recherche, avec les mêmes mots et [opérateurs](/guides/search#search-words-and-operators) que les champs de recherche, et leur ajoute des étiquettes, les déplace dans un dossier, ou les deux. Les règles n'agissent seules que là où vous l'activez, ci-dessous ; sinon chaque exécution est une vérification que vous appliquez.

<Steps>
<Step>
Dans les [paramètres](/settings#maintenance), sous **Règles intelligentes**, cliquez sur **Ajouter une règle**, ou sur **Partir d’un modèle** pour une règle qui étiquette les pages GitHub, les vidéos YouTube ou les tutoriels, ou qui déplace les favoris d’un dossier **Work / Reading**. Les modèles commencent désactivés. Celui qui déplace s’ouvre dans l’éditeur, car il n’a pas encore de dossier : il ne peut être ni activé ni enregistré tant que vous n’en avez pas choisi un.
</Step>
<Step>
Donnez à la règle un nom et une recherche, comme `domain:github.com`, `folder:Lecture -tag:lu` ou `(domain:github.com OR domain:gitlab.com) -tag:archived`. L'éditeur indique combien de favoris elle trouve actuellement, ou ce qui ne va pas dans la recherche, comme une parenthèse non fermée ; une règle ne peut être enregistrée que si sa recherche se lit. Ajoutez des étiquettes séparées par des virgules, choisissez un dossier de destination, ou les deux, puis enregistrez.
</Step>
<Step>
Dans la barre latérale **Outils** du gestionnaire, choisissez la portée sur la carte **Règles intelligentes** et cliquez sur **Exécuter** : le dossier affiché, tous les favoris ou, tant que le gestionnaire en a, **Résultats de recherche** (ce que liste la zone de recherche) ou **Favoris sélectionnés**. La portée est prise au clic, et un favori en dehors n'est jamais vérifié ni modifié.
</Step>
<Step>
Vérifiez les favoris par onglet : **Modifications**, **Conflits** (deux règles le déplaceraient vers des dossiers différents), **Bloqués** (son dossier n'existe plus ou est géré, ou dans ce dossier une autre règle le déplacerait de nouveau) et **Déjà fait**. Les modifications commencent sur **Appliquer** et les conflits sur **Ignorer** ; changez-en d'autres un par un ou avec **Appliquer à la sélection…**, puis cliquez sur **Appliquer** (par exemple **Appliquer 12 modifications**).
</Step>
</Steps>

Bon à savoir :

- Les règles s'exécutent dans l'ordre de la liste. Chaque règle qui correspond ajoute ses étiquettes ; la première qui déplace un favori l'emporte, et les dossiers des règles suivantes apparaissent comme des conflits. Faites glisser une règle pour changer l'ordre.
- Les exécutions se stabilisent : un favori déjà dans un dossier qu'une règle correspondante nomme y reste, et un déplacement n'a lieu que si, dans son nouveau dossier et avec ses nouvelles étiquettes, aucune règle ne le déplacerait de nouveau. Exécuter les règles deux fois ne fait donc jamais aller et venir un favori.
- Les règles traitent chaque favori à part : deux favoris de même adresse dans des dossiers différents sont évalués et modifiés séparément.
- Une étiquette qu'un favori a déjà, quelle que soit son écriture, n'est pas ajoutée de nouveau. Les dossiers ne sont jamais étiquetés ni déplacés.
- **Annuler** dans le message qui suit l'application remet à la fois les déplacements et les étiquettes. Les déplacements forment une seule modification dans l'historique. L'exécution figure aussi dans les paramètres sous **Modifiés par les règles** avec les favoris qu'elle a étiquetés ; **Annuler** y retire plus tard ces étiquettes là où elles sont encore. Ses déplacements s'annulent depuis l'historique.
- Les étiquettes et les déplacements sont enregistrés séparément, donc le message compte ce qui a été étiqueté, déplacé, ignoré (un favori supprimé, déplacé ou modifié depuis la vérification) et ce qui a échoué. Un déplacement n'a jamais lieu sans son entrée dans l'historique : si cette entrée ne peut pas être enregistrée, rien n'est déplacé, les étiquettes sont quand même ajoutées et le message le signale.
- Les règles restent sur cet appareil et font partie de **Sauvegarder les paramètres**. Une règle restaurée sur un autre appareil ne déplace des favoris que si son dossier y existe ; sinon, ses déplacements sont bloqués jusqu'à ce que vous choisissiez de nouveau le dossier. Elle retrouve ce dossier par son chemin quand il y porte un autre identifiant, tant qu’un seul dossier a ce chemin.
- Avec **Étiqueter les nouveaux favoris** activé dans les paramètres, les règles actives ajoutent leurs étiquettes à chaque nouveau favori qu'autorise **Nouveaux favoris de**. Par défaut, c'est **Enregistrés avec Bookmark Scout** : les favoris que vous enregistrez avec l'enregistrement rapide, la fenêtre contextuelle, le gestionnaire ou Ask AI. Choisissez **Partout** pour inclure les favoris venant de l'étoile du navigateur, d'une autre extension ou de la synchronisation ; le navigateur n'indique pas d'où vient un favori, donc ils sont tous traités de la même façon. Rien n'est jamais déplacé. Les nombreux favoris ajoutés d'un coup (une synchronisation ou une importation) restent tels quels, tout comme un favori ajouté pendant qu'un paramètre ne le permettait pas. Chaque étiquetage automatique figure dans les paramètres sous **Modifiés par les règles**, avec un Annuler qui retire ses étiquettes.
- Déplacer sans vérification demande deux choix de votre part, distincts de l'étiquetage : **Déplacer automatiquement les nouveaux favoris** sur la règle, à côté de son dossier, et **Déplacer les nouveaux favoris** dans les paramètres. La liste des règles indique **Déplace automatiquement les nouveaux favoris** sous une telle règle. Chaque nouveau favori qu'elle trouve va alors dans ce dossier, et seulement celui-là : si le dossier est supprimé, renommé, déplacé ou géré, la règle signale que ses déplacements automatiques sont arrêtés et rien n'est déplacé tant que vous n'avez pas choisi de nouveau le dossier et enregistré la règle ; un dossier ayant le même chemin n'est jamais utilisé à la place. Comme lors d'une exécution, la première règle qui déplace un favori décide, et un favori que deux règles déplaceraient dans des dossiers différents reste en place. Les favoris enregistrés par Bookmark Scout (enregistrement rapide, le gestionnaire) restent là où ils ont été placés, donc les déplacements automatiques demandent **Nouveaux favoris de** sur **Partout** ; les nombreux favoris ajoutés d'un coup et un favori déplacé de nouveau en quelques secondes restent aussi en place. Chaque groupe de déplacements est une modification dans l'[Historique](/guides/save-and-organize), par Bookmark Scout, nommée Règles intelligentes, automatiquement, et rien n'est déplacé si cette entrée ne peut pas être enregistrée. Chaque déplacement figure sous **Modifiés par les règles**, où Annuler remet le favori dans son dossier précédent, sauf s'il a été déplacé depuis.
- Une règle enregistrée avant que les recherches lisent `OR` et les parenthèses trouve toujours les mêmes favoris : ils sont lus comme du texte, entre guillemets.

## Chercher dans les pages [#search-inside-pages]

**Indexer le texte des pages** conserve le texte lisible des pages en favori sur cet appareil, pour que la recherche trouve des mots présents uniquement dans une page. Il est désactivé tant que vous ne l'activez pas, et télécharge chaque page que vous indexez.

<Steps>
<Step>
Activez **Activer Indexer le texte des pages** dans les [paramètres](/settings#index-page-text).
</Step>
<Step>
Dans la barre latérale **Outils** du gestionnaire, choisissez la portée sur la carte **Indexer le texte des pages** et cliquez sur **Indexer**. Choisissez ensuite les sites à lire : chaque site dont des pages sont à télécharger est listé avec son nombre de favoris, tous cochés au départ. Décochez ceux à laisser de côté (avec **Tout sélectionner**, **Tout désélectionner** et, pour une longue liste, un filtre), puis cliquez sur le bouton de lancement avec le nombre de sites (par exemple **Lancer avec 2 sites**). Si on vous le demande, autorisez l'accès à ces sites ; aucun autre site n'est demandé ni téléchargé. L'indexation s'exécute en arrière-plan : elle continue quand vous fermez le gestionnaire, et sa carte ainsi que **Tâches en arrière-plan** affichent sa progression, avec **Mettre en pause**, **Reprendre** et **Annuler** ; les pages attendent ensuite dans **Voir les résultats**.
</Step>
<Step>
Vérifiez les pages par onglet : **Texte trouvé**, **Aucun texte**, **Page de connexion** (la page demandait de vous connecter au lieu d'afficher son contenu ; son texte n'est jamais enregistré), **Redirigées** (l'adresse mène à une autre, qui n'est pas ouverte : un site que vous n'avez pas autorisé n'est donc jamais contacté ; ajoutez plutôt aux favoris l'adresse vers laquelle elle mène), **Échec**, **Déjà indexées** (auparavant, depuis la même adresse), **Non choisis** (sur un site que vous avez laissé de côté, donc jamais téléchargées) et **Ignorées** (pas une page web, ou sur votre réseau local). Les pages avec du texte commencent sur **Enregistrer le texte** ; cliquez sur **Enregistrer** (par exemple **Enregistrer le texte de 12 pages**). Avant qu'une page soit classée comme redirigée, son adresse `https:` et son adresse avec ou sans `www.` sont essayées, uniquement sur le site du favori et sans suivre d'autre redirection ; une page lue ainsi affiche **Lue depuis** et l'adresse depuis laquelle elle a été lue. Si l'espace de stockage de l'extension sur cet appareil est plein pendant l'enregistrement, les pages déjà enregistrées sont conservées et un message indique combien ne l'ont pas été ; libérez de l'espace disque ou utilisez **Supprimer le texte des pages** dans les Paramètres, puis indexez à nouveau.
</Step>
</Steps>

La recherche trouve ensuite ces favoris par leur texte dans la fenêtre pop-up, le panneau latéral et le gestionnaire. `content:` cherche uniquement dans le texte des pages, et `has:content` trouve les favoris qui en ont. Une page est relue quand l'adresse de son favori change. **Supprimer le texte des pages** dans les paramètres supprime l'index ; les favoris, les étiquettes et l'historique restent tels quels.

L'indexation télécharge les pages sans vos cookies : une page que vous ne pouvez lire qu'une fois connecté affiche donc sa page de connexion et se retrouve sous **Page de connexion**. Pour indexer ce que vous voyez sur une telle page, ouvrez-la : si elle est en favori et qu'Indexer le texte des pages est activé, le bouton de la ligne de la fenêtre pop-up qui indique où la page est enregistrée, **Indexer le texte de cette page**, lit le texte que l'onglet affiche et vous le montre avec un rappel de vérifier qu'il ne contient rien de privé. Il n'est conservé que si vous cliquez sur **Enregistrer le texte**. Le texte n'est lu que depuis la fenêtre pop-up de la barre d'outils, jamais dans une fenêtre privée, jamais sur une page de connexion, et seulement tant que l'onglet affiche la page du favori avant et après la lecture ; si l'onglet passe à une autre page entre-temps, rien n'est conservé.

## Afficher les couvertures sur les cartes [#show-covers-on-cards]

**Récupérer les couvertures** conserve une petite copie de l'image d'aperçu qu'une page indique pour elle-même (son image Open Graph ou de carte Twitter), pour que les **Cartes** du gestionnaire l'affichent. Il est désactivé tant que vous ne l'activez pas. Afficher les cartes ne télécharge jamais rien : une carte sans couverture enregistrée garde l'icône du site.

<Steps>
<Step>
Activez **Activer Récupérer les couvertures** dans les [paramètres](/settings#fetch-covers).
</Step>
<Step>
Dans la barre latérale **Outils** du gestionnaire, choisissez la portée sur la carte **Récupérer les couvertures** et cliquez sur **Récupérer**. Si on vous le demande, autorisez l'accès aux sites de cette portée.
</Step>
<Step>
Vérifiez les pages par onglet : **Couverture trouvée** (avec l'image), **Aucune couverture**, **Image inutilisable** (la page indique une image qui n'est pas dans un format pris en charge, est trop volumineuse ou ne peut pas être lue), **Sur un autre site** (l'image est sur un site que vous n'avez pas autorisé), **Redirigées** (l'adresse mène à une autre, qui n'est pas ouverte ; ses adresses `https:` et `www.` sont essayées d'abord, comme pour l'indexation du texte des pages), **Échec**, **Déjà récupérées** et **Ignorées**. Les couvertures trouvées commencent sur **Enregistrer la couverture** ; cliquez sur **Enregistrer** (par exemple **Enregistrer 12 couvertures**). Si l'espace de stockage de l'extension sur cet appareil est plein pendant l'enregistrement, les couvertures déjà enregistrées sont conservées et un message indique combien ne l'ont pas été ; libérez de l'espace disque ou utilisez **Supprimer les couvertures** dans les Paramètres, puis relancez la récupération.
</Step>
</Steps>

Passez le gestionnaire en **Cartes** avec le bouton à côté de **Afficher** pour les voir. Une couverture appartient à l'adresse dont elle vient : un favori déplacé vers une autre adresse affiche son icône jusqu'à une nouvelle récupération. Les couvertures restent sur cet appareil uniquement, jamais dans les sauvegardes ni les exports ; **Supprimer les couvertures** dans les paramètres les retire, et les favoris, les étiquettes et l'historique restent tels quels.

Vous pouvez aussi utiliser la page sur laquelle vous êtes : si elle est en favori et que Récupérer les couvertures est activé, le bouton au bout de la ligne de la fenêtre pop-up qui indique où la page est enregistrée, **Utiliser cette vue comme couverture**, capture l'onglet et vous montre l'image avec un rappel de vérifier qu'elle ne montre rien de privé. Elle n'est conservée que si vous cliquez sur **Enregistrer la couverture**. Les captures ne se font que depuis la fenêtre pop-up de la barre d'outils, jamais dans une fenêtre privée, et seulement tant que l'onglet affiche la page du favori.

## Outils associés [#related-tools]

- [Trouver et réparer les liens morts](/guides/dead-links) vérifie si les pages enregistrées en favoris se chargent toujours.
- **Analyseur de confidentialité** (sous **Sécurité**) signale les URL qui contiennent des jetons, des adresses e-mail, des UUID ou des paramètres sensibles (ainsi que les titres, si **Analyser les titres** est activé). Sa vérification les classe en **Élevé**, **Moyen** et **Faible** ; chacun commence sur **Laisser tel quel**, et ceux que vous passez sur **Supprimer le favori** (un par un ou avec **Appliquer à la sélection…**) sont supprimés quand vous cliquez sur **Supprimer**, avec annulation possible. Les liens ordinaires vers une partie de la page et les adresses d'applications comme `#inbox` de Gmail ne sont pas signalés.
- **Récupération des métadonnées** (sous **Titres et icônes des pages**) suggère des titres à partir des pages en ligne et n'applique que ceux que vous sélectionnez. Elle utilise le même accès aux sites Web que la vérification des liens morts. Elle s'exécute aussi en arrière-plan, et ses titres attendent dans **Voir les résultats**.
