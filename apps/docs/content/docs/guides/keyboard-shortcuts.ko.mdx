---
title: 키보드 단축키
description: 마우스 없이 검색하고, 폴더 사이를 이동하고, 현재 페이지를 저장하고, 관리자의 표를 다룹니다.
---

Bookmark Scout의 단축키는 `Ctrl`이나 `Cmd`를 사용하지 않으므로 `Ctrl/Cmd+L`, `T`, `W`, `N`, `R`, `D` 같은 브라우저 단축키는 그대로 동작합니다. 텍스트 필드에 입력하는 동안(검색창의 `Esc`는 예외), 입력기로 글자를 조합하는 동안, 대화 상자나 메뉴가 열려 있는 동안에는 단축키가 일시 중지됩니다.

## 팝업과 사이드 패널 [#popup-and-side-panel]

검색창에 마우스를 올리면 단축키 안내가 표시됩니다.

| 키 | 동작 |
| --- | --- |
| `/` | 검색창으로 포커스 이동 |
| 검색창에서 `Esc` | 검색어 지우기. 한 번 더 누르면 검색창에서 나감 |
| 검색창에서 `↓` | 첫 번째 폴더로 이동 |
| 빈 검색창에서 `Alt+↓` | 최근 검색 표시. `↓` / `↑`로 고르고, `Enter`로 검색하며, `Tab`으로 **지우기**로 이동 |
| `↓` / `↑`, `Home` / `End` | 표시된 폴더와 북마크 사이를 이동(첫 번째 행에서 `↑`를 누르면 검색창으로 돌아감) |
| `→` / `←` | 폴더 열기 또는 닫기. 열린 폴더에서 `→`는 첫 번째 항목으로, `←`는 상위 폴더로 이동 |
| 폴더에서 `Enter` | 현재 페이지를 그 폴더에 저장(이미 저장된 페이지는 중복 저장하지 않음) |
| 북마크에서 `Enter` | 새 탭에서 열기 |
| 폴더에서 `Space` | 폴더 열기 또는 닫기 |

## 북마크 관리자 [#bookmarks-manager]

관리자에서 `?`를 누르거나 머리글의 키보드 버튼을 클릭하면 이 목록이 표시됩니다.

| 키 | 동작 |
| --- | --- |
| `/` | 제목 필터로 포커스 이동 |
| `Backspace` 또는 `Alt+↑` | 상위 폴더로 이동 |
| `j` / `k` | 다음 또는 이전 표 행으로 이동(폴더 행, 또는 북마크 행의 작업 메뉴) |
| 폴더 행에서 `Enter` | 폴더 열기 |
| `s` | 저장된 검색 열기 |
| `?` | 키보드 단축키 표시 |
| `Esc` | 대화 상자나 메뉴 닫기 |

표에서 열 머리글의 가장자리에 포커스를 두고 `←` 또는 `→`를 누르면 해당 열의 너비가 조절됩니다.

키보드 단축키는 Chromium과 Edge 자동 테스트로 확인하며, Firefox 테스트에서는 확인하지 않습니다.
