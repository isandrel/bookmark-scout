## Full description: Chrome Web Store and Edge Add-ons

The same Edge condition as in `en.md` applies.

```text
Bookmark Scout(북마크 스카우트)는 툴바에서 또는 키보드 단축키 하나로 모든 페이지를 몇 초 만에 알맞은 폴더에 저장하고, 브라우저를 떠나지 않고 북마크를 찾고 정돈할 수 있게 도와주는 확장 프로그램입니다. 무료이며, 계정도 광고도 없습니다.

알맞은 폴더에 몇 초 만에 저장
• Bookmark Scout 버튼을 클릭하고 폴더 이름의 일부를 입력하면 트리 깊숙이 있는 폴더도 찾아, 키보드에서 손을 떼지 않고 페이지를 저장
• 레시피/파스타 같은 경로도 입력 가능(오타가 조금 있어도 폴더를 찾고, 최근 사용한 폴더가 먼저 표시됨)
• 이미 그 폴더에 있는 페이지는 중복 저장하지 않음
• 선택형 AI가 페이지에 가장 알맞은 폴더를 추천하거나, 만들기 전에 검토하는 새 폴더를 제안
• 선택형 오른쪽 클릭 메뉴(처음에는 꺼져 있으며, 설정에서 '마우스 오른쪽 버튼 메뉴'를 켜서 사용)로 링크를 최근 폴더에 저장

빠른 저장 단축키
• 아무 페이지에서나 Alt+Shift+S를 눌러 Bookmark Scout를 열지 않고 저장: 기본적으로 페이지에 가장 잘 맞는 폴더(기기 안에서 판단)에 저장하며, 마지막으로 사용한 폴더나 직접 고른 폴더로 바꿀 수 있음
• 페이지에 작은 알림이 표시되어 저장한 위치를 알려 주고, 실행 취소와 옮길 수 있는 다른 폴더를 제공
• AI를 켜면 Alt+Shift+D로 페이지를 첫 번째 AI 추천 폴더에 저장
• 키는 브라우저의 단축키 페이지에서 변경. 그곳에서 빠른 저장에 Ctrl+D(Mac에서는 ⌘D)를 지정해 브라우저의 북마크 대화상자 대신 사용할 수도 있으며, 방법은 설정에서 안내

북마크 찾기
• 툴바에서 바로, 입력하는 즉시 모든 북마크를 검색
• 드래그 앤 드롭, 모두 펼치기/접기, 새 폴더 만들기를 지원하는 폴더 트리
• 같은 트리, 검색, 폴더 일치 항목을 쓰는 사이드 패널
• 삭제 전 확인(기본값 켜짐)과 10초 실행 취소

북마크 관리자
Bookmark Scout는 브라우저의 북마크 페이지를 브라우저 자체 관리자처럼 동작하는 관리자로 바꾸고, 이동 경로, 정렬 가능한 표, 항상 최신 결과를 보여 주는 저장된 검색을 더합니다.
• 북마크, 폴더, 빈 공간의 오른쪽 클릭 메뉴: 편집, 이름 바꾸기, 잘라내기, 복사, 붙여넣기, 새 탭이나 새 창에서 열기, 폴더에서 보기, 삭제
• 드래그 앤 드롭으로 북마크를 폴더로 옮기거나 순서 변경(다른 페이지에서 끌어 온 링크는 북마크가 됨)
• Ctrl+클릭과 Shift+클릭으로 여러 행을 선택하고, 브라우저 자체 관리자와 같은 키보드 단축키 사용(Mac에서는 Cmd): Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V, Delete, 실행 취소는 Ctrl+Z, 다시 실행은 Ctrl+Shift+Z
• 편집, 이동, 정렬, 삭제를 실행 취소하고 다시 실행 가능('AI에게 묻기'가 한 변경 포함)
• 오른쪽 클릭 메뉴와 ⋯ 메뉴에 표시할 명령과 그 순서를 선택(설정)

몇 년 치 북마크를 깔끔하게
• 중복 정리: 중복 그룹을 검토한 뒤 남는 사본 삭제
• URL 정리: 웹 주소에 붙은 추적 코드를 미리 보고 제거
• 깨진 링크 확인: 더 이상 열리지 않는 링크를 찾고, 복구 방법(삭제, 새 주소 사용, 보관된 사본 연결, 직접 수정)을 검토해 적용하며 실행 취소 가능
• 메타데이터 가져오기: 페이지 제목을 제안하고 고른 것만 적용
• 개인정보 스캐너: 이메일 주소나 링크 속 로그인 코드 같은 개인 정보를 북마크에서 찾기
• 통계: 사이트, 폴더, 깊이, 중복
• 사이트 아이콘 새로 고침: 타사 아이콘 서비스 없이 각 사이트의 자체 아이콘을 가져오기
• 북마크 파일 가져오기(미리 보기, 중복 처리 선택, 실행 취소 지원)
• HTML, JSON, Markdown, CSV로 내보내기(개인 정보를 가릴 수 있는 선택형 개인정보 검토 포함)

브라우저가 요청하는 권한과 그 이유
설치할 때 브라우저는 "북마크 조회 및 변경" 한 가지만 요청합니다. Bookmark Scout가 북마크를 저장하고, 검색하고, 정리하는 데 필요한 권한입니다. 그 밖의 권한은 필요한 기능을 사용할 때만, 짧은 설명을 먼저 보여 준 뒤에 요청합니다. 거부하면 해당 기능만 꺼진 상태로 유지됩니다.
• "방문하는 웹사이트의 아이콘 조회": '사이트 아이콘 새로 고침'에서 '브라우저 아이콘 표시'를 클릭하거나 '브라우저 아이콘 캐시 사용'을 켤 때 요청하며, 브라우저가 이미 저장한 아이콘을 북마크 옆에 표시합니다
• "모든 example.com 사이트의 데이터를 읽고 변경"(또는 "여러 웹사이트의 데이터를 읽고 변경"): 깨진 링크 확인, 메타데이터 가져오기, 사이트 아이콘 새로 고침을 실행할 때 그 실행에 포함된 사이트에 대해서만 요청합니다. 20개가 넘는 사이트를 대상으로 하는 실행과 AI 설정의 '페이지 내용 읽기'는 "모든 웹사이트에 있는 전체 내 데이터 읽기 및 변경"을 요청합니다. 요청은 쿠키 없이 전송됩니다. 모든 웹사이트에 대한 접근을 허용하면 'AI에게 묻기'도 북마크한 링크가 아직 작동하는지 확인할 수 있습니다
• "방문 기록 확인": 사이드 패널에서 현재 페이지를 저장하거나 폴더 추천을 받을 때만 요청합니다. 툴바 버튼과 빠른 저장 단축키는 권한이 필요 없으며, Bookmark Scout는 열려 있는 탭의 제목과 주소만 읽습니다
• "협력 중인 기본 애플리케이션과 통신": '로컬 AI 에이전트'를 켤 때만 요청합니다(아래 '개발자용' 참고)
오른쪽 클릭 메뉴도 선택 권한이지만 경고가 없으므로 브라우저가 묻지 않고 추가합니다.

개인정보
• 계정, 분석, 추적, 광고가 없습니다
• 북마크는 브라우저 안에 머물고, 태그, 요약, 저장된 검색은 이 기기에만 보관됩니다
• 변경한 설정과 사용자 지정 프롬프트는 지원하는 브라우저에서 브라우저 계정을 통해 동기화됩니다

선택형 AI(기본값 꺼짐)
AI는 선택 사항이며, 위의 모든 기능은 AI 없이 동작합니다. AI를 쓰려면 AI 회사의 계정이 필요하며 사용할 때마다 약간의 요금이 들 수 있습니다. 내 컴퓨터에서 실행하는 무료 AI 프로그램을 쓸 수도 있습니다. Bookmark Scout에는 자체 AI 서비스가 없으므로, 설정에서 AI를 켜고 선택한 서비스를 추가하세요.
• 현재 페이지에 맞는 폴더 추천(새 폴더도 먼저 검토한 뒤 생성)
• 저장하기 전에 검토하는 태그 추천과 짧은 요약
• 폴더 재구성 계획(변경하기 전에 항상 미리 보기)
• AI에게 묻기: 북마크에 대해 채팅합니다. 단어, 폴더, 태그, 사이트, 추가한 날짜로 북마크를 검색하고, 중복을 찾고, 폴더를 추천하고, 현재 페이지를 살펴볼 수 있습니다
• 'AI에게 묻기'는 요청할 때만 변경합니다. 페이지를 저장하고, 이동, 이름 바꾸기, 삭제, 새 폴더를 계획으로 제안하며, 승인하기 전까지는 아무것도 변경되지 않습니다. 모든 변경은 실행 취소할 수 있습니다
• 답변 끝에 버튼이 표시될 수 있습니다: 후속 질문, 고를 수 있는 선택지, 추천 폴더에 페이지 저장, 북마크 열기. 클릭하기 전에는 아무 일도 일어나지 않습니다
• 'AI에게 묻기'가 조회하거나 변경할 수 있는 항목 선택(설정 > AI)
• 페이지 내용 읽기(기본값 꺼짐): 제목과 주소뿐 아니라 각 페이지의 본문도 보내 더 나은 제안을 받습니다

AI 기능을 사용하면 해당 기능에 필요한 데이터가 브라우저에서 사용자가 선택한 AI 서비스로 직접 전송되며, 해당 서비스의 약관에 따라 처리됩니다. 전송되는 데이터는 북마크 제목, 주소, 폴더 이름, 북마크를 추가한 날짜, 저장된 태그와 요약, 현재 페이지의 제목과 주소, 'AI에게 묻기' 메시지, 'AI에게 묻기'가 확인한 링크의 작동 여부이며, '페이지 내용 읽기'를 켠 경우에만 관련 페이지의 본문도 포함됩니다. Bookmark Scout로는 아무것도 전송되지 않습니다. API 키는 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. AI 서비스 사용에는 요금이 발생할 수 있습니다.

설정 및 백업
• 설정 맨 아래의 '설정 백업'으로 변경한 설정, 사용자 지정 프롬프트, AI 서비스(키는 제외), 저장된 검색, 관리자의 열 구성을 파일로 저장. '설정 복원'으로 되돌림
• 변경한 설정만 저장되므로, 이후 버전에서 개선된 기본값도 그대로 적용됨

개발자용
• 검색 옵션: 대소문자 구분, 단어 단위, 정규식. 관리자 주소에 검색어와 폴더가 유지되므로, 링크로 관리자를 검색 중인 상태(?q=react)로 열 수 있고, 뒤로와 앞으로 이동하면 둘 다 복원됨
• AI 서비스로 클라우드 AI 제공업체, 모든 OpenAI 호환 엔드포인트, 내 컴퓨터에서 실행되는 모델 서버를 사용 가능
• 선택한 북마크를 AI 채팅용 Markdown 또는 XML 컨텍스트로 내보내기(AI 없이 동작하며 아무것도 전송하지 않음)
• 개인정보 스캐너는 민감한 쿼리 매개변수, URL 프래그먼트, UUID도 찾아 줌
• 로컬 AI 에이전트(기본값 꺼짐): Claude Code 같은 컴퓨터의 AI 에이전트가 별도로 설치하는 오픈 소스 bookmark-scout-mcp 프로그램을 통해 북마크를 조회합니다. '변경 허용'도 켜면 북마크를 저장하고 재구성할 수 있으며, 모든 변경은 Bookmark Scout 창에서 승인을 기다립니다
• AGPL-3.0 오픈 소스: https://github.com/isandrel/bookmark-scout

이전 버전에서 업데이트

• 이미 그 폴더에 있는 페이지는 중복 저장하지 않음
• 선택형 AI가 페이지에 가장 알맞은 폴더를 추천하거나, 만들기 전에 검토하는 새 폴더를 제안
• 설정에서 '마우스 오른쪽 버튼 메뉴'를 켜면 오른쪽 클릭 메뉴로 링크를 최근 폴더에 저장

빠른 저장 단축키
• 아무 페이지에서나 Alt+Shift+S를 눌러 Bookmark Scout를 열지 않고 저장: 기본적으로 페이지에 가장 잘 맞는 폴더(기기 안에서 판단)에 저장하며, 마지막으로 사용한 폴더나 직접 고른 폴더로 바꿀 수 있음
• 페이지에 작은 알림이 표시되어 저장한 위치를 알려 주고, 실행 취소와 옮길 수 있는 다른 폴더를 제공
• AI를 켜면 Alt+Shift+D로 페이지를 첫 번째 AI 추천 폴더에 저장
• 키는 설정 > 저장 및 검색 > 키보드 단축키에서 변경

북마크 찾기
• 툴바에서 바로, 입력하는 즉시 모든 북마크를 검색
• 드래그 앤 드롭, 모두 펼치기/접기, 새 폴더 만들기를 지원하는 폴더 트리
• 같은 트리, 검색, 폴더 일치 항목을 Firefox 사이드바에서 사용(웹을 탐색하는 동안 계속 열려 있음)
• 삭제 전 확인(기본값 켜짐)과 10초 실행 취소

북마크 관리자
툴바 팝업이나 사이드바에서 '북마크 관리자 열기'를 누르면 폴더 트리와 정렬 가능한 표를 갖춘 전체 관리자가 새 탭에서 열립니다.
• 북마크, 폴더, 빈 공간의 오른쪽 클릭 메뉴: 편집, 이름 바꾸기, 잘라내기, 복사, 붙여넣기, 열기, 폴더에서 보기, 삭제
• 드래그 앤 드롭으로 북마크를 폴더로 옮기거나 순서 변경(다른 페이지에서 끌어 온 링크는 북마크가 됨)
• Ctrl+클릭과 Shift+클릭으로 여러 행 선택(Mac에서는 Cmd), 일반적인 키로 복사, 잘라내기, 붙여넣기, Ctrl+Z와 Ctrl+Shift+Z로 변경 사항 실행 취소와 다시 실행

Firefox가 요청하는 권한과 그 이유
설치할 때 Firefox는 북마크를 읽고 수정하는 권한 한 가지만 요청합니다. 그 밖의 권한은 필요한 기능을 사용할 때만, 짧은 설명을 먼저 보여 준 뒤에 요청합니다. 거부하면 해당 기능만 꺼진 상태로 유지됩니다.
• 브라우저 탭 접근: 사이드바에서 현재 페이지를 저장하거나 폴더 추천을 받을 때만 요청합니다. 툴바 버튼과 빠른 저장 단축키는 권한이 필요 없습니다
• AI 켜기: Firefox가 인증 정보, 북마크, 탐색 활동(API 키, 북마크와 폴더, 현재 페이지의 제목과 주소)을 공유할지 묻습니다. 확인 창에는 개발자가 이 데이터를 수집하려 한다고 표시되는데, 여기서 개발자는 사용자가 선택한 AI 서비스를 뜻하며, 이 서비스는 브라우저에서 직접 데이터를 받습니다. Bookmark Scout에는 아무것도 전달되지 않습니다
• '페이지 내용 읽기': 모든 웹사이트의 데이터에 접근하는 권한과, 웹사이트 콘텐츠를 AI 서비스와 공유하는 데 대한 동의를 요청합니다
• '서비스 확인': AI 서비스 주소에 대한 접근 권한과, 인증 정보(API 키)를 그 서비스와 공유하는 데 대한 동의를 요청합니다

개인정보
• 계정, 분석, 추적, 광고가 없습니다
• 북마크는 브라우저 안에 머뭅니다
• 변경한 설정과 사용자 지정 프롬프트는 Firefox Sync가 켜져 있으면 동기화됩니다

선택형 AI 폴더 추천(기본값 꺼짐)
AI는 선택 사항이며, 위의 모든 기능은 AI 없이 동작합니다. AI를 쓰려면 AI 회사의 계정이 필요하며 사용할 때마다 약간의 요금이 들 수 있습니다. 내 컴퓨터에서 실행하는 무료 AI 프로그램을 쓸 수도 있습니다. 설정에서 AI를 켜고 선택한 서비스를 추가하세요. 그러면 Bookmark Scout가 팝업에서 또는 AI 빠른 저장 단축키로 현재 페이지에 맞는 폴더를 추천하고, 검토 후 새 폴더를 만들 수도 있습니다.

추천을 요청하면 현재 페이지의 제목과 주소, 그리고 폴더 이름이 브라우저에서 사용자가 선택한 AI 서비스로 직접 전송되며, 해당 서비스의 약관에 따라 처리됩니다. '페이지 내용 읽기'를 켠 경우에만 페이지의 본문도 전송됩니다. Bookmark Scout로는 아무것도 전송되지 않습니다. API 키는 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. AI 서비스 사용에는 요금이 발생할 수 있습니다.

설정 및 백업
• 설정 맨 아래의 '설정 백업'으로 변경한 설정, 사용자 지정 프롬프트, AI 서비스(키는 제외), 저장된 검색을 파일로 저장. '설정 복원'으로 되돌림
• 변경한 설정만 저장되므로, 이후 버전에서 개선된 기본값도 그대로 적용됨

개발자용
• 검색 옵션: 대소문자 구분, 단어 단위, 정규식
• AI 서비스로 클라우드 AI 제공업체, 모든 OpenAI 호환 엔드포인트, 내 컴퓨터에서 실행되는 모델 서버를 사용 가능
• AGPL-3.0 오픈 소스: https://github.com/isandrel/bookmark-scout

이전 버전에서 업데이트
버전 0.3.3은 데이터를 새 형식으로 저장하며 이전 데이터를 변환하지 않습니다. 설정은 기본값으로 돌아가고, AI 서비스와 API 키는 다시 추가해야 하며, 사용자 지정 프롬프트, 저장된 검색, 태그, 요약, 저장된 사이트 아이콘은 삭제됩니다. 북마크 자체는 변경되지 않습니다.

회사도, 광고도, 계정도 없이 독립 개발자가 만듭니다. 9개 언어를 지원합니다. 라이트, 다크, 시스템 테마를 선택할 수 있습니다.
```
