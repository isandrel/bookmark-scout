## Full description: Chrome Web Store and Edge Add-ons

The same Edge condition as in `en.md` applies.

```text
Bookmark Scout(북마크 스카우트)는 툴바에서 또는 키보드 단축키 하나로 모든 페이지를 몇 초 만에 알맞은 폴더에 저장하고, 브라우저를 떠나지 않고 북마크를 찾고 정리할 수 있게 도와주는 확장 프로그램입니다.

알맞은 폴더에 몇 초 만에 저장
• 폴더 이름의 일부를 입력하면 트리 깊숙이 있는 폴더도 찾아, 키보드에서 손을 떼지 않고 현재 페이지를 저장
• work/react 같은 경로도 입력 가능(오타가 조금 있어도 폴더를 찾고, 최근 사용한 폴더가 먼저 표시됨)
• 이미 그 폴더에 있는 페이지는 중복 저장하지 않음
• 선택형 AI가 페이지에 가장 알맞은 폴더를 추천하거나, 만들기 전에 검토하는 새 폴더 경로를 제안
• 오른쪽 클릭 메뉴(설정에서 '컨텍스트 메뉴'를 켜기)로 링크를 최근 폴더에 저장

빠른 저장 단축키
• 아무 페이지에서나 Alt+Shift+S를 눌러 Bookmark Scout를 열지 않고 저장: 기본적으로 페이지에 가장 잘 맞는 폴더(순위는 기기 안에서 계산)에 저장하며, 마지막으로 사용한 폴더나 직접 고른 폴더로 바꿀 수 있음
• 페이지에 작은 알림이 표시되어 저장한 위치를 알려 주고, 실행 취소와 옮길 수 있는 다른 폴더를 제공
• AI를 켜면 Alt+Shift+D로 페이지를 첫 번째 AI 추천 폴더에 저장
• 키는 브라우저의 단축키 페이지에서 변경. 그곳에서 빠른 저장에 Ctrl+D(Mac에서는 ⌘D)를 지정해 브라우저의 북마크 대화상자 대신 사용할 수도 있으며, 방법은 설정에서 안내

툴바에서 검색
• 모든 북마크 즉시 검색(대소문자 구분, 단어 단위, 정규식 지원)
• 드래그 앤 드롭, 모두 펼치기/접기, 새 폴더 만들기를 지원하는 폴더 트리
• 같은 트리, 검색, 폴더 일치 항목을 쓰는 사이드 패널
• 확인 대화상자(기본값 켜짐)와 10초 실행 취소가 있는 삭제

북마크 관리자
Bookmark Scout는 브라우저의 북마크 페이지를 브라우저 자체 관리자처럼 동작하는 관리자로 바꾸고, 이동 경로, 정렬과 필터가 가능한 표, 너비를 조절할 수 있는 열, 저장된 검색(필터만 저장하고 항상 최신 결과를 보여 주는 스마트 보기)을 더합니다.
• 북마크, 폴더, 빈 공간의 오른쪽 클릭 메뉴: 편집, 이름 바꾸기, 잘라내기, 복사, 붙여넣기, 새 탭이나 새 창에서 열기, 폴더에서 보기, 삭제
• 드래그 앤 드롭으로 북마크를 폴더로 옮기거나 순서 변경(다른 페이지에서 끌어 온 링크는 북마크가 됨)
• Ctrl+클릭과 Shift+클릭으로 여러 행을 선택하고, 브라우저 자체 관리자와 같은 키보드 단축키 사용(Mac에서는 Cmd): Ctrl+A, Ctrl+C, Ctrl+X, Ctrl+V, Delete, 실행 취소는 Ctrl+Z, 다시 실행은 Ctrl+Y
• 편집, 이동, 정렬, 삭제를 실행 취소하고 다시 실행 가능('AI에게 묻기'가 한 변경 포함)
• 주소에 검색어와 폴더가 유지되므로, 링크로 관리자를 검색 중인 상태(?q=react)나 특정 폴더에서 바로 열 수 있고, 뒤로와 앞으로 이동하면 둘 다 복원됨
• 오른쪽 클릭 메뉴와 ⋯ 메뉴에 표시할 명령과 그 순서를 선택(설정 > 동작)

유지 관리 도구
• 중복 정리: 중복 그룹을 검토한 뒤 남는 사본 삭제
• URL 정리: 추적 매개변수 제거를 미리 보고 적용
• 깨진 링크 확인: 접속할 수 없는 링크를 찾고, 복구 방법(삭제, 리디렉션 대상 사용, 보관된 사본 연결, URL 편집)을 검토해 적용하며 실행 취소 가능
• 메타데이터 가져오기: 페이지 제목을 제안하고 선택한 것만 적용
• 개인정보 스캐너: 북마크에서 민감한 쿼리 매개변수, URL 프래그먼트, 이메일 주소, UUID 찾기
• 통계: 도메인, 폴더, 깊이, 중복
• 사이트 아이콘 새로 고침: 타사 아이콘 서비스 없이 각 사이트의 자체 아이콘을 가져오기
• HTML 또는 JSON 가져오기(미리 보기, 중복 처리 선택, 실행 취소 지원)
• HTML, JSON, Markdown, CSV로 내보내기(민감한 값을 가릴 수 있는 선택형 개인정보 검토 포함)

깨진 링크 확인, 메타데이터 가져오기, 사이트 아이콘 새로 고침, AI 설정의 '페이지 내용 읽기'는 처음 사용할 때 웹사이트 접근 권한(선택 권한)을 요청합니다. 권한을 허용하면 'AI에게 묻기'도 북마크한 링크가 아직 작동하는지 확인할 수 있습니다. 이 권한은 설치할 때 부여되지 않으며, 요청은 쿠키 없이 전송되고, 거부하면 해당 기능은 꺼진 상태로 유지됩니다.

설정 및 백업
• 설정 맨 아래의 '내보내기'로 백업 저장: 변경한 설정, 사용자 지정 프롬프트, AI 서비스(API 키는 제외), 저장된 검색, 관리자의 열 구성. '가져오기'로 복원
• 변경한 설정만 저장되므로, 이후 버전에서 개선된 기본값도 그대로 적용됨

선택형 AI 도구(기본값 꺼짐)
설정에서 AI를 켜고 클라우드 AI 제공업체, OpenAI 호환 엔드포인트 또는 내 컴퓨터에서 실행되는 모델 서버를 선택하세요. API 키가 필요한 제공업체에는 본인의 키를 사용합니다.
• 현재 페이지에 맞는 폴더 추천(새 폴더 경로도 검토 후 생성)
• 저장하기 전에 검토하는 태그 추천과 짧은 요약
• 폴더 재구성 계획(변경하기 전에 항상 미리 보기)
• 선택한 북마크를 AI 채팅용 Markdown 또는 XML 컨텍스트로 내보내기(AI 없이 동작하며 아무것도 전송하지 않음)
• AI에게 묻기: 북마크에 대해 채팅합니다. AI가 단어, 폴더, 태그, 사이트, 추가한 날짜로 북마크를 검색하고, 중복을 찾고, 폴더를 추천하고, 현재 페이지를 살펴볼 수 있습니다
• 'AI에게 묻기'는 요청할 때만 변경합니다. 페이지를 저장하고, 이동, 이름 바꾸기, 삭제, 새 폴더를 계획으로 제안하며, 승인하기 전까지는 아무것도 변경되지 않습니다. 모든 변경은 실행 취소할 수 있습니다
• 답변 끝에 버튼이 표시될 수 있습니다: 후속 질문, 고를 수 있는 선택지, 추천 폴더에 페이지 저장, 북마크 열기. 클릭하기 전에는 아무 일도 일어나지 않습니다
• 'AI에게 묻기'가 조회하거나 변경할 수 있는 항목 선택(설정 > AI)
• 페이지 내용 읽기(기본값 꺼짐): 제목과 URL뿐 아니라 각 페이지의 본문도 보내 더 나은 제안을 받습니다
• 로컬 AI 에이전트(기본값 꺼짐): Claude Code 같은 컴퓨터의 AI 에이전트가 별도로 설치하는 오픈 소스 bookmark-scout-mcp 프로그램을 통해 북마크를 조회합니다. '변경 허용'도 켜면 북마크를 저장하고 재구성할 수 있으며, 모든 변경은 Bookmark Scout 창에서 승인을 기다립니다

AI 기능을 사용하면 해당 기능에 필요한 데이터가 브라우저에서 사용자가 선택한 제공업체로 직접 전송되며, 해당 제공업체의 약관에 따라 처리됩니다. 전송되는 데이터는 북마크 제목, URL, 폴더 이름, 북마크를 추가한 날짜, 저장된 태그와 요약, 현재 페이지의 제목과 URL, 'AI에게 묻기' 메시지, 'AI에게 묻기'가 확인한 링크의 작동 여부이며, '페이지 내용 읽기'를 켠 경우에만 관련 페이지의 본문도 포함됩니다. Bookmark Scout로는 아무것도 전송되지 않습니다. API 키는 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. 제공업체 사용에는 요금이 발생할 수 있습니다.

개인정보
• 계정, 분석, 추적, 광고가 없습니다
• 북마크는 브라우저 안에 머물고, 태그, 요약, 저장된 검색은 로컬 확장 프로그램 저장소에 보관됩니다
• 변경한 설정과 사용자 지정 프롬프트는 지원하는 브라우저에서 브라우저 계정을 통해 동기화됩니다
• AGPL-3.0 오픈 소스: https://github.com/isandrel/bookmark-scout

이전 버전에서 업데이트
버전 0.3.3은 데이터를 새 형식으로 저장하며 이전 데이터를 변환하지 않습니다. 설정은 기본값으로 돌아가고, AI 서비스와 API 키는 다시 추가해야 하며, 사용자 지정 프롬프트, 저장된 검색, 태그, 요약, 저장된 사이트 아이콘은 삭제됩니다. 북마크 자체는 변경되지 않습니다.

9개 언어를 지원합니다. 라이트, 다크, 시스템 테마를 선택할 수 있습니다.

문서: https://docs.bookmark-scout.com
```

```text
• 변경한 설정만 저장되므로, 이후 버전에서 개선된 기본값도 그대로 적용됨

선택형 AI 폴더 추천(기본값 꺼짐)
설정에서 AI를 켜고 클라우드 AI 제공업체, OpenAI 호환 엔드포인트 또는 내 컴퓨터에서 실행되는 모델 서버를 선택하세요. API 키가 필요한 제공업체에는 본인의 키를 사용합니다. 그러면 Bookmark Scout가 팝업에서 또는 AI 빠른 저장 단축키로 현재 페이지에 맞는 폴더를 추천하고, 검토 후 새 폴더 경로를 만들 수도 있습니다.

추천을 요청하면 현재 페이지의 제목과 URL, 그리고 폴더 이름이 브라우저에서 사용자가 선택한 제공업체로 직접 전송되며, 해당 제공업체의 약관에 따라 처리됩니다. '페이지 내용 읽기'를 켠 경우에만 페이지의 본문도 전송됩니다. Bookmark Scout로는 아무것도 전송되지 않습니다. API 키는 이 브라우저의 로컬 확장 프로그램 저장소에 보관되며 동기화되지 않습니다. 제공업체 사용에는 요금이 발생할 수 있습니다.

개인정보
• 계정, 분석, 추적, 광고가 없습니다
• 북마크는 브라우저 안에 머뭅니다
• 변경한 설정과 사용자 지정 프롬프트는 Firefox Sync가 켜져 있으면 동기화됩니다
• AGPL-3.0 오픈 소스: https://github.com/isandrel/bookmark-scout

이전 버전에서 업데이트
버전 0.3.3은 데이터를 새 형식으로 저장하며 이전 데이터를 변환하지 않습니다. 설정은 기본값으로 돌아가고, AI 서비스와 API 키는 다시 추가해야 하며, 사용자 지정 프롬프트, 저장된 검색, 태그, 요약, 저장된 사이트 아이콘은 삭제됩니다. 북마크 자체는 변경되지 않습니다.
```
