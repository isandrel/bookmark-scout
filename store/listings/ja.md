## Full description: Chrome Web Store and Edge Add-ons

Plain text, 5,875 characters (2026-10-23); the Chrome Web Store allows 16,000. The same Edge condition as in `en.md` applies.

```text
Bookmark Scout（ブックマークスカウト）は、ツールバーから、またはキーボードショートカット 1 つで、どのページも数秒で正しいフォルダに保存し、ブラウザを離れずにブックマークを探して整理できる拡張機能です。無料で、アカウントも広告もありません。

数秒で正しいフォルダに保存
• Bookmark Scout のボタンをクリックしてフォルダ名の一部を入力すれば、ツリーの深い階層にあるフォルダでも見つかり、キーボードから手を離さずにページを保存
• ai/llms のようなパスでも入力可能。少しの入力ミスがあってもフォルダが見つかり、最近使ったフォルダが先頭に表示
• すでにそのフォルダにあるページは重複保存しません
• AI（任意）がページに最適なフォルダを提案。新しいフォルダは確認してから作成
• 右クリックメニュー（最初はオフ。設定で「右クリックメニュー」をオン）から、リンクや表示中のページを最近使ったフォルダに保存

クイック保存ショートカット
• どのページでも Mac の ⌥⇧S（Windows と Linux の Alt+Shift+S）を押すと、Bookmark Scout を開かずにページを保存。既定ではページに最も一致するフォルダ（判定はこの端末上で実行）に、または最後に使ったフォルダや指定のフォルダに保存
• ページ内の小さな通知に保存先が表示され、「元に戻す」と、移動先にできる別のフォルダも選べます
• AI をオンにすると、Mac の ⌥⇧D（Windows と Linux の Alt+Shift+D）で AI が最初に提案したフォルダにページを保存
• キーはブラウザのショートカットのページで変更できます。そこでクイック保存に Mac の ⌘D（Windows と Linux の Ctrl+D）を割り当てて、ブラウザのブックマークダイアログの代わりに使うこともできます。手順は設定に表示されます

ブックマークを探す
• ツールバーからすぐに、入力と同時にすべてのブックマークを検索。タイトル、アドレス、フォルダ、タグ、要約が対象で、tag:、domain:、folder: などの演算子も使えます
• ドラッグ＆ドロップ、すべて展開／折りたたみ、新規フォルダ作成ができるフォルダツリー
• 同じツリー、検索、フォルダの候補を使えるサイドパネル
• ブックマークにポインターを合わせると、アドレス、フォルダ、タグ、要約を表示
• 確認（既定でオン）と 10 秒間の元に戻す付きの削除

ブックマークマネージャー
ブラウザの「ブックマーク」ページを、ブラウザ標準のマネージャーと同じように使えるマネージャーに置き換えます。さらに、パンくずリスト、並べ替えができる表、常に最新の結果を表示する保存した検索を備えています。
• ブックマーク、フォルダ、空白部分の右クリックメニュー：編集、名前を変更、切り取り、コピー、貼り付け、新しいタブやウィンドウで開く、フォルダ内に表示、削除
• ドラッグ＆ドロップでブックマークをフォルダへ移動したり並べ替えたりできます。ほかのページからドロップしたリンクはブックマークになります
• Cmd+クリックと Shift+クリックで複数の行を選択し、ブラウザ標準のマネージャーと同じキーボードショートカットを使えます：Mac の ⌘A、⌘C、⌘X、⌘V、⌘⌫、⌘Z で元に戻す、⇧⌘Z でやり直す（Windows と Linux の Ctrl+クリック、Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、Delete、Ctrl+Z、Ctrl+Shift+Z）
• 元に戻す・やり直しは、編集、移動、並べ替え、削除に対応し、「AI に質問」による変更も対象です
• フォルダや検索結果を、リスト、またはページのカバー画像、タグ、要約付きのカードで表示。ブックマークを開かずにプレビューも可能
• ブックマークの履歴：ブックマークへのすべての変更を、各項目の変更前の状態とともに表示。元に戻すことができ、元に戻せなくなった後も削除した項目を復元できます
• マネージャーとポップアップのメニュー、列、カード、サイドバー、キーボードショートカットを設定で調整

何年分ものブックマークを片付ける
• 重複クリーナー：重複グループを確認し、残すコピーを選んで削除
• URLクリーナー：ウェブアドレスに含まれるトラッキング用のコードの削除をプレビューして適用
• リンク切れチェック：もう使えないリンクを検出し、修復（削除、新しいアドレスの使用、アーカイブ版へのリンク、アドレスの編集）を確認してから適用、元に戻すも可能
• メタデータ取得：ページタイトルを提案し、選んだものだけを適用
• プライバシースキャナー：メールアドレスやリンクに含まれるログイン用のコードなど、ブックマーク内の個人的な情報を検出
• 統計：サイト、フォルダ、階層の深さ、重複
• サイトアイコンを更新：サードパーティのアイコンサービスを使わず、各サイト自身のアイコンを取得
• スマートルール：検索に一致するブックマークにタグを付け、フォルダへ移動。確認してから適用するほか、オンにすれば新しいブックマークにも適用
• ページ本文の索引：選んだページの本文をこの端末に保存し、ページ内の言葉でも検索できるようにします
• カバー画像の取得：各ページのプレビュー画像をこの端末に保存し、カード表示に使います。「閲覧中にカバー画像を撮影」（既定でオフ）をオンにすると、ブックマークしたページを開いたときに撮影します
• 時間のかかるツールはマネージャーを閉じてもバックグラウンドで続行し、一時停止と再開ができます。どの確認画面でも複数の項目をまとめて設定できます
• ブックマークファイルのインポート（プレビュー、重複の扱いの選択、元に戻すに対応）
• HTML、JSON、Markdown、CSV へのエクスポート（個人的な情報を隠せるプライバシー確認付き）

ブラウザが確認する内容とその理由
インストール時にブラウザが求めるのは 1 つだけです：「ブックマークの読み取りと変更」。これにより、Bookmark Scout がブックマークを保存、検索、整理できます。それ以外はすべて、必要な機能を使うときにだけ、短い説明の後に求めます。許可しなかった場合は、その機能だけがオフのままになります。
• 「アクセスしたウェブサイトのアイコンの読み取り」：「サイトアイコンを更新」で「ブラウザのアイコンを表示」をクリックしたとき、または「ブラウザのアイコンキャッシュを使う」をオンにしたとき。ブラウザがすでに保存しているアイコンをブックマークの横に表示するためです
• 「example.com の全サイト 上にある自分のデータの読み取りと変更」（または「多数のウェブサイト上にある自分のデータの読み取りと変更」）：リンク切れチェック、メタデータ取得、サイトアイコンを更新、ページ本文の索引、カバー画像の取得を実行したとき。対象はその実行のサイトだけです。20 を超えるサイトにわたる実行、AI 設定の「ページの内容を読む」、「閲覧中にカバー画像を撮影」は、「すべてのウェブサイト上にある自分の全データの読み取りと変更」を求めます。「閲覧中にカバー画像を撮影」で撮影した画像はこの端末に保存されます。リクエストは Cookie なしで送信されます。すべてのウェブサイトを許可すると、「AI に質問」でもブックマークしたリンクがまだ有効かどうかを確認できます
• 「閲覧履歴の読み取り」：サイドパネルから表示中のページを保存するときや、フォルダの提案を受けるときだけ。ツールバーのボタンとクイック保存ショートカットには権限が不要で、Bookmark Scout が読み取るのは開いているタブのタイトルとアドレスだけです
• 「連携するネイティブ アプリケーションと通信」：ローカル AI エージェントをオンにしたときだけ（下の「開発者向け」を参照）
右クリックメニューも任意の権限ですが、警告がないため、ブラウザは確認せずに追加します。

プライバシー
• アカウント登録、アナリティクス、トラッキング、広告はありません
• ブックマークはブラウザ内にとどまり、タグ、要約、保存した検索、スマートルール、ページ本文、カバー画像、ブックマークの履歴はこの端末に保存されます
• 変更した設定、カスタムプロンプト、自己紹介は、対応するブラウザではブラウザのアカウントを通じて同期されます

AI（任意、既定でオフ）
AI は任意で、ここまでの機能はすべて AI なしで使えます。AI を使うには、AI 会社のアカウント（使うたびに少額の料金がかかる場合があります）か、自分のコンピューターで動く無料の AI プログラムが必要です。Bookmark Scout には独自の AI サービスはありません。設定で AI をオンにし、選んだサービスを追加してください。
• 表示中のページに合うフォルダの提案（新しいフォルダも先に確認してから作成）
• Chrome では、Chrome の内蔵 AI による無料のフォルダの提案。パソコン上で動き、アカウントもキーも不要です（そのパソコンで動かせる場合）
• 保存前に確認できるタグ候補と短い要約
• フォルダ再編成プラン（必ず適用前にプレビュー）
• AI に質問：ブックマークについてチャットできます。キーワード、フォルダ、タグ、サイト、追加日でブックマークを検索し、重複を見つけ、フォルダを提案し、表示中のページを参照できます
• 「AI に質問」が変更を行うのは依頼したときだけです。ページを保存し、移動、名前の変更、削除、新しいフォルダはプランとして提案します。プランは承認するまで何も変更しません。変更はすべて元に戻せます
• 回答の最後にボタンが表示されることがあります：追加の質問、選択肢、提案されたフォルダへのページの保存、ブックマークを開く。クリックするまで何も実行されません
• 「AI に質問」で調べられることと変更できることを選択（設定 > AI）
• ページの内容を読む（既定でオフ）：タイトルとアドレスに加えて各ページの本文も送信し、提案の精度を高めます
• タグ、要約、新しいフォルダ名を、あなたの言語、選んだ言語、または各ページの言語で返します（設定 > AI）

AI 機能を使うと、その機能に必要なデータがブラウザから選択した AI サービスへ直接送信され、そのサービスの規約に従って扱われます。送信されるのは、ブックマークのタイトル、アドレス、フォルダ名、ブックマークの追加日、保存したタグと要約、表示中のページのタイトルとアドレス、「AI に質問」のメッセージ、自己紹介に書いた内容（ある場合）、「AI に質問」が確認したリンクがまだ有効かどうか、そして「ページの内容を読む」をオンにした場合のみ対象ページの本文です。Bookmark Scout には何も送信されません。API キーはこのブラウザのローカル拡張機能ストレージに保存され、同期されません。AI サービスの利用には料金がかかる場合があります。

設定とバックアップ
• 設定の下部にある「設定をバックアップ」で、選んだ部分をファイルに保存します：設定、このパソコンの設定、保存した検索と表の表示、プロンプトと自己紹介、スマートルール、AI サービス、カバー画像。API キーは選んだ場合だけ含まれ、その場合はパスワードで保護されます
• 「設定を復元」は、各部分で何が変わるかを先に表示してから統合または置換し、「インポートを元に戻す」で元に戻せます
• 保存されるのは変更した設定だけなので、今後のバージョンで改善された既定値もそのまま反映されます

開発者向け
• 検索演算子：title:、url:、domain:、folder:、tag:、summary:、content:（ページ本文）、is:、has:、after:、before:、-（除外）、OR、かっこ。ほかに大文字と小文字の区別、単語単位、正規表現の検索オプション。マネージャーのアドレスに検索とフォルダが保持されるため、リンクから検索済みの状態（?q=react）で開けます。戻る・進むで両方が復元されます
• AI サービスには、クラウドの AI プロバイダー、OpenAI 互換の任意のエンドポイント、自分のコンピューターで動くモデルサーバーを、API キーの有無にかかわらず使えます
• 選択したブックマークを AI チャット用の Markdown または XML としてエクスポート（AI なしで使え、何も送信しません）
• プライバシースキャナーは、機密性の高いクエリパラメータ、URL フラグメント、UUID も検出します
• ローカル AI エージェント（既定でオフ）：Claude Code などコンピューター上の AI エージェントが、別途インストールするオープンソースの bookmark-scout-mcp プログラムを通じてブックマークを調べられます。「変更を許可」もオンにすると、ブックマークの保存や整理もでき、変更はすべて Bookmark Scout のウィンドウであなたの承認を待ちます
• AGPL-3.0 のオープンソース：https://github.com/isandrel/bookmark-scout

以前のバージョンからの更新
バージョン 0.3.3 はデータを新しい形式で保存し、以前のデータは変換しません。設定は既定値に戻り、AI サービスと API キーは追加し直す必要があります。カスタムプロンプト、保存した検索、タグ、要約、保存したサイトアイコンは消去されます。ブックマーク自体は変更されません。

個人の開発者が制作しています。企業ではなく、広告もアカウントもありません。12 言語に対応。ライト、ダーク、システムのテーマを選べます。

ドキュメント：https://docs.bookmark-scout.com
```

• アカウント登録、アナリティクス、トラッキング、広告はありません
• ブックマークはブラウザ内にとどまります
• 変更した設定、カスタムプロンプト、自己紹介は、Firefox Sync が有効な場合に同期されます

AI によるフォルダ提案（任意、既定でオフ）
AI は任意で、ここまでの機能はすべて AI なしで使えます。AI を使うには、AI 会社のアカウント（使うたびに少額の料金がかかる場合があります）か、自分のコンピューターで動く無料の AI プログラムが必要です。設定で AI をオンにし、選んだサービスを追加してください。ポップアップで、または AI クイック保存ショートカットで、表示中のページに合うフォルダを提案し、確認後に新しいフォルダを作成することもできます。

提案を求めると、表示中のページのタイトルとアドレス、およびフォルダ名が、ブラウザから選択した AI サービスへ直接送信され、そのサービスの規約に従って扱われます。「ページの内容を読む」をオンにした場合のみ、ページの本文も送信されます。Bookmark Scout には何も送信されません。API キーはこのブラウザのローカル拡張機能ストレージに保存され、同期されません。AI サービスの利用には料金がかかる場合があります。

設定とバックアップ
• 設定の下部にある「設定をバックアップ」で、選んだ部分をファイルに保存します：設定、このパソコンの設定、保存した検索と表の表示、プロンプトと自己紹介、AI サービスなど。API キーは選んだ場合だけ含まれ、その場合はパスワードで保護されます
• 「設定を復元」は、各部分で何が変わるかを先に表示してから統合または置換し、「インポートを元に戻す」で元に戻せます
• 保存されるのは変更した設定だけなので、今後のバージョンで改善された既定値もそのまま反映されます

開発者向け
• 検索演算子：title:、url:、domain:、folder:、tag:、summary:、is:、has:、after:、before:、-（除外）、OR、かっこ。ほかに大文字と小文字の区別、単語単位、正規表現の検索オプション
• AI サービスには、クラウドの AI プロバイダー、OpenAI 互換の任意のエンドポイント、自分のコンピューターで動くモデルサーバーを、API キーの有無にかかわらず使えます
• AGPL-3.0 のオープンソース：https://github.com/isandrel/bookmark-scout

• カバー画像とカード：ブックマークマネージャーでフォルダを、ページのカバー画像、タグ、要約付きのカードで表示できます。カバー画像は、ページ自身のプレビュー画像、選んだタブの画像、またはオンにした場合は閲覧中に撮影した画像から作られ、この端末に保存されます
