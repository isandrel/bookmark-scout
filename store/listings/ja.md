## Full description: Chrome Web Store and Edge Add-ons

The same Edge condition as in `en.md` applies.

```text
Bookmark Scout（ブックマークスカウト）は、ツールバーから、またはキーボードショートカット 1 つで、どのページも数秒で正しいフォルダに保存し、ブラウザを離れずにブックマークを探して整理できる拡張機能です。

数秒で正しいフォルダに保存
• フォルダ名の一部を入力すれば、ツリーの深い階層にあるフォルダでも見つかり、キーボードから手を離さずに表示中のページを保存
• work/react のようなパスでも入力可能。少しの入力ミスがあってもフォルダが見つかり、最近使ったフォルダが先頭に表示
• すでにそのフォルダにあるページは重複保存しません
• AI（任意）がページに最適なフォルダを提案。新しいフォルダパスは確認してから作成
• 右クリックメニュー（設定で「コンテキストメニュー」をオン）からリンクを最近使ったフォルダに保存

クイック保存ショートカット
• どのページでも Alt+Shift+S を押すと、Bookmark Scout を開かずにページを保存。既定ではページに最も一致するフォルダ（判定はこの端末上で実行）に、または最後に使ったフォルダや指定のフォルダに保存
• ページ内の小さな通知に保存先が表示され、「元に戻す」と、移動先にできる別のフォルダも選べます
• AI をオンにすると、Alt+Shift+D で AI が最初に提案したフォルダにページを保存
• キーはブラウザのショートカットのページで変更できます。そこでクイック保存に Ctrl+D（Mac では ⌘D）を割り当てて、ブラウザのブックマークダイアログの代わりに使うこともできます。手順は設定に表示されます

ツールバーから検索
• すべてのブックマークを即時検索（大文字と小文字の区別、単語単位、正規表現に対応）
• ドラッグ＆ドロップ、すべて展開／折りたたみ、新規フォルダ作成ができるフォルダツリー
• 同じツリー、検索、フォルダの候補を使えるサイドパネル
• 確認ダイアログ（既定でオン）と 10 秒間の元に戻す付きの削除

ブックマークマネージャー
ブラウザの「ブックマーク」ページを、ブラウザ標準のマネージャーと同じように使えるマネージャーに置き換えます。さらに、パンくずリスト、並べ替えと絞り込みができる表、幅を変えられる列、保存した検索（条件だけを保存し、常に最新の結果を表示するスマートビュー）を備えています。
• ブックマーク、フォルダ、空白部分の右クリックメニュー：編集、名前を変更、切り取り、コピー、貼り付け、新しいタブやウィンドウで開く、フォルダ内に表示、削除
• ドラッグ＆ドロップでブックマークをフォルダへ移動したり並べ替えたりできます。ほかのページからドロップしたリンクはブックマークになります
• Ctrl+クリックと Shift+クリックで複数の行を選択し、ブラウザ標準のマネージャーと同じキーボードショートカットを使えます（Mac では Cmd）：Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、Delete、Ctrl+Z で元に戻す、Ctrl+Y でやり直す
• 元に戻す・やり直しは、編集、移動、並べ替え、削除に対応し、「AI に質問」による変更も対象です
• アドレスに検索とフォルダが保持されるため、リンクからマネージャーを検索済みの状態（?q=react）やフォルダを開いた状態で開けます。戻る・進むで両方が復元されます
• 右クリックメニューと ⋯ メニューに表示するコマンドとその順序を選択（設定 > 動作）

メンテナンスツール
• 重複クリーナー：重複グループを確認してから余分なコピーを削除
• URLクリーナー：トラッキングパラメータの削除をプレビューして適用
• リンク切れチェック：アクセスできないリンクを検出し、修復（削除、リダイレクト先の使用、アーカイブ版へのリンク、URL の編集）を確認してから適用、元に戻すも可能
• メタデータ取得：ページタイトルを提案し、選んだものだけを適用
• プライバシースキャナー：ブックマーク内の機密性の高いクエリパラメータ、URL フラグメント、メールアドレス、UUID を検出
• 統計：ドメイン、フォルダ、階層の深さ、重複
• サイトアイコンを更新：サードパーティのアイコンサービスを使わず、各サイト自身のアイコンを取得
• HTML または JSON からのインポート（プレビュー、重複の扱いの選択、元に戻すに対応）
• HTML、JSON、Markdown、CSV へのエクスポート（機密値を伏せ字にできるプライバシー確認付き）

リンク切れチェック、メタデータ取得、サイトアイコンを更新、および AI 設定の「ページの内容を読む」は、初回使用時にウェブサイトへのアクセス（任意の権限）を求めます。許可すると、「AI に質問」でもブックマークしたリンクがまだ有効かどうかを確認できます。インストール時には付与されず、リクエストは Cookie なしで送信され、拒否した場合はその機能がオフのままになります。

設定とバックアップ
• 設定の下部にある「エクスポート」でバックアップを保存：変更した設定、カスタムプロンプト、AI サービス（API キーは含みません）、保存した検索、マネージャーの列。「インポート」で復元できます
• 保存されるのは変更した設定だけなので、今後のバージョンで改善された既定値もそのまま反映されます

オプトインの AI ツール（既定でオフ）
設定で AI を有効にし、クラウドの AI プロバイダー、OpenAI 互換のエンドポイント、または自分のコンピューターで動くモデルサーバーを選びます。API キーが必要なプロバイダーでは自分のキーを使います。
• 表示中のページに合うフォルダの提案（新しいフォルダパスも確認後に作成）
• 保存前に確認できるタグ候補と短い要約
• フォルダ再編成プラン（必ず適用前にプレビュー）
• 選択したブックマークを AI チャット用の Markdown または XML としてエクスポート（AI なしで使え、何も送信しません）
• AI に質問：ブックマークについてチャットできます。AI はキーワード、フォルダ、タグ、サイト、追加日でブックマークを検索し、重複を見つけ、フォルダを提案し、表示中のページを参照できます
• 「AI に質問」が変更を行うのは依頼したときだけです。ページを保存し、移動、名前の変更、削除、新しいフォルダはプランとして提案します。プランは承認するまで何も変更しません。変更はすべて元に戻せます
• 回答の最後にボタンが表示されることがあります：追加の質問、選択肢、提案されたフォルダへのページの保存、ブックマークを開く。クリックするまで何も実行されません
• 「AI に質問」で調べられることと変更できることを選択（設定 > AI）
• ページの内容を読む（既定でオフ）：タイトルと URL に加えて各ページの本文も送信し、提案の精度を高めます
• ローカル AI エージェント（既定でオフ）：Claude Code などコンピューター上の AI エージェントが、別途インストールするオープンソースの bookmark-scout-mcp プログラムを通じてブックマークを調べられます。「変更を許可」もオンにすると、ブックマークの保存や整理もでき、変更はすべて Bookmark Scout のウィンドウであなたの承認を待ちます

AI 機能を使うと、その機能に必要なデータがブラウザから選択したプロバイダーへ直接送信され、そのプロバイダーの規約に従って扱われます。送信されるのは、ブックマークのタイトル、URL、フォルダ名、ブックマークの追加日、保存したタグと要約、表示中のページのタイトルと URL、「AI に質問」のメッセージ、「AI に質問」が確認したリンクがまだ有効かどうか、そして「ページの内容を読む」をオンにした場合のみ対象ページの本文です。Bookmark Scout には何も送信されません。API キーはこのブラウザのローカル拡張機能ストレージに保存され、同期されません。プロバイダーの利用には料金がかかる場合があります。

プライバシー
• アカウント登録、アナリティクス、トラッキング、広告はありません
• ブックマークはブラウザ内にとどまり、タグ、要約、保存した検索はローカル拡張機能ストレージに保存されます
• 変更した設定とカスタムプロンプトは、対応するブラウザではブラウザのアカウントを通じて同期されます
• AGPL-3.0 のオープンソース：https://github.com/isandrel/bookmark-scout

以前のバージョンからの更新
バージョン 0.3.3 はデータを新しい形式で保存し、以前のデータは変換しません。設定は既定値に戻り、AI サービスと API キーは追加し直す必要があります。カスタムプロンプト、保存した検索、タグ、要約、保存したサイトアイコンは消去されます。ブックマーク自体は変更されません。

9 言語に対応。ライト、ダーク、システムのテーマを選べます。

ドキュメント：https://docs.bookmark-scout.com
```

## What's new in 0.3.3
