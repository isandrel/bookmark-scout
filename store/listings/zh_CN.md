## Full description: Chrome Web Store and Edge Add-ons

The same Edge condition as in `en.md` applies.

```text
Bookmark Scout 可以通过工具栏或一个键盘快捷键，在几秒钟内把每个网页保存到合适的文件夹，并且无需离开浏览器就能查找和整理书签。免费使用，无需账号，没有广告。

几秒钟内保存到合适的文件夹
• 点击 Bookmark Scout 按钮，输入任意文件夹名称的一部分，即使是文件夹树深处的文件夹也能找到，无需离开键盘就能将网页保存到那里
• 输入 ai/llms 这样的路径；有小的拼写错误也能找到文件夹，最近使用过的文件夹排在前面
• 已在该文件夹中的网页不会重复保存
• 可选的 AI 会为网页建议最合适的文件夹，或建议一个新文件夹，经确认后才会创建
• 可选的右键菜单（默认关闭；在设置中开启“右键菜单”），可将链接或当前页面保存到最近使用的文件夹

快速保存快捷键
• 在任意网页上按 Mac 上的 ⌥⇧S（Windows 和 Linux 上的 Alt+Shift+S），无需打开 Bookmark Scout 即可保存：默认保存到与网页最匹配的文件夹（在你的设备上计算得出），也可以保存到上次使用的文件夹或指定的文件夹
• 网页中会显示一条小通知，说明保存到了哪里，并提供“撤消”和可移动到的其他文件夹
• 开启 AI 后，按 Mac 上的 ⌥⇧D（Windows 和 Linux 上的 Alt+Shift+D） 可将网页保存到 AI 建议的第一个文件夹
• 可在浏览器的快捷键页面中更改按键。也可以在那里将 Mac 上的 ⌘D（Windows 和 Linux 上的 Ctrl+D）分配给快速保存，以代替浏览器的书签对话框；设置中有操作说明

查找书签
• 直接在工具栏中，边输入边搜索你的所有书签：标题、地址、文件夹、标签和摘要都能搜到，还可以用 tag:、domain:、folder: 等运算符
• 文件夹树支持拖放、全部展开和收起，以及新建文件夹
• 侧边栏提供同样的文件夹树、搜索和匹配的文件夹
• 将指针停在书签上，即可查看它的地址、文件夹、标签和摘要
• 删除前需要确认（默认开启），并可在 10 秒内撤消

书签管理器
Bookmark Scout 将浏览器的书签页面替换为一个用法与浏览器自带管理器相同的管理器，并增加了路径导航、可排序的表格，以及始终显示最新结果的已保存搜索。
• 书签、文件夹和空白处都有右键菜单：修改、重命名、剪切、复制、粘贴、在新标签页或新窗口中打开、在文件夹中显示以及删除
• 通过拖放将书签移入文件夹或调整顺序；从其他网页拖入的链接会成为书签
• 用 Cmd+点击和 Shift+点击选择多行，并使用与浏览器自带管理器相同的键盘快捷键：Mac 上的 ⌘A、⌘C、⌘X、⌘V、⌘⌫，⌘Z 撤消，⇧⌘Z 重做（Windows 和 Linux 上的 Ctrl+点击、Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、Delete、Ctrl+Z 和 Ctrl+Shift+Z）
• 撤消和重做涵盖修改、移动、排序和删除，包括“询问 AI”所做的更改
• 以列表或卡片显示文件夹或搜索结果，卡片上有网页的封面图、标签和摘要；不打开书签也能预览
• 书签历史记录：列出书签的每一次更改及各项更改前的样子，可以撤消；即使已无法撤消，也能恢复已删除的项目
• 在设置中调整管理器和弹出窗口的菜单、列、卡片、侧边栏和键盘快捷键

清理多年积攒的书签
• 重复书签清理：检查重复组，选择要保留的副本，再移除其余副本
• 网址清理：预览并移除网址中的跟踪代码
• 失效链接检查：找出已经无法打开的链接，然后检查修复方案（删除、使用新地址、指向存档副本或手动修改），并可撤消
• 元数据获取：建议网页标题，只应用你选中的标题
• 隐私扫描：找出书签中的私密信息，例如电子邮件地址和链接中的登录代码
• 统计：网站、文件夹、层级深度和重复项
• 刷新网站图标：获取每个网站自己的图标，不使用第三方图标服务
• 智能规则：给与搜索匹配的书签添加标签并移到文件夹，先检查再应用；开启后也会用于新添加的书签
• 索引网页正文：将你选择的网页正文保存在此设备上，搜索时也能找到网页里的文字
• 获取封面：将每个网页的预览图保存在此设备上，用于卡片视图。开启“浏览时捕获封面”（默认关闭）后，会在你打开已加入书签的网页时截图
• 耗时较长的工具在关闭管理器后仍在后台继续运行，可暂停和继续；每个检查界面都能一次设置多个项目
• 导入书签文件，支持预览、重复项处理和撤消
• 导出为 HTML、JSON、Markdown 或 CSV，可选的隐私检查能隐藏私密信息

浏览器会询问什么，以及原因
安装时，浏览器只请求一项权限：“读取和更改您的书签”，以便 Bookmark Scout 保存、搜索和整理书签。其他权限只会在使用需要它的功能时才请求，并且会先显示简短说明。如果拒绝，只有该功能会保持关闭。
• “读取您访问过的网站对应的图标”：在“刷新网站图标”中点击“显示浏览器图标”，或开启“使用浏览器的图标缓存”时请求，用于在书签旁显示浏览器已保存的图标
• “读取和更改您在 所有example.com网站 上的数据”（或“读取和更改您在一些网站上的数据”）：运行失效链接检查、元数据获取、刷新网站图标、索引网页正文或获取封面时请求，且只针对该次运行涉及的网站。涉及超过 20 个网站的运行、AI 设置中的“读取网页内容”以及“浏览时捕获封面”，会请求“读取和更改您在所有网站上的所有数据”；“浏览时捕获封面”拍下的图片只保存在此设备上。请求不会附带 Cookie。允许访问所有网站后，“询问 AI”还可以检查已加入书签的链接是否仍然有效
• “读取您的浏览记录”：仅用于在侧边栏中保存当前网页或获取文件夹建议。工具栏按钮和快速保存快捷键不需要任何权限，Bookmark Scout 只会读取当前打开的标签页的标题和网址
• “与协作的本机应用通信”：仅在开启“本地 AI 智能体”时请求（请参阅下方的“面向开发者”）
右键菜单同样是可选的，但它没有警告提示，因此浏览器会直接添加，不会询问。

隐私
• 无需账号，没有分析、跟踪或广告
• 你的书签保留在浏览器中；标签、摘要、已保存的搜索、智能规则、网页正文、封面和书签历史记录只保存在此设备上
• 在浏览器支持的情况下，更改过的设置、自定义提示词和“关于我”会通过浏览器账号同步

可选的 AI（默认关闭）
AI 是可选的，以上所有功能无需 AI 即可使用。要使用 AI，你需要一个 AI 公司的账号（每次使用可能会收取少量费用），或一个在你自己电脑上运行的免费 AI 程序。Bookmark Scout 没有自己的 AI 服务：在设置中开启 AI，然后添加你选择的服务即可。
• 为当前网页建议文件夹，包括先经你确认的新文件夹
• 在 Chrome 中，由 Chrome 内置 AI 免费推荐文件夹：它在你的电脑上运行，无需账号或密钥（需电脑能够运行）
• 标签建议和简短摘要，保存前先行审核
• 文件夹重组方案，在做出任何更改前总会先预览
• 询问 AI：就书签进行对话。它可以按字词、文件夹、标签、网站或添加日期搜索书签，查找重复项、建议文件夹，以及查看当前网页
• 询问 AI 只在收到请求时才做更改：它可以保存网页，并以方案的形式提出移动、重命名、删除和新建文件夹，批准前不会更改任何内容。每项更改都可以撤消
• 回答末尾可以带有按钮：后续问题、可供选择的选项、将网页保存到建议的文件夹，或打开某个书签。点击之前不会执行任何操作
• 选择“询问 AI”可以查找或更改哪些内容（“设置 > AI”）
• 读取网页内容（默认关闭）：除标题和网址外，还发送每个网页的可读文本，以获得更好的建议
• 标签、摘要和新文件夹名称会使用你的语言、你选择的语言或每个网页自己的语言（“设置 > AI”）

使用 AI 功能时，所需的数据会从浏览器直接发送给所选的 AI 服务，并受该服务条款的约束：书签标题、网址、文件夹名称、书签的添加日期以及已保存的标签和摘要；当前网页的标题和网址；在“询问 AI”中发送的消息；你填写的“关于我”（如有）；“询问 AI”所检查的链接是否仍然有效；以及仅在开启“读取网页内容”时，相关网页的文本。不会向 Bookmark Scout 发送任何内容。API 密钥保存在此浏览器的本地扩展程序存储中，不会同步。使用 AI 服务可能会产生费用。

设置与备份
• 设置页底部的“备份设置”会把你选择的部分保存为一个文件：设置、此电脑的设置、已保存的搜索和表格视图、提示词和“关于我”、智能规则、AI 服务、封面。只有你选择时才会包含 API 密钥，并且会用密码保护
• “恢复设置”会先显示每个部分将发生的变化，再合并或替换；“撤消导入”可以复原
• 只保存更改过的设置，因此后续版本改进的默认值仍会生效

面向开发者
• 搜索运算符：title:、url:、domain:、folder:、tag:、summary:、content:（网页正文）、is:、has:、after:、before:、-（排除）、OR 和括号；另有区分大小写、全字匹配和正则表达式等搜索选项。管理器的地址中会保留搜索内容和文件夹，因此链接可以直接打开正在搜索（?q=react）的管理器，“后退”和“前进”会同时恢复两者
• AI 服务可以是云端 AI 服务商、任何兼容 OpenAI 的端点，或在自己电脑上运行的模型服务器，有没有 API 密钥都可以
• 将所选书签导出为 Markdown 或 XML 上下文，供 AI 对话使用（无需 AI，不发送任何内容）
• 隐私扫描还会标出敏感的查询参数、网址片段和 UUID
• 本地 AI 智能体（默认关闭）：让电脑上的 AI 智能体（如 Claude Code）通过单独的开源程序 bookmark-scout-mcp 查找书签。同时开启“允许更改”后，它们可以保存和整理书签，每项更改都会在 Bookmark Scout 窗口中等待批准
• 基于 AGPL-3.0 开源：https://github.com/isandrel/bookmark-scout

从早期版本更新
0.3.3 版以新格式存储数据，不会转换旧数据：设置会恢复为默认值，需要重新添加 AI 服务和 API 密钥，自定义提示词、已保存的搜索、标签、摘要和已保存的网站图标会被清除。书签本身不受影响。

由一位独立开发者制作：没有公司、没有广告、无需账号。支持 12 种界面语言。提供浅色、深色和跟随系统主题。

文档：https://docs.bookmark-scout.com
```
