## Full description: Chrome Web Store and Edge Add-ons

The same Edge condition as in `en.md` applies.

```text
Bookmark Scout 可以通过工具栏或一个键盘快捷键，在几秒钟内把每个网页保存到合适的文件夹，并且无需离开浏览器就能查找和整理书签。

几秒钟内保存到合适的文件夹
• 输入任意文件夹名称的一部分，即使是文件夹树深处的文件夹也能找到，无需离开键盘就能将当前网页保存到那里
• 输入 work/react 这样的路径；有小的拼写错误也能找到文件夹，最近使用过的文件夹排在前面
• 已在该文件夹中的网页不会重复保存
• 可选的 AI 会为网页建议最合适的文件夹，或建议一个新的文件夹路径，经确认后才会创建
• 可选的右键菜单（在设置中开启“右键菜单”），可将链接保存到最近使用的文件夹

快速保存快捷键
• 在任意网页上按 Alt+Shift+S，无需打开 Bookmark Scout 即可保存：默认保存到与网页最匹配的文件夹（排序在设备上完成），也可以保存到上次使用的文件夹或指定的文件夹
• 网页中会显示一条小通知，说明保存到了哪里，并提供“撤消”和可移动到的其他文件夹
• 开启 AI 后，按 Alt+Shift+D 可将网页保存到 AI 建议的第一个文件夹
• 可在浏览器的快捷键页面中更改按键。也可以在那里将 Ctrl+D（Mac 上为 ⌘D）分配给快速保存，以代替浏览器的书签对话框；设置中有操作说明

在工具栏中搜索
• 即时搜索所有书签，支持区分大小写、全字匹配和正则表达式
• 文件夹树支持拖放、全部展开和收起，以及新建文件夹
• 侧边栏提供同样的文件夹树、搜索和匹配的文件夹
• 删除前显示确认对话框（默认开启），并可在 10 秒内撤消

书签管理器
Bookmark Scout 将浏览器的书签页面替换为一个用法与浏览器自带管理器相同的管理器，并增加了路径导航、可排序和筛选的表格、可调整宽度的列，以及已保存的搜索（只保存筛选条件、始终显示最新结果的智能视图）。
• 书签、文件夹和空白处都有右键菜单：修改、重命名、剪切、复制、粘贴、在新标签页或新窗口中打开、在文件夹中显示以及删除
• 通过拖放将书签移入文件夹或调整顺序；从其他网页拖入的链接会成为书签
• 用 Ctrl+点击和 Shift+点击选择多行，并使用与浏览器自带管理器相同的键盘快捷键（Mac 上为 Cmd）：Ctrl+A、Ctrl+C、Ctrl+X、Ctrl+V、Delete，Ctrl+Z 撤消，Ctrl+Y 重做
• 撤消和重做涵盖修改、移动、排序和删除，包括“询问 AI”所做的更改
• 地址中会保留搜索内容和文件夹，因此链接可以直接打开正在搜索（?q=react）或位于某个文件夹的管理器，“后退”和“前进”会同时恢复两者
• 可选择右键菜单和 ⋯ 菜单显示哪些命令以及显示顺序（“设置 > 行为”）

维护工具
• 重复书签清理：先检查重复组，再移除多余的副本
• 网址清理：预览并移除跟踪参数
• 失效链接检查：找出无法访问的链接，然后检查修复方案（删除、使用重定向目标、指向存档副本或修改网址），并可撤消
• 元数据获取：建议网页标题，只应用选中的标题
• 隐私扫描：找出书签中的敏感查询参数、网址片段、电子邮件地址和 UUID
• 统计：域名、文件夹、层级深度和重复项
• 刷新网站图标：获取每个网站自己的图标，不使用第三方图标服务
• 从 HTML 或 JSON 导入，支持预览、重复项处理和撤消
• 导出为 HTML、JSON、Markdown 或 CSV，可选的隐私检查能对敏感值做脱敏处理

失效链接检查、元数据获取、刷新网站图标以及 AI 设置中的“读取网页内容”会在首次使用时请求可选的网站访问权限；授予后，“询问 AI”还可以检查已加入书签的链接是否仍然有效。安装时绝不会授予此权限，请求不会附带 Cookie，拒绝后只是关闭相应功能。

设置与备份
• 设置页底部的“导出”会保存一份备份：更改过的设置、自定义提示词、AI 服务（绝不包含其 API 密钥）、已保存的搜索以及管理器的列。用“导入”即可恢复
• 只保存更改过的设置，因此后续版本改进的默认值仍会生效

可选的 AI 工具（默认关闭）
在设置中开启 AI，然后选择云端 AI 服务商、任何兼容 OpenAI 的端点，或在自己电脑上运行的模型服务器；服务商需要 API 密钥时，使用自己的密钥。
• 为当前网页建议文件夹，包括经确认后创建新的文件夹路径
• 标签建议和简短摘要，保存前先行审核
• 文件夹重组方案，在做出任何更改前总会先预览
• 将所选书签导出为 Markdown 或 XML 上下文，供 AI 对话使用（无需 AI，不发送任何内容）
• 询问 AI：就书签进行对话。AI 可以按字词、文件夹、标签、网站或添加日期搜索书签，查找重复项、建议文件夹，以及查看当前网页
• 询问 AI 只在收到请求时才做更改：它可以保存网页，并以方案的形式提出移动、重命名、删除和新建文件夹，批准前不会更改任何内容。每项更改都可以撤消
• 回答末尾可以带有按钮：后续问题、可供选择的选项、将网页保存到建议的文件夹，或打开某个书签。点击之前不会执行任何操作
• 选择“询问 AI”可以查找或更改哪些内容（“设置 > AI”）
• 读取网页内容（默认关闭）：除标题和网址外，还发送每个网页的可读文本，以获得更好的建议
• 本地 AI 智能体（默认关闭）：让电脑上的 AI 智能体（如 Claude Code）通过单独的开源程序 bookmark-scout-mcp 查找书签。同时开启“允许更改”后，它们可以保存和整理书签，每项更改都会在 Bookmark Scout 窗口中等待批准

使用 AI 功能时，所需的数据会从浏览器直接发送给所选的服务商，并受该服务商条款的约束：书签标题、网址、文件夹名称、书签的添加日期以及已保存的标签和摘要；当前网页的标题和网址；在“询问 AI”中发送的消息；“询问 AI”所检查的链接是否仍然有效；以及仅在开启“读取网页内容”时，相关网页的文本。不会向 Bookmark Scout 发送任何内容。API 密钥保存在此浏览器的本地扩展程序存储中，不会同步。使用服务商可能会产生费用。

隐私
• 无需账号，没有分析、跟踪或广告
• 书签保留在浏览器中；标签、摘要和已保存的搜索保存在本地扩展程序存储中
• 在浏览器支持的情况下，更改过的设置和自定义提示词会通过浏览器账号同步
• 基于 AGPL-3.0 开源：https://github.com/isandrel/bookmark-scout

从早期版本更新
0.3.3 版以新格式存储数据，不会转换旧数据：设置会恢复为默认值，需要重新添加 AI 服务和 API 密钥，自定义提示词、已保存的搜索、标签、摘要和已保存的网站图标会被清除。书签本身不受影响。

支持 9 种界面语言。提供浅色、深色和跟随系统主题。

文档：https://docs.bookmark-scout.com
```

```text
• 快速保存：在任意网页上按 Alt+Shift+S，即可将其保存到最匹配的文件夹。网页中会显示一条通知，说明保存到了哪里，并提供“撤消”和可移动到的其他文件夹。开启 AI 后，按 Alt+Shift+D 可保存到 AI 建议的第一个文件夹
```
